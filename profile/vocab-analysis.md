## 0. 一句话结论 (TL;DR)

```
如果把库里所有词都学会 → 词汇面 ≈ A2 扎实（SFI C），B1（SFI D）大约完成一半。
   教材核心词：A1 98% · A2 82% · B1 54%
   最常用 4 000 词里覆盖 ≈ 1 880 个 → Milton 标尺 A2 段（1 500–2 500）

最大缺口不在生活词，而在「抽象 / 观点 / 论证」词（SFI D 写论述文正好要用）。
```

### 5.2 规律

```
强项：具体、日常、看得见摸得着的词（幼儿园、食物、动物、家居、天气）
   ↳ 来源：场景练习 + 幼儿园通知 + 生活查词
弱项：① 抽象 / 论证词（P1 73 个）   ← SFI D 写论述文、讨论时必需
      ② 社会 / 工作 / 学校的「制度词」 ← samhälls-, arbets-, studieliv 场景
      ③ 副词和连接词（KB 只有 4% 是副词）← 文本连贯、"visst flyt" 靠它们
      ④ 固定词组（B1 只覆盖 47%）
```

这正好对上 SFI C → D 的跨越（见 `levels.md` §2.2）：D 要求「较正式场景」和「汇报文 / 论述文」，缺的就是这三类词。

## 6. KB 质量审计 (Hygiene)

| 项目 | 结果 | 建议 |
|------|------|------|
| CEFR 标签 vs 参考表（相差 ≥ 3 级的 265 个，审了 261 个） | **254 个 KB 标得对**（Kelly 按频率把 `apelsin`、`apotek` 定成 C 级才是问题） | 只改 7 个：`allergisk` → A2 · `gunga` → A2 · `avsked` / `hetta` / `kräsen` / `kvist` / `lykta` → B1 |

| 用复数当词元 | `badbyxor`、`flingor`、`galonbyxor`、`massor`；`öppettider` **跟已有的 `öppettid.md` 重复** | 合并或改成单数词元（`vitvaror` 习惯用复数，可以保留） |
| 跟已有词条重复的变形 | `sämre` / `värsta`（已有 `dålig`）· `mest`（`mycket`）· `några`（`någon`） | 可以保留作快捷入口，但正文里要链接到原词（`ska` 不算：它是情态动词的正式词条，`skola` 是名词「学校」） |
| 专名大小写 | `valhall` 的 lemma → **Valhall** | — |

| 未审计的 CEFR 分歧 | 4 个：`behållare`、`bensinstation`、`keps`、`nattduksbord`（KB 标 A2，Kelly 标 C1/C2） | 都是具体日常名词，A2 基本合理（`behållare` 可考虑 B1） |

## 8. 局限 (Caveats)

- **「KB 有笔记」≠「你会」**：这份报告衡量的是库的覆盖面。你真实的词汇量要跑 `/assess` 抽测才知道（`levels.md` §8.5 有方法）。
- 基础词按「SFI C/D 学习者肯定会」来判断，没有实测。
- CEFR ↔ 词汇量的换算（Milton 2010）来自英语研究，只能当近似参考；瑞典语复合词多，按词元计数会**低估**实际认词能力。
- 「读过的词」用 SALDO 还原词元，同形词（`var`、`för`）会让这个数偏高，所以只用来算阅读覆盖率，不用来判断级别。
- P1 / P2 / P3 是代理按「SFI D / grund 学习者此刻的价值」判断的；你觉得哪个主题更急，就先补哪个。
