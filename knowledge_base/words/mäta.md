# mäta — verb (oregelbundet, grupp 4)

📖 中文：测量 · English: to measure
发音提示：/ˈmɛːta/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | mäta |
| Presens | mäter |
| Preteritum | mätte |
| Supinum | mätt |
| Imperativ | mät |

## 词组搭配 (Collocations)

- `mäta temperaturen` — 测量温度
- `mäta blodsockret` — 测血糖
- `mäta ett rum` — 量房间
- `mäta upp tyg` — 量布料
- `mäta sig med` — 与……相比/竞争

## 例句 (Sentences)

- 🇸🇪 Det är den varmaste dagen i Malmö sedan Sverige började mäta temperaturen. — 🇨🇳 这是自瑞典开始测量气温以来马尔默最热的一天。
- 🇸🇪 Läkaren mätte min kroppstemperatur och sa att jag hade feber. — 🇨🇳 医生量了我的体温，说我发烧了。
- 🇸🇪 Vi mätte rummet innan vi köpte den nya soffan. — 🇨🇳 我们在买新沙发之前量了房间的尺寸。
- 🇸🇪 Kan du mäta hur lång den här plankan är? — 🇨🇳 你能量一下这块木板有多长吗？

## 词族 / 同义 / 反义 (Relations)

- 词族: *mätning* (en, 测量/测定), *mätare* (en, 仪表/测量员), *mått* (ett, 尺寸/度量)
- 主题: —

## 用法提示 (Usage Notes)

- 不规则变位：mäta → mäter → mätte → mätt（短元音型）
- 注意 supinum *mätt* 与形容词 *mätt* (吃饱的) 同形——根据上下文区分
- *mäta sig med* (比喻) = 与……一较高下: *Han kan inte mäta sig med mästaren.*
