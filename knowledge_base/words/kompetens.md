# kompetens — substantiv

📖 中文：能力；资历 · English: competence, qualifications

🇸🇪 Förklaring: kunskaper och färdigheter som behövs för ett arbete

发音提示：/kɔmpeˈtɛns/ — 重音在最后音节 -tens；e 短音

## 语法变形 (Forms)

| | 单数 | 复数 |
|---|---|---|
| 不定 | en kompetens | kompetenser |
| 定指 | kompetensen | kompetenserna |

## 词组搭配 (Collocations)

- `hög kompetens` — 高水平能力
- `kompetens inom vården` — 医疗领域的能力

## 例句 (Sentences)

- 🇸🇪 Företaget söker personal med rätt kompetens. — 🇨🇳 公司寻找有合适能力的员工。
- 🇸🇪 Hans kompetens inom IT är stor. — 🇨🇳 他的 IT 能力很强。
- 🇸🇪 Du kan visa din kompetens i cv:t. — 🇨🇳 你可以在简历里展示你的能力。
