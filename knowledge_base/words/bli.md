# bli — verb

📖 中文：变成, 成为; 将会 · English: to become; will be
发音提示：bli（单音节）

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| infinitiv | bli |
| presens | blir |
| preteritum | blev |
| supinum | blivit |
| imperativ | bli! |

## 词组搭配 (Collocations)

- `bli bättre` — 变好
- `bli skadad` — 受伤
- `det ska bli arbeten` — 将会施工
- `bli svårare` — 变得更难

## 例句 (Sentences)

**义项 1 — 变成/成为 (to become):**
- 🇸🇪 Arbetena är till för att vägarna ska bli bättre. — 🇨🇳 施工是为了让路况变好。
- 🇸🇪 Det kan bli svårare att ta sig fram. — 🇨🇳 通行可能会变得更难。

**义项 2 — 受到（被动含义） (be/get):**
- 🇸🇪 Människor jobbar där och de kan bli skadade om folk kör för fort. — 🇨🇳 有人在那里工作，如果人们开太快他们会受伤。

## 用法提示 (Usage Notes)

- `bli` 是不规则动词：bli → blir → blev → blivit
- `bli + adjektiv` = 变得…（bli trött = 变得累）
- `bli + participium` = 被动含义（bli skadad = 受伤，bli betald = 被支付）
