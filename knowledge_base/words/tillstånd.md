# tillstånd — substantiv ett

📖 中文：许可；批准；允许 · English: permission; permit; approval
发音提示：[ˈtɪlˌstond] — stress on first syllable

## 词组搭配 (Collocations)

- `ansöka om tillstånd` — 申请许可 → see [[vända-sig-till]]
- `få tillstånd` — 获得许可
- `kräva tillstånd` — 需要许可证

## 例句 (Sentences)

- 🇸🇪 Jag är medveten om att det krävs tillstånd för husdjur. — 🇨🇳 我知道养宠物需要取得许可。
- 🇸🇪 Man behöver tillstånd för att ha hund i lägenheten. — 🇨🇳 在公寓里养狗需要许可。
- 🇸🇪 Hyresvärden gav tillstånd att renovera köket. — 🇨🇳 房东批准了翻新厨房的请求。

## 用法提示 (Usage Notes)

- Frequent in rental contracts, administrative texts, official applications.
- *ansöka om tillstånd* = to apply for permission (formal register).
- Compare: *lov* (informal permission, e.g. *be om lov*) vs *tillstånd* (official/formal).
