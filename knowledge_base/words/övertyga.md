# övertyga — verb (grupp 1)

📖 中文：说服，使信服 · English: to convince, to persuade
发音提示：/²øːvərˌtyːɡa/，重音在 ö-，结尾 -tyga

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) övertyga |
| Presens | övertygar |
| Preteritum | övertygade |
| Supinum | övertygat |
| Imperativ | övertyga! |

**Grupp 1 动词：** 词干以 `-a` 结尾，规则变化（-r / -de / -t）。

## 词组搭配 (Collocations)

- **`övertyga någon om något`** — 使某人相信某事
- `övertyga någon om att + bisats` — 说服某人相信……
- `vara övertygad om att…` — 确信……（用过去分词作形容词）
- `med övertygelse` — 充满信念地

## 例句 (Sentences)

- 🇸🇪 Hon övertygade mig om att det var rätt beslut. — 🇨🇳 她让我相信这是正确的决定。
- 🇸🇪 Argumenten övertygade alla i rummet. — 🇨🇳 这些论点说服了房间里所有人。
- 🇸🇪 Jag är övertygad om att han har rätt. — 🇨🇳 我确信他是对的。

## 词族 / 同义 / 反义 (Relations)

- 词族: övertygad (adj, 确信的/被说服的), övertygelse (en, 信念/确信), övertygande (adj, 有说服力的)
- 同义词: övertala (劝服 — 偏"劝动去做某事")
- 反义词: —
- 主题: —

## 用法提示 (Usage Notes)

- **固定介词 `om`**：`övertyga någon **om** något` = 让某人相信某事；别漏 om。
- **övertyga vs övertala：**
  - `övertyga` = 让人在**心里相信**某事（信念、观点）。
  - `övertala` = 劝动人去**做**某事（行动），常含"软磨硬泡"意味。
- 过去分词 `övertygad om att…` = "确信……"，是极高频的表达。
