# skydda — verb (grupp 1)

📖 中文：保护；防护 · English: to protect; to shield

🇸🇪 Förklaring: se till att någon eller något inte blir skadat eller utsatt för fara

发音提示：`sk` 在 `y` 前读 [ɧ]（类似"舍"），`skydda` ≈ "ɧYD-da"。

## 词组搭配 (Collocations)

- `skydda mot / från …` — 保护免受…… → [[skydda-mot]]
- `skydda sig (mot …)` — 保护自己、防范
- `skydda barn / miljön / naturen` — 保护儿童 / 环境 / 自然
- `skydda människor som går` — 保护行人
- `ett skydd` — 保护；防护物（名词）
- `skyddad / ett skyddat område` — 受保护的 / 保护区

## 例句 (Sentences)

- 🇸🇪 Vi måste skydda människor som går. — 🇨🇳 我们必须保护步行的人。 → [[sent-vi-vill-inte-förbjuda-elsparkcyklar-men-vi]]
- 🇸🇪 Hjälmen skyddar huvudet. — 🇨🇳 头盔保护头部。
- 🇸🇪 Ta på dig en jacka för att skydda dig mot kylan. — 🇨🇳 穿上外套，抵御寒冷。
- 🇸🇪 Lagen ska skydda barn mot våld. — 🇨🇳 法律应当保护儿童免受暴力。

## 用法提示 (Usage Notes)

- 介词：`skydda **mot** + 威胁`（mot kylan, mot våld）或 `skydda **från**`（从物理上遮挡 / 免遭）；直接宾语是被保护的对象。
- 别和 [[hindra]] 混：`skydda` = 保护（让某物不受伤害）；`hindra` = 阻止（不让某事发生 / 妨碍）。
- 反身用法：`skydda sig mot smitta`（防范传染）。
