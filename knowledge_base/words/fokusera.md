# fokusera — verb (grupp 1)

📖 中文：专注 · English: to focus

🇸🇪 Förklaring: rikta all sin uppmärksamhet och energi mot en sak

发音提示：/fɔkɵˈseːra/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) fokusera |
| Presens | fokuserar |
| Preteritum | fokuserade |
| Supinum | fokuserat |
| Imperativ | fokusera! |
| S-passiv (presens) | fokuseras |
| S-passiv (preteritum) | fokuserades |

## 词组搭配 (Collocations)

- `fokusera på …` — 专注于……（文中：kunna fokusera på sin träning）
- `för att kunna fokusera` — 为了能专注 → see [[för-att-kunna]]
- `tappa fokus` — 失去专注 → see [[tappa-fokus]]

## 例句 (Sentences)

- 🇸🇪 Därför gjorde han ett tävlingsuppehåll på 2 år för att kunna fokusera på sin träning. — 🇨🇳 于是他暂停比赛两年，以便专注训练。
- 🇸🇪 Jag kan inte fokusera när det är så högljutt. — 🇨🇳 这么吵我没法集中精神。
- 🇸🇪 Vi måste fokusera på det viktigaste först. — 🇨🇳 我们得先专注于最重要的事。
- 🇸🇪 Läraren ville att eleverna skulle fokusera på uppgiften. — 🇨🇳 老师希望学生专注于任务。

## 用法提示 (Usage Notes)

- 规则第 1 组动词（-era）：fokusera – fokuserar – fokuserade – fokuserat。s-passiv `fokuseras`（被聚焦）。
- 固定搭配 **på**：fokusera **på** något（专注于某事）。
- 文中 `för att kunna fokusera` = 目的状语：`för att + kunna + inf.`。
