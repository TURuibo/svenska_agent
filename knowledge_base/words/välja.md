# välja — verb (grupp 2, oregelbundet)

📖 中文：选择、挑选 · English: to choose, to select
发音提示：["vɛlja]，ä 发 [ɛ]（像 "air" 的元音）；lj 中的 l 要发音，不是 [j]。

## 语法变形 (Forms)

> ⚠️ 不规则：preteritum/supinum 有元音变化 ä → a（välj- → val-）。

| Form | Swedish |
|------|---------|
| Infinitiv | (att) välja |
| Imperativ | välj! |
| Presens | väljer |
| Preteritum | valde |
| Supinum | (har) valt |
| Perfekt particip | vald / valt / valda |

## 词组搭配 (Collocations)

- `välja mellan A och B` — 在 A 和 B 之间选择
- `välja bort` — 舍弃、不选（partikelverb）
- `välja ut` — 挑选出（partikelverb）
- `välja att göra ngt` — 选择去做某事
- `fritt att välja` — 可自由选择
- `ha att välja på` — 有得选

## 例句 (Sentences)

- 🇸🇪 Du får välja mellan kaffe och te. — 🇨🇳 你可以在咖啡和茶之间选一个。
- 🇸🇪 Jag valde den blå tröjan. — 🇨🇳 我选了那件蓝色的毛衣。
- 🇸🇪 Vi har valt att stanna hemma i helgen. — 🇨🇳 我们决定（选择）周末待在家。
- 🇸🇪 Välj ett kort, vilket som helst! — 🇨🇳 选一张牌，随便哪张都行！

## 用法提示 (Usage Notes)

- **常用词 (常用)**。属于第 2 组动词，但有词干元音变化 ä → a，要单独记：välja–valde–valt。
- *välja* + *att* + 动词原形 表示"选择做某事"：*Jag väljer att vänta.*（我选择等待。）
- 别和名词 *val*（选择 / 选举）混淆——动词是 *välja*，名词是 *val*。
- partikelverb 很重要：*välja bort*（舍弃）≠ *välja ut*（挑出），意思相反方向。
