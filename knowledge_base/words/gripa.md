# gripa — verb

📖 中文：抓捕，逮捕；抓住 · English: to seize, arrest; to grasp
发音提示：['griːpa]

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| infinitiv | gripa |
| presens | griper |
| preteritum | grep |
| supinum | gripit |
| s-passiv preteritum | greps（被捕） |
| imperativ | grip! |

## 词组搭配 (Collocations)

- `gripa en misstänkt` — 逮捕嫌疑人
- `greps av polisen` — 被警察逮捕
- `gripas på bar gärning` — 当场被捕

## 例句 (Sentences)

- 🇸🇪 Mannen greps i Irak hösten 2023. — 🇨🇳 该男子于 2023 年秋天在伊拉克被捕。
- 🇸🇪 Polisen grep tre personer efter rånet. — 🇨🇳 警察在抢劫案发生后逮捕了三名嫌疑人。
- 🇸🇪 Den misstänkte greps vid gränsen. — 🇨🇳 嫌疑人在边境被捕。

## 用法提示 (Usage Notes)

- 不规则动词（starka verb）：gripa → grep → gripit
- s-被动形式：greps（被抓/被捕）是常见新闻用法
- 语义双关：物理上"抓住"（gripa tag i）和警察意义上"逮捕"
