# lurvig — adjektiv

📖 中文：毛茸茸的 · English: shaggy/furry
发音提示：/ˈlʉːrvɪɡ/

## 语法变形 (Forms)

| form | böjning |
|------|---------|
| utrum obestämd | lurvig |
| neutrum obestämd | lurvigt |
| bestämd/plural | lurviga |
| komparativ | lurvigare |
| superlativ | lurvigast |

## 词组搭配 (Collocations)

- `en lurvig räv` — 一只毛茸茸的狐狸
- `lurvigt päls` — 蓬乱的皮毛
- `en lurvig hund` — 一条毛茸茸的狗

## 例句 (Sentences)

- 🇸🇪 Räven är lurvig och håller sig varm om vintern. — 🇨🇳 狐狸毛茸茸的，冬天能保暖。
- 🇸🇪 Den lurviga hunden behöver klippas. — 🇨🇳 那条毛茸茸的狗需要剪毛。
- 🇸🇪 Björnen ser lurvig och mjuk ut. — 🇨🇳 熊看起来毛茸茸的，很柔软。
