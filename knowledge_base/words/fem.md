# fem — räkneord

📖 中文：五 · English: five

🇸🇪 Förklaring: talet efter fyra och före sex

发音提示：/fɛm/ — e 读开口短音 [ɛ]，近似 "fɛm"

## 语法变形 (Forms)

| 类型 | 形式 |
|------|------|
| 基数词 | fem |
| 序数词 | [[femte]] (第五) |
| 十五 / 五十 | [[femton]] / [[femtio]] |

## 词组搭配 (Collocations)

- `fem minuter` — 五分钟
- `klockan fem` — 五点钟
- `fem över / fem i` — 过五分 / 差五分 → see [[grammar-klockan-tidsuttryck]]

## 例句 (Sentences)

- 🇸🇪 Jag har fem minuter. — 🇨🇳 我有五分钟。
- 🇸🇪 Lektionen slutar klockan fem. — 🇨🇳 课五点结束。
- 🇸🇪 Hon har fem syskon. — 🇨🇳 她有五个兄弟姐妹。
