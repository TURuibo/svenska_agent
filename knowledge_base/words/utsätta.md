# utsätta — verb

📖 中文：使遭受；使暴露于（常用 utsätta … för …） · English: to expose, subject to

🇸🇪 Förklaring: göra så att någon eller något råkar ut för något farligt eller dåligt

发音提示：/ˈʉːtˌsɛta/ — 重音在 ut；ä 读短音 ɛ（ts 后）

## 语法变形 (Forms)

| 形式 | 词形 |
|------|------|
| 不定式 | utsätta |
| 现在时 | utsätter |
| 过去时 | utsatte |
| 完成时 | har utsatt |
| 过去分词 | utsatt / utsatta |

## 词组搭配 (Collocations)

- `utsätta någon för våld` — 对某人施暴 → see [[utsatt-för-våld]]
- `utsätta sig för risk` — 让自己冒险
- `bli utsatt för` — 遭受（被动，见 [[utsatt-för]]）

## 例句 (Sentences)

- 🇸🇪 Han utsätter sina nära för våld. — 🇨🇳 他对身边的人施暴。
- 🇸🇪 Du ska inte utsätta barnen för fara. — 🇨🇳 你不该让孩子们置身危险。
- 🇸🇪 Hon utsatte sig för stor risk. — 🇨🇳 她让自己冒了很大的风险。
