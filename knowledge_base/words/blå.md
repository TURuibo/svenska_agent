# blå — adjektiv

📖 中文：蓝色的 · English: blue
发音提示：/bloː/

## 语法变形 (Forms)

| form | en-form | ett-form | plural/bestämd |
|------|---------|----------|----------------|
| positiv obestämd | en blå (fågel) | ett blått (djur) | blå / blåa (djur) |
| positiv bestämd | den blå/blåa (fågeln) | det blå/blåa (djuret) | de blå/blåa (djuren) |
| komparativ | blåare | | |
| superlativ | blåast / blåaste | | |

**Obs:** *blå* har oregelbunden ett-form *blått* (dubbel-t). Bestämd form kan vara *blå* eller *blåa*.

## 词组搭配 (Collocations)

- `blå himmel` — 蓝天
- `blå ögon` — 蓝眼睛
- `en blå fågel` — 一只蓝色的鸟
- `blå val` — 蓝鲸
