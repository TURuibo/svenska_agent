# motivation — substantiv

📖 中文：动力、积极性 · English: motivation
发音提示：重音在 -ation，/mutiva'ʃuːn/

## 语法变形 (Forms)

| | 单数 | 复数 |
|---|---|---|
| 不定 | en motivation | motivationer |
| 定 | motivationen | motivationerna |

## 词组搭配 (Collocations)

- `känna motivation till att + inf.` — 有……的动力 → see [[grammar-preposition-att-infinitiv]]
- `ha svårt att känna motivation` — 很难有动力 → see [[ha-svårt-att]]
- `tappa motivationen` — 失去动力
- `hitta motivation` — 找到动力

## 例句 (Sentences)

- 🇸🇪 Jag har svårt att känna motivation till att träna. — 🇨🇳 我很难有锻炼的动力。
- 🇸🇪 Vad ger dig motivation att plugga svenska? — 🇨🇳 什么给你学瑞典语的动力？
- 🇸🇪 Min motivation är bättre när jag tränar med en vän. — 🇨🇳 和朋友一起锻炼时，我的动力更足。
