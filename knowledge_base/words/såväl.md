# såväl — adverb/konjunktion

📖 中文：……也……；既……又…… · English: as well as

🇸🇪 Förklaring: ord som används med som för att lägga till något mer

发音提示：/ˈsoːˌvɛːl/ — 重音在 så；å 读长音 /oː/，väl 读 /vɛːl/

## 语法变形 (Forms)

不变词 (oböjligt)；固定搭配 *såväl … som*

## 词组搭配 (Collocations)

- `såväl … som` — ……也好……也好 → see [[såväl-som]]

## 例句 (Sentences)

- 🇸🇪 Såväl barn som vuxna gillar glass. — 🇨🇳 孩子和大人都喜欢冰淇淋。
- 🇸🇪 Hon talar såväl svenska som engelska. — 🇨🇳 她既会说瑞典语也会说英语。
- 🇸🇪 Såväl lärare som elever var nöjda. — 🇨🇳 老师和学生都满意。
