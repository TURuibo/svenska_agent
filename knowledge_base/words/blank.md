# blank — adjektiv

📖 中文：光亮的；闪亮的 · English: shiny; glossy

🇸🇪 Förklaring: som har en slät yta som reflekterar ljus

发音提示：/blaŋk/ — nk 读 /ŋk/；a 短音

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| en-ord (sg. obestämd) | en blank |
| ett-ord | ett blankt |
| bestämd / plural | blanka |
| komparativ | blankare |
| superlativ | blankast |

## 词组搭配 (Collocations)

- `blank gaffel` — 光亮的叉子 → see [[gaffel]]
- `blank som en spegel` — 亮得像镜子

## 例句 (Sentences)

- 🇸🇪 Den blanka gaffeln ligger på bordet. — 🇨🇳 光亮的叉子放在桌上。
- 🇸🇪 Jag putsar kniven tills den är blank. — 🇨🇳 我把刀擦到发亮。
- 🇸🇪 Golvet är nytt och blankt. — 🇨🇳 地板是新的，很光亮。

## 词族 / 同义 / 反义 (Relations)

- 词族: [[blankpolera]] (抛光)
- 同义词: [[glansig]] (有光泽的)
- 反义词: [[matt]] (无光泽的)
- 主题: [[topic-mat-dryck]]

## 用法提示 (Usage Notes)

- 与 [[matt]] 相对；注意 blank 也可指「空白的」(blank tom)，此处为光亮义。
