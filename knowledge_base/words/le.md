# le — verb (oregelbundet)

📖 中文：微笑 · English: to smile

🇸🇪 Förklaring: dra upp mungiporna och visa att man är glad eller vänlig

发音提示：/leː/ — e 读长音 eː

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | le |
| Presens | ler |
| Preteritum | log |
| Supinum | lett |
| Imperativ | le |

## 词组搭配 (Collocations)

- `le mot någon` — 对某人微笑
- `le uppmuntrande` — 鼓励地微笑

## 例句 (Sentences)

- 🇸🇪 Jag log mot folk jag mötte på gatan. — 🇨🇳 我对街上遇到的人微笑。
- 🇸🇪 Han lägger ifrån sig surfplattan och ler uppmuntrande. — 🇨🇳 他放下平板，鼓励地微笑。
- 🇸🇪 Barnet ler när det ser sin mamma. — 🇨🇳 孩子看到妈妈就笑了。
