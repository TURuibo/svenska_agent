# farfar — substantiv (en)

📖 中文：祖父（父亲的父亲）；爷爷 · English: paternal grandfather

🇸🇪 Förklaring: den man som är pappa till ens pappa

发音提示：/ˈfarˌfaːr/ — far（父）+ far（父），第一音节重读。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Singular obestämd | farfar |
| Singular bestämd | farfadern |
| Plural obestämd | farfäder |
| Plural bestämd | farfäderna |

（日常几乎只用 *farfar*，常像名字一样不加冠词：*Farfar kommer!*；*farfadern / farfäder* 书面、较正式，*farfäder* 多指"父系祖先"。）

## 词组搭配 (Collocations)

- `hans farfar` — 他的爷爷
- `farfar och farmor` — 爷爷奶奶
- `hälsa på farfar` — 去看爷爷 → see [[hälsa-på]]
- `komma från sin farfar` — 源自（他的）祖父

## 例句 (Sentences)

- 🇸🇪 Det nederländska efternamnet kommer från hans farfar som emigrerade och bosatte sig i Trollhättan på 50-talet. — 🇨🇳 这个荷兰姓氏来自他的祖父，祖父在五十年代移民并定居在 Trollhättan。
- 🇸🇪 Min farfar är åttio år gammal. — 🇨🇳 我爷爷八十岁了。
- 🇸🇪 Farfar läser en saga för barnen. — 🇨🇳 爷爷给孩子们读故事。
- 🇸🇪 Vi hälsar på farfar och farmor på söndag. — 🇨🇳 周日我们去看爷爷奶奶。

## 用法提示 (Usage Notes)

- 瑞典语**区分父系 / 母系**，词是"far/mor + far/mor"拼起来的——**第一个成分 = 通过谁**，第二个 = 性别：

| 词 | 构成 | 中文 |
|----|------|------|
| farfar | far + far | 爷爷（爸爸的爸爸） |
| farmor | far + mor | 奶奶（爸爸的妈妈） |
| morfar | mor + far | 外公（妈妈的爸爸） |
| mormor | mor + mor | 外婆（妈妈的妈妈） |

- 英语只有 grandfather / grandmother，不区分，所以要特别记。
- 文章中的用法：`hans farfar som emigrerade`——解释姓氏（van der Poel）的荷兰来源。
