# kalas — substantiv (ett)

📖 中文：聚会；派对（庆祝） · English: party; celebration; feast
发音提示：/ˈkɑːlas/；ka-las，重音在第一音节，短 a。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Singular obestämd | ett kalas |
| Singular bestämd | kalasет |
| Plural obestämd | kalas |
| Plural bestämd | kalasеn |

## 词组搭配 (Collocations)

- `ha kalas` — 举办聚会 → 见 [[bjuda-på]]
- `på kalas` — 在聚会上；去参加聚会
- `barnkalas` — 儿童派对（常见复合词）
- `födelsdagskalas` — 生日派对

## 例句 (Sentences)

- 🇸🇪 Du är hjärtligt välkommen på kalas hos oss! — 🇨🇳 诚挚邀请你来我们家参加聚会！
- 🇸🇪 Barnen hade ett jätteroligt kalas på lördag. — 🇨🇳 孩子们周六举办了一个超棒的派对。
- 🇸🇪 Jag var på kalas hos min kompis igår. — 🇨🇳 我昨天去参加了朋友的聚会。
