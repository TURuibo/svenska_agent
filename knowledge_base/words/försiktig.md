# försiktig — adjektiv

📖 中文：谨慎的/小心的 · English: careful, cautious
发音提示：/fœˈsɪktɪɡ/ — "för-SIK-tig"

## 语法变形 (Forms)

| form | exempel |
|------|---------|
| obestämd singular (en-ord) | en **försiktig** person |
| obestämd singular (ett-ord) | ett **försiktigt** steg |
| bestämd / plural | den **försiktiga** personen · **försiktiga** människor |
| komparativ | **försiktigare** |
| superlativ (obestämd) | **försiktigast** |
| superlativ (bestämd) | den **försiktigaste** |

Se [[grammar-adjektiv-bojning]], [[grammar-adjektiv-kongruens]]

## 词组搭配 (Collocations)

- `vara försiktig` — 小心一点
- `ta det försiktigt` — 慢慢来/小心翼翼
- `en försiktig uppskattning` — 保守估计

## 例句 (Sentences)

- 🇸🇪 Var försiktig när du korsar gatan! — 🇨🇳 过马路时要小心！
- 🇸🇪 Hon kör alltid försiktigt i regnet. — 🇨🇳 她下雨天开车总是很谨慎。
- 🇸🇪 Det är viktigt att vara försiktig med pengar. — 🇨🇳 对钱要谨慎是很重要的。

## 用法提示 (Usage Notes)

- *Var försiktig!* = 小心！/ 注意安全！（常用警告语）
- Neutrum: **försiktigt** (ett-form) — också används som adverb: *köra försiktigt* (drive carefully).
