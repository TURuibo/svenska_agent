# lita — verb

📖 中文：信任，依靠（lita på） · English: to trust, to rely (lita på)

🇸🇪 Förklaring: tro att någon eller något är säkert och ärligt

发音提示：/ˈliːta/ — i 读长音 iː；t 清晰

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| infinitiv | lita |
| presens | litar |
| preteritum | litade |
| supinum | litat |
| imperativ | lita |

## 词组搭配 (Collocations)

- `lita på någon` — 相信某人
- `lita på att …` — 相信……

## 例句 (Sentences)

- 🇸🇪 Du kan lita på mig. — 🇨🇳 你可以相信我。
- 🇸🇪 Idag kan jag nästan lita på honom helt. — 🇨🇳 如今我几乎可以完全信任他。
- 🇸🇪 Jag litar inte på vädret i november. — 🇨🇳 我不相信十一月的天气。
