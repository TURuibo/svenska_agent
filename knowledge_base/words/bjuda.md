# bjuda — verb

📖 中文：邀请；请客；提供 · English: invite; treat; offer
发音提示：/ˈbjuːda/

## 语法变形 (Forms)

| form | exempel |
|------|---------|
| infinitiv | bjuda |
| presens | bjuder |
| preteritum | bjöd |
| supinum | bjudit |
| imperativ | bjud! |

## 词组搭配 (Collocations)

- `bjuda på` — 请客；提供（免费）→ see [[bjuda-på]]
- `bjuda hem` — 邀请回家
- `bjuda på sig själv` — 自嘲；付出自己

## 例句 (Sentences)

- 🇸🇪 Jag bjuder på middagen ikväll! — 🇨🇳 今晚晚饭我请客！
- 🇸🇪 Vi bjöd hem vänner på kaffe. — 🇨🇳 我们邀请朋友来家里喝咖啡。
- 🇸🇪 Kan jag bjuda dig på en fika? — 🇨🇳 我能请你吃个下午茶吗？

## 词族 / 同义 / 反义 (Relations)

- 词族: bjudning (宴请/聚会), bjudmat (宴客食物)
- 同义词: inbjuda (邀请, 更正式)

## 用法提示 (Usage Notes)

- `bjuda på` = 请客（付账）或提供某物（免费给予）。
- `bjuda in` = 邀请进入/加入（更正式语境）。
- oregelbundet verb: bjuda – bjuder – bjöd – bjudit。
