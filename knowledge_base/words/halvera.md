# halvera — verb

📖 中文：减半 · English: to halve
发音提示：hal-VE-ra，重音第二音节。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | att halvera |
| Imperativ | halvera! |
| Presens | halverar |
| Preteritum | halverade |
| Supinum | (har) halverat |

规则 grupp 1 动词（-ar/-ade/-at）。

## 词组搭配 (Collocations)

- `halvera priset` — 把价格减半
- `halvera antalet` — 把数量减半
- `halvera kostnaden` — 将成本减半

## 例句 (Sentences)

- [[sent-regeringen-vill-halvera-priset]] 🇸🇪 Regeringen vill halvera priset på månadskort i kollektivtrafiken. 🇨🇳 政府希望将公共交通月票价格减半。
- 🇸🇪 Vi kan **halvera** kostnaderna om vi åker kollektivt.
  🇨🇳 如果我们乘坐公共交通，可以将费用减半。
- 🇸🇪 Antalet olyckor har **halverats** på tio år.
  🇨🇳 十年来事故数量减少了一半。

## 词族 / 同义 / 反义 (Relations)

- 词族: [[halv]] (adj. 半), [[halva]] (en, 一半), [[halvering]] (en, 减半)
- 同义词: [[minska]] (v. 减少，不一定减半)
- 反义词: [[fördubbla]] (v. 加倍), [[öka]] (v. 增加)
- 主题: [[topic-nyheter-vecka22]]

## 用法提示 (Usage Notes)

- 来自 *halv*（半），加 `-era` 后缀构成动词，表示"使成一半"。
- 常见于新闻和政治语境：*halvera utsläppen*（将排放量减半）。
