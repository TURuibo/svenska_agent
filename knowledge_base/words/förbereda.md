# förbereda — verb

📖 中文：准备 · English: to prepare

🇸🇪 Förklaring: göra så att något eller någon är klar för det som ska hända

发音提示：/fœrˈbeːrɛda/ — 重音在 be，长音 eː；för- 不重读

## 语法变形 (Forms)

| 形式 | 例 |
|---|---|
| infinitiv | förbereda |
| presens | förbereder |
| preteritum | förberedde |
| supinum | förberett |
| imperativ | förbered! |

## 词组搭配 (Collocations)

- `förbereda sig på/inför` — 为……做准备
- `förbereda en middag` — 准备晚餐

## 例句 (Sentences)

- 🇸🇪 Jag måste förbereda mycket inför flytten. — 🇨🇳 我得为搬家准备很多东西。
- 🇸🇪 Läraren förbereder lektionen. — 🇨🇳 老师在备课。
- 🇸🇪 Hon förberedde sig noga för provet. — 🇨🇳 她为考试认真做了准备。
