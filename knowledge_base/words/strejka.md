# strejka — verb (v.1)

📖 中文：罢工，罢课 · English: strike, protest
发音提示：/ˈstrɛjka/；v.1 动词（-ar 结尾）。

## 语法变形 (Forms)

| tempus | form |
|--------|------|
| infinitiv | strejka |
| presens | strejkar |
| preteritum | strejkade |
| supinum | strejkat |
| imperativ | strejka |

## 词组搭配 (Collocations)

- `strejka för klimatet` — 为气候罢课
- `strejka på fredagar` — 在星期五罢课
- `börja strejka` — 开始罢工/罢课

## 例句 (Sentences)

- 🇸🇪 [[sent-många-unga-människor-började-också-strejka]] Många unga människor började också strejka för klimatet på fredagar. — 🇨🇳 许多年轻人也开始在周五为气候罢课。
- 🇸🇪 Arbetarna strejkade för bättre löner. — 🇨🇳 工人们为了更好的工资而罢工。
- 🇸🇪 Eleverna strejkade varje fredag. — 🇨🇳 学生们每个星期五都罢课。
