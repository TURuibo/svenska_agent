# hinna — verb

📖 中文：来得及；有时间（做某事） · English: to have time to; to manage to; to make it (in time)
发音提示：['hɪna]

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| infinitiv | hinna |
| presens | hinner |
| preteritum | hann |
| supinum | hunnit |
| imperativ | hinn |

> ⚠️ 强变化动词（oregelbundet）：hinna → hinner → hann → hunnit

## 词组搭配 (Collocations)

- `hinna (med) att + infinitiv` — 来得及做某事
- `hinna inte` — 来不及；没时间
- `hann du äta?` — 你吃了吗？（来得及吃吗？）
- `hinna hem` — 来得及回家
- `hinna med tåget` — 赶上火车

## 例句 (Sentences)

- 🇸🇪 Jag hann inte ringa dig igår. — 🇨🇳 我昨天没来得及给你打电话。
- 🇸🇪 Hann du äta frukost innan jobbet? — 🇨🇳 你上班前来得及吃早饭吗？
- 🇸🇪 Vi hinner inte med det nu. — 🇨🇳 我们现在没时间做那件事。
- 🇸🇪 Hann du städa och svara på mejlen? — 🇨🇳 你来得及打扫和回邮件了吗？
