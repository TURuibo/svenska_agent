# hinna — verb

📖 中文：来得及；有时间做；赶上 · English: to have time to; to manage to; to make it
发音提示：HIN-na（短促，重音在第一音节）

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| infinitiv | hinna |
| presens | hinner |
| preteritum | hann |
| supinum | hunnit |
| imperativ | hinn! |

## 词组搭配 (Collocations)

- `hinner du?` — 你来得及吗？你有时间吗？
- `hinna med` — 来得及；赶上（公车/会议等）
- `hinner inte` — 来不及；没时间
- `äntligen hann ses` — 终于有时间见面了

## 例句 (Sentences)

- 🇸🇪 Det är kul att vi äntligen hann ses! — 🇨🇳 很高兴我们终于找到时间见面了！
- 🇸🇪 Hinner du med bussen klockan fem? — 🇨🇳 你来得及赶上五点的公车吗？
- 🇸🇪 Jag hann inte äta frukost imorse. — 🇨🇳 我今早来不及吃早饭。

## 用法提示 (Usage Notes)

- `hinna` 是第四类动词（强变化）：`hinner` → `hann` → `hunnit`。
- 常加不定式：`hinna ses`（有时间见面），`hinna äta`（来得及吃）。
- 与 `kunna`（can/able to）区别：`hinna` 强调"时间上来得及"，`kunna` 强调"能力上能"。
- 否定常用 `hinner inte` = 来不及；有时间则说 `hinner` 或 `har tid att`。
