# rimlig — adjektiv

📖 中文：合理的；适度的 · English: reasonable; fair

🇸🇪 Förklaring: som verkar förnuftig och lagom; som man kan acceptera

发音提示：RIM-lig，重音在第一音节 `rim`；词尾 `-lig` 读 [lɪg]。

## 语法变形 (Forms)

| 形式 | Swedish | 例 |
|------|---------|----|
| en-ord | rimlig | en rimlig nivå |
| ett-ord | rimligt | ett rimligt pris |
| 复数 / 定形 | rimliga | rimliga kostnader |
| 副词 | rimligen / rimligtvis | Det är rimligtvis så. |
| 比较级 / 最高级 | rimligare / rimligast | |

## 词组搭配 (Collocations)

- `ett rimligt pris` — 合理的价格
- `en rimlig nivå` — 合理水平 → see [[leva-på-en-rimlig-nivå]]
- `rimlig tid` — 合理的时间
- `det är rimligt att …` — ……是合理的
- `en rimlig förklaring` — 说得通的解释
- `orimlig` — 不合理的（反义，加 `o-`）

## 例句 (Sentences)

- 🇸🇪 Priset är rimligt. — 🇨🇳 价格合理。
- 🇸🇪 Det är rimligt att vi delar på kostnaden. — 🇨🇳 我们分摊费用是合理的。
- 🇸🇪 Socialtjänsten bedömer om kostnaderna är rimliga. — 🇨🇳 社会服务处会评估这些费用是否合理。 → [[sent-socialtjänsten-bedömer-om-kostnaderna-är-rimliga]]
- 🇸🇪 Vad som är rimligt beror på olika saker. — 🇨🇳 什么算合理取决于不同情况。 → [[sent-vad-som-är-rimligt-beror-på-olika]]

## 用法提示 (Usage Notes)

- ⚠️ `rimlig` ≠ `billig`：它是"**说得过去、不过分**"，不是"便宜"。`ett rimligt pris` = 价格公道。
- 谓语位置要按名词变性：`Kostnaderna är rimliga.` / `Vad som är rimligt…`（中性 `rimligt`）。
- 官方文本用 `rimlig nivå`；法律原文常用 `skälig levnadsnivå`，意思相同。
