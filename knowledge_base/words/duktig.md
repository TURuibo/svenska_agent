# duktig — adjektiv

📖 中文：能干的；擅长的；努力的 · English: skilled; capable; diligent; good
发音提示：/ˈdɵktɪɡ/

## 语法变形 (Forms)

| form | exempel |
|------|---------|
| en-form (grundform) | duktig |
| ett-form | duktigt |
| plural / bestämd | duktiga |
| komparativ | duktigare |
| superlativ | duktigast |

## 词组搭配 (Collocations)

- `vara duktig på` — 擅长 → see [[vara-duktig-på]]
- `duktig på att` — 擅长做…… → see [[duktig-på-att]]
- `en duktig elev` — 一个努力/优秀的学生

## 例句 (Sentences)

- 🇸🇪 Hon är väldigt duktig på svenska. — 🇨🇳 她瑞典语说得很好。
- 🇸🇪 Du är duktig! Fortsätt så. — 🇨🇳 你很棒！继续加油。
- 🇸🇪 Han är en duktig läkare. — 🇨🇳 他是一位能干的医生。

## 词族 / 同义 / 反义 (Relations)

- 词族: duktighet (能力/才干)
- 同义词: [[klok]] (明智的), skicklig (技术熟练的)
- 主题: [[topic-karaktarsord]]

## 用法提示 (Usage Notes)

- `duktig på ngt/att göra ngt` 是核心搭配：vara duktig på matematik（擅长数学）。
- 在瑞典儿童文化中，`duktig` 也有"听话、乖"的含义（"vara duktig" = behave well）。
