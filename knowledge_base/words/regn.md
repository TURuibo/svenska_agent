# regn — substantiv (ett)

📖 中文：雨 · English: rain
发音提示：[reŋn]

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| obestämd singular | ett regn |
| bestämd singular | regnet |
| plural (obestämd) | regn |
| plural (bestämd) | regnen |

## 词组搭配 (Collocations)

- `mycket regn` — 大雨
- `lite regn` — 小雨
- `det kan bli regn` — 可能下雨

## 例句 (Sentences)

- 🇸🇪 Det kan bli åska och mycket regn i helgen. — 🇨🇳 周末可能有雷暴和大雨。
- 🇸🇪 Det regnar ute, ta med paraply. — 🇨🇳 外面在下雨，带上雨伞。
- 🇸🇪 Efter regnet kom solen fram. — 🇨🇳 雨后阳光出来了。

## 词族 / 同义 / 反义 (Relations)

- 词族: regna (下雨), regnig (雨天的), regnbåge (彩虹)

## 用法提示 (Usage Notes)

- `det regnar` = 在下雨（动词 regna）；`regn` 是名词。
- 关联词：[[väder]] (天气)、[[moln]] (云)、[[åska]] (雷暴)。
