# hakkors — substantiv (ett)

📖 中文：卐字符；纳粹十字 · English: swastika
发音提示：HAK-kors；两个清晰音节。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Singular obestämd | ett hakkors |
| Singular bestämd | hakkorset |
| Plural obestämd | hakkors |
| Plural bestämd | hakorsen |

## 词组搭配 (Collocations)

- `flagga med ett hakkors` — 带有卐字的旗帜
- `nazistiskt hakkors` — 纳粹卐字符
- `rita ett hakkors` — 画卐字符

## 例句 (Sentences)

- 🇸🇈 Polisen hittade en flagga med ett hakkors. — 🇨🇳 警察发现了一面带有卐字的旗帜。
- 🇸🇈 Att visa ett hakkors är ett brott i många länder. — 🇨🇳 在许多国家展示卐字符是违法行为。
- 🇸🇈 Hakkors är en symbol för nazismen. — 🇨🇳 卐字符是纳粹主义的象征。
