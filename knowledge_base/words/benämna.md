# benämna — verb

📖 中文：命名；把做的事说出来 · English: to name, to label (in words)
发音提示：/beˈnɛmːna/ — 重音在 -nämn-

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | benämna |
| Presens | benämner |
| Preteritum | benämnde |
| Supinum | benämnt |
| Imperativ | benämn! |

## 词组搭配 (Collocations)

- `benämna det ni gör` — 把你们做的事说出来
- `benämna saker` — 说出东西的名字
- `benämna känslor` — 说出情绪的名字

## 例句 (Sentences)

- 🇸🇪 Benämn det ni gör, till exempel "nu tar vi på jackan". — 🇨🇳 把你们正在做的事说出来，比如「现在我们穿外套」。
- 🇸🇪 Pedagogerna benämner allt de gör med barnen. — 🇨🇳 老师们把和孩子做的每件事都说出来。
- 🇸🇪 Det hjälper att benämna barnets känslor. — 🇨🇳 说出孩子的情绪名字很有帮助。

## 用法提示 (Usage Notes)

- v.2a 动词（词干 -n → 过去式 -de）。语言发展语境的关键词：benämna = 边做边说出名字，是给小孩「语言输入」的方法。
- 名词 benämning（名称）。
