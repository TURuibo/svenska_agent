# be — verb (grupp 4, oregelbundet)

📖 中文：请求；恳求；祈祷 · English: to ask (for), request; to pray
发音提示：/beː/（现在时 **ber** /beːr/）

## 语法变形 (Forms)

| 形式 | 写法 |
|------|------|
| infinitiv | (att) be |
| presens | **ber** |
| preteritum | bad |
| supinum | bett |
| imperativ | be! |

> ⚠️ 不规则短元音动词（e–a–e 元音交替），和 [[ge]]（ge–gav–gett）、[[se]]（se–såg–sett）同一小组。
> 你查的 **ber** 就是现在时 (presens)。

## 词组搭配 (Collocations)

- `be om ngt` — 请求某物（be om hjälp 求助；be om ursäkt 道歉）
- `be ngn (att) göra ngt` — 请某人做某事 → [[sent-ber-kommunen-bygga-cykelbana-storgatan]]
- `be en bön` / `be till Gud` — 祈祷 / 向上帝祈祷
- `jag ber er …` — 我恳请你们…… → [[jag-ber-er]]
- `vi ber om ert tålamod` — 我们恳请诸位耐心 → [[ber-om-ert-tålamod]]

## 例句 (Sentences)

- 🇸🇪 Jag **ber** kommunen att bygga en cykelbana. — 🇨🇳 我请求市政府修一条自行车道。
- 🇸🇪 Får jag **be** om lite hjälp? — 🇨🇳 我能请你帮点忙吗？
- 🇸🇪 Han **bad** om ursäkt för att han kom sent. — 🇨🇳 他为迟到道歉。（preteritum: bad）

## 用法提示 (Usage Notes)

- **be ≠ fråga**：`fråga` 是"提问、询问信息"；`be (om)` 是"请求得到/做某事"。
  `Jag frågar var stationen ligger`（问路）vs `Jag ber om hjälp`（求助）。
- "请某人做某事"结构：**be + 宾语 + att + 动词原形** — `Jag ber dig att stanna`（我请你留下）。口语里 `att` 常省略。
- 固定礼貌语：`be om ursäkt`（道歉）、`Får jag be om notan?`（可以结账吗？）。
