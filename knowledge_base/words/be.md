# be — verb (oregelbundet)

📖 中文：请求，恳请；祈祷 · English: to ask, request; to pray
发音提示：/beː/

⚠️ 注意：`bad` 是 be 的过去式（≠ 名词 bad “浴”，那是 [[bada]] 相关的词）。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | be |
| Presens | ber |
| Preteritum | bad |
| Supinum | bett |
| Imperativ | be |

## 词组搭配 (Collocations)

- `be om ursäkt` — 道歉
- `be någon om hjälp` — 请某人帮忙
- `be om något` — 请求某物

## 例句 (Sentences)

- 🇸🇪 Man ber alltid om ursäkt om man behöver komma fram i en folksamling. — 🇨🇳 在人群中要挤过去时，人们总会道歉。
- 🇸🇪 Gruppens medlemmar bad henne om fler recept. — 🇨🇳 小组成员请她提供更多食谱。
- 🇸🇪 Jag ber dig om hjälp. — 🇨🇳 我请你帮忙。
