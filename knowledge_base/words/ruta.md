# ruta — substantiv (en)

📖 中文：方格；窗玻璃；（腹肌的）块 · English: square; pane; (abs) block

🇸🇪 Förklaring: fyrkantig yta, till exempel i ett mönster, på ett fönster eller som man ser på magen hos vältränade
