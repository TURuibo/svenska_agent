# faktum — substantiv (ett)

📖 中文：事实 · English: fact

🇸🇪 Förklaring: något som är sant och som man kan visa

发音提示：/ˈfaktɵm/ — 重音在第一音节；-um 读 /ɵm/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Singular obestämd | ett faktum |
| Singular bestämd | faktumet |
| Plural obestämd | fakta |
| Plural bestämd | fakta / faktan |

## 词组搭配 (Collocations)

- `i själva verket` — 其实
- `ett faktum är att …` — 事实是……
- `faktum kvarstår` — 事实依旧

## 例句 (Sentences)

- 🇸🇪 Ett faktum som överraskade forskarna var att hälften sov för lite. — 🇨🇳 让研究者吃惊的事实是一半人睡眠不足。
- 🇸🇪 Det är ett faktum att jorden är rund. — 🇨🇳 地球是圆的是事实。
- 🇸🇪 Ett faktum är att många inte sover tillräckligt. — 🇨🇳 事实是许多人睡得不够。
