# skruva — verb

📖 中文：拧、旋 · English: to screw, to turn

🇸🇪 Förklaring: vrida något runt, till exempel en skruv eller mutter, så att det sitter fast eller lossnar

发音提示：/ˈskrʉːva/ — sk 读 s+k（在 r 前不是 sj 音）；u 为长的 ʉː

| infinitiv | skruva |
| presens | skruvar |
| preteritum | skruvade |
| supinum | skruvat |
| imperativ | skruva! |

## 词组搭配 (Collocations)

- `skruva fast` — 拧紧
- `skruva loss / av` — 拧下来
- `skruva upp / ner` — 调大/调小

## 例句 (Sentences)

- 🇸🇪 Man använder den för att skruva muttrar och bultar. — 🇨🇳 人们用它来拧螺母和螺栓。
- 🇸🇪 Kan du skruva fast hyllan på väggen? — 🇨🇳 你能把架子拧到墙上吗？
- 🇸🇪 Han skruvade av locket. — 🇨🇳 他把盖子拧开了。
