# rekord — substantiv (ett)

📖 中文：纪录 · English: record
发音提示：[reˈkuːɖ]

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| obestämd singular | ett rekord |
| bestämd singular | rekordet |
| plural (obestämd) | rekord (oförändrad) |
| plural (bestämd) | rekorden |

## 词组搭配 (Collocations)

- `slå rekord` — 打破纪录
- `sätta rekord` — 创造纪录
- `det var rekord` — 这是纪录
- `världsrekord` — 世界纪录

## 例句 (Sentences)

- 🇸🇪 Det var rekord på SVT Play för hur många som tittar på samma program. — 🇨🇳 这创下了SVT Play同时观看同一节目的人数纪录。
- 🇸🇪 Hon slog rekord i 100 meter. — 🇨🇳 她打破了100米纪录。
- 🇸🇪 Det är ett nytt rekord för Sverige. — 🇨🇳 这是瑞典的新纪录。

## 词族 / 同义 / 反义 (Relations)

- 词族: rekordstor (创纪录地大), rekordmånga (创纪录地多)
- 主题: [[topic-fotboll]]

## 用法提示 (Usage Notes)

- `rekord` 的复数形与单数形相同（零复数，ett-ord 第5变格）。
- `slå rekord` = 打破纪录（最常见搭配）；`hålla rekord` = 保持纪录。
