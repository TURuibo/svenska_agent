# tro — verb (grupp 3)

📖 中文：相信；认为；以为 · English: to believe; to think (suppose)
发音提示：/truː/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) tro |
| Presens | tror |
| Preteritum | trodde |
| Supinum | trott |
| Imperativ | tro! |

grupp 3（短元音结尾动词：-r/-dde/-tt）。

## 词组搭配 (Collocations)

- `tro på` — 相信（某人/某事）→ see [[tro-på]]
- `jag tror att …` — 我认为/我猜……
- `tro på sig själv` — 相信自己
- `jag tror det` / `jag tror inte det` — 我想是的 / 我想不是

## 例句 (Sentences)

**义项1 相信 (believe in):**
- 🇸🇪 Jag tror på dig. — 🇨🇳 我相信你。

**义项2 以为/认为 (suppose):**
- 🇸🇪 Jag tror att det blir regn i morgon. — 🇨🇳 我觉得明天会下雨。
- 🇸🇪 Hon trodde att bussen hade gått. — 🇨🇳 她以为公交车已经开走了。

## 词族 / 同义 / 反义 (Relations)

- 反义词: [[tvivla]]
- 相关: [[tycka]]、[[tänka]]

## 用法提示 (Usage Notes)

| 动词 | 含义 | 例 |
|------|------|-----|
| tro | 不确定的推测 / 信仰 | Jag tror att han kommer. 我猜他会来。 |
| tycka | 主观意见、评价 | Jag tycker att filmen är bra. 我觉得电影好。 |
| tänka | 思考；打算 | Jag tänker flytta. 我打算搬家。 |

- 中文都说“我觉得/我认为”，瑞典语要分：**不确定的事实 → tro**；**个人看法 → tycka**；**思考/打算 → tänka**。
