# tro — verb

📖 中文：相信；认为；以为 · English: to believe; to think (suppose)
发音提示：长 o，读作 /truː/，类似英语 "true"。**tror** = /truːr/。

## 语法变形 (Forms)

verbgrupp **3**（短词，词干以重读元音结尾：tro / bo / sy / ro）

| Form | Swedish |
|------|---------|
| Infinitiv | (att) tro |
| Imperativ | tro! |
| Presens | tror |
| Preteritum | trodde |
| Supinum | (har) trott |
| Perfekt particip | trodd (en) / trott (ett) / trodda (pl) |

> 你查的 **tror** 就是 presens（现在时），"相信 / 认为"。

## 词组搭配 (Collocations)

- `tro på` — 相信（某人/某事/某神），信仰
- `tro på sig själv` — 相信自己
- `jag tror det` — 我想是的 / 我认为是这样
- `jag tror inte det` — 我不这么认为
- `tro att …` — 认为……（引出从句 bisats）
- `tror du?` — 你觉得呢？/ 真的吗？
- `en tro` — 一种信仰（名词，en-ord）

## 例句 (Sentences)

- 🇸🇪 Jag tror att det regnar imorgon. — 🇨🇳 我觉得明天会下雨。
- 🇸🇪 Tror du på honom? — 🇨🇳 你相信他吗？
- 🇸🇪 Hon trodde att du var hemma. — 🇨🇳 她以为你在家。（preteritum）
- 🇸🇪 Jag tror inte det. — 🇨🇳 我不这么认为。

## 用法提示 (Usage Notes)

- ⚠️ **tro vs tycka vs tanka**：
  - **tro** = 相信、以为（对事实的推测，不确定）：*Jag tror att hon kommer.* 我想她会来。
  - **tycka** = 认为、觉得（主观意见/喜好）：*Jag tycker att filmen är bra.* 我觉得这电影好。
  - **tanka (tänka)** = 想、思考（脑中思考的动作）。
- 否定常说 **"Jag tror inte det"**（我不这么认为），而不是 "Jag tror det inte"。
- **tro på** + 人/神 = 信任、信仰；省略 på 时多接 att-从句表"认为"。
- 常用词 (常用)。
