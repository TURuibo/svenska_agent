# tro — verb (grupp 3)

📖 中文：认为、以为、相信 · English: to believe, think

🇸🇪 Förklaring: anse att något är sant utan att veta säkert; ha en religiös övertygelse

发音提示：/truː/；trodde /ˈtruːdɛ/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) tro |
| Presens | tror |
| Preteritum | trodde |
| Supinum | trott |
| Imperativ | tro! |
| Perfekt particip | trodd |
| S-passiv (presens) | tros |
| S-passiv (preteritum) | trodds |

## 词组搭配 (Collocations)

- `tro att …` — 以为 / 认为……（文中：Han trodde att idrottsmän förväntades …）
- `tro på` — 相信…… → see [[tro-på]]
- `jag tror det` / `jag tror inte det` — 我想是 / 我想不是
- `trodde att … skulle …` — 以为……会…… → see [[trodde-att-skulle]]

## 例句 (Sentences)

**义项1 认为、以为（推测）:**
- 🇸🇪 Han trodde att idrottsmän förväntades satsa 100 procent och inte ha andra intressen. — 🇨🇳 他以为运动员就该百分之百投入，不该有别的兴趣。
- 🇸🇪 Jag tror att det blir regn i morgon. — 🇨🇳 我想明天会下雨。

**义项2 相信 (tro på):**
- 🇸🇪 Tror du på spöken? — 🇨🇳 你相信有鬼吗？
- 🇸🇪 Hon tror på sig själv. — 🇨🇳 她相信自己。

## 用法提示 (Usage Notes)

- 第 3 组动词（以元音结尾的短动词）：tro – tror – **trodde** – **trott**。supinum `trott` 与形容词 `trött`（累）仅差变音符，注意区分。
- **tro vs tycka**：tro = 对事实的推测/相信；tycka = 主观评价。见 [[tycka]]、[[grammar-trodde-att-skulle]]。
- 后接 att 从句时，从句内可用 `skulle` 表示「当时预期会……」（[[grammar-trodde-att-skulle]]）。
