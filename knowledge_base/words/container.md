# container — substantiv (en)

📖 中文：废料集装箱；大型废弃物容器 · English: dumpster; skip; waste container
发音提示：[kɔnˈteɪnər]，借自英语，基本保留英语发音

## 语法变形 (Forms)

| 形式 | 写法 |
|------|------|
| 不定式单数 | en container |
| 定式单数 | containern |
| 不定式复数 | containrar |
| 定式复数 | containrarna |

## 词组搭配 (Collocations)

- `container i gården` — 院内废料箱
- `lägga i containern` — 放入废料箱
- `hyra en container` — 租一个废料箱

## 例句 (Sentences)

- 🇸🇪 Det finns en container i gården den här veckan. — 🇨🇳 本周院内有一个废料箱。
- 🇸🇪 Du kan lägga gamla möbler i containern. — 🇨🇳 你可以把旧家具放进废料箱。
- 🇸🇪 Vi hyrde en container för att kasta skräpet. — 🇨🇳 我们租了一个废料箱来处理垃圾。

## 用法提示 (Usage Notes)

- 瑞典语中 *container* 通常指临时放置在院子里、供居民丢弃大件废物的大型金属箱，类似英式英语的 "skip"。
- 不要与货运集装箱混淆（货运集装箱也可叫 container，但语境不同）。
