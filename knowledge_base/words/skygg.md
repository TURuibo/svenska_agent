# skygg — adjektiv

📖 中文：胆小的、怕生的 · English: shy / timid
发音提示：/ɧyɡː/

## 语法变形 (Forms)

| form | en-form | ett-form | plural/bestämd |
|------|---------|----------|----------------|
| positiv obestämd | en skygg (rådjur) | ett skygg (djur) | skygg / skyggа (djur) |
| positiv bestämd | den skyggа (rådjuret) | det skyggа (djuret) | de skyggа (djuren) |
| komparativ | skyggare | | |
| superlativ | skyggast / skyggaste | | |

**Obs:** *skygg* har samma form i en/ett obestämd (ingen ändelse i ett-form).

## 词组搭配 (Collocations)

- `ett skygg djur` — 一只怕生的动物
- `skygg för människor` — 怕人
- `rådjuret är skygg` — 狍子很胆小
