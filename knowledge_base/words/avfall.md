# avfall — substantiv

📖 中文：废物；垃圾 · English: waste
发音提示：AV-fall（重音在第一音节）

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| obestämd sg | ett avfall |
| bestämd sg | avfallet |
| obestämd pl | avfall |
| bestämd pl | avfallen |

## 词组搭配 (Collocations)

- `farligt avfall` — 危险废品 → see [[farligt-avfall]]
- `matavfall` — 厨余垃圾 → see [[matavfall]]
- `restavfall` — 普通垃圾 → see [[restavfall]]
- `sortera avfall` — 分类垃圾

## 例句 (Sentences)

- 🇸🇪 Vi sorterar avfallet i olika behållare. — 🇨🇳 我们把垃圾分类放入不同的容器中。
- 🇸🇪 Farligt avfall ska inte kastas i vanliga sopor. — 🇨🇳 危险废品不能扔进普通垃圾桶。
- 🇸🇪 Det finns många typer av avfall hemma. — 🇨🇳 家里有很多种垃圾。
- 🇸🇪 Vi minskar avfallet genom att återvinna. — 🇨🇳 我们通过回收利用来减少垃圾。
