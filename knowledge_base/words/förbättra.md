# förbättra — verb (grupp 1)

📖 中文：改善、改进、提高 · English: to improve
发音提示：för-**BÄTT**-ra；重音在 bätt，för- 弱读。

## 语法变形 (Forms)

| Tempus | Swedish |
|--------|---------|
| Infinitiv | (att) förbättra |
| Presens | **förbättrar** |
| Preteritum | förbättrade |
| Supinum | förbättrat |
| Imperativ | förbättra! |

> grupp 1（词干以 -a 结尾，最规则）：presens `-ar`、preteritum `-ade`、supinum `-at`。
> 你输入的 `förbättrar` 是 **presens**。

## 词组搭配 (Collocations)

- `förbättra sina kunskaper` — 提高自己的知识/水平
- `förbättra läget / situationen` — 改善局面/状况
- `förbättra sig` — （自己）进步、变好（反身）
- `ständig förbättring` — 持续改进

## 例句 (Sentences)

- 🇸🇪 Jag vill förbättra min svenska. — 🇨🇳 我想提高我的瑞典语。
- 🇸🇪 Företaget förbättrar arbetsmiljön. — 🇨🇳 公司在改善工作环境。
- 🇸🇪 Hennes hälsa har förbättrats. — 🇨🇳 她的健康状况好转了。

## 词族 / 同义 / 反义 (Relations)

- 词族: [[bättre]] (更好的，bra 的比较级), [[förbättring]] (改善/改进)
- 同义词: [[förbättras]] (变好，自动/s-形式), [[utveckla]] (发展/开发)
- 反义词: [[försämra]] (使变差、恶化)
- 主题: —

## 用法提示 (Usage Notes)

- ⚠️ 及物 vs 自动：`förbättra ngt`（**改善某物**，要宾语）vs `förbättras`（**自己变好**，s-动词、不带宾语）。
  例：Vi förbättrar X（我们改善 X）/ X förbättras（X 在变好）。
- 词根是比较级 **bättre**（更好），för- + bättra = "使更好"。
