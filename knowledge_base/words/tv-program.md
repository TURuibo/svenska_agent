# tv-program — substantiv (ett)

📖 中文：电视节目 · English: TV programme

🇸🇪 Förklaring: program som sänds på tv

发音提示：/ˈteːveːpruˌɡram/ — tv 读 "te-ve"，重音在 te-，program 次重音

## 词组搭配 (Collocations)

- `titta på tv-program` — 看电视节目
- `följa tv-program` — 关注电视节目
- `ett populärt tv-program` — 热门电视节目

## 例句 (Sentences)

- 🇸🇪 Jag följer många tidningar och tv-program som rapporterar nyheter. — 🇨🇳 我关注很多报道新闻的报纸和电视节目。
- 🇸🇪 Vi tittar på ett tv-program varje kväll. — 🇨🇳 我们每晚看一个电视节目。
- 🇸🇪 Det är ett bra tv-program för barn. — 🇨🇳 这是一档适合孩子的好节目。
