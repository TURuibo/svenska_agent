# namnlapp — substantiv

📖 中文：姓名标签 · English: name label; name tag

🇸🇪 Förklaring: liten etikett med någons namn som man sätter på kläder eller bär på bröstet

发音提示：/ˈnamnˌlapː/ — namn 的 mn 两个音都发，-lapp 短 a 带长 p

## 语法变形 (Forms)

| 形式 | 瑞典语 |
|------|--------|
| obestämd sing. | en namnlapp |
| bestämd sing. | namnlappen |
| obestämd plur. | namnlappar |
| bestämd plur. | namnlapparna |

## 词组搭配 (Collocations)

- `utan namnlapp` — 没有姓名标签
- `sätta namnlapp på kläderna` — 给衣服贴姓名标签 → see [[kläder]]
- `märka med namnlappar` — 用姓名标签标记 → see [[märka-med-namn]]
- `beställa namnlappar` — 订购姓名标签

## 例句 (Sentences)

- 🇸🇪 Utan namnlapp är det svårt att hitta rätt tröja. — 🇨🇳 没有姓名标签，很难找到对的那件上衣。
- 🇸🇪 Vi beställde namnlappar på nätet. — 🇨🇳 我们在网上订了姓名标签。
- 🇸🇪 Alla vantar måste ha namnlapp. — 🇨🇳 所有手套都必须有姓名标签。
- 🇸🇪 Namnlappen har lossnat från jackan. — 🇨🇳 姓名标签从夹克上掉了。

## 用法提示 (Usage Notes)

- 复合词 **namn + lapp**，en-词，复数 -ar。
- 瑞典幼儿园的硬要求：所有衣物、鞋、水杯都要有 namnlapp（熨烫贴/贴纸/手写），否则 *det är svårt att hitta rätt*。
- 动词说法见 [[märka-med-namn]]：*märka allt med namn*。
