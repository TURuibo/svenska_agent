# förstöra — verb

📖 中文：破坏/毁坏 · English: to destroy, to ruin
发音提示：/fœrˈstøːrɑ/；重音在第二音节 -stö-；ö 发 [øː]

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | förstöra |
| Presens | förstör |
| Preteritum | förstörde |
| Supinum | förstört |
| Imperativ | förstör! |

> 动词组 2b（-er / -de / -t）；presens = förstör

## 词组搭配 (Collocations)

- `förstöra naturen` — 破坏大自然
- `inte förstöra` — 不破坏
- `förstöra miljön` — 破坏环境

## 例句 (Sentences)

- 🇸🇪 Inte störa, inte förstöra — det är regeln. — 🇨🇳 不打扰，不破坏——这是规则。
- 🇸🇪 Vi ska inte förstöra naturen när vi är ute. — 🇨🇳 我们在户外时不应该破坏自然。
- 🇸🇪 Det är viktigt att inte förstöra miljön. — 🇨🇳 不破坏环境很重要。

## 用法提示 (Usage Notes)

- **förstöra** = 破坏（使某物变坏/不能用）；**störa** = 打扰（使不安宁）。
- 两者常并排出现：*Inte störa, inte förstöra*（不打扰，不破坏）——allemansrättens grundregel。
