# oroa — verb (grupp 1)

📖 中文：使担心；（oroa sig）担心 · English: to worry (oroa sig = to be worried)

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | oroa |
| Presens | oroar |
| Preteritum | oroade |
| Supinum | oroat |
| Imperativ | oroa |

## 词组搭配 (Collocations)

- `oroa sig för/över` — 为……担心
- `Det som oroar mig är …` — 让我担心的是……

## 例句 (Sentences)

- 🇸🇪 Du behöver inte oroa dig. — 🇨🇳 您不用担心。
- 🇸🇪 Det som oroar honom är mötet med Eva. — 🇨🇳 让他不安的是要见到 Eva。
- 🇸🇪 Hon oroar sig för sina barn. — 🇨🇳 她为孩子们担心。
