# reagera — verb (grupp 1)

📖 中文：反应；对……有反应 · English: to react

🇸🇪 Förklaring: göra, säga eller känna något som svar på något som händer

发音提示：/rɛaˈɡeːra/ — g 读硬音 /ɡ/；重音在 -ge

## 词组搭配 (Collocations)

- `reagera på något` — 对某事作出反应

## 例句 (Sentences)

- 🇸🇪 I början reagerade jag på att det var så rent här. — 🇨🇳 一开始让我惊讶的是这里这么干净。
- 🇸🇪 Hur reagerade han på nyheten? — 🇨🇳 他对这个消息有什么反应？
- 🇸🇪 Hon reagerar snabbt när något händer. — 🇨🇳 出事时她反应很快。
