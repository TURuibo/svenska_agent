# ätbar — adjektiv

📖 中文：可食用的；能吃的 · English: edible

🇸🇪 Förklaring: som man kan äta utan att bli sjuk

发音提示：/ˈɛːtbɑːr/ — ä 读长音 /ɛː/；-bar 读 /bɑːr/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| en-form | ätbar |
| ett-form | ätbart |
| plural / bestämd | ätbara |
| komparativ | ätbarare |
| superlativ | ätbarast |
| superlativ (bestämd) | ätbaraste |

> 实际很少分级。

## 词组搭配 (Collocations)

- `ätbar mat` — 可食用的食物
- `slänga ätbar mat` — 扔掉还能吃的食物
- `ätbara svampar` — 可食用的蘑菇

## 例句 (Sentences)

- 🇸🇪 Sluta slänga ätbar mat! — 🇨🇳 别再扔还能吃的食物了！
- 🇸🇪 Är den här svampen ätbar? — 🇨🇳 这种蘑菇能吃吗？
- 🇸🇪 Maten var knappt ätbar. — 🇨🇳 这食物勉强能吃。
