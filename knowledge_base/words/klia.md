# klia — verb (v.3)

📖 中文：发痒/痒 · English: to itch
发音提示：KLI-a；元音 `i` 长音。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | att klia |
| Imperativ | klia! |
| Presens | kliar |
| Preteritum | kliade |
| Supinum | (har) kliat |

Grupp 3 动词（短词根 + -r/-de/-t）。

## 词组搭配 (Collocations)

- `det kliar` — 痒（无人称结构）
- `klia sig` — 挠自己（反身）

## 例句 (Sentences)

- 🇸🇪 Det **kliar** på ryggen — kan du klia mig?
  🇨🇳 后背痒——你能帮我挠一下吗？
- 🇸🇪 Kläderna var obekväma och **kliade**.
  🇨🇳 衣服既不舒服又痒。
- 🇸🇪 Barnet **kliar** sig för att det fick myggbett.
  🇨🇳 孩子因为被蚊子咬了在挠痒。
