# bort — adverb

📖 中文：离开、掉、去远处 · English: away, off
发音提示：/bɔʈ/；`rt` 合成卷舌音 /ʈ/。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Adverb | bort |

## 词组搭配 (Collocations)

- `ta bort` — 去掉、移除
- `kasta bort` — 扔掉 → see [[kasta-bort]]
- `lägga bort` — 收起来、放到一边 → see [[lägga-bort]]
- `tappa bort` — 弄丢 → see [[tappa-bort]]
- `glömma bort` — 忘记（完全忘了）
- `långt bort` — 很远 → see [[långt-bort]]
- `bort från` — 离开…… → see [[bort-från]]

## 例句 (Sentences)

**义项1 partikelverb：去掉、弄走:**

- 🇸🇪 Det är svårt att motivera barn att träna om man tar bort tävlingsmomentet. — 🇨🇳 如果把竞赛因素拿掉，就很难激励孩子训练。
- 🇸🇪 Du kan kasta bort de gamla tidningarna. — 🇨🇳 你可以把旧报纸扔掉。

**义项2 去远处、离开（方向）:**

- 🇸🇪 Han gick bort till bordet. — 🇨🇳 他走到桌边去了。
- 🇸🇪 Jag glömde bort mötet. — 🇨🇳 我把会议完全忘了。

## 用法提示 (Usage Notes)

- **bort vs borta**：`bort` 是**方向**（去往别处，常和动作动词）：`Han gick bort`；`borta` 是**位置**（已经不在这里）：`Han är borta`。见 [[borta]]、[[grammar-riktnings-adverb]]。
- 文中 `tar bort tävlingsmomentet`：`ta bort` 是 **partikelverb**，`bort` 重读，**宾语夹在动词和小品词之间**（`man tar bort X` 或 `tar man X bort`），见 [[grammar-partikelverb]]。
