# hindra — verb (grupp 1)

📖 中文：阻止；妨碍；阻碍 · English: to prevent; to hinder; to obstruct
发音提示：HIN-dra，`i` 短。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | hindra |
| Presens | hindrar |
| Preteritum | hindrade |
| Supinum | hindrat |
| Imperativ | hindra |
| Perf. particip | hindrad / hindrat / hindrade |
| S-passiv | hindras |

## 词组搭配 (Collocations)

- `hindra någon från att + 不定式` — 阻止某人做某事 → [[hindra-från-att]]
- `hindra trafiken / framkomligheten` — 妨碍交通 / 通行
- `hindra rullstolar och barnvagnar` — 妨碍轮椅和婴儿车通行
- `hindra utvecklingen` — 阻碍发展
- `ett hinder` — 障碍（名词）

## 例句 (Sentences)

> 义项相近：`阻止（不让做成）` 与 `妨碍（挡路、造成不便）` 是同一动词的两种程度，下面从三个角度给例句。

- 🇸🇪 Cyklarna hindrar rullstolar och barnvagnar på smala trottoarer. — 🇨🇳 自行车在狭窄的人行道上妨碍轮椅和婴儿车通行。 → [[sent-i-en-rapport-beskriver-kommunen-hur-cyklarna]]
- 🇸🇪 Regnet hindrade oss från att gå ut. — 🇨🇳 下雨使我们没能出门。
- 🇸🇪 Ingen kan hindra dig från att försöka. — 🇨🇳 没人能阻止你去尝试。
- 🇸🇪 Den parkerade bilen hindrar trafiken. — 🇨🇳 那辆停着的车妨碍了交通。

## 词族 / 同义 / 反义 (Relations)

- 词族: [[hinder]]（障碍）、[[förhindra]]（（事先）防止，较正式）
- 同义词: [[stoppa]]（叫停；更口语、更强烈）；近义 `blockera`（堵住）
- 反义词: [[tillåta]]（允许）、[[hjälpa]]（帮助）
- 主题: [[topic-allmänna-verb]]

## 用法提示 (Usage Notes)

- 接人 + 做某事时必须 `**från att** + 不定式`：`hindra honom från att gå`（不能省掉 `från att`，不说 *hindra honom gå*）。
- 接物 / 行为时直接带宾语：`hindra trafiken`、`hindra utvecklingen`。
- 与 [[skydda]] 区别：`hindra` = 不让发生 / 挡路；`skydda` = 保护免受伤害。
