# kran — substantiv (en)

📖 中文：水龙头 · English: tap, faucet

🇸🇪 Förklaring: sak som man vrider på för att få vatten ur ett rör

发音提示：/kraːn/ — a 长音；kr 连读

## 语法变形 (Forms)

| 形式 | 写法 |
|------|------|
| 不定式单数 | en kran |
| 定式单数 | kranen |
| 不定式复数 | kranar |
| 定式复数 | kranarna |

## 词组搭配 (Collocations)

- `vrida på kranen` — 打开水龙头
- `stänga kranen` — 关水龙头
- `kranvatten` — 自来水

## 例句 (Sentences)

- 🇸🇪 Låt kranen rinna i några minuter. — 🇨🇳 请让水龙头流几分钟。
- 🇸🇪 Kranen i köket droppar. — 🇨🇳 厨房的水龙头在滴水。
- 🇸🇪 Du kan dricka vatten direkt från kranen. — 🇨🇳 你可以直接喝水龙头里的水。
