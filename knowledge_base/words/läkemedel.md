# läkemedel — substantiv

📖 中文：药品 · English: medicine, medication

🇸🇪 Förklaring: något man tar för att bli frisk eller må bättre, till exempel tabletter

发音提示：/ˈlɛːkɛˌmeːdɛl/ — 重音在 läke-；复合词，第二个 -medel 为次重音

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Singular obestämd | ett läkemedel |
| Singular bestämd | läkemedlet |
| Plural obestämd | läkemedel |
| Plural bestämd | läkemedlen |

## 词组搭配 (Collocations)

- `ta läkemedel` — 吃药
- `receptbelagda läkemedel` — 处方药

## 例句 (Sentences)

- 🇸🇪 Ta med en lista över alla läkemedel som du använder. — 🇨🇳 请带上你所用全部药品的清单。
- 🇸🇪 Gamla läkemedel lämnar du på apoteket. — 🇨🇳 旧药要交到药店。
- 🇸🇪 Det här läkemedlet kräver recept. — 🇨🇳 这种药需要处方。
