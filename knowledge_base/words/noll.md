# noll — räkneord

📖 中文：零 · English: zero

🇸🇪 Förklaring: siffran eller talet som betyder ingenting alls

发音提示：/nɔl/ — o 读短 [ɔ]，ll 是长辅音

## 语法变形 (Forms)

| 形式 | 说明 |
|------|------|
| noll | 数词，不随 en/ett 变化 |
| nollan (en) | 作名词：数字 0 |

## 词组搭配 (Collocations)

- `noll grader` — 零度
- `noll komma fem` — 0.5（瑞典语小数用逗号）
- `ringa 08-…` 电话号码里常读 "noll åtta"

## 例句 (Sentences)

- 🇸🇪 Det är noll grader ute. — 🇨🇳 外面是零度。
- 🇸🇪 Mitt nummer börjar på noll sju noll. — 🇨🇳 我的号码以 070 开头。
- 🇸🇪 Vi har noll problem. — 🇨🇳 我们没有任何问题。
