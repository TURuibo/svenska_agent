# lager — substantiv (ett)

发音提示：['lɑːɡər]（"a"长音）

| form | Swedish |

| obestämd singular | ett lager |
| bestämd singular | lagret |
| obestämd plural | lager |

## 词组搭配 (Collocations)

- `jobba på ett lager` — 在仓库工作
- `lagerarbetare` — 仓库工人
- `lagerhålla` — 储存，库存

## 例句 (Sentences)

- 🇸🇪 Min man jobbar på ett lager i staden. — 🇨🇳 我丈夫在城里的仓库工作。
- 🇸🇪 Varorna finns i lagret på baksidan. — 🇨🇳 货物在后面的仓库里。
- 🇸🇪 Det är ett stort lager med mycket mat. — 🇨🇳 那是一个有很多食物的大仓库。
