# desto — adverb

📖 中文：越……（用于 ju … desto … 结构） · English: the … (in "the more … the more …")

🇸🇪 Förklaring: ord som visar att något ökar eller minskar lika mycket som något annat, används med komparativ

发音提示：/ˈdɛstu/ — 重音在 de；e 读 /ɛ/，结尾 o 读 /ʊ/

## 词组搭配 (Collocations)

- `ju … desto …` — 越……越…… → see [[ju-desto]]

- `desto mer` — 越多

## 例句 (Sentences)

- 🇸🇪 Men ju närmare middagen kom, desto mer nervös blev Johan. — 🇨🇳 可晚饭越临近，约翰就越紧张。
- 🇸🇪 Ju mer du övar, desto bättre blir du. — 🇨🇳 你练得越多，就越好。
- 🇸🇪 Ju tidigare vi åker, desto fortare kommer vi fram. — 🇨🇳 我们出发越早，到得越快。
