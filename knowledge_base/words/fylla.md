# fylla — verb

📖 中文：装满；填 · English: to fill

🇸🇪 Förklaring: hälla eller lägga i något tills det inte får plats mer

发音提示：/ˈfʏlːa/ — 短 y（圆唇 i）+ 长 l

## 语法变形 (Forms)

| 形式 | 瑞典语 |
|------|--------|
| infinitiv | fylla |
| presens | fyller |
| preteritum | fyllde |
| supinum | fyllt |
| imperativ | fyll! |

## 词组搭配 (Collocations)

- `fylla på` — 补充；补上 → see [[fylla-på]]
- `fylla i en blankett` — 填表
- `fylla år` — 过生日（*hon fyller tre år* 她满三岁）
- `fylla glaset` — 把杯子倒满

## 例句 (Sentences)

- 🇸🇪 Kolla ditt barns hylla varje dag och fyll på det som saknas. — 🇨🇳 每天看一下你孩子的格子，把缺的补上。
- 🇸🇪 Kan du fylla i den här blanketten? — 🇨🇳 你能填一下这张表吗？
- 🇸🇪 Ella fyller tre år i november. — 🇨🇳 Ella 十一月满三岁。
- 🇸🇪 Jag fyllde flaskan med vatten. — 🇨🇳 我把瓶子灌满了水。

## 用法提示 (Usage Notes)

- 第 2a 组动词：*fyller / fyllde / fyllt*；祈使式去 -a → **fyll!**（公告里常见）。
- 三个高频搭配意思差别大：**fylla på**（补上、加满）、**fylla i**（填表）、**fylla år**（过生日）——中文母语者容易只记「填」。
- 「装满 X」用 *fylla X med Y*：*fylla lådan med kläder*。
