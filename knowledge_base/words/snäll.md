# snäll — adjektiv

📖 中文：善良的；友善的 · English: kind
发音提示：/snɛlː/

## 语法变形 (Forms)

| form | böjning |
|------|---------|
| utrum obestämd | snäll |
| neutrum obestämd | snällt |
| bestämd/plural | snälla |
| komparativ | snällare |
| superlativ | snällast |

## 词组搭配 (Collocations)

- `en snäll elefant` — 一头温顺的大象
- `snäll mot djur` — 对动物友善
- `var snäll och…` — 请（polite request）

## 例句 (Sentences)

- 🇸🇪 Elefanten är känd för att vara snäll och intelligent. — 🇨🇳 大象以温顺和聪明著称。
- 🇸🇪 Var snäll och stäng dörren. — 🇨🇳 请把门关上。
- 🇸🇪 Hon är snäll mot alla djur i stallet. — 🇨🇳 她对马厩里所有的动物都很温柔。
