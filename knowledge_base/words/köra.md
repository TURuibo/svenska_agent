# köra — verb

📖 中文：开（车）, 驾驶 · English: to drive
发音提示：kö-ra

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| infinitiv | köra |
| presens | kör |
| preteritum | körde |
| supinum | kört |
| imperativ | kör! |

## 词组搭配 (Collocations)

- `köra bil` — 开车
- `köra för fort` — 开太快，超速
- `köra extra långsamt` — 开得特别慢
- `köra förbi` — 开车经过

## 例句 (Sentences)

- 🇸🇪 Den som ska ut och köra bil kan få svårare att ta sig fram. — 🇨🇳 开车出行的人可能更难通行。
- 🇸🇪 Det är viktigt att köra extra långsamt förbi arbeten på vägarna. — 🇨🇳 经过施工路段开得特别慢也很重要。
- 🇸🇪 Människor kan bli skadade om folk kör för fort. — 🇨🇳 如果人们开太快，人们可能会受伤。
