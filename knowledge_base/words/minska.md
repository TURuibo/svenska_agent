# minska — verb (v.1)

📖 中文：减少 · English: reduce, decrease, diminish
发音提示：/ˈmɪnska/；v.1 动词（-ar 结尾）。

## 语法变形 (Forms)

| tempus | form |
|--------|------|
| infinitiv | minska |
| presens | minskar |
| preteritum | minskade |
| supinum | minskat |
| imperativ | minska |

既可用作及物动词（减少某物）也可用作不及物动词（减少了）。

## 词组搭配 (Collocations)

- `minska utsläppen` — 减少排放
- `minska risken` — 降低风险
- `antalet minskar` — 数量减少了

## 例句 (Sentences)

- 🇸🇪 [[sent-hon-ville-att-politikerna-skulle-lyssna]] Hon ville att politikerna skulle lyssna och minska utsläppen. — 🇨🇳 她想让政治家们倾听，并减少排放。
- 🇸🇪 Temperaturen minskade snabbt. — 🇨🇳 温度迅速下降。
- 🇸🇪 Vi måste minska vårt koldioxidavtryck. — 🇨🇳 我们必须减少我们的碳足迹。

## 词族 / 同义 / 反义 (Relations)

- 词族: minskning（减少，名词），liten（小的）
- 同义词: reducera（减少）
- 反义词: [[öka]]（增加）

## 用法提示 (Usage Notes)

- 及物用法：`minska ngt`（减少某物）；不及物用法：`ngt minskar`（某物减少）。
