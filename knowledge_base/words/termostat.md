# termostat — substantiv (en)

📖 中文：恒温器 · English: thermostat

🇸🇪 Förklaring: apparat som styr hur varmt det blir, till exempel på ett element

发音提示：/tɛrmʊˈstɑːt/ — 重音在最后音节 -stat，a 读长音

## 例句 (Sentences)

- 🇸🇪 Termostaten står på tre. — 🇨🇳 恒温器调在三档。
- 🇸🇪 Jag vred på termostaten, men elementet blev inte varmt. — 🇨🇳 我拧了恒温器，但暖气片还是不热。
- 🇸🇪 Termostaten på elementet är trasig. — 🇨🇳 暖气片上的恒温器坏了。
