# skynda — verb (grupp 1)

📖 中文：赶快；急忙 · English: to hurry
发音提示：SKYN-da；两音节。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | att skynda |
| Imperativ | skynda! |
| Presens | skyndar |
| Preteritum | skyndade |
| Supinum | (har) skyndat |

## 词组搭配 (Collocations)

- `skynda dig` — 快点（反身，祈使句）
- `skynda sig` — 赶快（第三人称反身）
- `skynda på` — 加快/催促

## 例句 (Sentences)

- [[sent-skynda-dig-lite]] 🇸🇪 Skynda dig lite. 🇨🇳 稍微快点。

- 反义词: [[ta det lugnt]] (放慢/别急)

## 用法提示 (Usage Notes)

- `skynda sig` 是反身动词：*Han skyndar sig* = 他赶快。
- 祈使句：`Skynda dig!` = 快点！（注意 `dig` 是反身代词，二人称）
- 见词组 [[skynda-dig]] 和语法 [[grammar-reflexivt-verb]]。
