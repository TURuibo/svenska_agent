# motivera — verb (grupp 1)

📖 中文：激励 · English: to motivate
发音提示：/mʊtɪˈveːra/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) motivera |
| Presens | motiverar |
| Preteritum | motiverade |
| Supinum | motiverat |
| Imperativ | motivera! |

## 词组搭配 (Collocations)

- `svårt att motivera barn att träna` — 难以激励孩子训练

## 例句 (Sentences)

- 🇸🇪 Det är svårt att motivera barn att träna om man tar bort tävlingsmomentet. — 🇨🇳 如果把竞赛因素拿掉，就很难激励孩子训练。
- 🇸🇪 Läraren försökte motivera eleverna att läsa mer. — 🇨🇳 老师试图激励学生多读书。
- 🇸🇪 Vad motiverar dig att träna varje dag? — 🇨🇳 是什么激励你每天训练？
