# täcka — verb (grupp 2a)

📖 中文：覆盖；盖住 · English: to cover
发音提示：/ˈtɛka/

## 语法变形 (Forms)

| form | exempel |
|------|---------|
| infinitiv | täcka |
| presens | täcker |
| preteritum | täckte |
| supinum | täckt |
| imperativ | täck! |

## 词组搭配 (Collocations)

- `täcka marken` — 覆盖大地
- `täcka med ett lakan` — 用床单盖住
- `täcka sig med en filt` — 用毯子盖自己
- `snow-täckt` — 被雪覆盖的

## 例句 (Sentences)

- 🇸🇪 Snön täcker marken med ett vitt lakan. — 🇨🇳 雪用白色的"被单"盖住大地。 → [[sent-snon-faller-tyst-och-tacker-marken]]
- 🇸🇪 Molnen täcker solen. — 🇨🇳 云层遮住了太阳。
- 🇸🇪 Hon täckte sig med filten. — 🇨🇳 她用毯子盖住自己。

## 词族 / 同义 / 反义 (Relations)

- 词族: täcke（被子，名词），täckning（覆盖，名词）
- 主题: [[topic-vader-och-arstider]]

## 用法提示 (Usage Notes)

- 动词变化：täcka → täcker → täckte → täckt（规则 -2a 动词）。
- 常见搭配：*täcka* + *med*（用…盖住），如 *täcka med snö*（被雪覆盖）。
