# fastighetsförvaltning — substantiv (en)

📖 中文：物业管理；房产管理 · English: property management
发音提示：[fasˈtiːçeˌfœrˌvaltniŋ]，复合词，很长

## 语法变形 (Forms)

| 形式 | 写法 |
|------|------|
| 不定式单数 | en fastighetsförvaltning |
| 定式单数 | fastighetsförvaltningen |
| 不定式复数 | fastighetsförvaltningar |
| 定式复数 | fastighetsförvaltningarna |

## 词组搭配 (Collocations)

- `fastighetsförvaltningen skickar ett brev` — 物业管理处寄来一封信
- `kontakta fastighetsförvaltningen` — 联系物业管理处
- `ansvarig fastighetsförvaltning` — 负责的物业管理方

## 例句 (Sentences)

- 🇸🇪 Fastighetsförvaltningen informerar om planerat arbete. — 🇨🇳 物业管理处就计划施工作出通知。
- 🇸🇪 Kontakta fastighetsförvaltningen om du har frågor. — 🇨🇳 如有疑问，请联系物业管理处。
- 🇸🇪 Brevet kom från fastighetsförvaltningen. — 🇨🇳 这封信来自物业管理处。
