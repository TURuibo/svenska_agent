# halloumi — substantiv ett

📖 中文：哈鲁米奶酪 · English: halloumi cheese
发音提示：/ha-LOO-mi/（借词自塞浦路斯希腊语）

|------|---------|
| obestämd sing | ett halloumi |
| bestämd sing | halloumin |
| obestämd pl | halloumier / halloumi |
| bestämd pl | halloumierna |

## 词组搭配 (Collocations)

- `halloumi på grillen` — 烤哈鲁米 → [[topic-mat-dryck]]

## 例句 (Sentences)

- 🇸🇪 Jag letar efter halloumi. — 🇨🇳 我在找哈鲁米奶酪。
- 🇸🇪 Halloumit ligger i kylen på osthyllan. — 🇨🇳 哈鲁米奶酪在冷藏区的奶酪货架上。
- 🇸🇪 Kan du grilla halloumin? — 🇨🇳 你能把哈鲁米奶酪烤一下吗？

## 用法提示 (Usage Notes)

- 一种地中海风格的硬奶酪（原产塞浦路斯），烧烤不会融化，瑞典超市常见。
- 通常在 *osthyllan*（奶酪货架）或 *mejeriavdelningen*（乳制品区）。
