# gymnasium — substantiv ett

📖 中文：高中 · English: upper secondary school

🇸🇪 Förklaring: frivillig skola efter grundskolan, där man oftast går i tre år från 16 års ålder

发音提示：/jʏmˈnɑːsɪɵm/ — g 在 y 前读 j；重音在 na

## 语法变形 (Forms)

| | 单数 | 复数 |
|---|---|---|
| 不定 | ett gymnasium | gymnasier |
| 定 | gymnasiet | gymnasierna |

## 词组搭配 (Collocations)

- `gå på gymnasiet` — 上高中

## 例句 (Sentences)

- 🇸🇪 Hon går på gymnasiet. — 🇨🇳 她上高中。
- 🇸🇪 Efter gymnasiet vill jag studera. — 🇨🇳 高中之后我想继续学习。
- 🇸🇪 Det finns tre gymnasier i staden. — 🇨🇳 城里有三所高中。
