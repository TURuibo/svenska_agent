# använda — verb (grupp 2)

📖 中文：使用 · English: to use
发音提示：/ˈanˌvɛnda/（重音在 an-）

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) använda |
| Presens | använder |
| Preteritum | använde |
| Supinum | använt |
| Imperativ | använd! |
| Perfekt particip | använd |
| S-passiv (presens) | används |
| S-passiv (preteritum) | användes |

## 词组搭配 (Collocations)

- `använda … som …` — 把……当作……用（文中：använde han sötsaker som belöning）
- `använda sig av` — 利用
- `gratis att använda` — 免费使用 → see [[gratis-att-anvanda]]
- `används för att …` — 用来……

## 例句 (Sentences)

- 🇸🇪 Till skillnad från många andra elitidrottare som följer en strikt diet använde han sötsaker som belöning. — 🇨🇳 与许多遵守严格饮食的精英运动员不同，他把甜食当作奖励。
- 🇸🇪 Jag använder en app för att lära mig svenska. — 🇨🇳 我用一个应用来学瑞典语。
- 🇸🇪 Får jag använda din telefon? — 🇨🇳 我可以用一下你的手机吗？
- 🇸🇪 Ordet används ofta i tal. — 🇨🇳 这个词常用于口语。

## 用法提示 (Usage Notes)

- 第 2 组动词（词干以 d 结尾，不重复）：använda – använder – **använde** – **använt**。
- `använda ngt som ngt` = 把某物当作……用。s-passiv：`används` / `användes`（见 [[grammar-s-passiv]]）。
- 与 `bruka`（习惯于）不同；`använda` 才是「使用」。
