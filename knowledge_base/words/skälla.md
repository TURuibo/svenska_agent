# skälla — verb (grupp 2a)

📖 中文：训斥；骂（狗：叫） · English: to scold; to bark

🇸🇪 Förklaring: 1) (om hund) ge ifrån sig korta, höga läten; 2) säga arga ord till någon som har gjort fel

发音提示：SHELL-a（sk- 在 ä 前读 /ɧ/，像"许"）

## 语法变形 (Forms)

| Form | |
|------|-|
| Infinitiv | skälla |
| Presens | skäller |
| Preteritum | skällde |
| Supinum | skällt |
| Imperativ | skäll! |

## 词组搭配 (Collocations)

- `skälla på någon` — 训斥某人（固定介词 **på**）
- `skäll inte på henne` — 别训她
- `hunden skäller` — 狗叫
- `få skäll` — 挨骂（名词 skäll）

## 例句 (Sentences)

- 🇸🇪 Avled henne med något annat, och skäll inte på henne. — 🇨🇳 用别的东西转移她的注意力，不要训斥她。
- 🇸🇪 Mamma skällde på mig för att jag kom sent. — 🇨🇳 妈妈因为我回来晚训了我。
- 🇸🇪 Grannens hund skäller hela natten. — 🇨🇳 邻居的狗整夜叫。

## 用法提示 (Usage Notes)

- 两个义项：**skälla på + 人** = 骂人；**hund skäller** = 狗叫。两者同一个词，中文母语者觉得奇怪但很好记：骂人像狗叫。
- 命令式否定：*Skäll inte.*（v.2 动词去掉 -a：skäll!），见 [[grammar-imperativ]]。
