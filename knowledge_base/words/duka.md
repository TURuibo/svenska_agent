# duka — verb (v.1)

📖 中文：摆（餐桌）；摆好餐具 · English: to set the table

🇸🇪 Förklaring: lägga fram tallrikar, bestick och glas på bordet före maten

发音提示：/ˈdɵːka/ — u 读长音 /ɵː/；重音在第一音节

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| infinitiv | (att) duka |
| presens | dukar |
| preteritum | dukade |
| supinum | dukat |
| imperativ | duka! |

## 词组搭配 (Collocations)

- `duka bordet` — 摆桌子
- `duka fram` — 摆出（食物）→ see [[duka-fram]]
- `duka av` — 收拾桌子

## 例句 (Sentences)

- 🇸🇪 Kan du duka, snälla? — 🇨🇳 你能摆一下桌子吗？
- 🇸🇪 Vi dukar fram fika. — 🇨🇳 我们会摆好茶点。
- 🇸🇪 Jag dukar för sex personer. — 🇨🇳 我摆六个人的餐具。
