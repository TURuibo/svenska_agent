# klara — verb

📖 中文：应付；通过；搞定 · English: manage; pass; handle; cope
发音提示：/ˈklɑːra/

## 语法变形 (Forms)

| form | exempel |
|------|---------|
| infinitiv | klara |
| presens | klarar |
| preteritum | klarade |
| supinum | klarat |
| imperativ | klara! |

## 词组搭配 (Collocations)

- `klara sig` — 自己应付；生存 → see [[klara-sig]]
- `klara av` — 搞定；完成 → see [[klara-av]]
- `klara provet` — 通过考试

## 例句 (Sentences)

- 🇸🇪 Klarade du provet? — 🇨🇳 你通过考试了吗？
- 🇸🇪 Jag klarar mig bra på egen hand. — 🇨🇳 我能靠自己应付得很好。
- 🇸🇪 Det är svårt men jag klarar av det. — 🇨🇳 虽然困难，但我能搞定。
