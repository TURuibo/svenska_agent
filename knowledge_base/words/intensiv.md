# intensiv — adjektiv

📖 中文：强烈的；充实的；密集的 · English: intense; intensive
发音提示：/ɪnˈteːnsɪv/

## 语法变形 (Forms)

| form | exempel |
|------|---------|
| en-form (grundform) | intensiv |
| ett-form | intensivt |
| plural / bestämd | intensiva |
| komparativ | intensivare |
| superlativ | intensivast |

## 词组搭配 (Collocations)

- `intensiv sommar` — 充实的夏天
- `intensivt arbete` — 密集的工作
- `intensivkurs` — 强化课程
- `intensiv träning` — 高强度训练

## 例句 (Sentences)

- 🇸🇪 Sommaren är kort men intensiv. — 🇨🇳 夏天短暂却充满活力（充实）。 → [[sent-sommaren-ar-kort-men-intensiv]]
- 🇸🇪 Det var en intensiv arbetsdag. — 🇨🇳 那是繁忙充实的一天。
- 🇸🇪 De tränade intensivt inför tävlingen. — 🇨🇳 他们在比赛前进行了密集训练。

## 词族 / 同义 / 反义 (Relations)

- 词族: intensitet（强度，名词），intensivkurs（强化课，名词），intensifiera（加强，动词）
- 主题: [[topic-vader-och-arstider]]

## 用法提示 (Usage Notes)

- *intensiv* 可以带有正面含义（充实、热烈）也可以是负面（高强度、紧张）——需根据语境判断。
- 在情境中 *kort men intensiv* 是对比结构，说明虽短暂但内容丰富。
