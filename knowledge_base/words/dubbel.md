# dubbel — adjektiv

📖 中文：双的、两倍的 · English: double
发音提示：/ˈdɵbɛl/；重音在第一音节 DUB-bel，`u` 读短 /ɵ/。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Utrum | dubbel |
| Neutrum | dubbelt |
| Plural / bestämd | dubbla |

## 词组搭配 (Collocations)

- `dubbla OS-guld` — 两枚奥运金牌
- `en dubbel espresso` — 一杯双份浓缩咖啡
- `dubbelt så mycket` — 两倍那么多
- `dubbelrum` / `dubbelsäng` — 双人房 / 双人床

## 例句 (Sentences)

**义项1 双重、成双 (dubbel / dubbla):**

- 🇸🇪 Nils van der Poel gick från att vara anonym till att vinna VM-guld, dubbla OS-guld samt slå världsrekord. — 🇨🇳 Nils 从默默无闻到拿下世锦赛金牌、两枚奥运金牌，并打破世界纪录。
- 🇸🇪 Jag vill ha en dubbel espresso, tack. — 🇨🇳 我想要一杯双份浓缩咖啡，谢谢。
- 🇸🇪 Vi bokade ett dubbelrum på hotellet. — 🇨🇳 我们在酒店订了一间双人房。

**义项2 两倍 (dubbelt):**

- 🇸🇪 Priset är dubbelt så högt som förra året. — 🇨🇳 价格是去年的两倍。

## 用法提示 (Usage Notes)

- 文中 `dubbla OS-guld` 是**复数无冠词**用法：`dubbel` 加复数词尾变成 `dubbla`（和 gammal → gamla、enkel → enkla 一样，**丢掉词尾 -e-**）。参见 [[grammar-adjektiv-bojning]]。
- `dubbelt` 既是 ett-词的中性形式（`ett dubbelt nöje`），也常当**副词**用：`dubbelt så ... som ...`（两倍于……），见 [[grammar-dubbelt-sa-som]]。
