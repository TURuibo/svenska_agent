# jaga — verb

📖 中文：打猎；追赶 · English: to hunt; to chase

🇸🇪 Förklaring: följa efter ett djur för att fånga eller döda det

发音提示：/ˈjɑːɡa/ — j 读 /j/；a 长音，g 为硬音 /ɡ/

## 语法变形 (Forms)

| 形式 | 瑞典语 |
|------|--------|
| Infinitiv | att jaga |
| Presens | jagar |
| Preteritum | jagade |
| Supinum | jagat |
| Imperativ | jaga! |

## 词组搭配 (Collocations)

- `jaga älg` — 猎驼鹿
- `jaga efter något` — 追逐某物

## 例句 (Sentences)

- 🇸🇪 Människor hade jagat dem länge. — 🇨🇳 人们长期捕猎它们。
- 🇸🇪 Katten jagar en mus. — 🇨🇳 猫在追一只老鼠。
- 🇸🇪 Många jagar älg på hösten. — 🇨🇳 很多人秋天猎驼鹿。
