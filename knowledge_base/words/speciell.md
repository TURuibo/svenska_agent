# speciell — adjektiv

📖 中文：特别的；特殊的 · English: special; particular
发音提示：spe-ci-ELL（重音在最后一音节）

## 语法变形 (Forms)

| Form | Example |
|------|---------|
| Grundform (en-ord) | speciell |
| Utrum/definit/plural | speciella |
| Neutrum (ett-ord) | speciellt |
| Komparativ | mer speciell |
| Superlativ | mest speciell |

## 词组搭配 (Collocations)

- `ingenting speciellt` — 没什么特别的 → see [[ingenting]]
- `något speciellt` — 什么特别的事 → see [[något]]
- `en speciell dag` — 一个特别的日子

## 例句 (Sentences)

- 🇸🇪 Ingenting speciellt. — 🇨🇳 没什么特别的。
- 🇸🇪 Det var en speciell upplevelse. — 🇨🇳 那是一次特别的体验。
- 🇸🇪 Har du något speciellt för dig i dag? — 🇨🇳 你今天有什么特别的安排吗？

## 用法提示 (Usage Notes)

- Speciell (en) / speciellt (ett) / speciella (plural/definit). Adverbially: speciellt = "especially/particularly".
- Often interchangeable with *särskild*, but *speciell* leans more toward "special/unusual".
