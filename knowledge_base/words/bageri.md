# bageri — substantiv (ett)

📖 中文：面包房 · English: bakery
发音提示：ba-ge-RI（重音在最后一音节）

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| singular obestämd | ett bageri |
| singular bestämd | bageriet |
| plural obestämd | bagerier |
| plural bestämd | bagerierna |

## 词组搭配 (Collocations)

- `gå till bageriet` — 去面包房
- `bröd från bageriet` — 面包房的面包
- `jobba på ett bageri` — 在面包房工作

## 例句 (Sentences)

- 🇸🇪 Bageriet öppnar klockan sex på morgonen. — 🇨🇳 面包房早上六点开门。
- 🇸🇪 Vi köper alltid bröd från bageriet i mataffären. — 🇨🇳 我们总是在超市的面包房买面包。
- 🇸🇪 Det luktar gott vid bageriet. — 🇨🇳 面包房旁边闻起来很香。

## 用法提示 (Usage Notes)

- **bageri** = 以面包为主（bröd, bulle 等）
- **[[konditori]]** = 以蛋糕、糕点为主，通常有咖啡座
- 大型超市内常有一个 **bageridisk**（面包柜台）或 **bageriet**（面包区）
