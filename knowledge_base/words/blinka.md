# blinka — verb (grupp 1)

📖 中文：闪烁；（灯）闪 · English: to blink / flash
发音提示：BLIN-ka；两音节。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | att blinka |
| Imperativ | blinka! |
| Presens | blinkar |
| Preteritum | blinkade |
| Supinum | (har) blinkat |

## 词组搭配 (Collocations)

- `trafikljuset blinkar` — 交通灯闪烁
- `blinka rött` — 闪红灯
- `blinka till höger` — 打右转向灯（驾车时）
- `stjärnorna blinkar` — 星星闪烁

## 例句 (Sentences)

- 🇸🇈 Trafikljuset **blinkar** rött vid korsningen. — 🇨🇳 交通灯在十字路口闪烁红色。
- 🇸🇈 Du måste **blinka** innan du svänger. — 🇨🇳 转弯前你必须打转向灯。
- 🇸🇈 Stjärnorna **blinkar** på den mörka himlen. — 🇨🇳 星星在黑暗的天空中闪烁。
