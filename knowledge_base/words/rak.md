# rak — adjektiv

📖 中文：笔直的、直的 · English: straight

🇸🇪 Förklaring: som inte har någon kurva eller böj

发音提示：/rɑːk/

## 语法变形 (Forms)

| form | en-form | ett-form | plural/bestämd |
|------|---------|----------|----------------|
| positiv obestämd | en rak (väg) | ett rakt (streck) | raka (vägar) |
| positiv bestämd | den raka (vägen) | det raka (strecket) | de raka (vägarna) |
| komparativ | rakare | | |
| superlativ | rakast / rakaste | | |

## 词组搭配 (Collocations)

- `en rak väg` — 一条笔直的路
- `gå rakt fram` — 一直往前走（副词 *rakt*）
- `rak i ryggen` — 背挺直

## 例句 (Sentences)

- 🇸🇪 Motorvägen är lång och rak. — 🇨🇳 高速公路又长又直。
- 🇸🇪 Gå rakt fram och sväng sedan till vänster. — 🇨🇳 一直走，然后向左拐。

## 词族 / 同义 / 反义 (Relations)

- 反义词: krokig (弯曲的)

## 用法提示 (Usage Notes)

- 副词形式 *rakt* = 直接地、径直地（rakt fram）。
- 与 [[grammar-adjektiv-bojning]] 规则一致：rak → rakt → raka。
