# rinna — verb

📖 中文：流；淌 · English: to run, flow

🇸🇪 Förklaring: röra sig som vatten eller en annan vätska

发音提示：/ˈrɪnːa/ — nn 长辅音，i 短；重音在 rin-

## 语法变形 (Forms)

| 形式 | 写法 |
|------|------|
| 不定式 | rinna |
| presens | rinner |
| preteritum | rann |
| supinum | runnit |
| imperativ | rinn! |

## 词组搭配 (Collocations)

- `låta vattnet rinna` — 让水流着
- `tårarna rinner` — 眼泪流下
- `rinna över` — 溢出

## 例句 (Sentences)

- 🇸🇪 Låt kranen rinna i några minuter. — 🇨🇳 请让水龙头流几分钟。
- 🇸🇪 Vattnet rinner ner i handfatet. — 🇨🇳 水流进洗手池。
- 🇸🇪 Tårarna rann nerför hennes kinder. — 🇨🇳 泪水顺着她的脸颊流下。
