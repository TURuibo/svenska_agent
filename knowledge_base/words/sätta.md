# sätta — verb (oregelbundet)

📖 中文：放(坐着)、设置 · English: to put, set

🇸🇪 Förklaring: placera något på ett visst ställe; få någon att sitta

发音提示：/ˈsɛtːa/；satte /ˈsatːɛ/

## 词组搭配 (Collocations)

- `sätta upp mål` — 设定目标（文中：satte han upp mål efter vägen）
- `sätta sig` — 坐下
- `sätta stopp för` — 叫停 → see [[sätta-stopp-för]]
- `sätta ord på känslor` — 用语言表达感受 → see [[sätta-ord-på-känslor]]
- `sätta åldersgränser` — 设定年龄限制 → see [[sätta-åldersgränser]]
- `sätta på` — 打开（电器）

## 例句 (Sentences)

**义项1 设定 (sätta upp mål):**
- 🇸🇪 För att motivera sig själv satte han upp mål efter vägen. — 🇨🇳 为了激励自己，他一路上给自己设小目标。

**义项2 放(使坐着/固定):**
- 🇸🇪 Hon satte barnet på stolen. — 🇨🇳 她把孩子放在椅子上坐好。
- 🇸🇪 Vi satte upp en hylla på väggen. — 🇨🇳 我们在墙上装了一个架子。

**义项3 sätta sig = 坐下:**
- 🇸🇪 Sätt dig ner! — 🇨🇳 坐下吧！
- 🇸🇪 Jag sätter mig här vid fönstret. — 🇨🇳 我坐在这里窗边。

## 用法提示 (Usage Notes)

- 不规则动词：sätta – sätter – **satte** – **satt**。
- ⚠️ **`satt` 有两个身份**：①sätta 的 supinum（Jag har **satt** mig）；②**sitta 的 preteritum**（Han **satt** på bussen = 他当时坐着）。靠上下文和助动词区分：`har satt`（sätta） vs `satt`（单独做谓语，sitta）。
- **sätta vs sitta**：`sätta` = 及物（把某物放成坐姿 / 设置）；`sitta` = 不及物（正处于坐着）。同理 `ställa`（竖放）/ `lägga`（平放）。见 [[grammar-ligga-sta-sitta]]、[[sitta]]、[[ställa]]。
- 文中 `sätta upp mål` = 设定目标。
