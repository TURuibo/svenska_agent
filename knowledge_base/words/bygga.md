# bygga — verb

📖 中文：建造；盖；搭建 · English: to build
发音提示：BYGG-a；y 是圆唇前元音，gg 发浊音。

## 语法变形 (Forms)

verbgrupp **2**（词干 bygg- 以浊辅音结尾 → preteritum 加 -de）

| Form | Swedish |
|------|---------|
| Infinitiv | att bygga |
| Imperativ | bygg! |
| Presens | bygger |
| Preteritum | byggde |
| Supinum | (har) byggt |
| Perfekt particip | byggd / byggt / byggda |

## 词组搭配 (Collocations)

- `bygga ett hus` — 盖一栋房子
- `bygga upp` — 建立、搭建起来（partikelverb）
- `bygga om` — 改建、翻新（partikelverb）
- `bygga ut` — 扩建（partikelverb）
- `bygga vidare på` — 在…基础上继续发展
- `bygga på (något)` — 基于、以…为基础

## 例句 (Sentences)

- 🇸🇪 De bygger ett nytt hus vid sjön. — 🇨🇳 他们在湖边盖一栋新房子。
- 🇸🇪 Vi byggde en koja när vi var små. — 🇨🇳 我们小时候搭过一个小屋。
- 🇸🇪 Förtroende byggs upp långsamt. — 🇨🇳 信任是慢慢建立起来的。

## 用法提示 (Usage Notes)

- 命令式（imperativ）就是 `bygg!` —— 和你刚输入的形式一致。
- partikelverb 很常用：`bygga **upp**`（建立）、`bygga **om**`（改建）、`bygga **ut**`（扩建）、`bygga **till**`（加盖）。
- 抽象用法也常见：`bygga upp förtroende/ett företag`（建立信任/创办公司）。
