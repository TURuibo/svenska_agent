# bygga — verb (grupp 2a)

📖 中文：建造、盖、搭建 · English: to build
发音提示：BYGG-a；y 圆唇，gg 浊塞音。

## 语法变形 (Forms)

| Tempus | Swedish |
|--------|---------|
| Infinitiv | (att) bygga |
| Presens | bygger |
| Preteritum | byggde |
| Supinum | byggt |
| Imperativ | **bygg!** |

> 你输入的 `bygg` 是 **imperativ**（命令式）/ 词干，grundform 是 `bygga`。

## 词组搭配 (Collocations)

- `bygga ett hus` — 盖一栋房子
- `bygga upp` — 建立起、搭建起（partikelverb）
- `bygga om` — 改建、翻修
- `bygga på` — 以…为基础、依靠（bygga på erfarenhet）

## 例句 (Sentences)

- 🇸🇪 De bygger ett nytt hus. — 🇨🇳 他们在盖一栋新房子。
- 🇸🇪 Vi byggde en koja när vi var barn. — 🇨🇳 我们小时候搭过一个小棚屋。
- 🇸🇪 Förtroende byggs upp långsamt. — 🇨🇳 信任是慢慢建立起来的。

## 词族 / 同义 / 反义 (Relations)

- 词族: [[byggnad]] (建筑), [[byggare]] (建造者), [[byggnation]] (建设活动)
- 同义词: [[konstruera]] (构造/建造，更技术)
- 反义词: [[riva]] (拆除)
- 主题: [[topic-stadsmiljo]]

## 用法提示 (Usage Notes)

- grupp 2a：词干以浊音结尾，preteritum 加 `-de`（byggde），supinum 加 `-t`（byggt）。
- 抽象用法很常见：`bygga upp förtroende/ett företag`（建立信任/一家公司）。
