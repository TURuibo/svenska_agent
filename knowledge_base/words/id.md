# id — substantiv (ett-ord)

📖 中文：身份证明、ID（Bank-id = 银行电子身份） · English: ID

🇸🇪 Förklaring: kort eller dokument med foto som visar vem man är

发音提示：/ˈiːdeː/ — 按字母读 i-de，e 读长音

## 词组搭配 (Collocations)

- `Bank-id` — 银行电子身份验证（BankID）
- `id-kort` — 身份证
- `logga in med Bank-id` — 用 Bank-id 登录

## 例句 (Sentences)

- 🇸🇪 Det enda du behöver göra är att logga in på ditt Bank-id. — 🇨🇳 您唯一需要做的就是登录您的 Bank-id。
- 🇸🇪 Har du id med dig? — 🇨🇳 你带身份证件了吗？
- 🇸🇪 Jag glömde mitt id-kort hemma. — 🇨🇳 我把身份证落在家里了。
