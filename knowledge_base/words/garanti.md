# garanti — substantiv (en)

📖 中文：保修；保证 · English: warranty, guarantee

🇸🇪 Förklaring: löfte från butiken att man kan få en ny eller lagad vara om den går sönder

发音提示：/ɡaranˈtiː/ — 重音在最后一个音节，ti 读长音

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| obestämd singular | en garanti |
| bestämd singular | garantin |
| obestämd plural | garantier |
| bestämd plural | garantierna |

## 词组搭配 (Collocations)

- `ett års garanti` — 一年保修
- `ha garanti` — 在保修期内
- `garantibevis` — 保修证明

## 例句 (Sentences)

- 🇸🇪 Mobilen har två års garanti. — 🇨🇳 这部手机有两年保修。
- 🇸🇪 Spara kvittot, för det gäller som garanti. — 🇨🇳 留好收据，它就是保修凭证。
- 🇸🇪 Det finns ingen garanti för att det blir bra väder. — 🇨🇳 没有天气一定好的保证。
