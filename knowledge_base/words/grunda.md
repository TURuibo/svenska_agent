# grunda — verb

📖 中文：创办；建立 · English: to found; to establish

🇸🇪 Förklaring: skapa något nytt som ska finnas länge, till exempel ett företag

发音提示：/ˈɡrɵnda/ — u 读短 ɵ（像「额」带圆唇），重音在第一音节

## 语法变形 (Forms)

| 形式 | 例 |
|---|---|
| infinitiv | grunda |
| presens | grundar |
| preteritum | grundade |
| supinum | grundat |
| s-passiv | grundas / grundades |

## 词组搭配 (Collocations)

- `grunda ett företag` — 创办公司
- `grundas på` — 基于
- `grundades 1998` — 1998 年创办

## 例句 (Sentences)

- 🇸🇪 Det grundades 1998 av två vänner. — 🇨🇳 它由两个朋友在 1998 年创办。
- 🇸🇪 Hon grundade ett litet företag. — 🇨🇳 她创办了一家小公司。
- 🇸🇪 Filmen grundas på en sann historia. — 🇨🇳 这部电影基于真实故事。
