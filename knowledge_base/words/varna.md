# varna — verb

📖 中文：警告，提醒 · English: to warn
发音提示：[ˈvɑːɳa]

## 语法变形 (Forms)

| tid | form |
|-----|------|
| infinitiv | varna |
| presens | varnar |
| preteritum | varnade |
| supinum | varnat |

## 词组搭配 (Collocations)

- `varna för ngt` — 警告某事
- `varna ngn för fara` — 警告某人有危险
- `experterna varnar` — 专家警告

## 例句 (Sentences)

- 🇸🇪 Experterna varnar för att det kan bli åska. — 🇨🇳 专家警告说可能有雷暴。
- 🇸🇪 Polisen varnade för is på vägarna. — 🇨🇳 警察警告路上有冰。
- 🇸🇪 Jag vill varna dig för den farliga situationen. — 🇨🇳 我想提醒你注意这个危险情况。

## 词族 / 同义 / 反义 (Relations)

- 词族: varning (en, 警告), varningsskylt (警告标志)

## 用法提示 (Usage Notes)

- 固定搭配 `varna för` + 名词/att-sats：总是用介词 `för`，不用 `om`。
- 例：`varna för storm`（警告有风暴）/ `varna för att köra fort`（警告不要开快车）。
