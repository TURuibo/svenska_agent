# mittenparti — substantiv (ett)

📖 中文：中间派政党 · English: centre party
发音提示：MIT-ten-par-ti

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| obestämd singular | ett mittenparti |
| bestämd singular | mittenpartiet |
| obestämd plural | mittenpartier |
| bestämd plural | mittenpartierna |

## 词组搭配 (Collocations)

- `varken höger eller vänster` — 既不是右翼也不是左翼 → see [[grammar-varken-eller]]
- `ett mittenparti i politiken` — 政治中的一个中间派政党

## 例句 (Sentences)

- 🇸🇪 Sedan finns det mittenpartier. — 🇨🇳 此外还有中间派政党。
- 🇸🇪 Mittenpartierna säger att de varken är höger eller vänster. — 🇨🇳 中间派政党说自己既不是右翼也不是左翼。
- 🇸🇪 Ett mittenparti kan ibland samarbeta med båda blocken. — 🇨🇳 中间派政党有时可以和两个阵营都合作。
