# säker — adjektiv

📖 中文：安全的；确定的；有把握的 · English: safe; sure; certain
发音提示：/ˈsɛːkɛr/

## 语法变形 (Forms)

| form | exempel |
|------|---------|
| en-form (grundform) | säker |
| ett-form | säkert |
| plural / bestämd | säkra |
| komparativ | säkrare |
| superlativ | säkrast |

## 词组搭配 (Collocations)

- `vara säker på` — 对……有把握 → see [[vara-säker-på]]
- `vara säker på att` — 确信…… → see [[vara-säker-på-att]]
- `en säker plats` — 一个安全的地方

## 例句 (Sentences)

- 🇸🇪 Är det säkert att simma här? — 🇨🇳 在这里游泳安全吗？
- 🇸🇪 Jag är inte säker på svaret. — 🇨🇳 我不确定答案。
- 🇸🇪 Det är säkrare att ta tåget. — 🇨🇳 坐火车更安全。

## 词族 / 同义 / 反义 (Relations)

- 词族: säkerhet (安全/确定性), säkra (确保, verb)
- 同义词: trygg (有安全感的)
- 反义词: [[farlig]] (危险的), osäker (不确定的)
- 主题: [[topic-karaktarsord]]

## 用法提示 (Usage Notes)

- `säker` 有两义：1) 安全的（safe）；2) 确定的、有把握的（sure/certain）。
- `trygg` 更强调心理安全感（feel safe/secure）。
