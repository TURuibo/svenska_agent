# andrahandsuthyrning — substantiv (en)

📖 中文：转租；二手出租 · English: subletting
发音提示：[ˈandraˌhandsɵthyːrnɪŋ]

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| obestämd sg | en andrahandsuthyrning |
| bestämd sg | andrahandsuthyrningen |
| obestämd pl | andrahandsuthyrningar |
| bestämd pl | andrahandsuthyrningarna |

Sammansatt ord: *andra hand* ("second hand") + *uthyrning* ("renting out", av verbet [[hyra-ut]]).

## 词组搭配 (Collocations)

- `ansöka om andrahandsuthyrning` — 申请转租
- `tillstånd för andrahandsuthyrning` — 转租许可
- `blankett för andrahandsuthyrning` — 转租申请表 → see [[blankett]]

## 例句 (Sentences)

- 🇸🇪 Kan ni skicka mig blanketten för andrahandsuthyrning? — 🇨🇳 您能给我发一份转租申请表吗？
- 🇸🇪 Vi behöver hyresvärdens tillstånd för andrahandsuthyrning. — 🇨🇳 我们需要房东的许可才能转租。
- 🇸🇪 Andrahandsuthyrning utan tillstånd kan leda till uppsägning. — 🇨🇳 未经许可的转租可能导致被解约。

## 用法提示 (Usage Notes)

- 在瑞典租房制度中，将租来的住房再转租给第三人（*hyra ut i andra hand*）通常**必须**事先获得房东（*hyresvärden*）的书面许可。
- 常见于因工作调动、留学等临时离开住所的情况。
- 与 [[hyra-ut]]（一般"出租"）不同，*andrahandsuthyrning* 特指"承租人把自己租来的房子再转租出去"。
