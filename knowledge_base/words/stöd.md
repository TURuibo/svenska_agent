# stöd — substantiv (ett)

📖 中文：支持；援助；补助；支撑物 · English: support; aid; benefit; (physical) support

🇸🇪 Förklaring: hjälp och uppmuntran som man får från andra; pengar som man kan få från samhället; något som håller uppe något annat

发音提示：STÖD，`ö` 读 [øː]（圆唇，类似"鹅"但嘴更圆）。

## 语法变形 (Forms)

| form | singular obestämd | singular bestämd | plural obestämd | plural bestämd |
|------|-------------------|-----------------|-----------------|----------------|
| grundform | ett stöd | stödet | stöd | stöden |

> ett-ord，复数与单数同形（`ett stöd` → `två stöd`）。

## 词组搭配 (Collocations)

- `få stöd från / av …` — 从……得到帮助 / 支持
- `ge stöd` / `ge stöd till …` — 给予支持
- `ekonomiskt stöd` — 经济补助 → see [[ekonomisk]]
- `psykiskt stöd` — 心理支持
- `stöd och hjälp` — 支持与帮助
- `stöd för (kostnader)` — 对（某些费用）的补助
- `ha stöd av …` — 有……作后盾 / 依据

## 例句 (Sentences)

**义项 1 — 支持、帮助 (support):**

- 🇸🇪 Hon får stöd av sin familj. — 🇨🇳 她得到家人的支持。
- 🇸🇪 Då kan du få stöd från socialtjänsten. — 🇨🇳 那你可以从社会服务处得到帮助。 → [[sent-då-kan-du-få-stöd-från-socialtjänsten]]
- 🇸🇪 Vilket stöd du kan få beror på vad du behöver hjälp med. — 🇨🇳 你能得到哪种帮助，取决于你需要哪方面的帮助。 → [[sent-vilket-stöd-du-kan-få-beror-på]]

**义项 2 — 补助、津贴 (benefit, money):**

- 🇸🇪 Du kan också få stöd för vissa andra kostnader. — 🇨🇳 你也可以就某些其他费用获得补助。 → [[sent-du-kan-också-få-stöd-för-vissa-andra]]
- 🇸🇪 Socialtjänsten bedömer om stödet behövs. — 🇨🇳 社会服务处评估是否需要这笔补助。 → [[sent-socialtjänsten-bedömer-om-stödet-behövs-för-att]]

**义项 3 — 支撑物 (physical support):**

- 🇸🇪 Den gamla damen använder en käpp som stöd. — 🇨🇳 这位老太太用拐杖作支撑。

## 用法提示 (Usage Notes)

- 同一个词可指**精神上的支持、实际帮助、国家补助、支撑物**，在文章里先看搭配：`få stöd` = 得到帮助/补助；`stöd för kostnader` = 费用补助。
- `stöd` 是名词，动词是 [[stödja]]（`stödja någon`）。
- 与 [[bistånd]]：两者都可译"补助"，`ekonomiskt bistånd` 是法定固定说法，`ekonomiskt stöd` 更宽泛。
