# ska — verb (oregelbundet)

📖 中文：将要；应该；(skulle) 会 · English: shall, will; should
⚠️ 本词条的 lemma 是 `ska`（助动词）。与名词 `skola`（学校）无关，见 [[skola]]。

🇸🇪 Förklaring: 1) används för att tala om framtiden eller om planer; 2) används för att säga vad man måste eller bör göra

发音提示：/skɑː/；skulle /ˈskɵlɛ/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) skola |
| Presens | ska |
| Presens (formell / 较旧) | skall |
| Preteritum | skulle |
| Supinum | skolat |

（助动词，没有命令式；infinitiv `skola` 与 supinum `skolat` 极少使用。）

## 词组搭配 (Collocations)

- `ska + inf.` — 将要 / 打算……→ see [[grammar-ska-infinitiv]]
- `Om … skulle + inf.` — 如果……想要 / 要是……的话（文中：Om Nils skulle nå toppen）→ see [[grammar-konditionalis-med-om]]
- `Skulle … verkligen + inf.?` — ……真的能……吗？（文中）
- `ska vara + adj.` — 据说……→ see [[grammar-ska-infinitiv-hearsay]]
- `Ska vi …?` — 我们……好吗？（提议）→ see [[grammar-ska-infinitiv-forslag]]
- `Jag skulle vilja …` — 我想要……（礼貌）→ see [[jag-skulle-vilja-ha]]
- `trodde att … skulle` — 以为……会 → see [[trodde-att-skulle]]

## 例句 (Sentences)

**义项1 skulle = 假设 / 想要（om-从句）:**
- 🇸🇪 Om Nils skulle nå toppen behövde han träna mer. — 🇨🇳 要想登顶，Nils 需要练得更多。

**义项2 skulle = 疑问（真的能……吗？）:**
- 🇸🇪 Skulle han verkligen klara det? — 🇨🇳 他真的能行吗？

**义项3 ska = 将要、打算:**
- 🇸🇪 Jag ska åka till Stockholm i morgon. — 🇨🇳 我明天要去斯德哥尔摩。
- 🇸🇪 Vad ska du göra i helgen? — 🇨🇳 你周末打算做什么？

**义项4 ska = 应该、必须（规则/命令）:**
- 🇸🇪 Du ska inte vara rädd. — 🇨🇳 你不用害怕 / 你不该害怕。

**义项5 skulle = 过去的将来（转述）:**
- 🇸🇪 Hon sa att hon skulle komma sent. — 🇨🇳 她说她会来晚。

**义项6 ska = 据说:**
- 🇸🇪 Det ska bli kallt i helgen. — 🇨🇳 据说周末会变冷。

## 用法提示 (Usage Notes)

- 常见形式只有 **ska**（口语/书面均可）和 **skulle**；`skall` 是较旧的书写形式。
- 情态助动词，后接**不带 att 的不定式**（见 [[grammar-modala-hjalpverb]]）。
- 文中的 `skulle` 出现在 `om`-从句（Om Nils skulle nå toppen）和反问句（Skulle han verkligen klara det?）里，表示「假设 / 是否真的能」，不是单纯的过去时。
- 注意：`ska` 在口语里与名词 `skola`（学校）无关，别混淆；本笔记的 slug 是 `ska`。
