# porto — substantiv

📖 中文：邮资 · English: postage

🇸🇪 Förklaring: pengar man betalar för att skicka ett brev eller ett paket

发音提示：/ˈpɔʈɔ/ — rt 读卷舌 ʈ；重音在第一音节

## 语法变形 (Forms)

| 形式 | 瑞典语 |
|------|--------|
| 单数不定 | ett porto |
| 单数定 | portot |
| 复数不定 | porton |
| 复数定 | portona |

## 词组搭配 (Collocations)

- `betala portot` — 付邮资
- `gratis porto` — 免邮费

## 例句 (Sentences)

- 🇸🇪 Du betalar bara för portot. — 🇨🇳 你只需付邮资。
- 🇸🇪 Portot för ett paket är dyrt. — 🇨🇳 寄包裹的邮资很贵。
- 🇸🇪 Det är gratis porto när du handlar för 500 kronor. — 🇨🇳 购物满500克朗免邮费。
