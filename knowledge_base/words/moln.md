# moln — substantiv (ett)

📖 中文：云 · English: cloud
发音提示：[muːln]

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| obestämd singular | ett moln |
| bestämd singular | molnet |
| plural (obestämd) | moln (oförändrad) |
| plural (bestämd) | molnen |

## 词组搭配 (Collocations)

- `lite moln` — 少量云
- `molnigt väder` — 多云天气
- `bakom molnen` — 在云后面

## 例句 (Sentences)

- 🇸🇪 Det finns lite moln på himlen men solen skiner. — 🇨🇳 天空中有少量云，但阳光普照。
- 🇸🇪 Imorgon blir det molnigt och kallt. — 🇨🇳 明天会多云变冷。
- 🇸🇪 Stora mörka moln kommer från väster. — 🇨🇳 大片黑云从西方涌来。
