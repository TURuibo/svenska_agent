# säga — verb (oregelbundet)

📖 中文：说；讲 · English: to say
发音提示：/ˈsɛja/（口语 sa /sɑː/）

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) säga |
| Presens | säger |
| Preteritum | sade |
| Preteritum (kort) | sa |
| Supinum | sagt |
| Imperativ | säg! |
| S-passiv presens | sägs |
| S-passiv preteritum | sades |

## 词组搭配 (Collocations)

- `säga nej` — 说不
- `sägs vara` — 据说是……
- `säga till` — 告诉；吩咐 → see [[säga-till]]
- `säga stopp` → see [[säga-stopp]]

## 例句 (Sentences)

- 🇸🇪 Jag berättade för min fru om mina känslor och hon sa att det inte berodde på mig. — 🇨🇳 我把感受告诉了妻子，她说这与我无关。
- 🇸🇪 Svenskar är konflikträdda och vågar inte säga nej. — 🇨🇳 瑞典人怕冲突，不敢说不。
- 🇸🇪 Här finns många populära stränder som sägs vara några av Sveriges finaste. — 🇨🇳 这里有许多受欢迎的海滩，据说是瑞典最美的几个。
- 🇸🇪 Vad säger du? — 🇨🇳 你说什么？
