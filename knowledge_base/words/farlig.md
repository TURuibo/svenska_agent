# farlig — adjektiv

📖 中文：危险的 · English: dangerous
发音提示：/ˈfɑːrlɪɡ/

## 语法变形 (Forms)

| form | böjning |
|------|---------|
| utrum obestämd | farlig |
| neutrum obestämd | farligt |
| bestämd/plural | farliga |
| komparativ | farligare |
| superlativ: | farligast |

## 词组搭配 (Collocations)

- `en farlig orm` — 一条危险的蛇
- `farlig situation` — 危险的情况
- `farliga djur` — 危险的动物

## 例句 (Sentences)

- 🇸🇪 Ormen är farlig och kan bita. — 🇨🇳 蛇很危险，会咬人。
- 🇸🇪 Det är farligt att gå ensam på natten. — 🇨🇳 晚上独自行走是危险的。
- 🇸🇪 Vargen kan vara farlig om man stör den. — 🇨🇳 如果打扰到狼，它可能会很危险。
