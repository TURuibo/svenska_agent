# skydd — substantiv (ett)

📖 中文：保护；掩蔽处 · English: protection; shelter

🇸🇪 Förklaring: 1) något som gör att man inte blir skadad eller utsatt för fara; 2) plats där man kan söka sig undan regn eller fara

发音提示：/ɧʏd/

## 词组搭配 (Collocations)

- `söka skydd` — 寻求庇护/躲避
- `skydd mot` — 防护……

## 例句 (Sentences)

- 🇸🇪 Människor tvingades söka skydd på sina hustak. — 🇨🇳 人们被迫到屋顶上躲避。
- 🇸🇪 Hjälmen ger skydd mot skador. — 🇨🇳 头盔能防止受伤。
- 🇸🇪 De fick skydd under ett träd. — 🇨🇳 他们在树下躲避。
