# sitta — verb (grupp 4 / stark verb)

📖 中文：坐；固定；贴附 · English: to sit; to be fixed (in place)
发音提示：SIT-ta；två stavelser.

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | att sitta |
| Imperativ | sitt! |
| Presens | sitter |
| Preteritum | satt |
| Supinum | (har) suttit |

## 词组搭配 (Collocations)

- `sitta på stolen` — 坐在椅子上
- `sitta i soffan` — 坐在沙发里
- `sitta fast` — 固定住；粘住
- `sitta på hyllan` — 固定在架子上（物体）
- `sitter på väggen` — 固定在墙上

## 例句 (Sentences)

- 🇸🇈 Ett foto **sitter** på den översta hyllan. — 🇨🇳 一张照片固定在最上面那层架子上。
- 🇸🇈 Jag **sitter** i soffan och läser. — 🇨🇳 我坐在沙发里看书。
- 🇸🇈 Etiketten **sitter** fast på burken. — 🇨🇳 标签贴牢在罐子上。

## 词族 / 同义 / 反义 (Relations)

- 词族: [[sätta]] (动词，"放置/坐下"，动态), [[sittplats]] (座位)
- 同义词: [[hänga]] (某些墙上物体可互换，但语感不同)
- 反义词: [[stå]] (站立), [[ligga]] (躺/平放)
- 主题: [[topic-rumsliga-relationer]]

## 用法提示 (Usage Notes)

- **sitta vs sätta**：`sitta` = 状态（坐着/固定着）；`sätta` = 动态（坐下/放置）。
  - *Fotografiet **sitter** på väggen.* (现在固定着) → *Jag **satte** upp fotografiet.* (我把照片贴上去)
- 贴附或嵌入某处的物体用 **sitta**：照片（固定在架子/墙上）、螺丝、标签。
- 描述人：坐在椅子/沙发上也用 sitta。
- 强变词（stark verb）：sitta → satt → suttit。
