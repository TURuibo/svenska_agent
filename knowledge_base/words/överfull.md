# överfull — adjektiv

📖 中文：超员的、过满的 · English: overcrowded, overfull
发音提示：Ö-ver-full

## 语法变形 (Forms)

| Form | Exempel |
|------|---------|
| Utrum sg. indef. | en överfull buss |
| Neutrum sg. indef. | ett överfullt tåg |
| Definite sg. | den/det överfulla vagnen |
| Plural indef. | överfulla bussar |
| Plural def. | de överfulla tågen |

## 词组搭配 (Collocations)

- `ett överfullt pendeltåg` — 超载的通勤列车
- `överfull buss` — 过满的公共汽车
- `överfull tunnelbana` — 超员的地铁

## 例句 (Sentences)

- 🇸🇪 Pendeltåget var överfullt under morgonens rusningstid. — 🇨🇳 早高峰时通勤列车严重超载。
- 🇸🇪 Bussen var så överfull att vi fick vänta på nästa. — 🇨🇳 公共汽车太满了，我们不得不等下一班。
- 🇸🇪 Det överfulla torget gjorde det svårt att gå. — 🇨🇳 过于拥挤的广场让人难以行走。
