# block — substantiv (ett)

📖 中文：阵营；（写字）本；街区 · English: bloc; (writing) pad; (city) block
发音提示：BLÅKK

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| obestämd singular | ett block |
| bestämd singular | blocket |
| obestämd plural | block |
| bestämd plural | blocken |

## 词组搭配 (Collocations)

- `höger- och vänsterblock` — 右翼和左翼阵营
- `ett skrivblock` — 一本写字本
- `bo i ett block` — 住在一栋楼/街区里

## 例句 (Sentences)

**义项1 — 政治阵营 (political bloc):**
- 🇸🇪 Man brukar dela in partierna i höger- och vänsterblock. — 🇨🇳 人们通常把政党分成右翼和左翼阵营。

**义项2 — 写字本 (notepad):**
- 🇸🇪 Hon skrev ner numret på ett block. — 🇨🇳 她把号码写在了一本便签本上。

**义项3 — 街区/楼群 (city block):**
- 🇸🇪 De bor i ett stort block nära centrum. — 🇨🇳 他们住在市中心附近的一栋大楼里。
