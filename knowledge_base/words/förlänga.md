# förlänga — verb (grupp 2)

📖 中文：延长；使变长 · English: to extend; to prolong

🇸🇪 Förklaring: göra något längre i tid eller i storlek

发音提示：/fœrˈlɛŋa/ — 重音在第二音节 `läng`；ng 读 /ŋ/

| Presens | förlänger |

| Supinum | förlängt |
| Imperativ | förläng |
| S-passiv | förlängs |

## 词组搭配 (Collocations)

- `förlänga tiden` — 延长时间
- `förlänga ett avtal` — 续签合同
- `förlänga ett visum` — 延长签证

## 例句 (Sentences)

- 🇸🇪 Om vädret blir dåligt kan tiden förlängas. — 🇨🇳 如果天气不好，时间可能会延长。
- 🇸🇪 Företaget vill förlänga avtalet med ett år. — 🇨🇳 公司想把合同延长一年。
- 🇸🇪 Du kan förlänga lånet på biblioteket. — 🇨🇳 你可以在图书馆续借。
- 🇸🇪 Vi förlängde semestern med två dagar. — 🇨🇳 我们把假期延长了两天。
