# kosta — verb (v.2a)

📖 中文：花费；价钱为 · English: to cost

🇸🇪 Förklaring: ha ett visst pris som man måste betala

发音提示：/ˈkɔstˌa/ — 重音第一音节，st 清晰连读，a 在末尾

## 语法变形 (Forms)

| Form | Swedish |

| Infinitiv | kosta |
| Presens | kostar |
| Preteritum | kostade |
| Supinum | kostat |
| Imperativ | kosta |

## 词组搭配 (Collocations)

- `Vad kostar det?` — 这个多少钱？
- `kosta mycket` — 很贵

## 例句 (Sentences)

- 🇸🇪 Biljetten kostade hundra kronor. — 🇨🇳 门票花了一百克朗。
- 🇸🇪 Vad kostar kaffet? — 🇨🇳 咖啡多少钱？
- 🇸🇪 Resan kostar mycket pengar. — 🇨🇳 这趟旅行很花钱。
