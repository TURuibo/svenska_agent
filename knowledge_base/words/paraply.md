# paraply — substantiv (ett)

📖 中文：雨伞 · English: umbrella
发音提示：pa-ra-PLY（重音在末音节）

## 语法变形 (Forms)

| form | example |
|------|---------|
| grundform (obestämd) | ett paraply |
| bestämd form | paraplyet |
| plural obestämd | paraplyer |
| plural bestämd | paraplyerna |

## 词组搭配 (Collocations)

- `ta med ett paraply` — 带上雨伞
- `öppna/stänga paraplyet` — 打开/收起雨伞
- `köpa ett bra paraply` — 买一把好雨伞
- `paraplyet gick sönder` — 雨伞坏了

## 例句 (Sentences)

- 🇸🇪 Jag har köpt ett bra paraply för det regnar ofta i Sverige. — 🇨🇳 我买了一把好雨伞，因为瑞典经常下雨。
- 🇸🇪 Kom ihåg att ta med paraplyet — prognosen säger regn hela dagen. — 🇨🇳 记得带雨伞——预报说全天都会下雨。
- 🇸🇪 Man behöver inte ett billigt paraply — man behöver ett stabilt! — 🇨🇳 不需要便宜雨伞——需要一把结实的！
