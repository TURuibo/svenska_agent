# veta — verb (oregelbundet)

📖 中文：知道 · English: to know (a fact)
发音提示：/ˈveːta/；vet /veːt/；visste /ˈvɪstɛ/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) veta |
| Presens | vet |
| Preteritum | visste |
| Supinum | vetat |
| Imperativ | vet! |

## 词组搭配 (Collocations)

- `veta att …` — 知道……（文中：han visste att det fanns mer att ge）
- `veta vad …` — 知道……是什么（文中：visste inte vad hans liv gick ut på）→ see [[gå-ut-på]]
- `Jag vet inte.` — 我不知道。
- `bra att veta` — 知道了很好 → see [[bra-att-veta]]
- `Vad vet jag?` — 我哪知道？

## 例句 (Sentences)

- 🇸🇪 Tiden som följde var jobbig eftersom han inte visste vad hans liv gick ut på. — 🇨🇳 接下来的日子很难熬，因为他不知道自己的人生意义何在。
- 🇸🇪 Han var nöjd men han visste att det fanns mer att ge. — 🇨🇳 他挺满意，但他知道自己还有更多可以付出。
- 🇸🇪 Jag vet inte var stationen ligger. — 🇨🇳 我不知道车站在哪里。
- 🇸🇪 Vet du vad hon heter? — 🇨🇳 你知道她叫什么名字吗？

## 用法提示 (Usage Notes)

- 不规则动词：veta – vet – **visste** – **vetat**；presens 与词干同形（vet）。
- **veta / känna / kunna**：`veta` = 知道事实（Jag vet att …）；`känna` = 认识人或地方（Jag känner henne）；`kunna` = 会（技能）。
- 后接从句：`veta att …`（知道……）、`veta vad/var/hur …`（知道……是什么/哪里/如何，间接问句，见 [[grammar-indirekt-fraga]]）。
