# veta — verb (oregelbundet)

📖 中文：知道（事实） · English: to know (a fact)
发音提示：/ˈveːta/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) veta |
| Presens | vet |
| Preteritum | visste |
| Supinum | vetat |
| Imperativ | vet! |

不规则：presens `vet`（无 -er），preteritum `visste`。

## 词组搭配 (Collocations)

- `jag vet inte` — 我不知道
- `veta att …` — 知道……
- `bra att veta` — 好知道 → see [[bra-att-veta]]
- `ge besked / låta ngn veta` — 让某人知道

## 例句 (Sentences)

- 🇸🇪 Jag vet inte var han bor. — 🇨🇳 我不知道他住哪里。
- 🇸🇪 Visste du att Sverige har många öar? — 🇨🇳 你知道瑞典有很多岛吗？
- 🇸🇪 Hon har aldrig vetat svaret. — 🇨🇳 她从来不知道答案。

## 词族 / 同义 / 反义 (Relations)

- 相关: [[känna]]、[[kunna]]

## 用法提示 (Usage Notes)

| 动词 | 含义 | 例 |
|------|------|-----|
| veta | 知道事实/信息 | Jag vet att han bor här. |
| känna | 认识（人/地方）；感觉 | Jag känner honom. |
| kunna | 会（技能）；能 | Jag kan simma. |

- 中文“知道/认识/会”对应三个动词，别混用：*Jag vet honom* ✗ → *Jag känner honom* ✓。
