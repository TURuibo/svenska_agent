# möjlig — adjektiv

📖 中文：可能的 · English: possible
发音提示：/ˈmøːjlɪɡ/

## 语法变形 (Forms)

| 形式 | 写法 |
|------|------|
| en-form (utrum) | möjlig |
| ett-form (neutrum) | **möjligt** |
| plural / bestämd | möjliga |
| komparativ | (mer möjlig) |
| superlativ | (mest möjlig) |

> 你查的 **möjligt** 是中性（ett-form），也用作副词性搭配（så … som möjligt）。见 [[grammar-adjektiv-kongruens]]。

## 词组搭配 (Collocations)

- `så … som möjligt` — 尽可能地……（så snart som möjligt 尽快）→ [[så-snart-som-möjligt]]、[[snarast-möjligt]]
- `det är möjligt att …` — 有可能……（后接从句）
- `om möjligt` — 如果可能的话
- `göra ngt möjligt` — 使某事成为可能

## 例句 (Sentences)

- 🇸🇪 Är det **möjligt** att boka bord? — 🇨🇳 可以订位吗？（有可能订位吗？）
- 🇸🇪 Kom så snart som **möjligt**. — 🇨🇳 尽快过来。
- 🇸🇪 Alla **möjliga** lösningar är testade. — 🇨🇳 所有可能的方案都试过了。

## 词族 / 同义 / 反义 (Relations)

- 词族: [[möjlighet]]（名词：可能性、机会）、[[möjligen]]（副词：可能、也许）
- 同义词: —
- 反义词: [[omöjlig]]（不可能的）
- 主题: —

## 用法提示 (Usage Notes)

- 形容词随名词性/数变化：**en möjlig** lösning / **ett möjligt** problem / flera **möjliga** vägar。
- `så … som möjligt` 是超高频固定框架，中间填副词/形容词：`så snart / så fort / så mycket / så billigt … som möjligt`。
- 别把 `möjligt`（形容词/副词，"可能的"）和 `möjlighet`（名词，"机会/可能性"）混淆。
