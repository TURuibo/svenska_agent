# möjlig — adjektiv

📖 中文：可能的 · English: possible

🇸🇪 Förklaring: som kan hända, göras eller finnas

发音提示：/ˈmœ̂jːlɪɡ/ —— g 在 -ig 结尾常弱读；**möjligt** 读 /ˈmœjːlɪt/（g 不发音）

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| en-ord (obestämd) | möjlig |
| ett-ord (obestämd) | **möjligt** |
| plural / bestämd | möjliga |
| komparativ | (mer möjlig — 罕用) |
| superlativ | **möjligast** / bästa möjliga |

> 📌 **möjligt** 的三种常见身份：
> 1. ett-名词前：*ett **möjligt** svar* 一个可能的答案
> 2. 形容词作谓语，主语是 `det`：*Det är **möjligt**.* 这是可能的（`det` 按 ett 词处理 → -t）→ [[grammar-adjektiv-som-predikat]]
> 3. 副词性固定搭配：`så snart som möjligt`、`snarast möjligt`

## 词组搭配 (Collocations)

- `Det är möjligt att …` — ……是可能的
- `så snart som möjligt` — 尽快 → see [[så-snart-som-möjligt]]
- `snarast möjligt` — 尽快（正式） → see [[snarast-möjligt]]
- `så mycket som möjligt` — 尽可能多
- `om möjligt` — 如果可能的话
- `bästa möjliga …` — 尽可能好的……：*bästa möjliga resultat*
- `göra det möjligt för någon att …` — 使某人能够……

## 例句 (Sentences)

- 🇸🇪 Är det möjligt att boka en tid i morgon? — 🇨🇳 明天可以预约一个时间吗？
- 🇸🇪 Jag ber er skicka en rörmokare så snart som möjligt. — 🇨🇳 请尽快派一个水管工来。
- 🇸🇪 Det finns flera möjliga lösningar. — 🇨🇳 有好几种可能的解决方案。
- 🇸🇪 Ring mig, om möjligt före klockan fem. — 🇨🇳 给我打电话，可能的话五点前。

## 用法提示 (Usage Notes)

- `Det är möjligt` 里用 **-t**：形容词谓语要和主语 `det` 一致（ett 形式）→ [[grammar-adjektiv-kongruens]]。
- `möjligt` ≈ 英语 possible；`kanske`（也许）是副词，别混：*Det är möjligt.* = *Kanske.*
