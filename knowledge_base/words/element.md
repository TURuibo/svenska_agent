# element — substantiv (ett)

📖 中文：暖气片；散热器 · English: radiator
发音提示：e-le-MENT；tre stavelser, betoning på sista.

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Singular obestämd | ett element |
| Singular bestämd | elementet |
| Plural obestämd | element（零复数）|
| Plural bestämd | elementen |

## 词组搭配 (Collocations)

- `under fönstret` — 在窗户下面（典型安装位置）
- `elementet är varmt` — 暖气片是热的
- `sätta på elementet` — 开暖气

## 例句 (Sentences)

- 🇸🇈 Under fönstret **finns** ett element. — 🇨🇳 窗户下面有一个暖气片。
- 🇸🇈 Elementet är kallt — vi har inte slagit på värmen. — 🇨🇳 暖气片是凉的——我们还没开暖气。
- 🇸🇈 I Sverige **finns** det element i nästan varje rum. — 🇨🇳 在瑞典，几乎每个房间都有暖气片。

## 词族 / 同义 / 反义 (Relations)

- 词族: [[värme]] (热；暖气), [[uppvärmning]] (供暖), [[värmepump]] (热泵)
- 同义词: [[radiator]] (散热器，更技术性), [[värmeelement]] (暖气元件)
- 反义词: —
- 主题: [[topic-hemmet]]

## 用法提示 (Usage Notes)

- 暖气片通常安装在窗户下面（防止冷气下沉）。
- 在"暖气片"的意义上，`element` 是 ett 词，零复数。
- `element` 在化学语境中也指"元素"（grundämne），但家居语境中只指暖气片。
