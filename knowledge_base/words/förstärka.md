# förstärka — verb (v.2)

📖 中文：加强；加剧 · English: to strengthen / reinforce
发音提示：för-STÄRK-a

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) förstärka |
| Presens | förstärker |
| Preteritum | förstärkte |
| Supinum | förstärkt |

## 词组搭配 (Collocations)

- `förstärka klyftorna` — 加剧差距 → see [[klyfta]]
- `förstärka ett argument` — 加强一个论点
- `förstärka känslan av` — 加强……的感觉

## 例句 (Sentences)

- 🇸🇪 De rikaste kan förstärka de ekonomiska klyftorna. — 🇨🇳 最富有的人可能会加剧经济差距。
- 🇸🇪 Regeringen vill förstärka skolan med mer pengar. — 🇨🇳 政府想用更多资金加强学校。
- 🇸🇪 Solen förstärkte känslan av sommar. — 🇨🇳 阳光加强了夏天的感觉。

## 词族 / 同义 / 反义 (Relations)

- 反义词: [[försvaga]]（削弱）

## 用法提示 (Usage Notes)

- 前缀 `för-` + `stärka`（使强壮），词根 `stark`（强壮的）。
- Verbgrupp 2, 弱变化：förstärker / förstärkte / förstärkt。
