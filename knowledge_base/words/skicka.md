# skicka — verb

📖 中文：寄, 发送, 运送 · English: to send

🇸🇪 Förklaring: se till att något, t.ex. ett brev eller ett paket, kommer till en annan person eller plats

发音提示：skic-ka

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| infinitiv | skicka |
| presens | skickar |
| preteritum | skickade |
| supinum | skickat |
| imperativ | skicka! |

## 词组搭配 (Collocations)

- `skicka vapen` — 运送武器
- `skicka ett brev` — 寄信
- `skicka ett mejl` — 发邮件

## 例句 (Sentences)

- 🇸🇪 Länderna ska skicka mer vapen till Ukraina. — 🇨🇳 这些国家将向乌克兰运送更多武器。
- 🇸🇪 Kan du skicka mig länken? — 🇨🇳 你能把链接发给我吗？
- 🇸🇪 Han skickade ett brev till sin familj. — 🇨🇳 他给家人写了封信。
