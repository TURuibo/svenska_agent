# flyg — substantiv

📖 中文：飞机；航班；空运 · English: plane; flight; air travel

🇸🇪 Förklaring: resa eller transport med flygplan; ett flygplan

发音提示：/flyːɡ/ — y 长音

## 语法变形 (Forms)

| form | svenska |
|------|---------|
| obestämd sg | flyg |
| bestämd sg | flyget |
| obestämd pl | flyg |
| bestämd pl | flygen |

## 词组搭配 (Collocations)

- `ta flyg / ta flyget` — 坐飞机
- `med flyg` — 乘飞机
- `flyg från Arlanda` — 从阿兰达起飞的航班

## 例句 (Sentences)

- 🇸🇪 Ön har ingen broförbindelse så för att ta sig dit tar man flyg eller båt. — 🇨🇳 岛没有桥连接，所以要去那里得坐飞机或船。
- 🇸🇪 Flyg från Arlanda tar 50 minuter. — 🇨🇳 从阿兰达飞过去要 50 分钟。
