# upprop — substantiv (ett)

📖 中文：请愿书；呼吁；号召 · English: petition; appeal; call
发音提示：[ˈɵpˌruːp] — prefix upp + rop (shout/call)

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Obestämd sing. | ett upprop |
| Bestämd sing. | uppropet |
| Obestämd pl. | upprop |
| Bestämd pl. | uppropet (pl.) → uppropens |

*Plural = samma som singular (ett-ord med nollplural): upprop*

## 词组搭配 (Collocations)

- `skriva under ett upprop` — 签署一份请愿书
- `starta ett upprop` — 发起一份请愿
- `ett upprop för klimatet` — 气候请愿书
- `ett namninsamlingsupprop` — 征名请愿

## 例句 (Sentences)

- 🇸🇪 Över 200 kända personer har skrivit under ett upprop om klimatet. — 🇨🇳 超过200位知名人士签署了一份气候请愿书。
- 🇸🇪 Organisationen startade ett upprop mot nedläggningen av skolan. — 🇨🇳 该组织发起了一份反对关闭学校的请愿。
- 🇸🇪 Ett upprop är när många människor skriver under för att visa att de håller med. — 🇨🇳 请愿书是指许多人签名以表示他们赞同某事。

## 词族 / 同义 / 反义 (Relations)

- 词族: ropa (to call/shout), upp (up)
- 同义词: petition, vädjan
- 主题: [[topic-samhälle-och-politik]], [[topic-miljö-och-klimat]]

## 用法提示 (Usage Notes)

- Sammansatt ord: upp + rop (a call upward/out)
- Plural utan ändelse: ett upprop → många upprop
- "Skriva under ett upprop" = sign a petition (sign underneath)
