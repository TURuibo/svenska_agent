# grovavfall — substantiv (ett)

📖 中文：大件垃圾 · English: bulky waste

🇸🇪 Förklaring: stora saker som möbler och mattor som inte får plats i vanliga sopor

发音提示：/ˈɡruːvˌavfal/ — 主重音 gro-，次重音 av-；v 轻读

## 语法变形 (Forms)

| 形式 | 写法 |
|------|------|
| 不定式单数 | ett grovavfall |
| 定式单数 | grovavfallet |
| 复数 | （不可数，少用） |

## 词组搭配 (Collocations)

- `slänga grovavfall` — 扔大件垃圾
- `lämna grovavfall` — 交大件垃圾
- `container för grovavfall` — 大件垃圾箱

## 例句 (Sentences)

- 🇸🇪 Där kan du slänga gamla möbler, mattor och annat grovavfall. — 🇨🇳 你可以在那里扔旧家具、地毯和其他大件垃圾。
- 🇸🇪 Grovavfall ska lämnas på återvinningscentralen. — 🇨🇳 大件垃圾应送到回收中心。
- 🇸🇪 Soffan räknas som grovavfall. — 🇨🇳 沙发算大件垃圾。
