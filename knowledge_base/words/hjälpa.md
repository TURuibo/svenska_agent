# hjälpa — verb

📖 中文：帮助 · English: to help

🇸🇪 Förklaring: göra något för någon så att det blir lättare för hen

发音提示：hjäl-pa（h不发音）

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| infinitiv | hjälpa |
| presens | hjälper |
| preteritum | hjälpte |
| supinum | hjälpt |
| imperativ | hjälp! |
| s-form (hjälpas åt) | hjälps |
| s-form preteritum | hjälptes |

## 词组搭配 (Collocations)

- `hjälpa Ukraina` — 帮助乌克兰
- `hjälpa till` — 帮忙
- `hjälpa ngn med ngt` — 帮助某人做某事

## 例句 (Sentences)

- 🇸🇪 De kom överens om att fortsätta hjälpa Ukraina i kriget mot Ryssland. — 🇨🇳 他们一致同意继续帮助乌克兰对抗俄罗斯的战争。
- 🇸🇪 Kan du hjälpa mig med mina läxor? — 🇨🇳 你能帮我做作业吗？
- 🇸🇪 Hon hjälper sin mamma varje dag. — 🇨🇳 她每天都帮助她的妈妈。

## 用法提示 (Usage Notes)

- verb grupp 2（hjälpte, hjälpt）
- `hjälpa` + infinitiv（无 att）：`Jag hjälper dig laga maten.`
- `hjälpas åt` = 互相帮忙（s-形式表"互相"）：Vi hjälps åt med städningen.（我们一起分担打扫。）
