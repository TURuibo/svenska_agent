# smaka — verb (grupp 1)

📖 中文：品尝；尝起来 · English: to taste; to try
发音提示：SMAH-kah

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| infinitiv | smaka |
| presens | smakar |
| preteritum | smakade |
| supinum | smakat |
| imperativ | smaka! |

## 词组搭配 (Collocations)

- `det smakar gott` — 味道很好
- `hoppas det smakar` — 希望好吃
- `smaka på något` — 尝尝某样东西
- `smakar för gott` — 太好吃了（口语）

## 例句 (Sentences)

- 🇸🇪 Det smakar ju faktiskt för gott! — 🇨🇳 说真的，味道太好了！
- 🇸🇪 Hoppas det smakar! — 🇨🇳 希望好吃！
- 🇸🇪 Kan jag smaka på kakan? — 🇨🇳 我可以尝一口蛋糕吗？

## 词族 / 同义 / 反义 (Relations)

- 词族: smak (口味/味道), smaklig (美味的), välsmakande (好吃的)
- 主题: [[topic-kafe-fika]]

## 用法提示 (Usage Notes)

- *Smakar gott* = 好吃；*Smakar inte* = 不好吃。
- *Smaka på* = 品尝一下（试吃）；*Det smakar* + adj 描述味道。
