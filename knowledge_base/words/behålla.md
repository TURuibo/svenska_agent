# behålla — verb (grupp 4)

📖 中文：保持、保留 · English: to keep, retain
发音提示：/beˈhoːla/；behöll /beˈhœl/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) behålla |
| Presens | behåller |
| Preteritum | behöll |
| Supinum | behållit |
| Imperativ | behåll! |
| Perfekt particip | behållen |
| S-passiv (presens) | behålls |
| S-passiv (preteritum) | behölls |

## 词组搭配 (Collocations)

- `behålla balansen` — 保持平衡（文中：behålla balansen mellan träning och fritid）
- `behålla lugnet` — 保持冷静
- `behålla jobbet` — 保住工作
- `behålla kvittot` — 留着收据

## 例句 (Sentences)

- 🇸🇪 Om Nils skulle nå toppen behövde han träna mer, men han ville fortfarande behålla balansen mellan träning och fritid. — 🇨🇳 要想登顶，Nils 需要练得更多，但他仍想保持训练与业余生活之间的平衡。
- 🇸🇪 Du kan behålla boken. — 🇨🇳 这本书你可以留着。
- 🇸🇪 Hon behöll lugnet trots stressen. — 🇨🇳 尽管压力很大，她还是保持了冷静。
- 🇸🇪 Vi vill behålla vårt gamla hus. — 🇨🇳 我们想保留我们的老房子。

## 用法提示 (Usage Notes)

- 强变化动词，变位同 `hålla`：behålla – behåller – **behöll** – **behållit**（å → ö，见 [[grammar-starka-verb]]）。
- `behålla` = 保持不丢（状态/物品）；`hålla` = 握住、保持；`spara` = 储蓄、存。
- 与 `förlora`（失去）相对。
