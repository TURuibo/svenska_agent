# fri — adjektiv

📖 中文：自由的 · English: free
发音提示：/friː/

## 语法变形 (Forms)

| form | en-form | ett-form | plural/bestämd |
|------|---------|----------|----------------|
| positiv obestämd | en fri (fågel) | ett fritt (djur) | fria (djur) |
| positiv bestämd | den fria (fågeln) | det fria (djuret) | de fria (djuren) |
| komparativ | friare | | |
| superlativ | friast / friaste | | |

**Obs:** ett-form *fritt* (dubbel-t).

## 词组搭配 (Collocations)

- `en fri fågel` — 一只自由的鸟
- `fri som en fågel` — 自由如鸟（成语）
- `fri tid` — 空闲时间
- `i frihet` — 在自由中、在野外

## 例句 (Sentences)

- 🇸🇪 Fågeln är fri och flyger högt. — 🇨🇳 鸟儿自由地飞翔在高空。
- 🇸🇪 Jag har fri tid på helgen. — 🇨🇳 我周末有空闲时间。
- 🇸🇪 Djuret lever fritt i naturen. — 🇨🇳 动物在大自然中自由生活。
