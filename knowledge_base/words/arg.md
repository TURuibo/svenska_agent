# arg — adjektiv

📖 中文：生气的 · English: angry
发音提示：/arj/

## 语法变形 (Forms)

| form | böjning |
|------|---------|
| utrum obestämd | arg |
| neutrum obestämd | argt |
| bestämd/plural | arga |
| komparativ | argare |
| superlativ | argast |

## 词组搭配 (Collocations)

- `en arg älg` — 一头愤怒的驼鹿
- `arg på någon` — 对某人生气
- `bli arg` — 变得生气

## 例句 (Sentences)

- 🇸🇪 Älgen blev arg när vi kom för nära. — 🇨🇳 当我们走得太近时，驼鹿变得很愤怒。
- 🇸🇪 Hon är arg på sin bror för att han tog hennes saker. — 🇨🇳 她对弟弟很生气，因为他拿了她的东西。
- 🇸🇪 Bli inte arg — vi löser det här. — 🇨🇳 别生气——我们会解决这个问题的。
