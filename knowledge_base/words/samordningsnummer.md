# samordningsnummer — substantiv

📖 中文：协调号码（给未办户籍登记者的身份号） · English: coordination number

🇸🇪 Förklaring: identitetsnummer för den som inte är folkbokförd i Sverige

发音提示：/samˈɔrdnɪŋsˌnʉmɛr/ — 重音在 -ord-；sam-ord-nings-nummer 四段连读，次重音在 nummer

## 语法变形 (Forms)

| | 单数 | 复数 |
|---|---|---|
| 不定 | ett samordningsnummer | samordningsnummer |
| 定 | samordningsnumret | samordningsnumren |

## 例句 (Sentences)

- 🇸🇪 Den som inte är folkbokförd kan få ett samordningsnummer. — 🇨🇳 没有户籍登记的人可以得到协调号码。
- 🇸🇪 Ett samordningsnummer ser nästan likadant ut som ett personnummer. — 🇨🇳 协调号码看起来几乎和个人号码一样。
- 🇸🇪 Dagen i samordningsnumret är 60 högre. — 🇨🇳 协调号码里的“日”大 60。
