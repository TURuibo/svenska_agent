# system — substantiv

📖 中文：系统；制度 · English: system

🇸🇪 Förklaring: flera delar som hör ihop och fungerar tillsammans; ordning för hur något är organiserat i samhället

发音提示：/sʏˈsteːm/ — 重音在第二音节 -stem

## 语法变形 (Forms)

| 形式 | 单数 | 复数 |
|---|---|---|
| 不定 | ett system | system |
| 定指 | systemet | systemen |

## 词组搭配 (Collocations)

- ett-ord，复数同形。常作复合词尾：skattesystem, välfärdssystem。

## 例句 (Sentences)

- 🇸🇪 Det svenska skattesystemet är komplicerat. — 🇨🇳 瑞典的税收制度很复杂。
- 🇸🇪 Datorn har ett nytt system. — 🇨🇳 这台电脑有新系统。
- 🇸🇪 Vi behöver ett bättre system för sophantering. — 🇨🇳 我们需要更好的垃圾处理系统。
