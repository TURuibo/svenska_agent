# lugn — adjektiv

📖 中文：平静的、安静的 · English: calm
发音提示：/lɵŋːn/

## 语法变形 (Forms)

| form | en-form | ett-form | plural/bestämd |
|------|---------|----------|----------------|
| positiv obestämd | en lugn (häst) | ett lugnt (djur) | lugna (djur) |
| positiv bestämd | den lugna (hästen) | det lugna (djuret) | de lugna (djuren) |
| komparativ | lugnare | | |
| superlativ | lugnast / lugnaste | | |

## 词组搭配 (Collocations)

- `ta det lugnt` — 放轻松、慢慢来
- `vara lugn` — 保持平静
- `ett lugnt djur` — 一只温顺平静的动物
- `lugn och stilla` — 安静而平和
