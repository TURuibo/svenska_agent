# uttala — verb

📖 中文：发音；表达（uttala sig = 发表意见） · English: to pronounce; to express (uttala sig)

🇸🇪 Förklaring: säga ett ord på ett visst sätt; säga vad man tycker om något

发音提示：/ˈʉːtˌɑːla/ — 重音在 ut-，ut 读长音 /ʉː/；注意 u 是瑞典语特有的圆唇前元音

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | uttala |
| Presens | uttalar |
| Preteritum | uttalade |
| Supinum | uttalat |
| Imperativ | uttala! |

## 词组搭配 (Collocations)

- `uttala sig om` — 就…发表意见
- `uttala ett ord` — 发一个词的音

## 例句 (Sentences)

- 🇸🇪 Hur uttalar man det här ordet? — 🇨🇳 这个词怎么发音？
- 🇸🇪 Politikern ville inte uttala sig om saken. — 🇨🇳 这位政治家不想就此事发表意见。
- 🇸🇪 Många utlänningar tycker att sj-ljudet är svårt att uttala. — 🇨🇳 很多外国人觉得 sj 音很难发。
