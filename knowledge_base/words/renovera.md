# renovera — verb (grupp 1)

📖 中文：翻修；整修 · English: to renovate

🇸🇪 Förklaring: göra ett gammalt hus eller rum som nytt igen

发音提示：/renɔˈveːra/ — 重音在第三音节 `ve`（长音）

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | renovera |
| Presens | renoverar |
| Preteritum | renoverade |
| Supinum | renoverat |
| Imperativ | renovera |
| S-passiv | renoveras |

## 词组搭配 (Collocations)

- `renovera köket` — 翻修厨房
- `renovera ett hus` — 翻修房子
- `ett renoverat badrum` — 翻新过的浴室

## 例句 (Sentences)

- 🇸🇪 Det är dyrare att renovera än att bygga nytt. — 🇨🇳 翻修比新建更贵。
- 🇸🇪 Vi renoverar badrummet i sommar. — 🇨🇳 我们今年夏天翻修浴室。
- 🇸🇪 Huset renoverades förra året. — 🇨🇳 这栋房子去年翻修过。
- 🇸🇪 De har renoverat hela lägenheten. — 🇨🇳 他们把整套公寓都翻新了。
