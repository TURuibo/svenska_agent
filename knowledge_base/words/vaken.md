# vaken — adjektiv

📖 中文：清醒的、警醒的 · English: awake / alert
发音提示：/ˈvɑːkɛn/

## 语法变形 (Forms)

| form | en-form | ett-form | plural/bestämd |
|------|---------|----------|----------------|
| positiv obestämd | en vaken (björn) | ett vake**t** (djur) | vakna (djur) |
| positiv bestämd | den vakna (björnen) | det vakna (djuret) | de vakna (djuren) |
| komparativ | mer vaken / vakare | | |
| superlativ | mest vaken / vakast | | |

**Obs:** *vaken* är ett -en adjektiv (har -et i ett-form, -na i bestämd/plural).

## 词组搭配 (Collocations)

- `vara vaken` — 保持清醒
- `ett vaken djur` — 一只警醒的动物
- `hålla sig vaken` — 保持清醒

## 例句 (Sentences)

- 🇸🇪 Är du vaken? — 🇨🇳 你醒了吗？
- 🇸🇪 Barnet är vaken hela natten. — 🇨🇳 孩子整夜都没睡着。
- 🇸🇪 Hunden är alltid vaken och alert. — 🇨🇳 那只狗总是保持警觉。
