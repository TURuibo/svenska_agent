# råda — verb (grupp 2)

📖 中文：① 建议（某人做某事）② （状况）存在、占主导 · English: ① to advise ② to prevail; to exist

🇸🇪 Förklaring: 1) säga till någon vad hen borde göra; 2) (om ett läge eller en känsla) finnas och vara det som gäller

发音提示：RÅ-da，`å` 读 [oː]。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | råda |
| Presens | råder |
| Preteritum | rådde |
| Supinum | rått |
| Imperativ | råd |
| Pres. particip | rådande（`den rådande situationen` 当前的局面） |

> 导入块标为 "v.4"，但 `rådde / rått` 是第 2 组的 -dde / -tt 变位（同 `betyda – betydde – betytt`），不是强变化，所以这里记为 **第 2 组**。部分资料也见 `rådit`，规范词典以 **rått** 为准（`Det har rått oenighet.`）。

## 词组搭配 (Collocations)

- `råda någon att + 不定式` — 建议某人做某事 → [[råda-någon-att]]
- `Det råder + 名词` — 存在……（状况） → [[det-råder-oklarhet]]
  - `Det råder oklarhet / förvirring / brist på … / stor enighet` — 不明确 / 混乱 / ……短缺 / 高度一致
  - `Här råder förbud mot …` — 此处禁止……
- `råda bot på …` — 补救、解决（`råda bot på bristen`）
- `rådande` — 当前的、现行的（形容词）

## 例句 (Sentences)

**义项1 建议 (to advise) — 直接宾语，后接 att + 不定式:**

- 🇸🇪 Polisen råder förarna att använda hjälm. — 🇨🇳 警方建议骑行者戴头盔。 → [[sent-polisen-råder-förarna-att-använda-hjälm]]
- 🇸🇪 Läkaren råder mig att vila några dagar. — 🇨🇳 医生建议我休息几天。

**义项2 存在、占主导 (to prevail) — 虚主语 det，书面 / 新闻:**

- 🇸🇪 I dag råder det oklarhet om var man får parkera. — 🇨🇳 目前，关于可以在哪里停车仍然不明确。 → [[sent-i-dag-råder-det-oklarhet-om-var]]
- 🇸🇪 Det råder stor förvirring efter beskedet. — 🇨🇳 消息公布后一片混乱。
- 🇸🇪 Här råder förbud mot cykling. — 🇨🇳 此处禁止骑行。

## 词族 / 同义 / 反义 (Relations)

- 同义词: 义项1 [[rekommendera]]（推荐）, 义项2 近义 [[finnas]], [[förekomma]]（偏口语；`råda` 更书面）
- 反义词: [[avråda]] (劝阻)

## 用法提示 (Usage Notes)

- ⚠️ 两个义项**结构完全不同**：义项1 是 `råda + 人 + att + 不定式`（人是直接宾语，不加 till / för）；义项2 是 `det råder + 名词`（`det` 是虚主语，真正的主语在后面），几乎只出现在书面和新闻里。
- 与 `ge råd`（给建议）、`ett råd`（一条建议）区分：`råda` 是动词，`råd` 是名词。
- 与 [[få-råd]]、[[ha-råd-med]] 里的 `råd`（"负担得起"）是同形词，别混。
