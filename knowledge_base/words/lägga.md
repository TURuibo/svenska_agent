# lägga — verb (oregelbundet)

📖 中文：放；搁置；躺下（lägga sig） · English: to lay / put / place
发音提示：LÄG-ga；两音节，重音在首音节。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | att lägga |
| Imperativ | lägg! |
| Presens | lägger |
| Preteritum | lade |
| Supinum | (har) lagt |

## 词组搭配 (Collocations)

- `lägga sig` — 躺下；去睡觉 → see [[lägga-sig]]
- `lägga sig tidigt` — 早点睡
- `lägga fram` — 摆出；提出（方案）
- `lägga märke till` — 注意到

## exempel på Sentences

- 🇸🇪 På kvällen kom jag hem och **lade** mig tidigt. — 🇨🇳 晚上我回到家，很早就躺下了。
- 🇸🇈 Han **lägger** alltid boken på bordet innan han sover. — 🇨🇳 他睡前总是把书放在桌子上。
- 🇸🇈 Kom ihåg att **lägga** dig i tid ikväll! — 🇨🇳 记得今晚早点睡！

## 词族 / 同义 / 反义 (Relations)

- 词族: [[ligga]] (v. 平躺/位于，状态动词), [[läge]] (ett, 位置/情况), [[lägga sig]] (v. 躺下)
- 同义词: [[placera]] (v. 放置，正式), [[sätta]] (v. 竖着放/放)
- 反义词: [[ta upp]] (v. 拿起/捡起)
- 主题: [[topic-vardagsrutin]]

## 用法提示 (Usage Notes)

- 重要区分：`lägga` = 把东西放成卧倒状态（及物）；`ligga` = 躺着/位于（不及物，状态）。
- `lägga sig` = 去躺下（开始躺的动作）；`ligga` = 已经躺着（持续状态）。
- 不规则：lägga → **lade** → lagt（注意不是 *lade sig* 的 preteritum 是 *lade*）。
