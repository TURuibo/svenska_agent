# tusen — räkneord

📖 中文：一千 · English: thousand

🇸🇪 Förklaring: talet 1000, tio gånger hundra

发音提示：/ˈtʉːsɛn/ — u 读长圆唇音 [ʉː]，-en 弱读

## 语法变形 (Forms)

| 形式 | 说明 |
|------|------|
| tusen | 1000（也作名词 ett tusen） |
| tvåtusen | 2000（连写） |
| tusental | 几千 |

## 词组搭配 (Collocations)

- `tusen kronor` — 一千克朗
- `tusen tack` — 千谢
- `två tusen tjugosex` — 2026（年份：tjugohundratjugosex）

## 例句 (Sentences)

- 🇸🇪 Hyran är åtta tusen kronor. — 🇨🇳 房租八千克朗。
- 🇸🇪 Tusen tack för hjälpen! — 🇨🇳 非常感谢帮忙！
- 🇸🇪 Det bor tusen människor här. — 🇨🇳 这里住着一千人。
