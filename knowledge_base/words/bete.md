# bete — verb (grupp 2, 主要用 bete sig)

📖 中文：bete sig = 举止、表现 · English: to behave
发音提示：/ˈbeːte/

⚠️ 同形：名词 `bete`（诱饵/牧草）、动词 `bita`（咬）无关。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | bete |
| Presens | beter |
| Preteritum | betedde |
| Supinum | betett |
| Imperativ | bete |

## 词组搭配 (Collocations)

- `bete sig märkligt` — 举止奇怪
- `bete sig illa` — 举止恶劣

## 例句 (Sentences)

- 🇸🇪 Hon verkade berusad och betedde sig märkligt. — 🇨🇳 她看上去醉了，举止奇怪。
- 🇸🇪 Barnen beter sig fint i skolan. — 🇨🇳 孩子们在学校表现很好。
- 🇸🇪 Bete dig ordentligt! — 🇨🇳 好好表现！
