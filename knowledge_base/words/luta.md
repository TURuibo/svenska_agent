# luta — verb

📖 中文：倾斜，向一侧倾 · English: to tilt, to lean
发音提示：['lʉːta]，重音在第一音节

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | luta |
| Presens | lutar |
| Preteritum | lutade |
| Supinum | lutat |
| Imperativ | luta |

## 词组搭配 (Collocations)

- `luta åt höger/vänster` — 向右/左倾 → see [[riktning]]
- `luta mot` — 倾向于，靠着
- `luta bort från` — 向远离…方向倾斜 → see [[bort-från]]
- `luta sig` — 倚靠，倚

## 例句 (Sentences)

- 🇸🇪 Jorden lutar lite. — 🇨🇳 地球有点倾斜。
- 🇸🇪 Den lutar ungefär 23,5 grader. — 🇨🇳 它倾斜大约23.5度。
- 🇸🇪 På vintern lutar den norra delen av jorden bort från solen. — 🇨🇳 冬天时，地球的北部向远离太阳的方向倾斜。
- 🇸🇪 Han lutade cykeln mot väggen. — 🇨🇳 他把自行车靠在墙上。

## 用法提示 (Usage Notes)

- Grupp 1 verb: lutar / lutade / lutat — 规则变位
- 描述物体倾斜（如地球、梯子、身体）；与 `åt`（向某方向）或 `mot`（靠着）连用
- 也可引申为"倾向于某观点"：Han lutar mot att flytta = 他倾向于搬家
