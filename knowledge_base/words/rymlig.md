# rymlig — adjektiv

📖 中文：宽敞的 · English: spacious
发音提示：/ˈryːmˌlɪɡ/

## 语法变形 (Forms)

| form | exempel |
|------|---------|
| en-form (grundform) | rymlig |
| ett-form | rymligt |
| plural/bestämd | rymliga |
| komparativ | rymligare |
| superlativ | rymligast / rymligaste |

## 词组搭配 (Collocations)

- `en rymlig lägenhet` — 一套宽敞的公寓
- `rymligt kök` — 宽敞的厨房
- `en rymlig garderob` — 一个宽敞的衣柜 → see [[garderob]]

## 例句 (Sentences)

- 🇸🇪 Lägenheten är rymlig och ljus. — 🇨🇳 这套公寓宽敞明亮。
- 🇸🇪 De letar efter ett rymligt hus med stor trädgård. — 🇨🇳 他们在找一栋带大花园的宽敞房子。
- 🇸🇪 Köket är rymligt nog för ett stort matbord. — 🇨🇳 厨房足够宽敞，能放下一张大餐桌。
