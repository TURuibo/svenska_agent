# spendera — verb

📖 中文：花费（钱、时间） · English: to spend (money, time)

🇸🇪 Förklaring: använda pengar eller tid på något

发音提示：/spɛnˈdeːra/ — 重音在 -de-；e 读长音

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| infinitiv | spendera |
| presens | spenderar |
| preteritum | spenderade |
| supinum | spenderat |
| imperativ | spendera |

## 词组搭配 (Collocations)

- `spendera pengar på` — 在…上花钱
- `spendera tid` — 花时间

## 例句 (Sentences)

- 🇸🇪 Jag spenderar mycket pengar på mat. — 🇨🇳 我在吃的上花很多钱。
- 🇸🇪 Vi spenderade hela dagen på stranden. — 🇨🇳 我们在海滩上度过了一整天。
- 🇸🇪 Hur mycket har du spenderat den här månaden? — 🇨🇳 这个月你花了多少钱？
