# fatta — verb (grupp 1)

📖 中文：做出（决定）；（口语）明白、理解 · English: to make (a decision); to grasp, to get it (colloquial)
发音提示：FAT-ta，`a` 短。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | fatta |
| Presens | fattar |
| Preteritum | fattade |
| Supinum | fattat |
| Imperativ | fatta |
| Perf. particip | fattad / fattat / fattade |
| S-passiv | fattas（`beslutet fattades` 决定被做出） |

## 词组搭配 (Collocations)

- `fatta beslut` / `fatta ett beslut` — 做出决定 → [[fatta-beslut]]
- `Beslutet fattades …` — 决定是……做出的（新闻 / 公文被动式）
- `Jag fattar inte.` / `Fattar du?` — 我不明白 / 你明白吗？（口语）
- `fatta sig kort` — 长话短说
- `fatta tag i …` — 抓住（第三种较少见的用法）；`fatta eld` — 着火
- 对比 [[ta-sitt-livs-beslut]]：`ta ett beslut` 也说得通，`fatta beslut` 更书面

## 例句 (Sentences)

**义项1 做出（决定）— 书面 / 新闻:**

- 🇸🇪 I måndags fattade kommunfullmäktige beslutet om de nya reglerna. — 🇨🇳 周一，市议会就新规做出了决定。 → [[sent-i-måndags-fattade-kommunfullmäktige-beslutet]]
- 🇸🇪 Vi måste fatta ett beslut i dag. — 🇨🇳 我们今天必须做出决定。
- 🇸🇪 Beslutet fattades av styrelsen i går kväll. — 🇨🇳 这个决定是董事会昨晚做出的。

**义项2 明白、理解 — 口语:**

- 🇸🇪 Jag fattar inte vad du menar. — 🇨🇳 我不明白你的意思。
- 🇸🇪 Fattar du? — 🇨🇳 你明白了吗？
- 🇸🇪 Hon fattade direkt vad som hade hänt. — 🇨🇳 她立刻明白了发生了什么。

## 用法提示 (Usage Notes)

- 新闻 / 公文里几乎只用义项1：`fatta beslut`；说话人若想表达"明白"，口语用 `fatta`，书面改用 `förstå`。
- ⚠️ `fattas`（s-形）还有另一个意思"缺少"：`Det fattas pengar.`（缺钱）、`Vad fattas dig?`（你怎么了？）——和被动"被做出"同形，看上下文判断。
- `beslut` 是 ett-词：`ett beslut`，所以 `beslutet fattades`。
