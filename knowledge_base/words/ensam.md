# ensam — adjektiv

📖 中文：孤独的/独自的 · English: alone, lonely
发音提示：EN-sam；重音在第一音节，元音 `e` 短促。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Utrum singular | ensam |
| Neutrum singular | ensamt |
| Plural / bestämd | ensamma |

## 词组搭配 (Collocations)

- `vara ensam` — 独自一人
- `känna sig ensam` — 感到孤独（情感上）
- `bo ensam` — 独居

## 例句 (Sentences)

- [[sent-eftersom-astrid-var-ensam-kunde-hon]] 🇸🇪 Eftersom Astrid var ensam kunde hon inte ta hand om barnet själv. 🇨🇳 因为阿斯特丽德是独自一人，她无法自己照顾孩子。

## 用法提示 (Usage Notes)

- `ensam` 可以是中性描述（alone = 独自一人）或情感上的孤独（lonely）— 语境区分。
  - *Hon bor ensam.* = 她独居（中性）
  - *Hon känner sig ensam.* = 她感到孤独（情感）
- 原文：*Eftersom Astrid var ensam kunde hon inte ta hand om barnet själv.*
