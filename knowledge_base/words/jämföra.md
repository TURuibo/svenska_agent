# jämföra — verb (oregelbundet, som "föra")

📖 中文：比较 · English: to compare
发音提示：jäm-FÖ-ra

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| infinitiv | jämföra |
| presens | jämför |
| preteritum | jämförde |
| supinum | jämfört |
| imperativ | jämför! |

## 词组搭配 (Collocations)

- `jämföra priser` — 比较价格
- `jämföra A med B` — 把A和B进行比较
- `jämfört med` — 与……相比 → see [[jämfört-med]]

## 例句 (Sentences)

- 🇸🇪 [[sent-pricerunner-ar-en-webbplats-dar]] Pricerunner är en webbplats där konsumenter kan jämföra priser på produkter. — 🇨🇳 Pricerunner是一个消费者可以比较产品价格的网站。
- 🇸🇪 Jämför alltid priser innan du köper något dyrt. — 🇨🇳 买贵重物品前一定要先比较价格。
- 🇸🇪 Man kan inte jämföra en cykel med en bil. — 🇨🇳 自行车和汽车没法比较。
