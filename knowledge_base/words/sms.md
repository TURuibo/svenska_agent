# sms — substantiv (ett)

📖 中文：短信 · English: text message, SMS

🇸🇪 Förklaring: kort textmeddelande som man skickar med mobiltelefonen

发音提示：ess-emm-ESS（按字母读，重音在最后）

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Singular obestämd | ett sms |
| Singular bestämd | sms:et |
| Plural obestämd | sms |
| Plural bestämd | sms:en |

> 缩略词加词尾时用冒号：**sms:et, sms:en**。动词 *sms:a*（发短信）= sms:ar / sms:ade / sms:at。

## 词组搭配 (Collocations)

- `skicka ett sms` — 发短信 → see [[skicka-ett-sms]]
- `få ett sms` — 收到短信
- `svara på ett sms` — 回短信
- `via sms` — 通过短信

## 例句 (Sentences)

- 🇸🇪 Säg ditt nummer, så skickar jag ett sms. — 🇨🇳 你说号码，我发个短信给你。
- 🇸🇪 Jag fick ett sms från förskolan i morse. — 🇨🇳 今早我收到幼儿园的一条短信。
- 🇸🇪 Kan du svara på mitt sms? — 🇨🇳 你能回一下我的短信吗？
- 🇸🇪 Vi sms:ar varandra om tiden. — 🇨🇳 我们用短信互相确认时间。
