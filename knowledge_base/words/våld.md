# våld — substantiv

📖 中文：暴力 · English: violence

🇸🇪 Förklaring: när någon skadar eller slår en annan person eller använder kraft mot någon

发音提示：/vɔld/ — å 读短音 ɔ；ld 两个辅音都要读

## 语法变形 (Forms)

| 形式 | 词形 |
|------|------|
| 单数不定 | ett våld |
| 单数定 | våldet |
| 复数 | （通常不用复数） |

## 词组搭配 (Collocations)

- `utsatt för våld` — 遭受暴力 → see [[utsatt-för-våld]]
- `våld i nära relationer` — 亲密关系中的暴力
- `använda våld` — 使用暴力

## 例句 (Sentences)

- 🇸🇪 Han är utsatt för våld i sin relation. — 🇨🇳 他在亲密关系中遭受暴力。
- 🇸🇪 Det finns hjälp för den som utsätter andra för våld. — 🇨🇳 对身边的人施暴的人也有帮助可寻。
- 🇸🇪 Polisen använde inte våld. — 🇨🇳 警方没有使用暴力。
