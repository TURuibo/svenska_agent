# samtal — substantiv (ett)

📖 中文：电话；通话；对话；谈话 · English: call / conversation / talk
发音提示：SAM-tal；两音节，重音在首音节。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Singular obestämd | ett samtal |
| Singular bestämd | samtalet |
| Plural obestämd | samtal |
| Plural bestämd | samtalen |

注意：`samtal` 复数与基本形相同（不变格复数）。

## 词组搭配 (Collocations)

- `få ett samtal` — 接到一个电话
- `ett telefonsamtal` — 一通电话
- `ha ett samtal med ngn` — 与某人通话/交谈
- `avbryta ett samtal` — 中断通话

## 例句 (Sentences)

- 🇸🇪 En stund senare fick jag ett **samtal** — de hade hittat min plånbok! — 🇨🇳 过了一会儿，我接到一个电话——他们找到了我的钱包！
- 🇸🇈 Jag hade ett långt **samtal** med min chef idag. — 🇨🇳 今天我和老板进行了一次长谈。
- 🇸🇈 **Samtalet** bröts mitt i — mobilnätet var dåligt. — 🇨🇳 通话在中途断了——手机网络不好。
