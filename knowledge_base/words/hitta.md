# hitta — verb (grupp 1)

📖 中文：找到；发现 · English: to find / discover
发音提示：HIT-ta；两音节，重音在首音节。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | att hitta |
| Imperativ | hitta! |
| Presens | hittar |
| Preteritum | hittade |
| Supinum | (har) hittat |

## 词组搭配 (Collocations)

- `hitta sin plånbok` — 找到自己的钱包
- `hitta rätt` — 找到正确的路/位置
- `hitta på` — 发明/想出（主意）→ see [[hitta-på]]
- `kunna hitta hem` — 能找到回家的路

## 例句 (Sentences)

- 🇸🇪 Personalen hade **hittat** min plånbok. — 🇨🇳 工作人员找到了我的钱包。
- 🇸🇈 Jag kan inte **hitta** mina nycklar! — 🇨🇳 我找不到我的钥匙！
- 🇸🇈 Vi **hittade** en fin restaurang nära hotellet. — 🇨🇳 我们在酒店附近找到了一家好餐厅。
