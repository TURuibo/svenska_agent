# kall — adjektiv

📖 中文：冷的；寒冷的 · English: cold
发音提示：/kalː/

## 语法变形 (Forms)

| form | exempel |
|------|---------|
| en-form (grundform) | kall |
| ett-form | kallt |
| plural / bestämd | kalla |
| komparativ | kallare |
| superlativ | kallast |

## 词组搭配 (Collocations)

- `kallt vatten` — 冷水
- `en kall dag` — 一个寒冷的天
- `kall vind` — 寒风

## 例句 (Sentences)

- 🇸🇪 Det är väldigt kallt ute idag. — 🇨🇳 今天外面很冷。
- 🇸🇪 Kan du ge mig ett glas kallt vatten? — 🇨🇳 你能给我一杯冷水吗？
- 🇸🇪 Det kalla vädret gör mig sjuk. — 🇨🇳 寒冷的天气让我生病了。

## 词族 / 同义 / 反义 (Relations)

- 词族: kyla (寒冷, substantiv), kallna (变冷, verb)
- 同义词: kylig (凉飕飕的，稍弱)
- 反义词: varm (温暖的), het (热的)
- 主题: [[topic-hälsa]], [[topic-karaktarsord]]

## 用法提示 (Usage Notes)

- `kall` = 冷（具体温度）；`kylig` = 有点凉（常用于天气或态度）。
- 比较级用于天气：Imorgon blir det kallare（明天会更冷）。
