# långsam — adjektiv

📖 中文：慢的 · English: slow
发音提示：/ˈlɔŋˌsɑːm/

## 语法变形 (Forms)

| form | böjning |
|------|---------|
| utrum obestämd | långsam |
| neutrum obestämd | långsamt |
| bestämd/plural | långsamma |
| komparativ | långsammare |
| superlativ | långsammast |

## 词组搭配 (Collocations)

- `en långsam apa` — 一只慢动作的猴子
- `ett långsamt tempo` — 缓慢的节奏
- `långsamma rörelser` — 缓慢的动作

## 例句 (Sentences)

- 🇸🇪 Apan klättrar långsamt upp i trädet. — 🇨🇳 猴子缓慢地爬上树。
- 🇸🇪 Tåget är långsamt men billigt. — 🇨🇳 火车很慢但便宜。
- 🇸🇪 Sköldpaddan är känd för sina långsamma rörelser. — 🇨🇳 乌龟以动作缓慢著称。
