# samla — verb (grupp 1)

📖 中文：收集；聚集 · English: to collect; to gather
发音提示：/ˈsamla/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) samla |
| Presens | samlar |
| Preteritum | samlade |
| Supinum | samlat |
| Imperativ | samla! |
| Perfekt particip | samlad |

## 词组搭配 (Collocations)

- `samla in pengar` — 募集资金 → see [[samla-in]]
- `samla alla recept` — 把所有食谱收集起来

## 例句 (Sentences)

- 🇸🇪 Det var ett sätt för henne att samla alla recept som hon hade nedskrivna på olika lappar. — 🇨🇳 这对她来说是把写在各种纸条上的所有食谱收集起来的一个办法。
- 🇸🇪 Jag har sett att det finns många Facebookgrupper som samlar in pengar. — 🇨🇳 我看到有很多 Facebook 小组在募集资金。
- 🇸🇪 Barnen samlar på frimärken. — 🇨🇳 孩子们收集邮票。
