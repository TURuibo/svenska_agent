# intresse — substantiv

📖 中文：兴趣，关注 · English: interest

🇸🇪 Förklaring: vilja att veta mer om något eller att ägna sig åt något

发音提示：/ɪnˈtrɛsːɛ/ — 重音在 tres（第二音节），e 短

## 语法变形 (Forms)

| 形式 | 词形 |
|------|------|
| obestämd singular | ett intresse |
| bestämd singular | intresset |
| obestämd plural | intressen |
| bestämd plural | intressena |

## 词组搭配 (Collocations)

- `visa intresse för` — 对…表示兴趣/关注
- `ha intresse av` — 对…有兴趣

## 例句 (Sentences)

- 🇸🇪 Ingen visade intresse för deras krav efter kriget. — 🇨🇳 战后没有人对她们的诉求表示关注。
- 🇸🇪 Hon har stort intresse för musik. — 🇨🇳 她对音乐很感兴趣。
- 🇸🇪 Barnen visade intresse för det nya spelet. — 🇨🇳 孩子们对这个新游戏表现出兴趣。
