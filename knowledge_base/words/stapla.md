# stapla — verb

📖 中文：堆叠/摞起 · English: to stack, to pile
发音提示：STA-pla（重音在第一音节）

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| infinitiv | stapla |
| presens | staplar |
| preteritum | staplade |
| supinum | staplat |
| imperativ | stapla! |

**Verbgrupp:** 1 (presens +r, preteritum -ade, supinum -at)

## 词组搭配 (Collocations)

- `stapla kartonger` — 堆叠纸盒
- `stapla böcker` — 摞书
- `lätt att stapla` — 容易堆叠
- `stapla på varandra` — 一个摞一个

## 例句 (Sentences)

- 🇸🇪 Den var lättare att stapla och transportera än de gamla förpackningarna. — 🇨🇳 它比旧包装更容易堆叠和运输。
- 🇸🇪 Du kan stapla kartongerna i hyllan. — 🇨🇳 你可以把纸盒摞放在架子上。
- 🇸🇪 Varorna staplas i lager för att spara plats. — 🇨🇳 货物被堆叠在仓库里以节省空间。
