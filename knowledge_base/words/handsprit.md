# handsprit — substantiv (en)

📖 中文：免洗洗手液；酒精洗手液 · English: hand sanitizer

🇸🇪 Förklaring: vätska med alkohol som man gnider in i händerna för att döda bakterier och virus

发音提示：[ˈhandˌspriːt]，hand + sprit（酒精）。

- 🇸🇪 Handsprit hjälper inte mot magsjuka. — 🇨🇳 免洗洗手液对肠胃炎不管用。
- 🇸🇪 Det finns handsprit vid dörren. — 🇨🇳 门口有免洗洗手液。
- 🇸🇪 Vi använder handsprit efter tvål och vatten. — 🇨🇳 我们用肥皂水洗完手再用免洗洗手液。

- sprit = 烈酒/酒精，所以 handsprit 字面「手酒精」。
- 幼儿园常识：肠胃炎病毒（vinterkräksjuka）用 handsprit 杀不死，要 **tvål och vatten**。
