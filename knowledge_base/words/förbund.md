# förbund — substantiv (ett)

📖 中文：联合会；联盟 · English: federation; union

🇸🇪 Förklaring: organisation som många föreningar eller grupper bildar tillsammans

发音提示：/ˈfœrˌbɵnd/ — 重音在第一音节；ö 在 r 前读开口音

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Singular obestämd | ett förbund |
| Singular bestämd | förbundet |
| Plural obestämd | förbund |
| Plural bestämd | förbunden |

## 词组搭配 (Collocations)

- `skidförbund` — 雪联；`idrottsförbund` — 体育联合会

## 例句 (Sentences)

- 🇸🇪 Det svenska skidförbundet säger nej. — 🇨🇳 瑞典雪联说不。
- 🇸🇪 Hon jobbar för ett förbund som hjälper lärare. — 🇨🇳 她在一个帮助教师的联合会工作。
- 🇸🇪 Fotbollsförbundet väljer en ny chef. — 🇨🇳 足球协会选出新负责人。
