# kändisskap — substantiv (ett)

📖 中文：名人身份；名气 · English: celebrity / fame
发音提示：KÄN-dis-skap

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Obestämd singular | ett kändisskap |
| Bestämd singular | kändisskapet |
| Plural | (saknas — 抽象不可数名词) |

## 词组搭配 (Collocations)

- `en koppling mellan rikedom och kändisskap` — 财富与名人身份之间的联系 → see [[koppling]]
- `uppnå kändisskap` — 获得名人身份

## 例句 (Sentences)

- 🇸🇪 Finns det en koppling mellan rikedom och kändisskap? — 🇨🇳 财富与名人身份之间存在联系吗？
- 🇸🇪 Kändisskap kan komma med både fördelar och nackdelar. — 🇨🇳 名人身份既有优点也有缺点。
- 🇸🇪 Hon vande sig aldrig vid sitt kändisskap. — 🇨🇳 她从来没有习惯自己的名人身份。

## 词族 / 同义 / 反义 (Relations)

- 词族: [[kändis]]（名人，名词）

## 用法提示 (Usage Notes)

- 由名词 `kändis`（名人）+ 抽象后缀 `-skap` 构成（类似英语 -hood/-ship）。
- ett-ord，通常不用复数。
