# disk — substantiv

📖 中文：吧台；柜台；（也指）洗碗 · English: counter; bar; (also: dishwashing)
发音提示：disk（短促，清晰的 k 音）

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| obestämd sg | en disk |
| bestämd sg | disken |
| obestämd pl | diskar |
| bestämd pl | diskarna |

## 词组搭配 (Collocations)

- `vid disken` — 在吧台；在柜台
- `gå till disken` — 走到吧台
- `diska` (verb) — 洗碗
- `stå vid disken` — 站在柜台旁

## 例句 (Sentences)

**义项1 — 吧台/柜台 (counter/bar):**

- 🇸🇪 Gå och beställ vid disken, så sätter jag mig. — 🇨🇳 你去吧台点，我先坐下。
- 🇸🇪 Kassören stod bakom disken och log. — 🇨🇳 收银员站在柜台后面微笑。

**义项2 — 洗碗 (dishwashing):**

- 🇸🇪 Kan du ta hand om disken ikväll? — 🇨🇳 今晚你能洗碗吗？

- 在咖啡馆语境中，`disk` = 吧台/点餐柜台（counter）。
- 在家庭语境中，`disk` = 需要洗的碗碟（dishwashing/the dishes）。
- 动词 `diska` = 洗碗（to wash the dishes）。
