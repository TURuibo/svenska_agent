# kräva — verb (grupp 2)

📖 中文：要求、需要 · English: to require, demand
发音提示：/ˈkrɛːva/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) kräva |
| Presens | kräver |
| Preteritum | krävde |
| Supinum | krävt |
| Imperativ | kräv! |
| Perfekt particip | krävd |
| S-passiv (presens) | krävs |
| S-passiv (preteritum) | krävdes |

## 词组搭配 (Collocations)

- `det krävs …` — 需要…… → see [[det-krävs]]
- `det som krävs` — 所必需的（文中：det som krävdes för att hålla uppe en elitkarriär）→ see [[hålla-uppe]]
- `kräva att + 从句` — 要求……
- `kräva ersättning` — 要求赔偿
- `kräva svar` — 要求答复

## 例句 (Sentences)

**义项1 需要（客观要求, 常用 krävs）:**
- 🇸🇪 Därför gjorde han bara det som krävdes för att hålla uppe en elitkarriär. — 🇨🇳 所以他只做维持一份精英运动生涯所必需的那些。
- 🇸🇪 Det krävs mycket träning för att bli bra. — 🇨🇳 要变强需要大量训练。
- 🇸🇪 Jobbet kräver körkort. — 🇨🇳 这份工作需要驾照。

**义项2 要求、强烈要求:**
- 🇸🇪 Fansen krävde att biljetterna skulle bli billigare. — 🇨🇳 球迷要求票价降低。
- 🇸🇪 Han kräver svar på sin fråga. — 🇨🇳 他要求对他的问题给出答复。

## 用法提示 (Usage Notes)

- 第 2 组动词：kräva – kräver – **krävde** – **krävt**。
- 文中的 `krävdes` 是 **s-passiv 过去式**：`det som krävdes` = 「所被需要的东西 / 所必需的」。结构见 [[grammar-s-passiv]]；非人称句式 `det krävs …`（= 需要……）见 [[grammar-det-kravs]]。
- 名词 `krav`（要求）出现在文中 `ställa krav`（提出要求）。
