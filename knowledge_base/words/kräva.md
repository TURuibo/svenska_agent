# kräva — verb (grupp 2a)

📖 中文：要求；需要（强烈） · English: to demand; to require
发音提示：/ˈkrɛːva/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) kräva |
| Presens | kräver |
| Preteritum | krävde |
| Supinum | krävt |
| Imperativ | kräv! |

grupp 2a（-er/-de/-t；词干 kräv-）。

## 词组搭配 (Collocations)

- `kräva något av någon` — 向某人要求某事
- `kräva att + 从句` — 要求……
- `det krävs` — 需要有、必须 → see [[det-krävs]]
- `kräva tid / mod` — 需要时间 / 勇气

## 例句 (Sentences)

- 🇸🇪 Jobbet kräver goda kunskaper i svenska. — 🇨🇳 这份工作要求良好的瑞典语。
- 🇸🇪 Eleverna krävde ett nytt schema. — 🇨🇳 学生们要求一份新课表。
- 🇸🇪 Det kräver mycket träning att bli bra. — 🇨🇳 要变好需要大量练习。

## 词族 / 同义 / 反义 (Relations)

- 词族: [[krav]]（ett，要求）、[[det-krävs]]
- 近义: [[behöva]]（需要，较弱）

## 用法提示 (Usage Notes)

- `behöva` = 需要（一般）；`kräva` = 要求/必须具备（更强、更正式）。
