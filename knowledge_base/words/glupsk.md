# glupsk — adjektiv

📖 中文：贪吃的、贪婪的 · English: voracious / greedy
发音提示：/ɡlɵpsk/

## 语法变形 (Forms)

| form | en-form | ett-form | plural/bestämd |
|------|---------|----------|----------------|
| positiv obestämd | en glupsk (haj) | ett glupsk (djur) | glupska (djur) |
| positiv bestämd | den glupska (hajen) | det glupska (djuret) | de glupska (djuren) |
| komparativ | glupskare | | |
| superlativ | glupskast / glupskaste | | |

**Obs:** *glupsk* har ingen ändelse i ett-form (konsonantkluster -psk).

## 词组搭配 (Collocations)

- `en glupsk haj` — 一条贪吃的鲨鱼
- `glupsk aptit` — 贪婪的胃口
- `äta glupsk` — 狼吞虎咽

## 例句 (Sentences)

- 🇸🇪 Hajen är ett glupsk djur. — 🇨🇳 鲨鱼是一种贪食的动物。
- 🇸🇪 Han åt glupsk och lämnade ingenting kvar. — 🇨🇳 他狼吞虎咽，什么都没留下。
- 🇸🇪 Katten har en glupsk aptit. — 🇨🇳 这只猫食欲非常旺盛。
