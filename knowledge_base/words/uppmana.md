# uppmana — verb (grupp 1)

📖 中文：呼吁；敦促；督促 · English: to urge; to call on; to exhort
发音提示：UPP-ma-na，重音在第一音节（`upp-` 词头）。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | uppmana |
| Presens | uppmanar |
| Preteritum | uppmanade |
| Supinum | uppmanat |
| Imperativ | uppmana |
| S-passiv | uppmanas / uppmanades |

## 词组搭配 (Collocations)

- `uppmana någon att + inf` — 呼吁 / 敦促某人去……
- `uppmana till lugn` — 呼吁保持冷静
- `polisen uppmanar allmänheten att …` — 警方呼吁公众……（新闻常用句）
- `en uppmaning` — 一项呼吁 / 敦促（名词）

## 例句 (Sentences)

- 🇸🇪 Jag uppmanar politikerna att ta frågan på allvar innan nästa budgetmöte. — 🇨🇳 我呼吁政治家们在下一次预算会议之前认真对待这个问题。 → [[sent-jag-uppmanar-politikerna-att-ta-frågan-på]]
- 🇸🇪 Polisen uppmanar allmänheten att vara försiktig. — 🇨🇳 警方呼吁公众保持谨慎。
- 🇸🇪 Läraren uppmanade eleverna att vara tysta. — 🇨🇳 老师督促学生保持安静。
- 🇸🇪 Vi uppmanar alla att spara el. — 🇨🇳 我们呼吁大家节约用电。
- 🇸🇪 Regeringen uppmanar till lugn. — 🇨🇳 政府呼吁保持冷静。

## 词族 / 同义 / 反义 (Relations)

- 词族: `uppmaning`（名词：呼吁）、`mana`（鼓动，古旧）
- 同义词: `be`（请求，更口语）、`kräva`（要求，更强）
- 反义词: `avråda`（劝阻）
- 主题: [[topic-argumentation]]

## 用法提示 (Usage Notes)

- 结构：`uppmana + 宾语（人）+ att + 动词原形`，**att 后没有主语**，见 [[grammar-infinitivkonstruktion]]：`Jag uppmanar politikerna att ta frågan …`。
- 语气：比 `be` 正式、比 `kräva` 温和——典型的**论说文收尾 / 呼吁段**动词，见 [[grammar-insandare-styckelogik]]（第 4 段"结论：呼吁"）。
