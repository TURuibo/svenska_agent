# begå — verb (oregelbundet, som gå)

📖 中文：犯（罪/错误） · English: to commit (a crime/mistake)
发音提示：/beˈɡoː/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | begå |
| Presens | begår |
| Preteritum | begick |
| Supinum | begått |
| Imperativ | begå |
| S-passiv | begås |
| S-passiv pret. | begicks |

## 词组搭配 (Collocations)

- `begå brott` — 犯罪
- `begå ett misstag` — 犯错

## 例句 (Sentences)

- 🇸🇪 Om hon skulle begå nya brott inom två år kan straffet bli fängelse. — 🇨🇳 如果她两年内再犯罪，刑罚可能变成监禁。
- 🇸🇪 Han begick ett stort misstag. — 🇨🇳 他犯了一个大错误。
- 🇸🇪 Många brott begås på natten. — 🇨🇳 许多罪行发生在夜里。
