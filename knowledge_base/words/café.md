# café — substantiv (ett)

📖 中文：咖啡馆 · English: café; coffee shop
发音提示：/kaˈfeː/；法语借词。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Singular obestämd | ett café |
| Singular bestämd | caféet |
| Plural obestämd | caféer |
| Plural bestämd | caféerna |

## 词组搭配 (Collocations)

- `på ett café` — 在一家咖啡馆
- `stanna till på ett café` — 顺路在咖啡馆停一下
- `kaffe att ta med från caféet` — 从咖啡馆买外带咖啡

## 例句 (Sentences)

- 🇸🇪 Sara stannar till på ett café för att köpa kaffe. — 🇨🇳 萨拉顺路在咖啡馆停下买咖啡。
- 🇸🇪 Det finns ett mysigt café på hörnet. — 🇨🇳 街角有一家很舒适的咖啡馆。
- 🇸🇪 Vi fikar på caféet varje fredag. — 🇨🇳 我们每周五在咖啡馆喝咖啡。
