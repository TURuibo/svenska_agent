# larma — verb (grupp 1)

📖 中文：报警；发出警报 · English: to alert, alarm
发音提示：[ˈlarːma]

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| infinitiv | larma |
| presens | larmar |
| preteritum | larmade |
| supinum | larmat |
| imperativ | larma! |

## 词组搭配 (Collocations)

- `larma polisen` — 报警
- `larma om något` — 就某事发出警报
- `larma 112` — 拨打112报警

## 例句 (Sentences)

- 🇸🇪 Grannarna larmade polisen om branden. — 🇨🇳 邻居们就火灾向警方报警。
- 🇸🇪 Personer hade larmat socialtjänsten flera gånger. — 🇨🇳 曾有人多次向社会服务部门报警。
- 🇸🇪 Larma alltid 112 om det brinner. — 🇨🇳 如果发生火灾，一定要拨打112报警。

## 用法提示 (Usage Notes)

- `larma om + ngt` = 就某事报警/发出警报；`larma till + person/myndighet` 也常见。
- 名词 `larm` = 警报器/报警（本身），常见搭配 `slå larm`（拉响警报/敲响警钟）。
