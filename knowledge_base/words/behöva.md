# behöva — verb (grupp 2a)

📖 中文：需要 · English: to need
发音提示：/beˈhøːva/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) behöva |
| Presens | behöver |
| Preteritum | behövde |
| Supinum | behövt |
| Imperativ | behöv! |

grupp 2a（-er/-de/-t；词干 behöv-）。

## 词组搭配 (Collocations)

- `behöva + 名词` — 需要某物
- `behöva + infinitiv`（不带 att）— 需要做某事
- `behöver inte` — 不必（= inte behöva）

## 例句 (Sentences)

- 🇸🇪 Jag behöver mer tid. — 🇨🇳 我需要更多时间。
- 🇸🇪 Du behöver inte komma i morgon. — 🇨🇳 你明天不必来。
- 🇸🇪 Barnen behövde hjälp med läxorna. — 🇨🇳 孩子们需要作业方面的帮助。

## 词族 / 同义 / 反义 (Relations)

- 词族: [[behov]]（ett，需求）

## 用法提示 (Usage Notes)

- `behöva` + 不定式时通常**不加 att**（口语）：Jag behöver sova。否定形式 `behöver inte` = “不必”，不是“不许”（不许 = får inte）。
