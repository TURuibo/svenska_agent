# behöva — verb (grupp 2)

📖 中文：需要 · English: to need

🇸🇪 Förklaring: inte klara sig utan något; vara tvungen att göra något

发音提示：/beˈhøːva/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) behöva |
| Presens | behöver |
| Preteritum | behövde |
| Supinum | behövt |
| Imperativ | behöv! |
| S-passiv (presens) | behövs |
| S-passiv (preteritum) | behövdes |

## 词组搭配 (Collocations)

- `behöva + inf.` — 需要做……（文中：behövde han träna mer）
- `behöva hjälp` — 需要帮助
- `behöver inte` — 不需要、不必（= don't have to）
- `Behöver du en kasse?` — 你需要购物袋吗？→ see [[behöver-du-en-kasse]]

## 例句 (Sentences)

- 🇸🇪 Om Nils skulle nå toppen behövde han träna mer. — 🇨🇳 要想登顶，Nils 需要练得更多。
- 🇸🇪 Jag behöver hjälp med läxan. — 🇨🇳 我做作业需要帮助。
- 🇸🇪 Du behöver inte komma i morgon. — 🇨🇳 你明天不必来。
- 🇸🇪 Barn behöver sova mycket. — 🇨🇳 孩子需要多睡觉。

## 用法提示 (Usage Notes)

- 第 2 组动词：behöva – behöver – **behövde** – **behövt**。s-passiv `behövs` = 「被需要」，如 `Det behövs mer tid.`（见 [[grammar-s-passiv]]）。
- 接不定式时通常**省略 att**：Jag behöver träna（也可写 behöver **att** träna）。
- `behöver inte` = 不必（没有义务）；禁止要用 `får inte`；`måste` = 必须 → [[måste]]。
