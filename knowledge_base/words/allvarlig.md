# allvarlig — adjektiv

📖 中文：严肃的/严重的 · English: serious, grave
发音提示：/alˈvaːrlɪɡ/ — "all-VAR-lig"

## 语法变形 (Forms)

| form | exempel |
|------|---------|
| obestämd singular (en-ord) | en **allvarlig** man |
| obestämd singular (ett-ord) | ett **allvarligt** problem |
| bestämd / plural | den **allvarliga** mannen · **allvarliga** människor |
| komparativ | **allvarligare** |
| superlativ (obestämd) | **allvarligast** |
| superlativ (bestämd) | den **allvarligaste** |

Se [[grammar-adjektiv-bojning]], [[grammar-adjektiv-kongruens]]

## 词组搭配 (Collocations)

- `en allvarlig situation` — 严重的情况
- `ta allvarligt` — 认真对待
- `allvarligt menad` — 认真的/严肃的（态度）
- `ett allvarligt sjuk` — 病重的

- *Ta något på allvar* = 认真对待某事 (partikelverb med substantivet "allvar").
