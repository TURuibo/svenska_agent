# para — verb (grupp 1)

📖 中文：配对；使成对；（动物）交配 · English: to pair; to match up; to mate

🇸🇪 Förklaring: sätta två saker som hör ihop tillsammans; om djur: få ungar

发音提示：/ˈpɑːra/ — pa 读长音 /ɑː/，重音在第一音节

| Form | Swedish |
|------|---------|
| Infinitiv | para |
| Presens | parar |
| Preteritum | parade |
| Supinum | parat |
| Imperativ | para |

## 词组搭配 (Collocations)

- `para ihop A med B` — 把 A 和 B 配对 → see [[para-ihop]]
- `para ihop rätt rubrik med rätt stycke` — 把标题配到段落
- `para sig` — （动物）交配

## 例句 (Sentences)

**义项1 配对:**
- 🇸🇪 Läs informationen från WWF och para ihop rätt rubrik vid rätt stycke. — 🇨🇳 阅读 WWF 的信息，把正确的标题配到正确的段落。
- 🇸🇪 Para ihop orden med rätt bild. — 🇨🇳 把单词和正确的图片配对。
- 🇸🇪 Läraren parade ihop eleverna två och två. — 🇨🇳 老师把学生两两配对。

**义项2 交配:**
- 🇸🇪 Fåglarna parar sig på våren. — 🇨🇳 鸟类在春天交配。
