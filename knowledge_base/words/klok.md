# klok — adjektiv

📖 中文：明智的；有智慧的 · English: wise; sensible; clever
发音提示：/kluːk/

## 语法变形 (Forms)

| form | exempel |
|------|---------|
| en-form (grundform) | klok |
| ett-form | klokt |
| plural / bestämd | kloka |
| komparativ | klokare |
| superlativ | klokast |

## 词组搭配 (Collocations)

- `ett klokt beslut` — 一个明智的决定
- `vara klok nog att` — 足够明智去……
- `bli klok på` — 搞懂（口语）

## 例句 (Sentences)

- 🇸🇪 Det var ett klokt beslut att spara pengar. — 🇨🇳 存钱是个明智的决定。
- 🇸🇪 Hon är klok och löser problem snabbt. — 🇨🇳 她很聪明，能快速解决问题。
- 🇸🇪 Jag kan inte bli klok på det här. — 🇨🇳 我搞不懂这个。

## 词族 / 同义 / 反义 (Relations)

- 词族: klokhet (智慧, substantiv)
- 同义词: [[duktig]] (能干的), intelligent
- 反义词: [[dum]]
- 主题: [[topic-karaktarsord]]

## 用法提示 (Usage Notes)

- `klok` 偏向"有判断力、有智慧"；`intelligent` 偏向智商高。
- `bli klok på ngt` 是口语表达，意为"搞懂某事"。
