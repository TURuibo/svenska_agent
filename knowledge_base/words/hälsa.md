# hälsa — verb

📖 中文：打招呼；问候；代某人致意 · English: to greet; to say hello; to send regards
发音提示：重音在第一音节：**HÄL-sa**。注意和名词 `hälsa`（健康）同形，但这里是动词。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | att hälsa |
| Imperativ | hälsa! |
| Presens | hälsar |
| Preteritum | hälsade |
| Supinum | (har) hälsat |

规则的 grupp 1 动词（-ar/-ade/-at）。

## 词组搭配 (Collocations)

- `hälsa på ngn` — 拜访某人；去看望某人
- `hälsa ngn välkommen` — 欢迎某人
- `hälsa från ngn` — 代某人问好
- `hälsa på publiken` — 向观众致意

## 例句 (Sentences)

- 🇸🇪 Hon **hälsade** vänligt på grannarna.
  🇨🇳 她友好地和邻居们打了招呼。
- 🇸🇪 Kan du **hälsa** från mig?
  🇨🇳 你能代我问好吗？
- 🇸🇪 Vi ska **hälsa på** mormor i helgen.
  🇨🇳 这个周末我们要去看望外婆。

## 用法提示 (Usage Notes)

- `hälsade` 是 `hälsa` 的过去时，表示“打了招呼 / 问候了”。
- `hälsa på` 很常用，意思常常不是“打招呼一下”，而是“拜访、探望”。
- `hälsa` 也可作名词，表示“健康”；查词时要靠上下文区分词性。
