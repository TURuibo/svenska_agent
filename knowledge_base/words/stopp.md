# stopp — substantiv

📖 中文：停止 · English: stop

🇸🇪 Förklaring: det att något stannar eller inte får fortsätta; tillfälligt hinder

发音提示：/stɔpː/ — o 短读 ɔ；p 读长

## 语法变形 (Forms)

| 形式 | 词形 |
|------|------|
| obestämd singular | ett stopp |
| bestämd singular | stoppet |
| plural | (sällan använt) |

## 词组搭配 (Collocations)

- `sätta stopp för` — 叫停，终止 → see [[sätta-stopp-för]]

## 例句 (Sentences)

- 🇸🇪 Kriget satte stopp för kampen för rösträtt. — 🇨🇳 战争让争取选举权的斗争中断了。
- 🇸🇪 Bussen gjorde ett kort stopp vid stationen. — 🇨🇳 公交车在车站短暂停靠。
- 🇸🇪 Läkaren sa stopp för allt hårt arbete. — 🇨🇳 医生叫停了所有繁重的工作。
