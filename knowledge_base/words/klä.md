# klä — verb (grupp 3)

📖 中文：给…穿衣；klä sig = 自己穿衣 · English: to dress
发音提示：klä [klɛː]；长 ä，单音节。

## 语法变形 (Forms)

| Tempus | Swedish |
|--------|---------|
| Infinitiv | (att) klä |
| Presens | **klär** |
| Preteritum | klädde |
| Supinum | klätt |
| Imperativ | klä! |

> grupp 3 动词（词干以重读元音结尾）：preteritum 加 `-dde`，supinum 加 `-tt`。
> 你输入的 `klär` 是 **presens**。

## 词组搭配 (Collocations)

- `klä sig` — 穿衣打扮（反身）
- `klä på sig` — 把衣服穿上（partikelverb）
- `klä av sig` — 脱衣服
- `klä om sig` — 换衣服
- `klä ut sig (till …)` — 装扮成…（化装）

## 例句 (Sentences)

- 🇸🇪 Hon klär sig alltid snyggt. — 🇨🇳 她总是穿得很得体。
- 🇸🇪 Jag klär på mig och går ut. — 🇨🇳 我穿上衣服就出门。
- 🇸🇪 Den röda klänningen klär dig. — 🇨🇳 这条红裙子很衬你 / 很适合你。

## 用法提示 (Usage Notes)

- ⚠️ `klä sig`（自己穿）vs `klä någon`（给别人穿）；反身代词随主语变。
- 特殊义：`X klär dig` = X **衬你/适合你**（说穿戴好看），很常用、很地道。
