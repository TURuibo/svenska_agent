# nödfall — substantiv (ett)

📖 中文：紧急情况 · English: emergency
发音提示：/ˈnøːdˌfalː/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Grundform (obestämd singular) | ett nödfall |
| Bestämd singular | nödfallet |
| Obestämd plural | nödfall |
| Bestämd plural | nödfallen |

⚠️ Nollplural: ett nödfall → nödfall (plural = grundform).

## 词组搭配 (Collocations)

- `om det inte är ett nödfall` — 除非是紧急情况

## 例句 (Sentences)

- 🇸🇪 De tar inte spontant kontakt om det inte är ett nödfall. — 🇨🇳 他们通常不会主动联系，除非是紧急情况。
- 🇸🇪 Ring bara vid nödfall. — 🇨🇳 只有紧急情况才打电话。
- 🇸🇪 Det var ett nödfall och alla var tvungna att agera snabbt. — 🇨🇳 那是紧急情况，大家都必须迅速行动。
