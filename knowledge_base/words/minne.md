# minne — substantiv en/ett: ett

📖 中文：记忆；回忆 · English: memory

🇸🇪 Förklaring: förmågan att komma ihåg saker; något som man kommer ihåg från förr

发音提示：/ˈmɪnːɛ/ — i 短；nn 读长辅音

## 语法变形 (Forms)

| 形式 | 单数 | 复数 |
|---|---|---|
| 不定 | ett minne | minnen |
| 定 | minnet | minnena |

## 词组搭配 (Collocations)

- `ett starkt minne` — 深刻的记忆
- `ha dåligt minne` — 记性差
- `till minne av` — 纪念

## 例句 (Sentences)

- 🇸🇪 Mitt starkaste minne från den tiden är hemtelefonen. — 🇨🇳 那个年代我最深的记忆是家里的座机。
- 🇸🇪 Hon har ett gott minne för namn. — 🇨🇳 她很会记名字。
- 🇸🇪 Det är ett fint minne från sommaren. — 🇨🇳 这是夏天的美好回忆。
