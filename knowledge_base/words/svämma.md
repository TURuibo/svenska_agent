# svämma — verb (grupp 1)

📖 中文：泛滥；涌出 · English: to flood; to overflow
发音提示：/ˈsvɛmːa/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) svämma |
| Presens | svämmar |
| Preteritum | svämmade |
| Supinum | svämmat |
| Imperativ | svämma! |

## 词组搭配 (Collocations)

- `svämma över` — 泛滥、漫出 → see [[svämma-över]]

## 例句 (Sentences)

- 🇸🇪 Enorma monsunregn och vatten från glaciärerna gjorde att en tredjedel av landet svämmade över. — 🇨🇳 巨大的季风降雨和冰川融水使三分之一的国土被淹。
- 🇸🇪 Floden svämmade över. — 🇨🇳 河水泛滥了。
- 🇸🇪 Badkaret svämmar över! — 🇨🇳 浴缸要溢出来了！
