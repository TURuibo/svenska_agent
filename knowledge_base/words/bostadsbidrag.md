# bostadsbidrag — substantiv (ett)

📖 中文：住房津贴 · English: housing allowance

🇸🇪 Förklaring: pengar som familjer eller unga med låg inkomst kan få för att betala hyran

发音提示：[ˈbʊstɑːdsˌbiːdrɑːɡ]

## 语法变形 (Forms)

| | 单数 | 复数 |
|---|---|---|
| 不定 | ett bostadsbidrag | bostadsbidrag |
| 定 | bostadsbidraget | bostadsbidragen |

## 词组搭配 (Collocations)

- `söka bostadsbidrag` — 申请住房津贴
- `få bostadsbidrag` — 领取住房津贴

## 例句 (Sentences)

- 🇸🇪 Hon får bostadsbidrag för hyran. — 🇨🇳 她为房租领取住房津贴。
- 🇸🇪 Du kan söka bostadsbidrag hos Försäkringskassan. — 🇨🇳 你可以向社会保险局申请住房津贴。
- 🇸🇪 Med bostadsbidrag blir hyran lättare att betala. — 🇨🇳 有了住房津贴，房租更容易负担。
