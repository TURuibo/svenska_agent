# ört — substantiv (en)

📖 中文：香草；草本植物 · English: herb

🇸🇪 Förklaring: mjuk växt med gröna blad som man använder som krydda eller medicin

发音提示：/œʈ/ — rt 合成卷舌音 /ʈ/；ö 读 /œ/

## 语法变形 (Forms)

| Form | Swedish |

| obestämd sg | ört |
| bestämd sg | örten |
| obestämd pl | örter |
| bestämd pl | örterna |

## 词组搭配 (Collocations)

- `färska örter` — 新鲜香草
- `ört-/salladskrukor` — 香草/生菜盆
- `örtte` — 草本茶

## 例句 (Sentences)

- 🇸🇪 Ört-/salladskrukor ska inte i matavfallet. — 🇨🇳 香草/生菜盆不能放进厨余垃圾。
- 🇸🇪 Jag odlar örter på balkongen. — 🇨🇳 我在阳台上种香草。
- 🇸🇪 Färska örter gör maten godare. — 🇨🇳 新鲜香草让食物更好吃。
