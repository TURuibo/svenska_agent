# bidrag — substantiv (ett)

📖 中文：补贴、补助 · English: grant / subsidy
发音提示：BI-drag，重音第一音节。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Singular obestämd | ett bidrag |
| Singular bestämd | bidraget |
| Plural obestämd | bidrag |
| Plural bestämd | bidragen |

## 词组搭配 (Collocations)

- `söka bidrag` — 申请补贴
- `barnbidrag` — 儿童津贴（复合词）
- `bostadsbidrag` — 住房补贴（复合词）
- `lämna ett bidrag` — 做出贡献（也有"贡献"之义）

## 例句 (Sentences)

- 🇸🇪 Familjen får **bidrag** från kommunen för att betala hyran.
  🇨🇳 这家人从市政府得到补贴来支付房租。
- 🇸🇪 Studiemedlets **bidrag**sdel behöver inte betalas tillbaka.
  🇨🇳 助学金中的补贴部分不需要偿还。
- 🇸🇪 Han söker **barnbidrag** för sina tre barn.
  🇨🇳 他为三个孩子申请儿童津贴。

## 词族 / 同义 / 反义 (Relations)

- 词族: [[bidra]] (v. 贡献/提供), [[bidragsgivare]] (en, 资助者)
- 同义词: [[stöd]] (ett, 支持/补助), [[subvention]] (en, 补贴，较正式)
- 反义词: [[lån]] (ett, 贷款，需偿还)
- 主题: [[topic-nyheter-vecka22]], [[topic-skola-och-utbildning]]

## 用法提示 (Usage Notes)

- `bidrag` 既指政府补贴（福利），也可指"贡献"（*ge ett bidrag till diskussionen* = 对讨论做贡献）。
- 在 [[studiemedel]] 语境中，*bidrag* 是不需偿还的部分，与 [[lån]]（贷款，需偿还）对应。
