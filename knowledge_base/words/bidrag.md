# bidrag — substantiv (ett)

📖 中文：补贴、补助 · English: grant / subsidy
发音提示：BI-drag，重音第一音节。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Singular obestämd | ett bidrag |
| Singular bestämd | bidraget |
| Plural obestämd | bidrag |
| Plural bestämd | bidragen |

## 词组搭配 (Collocations)

- `söka bidrag` — 申请补贴
- `barnbidrag` — 儿童津贴（复合词）
- `bostadsbidrag` — 住房补贴（复合词）
- `lämna ett bidrag` — 做出贡献（也有"贡献"之义）

## 用法提示 (Usage Notes)

- `bidrag` 既指政府补贴（福利），也可指"贡献"（*ge ett bidrag till diskussionen* = 对讨论做贡献）。
- 在 [[studiemedel]] 语境中，*bidrag* 是不需偿还的部分，与 [[lån]]（贷款，需偿还）对应。
