# få — verb (oregelbundet)

📖 中文：得到；被允许；让(某人做) · English: to get; be allowed to; make (sb do)

🇸🇪 Förklaring: 1) ta emot något som någon ger en; 2) ha lov att göra något; 3) lyckas göra så att någon gör något

发音提示：/foː/；fick /fɪk/；fått /fɔt/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) få |
| Presens | får |
| Preteritum | fick |
| Supinum | fått |
| Imperativ | få! |

## 词组搭配 (Collocations)

- `få barn` — 生孩子 / `fick barn inte satsa` 中则是「被允许」
- `få lära sig` — 有机会学到（文中）
- `få någon att + inf.` — 使某人（做某事）（文中：få honom att lägga av）
- `få framtiden utvisa` — 交给未来去揭晓 → see [[få-framtiden-utvisa]]
- `kan jag få …?` — 我可以要……吗？→ see [[kan-jag-få]]
- `få ont i huvudet` — 头疼起来 → see [[få-ont-i-huvudet]]
- `få ihop` — 凑齐、拼在一起 → see [[få-ihop]]

## 例句 (Sentences)

**义项1 被允许 (får/fick + inf.):**
- 🇸🇪 Inom många andra idrotter fick barn inte satsa seriöst. — 🇨🇳 在很多别的运动里，孩子是不被允许认真拼的。
- 🇸🇪 Får jag sitta här? — 🇨🇳 我可以坐这儿吗？

**义项2 有机会 / 能够 (få + inf.):**
- 🇸🇪 Han menar att det är bra att få lära sig att både vinna och förlora. — 🇨🇳 他认为学会赢也学会输是好事。

**义项3 让(某人做) / 导致 (få någon att …):**
- 🇸🇪 Det hade kunnat få honom att lägga av. — 🇨🇳 这本可能让他放弃。

**义项4 得到、收到:**
- 🇸🇪 Jag fick en present av min syster. — 🇨🇳 我从姐姐那里收到一份礼物。
- 🇸🇪 Hon fick en liten flicka i maj. — 🇨🇳 她五月生了一个小女孩。

**义项5 将不得不 / 由……来(固定表达):**
- 🇸🇪 Vad det blir får framtiden utvisa. — 🇨🇳 那会是什么，就交给未来去揭晓。

## 用法提示 (Usage Notes)

- 不规则动词：få – får – **fick** – **fått**。
- `få` 一词多义：①得到（+名词）；②被允许（+动词原形，见 [[grammar-modal-fa-permission]]、[[grammar-modala-hjalpverb]]）；③`få … att + inf.` = 使……做；④`får/fick` 在固定表达里表示「由……去」（få framtiden utvisa）。
- `inte få` = 不被允许；`inte behöva` = 不必。注意区别：Du får inte gå（禁止） vs Du behöver inte gå（不必）。
