# skriva — verb (grupp 4, stark)

📖 中文：写 · English: to write
发音提示：/ˈskriːva/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) skriva |
| Presens | skriver |
| Preteritum | skrev |
| Supinum | skrivit |
| Imperativ | skriv! |
| Perfekt particip | skriven |

## 词组搭配 (Collocations)

- `skriva ner` — 写下来
- `skriva på / under` — 签名 → see [[skriva-på]]、[[skriva-under]]
- `skriva in` → see [[skriva-in]]

## 例句 (Sentences)

- 🇸🇪 Många skrev kränkande och rasistiska kommentarer om henne på nätet. — 🇨🇳 许多人在网上写了侮辱性和种族主义的评论来攻击她。
- 🇸🇪 Hon skrev ner recepten på lappar. — 🇨🇳 她把食谱写在纸条上。
- 🇸🇪 Jag skriver ett brev till min mamma. — 🇨🇳 我在给妈妈写信。
