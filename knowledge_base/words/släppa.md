# släppa — verb (grupp 2)

📖 中文：放开；让……进入；排放 · English: to let go; to release
发音提示：/ˈslɛpa/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) släppa |
| Presens | släpper |
| Preteritum | släppte |
| Supinum | släppt |
| Imperativ | släpp! |

## 词组搭配 (Collocations)

- `släppa in` — 放进来、接纳
- `släppa ut` — 排放；放出 → see [[släppa-ut]]

## 例句 (Sentences)

- 🇸🇪 Jag tror också att svenskar har svårt för att släppa in nya människor. — 🇨🇳 我也认为瑞典人很难接纳新朋友。
- 🇸🇪 Problemet är att vi släpper ut för mycket koldioxid. — 🇨🇳 问题是我们排放了太多二氧化碳。
- 🇸🇪 Släpp inte handen! — 🇨🇳 别松手！
