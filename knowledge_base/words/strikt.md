# strikt — adjektiv

📖 中文：严格的 · English: strict
发音提示：/strɪkt/；单音节，结尾 `-kt` 清晰。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Utrum | strikt |
| Neutrum | strikt |
| Plural / bestämd | strikta |
| Komparativ | striktare |
| Superlativ | striktast |
| Superlativ bestämd | striktaste |

## 词组搭配 (Collocations)

- `en strikt diet` — 严格的饮食
- `strikta regler` — 严格的规则
- `ett strikt schema` — 严格的日程
- `strikt förbjuden` — 严禁（`strikt` 也可作副词）

## 例句 (Sentences)

- 🇸🇪 Till skillnad från många andra elitidrottare som följer en strikt diet använde han sötsaker som belöning. — 🇨🇳 与许多遵守严格饮食的精英运动员不同，他把甜食当作奖励。
- 🇸🇪 Vår lärare är väldigt strikt. — 🇨🇳 我们的老师非常严格。
- 🇸🇪 Det finns strikta regler på skolan. — 🇨🇳 学校里有严格的规定。
- 🇸🇪 Hon följer ett strikt schema varje dag. — 🇨🇳 她每天都遵守严格的日程。

## 词族 / 同义 / 反义 (Relations)

- 词族: striktare, striktast（比较级/最高级）
- 同义词: sträng（严厉的）
- 反义词: slapp（松散的）, mild（宽松的）

## 用法提示 (Usage Notes)

- 以 `-t` 结尾的外来形容词（`strikt, korrekt, perfekt, intressant`）**en-词和 ett-词形式相同**，不再加 -t：`en strikt diet`、`ett strikt schema`；复数/bestämd 加 `-a`：`strikta regler`。参见 [[grammar-adjektiv-bojning]]。
- 文中 `en strikt diet` 修饰 en-词，中性形式与基本形式一样，所以看不出差别。
