# steg — substantiv (ett)

📖 中文：步，脚步；阶段 · English: step, pace
发音提示：/steːg/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| singular obestämd | steg |
| singular bestämd | steget |
| plural obestämd | steg |
| plural bestämd | stegen |
| genitiv | stegets |

## 词组搭配 (Collocations)

- `backa några steg` — 后退几步
- `ta ett steg` — 迈一步
- `steg för steg` — 一步一步
- `i samma steg` — 同步
- `första steget` — 第一步

## 例句 (Sentences)

**义项1 步（脚步）:**

- 🇸🇪 Då blir personen obekväm och backar försiktigt några steg. — 🇨🇳 这时对方会不舒服，小心地后退几步。
- 🇸🇪 Det är bara tio steg till dörren. — 🇨🇳 到门口只有十步。

**义项2 步骤/阶段:**

- 🇸🇪 Det första steget är att öva varje dag. — 🇨🇳 第一步是每天练习。
- 🇸🇪 Vi gör det steg för steg. — 🇨🇳 我们一步一步地做。

## 用法提示 (Usage Notes)

- ⚠️ **同形异义**：`steg` 也是动词 **stiga**（上升/迈步）的**过去式 (preteritum)**：`Priset steg` = 价格上涨了；`Han steg in` = 他走了进来。名词前常有 ett/冠词/数词，动词前常有主语。
- ett-ord，复数与单数同形 `steg`。
