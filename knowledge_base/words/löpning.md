# löpning — substantiv (en)

📖 中文：跑步（作为运动 / 训练项目） · English: running

🇸🇪 Förklaring: det att springa, ofta som träning eller idrott

发音提示：/ˈløːpnɪŋ/（重音在第一音节，ö 长音）

## 词组搭配 (Collocations)

- `4 timmars löpning` — 四小时的跑步 → see [[timme]]
- `löpning i skogen` — 在森林里跑步
- `efter löpningen` — 跑完之后
- `löparskor` — 跑鞋
- `löprunda` — 一圈跑步 / 一次慢跑

## 例句 (Sentences)

- 🇸🇪 Ett vanligt träningspass var ofta 6–7 timmar på cykel eller 4 timmars löpning. — 🇨🇳 一次普通训练往往是骑车 6–7 小时，或者跑步 4 小时。
- 🇸🇪 Jag gillar löpning i skogen. — 🇨🇳 我喜欢在森林里跑步。
- 🇸🇪 Efter löpningen dricker jag mycket vatten. — 🇨🇳 跑完步后我喝很多水。
- 🇸🇪 Löpning är bra för hjärtat. — 🇨🇳 跑步对心脏有好处。

## 用法提示 (Usage Notes)

- **löpning vs springa**：日常说"跑"的动词是 **springa**（*Jag springer varje morgon*）；**löpning** 是名词，指"跑步这项运动 / 训练"，如运动安排、杂志、训练计划里。
- 文章中的结构 `4 timmars löpning`：**数字 + timmars（genitiv）+ 名词** = "4 小时的跑步"，作定语。
