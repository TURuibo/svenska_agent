# dygn — substantiv (ett)

📖 中文：一昼夜，24小时 · English: 24-hour period, day (24 hours)
发音提示：[dygn]，单音节

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Obestämd sg | ett dygn |
| Bestämd sg | dygnet |
| Obestämd pl | dygn |
| Bestämd pl | dygnen |

## 词组搭配 (Collocations)

- `hela dygnet` — 整整24小时，全天 → see [[hela-dygnet]]
- `dygnet runt` — 全天候，24小时不停 → see [[hela-dygnet-runt]]
- `under ett dygn` — 在24小时内
- `varannat dygn` — 每隔一天

## 例句 (Sentences)

- 🇸🇪 Det är mörkt hela dygnet. — 🇨🇳 整整24小时都是黑暗的。
- 🇸🇪 Då är det ljust nästan hela dygnet. — 🇨🇳 那时几乎整整24小时都是亮的。
- 🇸🇪 Sjukhuset är öppet dygnet runt. — 🇨🇳 医院全天候开放。

## 用法提示 (Usage Notes)

- `dygn` ≠ `dag`：dag = 白天/一天（口语），dygn 强调整个24小时周期（含夜晚）
- `hela dygnet` vs `dygnet runt`：意思相近，都表示"24小时不间断"，后者更强调连续性
- 注意复数与单数同形：ett dygn → dygn（pl）
