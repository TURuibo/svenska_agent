# böra — verb (hjälpverb, oregelbundet)

📖 中文：应该 · English: ought to, should

🇸🇪 Förklaring: används för att säga att något är rätt, klokt eller lämpligt att göra

发音提示：/ˈbøːra/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | böra |
| Presens | bör |
| Preteritum | borde |
| Supinum | bort |

## 词组搭配 (Collocations)

- `man bör` + 不定式 — 人们应该……
- `borde ha` + supinum — 本应该已经……

## 例句 (Sentences)

- 🇸🇪 Man bör dock tänka på att inte störa andra människor. — 🇨🇳 不过应当注意不要打扰别人。
- 🇸🇪 Lönen borde ha kommit in på kontot. — 🇨🇳 工资本该已经进账了。
- 🇸🇪 Jag tycker att vi unga också borde få rösta. — 🇨🇳 我觉得我们年轻人也应该能投票。
