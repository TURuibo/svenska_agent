# program — substantiv (ett)

📖 中文：节目；程序 · English: programme; program

🇸🇪 Förklaring: 1) det som sänds i radio eller tv; 2) instruktioner som får en dator att utföra något

发音提示：/prʊˈɡramː/ — 重音在第二音节 -gram

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Singular obestämd | program |
| Singular bestämd | programmet |
| Plural obestämd | program |
| Plural bestämd | programmen |

## 词组搭配 (Collocations)

- `ett tv-program` — 电视节目
- `ett matlagningsprogram` — 烹饪节目

## 例句 (Sentences)

**义项1 节目:**
- 🇸🇪 Dialogerna i de här programmen är lätta att förstå. — 🇨🇳 这些节目里的对话容易懂。
- 🇸🇪 Nu börjar debattprogrammet. — 🇨🇳 辩论节目开始了。

**义项2 程序（软件）:**
- 🇸🇪 Jag har installerat ett nytt program. — 🇨🇳 我装了一个新程序。
