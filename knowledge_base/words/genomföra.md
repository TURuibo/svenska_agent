# genomföra — verb (grupp 2)

📖 中文：实施；执行；完成 · English: to carry out; to implement; to conduct
发音提示：`g` 在 `e` 前读 /j/（"耶-nom-fö-ra"）。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | genomföra |
| Presens | genomför |
| Preteritum | genomförde |
| Supinum | genomfört |
| Imperativ | genomför |
| Perf. particip | genomförd / genomfört / genomförda |
| S-passiv | genomförs（`reglerna genomförs` 规则被实施） |

> 与 `föra`（föra – förde – fört）同一变位；前缀 `genom-` 不可分。

## 词组搭配 (Collocations)

- `genomföra en plan / ett beslut / en reform` — 实施计划 / 决定 / 改革
- `genomföra en undersökning / ett test / ett prov` — 进行调查 / 测试 / 考试
- `genomföra en resa / ett möte` — 完成一次旅行 / 开一次会
- `genomföra steg för steg` — 逐步实施 → [[steg-för-steg]]
- `ett genomförande` — 实施；执行（名词）

## 例句 (Sentences)

- 🇸🇪 Kommunen ska genomföra reglerna steg för steg. — 🇨🇳 市政府将逐步实施这些规则。 → [[sent-kommunen-ska-genomföra-reglerna-steg-för-steg]]
- 🇸🇪 Vi genomförde en undersökning i klassen. — 🇨🇳 我们在班里进行了一项调查。
- 🇸🇪 Planen är svår att genomföra utan mer pengar. — 🇨🇳 没有更多资金，这个计划很难实施。
- 🇸🇪 Skolan har genomfört flera prov i höst. — 🇨🇳 学校今年秋天已经进行了好几次考试。

## 词族 / 同义 / 反义 (Relations)

- 词族: [[genomförande]]（实施，名词）；词根 `föra`（带；引导）
- 同义词: [[utföra]]（执行，较中性）；近义 [[införa]]（引入、开始实行一项规则）
- 反义词: —
- 主题: [[topic-allmänna-verb]]

## 用法提示 (Usage Notes)

- 比 `göra` 正式、有"把计划落实 / 做完"的意味，常接**具体的、有计划的对象**：`genomföra ett beslut / en plan / en undersökning`。
- 区分：`införa` 是"引入、开始施行（新规则）"；`genomföra` 是"把已定的事一步步做完 / 落实"。
- 新闻、公文里高频：`Kommunen genomför …`、`Undersökningen genomfördes i maj.`（s-passiv）。
