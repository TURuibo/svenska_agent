# val — substantiv (ett)

📖 中文：选择；选项；投票（选举） · English: choice; election
发音提示：单音节，**val**，`a` 较长。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Singular obestämd | ett val |
| Singular bestämd | valet |
| Plural obestämd | val (同形) |
| Plural bestämd | valen |

## 词组搭配 (Collocations)

- `göra ett val` — 做出一个选择
- `önskade val` — 意愿选择；首选志愿
- `fria val` — 自由选择
- `allmänna val` — 大选；普选

## 例句 (Sentences)

- 🇸🇪 Det är fullt på alla dina önskade **val**.
  🇨🇳 你所有的意愿名额均已满员。

- 🇸🇪 Det var ett svårt **val** — både alternativen var bra.
  🇨🇳 这是一个艰难的选择——两个选项都很好。
- 🇸🇪 I Sverige hålls **val** vart fjärde år.
  🇨🇳 在瑞典，每四年举行一次选举。

## 用法提示 (Usage Notes)

- `val` 有两个主要含义：(1) 选择/选项（如"önskade val"= 意愿志愿）；(2) 选举/投票（如"allmänna val"= 大选）。
- 注意 `val` 在单复数同形，需靠语境区分。
- 词族动词 `välja`（选择）是不规则动词：väljer / valde / valt。
