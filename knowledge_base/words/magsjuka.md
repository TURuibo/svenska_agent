# magsjuka — substantiv (en)

📖 中文：肠胃炎（呕吐/腹泻） · English: stomach bug; gastroenteritis
发音提示：[ˈmɑːgˌɧʉːka]，mag- 长 a；sj = [ɧ]。

不可数疾病名，几乎不用复数。

## 词组搭配 (Collocations)

- `vid magsjuka` — 得肠胃炎时（规定用语）
- `magsjukan går runt` — 肠胃炎在流行 → see [[gå-runt]]
- `ha magsjuka` — 得了肠胃炎
- `hjälper inte mot magsjuka` — 对肠胃炎不管用 → see [[hjälpa]]

## 例句 (Sentences)

- 🇸🇪 Vid magsjuka gäller 48-timmarsregeln. — 🇨🇳 得肠胃炎时适用 48 小时规则。
- 🇸🇪 Magsjukan går runt på avdelningen just nu. — 🇨🇳 现在肠胃炎正在班上传。
- 🇸🇪 Handsprit hjälper inte mot magsjuka. — 🇨🇳 免洗洗手液对肠胃炎不管用。
