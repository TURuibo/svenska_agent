# tvinga — verb (grupp 1)

📖 中文：迫使；强迫 · English: to force; to compel
发音提示：[ˈtvɪŋa] — "TVING-a"

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| infinitiv | tvinga |
| presens | tvingar |
| preteritum | tvingade |
| supinum | tvingat |
| imperativ | tvinga! |
| s-passiv presens | tvingas |
| s-passiv preteritum | tvingades |

## 词组搭配 (Collocations)

- `tvingas (att) göra något` — 被迫做某事（-s 被动形式）
- `tvinga någon att` — 强迫某人…
- `tvinga fram` — 强行推进；逼出

## 例句 (Sentences)

- 🇸🇪 Jag tvingas kasta bort mat varje dag. — 🇨🇳 我每天不得不扔掉食物。（被迫）
- 🇸🇪 De tvingade honom att lämna landet. — 🇨🇳 他们强迫他离开了这个国家。
- 🇸🇪 Han tvingades sälja sin lägenhet. — 🇨🇳 他被迫卖掉了自己的公寓。

## 用法提示 (Usage Notes)

- `tvingas` 是 `tvinga` 的 -s 被动形式（reciprok/passiv）：`jag tvingas göra X` = 我被迫/不得不做 X。
- 与 `måste` 的语气区别：`måste` = 必须（中性）；`tvingas` = 被迫（强调外力迫不得已，语气更强）。
