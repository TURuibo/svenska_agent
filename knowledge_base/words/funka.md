# funka — verb (grupp 1)

📖 中文：行得通；好使（口语） · English: to work (informal, = fungera)
发音提示：["fʊŋka]

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| infinitiv | funka |
| presens | funkar |
| preteritum | funkade |
| supinum | funkat |
| imperativ | funka! |

## 词组搭配 (Collocations)

- `det funkar` — 可以/没问题
- `funkar det för dig?` — 你可以吗？/对你行吗？
- `funkar inte` — 不好使/不行

## 例句 (Sentences)

- 🇸🇪 Annars funkar söndag också för mig. — 🇨🇳 不然周日对我也行。
- 🇸🇪 Det funkar! Vi ses på söndag. — 🇨🇳 行！我们周日见。
- 🇸🇪 Den här appen funkar inte på min telefon. — 🇨🇳 这个应用在我手机上用不了。
