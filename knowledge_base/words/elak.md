# elak — adjektiv

📖 中文：刻薄的；恶意的；坏心眼的 · English: mean, nasty

🇸🇪 Förklaring: som är dum och vill göra andra illa

发音提示：/ˈeːlɑːk/ — 两个长音 eː 和 ɑː，重音在第一音节

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| utrum | elak |
| neutrum | elakt |
| plural | elaka |
| komparativ | elakare |
| superlativ | elakast |

## 词组搭配 (Collocations)

- `elak mot någon` — 对某人刻薄
- `elak kommentar` — 刻薄的评论

## 例句 (Sentences)

- 🇸🇪 Han var elak mot barnen. — 🇨🇳 他对孩子们很刻薄。
- 🇸🇪 Var inte så elak! — 🇨🇳 别这么刻薄！
- 🇸🇪 Det var ett elakt skämt. — 🇨🇳 那是个恶意的玩笑。
