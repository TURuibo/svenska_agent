# bosätta sig — verb (grupp 4, reflexivt)

📖 中文：定居 · English: to settle down
发音提示：/ˈbuːˌsɛtːa/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) bosätta sig |
| Presens | bosätter sig |
| Preteritum | bosatte sig |
| Supinum | bosatt sig |

## 词组搭配 (Collocations)

- `bosätta sig i Trollhättan` — 定居在 Trollhättan

## 例句 (Sentences)

- 🇸🇪 Farfar emigrerade och bosatte sig i Trollhättan på 50-talet. — 🇨🇳 祖父在五十年代移民并定居在 Trollhättan。
- 🇸🇪 De valde att bosätta sig nära havet. — 🇨🇳 他们选择在靠近海边的地方定居。
- 🇸🇪 Familjen bosatte sig i Sverige för många år sedan. — 🇨🇳 这家人很多年前就在瑞典定居了。
