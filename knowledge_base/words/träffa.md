# träffa — verb (grupp 1)

📖 中文：见面；遇见；遇到 · English: to meet; to see (someone); to run into
发音提示：['trɛfa]

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| infinitiv | träffa |
| presens | träffar |
| preteritum | träffade |
| supinum | träffat |
| imperativ | träffa! |

Reflexiv form: `träffas` (互相见面，双向)

## 词组搭配 (Collocations)

- `träffa en vän` — 见一个朋友
- `träffas på helgen` — 在周末见面
- `träffa någon på riktigt` — 真正地见某人（面对面）
- `råka träffa` — 碰巧遇见

## 例句 (Sentences)

- 🇸🇪 Vi träffas ibland på helgen. — 🇨🇳 我们有时在周末见面。
- 🇸🇪 Det är inte samma sak som att träffas på riktigt. — 🇨🇳 这和真正面对面见面是不一样的。
- 🇸🇪 Jag träffar min syster varje vecka. — 🇨🇳 我每周见我的妹妹。
- 🇸🇪 Var kan vi träffas idag? — 🇨🇳 我们今天可以在哪里见面？

## 用法提示 (Usage Notes)

- `träffa` (träffar) = 遇见/见到某人（单向）
- `träffas` (träffas) = 互相见面（双向，reflexiv form）
- 常见搭配：`träffa en kompis`, `träffa familjen`, `träffas på kaffe`
