# schema — substantiv (ett)

📖 中文：时间表；（每周）在园时间表 · English: schedule, timetable

🇸🇪 Förklaring: plan som visar vilka tider något ska ske, till exempel lektioner eller ett barns tider på förskolan

发音提示：SKE-ma（sch 读 /ɧ/，类似"呼"的气音）

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| obestämd singular | ett schema |
| bestämd singular | schemat |
| obestämd plural | scheman |
| bestämd plural | schemana |

## 词组搭配 (Collocations)

- `ändra schemat` — 修改时间表
- `enligt schemat` — 按照时间表
- `lägga in ett schema` — 录入时间表
- `barnets schema på förskolan` — 孩子在幼儿园的在园时间表

## 例句 (Sentences)

- 🇸🇪 Då måste du ändra schemat i e-tjänsten. — 🇨🇳 那你得在电子服务里改在园时间表。
- 🇸🇪 Ella ska hämtas halv fem enligt schemat. — 🇨🇳 按时间表，Ella 四点半被接走。
- 🇸🇪 Jag har ett nytt schema på jobbet. — 🇨🇳 我工作上有了新的时间表。

## 用法提示 (Usage Notes)

- ett-词，复数 scheman（外来词，类似 tema → teman）。
- 在 förskola 语境专指家长每周登记的孩子在园时间（vistelsetid），改动要在 e-tjänst/app 里做，通常需提前两周。
- "时间表"义近 tidtabell（公交时刻表），但 schema 用于课程表/工作排班/在园时间。
