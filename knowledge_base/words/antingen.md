# antingen — adverb/konjunktion

📖 中文：要么 · English: either

🇸🇪 Förklaring: ord som visar att man kan välja mellan två saker; används med eller

发音提示：/ˈantɪŋɛn/ — 重音在 an-；ng 读 /ŋ/；末音节 -en 弱读

## 语法变形 (Forms)

不变词 (oböjligt)；固定搭配 *antingen … eller*

## 词组搭配 (Collocations)

- `antingen … eller` — 要么……要么 → see [[antingen-eller]]

## 例句 (Sentences)

- 🇸🇪 Vi kan antingen gå eller ta bussen. — 🇨🇳 我们可以要么走路，要么坐公交。
- 🇸🇪 Antingen kommer han i dag eller i morgon. — 🇨🇳 他要么今天来，要么明天来。
- 🇸🇪 Du kan antingen betala nu eller senare. — 🇨🇳 你可以现在付，也可以以后付。
