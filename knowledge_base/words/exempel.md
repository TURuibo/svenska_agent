# exempel — substantiv (ett)

📖 中文：例子；榜样 · English: example
发音提示：/ɛkˈsɛmpɛl/（重音在第二音节 -sem-）

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Singular obestämd | exempel |
| Singular bestämd | exemplet |
| Plural obestämd | exempel |
| Plural bestämd | exemplen |

（ett-词，以 -el 结尾，复数同形：*ett exempel, två exempel*。）

## 词组搭配 (Collocations)

- `till exempel` (`t.ex.`) — 例如
- `ge ett exempel` — 举个例子
- `ta ett exempel` — 举个例子
- `ett bra exempel` — 一个好例子
- `följa någons exempel` — 以某人为榜样
- `vara ett exempel på` — 是……的例子

## 例句 (Sentences)

**义项1 例子:**
- 🇸🇪 Han kunde till exempel springa 3 timmar för att köpa godis eller cykla flera mil för en pizza. — 🇨🇳 比如他会跑三个小时去买糖，或者骑几十公里去吃一个披萨。
- 🇸🇪 Kan du ge ett exempel? — 🇨🇳 你能举个例子吗？
- 🇸🇪 Frukt, till exempel äpplen och bananer, är nyttigt. — 🇨🇳 水果，例如苹果和香蕉，是有益健康的。

**义项2 榜样:**
- 🇸🇪 Hon är ett bra exempel för alla barn. — 🇨🇳 她是所有孩子的好榜样。

## 用法提示 (Usage Notes)

- 文章中的 `till exempel`（缩写 *t.ex.*）是最高频的举例表达，用来引出具体例子（Nils 用糖果当奖励的两个例子）。
- 注意 **exempel 是 ett-词**（ett exempel），常有人误用 en。
- 书面中缩写 *t.ex.*、*dvs.*（即）、*bl.a.*（其中包括）要认得。
