# rädda — verb (grupp 1)

📖 中文：拯救；营救 · English: to save; to rescue
发音提示：["rEd-da"] — 短促清晰的 -dd-

## 语法变形 (Forms)

| 形式 | 变形 |
|------|------|
| infinitiv | rädda |
| presens | räddar |
| preteritum | räddade |
| supinum | räddat |
| imperativ | rädda! |

## 词组搭配 (Collocations)

- `rädda liv` — 拯救生命
- `rädda någon` — 救某人
- `räddningsarbetare` — 救援人员（词族）
- `försöker rädda` — 试图拯救

## 例句 (Sentences)

- 🇸🇪 Räddningsarbetarna försöker rädda människor under rasmassorna. — 🇨🇳 救援人员正试图从废墟中救出人们。
- 🇸🇪 Läkaren räddade barnets liv. — 🇨🇳 医生救了这个孩子的命。
- 🇸🇪 Brandmännen räddade alla ur huset. — 🇨🇳 消防员把所有人从房子里救了出来。
