# hus — substantiv (ett-ord)

📖 中文：房子；楼房；建筑 · English: house, building
发音提示：/hɵːs/

## 语法变形 (Forms)

| | Singular | Plural |
|---|---|---|
| **Obestämd** | ett hus | hus |
| **Bestämd** | huset | husen |

注意：ett-ord，zero-plural（plural obestämd 与 singular 同形）。

## 词组搭配 (Collocations)

- `högt hus` — 高楼 → see [[hög]]
- `tomt hus` — 空房子 → see [[tom]]
- `gammalt hus` — 老房子 → see [[gammal]]

## 例句 (Sentences)

- 🇸🇪 De bor i ett litet rött hus på landet. — 🇨🇳 他们住在乡下一座小红房子里。
- 🇸🇪 Huset har tre rum och ett kök. — 🇨🇳 这座房子有三个房间和一个厨房。
- 🇸🇪 Det gamla huset vid sjön är mycket vackert. — 🇨🇳 湖边那座老房子非常漂亮。

## 词族 / 同义 / 反义 (Relations)

- 词族: husägare (房主), hyreshus (公寓楼), radhus (联排别墅)
- 同义词: [[byggnad]]
- 反义词: —
- 主题: [[topic-stadsmiljo]]

## 用法提示 (Usage Notes)

- `hus` 侧重居住用途；`byggnad` 更泛指任何建筑物（含商业/公共建筑）。
