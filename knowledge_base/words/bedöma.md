# bedöma — verb (grupp 2)

📖 中文：评估；判断；评定 · English: to assess; to judge; to evaluate
发音提示：be-DÖ-ma，重音在第二音节 `dö`（`ö` 读 [øː]）。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | bedöma |
| Presens | bedömer |
| Preteritum | bedömde |
| Supinum | bedömt |
| Imperativ | bedöm |
| Perf. particip | bedömd / bedömt / bedömda |
| S-passiv | bedöms |

## 词组搭配 (Collocations)

- `bedöma om …` — 评估是否……（后接 om-从句）
- `bedöma hur allvarligt …` — 判断……有多严重
- `bedöma ett prov / en uppsats` — 给考试 / 作文评分
- `en bedömning` — 评估（名词）
- `enligt min bedömning` — 据我判断
- `bedömas vara …` — 被认为是……（s-passiv）

## 例句 (Sentences)

**义项 1 — 评估、判断（机构评估情况）:**

- 🇸🇪 Socialtjänsten bedömer om kostnaderna är rimliga. — 🇨🇳 社会服务处会评估这些费用是否合理。 → [[sent-socialtjänsten-bedömer-om-kostnaderna-är-rimliga]]
- 🇸🇪 Socialtjänsten bedömer om stödet behövs för att du ska kunna leva på en rimlig nivå. — 🇨🇳 社会服务处会评估是否需要这笔补助，好让你能过上合理水平的生活。 → [[sent-socialtjänsten-bedömer-om-stödet-behövs-för-att]]
- 🇸🇪 Läkaren bedömer hur allvarlig skadan är. — 🇨🇳 医生评估伤势有多严重。

**义项 2 — 评分、评判 (grade / rate):**

- 🇸🇪 Läraren bedömer elevernas prov. — 🇨🇳 老师评定学生的考试。

## 用法提示 (Usage Notes)

- `bedöma` 强调"**依据情况作出判断**"，常以机构为主语（`socialtjänsten`、`läkaren`、`domaren`）。后接 `om / hur / vad` 从句时遵循从句语序，见 [[grammar-indirekt-fraga]] · [[grammar-bisats-om]]。
- 经济补助是否发放，要经过 `behovsprövning`（需求评估）——`bedömning` 是关键一步。
