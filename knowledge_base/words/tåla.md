# tåla — verb (grupp 2)

📖 中文：受得了；耐受 · English: to tolerate; to stand
发音提示：TÅ-la

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | tåla |
| Presens | tål |
| Preteritum | tålde |
| Supinum | tålt |
| Imperativ | tål! |

注意：presens 形式是 *tål*（不是 *tålar*）

## 词组搭配 (Collocations)

- `tål inte laktos` — 不耐乳糖 → [[laktos]]
- `tåla smärta` — 忍受疼痛
- `tåla väntan` — 耐心等待
- `kan inte tåla` — 受不了…

## 例句 (Sentences)

- 🇸🇪 Hon tål inte laktos och kan inte äta grädde. — 🇨🇳 她不耐乳糖，不能吃奶油。
- 🇸🇪 Jag tål inte starkt kryddad mat. — 🇨🇳 我受不了重口味的食物。
- 🇸🇪 Kan du tåla att vänta lite till? — 🇨🇳 你能再等一会儿吗？

## 词族 / 同义 / 反义 (Relations)

- 词族: tålamod（耐心），tålmodig（有耐心的）
- 同义词: klara (av)（应付，受得了），stå ut med（忍受）
- 反义词: —
- 主题: [[topic-mat-dryck]] · [[topic-hälsa]]

## 用法提示 (Usage Notes)

- presens 不规则：*tålar* 是口语中偶见的，但标准形式是 *tål*
- 食物过敏/不耐受语境：*tål inte X* = 不耐受X（比 *allergisk* 更广，包括不耐症）
