# listig — adjektiv

📖 中文：狡猾的；机灵的 · English: cunning, sly

🇸🇪 Förklaring: som är smart på ett lite slugt sätt för att få som man vill

发音提示：/ˈlɪstɪɡ/ — 重音在第一音节；g 在词尾读 /ɡ/

## 词组搭配 (Collocations)

- `en listig räv` — 一只狡猾的狐狸
- `listig som en räv` — 像狐狸一样狡猾

## 例句 (Sentences)

- 🇸🇪 Räven är ett listigt djur i många sagor. — 🇨🇳 狐狸在许多童话里是狡猾的动物。
- 🇸🇪 Den listiga kråkan hittade maten först. — 🇨🇳 那只狡猾的乌鸦最先找到了食物。
- 🇸🇪 Hon gav honom ett listigt leende. — 🇨🇳 她给了他一个狡黠的微笑。
