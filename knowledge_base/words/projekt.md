# projekt — substantiv (ett-ord)

📖 中文：项目 · English: project
发音提示：pro-JEKT

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| obestämd singular | ett projekt |
| bestämd singular | projektet |
| obestämd plural | projekt |
| bestämd plural | projekten |

## 词组搭配 (Collocations)

- `jobba med ett projekt` — 参与一个项目
- `starta ett projekt` — 启动一个项目
- `projektledare` — 项目负责人

## 例句 (Sentences)

- 🇸🇪 Vi jobbar med ett nytt projekt på skolan. — 🇨🇳 我们在学校做一个新项目。
- 🇸🇪 Projektet är klart nästa måndag. — 🇨🇳 这个项目下周一就完成了。
- 🇸🇪 Hon är ledare för projektet. — 🇨🇳 她是这个项目的负责人。
