# bita — verb (grupp 4, 强变化)

📖 中文：咬 · English: to bite

🇸🇪 Förklaring: ta tag i något med tänderna eller skada någon med tänderna

发音提示：BEE-ta（长 i）；过去式 bet 读 [be:t]，长 e

## 语法变形 (Forms)

| Form | |
|------|-|
| Infinitiv | bita |
| Presens | biter |
| Preteritum | **bet** |
| Supinum | bitit |
| Imperativ | bit! |
| Perfekt particip | biten / bitet / bitna |

## 词组搭配 (Collocations)

- `bita någon i armen` — 咬某人的胳膊 → 身体部位用 **i + 定式**，见 [[grammar-ont-i-kroppsdel]]
- `bli biten` — 被咬 → see [[bli-biten]]
- `bita på allt` — （长牙期）什么都咬
- `bita ihop` — 咬紧牙关；忍住（习语）

## 例句 (Sentences)

- 🇸🇪 Ella bet en kompis i armen. — 🇨🇳 Ella 咬了一个小朋友的胳膊。
- 🇸🇪 Vi har pratat med barnen om att vi inte biter. — 🇨🇳 我们跟孩子们讲了：我们不咬人。
- 🇸🇪 Hunden biter inte, den är snäll. — 🇨🇳 这狗不咬人，它很乖。
- 🇸🇪 Har hon själv blivit biten? — 🇨🇳 她自己有没有被咬过？

## 用法提示 (Usage Notes)

- ⚠️ 强变化：biter / **bet** / bitit。过去式只有三个字母 bet，不要写成 ✗ bitade，也别被英语 bit 带偏成 ✗ bit。
- 📌 "咬了他的胳膊"瑞典语不用领属，说 *bita honom **i armen***（同 dra i håret, slå i huvudet）。中文母语者最常错成 ✗ *bita hans arm*。
- 在幼儿园语境里 bita 是"咬人"这个行为问题的固定词：*bitare*（爱咬人的孩子）、*bitmärke*（咬痕）。
