# trygg — adjektiv

📖 中文：安全的；有安全感的、安心的 · English: safe, secure (esp. a feeling of security)
发音提示：/trʏɡ/，y 是圆唇前元音（嘴像发 i 但圆唇）；ggg 短促。

## 语法变形 (Forms)

| Form | Example |
|------|---------|
| En-form (grundform) | trygg |
| Ett-form | tryggt |
| Bestämd form / Plural | trygga |
| Komparativ | tryggare |
| Superlativ | tryggast |

## 词组搭配 (Collocations)

- `känna sig trygg` — 感到安心 / 有安全感
- `trygg och säker` — 安全又安心（固定搭配）
- `en trygg miljö` — 一个让人安心的环境
- `trygg uppväxt` — 安稳的成长环境
- `göra ngn trygg` — 让某人有安全感

## 例句 (Sentences)

- 🇸🇪 Jag känner mig trygg hemma. — 🇨🇳 我在家觉得很安心。
- 🇸🇪 Barnen behöver en trygg miljö. — 🇨🇳 孩子们需要一个安全、有安全感的环境。
- 🇸🇪 Med dig känns allt tryggare. — 🇨🇳 有你在，一切都让人更安心。

## 词族 / 同义 / 反义 (Relations)

- 同义词: [[säker]]（安全的/确定的）
- 反义词: [[otrygg]]（缺乏安全感的）、rädd（害怕的）
- 主题: [[topic-karaktarsord]]

## 用法提示 (Usage Notes)

- **常用词**。*trygg* 偏重**心理上的安全感 / 安心**；*säker* 偏重**客观安全 / 有把握**。
  例：*en säker plats*（客观安全的地方） vs *en trygg plats*（让人安心的地方）。
- 与反身代词连用很常见：*känna sig trygg*（感到安心）。
- "trygga"（你查的形式）是 trygg 的**复数/定形**，也可能是动词 [[trygga]]，看语境区分。
