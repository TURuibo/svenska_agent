# uttalande — substantiv (ett)

📖 中文：声明；表态 · English: statement

🇸🇪 Förklaring: något som någon officiellt säger om en fråga

发音提示：/ˈʉːtˌɑːlandɛ/ — 重音在 ut-；-ande 读 /andɛ/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Singular obestämd | ett uttalande |
| Singular bestämd | uttalandet |
| Plural obestämd | uttalanden |
| Plural bestämd | uttalandena |

## 词组搭配 (Collocations)

- `göra ett uttalande` — 发表声明

## 例句 (Sentences)

- 🇸🇪 Ministern gjorde ett uttalande på måndagen. — 🇨🇳 部长周一发表了声明。
- 🇸🇪 Uttalandet väckte starka reaktioner. — 🇨🇳 这一表态引起强烈反应。
- 🇸🇪 Företaget har inte kommit med något uttalande. — 🇨🇳 公司没有发表任何声明。
