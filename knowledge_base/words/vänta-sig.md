# vänta sig — verb (grupp 2, reflexivt)

📖 中文：预期；期待 · English: to expect

🇸🇪 Förklaring: tro att något ska hända eller vara på ett visst sätt

发音提示：/ˈvɛnta sɛj/ — 重音在 vän-；sig 读 /sɛj/

## 语法变形 (Forms)

| 形式 | 瑞典语 |
|------|--------|
| 不定式 | vänta sig |
| 现在时 | väntar sig |
| 过去时 | väntade sig |
| 完成分词 | väntat sig |

## 词组搭配 (Collocations)

- `vänta sig något av någon` — 对某人抱有期待
- `mer än jag hade väntat mig` — 超出我的预期

## 例句 (Sentences)

- 🇸🇪 Det var raka motsatsen till vad jag hade väntat mig. — 🇨🇳 这和我原先的预期正好相反。
- 🇸🇪 Jag väntade mig mer av filmen. — 🇨🇳 我对这部电影期望更高。
- 🇸🇪 Man kan inte vänta sig att alla håller med. — 🇨🇳 不能指望所有人都同意。
