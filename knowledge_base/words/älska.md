# älska — verb (v.1)

📖 中文：热爱；爱 · English: to love
发音提示：/ˈɛlska/；ä 前元音，sk 在此不变音（后接辅音）。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | att älska |
| Imperativ | älska! |
| Presens | älskar |
| Preteritum | älskade |
| Supinum | (har) älskat |

规则 grupp 1 动词（-ar/-ade/-at）。

## 词组搭配 (Collocations)

- `älska ngn` — 爱某人（浪漫之爱或深厚感情）
- `älska fotboll` — 热爱足球
- `älska att + infinitiv` — 热爱做某事

## 例句 (Sentences)

- 🇸🇪 Zlatan älskade fotboll redan som liten pojke. — 🇨🇳 兹拉坦从小就热爱足球。
- 🇸🇪 Jag älskar att läsa böcker på svenska. — 🇨🇳 我热爱用瑞典语读书。
- 🇸🇪 Hon älskar sina barn över allt annat. — 🇨🇳 她比一切都更爱她的孩子们。

## 词族 / 同义 / 反义 (Relations)

- 词族: [[kärlek]] (en, 爱情/爱), [[älskling]] (en, 亲爱的/心爱之人), [[kär]] (adj. 相爱的)
- 同义词: [[tycka mycket om]] (非常喜欢，程度略弱)
- 反义词: [[hata]] (恨)
- 主题: [[topic-familj-och-barn]]

## 用法提示 (Usage Notes)

- `älska` 强度比 `tycka om` 强，用于深切的爱（人、活动、食物等均可）。
- `Jag älskar dig` = 我爱你（情侣常用）。
