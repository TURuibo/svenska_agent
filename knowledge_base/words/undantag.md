# undantag — substantiv

📖 中文：例外 · English: exception
发音提示：UN-dan-tag，重音在第一音节

## 语法变形 (Forms)

| | 单数 | 复数 |
|---|------|------|
| 不定 | ett undantag | undantag |
| 定 | undantaget | undantagen |

## 词组搭配 (Collocations)

- `med få undantag` — 只有少数例外
- `göra ett undantag` — 破例
- `utan undantag` — 无一例外
- `ett undantag från regeln` — 规则的例外

## 例句 (Sentences)

- 🇸🇪 Alla får arbeta hemma, med några undantag. — 🇨🇳 所有人都可以在家工作，只有少数例外。
- 🇸🇪 Det finns ett undantag från den regeln. — 🇨🇳 这条规则有一个例外。
- 🇸🇪 Läraren gjorde ett undantag för mig. — 🇨🇳 老师为我破了例。

## 词族 / 同义 / 反义 (Relations)

- 反义词: regel

## 用法提示 (Usage Notes)

- 复数形式与单数相同（ett-ord，以 -ag 结尾）。
