# stiga — verb (oregelbundet)

📖 中文：上升；迈步；走上 · English: to rise / step / climb
发音提示：STI-ga；两音节。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | att stiga |
| Presens | stiger |
| Preteritum | steg |
| Supinum | (har) stigit |

## 词组搭配 (Collocations)

- `stiga upp` — 起床；站起来 → see [[stiga-upp]]
- `stiga av (bussen)` — 下（公共汽车）
- `stiga på (tåget)` — 上（火车）
- `temperaturen stiger` — 温度上升

## 例句 (Sentences)

- 🇸🇪 Jag **steg** upp klockan sex och drack kaffe. — 🇨🇳 我六点起床喝了咖啡。
- 🇸🇪 Hon **stiger** alltid upp tidigt på morgonen. — 🇨🇳 她早上总是很早起床。
- 🇸🇪 Temperaturen **stiger** snabbt på sommaren. — 🇨🇳 夏天气温迅速上升。

## 词族 / 同义 / 反义 (Relations)

- 词族: [[stiga upp]] (partikelverb: 起床), [[uppstigning]] (上升)
- 同义词: [[klättra]] (v. 攀爬，指努力往上爬)
- 反义词: [[sjunka]] (v. 下沉/下降)
- 主题: [[topic-vardagsrutin]]

## 用法提示 (Usage Notes)

- `stiga upp` 是"起床"最自然的表达，比 `gå upp` 稍正式。
- 不规则变形：stiga → steg → stigit（类似 *skriva→skrev→skrivit*）。
