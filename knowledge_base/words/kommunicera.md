# kommunicera — verb (grupp 1)

📖 中文：沟通；交流；通讯 · English: to communicate
发音提示：[kɔmʊnɪˈseːra]（重音在 -se-）

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| infinitiv | kommunicera |
| presens | kommunicerar |
| preteritum | kommunicerade |
| supinum | kommunicerat |
| imperativ | kommunicera! |

## 词组搭配 (Collocations)

- `kommunicera bättre` — 更好地沟通
- `kommunicera med varandra` — 互相沟通
- `kommunicera på svenska` — 用瑞典语交流

## 例句 (Sentences)

- 🇸🇪 Jag försöker lära mig svenska för att kunna kommunicera bättre. — 🇨🇳 我努力学习瑞典语，以便能更好地沟通。
- 🇸🇪 Det är viktigt att kommunicera med familjen. — 🇨🇳 与家人沟通很重要。
- 🇸🇪 Vi kommunicerar på video varje vecka. — 🇨🇳 我们每周通过视频交流。
