# kod — substantiv (en)

📖 中文：码；代码；密码 · English: code
发音提示：/kuːd/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Singular obestämd | en kod |
| Singular bestämd | koden |
| Plural obestämd | koder |
| Plural bestämd | koderna |

## 词组搭配 (Collocations)

- `Swish-koden` — Swish 付款码
- `fixa koden` — 弄好付款码（口语）
- `ange koden` — 输入密码
- `QR-kod` — 二维码

## 例句 (Sentences)

- 🇸🇪 Absolut, jag fixar koden. — 🇨🇳 完全可以，我来弄付款码。
- 🇸🇈 Kan du visa mig din Swish-kod? — 🇨🇳 你能给我看你的 Swish 码吗？
- 🇸🇪 Glöm inte din PIN-kod! — 🇨🇳 别忘了你的 PIN 码！
