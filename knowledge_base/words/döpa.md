# döpa — verb (v.2a)

📖 中文：命名/洗礼 · English: to baptize, to name
发音提示：DÖ-pa；元音 `ö` 长音，嘴形圆扁。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | att döpa |
| Imperativ | döp! |
| Presens | döper |
| Preteritum | döpte |
| Supinum | (har) döpt |

Grupp 2a 动词（-er/-te/-t）。

## 词组搭配 (Collocations)

- `döpa till` — 取名为…（例：döpa till Lars）
- `döpa ett barn` — 给孩子洗礼/命名

## 用法提示 (Usage Notes)

- `döpa till` = 取名为：*Hon döpte sonen till Lars* — 她给儿子取名拉尔斯。
- 除了宗教洗礼，`döpa` 也可以普通地指"命名"（为某物起名）。
