# tipsa — verb (grupp 1)

📖 中文：建议；告知；给小贴士 · English: to tip off; to advise; to give a tip
发音提示：TIP-sa；短促的 i。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | tipsa |
| Presens | tipsar |
| Preteritum | tipsade |
| Supinum | tipsat |
| Imperativ | tipsa! |

## 词组搭配 (Collocations)

- `tipsa folk om att` — 建议人们…
- `tipsa polisen` — 向警方举报/提供线索
- `tipsa om` — 告知关于…的信息

## 例句 (Sentences)

- 🇸🇈 Han tipsar folk att dricka mycket vatten i värmen. — 🇨🇳 他建议人们在炎热天气中多喝水。
- 🇸🇈 Kan du tipsa mig om ett bra café i Stockholm? — 🇨🇳 你能给我推荐斯德哥尔摩一家好咖啡馆吗？
- 🇸🇈 Läkaren tipsade patienten om vikten av motion. — 🇨🇳 医生建议患者注意运动的重要性。

## 用法提示 (Usage Notes)

- `tipsa ngn om att + infinitiv`：建议某人做某事。
- `tipsa om`：告知关于某事的信息（如 `tipsa om ett brott` = 向警察举报犯罪）。
- 比 `råda` 更口语化，带有"分享小秘诀"的语感。
