# kunna — verb (oregelbundet)

📖 中文：能、会 · English: can, be able to

🇸🇪 Förklaring: 1) ha förmåga eller möjlighet att göra något; 2) veta hur man gör något eller ha lärt sig något

发音提示：/ˈkɵnːa/；kan /kan/；kunde /ˈkɵndɛ/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) kunna |
| Presens | kan |
| Preteritum | kunde |
| Supinum | kunnat |

（助动词，没有命令式。）

## 词组搭配 (Collocations)

- `för att kunna + inf.` — 为了能够……→ see [[för-att-kunna]]
- `hade kunnat + inf.` — 本来可以……（文中：Det hade kunnat få honom att lägga av）→ see [[grammar-kunde-ha-supinum]]
- `kan jag få …?` — 我可以要……吗？→ see [[kan-jag-få]]
- `kan ha med … att göra` — 可能与……有关 → see [[kan-ha-med-att-göra]]
- `kunna svenska` — 会说/懂瑞典语

## 例句 (Sentences)

**义项1 本来可以 (hade kunnat):**
- 🇸🇪 Det hade kunnat få honom att lägga av men istället tog han sitt livs viktigaste beslut. — 🇨🇳 这本可能让他放弃，但他却做出了一生中最重要的决定。

**义项2 能够（目的）:**
- 🇸🇪 Därför gjorde han ett tävlingsuppehåll för att kunna fokusera på sin träning. — 🇨🇳 所以他停赛，以便能专注训练。

**义项3 能（过去的能力）:**
- 🇸🇪 Han kunde till exempel springa 3 timmar för att köpa godis. — 🇨🇳 比如他能跑三个小时去买糖。

**义项4 会（技能）:**
- 🇸🇪 Jag kan inte simma. — 🇨🇳 我不会游泳。
- 🇸🇪 Kan du prata svenska? — 🇨🇳 你会说瑞典语吗？

**义项5 可以（请求）/ 可能:**
- 🇸🇪 Kan du hjälpa mig? — 🇨🇳 你能帮我一下吗？
- 🇸🇪 Det kan bli kallt i natt. — 🇨🇳 今晚可能会变冷。

## 用法提示 (Usage Notes)

- 情态助动词，后接**不带 att 的不定式**：kan springa、kunde cykla。见 [[grammar-modala-hjalpverb]]、[[grammar-modalt-hjalpverb-infinitiv]]。
- 不规则：kunna – kan – **kunde** – **kunnat**；presens 与不定式不同形。
- `hade kunnat` = 「本来可以（但没有）」，是非现实的过去（见 [[grammar-kunde-ha-supinum]]）。
- `kunna` 也可作实义动词「会/懂」：kunna svenska。
