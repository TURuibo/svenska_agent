# äga — verb

📖 中文：拥有 · English: to own
发音提示：/ˈɛːɡa/；ä 发 [ɛː]（类似英文"air"中的元音）

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | äga |
| Presens | äger |
| Preteritum | ägde |
| Supinum | ägt |
| Imperativ | äg! |

> 动词组 2a（-er / -de / -t）；不规则拼写：äg- 词干

## 词组搭配 (Collocations)

- `äga mark` — 拥有土地
- `äga ett hus` — 拥有一栋房子
- `äga rum` — 发生（固定短语，字面"占有空间"）
- `vem äger marken?` — 谁拥有这块土地？

## 例句 (Sentences)

- 🇸🇪 Det spelar ingen roll vem som äger marken. — 🇨🇳 无论谁拥有那片土地都没关系。
- 🇸🇪 Hon äger ett litet hus på landet. — 🇨🇳 她在乡间拥有一栋小房子。
- 🇸🇪 Mötet äger rum på fredag. — 🇨🇳 会议在周五举行。（固定短语 äga rum = 发生）

## 词族 / 同义 / 反义 (Relations)

- 词族: [[ägare]]（所有者/主人）
- 同义词: [[ha]]（有，口语中常替代）
- 反义词: —
- 主题: [[topic-allemansratten]]

## 用法提示 (Usage Notes)

- **äga** 强调所有权（ownership），**ha** 更宽泛（possession）。
- 固定短语 **äga rum** = "发生"，与"拥有"义完全不同，需单独记忆。
