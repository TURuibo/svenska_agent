# svara — verb

📖 中文：回答；答复 · English: to answer, to reply
发音提示：/ˈsvɑːra/ — 重音在首音节，"sv"如英语"sw-"

## 语法变形 (Forms)

| 形式 | 词形 |
|------|------|
| infinitiv | svara |
| presens | svarar |
| preteritum | svarade |
| supinum | svarat |
| imperativ | svara! |

## 词组搭配 (Collocations)

- `svara på (en fråga)` — 回答（一个问题）→ see [[svara-på]]
- `svara med` — 以……作答（如 *svara med ett leende* = 用微笑回应）
- `svara mot` — 对应；符合（*svara mot förväntningarna* = 符合预期）
- `svara för` — 对……负责（*svara för sina handlingar* = 为自己的行为负责）
- `inte svara` — 不接电话；不回复

## 例句 (Sentences)

- 🇸🇪 Vad svarade han på frågan? — 🇨🇳 他如何回答了这个问题？
- 🇸🇪 Kan du svara på det här mejlet? — 🇨🇳 你能回复这封邮件吗？
- 🇸🇪 Hon svarade inte när jag ringde. — 🇨🇳 我打电话时她没有接。
- 🇸🇪 Svara på frågorna nedan. — 🇨🇳 回答以下问题。

## 用法提示 (Usage Notes)

- 最常见搭配是 **svara på (något)**，表示"回答某事/某问题"
- 与 *besvara* 同义但 *besvara* 更正式：*besvara ett brev*（正式书信答复）
- 注意：*svara i telefon* = 接电话，但 *svara på ett meddelande* = 回复消息
