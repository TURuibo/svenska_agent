# knuffa — verb (grupp 1)

📖 中文：推；推撞 · English: to push, to shove
发音提示：KNUFF-a，k 要发音（kn- 不像英语哑音）

## 语法变形 (Forms)

| Form | |
|------|-|
| Infinitiv | knuffa |
| Presens | knuffar |
| Preteritum | knuffade |
| Supinum | knuffat |
| Imperativ | knuffa! |

## 词组搭配 (Collocations)

- `knuffa någon` — 推某人
- `knuffas` — 互相推搡（-s 相互式）；*vi knuffas inte!* 我们不推人
- `knuffa till någon` — 撞了某人一下
- `en knuff` — 一推（名词）

## 例句 (Sentences)

- 🇸🇪 Noah knuffade Ella förra veckan. — 🇨🇳 Noah 上周推了 Ella。
- 🇸🇪 Knuffa inte! — 🇨🇳 别推！
- 🇸🇪 Barnen knuffas i kön. — 🇨🇳 孩子们在队伍里互相推挤。

## 用法提示 (Usage Notes)

- 规则 v.1 动词，最省心：-ar / -ade / -at。
- knuffa 是"推人"（带撞击意味）；"推车/推门"用 *skjuta*（skjuta vagnen）或 *trycka*（按/推门）。
- 幼儿园规矩三连：*vi biter inte, vi knuffas inte, vi slåss inte*。
