# dokument — substantiv

📖 中文：文件；文档 · English: document

🇸🇪 Förklaring: papper eller fil med viktig information, till exempel ett brev, ett intyg eller ett avtal

发音提示：/dɔkɵˈmɛnt/ — 重音在最后一个音节 -ment；u 读 ɵ

## 语法变形 (Forms)

| 形式 | 词形 |
|------|------|
| 单数不定 | ett dokument |
| 单数定 | dokumentet |
| 复数不定 | dokument（不变） |
| 复数定 | dokumenten |

## 词组搭配 (Collocations)

- `viktiga dokument` — 重要文件
- `översätta dokument` — 翻译文件
- `underteckna ett dokument` — 签署文件

## 例句 (Sentences)

- 🇸🇪 De ska också översätta viktiga dokument. — 🇨🇳 他们也应当翻译重要文件。
- 🇸🇪 Jag har alla dokument i en mapp. — 🇨🇳 我把所有文件放在一个文件夹里。
- 🇸🇪 Du måste skicka dokumentet före fredag. — 🇨🇳 你必须在周五前寄出这份文件。
