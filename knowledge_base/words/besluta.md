# besluta — verb (grupp 1)

📖 中文：决定，裁决 · English: to decide
发音提示：/beˈslɵːta/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | besluta |
| Presens | beslutar |
| Preteritum | beslutade |
| Supinum | beslutat |
| Imperativ | besluta |

## 词组搭配 (Collocations)

- `besluta om` — 就……作决定
- `besluta att` + 不定式 — 决定做……

## 例句 (Sentences)

- 🇸🇪 Riksdagen beslutar om Sveriges budget och vilka lagar som ska finnas. — 🇨🇳 议会决定瑞典的预算和应有哪些法律。
- 🇸🇪 Nämndemännen ska tillsammans med domaren besluta om domen. — 🇨🇳 陪审员要与法官一起对判决作出决定。
- 🇸🇪 Vi beslutade att flytta. — 🇨🇳 我们决定搬家。
