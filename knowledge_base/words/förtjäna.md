# förtjäna — verb (grupp 1)

📖 中文：应得；值得 · English: to deserve
发音提示：för-TJÄ-na

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| infinitiv | förtjäna |
| presens | förtjänar |
| preteritum | förtjänade |
| supinum | förtjänat |
| imperativ | förtjäna! |

## 词组搭配 (Collocations)

- `förtjäna att vinna` — 应该赢
- `förtjäna respekt` — 应得到尊重
- `förtjäna på något` — 从某事中获利

## 例句 (Sentences)

**义项1 应得/值得:**
- 🇸🇪 Frankrike förtjänade att vinna matchen. — 🇨🇳 法国队值得赢得这场比赛。
- 🇸🇪 Hon förtjänar mer respekt för sitt arbete. — 🇨🇳 她的工作应该得到更多尊重。

**义项2 获利/挣得:**
- 🇸🇪 Företaget förtjänade mycket pengar på affären. — 🇨🇳 公司从这笔交易中赚了很多钱。

## 词族 / 同义 / 反义 (Relations)

## 用法提示 (Usage Notes)

- `förtjäna` 比 `tjäna`（挣钱）更强调"应得的"，常跟 `att + infinitiv`。
- 体育新闻常见句型：`X förtjänade att vinna`（X 值得获胜）。
