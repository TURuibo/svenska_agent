# hedersvåld — substantiv (ett)

📖 中文：荣誉暴力（以家族荣誉为由的暴力） · English: honour-based violence
发音提示：HEH-ders-vold（重音在 heder）

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| obestämd sing. | ett hedersvåld |
| bestämd sing. | hedersvåldet |
| obestämd pl. | (hedersvåld – sällan plural) |
| bestämd pl. | hedersvålden |

词源：复合词 **heder**（荣誉）+ **våld**（暴力）

## 词组搭配 (Collocations)

- `hedersvåld i familjer` — 家庭中的荣誉暴力
- `stoppa hedersvåld` — 阻止荣誉暴力
- `utsatt för hedersvåld` — 遭受荣誉暴力

## 例句 (Sentences)

- 🇸🇪 Att slå någon i sin familj för att den klär sig på ett visst sätt kallas hedersvåld. — 🇨🇳 殴打家庭成员因其穿着方式，这被称为荣誉暴力。
- 🇸🇪 Regeringen ger pengar till kommunerna för att stoppa hedersvåld i familjer. — 🇨🇳 政府向各市政府拨款以阻止家庭中的荣誉暴力。
- 🇸🇪 Lagen mot hedersvåld blir hårdare från och med juli. — 🇨🇳 针对荣誉暴力的法律将从七月起变得更严格。

## 用法提示 (Usage Notes)

- 专业社会/法律用语，指以维护家族荣誉为名，对家庭成员（尤其是女性和年轻人）实施的暴力或压迫行为。
- 瑞典法律已将此列为专门罪类，与普通暴力罪区分开来。
