# foto — substantiv (ett)

📖 中文：照片 · English: photo; photograph
发音提示：FO-to；två stavelser.

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Singular obestämd | ett foto |
| Singular bestämd | fotot |
| Plural obestämd | foton |
| Plural bestämd | fotona |

## 词组搭配 (Collocations)

- `ta ett foto` — 拍一张照片
- `ett foto sitter på hyllan` — 一张照片固定在架子上
- `titta på foton` — 看照片

## 例句 (Sentences)

- 🇸🇈 Ett foto **sitter** på den översta hyllan. — 🇨🇳 一张照片固定在最上面那层架子上。（用 sitta：贴/固定）
- 🇸🇈 Kan du ta ett foto av oss? — 🇨🇳 你能给我们拍张照吗？
- 🇸🇈 Det **hänger** ett gammalt foto på väggen. — 🇨🇳 墙上挂着一张旧照片。

## 用法提示 (Usage Notes)

- 照片固定在架子/墙上：用 **sitter**（贴/固定）；用钩子挂着：用 **hänger**。
- 复数：foton（不是 fotor）。
