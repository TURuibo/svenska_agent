# bitmärke — substantiv (ett)

📖 中文：咬痕 · English: bite mark
发音提示：BEET-mär-ke，复合词重音在第一部分

## 语法变形 (Forms)

| | Singular | Plural |
|-|----------|--------|
| Obestämd | ett bitmärke | bitmärken |
| Bestämd | bitmärket | bitmärkena |

## 词组搭配 (Collocations)

- `få ett bitmärke` — 留下一个咬痕
- `ett litet / rött bitmärke` — 一个小的 / 红色的咬痕
- `bitmärke på armen` — 胳膊上的咬痕 → see [[arm]]

## 例句 (Sentences)

- 🇸🇪 Han fick ett litet bitmärke. — 🇨🇳 他留了一个小咬痕。
- 🇸🇪 Det syns fortfarande ett bitmärke på armen. — 🇨🇳 胳膊上还看得见一个咬痕。
- 🇸🇪 Bitmärket försvann efter några dagar. — 🇨🇳 咬痕几天后就消失了。

## 用法提示 (Usage Notes)

- 复合词 bit- + märke（[[märke]] 是 ett 词，所以 bitmärke 也是 ett 词——复合词的性由**最后一部分**决定）。
- 日常也说 *ett rött märke*（一个红印），bitmärke 更具体。
