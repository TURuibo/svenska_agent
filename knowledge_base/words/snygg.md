# snygg — adjektiv

📖 中文：好看的；帅的；漂亮的 · English: attractive; stylish; good-looking
发音提示：/snɵɡ/

## 语法变形 (Forms)

| form | exempel |
|------|---------|
| en-form (grundform) | snygg |
| ett-form | snyggt |
| plural / bestämd | snygga |
| komparativ | snyggare |
| superlativ | snyggast |

## 词组搭配 (Collocations)

- `se snygg ut` — 看起来很好看
- `snygg kille/tjej` — 帅气的男孩/漂亮的女孩
- `snyggt klädd` — 穿着时髦

## 例句 (Sentences)

- 🇸🇪 Hon ser jättesnygg ut i den klänningen. — 🇨🇳 她穿那条裙子看起来非常漂亮。
- 🇸🇪 Det är ett snyggt rum du har! — 🇨🇳 你的房间好好看！
- 🇸🇪 Vad snygg din nya jacka är! — 🇨🇳 你的新夹克真好看！

## 词族 / 同义 / 反义 (Relations)

- 词族: snygghet
- 同义词: [[söt]] (可爱的), [[stilig]] (有型的), [[vacker]] (美丽的)
- 反义词: ful (丑的)

## 用法提示 (Usage Notes)

- `snygg` 是最常用的口语词，适用于人和物；`vacker` 更书面、更正式。
- `stilig` 常用于男性，`söt` 常用于可爱/萌。
