# föra — verb (grupp 2)

📖 中文：带领；运送；进行（对话） · English: to lead; to carry; to conduct

🇸🇪 Förklaring: ta eller leda något någonstans; hålla på med något, till exempel ett samtal

发音提示：/ˈføːra/ — ö 长音，重音在第一音节；r 轻弹

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | föra |
| Presens | för |
| Preteritum | förde |
| Supinum | fört |
| Imperativ | för |
| S-passiv | förs |

## 词组搭配 (Collocations)

- `föra en dialog` — 进行对话
- `föra samtal` — 交谈
- `föra bok över` — 记账
- `föra med sig` — 带来；伴随

## 例句 (Sentences)

- 🇸🇪 Kommunen vill föra en dialog med de boende. — 🇨🇳 市政府希望与居民对话。
- 🇸🇪 Vägen för till havet. — 🇨🇳 这条路通向大海。
- 🇸🇪 Hon förde dagbok i många år. — 🇨🇳 她写了很多年日记。
- 🇸🇪 Bron för över floden. — 🇨🇳 这座桥横跨河流。
