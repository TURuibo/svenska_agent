# van — adjektiv

📖 中文：习惯的；熟练的 · English: used (to); accustomed

🇸🇪 Förklaring: som har gjort något många gånger och därför tycker att det är lätt eller normalt

发音提示：/vɑːn/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Utrum | van |
| Neutrum | vant |
| Plural / bestämd | vana |
| Komparativ | vanare |
| Superlativ | vanast |

## 词组搭配 (Collocations)

- `vara van vid` — 习惯于 → see [[vara-van-vid]]
- `van vid kylan` — 习惯了寒冷

## 例句 (Sentences)

- 🇸🇪 I Wales är jag van vid att man hälsar på människor som man möter. — 🇨🇳 在威尔士，我习惯于对遇到的人打招呼。
- 🇸🇪 Hon är van vid att stiga upp tidigt. — 🇨🇳 她习惯早起。
- 🇸🇪 Barnen är vana vid snö. — 🇨🇳 孩子们习惯了雪。
