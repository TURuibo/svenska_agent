# mord — substantiv

📖 中文：谋杀 · English: murder

🇸🇪 Förklaring: brott där någon med avsikt dödar en annan människa

发音提示：/muːrd/，rd 连读为卷舌音。

## 语法变形 (Forms)

| | 单数 | 复数 |
|---|---|---|
| 不定 | ett mord | mord |
| 定 | mordet | morden |

## 词组搭配 (Collocations)

- `begå ett mord` — 犯下谋杀 → see [[begå]]
- `dömas för mord` — 因谋杀被判刑 → see [[döma]]
- `mordet på …` — …被谋杀案

## 例句 (Sentences)

- 🇸🇪 Polisen undersöker ett mord i staden. — 🇨🇳 警方在调查城里的一起谋杀案。
- 🇸🇪 Han dömdes för mord och fick livstids fängelse. — 🇨🇳 他因谋杀被判刑，被判无期徒刑。
- 🇸🇪 Mordet hände på natten. — 🇨🇳 谋杀发生在夜里。
