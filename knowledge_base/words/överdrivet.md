# överdrivet — adjektiv/adverb

📖 中文：过度的；过分的 · English: excessive; excessively
发音提示：/ö-ver-DRI-vet/

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| utrum | överdriven |
| neutrum | överdrivet |
| plural/bestämd | överdrivna |
| adverb | överdrivet |

## 词组搭配 (Collocations)

- `ett överdrivet användande` — 过度使用
- `överdrivet beteende` — 过度行为
- `överdriva` — 夸大；过度（动词）

## 例句 (Sentences)

- 🇸🇪 Ett överdrivet användande kan leda till ångest. — 🇨🇳 过度使用可能导致焦虑。
- 🇸🇪 Jag tycker att du överdrev lite. — 🇨🇳 我觉得你稍微夸大了。

## 词族 / 同义 / 反义 (Relations)

- 词族: överdriva（动词：夸大）· överdrift（名词：夸张）
- 反义词: lagom（适度的/恰好的）
