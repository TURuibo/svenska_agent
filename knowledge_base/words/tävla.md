# tävla — verb (grupp 1)

📖 中文：比赛；竞赛 · English: to compete
发音提示：[ˈtɛːvla]

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| infinitiv | tävla |
| presens | tävlar |
| preteritum | tävlade |
| supinum | tävlat |
| imperativ | tävla! |

## 词组搭配 (Collocations)

- `tävla i något` — 参加…比赛
- `tävla mot någon` — 与某人竞争
- `tävla för ett land` — 代表某国参赛

## 例句 (Sentences)

- 🇸🇪 Kanada får vara med och tävla i Eurovision. — 🇨🇳 加拿大获准参加欧洲歌唱大赛。
- 🇸🇪 Sverige tävlade mot Frankrike i VM. — 🇨🇳 瑞典在世界杯上对阵法国。
- 🇸🇪 Hon tävlade för Schweiz, inte för sitt eget land. — 🇨🇳 她代表瑞士参赛，而不是自己的国家。
