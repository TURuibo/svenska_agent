# utan — konjunktion / preposition

📖 中文：（否定之后）而是；没有 · English: but (rather); without

🇸🇪 Förklaring: används efter ett nekande led för att visa vad som gäller i stället; när man inte har något eller någon med sig

发音提示：/ˈʉːtan/；`u` 读长 /ʉː/，重音在第一音节 U-tan。

## 词组搭配 (Collocations)

- `inte X utan Y` — 不是 X 而是 Y
- `inte bara … utan också/även …` — 不仅……而且…… → see [[grammar-inte-bara-utan-aven]]
- `utan socker` — 不加糖
- `utan att + infinitiv` — 没有做…就…
- `med eller utan` — 有或没有 → see [[med-eller-utan]]
- `utan tvekan` — 毫无疑问 → see [[utan-tvekan]]
- `utan hänsyn till` — 不顾…… → see [[utan-hänsyn-till]]

## 例句 (Sentences)

**义项1 konjunktion：（否定之后）而是 (but rather):**

- 🇸🇪 Han gillade egentligen inte konditionsträning utan det som lockade var saften och kakorna efter träningen. — 🇨🇳 其实他并不喜欢耐力训练，吸引他的是训练后的果汁和饼干。
- 🇸🇪 Jag vill inte ha kaffe utan te. — 🇨🇳 我不想要咖啡，而是要茶。

**义项2 preposition：没有 (without):**

- 🇸🇪 Jag dricker kaffe utan socker. — 🇨🇳 我喝不加糖的咖啡。
- 🇸🇪 Han gick utan att säga hejdå. — 🇨🇳 他没说再见就走了。

## 用法提示 (Usage Notes)

- **`inte … utan …`**：前面是否定句（inte/ingen/aldrig…），后面纠正为「而是……」。这里 `utan` 是**并列连词**（像 och/men/eller），后面接**主句语序**，不触发倒装：`…inte konditionsträning utan det som lockade var saften`。
- 对比 `men`（但是）：`men` 不要求前句是否定，也不是「纠正」。完整对比见 [[grammar-utan-vs-men]]。
- 作介词时 `utan` = 「没有」，后面接名词（`utan socker`）或 `att + 不定式`（`utan att fråga`）。
