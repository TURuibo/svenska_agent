# stå — verb (grupp 4 / stark verb)

📖 中文：站；立；摆放 · English: to stand; to be standing
发音提示：stå（单音节）；lång å.

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | att stå |
| Imperativ | stå! |
| Presens | står |
| Preteritum | stod |
| Supinum | (har) stått |

## 词组搭配 (Collocations)

- `stå och vänta` — 站着等待
- `stå i hörnet` — 站在角落里
- `stå framför` — 站在……前面
- `stå längs väggen` — 靠墙站/摆
- `förstå` — 理解（词族，不同义）

## 例句 (Sentences)

- 🇸🇈 Sängen **står** längs väggen. — 🇨🇳 床靠墙摆放。
- 🇸🇈 Bredvid sängen **står** ett litet nattduksbord. — 🇨🇳 床边立着一张小床头柜。
- 🇸🇈 Soffan **står** mitt i rummet. — 🇨🇳 沙发摆在房间中央。

## 用法提示 (Usage Notes)

- **stå vs ställa**：`stå` = 状态（某物竖立着）；`ställa` = 动作（把某物竖立放置）。
  - *Stolen **står** vid bordet.* (现在立着) → *Jag **ställde** stolen vid bordet.* (我把椅子放到桌旁)
- 竖立或有高度的物体用 **stå**：家具（床、桌、椅、书架、柜子）、直立的书（书架上）、灯。
- 强变词（stark verb）：stå → stod → stått（不规则变化）。
