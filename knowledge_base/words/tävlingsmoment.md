# tävlingsmoment — substantiv (ett)

📖 中文：比赛环节，竞赛部分 · English: competitive element; competition part
发音提示：/ˈtɛːvlɪŋsmʊˌmɛnt/

## 语法变形 (Forms)

| | obestämd | bestämd |
|---|---|---|
| singular | ett tävlingsmoment | **tävlingsmomentet** |
| plural | tävlingsmoment | tävlingsmomenten |

## 构词 (Sammansättning)

`tävling` (比赛) + **-s-** (连接音) + `moment` (环节) → **tävlingsmoment**
- 复合词的**词性和性别跟最后一个词**：moment 是 ett-词 → *ett* tävlingsmoment → -et
- 以 `-ing` 结尾的前半部分几乎总加 **-s-**：tävling**s**moment, tidning**s**artikel, regering**s**chef

## 词组搭配 (Collocations)

- `tävlingsmomentet` — 比赛这一部分/元素（相对于训练、乐趣等）
- `ett nytt tävlingsmoment` — 一个新的比赛项目/环节

## 例句 (Sentences)

- 🇸🇪 För honom var tävlingsmomentet viktigare än själva sporten. — 🇨🇳 对他来说，比赛本身比这项运动更重要。
- 🇸🇪 Programmet har tre tävlingsmoment: frågor, sång och dans. — 🇨🇳 这个节目有三个比赛环节：问答、唱歌和跳舞。
- 🇸🇪 Barnen tycker om lekar utan tävlingsmoment. — 🇨🇳 孩子们喜欢没有竞争成分的游戏。

## 用法提示 (Usage Notes)

- 遇到长复合词先**拆开**：找到最后的核心词（moment），前面是修饰（tävling-），中间 `-s-` 是连接音。
- `moment` 在这里是"组成部分/环节"，不是"瞬间"。
