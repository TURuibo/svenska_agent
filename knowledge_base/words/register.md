# register — substantiv

📖 中文：登记册，名册；登记簿 · English: register

🇸🇪 Förklaring: lista där man skriver upp namn eller uppgifter om personer eller saker

发音提示：/rɛˈjɪstɛr/ — 重音在 -gis-；g 在 i 前读 j；末尾 -er 弱读

## 语法变形 (Forms)

| | 单数 | 复数 |
|---|---|---|
| 不定 | ett register | register |
| 定 | registret | registren |

## 例句 (Sentences)

- 🇸🇪 Då skriver Skatteverket in dig i ett register. — 🇨🇳 那时税务局会把你登记进名册。
- 🇸🇪 Namnet finns i registret. — 🇨🇳 名字在登记册里。
- 🇸🇪 Företaget har ett register över alla kunder. — 🇨🇳 公司有一份所有客户的登记册。
