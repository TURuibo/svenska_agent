# betala — verb (grupp 1)

📖 中文：支付；付钱 · English: to pay
发音提示：beh-TAH-lah

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| infinitiv | betala |
| presens | betalar |
| preteritum | betalade |
| supinum | betalat |
| imperativ | betala! |

## 词组搭配 (Collocations)

- `betala med kort` — 刷卡
- `betala kontant` — 付现金
- `betala med Swish` — 用 Swish 付款
- `betala för` — 为……付钱
- `betala tillbaka` — 还钱

## 例句 (Sentences)

- 🇸🇪 Jag betalar med Swish. — 🇨🇳 我用 Swish 付。
- 🇸🇪 Kan jag betala med kort? — 🇨🇳 我可以刷卡吗？
- 🇸🇪 Vem betalar idag? — 🇨🇳 今天谁付钱？

## 词族 / 同义 / 反义 (Relations)

- 词族: betalning (支付/付款), betalkortet (支付卡)
- 主题: [[topic-betalning]]

## 用法提示 (Usage Notes)

- *Betala med* + betalningssätt: betala med kort / kontant / Swish。
- *Betala för något* = 为某事付款（如 *betala för maten*）。
