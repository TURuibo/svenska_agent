# gosedjur — substantiv

📖 中文：毛绒玩具 · English: stuffed animal; cuddly toy

🇸🇪 Förklaring: mjukt leksaksdjur av tyg som barn gärna kramar

发音提示：/ˈɡuːsɛˌjʉːr/ — gose- 长 o（读「古瑟」），-djur 的 d 不发音

## 语法变形 (Forms)

| 形式 | 瑞典语 |
|------|--------|
| obestämd sing. | ett gosedjur |
| bestämd sing. | gosedjuret |
| obestämd plur. | gosedjur |
| bestämd plur. | gosedjuren |

## 词组搭配 (Collocations)

- `ett gosedjur` — 一个毛绒玩具
- `sova med ett gosedjur` — 抱着毛绒玩具睡
- `snuttefilt eller gosedjur` — 安抚毯或毛绒玩具 → see [[snuttefilt]]
- `favoritgosedjur` — 最喜欢的毛绒玩具

## 例句 (Sentences)

- 🇸🇪 Till vilan: napp och snuttefilt eller ett gosedjur. — 🇨🇳 午睡用：奶嘴和安抚毯，或者一个毛绒玩具。
- 🇸🇪 Ella sover alltid med sitt gosedjur. — 🇨🇳 Ella 总是抱着她的毛绒玩具睡。
- 🇸🇪 Vilket gosedjur vill du ta med till förskolan? — 🇨🇳 你想带哪个毛绒玩具去幼儿园？
- 🇸🇪 Gosedjuret heter Nalle. — 🇨🇳 这个毛绒玩具叫 Nalle。

## 用法提示 (Usage Notes)

- 复合词 **gosa + djur**：*gosa* = 搂着依偎，*djur* = 动物 → 「可以搂的动物」。ett-词，单复数同形。
- 也说 *mjukisdjur*（软软的动物），意思一样。泰迪熊专门叫 *nalle*。
- 幼儿园午睡（vilan）常允许带一个 gosedjur 当安抚物。
