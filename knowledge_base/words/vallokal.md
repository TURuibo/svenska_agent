# vallokal — substantiv (en)

📖 中文：投票站 · English: polling station

| form | Swedish |

| bestämd singular | vallokalen |
| obestämd plural | vallokaler |
| bestämd plural | vallokalerna |

## 词组搭配 (Collocations)

- `gå till vallokalen` — 去投票站
- `inne i vallokalen` — 在投票站里面

## 例句 (Sentences)

- 🇸🇪 På röstkortet står det vilken vallokal man ska gå till. — 🇨🇳 选民卡上写着你该去哪个投票站。
- 🇸🇪 Inne i vallokalen ligger alla partiers valsedlar. — 🇨🇳 投票站里放着所有政党的选票。
- 🇸🇪 Vallokalen öppnar klockan åtta på morgonen. — 🇨🇳 投票站早上八点开放。
