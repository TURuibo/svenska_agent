# lära — verb (grupp 2b)

📖 中文：教；lära sig = 学（自己学会）· English: teach / (reflexive) learn
发音提示：LÄ-ra；长 ä 音。

## 语法变形 (Forms)

| Tempus | Swedish |
|--------|---------|
| Infinitiv | (att) lära |
| Presens | lär |
| Preteritum | lärde |
| Supinum | lärt |
| Imperativ | lär! |

> 也可作 **substantiv**：`en lära` = 学说/教义（pl. läror）。

## 词组搭配 (Collocations)

- `lära sig (något)` — 学会、掌握（反身，= 自己学）
- `lära (någon) något` — 教某人某事
- `lära känna (någon)` — 结识、认识某人
- `lära ut` — 把知识教出去（partikelverb）

## 例句 (Sentences)

- 🇸🇪 Jag vill lära mig svenska. — 🇨🇳 我想学瑞典语。
- 🇸🇪 Hon lärde mig att laga mat. — 🇨🇳 她教我做饭。
- 🇸🇪 Vi lärde känna varandra på jobbet. — 🇨🇳 我们在工作中相识。

## 用法提示 (Usage Notes)

- ⚠️ 关键区分：`lära sig` = **学**（学的人是主语）；`lära någon` = **教**（教的人是主语）。
- `lära sig` 的反身代词随主语变：jag lär **mig**, du lär **dig**, hon lär **sig** …
- 口语里"教"也常用 `lära ut`；"学"也用 `studera`（更正式/系统）。
