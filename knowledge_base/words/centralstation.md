# centralstation — substantiv (en)

📖 中文：中央车站 · English: central station
发音提示：cen-tral-sta-TION；重音在末音节。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Singular obestämd | en centralstation |
| Singular bestämd | centralstationen |
| Plural obestämd | centralstationer |
| Plural bestämd | centralstationerna |

## 词组搭配 (Collocations)

- `komma fram till Centralstationen` — 到达中央车站
- `mötas vid centralstationen` — 在中央车站碰面
- `Stockholms Centralstation` — 斯德哥尔摩中央车站

## 例句 (Sentences)

- 🇸🇪 Vid halv nio kom jag fram till **Centralstationen**. — 🇨🇳 将近八点半，我到了中央车站。
- 🇸🇪 Vi ses utanför **Centralstationen** klockan tre. — 🇨🇳 我们三点在中央车站外见。
- 🇸🇪 Tåget från **Centralstationen** avgår om fem minuter. — 🇨🇳 从中央车站出发的火车五分钟后开车。
