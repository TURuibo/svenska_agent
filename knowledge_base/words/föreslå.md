# föreslå — verb (grupp 4, 不规则强变化)

📖 中文：建议；提议；提出（方案） · English: to propose; to suggest

🇸🇪 Förklaring: säga eller skriva vad man tycker att någon ska göra eller hur något kan lösas

发音提示：fö-re-SLÅ，重音在最后一个音节 `slå`。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | föreslå |
| Presens | föreslår |
| Preteritum | föreslog |
| Supinum | föreslagit |
| Imperativ | föreslå |
| S-passiv | föreslås / föreslogs |

变位与 `slå`（slår – slog – slagit）相同。

## 词组搭配 (Collocations)

- `föreslå att + 从句` — 建议……
- `föreslå en lösning` — 提出一个解决办法
- `föreslå någon som …` — 提名某人为……
- `det föreslås att …` — 有人建议……
- 名词 `förslag`：`komma med förslag` → see [[komma-med-förslag]]

## 例句 (Sentences)

- 🇸🇪 Jag föreslår att kommunen öppnar en ny fritidsgård i det gamla bibliotekshuset. — 🇨🇳 我建议市里在旧图书馆大楼里开设一个新的青少年活动中心。 → [[sent-jag-föreslår-att-kommunen-öppnar-en-ny]]
- 🇸🇪 Läraren föreslår att vi tar en paus. — 🇨🇳 老师建议我们休息一下。
- 🇸🇪 Kan du föreslå ett bra ställe att äta på? — 🇨🇳 你能推荐一个吃饭的好地方吗？
- 🇸🇪 Kommunen föreslog en ny bussrutt. — 🇨🇳 市里提出了一条新的公交线路。

## 词族 / 同义 / 反义 (Relations)

- 词族: [[förslag]]（名词：提议）, [[förslå]]（足够，另一个词，别混）
- 同义词: 近义 [[rekommendera]]（推荐，更偏"我觉得好"）, [[tipsa]]（口语：给提示）
- 反义词: —（近义对立：[[avslå]] 否决）
- 主题: [[topic-argumentation]]

## 用法提示 (Usage Notes)

- 后接 **att-从句**：`Jag föreslår att + 主语 + 动词`，见 [[grammar-att-bisats]]；从句里用现在时 / `ska`，不用 infinitiv 直接接（~~Jag föreslår kommunen öppna~~）。
- 论说文固定段落：**观点 → 理由 → `Jag föreslår att …` → 呼吁**，见 [[grammar-insandare-styckelogik]]。
- `föreslå` 比 `rekommendera` 更正式，常用于会议、提案、投书。
