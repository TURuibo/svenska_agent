# blodig — adjektiv

📖 中文：流血的、血淋淋的 · English: bloody
发音提示：/ˈbluːdɪɡ/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Positiv utrum (en-ord) | blodig |
| Positiv neutrum (ett-ord) | blodigt |
| Positiv plural/bestämd | blodiga |
| Komparativ | mer blodig |
| Superlativ | mest blodig |

## 词组搭配 (Collocations)

- `ett blodigt sår` — 一处流血的伤口
- `blodiga händer` — 血手
- `blodigt kött` — 半熟/带血的肉
