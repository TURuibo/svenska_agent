# parkera — verb (grupp 1)

📖 中文：停放（车辆）；停车 · English: to park

🇸🇪 Förklaring: ställa en bil eller ett annat fordon på en plats och lämna det där en stund

发音提示：par-KE-ra，重音在第二音节 `ke`。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | parkera |
| Presens | parkerar |
| Preteritum | parkerade |
| Supinum | parkerat |
| Imperativ | parkera |
| Perf. particip | parkerad / parkerat / parkerade |
| S-passiv | parkeras（`Cyklar får inte parkeras här.`） |

## 词组搭配 (Collocations)

- `parkera bilen / cykeln` — 停车 / 停自行车
- `parkera på gatan / på trottoaren / vid huset` — 停在街上 / 人行道上 / 房子旁
- `Det är förbjudet att parkera här.` — 此处禁止停车
- `felparkera` / `felparkerad` — 停放不当 → [[felparkerad]]
- `en parkeringsplats` / `parkering` — 停车位 / 停车 → [[parkeringsplats]]

## 例句 (Sentences)

- 🇸🇪 Från den 1 november får elsparkcyklar inte längre parkeras på trottoarerna i centrum. — 🇨🇳 从 11 月 1 日起，电动滑板车不得再停放在市中心的人行道上。 → [[sent-från-den-1-november-får-elsparkcyklar-inte]]
- 🇸🇪 I dag råder det oklarhet om var man får parkera. — 🇨🇳 目前，关于可以在哪里停车仍然不明确。 → [[sent-i-dag-råder-det-oklarhet-om-var]]
- 🇸🇪 Var kan jag parkera bilen? — 🇨🇳 我可以把车停在哪里？
- 🇸🇪 Du får inte parkera här. — 🇨🇳 你不能在这里停车。
- 🇸🇪 Vi parkerade cyklarna utanför butiken. — 🇨🇳 我们把自行车停在商店外面。
