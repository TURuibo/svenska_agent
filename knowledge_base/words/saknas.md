# saknas — verb (deponensverb)

📖 中文：失踪；缺少；被想念 · English: to be missing; to be lacking; to be missed
发音提示：["saknas"] — 重音在第一音节，-kn- 连读

## 语法变形 (Forms)

| 形式 | 变形 |
|------|------|
| grundform (infinitiv) | saknas |
| presens | saknas |
| preteritum | saknades |
| supinum | saknat(s) |
| imperativ | — (deponensverb，无主动形式) |

> **Deponensverb（被动形式动词）**：saknas 只有 s-形式，无主动形对应词。
> 主动对应词为 [[sakna]]（主动，"思念某人"）。

## 词组搭配 (Collocations)

- `saknas fortfarande` — 仍然下落不明
- `50 000 människor saknas` — 5万人失踪
- `det saknas pengar` — 缺钱（it, existential）

## 例句 (Sentences)

**义项1 — 失踪/下落不明 (be missing/unaccounted for):**
- 🇸🇪 Över 50 000 människor saknas fortfarande. — 🇨🇳 仍有5万多人下落不明。
- 🇸🇪 Barnet saknas sedan igår. — 🇨🇳 这个孩子从昨天起就失踪了。

**义项2 — 缺少/不足 (be lacking/absent):**
- 🇸🇪 Det saknas stolar i klassrummet. — 🇨🇳 教室里椅子不够。
- 🇸🇪 Vad saknas i din väska? — 🇨🇳 你包里少了什么？

**义项3 — 被思念 (be missed):**
- 🇸🇪 Du saknas varje dag. — 🇨🇳 每天都在想你。

- "sakna" (主动) = 我思念某人；"saknas" = 某人失踪/不在
