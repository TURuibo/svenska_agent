# kallas — verb

📖 中文：被称为；叫做 · English: to be called
发音提示：KAL-las（重音第一音节）

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| infinitiv (aktiv) | kalla |
| presens (aktiv) | kallar |
| preteritum (aktiv) | kallade |
| supinum (aktiv) | kallat |
| presens passiv (s-passiv) | kallas |
| preteritum passiv | kallades |
| imperativ | kalla! |

> kallas 是 kalla 的 s-passiv 形式；在"叫做/被称为"语义下，kallas/kallades 最常用

## 词组搭配 (Collocations)

- `kallas för` — 被称为
- `kallas ibland` — 有时被称为
- `vad kallas det?` — 这叫什么？

## 例句 (Sentences)

- 🇸🇪 Stockholm kallas ibland "Nordens Venedig". — 🇨🇳 斯德哥尔摩有时被称为"北欧的威尼斯"。
- 🇸🇪 T-banan kallas också tunnelbanan. — 🇨🇳 T-banan也被称为tunnelbanan（地铁）。
- 🇸🇪 Vad kallas det här på svenska? — 🇨🇳 这个用瑞典语怎么说？
