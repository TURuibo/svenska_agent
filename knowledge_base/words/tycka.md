# tycka — verb

📖 中文：觉得；认为（表达主观看法/意见） · English: to think (have an opinion), to feel
发音提示：TYCK-a（y 发短 [ʏ]）

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | tycka |
| Presens | tycker |
| Preteritum | tyckte |
| Supinum | tyckt |
| Imperativ | tycka |

## 词组搭配 (Collocations)

- `tycka om ngn/ngt` — 喜欢某人/某事（注意：tycka om = 喜欢，与 tycka 单独用法不同）
- `tycka att + bisats` — 认为/觉得……（接从句）
- `vad tycker du?` — 你觉得呢？你怎么看？
- `tycker du?` — 你认为呢？

## 例句 (Sentences)

**义项1 — 觉得/认为（表达意见）:**
- 🇸🇪 Vilken lägenhet ska Daniel välja, tycker du? — 🇨🇳 你觉得 Daniel 应该选哪套公寓？
- 🇸🇪 Jag tycker att det är viktigt att bo nära naturen. — 🇨🇳 我觉得住在大自然附近很重要。

**义项2 — tycka om（喜欢）:**
- 🇸🇪 Tycker du om att bo i stad eller på landet? — 🇨🇳 你喜欢住在城市还是乡村？

## 用法提示 (Usage Notes)

- ⚠️ **三词辨析（学习者高频混淆）：**
  - **tycka** — 表达主观看法/意见：*Jag tycker att filmen är bra.* （我觉得这部电影不错）
  - **tänka** — 思考、打算：*Jag tänker på framtiden.* （我在思考/想着未来）
  - **tro** — 相信、推测（基于信仰或不确定）：*Jag tror att det regnar imorgon.* （我认为明天会下雨）
- **tycka om** = 喜欢（≠ 单独 tycka = 认为），注意不要混淆。
- **tyckte att** 接 bisats（从句），参见 [[grammar-tyckte-att-bisats]]。
