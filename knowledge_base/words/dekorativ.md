# dekorativ — adjektiv

发音提示：de-ko-ra-TIV

| Form | Exempel |

| Neutrum sg. indef. | ett dekorativt element |
| Definite sg. | den/det dekorativa fontänen |
| Plural indef. | dekorativa lyktor |
| Plural def. | de dekorativa bänkarna |

- `dekorativa lyktor` — 装饰性路灯
- `dekorativ fontän` — 装饰性喷泉
- `dekorativt element` — 装饰性元素

## 例句 (Sentences)

- 🇸🇪 De dekorativa lyktorna längs promenadstråket är vackra på kvällen. — 🇨🇳 散步道沿线的装饰性路灯在傍晚时分十分漂亮。
- 🇸🇪 Fontänen på torget är mest dekorativ och inte funktionell. — 🇨🇳 广场上的喷泉主要是装饰性的，并不实用。
- 🇸🇪 Det dekorativa räcket längs hamnen är välskött. — 🇨🇳 港口沿线的装饰性围栏维护得很好。
