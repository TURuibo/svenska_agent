# randig — adjektiv

📖 中文：有条纹的 · English: striped
发音提示：/ˈrandɪɡ/

## 语法变形 (Forms)

| form | en-form | ett-form | plural/bestämd |
|------|---------|----------|----------------|
| positiv obestämd | en randig (zebra) | ett randigt (djur) | randiga (djur) |
| positiv bestämd | den randiga (zebran) | det randiga (djuret) | de randiga (djuren) |
| komparativ | randigare | | |
| superlativ | randigast / randigaste | | |

## 词组搭配 (Collocations)

- `randig päls` — 有条纹的皮毛
- `en randig zebra` — 一匹有条纹的斑马
- `randiga djur` — 有条纹的动物
- `en randig tröja` — 一件条纹毛衣
- `randiga strumpor` — 条纹袜子

## 例句 (Sentences)

- 🇸🇪 Zebran är svart och vit randig. — 🇨🇳 斑马是黑白条纹的。
- 🇸🇪 Hon hade en randig tröja på sig. — 🇨🇳 她穿着一件条纹毛衣。
