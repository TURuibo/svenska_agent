# mejl — substantiv

📖 中文：电子邮件 · English: email
发音提示：/mejl/（口语 /mɛjl/）

## 语法变形 (Forms)

| | 单数 | 复数 |
|---|---|---|
| 不定 | ett mejl | mejl |
| 定 | mejlet | mejlen |

## 词组搭配 (Collocations)

- `skriva ett mejl` — 写邮件
- `svara på ett mejl` — 回复邮件 → see [[svara]]
- `skicka ett mejl` — 发邮件
- `ett formellt / informellt mejl` — 正式/非正式邮件 → see [[grammar-formellt-mejl]]

## 例句 (Sentences)

- 🇸🇪 Jag skriver ett mejl till min lärare. — 🇨🇳 我给老师写一封邮件。
- 🇸🇪 Skriv ett eget svar på Ellens mejl. — 🇨🇳 给艾伦的邮件写一份你自己的回复。
- 🇸🇪 Jag fick ditt mejl i går. — 🇨🇳 我昨天收到了你的邮件。

## 词族 / 同义 / 反义 (Relations)

- 词族: mejla（动词，发邮件；未建条目）
- 同义: e-post（更正式的写法）
