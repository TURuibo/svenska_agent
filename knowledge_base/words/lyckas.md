# lyckas — verb (deponens)

📖 中文：成功、做成（某事） · English: to succeed, manage

🇸🇪 Förklaring: klara av att göra det som man har försökt eller velat

发音提示：/ˈlʏkːas/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) lyckas |
| Presens | lyckas |
| Preteritum | lyckades |
| Supinum | lyckats |

deponens 动词：形式上带 -s，意思却是主动的（"成功"，不是"被……"）；没有不带 -s 的形式 → [[grammar-deponensverb]]

## 词组搭配 (Collocations)

- `lyckas med något` — 在某事上取得成功
- `lyckas (att) göra något` — 成功做到某事（att 常省略）
- `misslyckas` — 失败

## 例句 (Sentences)

- 🇸🇪 Vi lyckas med patientsäkerhetsarbetet. — 🇨🇳 我们在患者安全工作上取得了成功。
- 🇸🇪 Jag lyckades till slut öppna dörren. — 🇨🇳 我终于把门打开了。
- 🇸🇪 Hon har lyckats bra i sitt nya jobb. — 🇨🇳 她在新工作里干得很成功。
