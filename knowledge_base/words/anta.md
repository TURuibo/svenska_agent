# anta — verb (grupp 4, 不规则强变化)

📖 中文：假设；认为；录取；通过（法案） · English: to assume; to suppose; to accept; to adopt

🇸🇪 Förklaring: tro att något är sant utan att veta säkert; ge någon plats på en utbildning; besluta att ett förslag ska gälla

发音提示：AN-ta，重音在第一音节；`an-` 是词头，不要读成 `an-ta`.

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | anta |
| Presens | antar |
| Preteritum | antog |
| Supinum | antagit |
| Imperativ | anta |
| S-passiv | antas / antogs |

变位与 `ta`（tar – tog – tagit）相同。

## 词组搭配 (Collocations)

- `anta att + 从句` — 假设 / 以为……
- `det antas att …` — 一般认为……
- `antas till (utbildning)` — 被（专业/课程）录取
- `anta en lag / ett förslag / en budget` — 通过一项法律 / 提案 / 预算
- `anta en utmaning` — 接受挑战

## 例句 (Sentences)

**义项1 假设 / 认为 (assume):**

- 🇸🇪 Jag antar att du är hungrig. — 🇨🇳 我想你饿了。
- 🇸🇪 Vi antar att tåget kommer i tid. — 🇨🇳 我们假定火车会准时到。
- 🇸🇪 Några antar att tonåringar kan umgås hemma eller i centrum. — 🇨🇳 有些人认为青少年可以在家或在市中心聚在一起。 → [[sent-några-antar-att-tonåringar-kan-umgås]]

**义项2 录取 / 接受 (be accepted to a programme):**

- 🇸🇪 Hon antogs till universitetet i Uppsala. — 🇨🇳 她被乌普萨拉大学录取了。

**义项3 通过 / 采纳 (adopt a law, plan):**

- 🇸🇪 Kommunen antog budgeten i går. — 🇨🇳 市政府昨天通过了预算。

## 用法提示 (Usage Notes)

- 义项1 的语气比 `tro` 更"推理"：`anta` = 根据已有信息做合理假设，常用于论说文引出对方的前提（`Några antar att …`）。
- 后接 **att-从句**，见 [[grammar-att-bisats]]。
- 不规则变位：antar / **antog** / antagit，与 `ta` 一样。
