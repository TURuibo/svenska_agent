# upprepa — verb

📖 中文：重复 · English: to repeat

🇸🇪 Förklaring: göra eller säga något en gång till

发音提示：/ˈɵpˌreːpa/ — 重音在 upp-；rep 长音 eː

## 语法变形 (Forms)

| 形式 | 例 |
|---|---|
| infinitiv | upprepa |
| presens | upprepar |
| preteritum | upprepade |
| supinum | upprepat |

## 词组搭配 (Collocations)

- `upprepa ett misstag` — 重蹈覆辙
- `upprepa sig` — 重复自己的话

## 例句 (Sentences)

- 🇸🇪 Jag ville inte upprepa samma misstag. — 🇨🇳 我不想重蹈覆辙。
- 🇸🇪 Kan du upprepa frågan? — 🇨🇳 你能重复一下问题吗？
- 🇸🇪 Historien upprepar sig. — 🇨🇳 历史重演。
