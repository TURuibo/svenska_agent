# gym — substantiv

📖 中文：健身房 · English: gym
发音提示：/jym/，y 读圆唇前元音

## 语法变形 (Forms)

| | 单数 | 复数 |
|---|---|---|
| 不定 | ett gym | gym |
| 定 | gymmet | gymmen |

## 词组搭配 (Collocations)

- `gå till gymmet` — 去健身房
- `träna på gym` — 在健身房锻炼 → see [[träna]]
- `sätta sin fot på ett gym` — 踏进健身房 → see [[sätta-sin-fot]]

## 例句 (Sentences)

- 🇸🇪 Jag går till gymmet tre gånger i veckan. — 🇨🇳 我每周去三次健身房。
- 🇸🇪 Det finns ett stort gym nära min skola. — 🇨🇳 我学校附近有一个大健身房。
- 🇸🇪 Jag som aldrig satt min fot på ett gym. — 🇨🇳 我这个从来没进过健身房的人。
