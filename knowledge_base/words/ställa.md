# ställa — verb (grupp 2a)

📖 中文：（竖着）放；提出（问题） · English: to put (upright); to ask (a question)
发音提示：/ˈstɛlːa/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) ställa |
| Presens | ställer |
| Preteritum | ställde |
| Supinum | ställt |
| Imperativ | ställ! |

grupp 2a（-er/-de/-t）。

## 词组搭配 (Collocations)

- `ställa en fråga` — 提问
- `ställa krav` — 提出要求 → see [[ställa-krav]]
- `ställa in` — 取消；调整 → see [[ställa-in]]
- `ställa upp` — 帮忙；参选 → see [[ställa-upp]]
- `ställa sig` — 站到（某处）

## 例句 (Sentences)

**义项1 竖着放 (put upright):**
- 🇸🇪 Jag ställde glaset på bordet. — 🇨🇳 我把杯子放在桌上。

**义项2 提出 (ask/pose):**
- 🇸🇪 Får jag ställa en fråga? — 🇨🇳 我可以问个问题吗？
- 🇸🇪 Läraren ställde många frågor. — 🇨🇳 老师提了很多问题。

## 词族 / 同义 / 反义 (Relations)

- 词族: [[stå]]（状态 ↔ 动作）、[[ställa-in]]、[[ställa-upp]]、[[ställa-krav]]

## 用法提示 (Usage Notes)

- `stå` = 状态（立着）；`ställa` = 动作（把…立起来）。ställa 的“竖/立”对比 `lägga`（平放）、`sätta`（放置/坐下）。
