# vattenläckage — substantiv (ett)

📖 中文：漏水；水管渗漏 · English: water leak
发音提示：/ˈvatːɛnˌlɛkːaːɧɛ/

## 语法变形 (Forms)

| 形式 | 写法 |
|------|------|
| 不定式单数 | ett vattenläckage |
| 定式单数 | vattenläckaget |
| 不定式复数 | vattenläckage |
| 定式复数 | vattenläckagena |

## 词组搭配 (Collocations)

- `ett vattenläckage i köket` — 厨房漏水
- `anmäla ett vattenläckage` — 报告漏水故障
- `orsaka vattenläckage` — 造成漏水

## 例句 (Sentences)

- 🇸🇪 Det var ett stort vattenläckage i källaren igår. — 🇨🇳 昨天地下室发生了严重漏水。
- 🇸🇪 Vi upptäckte vattenläckaget för sent. — 🇨🇳 我们发现漏水时已经太晚了。
- 🇸🇪 Vattenläckage kan orsaka stora skador på huset. — 🇨🇳 漏水会给房屋造成严重损坏。
