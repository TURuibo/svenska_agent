# väcka — verb (grupp 2a)

📖 中文：叫醒（他人） · English: to wake (someone) up
发音提示：VECK-a；两音节，重音在首音节。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | att väcka |
| Imperativ | väck! |
| Presens | väcker |
| Preteritum | väckte |
| Supinum | (har) väckt |

## 词组搭配 (Collocations)

- `väcka barnen` — 叫孩子们起床
- `väcka ngn tidigt` — 早早叫醒某人
- `väckarklocka` — 闹钟（字面：叫醒钟）

## 例句 (Sentences)

- 🇸🇪 Jag **väcker** barnen klockan sju varje morgon. — 🇨🇳 我每天早上七点叫孩子们起床。
- 🇸🇪 Kan du **väcka** mig klockan sex imorgon? — 🇨🇳 你明天能六点叫醒我吗？
- 🇸🇪 Hon **väckte** sin man när det ringde på dörren. — 🇨🇳 门铃响时她把丈夫叫醒了。

## 词族 / 同义 / 反义 (Relations)

- 词族: [[vakna]] (v. 自己醒来, intransitiv), [[vaken]] (adj. 醒着的)
- 同义词: —
- 反义词: [[somna]] (v. 入睡)
- 主题: [[topic-vardagsrutin]]

## 用法提示 (Usage Notes)

- `väcka` = 及物动词，叫醒**别人**；`vakna` = 不及物动词，**自己**醒来。
- 对比: *Jag vaknar kl. 6.* (我六点醒来) vs *Jag väcker barnen kl. 6.* (我六点叫孩子们起床)
