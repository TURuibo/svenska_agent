# fundera — verb (grupp 1)

📖 中文：思考、琢磨 · English: to ponder, think about
发音提示：/fɵnˈdeːra/（重音在 -de-）

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) fundera |
| Presens | funderar |
| Preteritum | funderade |
| Supinum | funderat |
| Imperativ | fundera! |

## 词组搭配 (Collocations)

- `fundera på …` — 考虑……（文中：funderade på om det var värt det）→ see [[vara-värt-det]]
- `fundera på att + inf.` — 考虑要不要……
- `fundera över …` — 琢磨……
- `fundera ut` — 想出来、弄明白

## 例句 (Sentences)

- 🇸🇪 Nils började tvivla på sin satsning och funderade på om det var värt det. — 🇨🇳 Nils 开始怀疑自己的投入，思考这一切是否值得。
- 🇸🇪 Jag funderar på att köpa en ny cykel. — 🇨🇳 我在考虑买一辆新自行车。
- 🇸🇪 Hon funderade en stund innan hon svarade. — 🇨🇳 她想了一会儿才回答。
- 🇸🇪 Fundera på saken och ring mig sedan! — 🇨🇳 你好好想想这件事，然后给我打电话！

## 用法提示 (Usage Notes)

- 规则第 1 组动词（外来词，以 -era 结尾）：fundera – funderar – funderade – funderat。
- 搭配固定用 **på**：fundera **på** något。后接从句时可用 `på om …`（是否……）或 `på hur …`（如何……），如文中 `funderade på om det var värt det`。
- 比 `tänka` 更强调「反复思量、斟酌」。
