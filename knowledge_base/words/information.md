# information — substantiv (en)

📖 中文：信息；资料；说明 · English: information

🇸🇪 Förklaring: kunskap eller uppgifter om något som man får genom text, tal eller bild

发音提示：/ɪnfɔrmaˈɧuːn/ — 重音在 -tion；-tion 读 /ɧuːn/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Obestämd singular | information |
| Bestämd singular | informationen |
| Obestämd plural | informationer |
| Bestämd plural | informationerna |

> 通常用单数不可数：`mycket information`。

## 词组搭配 (Collocations)

- `få information om` — 获得关于……的信息
- `läsa informationen` — 阅读信息
- `söka information` — 查找信息
- `ge information` — 提供信息

## 例句 (Sentences)

- 🇸🇪 Läs informationen från WWF och para ihop rätt rubrik vid rätt stycke. — 🇨🇳 阅读 WWF 的信息，把正确的标题配到正确的段落。
- 🇸🇪 Du hittar mer information på webbplatsen. — 🇨🇳 你可以在网站上找到更多信息。
- 🇸🇪 Jag behöver information om bussarna. — 🇨🇳 我需要关于公交车的信息。
