# samlas — verb (deponens)

📖 中文：聚集，聚会 · English: to gather, to assemble
发音提示：[ˈsɑːmlas]

## 语法变形 (Forms)

| tid | form |
|-----|------|
| infinitiv | samlas |
| presens | samlas |
| preteritum | samlades |
| supinum | samlats |

> **Deponens-verb**: 形式上是被动（-s 结尾），意义上是主动。参见 [[grammar-deponensverb]]。

## 词组搭配 (Collocations)

- `samlas för att fira` — 聚集庆祝
- `samlas utomhus` — 在户外聚集
- `samlas kring bordet` — 围坐在桌旁

## 例句 (Sentences)

- 🇸🇪 Många människor samlas i parken på midsommarafton. — 🇨🇳 仲夏节前夕许多人聚集在公园里。
- 🇸🇪 Familjen samlas för att äta middag tillsammans. — 🇨🇳 家人聚在一起共进晚餐。
- 🇸🇪 Studenterna samlas utanför skolan. — 🇨🇳 学生们聚集在学校外面。

## 词族 / 同义 / 反义 (Relations)

- 词族: samla (收集，召集，及物动词)

## 用法提示 (Usage Notes)

- Deponens-verb: `samlas` 是 `samla`（召集/收集）的反身/deponens 形式，意为"聚集"（自发地聚到一起）。
- 与 `samla` 区别：`samla frimärken`（收集邮票）vs. `samlas i parken`（在公园聚集）。
