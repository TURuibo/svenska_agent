# bit — substantiv (en)

📖 中文：一块；一片；一点 · English: piece; slice; bit
发音提示：/biːt/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Singular obestämd | en bit |
| Singular bestämd | biten |
| Plural obestämd | bitar |
| Plural bestämd | bitarna |

## 词组搭配 (Collocations)

- `en bit kaka` — 一块蛋糕
- `en bit bröd` — 一片面包
- `en liten bit` — 一小块
- `lite till / en bit till` — 再来一点

## 例句 (Sentences)

- 🇸🇪 Då tar jag en bit morotskaka, tack. — 🇨🇳 那我要一块胡萝卜蛋糕，谢谢。
- 🇸🇪 Kan jag få en bit bröd till soppan? — 🇨🇳 能给我一片面包配汤吗？
- 🇸🇪 Vill du ha en liten bit tårta? — 🇨🇳 你想要一小块蛋糕吗？

## 词族 / 同义 / 反义 (Relations)

- 词族: bita（咬）
- 同义词: stycke（块/件）
- 主题: [[topic-mat-dryck]]

## 用法提示 (Usage Notes)

- `en bit` + 名词：用于数量表达"一块/一片"，类似英语 "a piece of"。
- 不可与 `ett stycke` 混淆：`stycke` 更指成件的东西，`bit` 更强调是从整体切/掰下的一部分。
