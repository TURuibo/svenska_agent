# förskola — substantiv (en)

📖 中文：幼儿园；学前班 · English: preschool
发音提示：**för**-sko-la，重音在第一音节。

| Singular bestämd | förskolan |
| Plural obestämd | förskolor |
| Plural bestämd | förskolorna |

## 词组搭配 (Collocations)

- `plats på förskolan` — 幼儿园名额
- `söka till förskolan` — 申请幼儿园 → [[söka-till]]
- `förskolan e-tjänst` — 幼儿园电子服务平台 → [[e-tjänst]]

  🇨🇳 你的孩子已获得一所幼儿园的入园名额。

  🇨🇳 孩子们一岁时开始上幼儿园。

  🇨🇳 这个地区有很多好的幼儿园。

## 用法提示 (Usage Notes)

- 瑞典公立幼儿园面向 1–5 岁儿童，由 kommunen（市政府）管理。
- 属于瑞典福利制度的重要组成部分，大多数家庭通过 e-tjänst 在线申请。
- 注意区分：`förskola`（学前教育/幼儿园）vs `skola`（学校，小学起）。
