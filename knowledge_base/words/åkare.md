# åkare — substantiv (en)

📖 中文：（滑冰/滑雪/驾驶的）人；货运商 · English: skater, skier, rider; haulier
发音提示：/ˈoːkare/

## 语法变形 (Forms)

| | obestämd | bestämd |
|---|---|---|
| singular | en åkare | åkaren |
| plural | åkare | åkarna |

## 词组搭配 (Collocations)

- `skridskoåkare` — 滑冰运动员 → [[skridskoåkare]]
- `skidåkare` — 滑雪者
- `den snabbaste åkaren` — 最快的选手

## 例句 (Sentences)

**义项1 运动中"滑/骑/驾"的人 (-åkare 复合词):**

- 🇸🇪 Nils var den snabbaste åkaren i loppet. — 🇨🇳 Nils 是比赛中最快的滑冰者。
- 🇸🇪 Många åkare väntar vid startlinjen. — 🇨🇳 许多选手在起跑线等候。

**义项2 货运商（较旧）:**

- 🇸🇪 Åkaren körde möblerna till det nya huset. — 🇨🇳 货运商把家具运到新房子。
