# korsning — substantiv (en)

📖 中文：十字路口；交叉口 · English: intersection / crossroads
发音提示：KORS-ning；两音节，重音在首音节。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Singular obestämd | en korsning |
| Singular bestämd | korsningen |
| Plural obestämd | korsningar |
| Plural bestämd | korsningarna |

## 词组搭配 (Collocations)

- `vid korsningen` — 在十字路口
- `sväng höger vid korsningen` — 在十字路口向右转
- `en trafikerad korsning` — 一个繁忙的十字路口

## 例句 (Sentences)

- 🇸🇈 Vid **korsningen** **blinkar** trafikljuset rött. — 🇨🇳 在十字路口，交通灯闪烁红色。
- 🇸🇈 Sväng till vänster vid nästa **korsning**. — 🇨🇳 在下一个十字路口向左转。
- 🇸🇈 Det finns en **korsning** med trafikljus lite längre fram. — 🇨🇳 再往前一点有一个设有交通灯的十字路口。
