# påträngande — adjektiv

📖 中文：冒昧的、打扰的 · English: intrusive

## 语法变形 (Forms)

不变化（以 -ande 结尾的形容词，各性数同形）：påträngande

## 词组搭配 (Collocations)

- `kännas påträngande` — 显得冒昧
- `uppfattas som påträngande` — 被视为冒昧 → see [[uppfatta]]

## 例句 (Sentences)

- 🇸🇪 Frågan om hans lön kändes påträngande. — 🇨🇳 问他工资这个问题显得很冒昧。
- 🇸🇪 Ett spontant besök utan förvarning kan uppfattas som påträngande. — 🇨🇳 没有预先通知的突然拜访可能被视为冒昧。
- 🇸🇪 Hon tyckte att frågorna var för påträngande. — 🇨🇳 她觉得这些问题太冒昧了。
