# umgås — verb (deponens, 不规则强变化)

📖 中文：交往；相处；一起玩 / 聚在一起 · English: to socialise; to hang out; to spend time (with)
发音提示：UM-gås，重音在第一音节；`g` 在 å 前读 [g]。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | umgås |
| Presens | umgås |
| Preteritum | umgicks |
| Supinum | umgåtts |
| Imperativ | umgås! |

⚠️ 只有 **-s 形式**（deponens：形式是被动、意思是主动），没有 ~~umgå~~ 这样的主动形式，见 [[grammar-deponensverb]]。变位与 `gå`（går – gick – gått）同类。

## 词组搭配 (Collocations)

- `umgås med någon` — 和某人来往 / 相处
- `umgås med vänner / kompisar` — 和朋友们相处
- `umgås hemma` — 在家聚会
- `de umgås mycket` — 他们经常来往
- `umgås i samma kretsar` — 交际圈相同

## 例句 (Sentences)

- 🇸🇪 Vi umgås ofta på helgerna. — 🇨🇳 我们周末经常聚在一起。
- 🇸🇪 Hon umgås mest med sina kollegor. — 🇨🇳 她主要和同事来往。
- 🇸🇪 Tonåringar vill umgås med kompisar. — 🇨🇳 青少年想和朋友们在一起。
- 🇸🇪 Vi umgicks mycket när vi var små. — 🇨🇳 我们小时候经常一起玩。
- 🇸🇪 Några antar att tonåringar kan umgås hemma eller i centrum. — 🇨🇳 有些人认为青少年可以在家或在市中心聚在一起。 → [[sent-några-antar-att-tonåringar-kan-umgås]]

## 词族 / 同义 / 反义 (Relations)

- 词族: `umgänge`（来往；交际圈）、`umgängeskrets`（朋友圈）
- 同义词: `träffas`（见面）、`hänga`（口语：闲逛）
- 反义词: `isolera sig`（与世隔绝）
- 主题: [[topic-social-kontakt]]

## 用法提示 (Usage Notes)

- 强调**一段时间的相处 / 社交**，不是一次性的"见面"（那是 `träffas` / `ses`）。
- `umgås` 后面直接接 `med`；表示"互相"来往时，本身已是 s-动词，不需要再加 `varandra`。
