# underställ — substantiv

📖 中文：保暖内衣 · English: base layer; thermal underwear
发音提示：/ˈɵndɛrˌstɛlː/ — under- 短 u（像英语 "oon" 短），-ställ 短 ä 带长 l

## 语法变形 (Forms)

| 形式 | 瑞典语 |
|------|--------|
| obestämd sing. | ett underställ |
| bestämd sing. | understället |
| obestämd plur. | underställ |
| bestämd plur. | underställen |

## 词组搭配 (Collocations)

- `underställ i ull` — 羊毛保暖内衣 → see [[ull]]
- `ta på understället` — 穿上保暖内衣
- `underställ och fleece` — 保暖内衣和抓绒衣 → see [[fleece]]
- `lager på lager` — 多层穿衣 → see [[lager-på-lager]]

## 例句 (Sentences)

- 🇸🇪 I lådan: underställ i ull och fleece. — 🇨🇳 箱子里：羊毛保暖内衣和抓绒衣。
- 🇸🇪 På vintern har barnen underställ under overallen. — 🇨🇳 冬天孩子们在连体外套里面穿保暖内衣。
- 🇸🇪 Vi behöver köpa ett nytt underställ, det gamla är för litet. — 🇨🇳 我们得买一套新的保暖内衣，旧的太小了。
- 🇸🇪 Understället ligger i lådan. — 🇨🇳 保暖内衣在箱子里。

## 用法提示 (Usage Notes)

- ett-词，单复数同形：*ett underställ, två underställ*。指**上下一套**的贴身保暖层。
- 瑞典幼儿园的 *lager på lager* 穿衣法：**underställ**（最里层）→ fleece（中层）→ overall（外层）。
- 材质常用 *ull*（羊毛）或 *syntet*；说材质用 **i**：*underställ i ull*。
