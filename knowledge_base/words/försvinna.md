# försvinna — verb (oregelbundet)

📖 中文：消失 · English: to disappear
发音提示：/fœrˈsvɪna/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | försvinna |
| Presens | försvinner |
| Preteritum | försvann |
| Supinum | försvunnit |
| Imperativ | försvinn |
| Perfekt particip | försvunnen / försvunnet / försvunna |

## 词组搭配 (Collocations)

- `försvinna spårlöst` — 消失得无影无踪
- `folk som försvunnit` — 失踪的人
- `försvinna i luften` — 凭空消失
- `låta någon försvinna` — 让某人消失

## 例句 (Sentences)

- 🇸🇪 Många människor måste leta själva efter folk som försvunnit. — 🇨🇳 许多人不得不自己去寻找失踪的亲人。
- 🇸🇪 Smärtan försvann efter att hon tog medicinen. — 🇨🇳 吃了药之后，她的疼痛消失了。
- 🇸🇪 Katten försvann i tre dagar och kom sedan tillbaka. — 🇨🇳 猫消失了三天，然后回来了。
- 🇸🇪 Varje år försvinner tusentals människor i världen. — 🇨🇳 每年世界上有数千人失踪。

## 用法提示 (Usage Notes)

- 不规则强变位动词：försvinna → försvinner → försvann → försvunnit
- 注意 perfekt: *har försvunnit* (消失了) vs. preteritum: *försvann* (消失了，叙事用)
- 形容词形式：*en försvunnen person* = 一个失踪的人
