# enkel — adjektiv

📖 中文：简单的；容易的；单一的 · English: simple; easy; single
发音提示：/ˈɛŋkɛl/

## 语法变形 (Forms)

| form | exempel |
|------|---------|
| en-form (grundform) | enkel |
| ett-form | enkelt |
| plural / bestämd | enkla |
| komparativ | enklare |
| superlativ | enklast |

## 词组搭配 (Collocations)

- `en enkel fråga` — 一个简单的问题
- `enkelbiljett` — 单程票
- `på ett enkelt sätt` — 用简单的方式

## 例句 (Sentences)

- 🇸🇪 Det här är en enkel uppgift. — 🇨🇳 这是一个简单的任务。
- 🇸🇪 Kan du förklara det på ett enkelt sätt? — 🇨🇳 你能用简单的方式解释吗？
- 🇸🇪 Vi åker enkelbiljett till Stockholm. — 🇨🇳 我们买单程票去斯德哥尔摩。

## 词族 / 同义 / 反义 (Relations)

- 词族: enkelhet (简单性), enkelbiljett (单程票), enkelriktad (单向的)
- 同义词: lätt (容易的)
- 反义词: [[svår]] (难的), komplicerad (复杂的)
- 主题: [[topic-karaktarsord]]

## 用法提示 (Usage Notes)

- `enkel` 有两个主要义：1) 简单/容易；2) 单一的（如 enkelbiljett 单程票）。
- `lätt` 侧重"容易做到"，`enkel` 侧重"不复杂"。
