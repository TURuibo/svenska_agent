# sällskap — substantiv

📖 中文：陪伴；同伴；组织 · English: company; companionship; group; society
发音提示：/ˈsɛlːʃap/

## 语法变形 (Forms)

| form | exempel |
|------|---------|
| singular obestämd | ett sällskap |
| singular bestämd | sällskapet |
| plural obestämd | sällskap |
| plural bestämd | sällskapen |

## 词组搭配 (Collocations)

- `hålla någon sällskap` — 陪伴某人 → see [[hålla-någon-sällskap]]
- `tack för sällskapet` — 谢谢陪伴 → see [[tack-för-sällskapet]]
- `i gott sällskap` — 在好的陪伴下；身处好的圈子

- 🇸🇪 Vi reste i ett sällskap på tio personer. — 🇨🇳 我们一行十人旅行。
