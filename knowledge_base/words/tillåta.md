# tillåta — verb (grupp 4, oregelbundet)

📖 中文：允许 · English: to allow
发音提示：/ˈtɪlːˌoːta/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) tillåta |
| Presens | tillåter |
| Preteritum | tillät |
| Supinum | tillåtit |
| Imperativ | tillåt! |

## 词组搭配 (Collocations)

- `barn tilläts tävla` — 孩子被允许参加比赛

## 例句 (Sentences)

- 🇸🇪 Det som lockade var att barn tilläts tävla. — 🇨🇳 吸引他的是孩子可以参加比赛。
- 🇸🇪 Läraren tillåter inte mobiler i klassrummet. — 🇨🇳 老师不允许在教室里用手机。
- 🇸🇪 Vi tillåts ha husdjur i lägenheten. — 🇨🇳 我们被允许在公寓里养宠物。
