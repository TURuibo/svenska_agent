# projektledare — substantiv (en)

📖 中文：项目负责人 · English: project manager

🇸🇪 Förklaring: person som leder och planerar ett projekt

发音提示：/prɔˈjɛktˌleːdare/ — 重音在 `jekt`，复合词次重音在 `led`

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Singular obestämd | en projektledare |
| Singular bestämd | projektledaren |
| Plural obestämd | projektledare |
| Plural bestämd | projektledarna |

## 词组搭配 (Collocations)

- `projektledare för …` — …的项目负责人
- `bli projektledare` — 成为项目负责人

## 例句 (Sentences)

- 🇸🇪 Projektledaren Karin Lund talar med journalisterna. — 🇨🇳 项目负责人卡琳·伦德与记者交谈。
- 🇸🇪 Han jobbar som projektledare på ett byggföretag. — 🇨🇳 他在建筑公司做项目负责人。
- 🇸🇪 Projektledaren planerar arbetet vecka för vecka. — 🇨🇳 项目负责人逐周规划工作。
