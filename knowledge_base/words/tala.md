# tala — verb (grupp 1)

📖 中文：说话；讲(语言) · English: to speak; to talk

🇸🇪 Förklaring: använda rösten för att säga ord; kunna använda ett visst språk muntligt

发音提示：/ˈtɑːla/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) tala |
| Presens | talar |
| Preteritum | talade |
| Supinum | talat |
| Imperativ | tala! |
| S-passiv presens | talas |
| S-passiv supinum | talats |

## 词组搭配 (Collocations)

- `höra talas om` — 听说过
- `tala svenska` — 说瑞典语

## 例句 (Sentences)

- 🇸🇪 Han hade hört talats om sådana bedrägerier förut. — 🇨🇳 他以前听说过这类诈骗。
- 🇸🇪 Hon talar tre språk. — 🇨🇳 她会说三种语言。
- 🇸🇪 Kan du tala lite långsammare? — 🇨🇳 你能说慢一点吗？
