# bry — verb (grupp 3)

📖 中文：在乎、关心（几乎只用反身 **bry sig (om)**）· English: to care / bother
发音提示：bry [bryː]；长 y（圆唇），单音节。

## 语法变形 (Forms)

| Tempus | Swedish |
|--------|---------|
| Infinitiv | (att) bry |
| Presens | **bryr** |
| Preteritum | brydde |
| Supinum | brytt |
| Imperativ | bry! |

> grupp 3：preteritum `-dde`、supinum `-tt`（brydde / brytt）。
> 你输入的 `bry` 是 **infinitiv/词干**。

## 词组搭配 (Collocations)

- `bry sig om (något/någon)` — 在乎、关心某事/某人
- `bry sig` — 理会、上心（口语，常用于否定）
- `inte bry sig` — 不在乎、不理
- `bry dig inte om det` — 别管那个 / 别在意

## 例句 (Sentences)

- 🇸🇪 Jag bryr mig om dig. — 🇨🇳 我在乎你。
- 🇸🇪 Han bryr sig inte om vad andra tycker. — 🇨🇳 他不在乎别人怎么想。
- 🇸🇪 Bry dig inte om det! — 🇨🇳 别理那事 / 别放在心上！

## 用法提示 (Usage Notes)

- ⚠️ 几乎永远带反身 + `om`：**bry sig om**。光 `bry` 不单用。
- 反身代词随主语：jag bryr **mig**, du bryr **dig**, han bryr **sig** …
- 否定句最常见：`inte bry sig om` = 满不在乎。
