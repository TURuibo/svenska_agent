# vass — adjektiv

📖 中文：锋利的 · English: sharp
发音提示：/vasː/

## 语法变形 (Forms)

| form | en-form | ett-form | plural/bestämd |
|------|---------|----------|----------------|
| positiv obestämd | en vass (tand) | ett vasst (djur) | vassa (tänder) |
| positiv bestämd | den vassa (tanden) | det vassa (djuret) | de vassa (tänderna) |
| komparativ | vassare | | |
| superlativ | vassast / vassaste | | |

**Obs:** ett-form *vasst* (dubbel-t).

## 词组搭配 (Collocations)

- `vassa tänder` — 锋利的牙齿
- `vassa klor` — 锋利的爪子
- `en vass kniv` — 一把锋利的刀
