# skjuta — verb

📖 中文：射击，开枪；推动；发射 · English: to shoot; to push; to fire
发音提示：/ˈʂʉːta/

## 语法变形 (Forms)

| form | form |
|------|------|
| infinitiv | skjuta |
| presens | skjuter |
| preteritum | sköt |
| supinum | skjutit |
| imperativ | skjut |

⚠️ 强变化动词（starka verb）—— preteritum 是 **sköt**，勿和 `sköta`（照料）混淆！

## 词组搭配 (Collocations)

- `skjuta skott` — 开枪，鸣枪
- `skjuta mot` — 向……射击
- `skjuta för att varna` — 开枪示警
- `skjuta upp` — 推迟；发射（火箭）

## 例句 (Sentences)

**义项1：射击**
- 🇸🇪 [[sent-ett-ryskt-militärfartyg-sköt-skott]] Ett ryskt militärfartyg sköt skott mot en civil båt. — 🇨🇳 一艘俄罗斯军舰向一艘民用船只开了枪。
- 🇸🇪 [[sent-ryssland-säger-att-de-sköt]] Ryssland säger att de sköt för att varna båten. — 🇨🇳 俄罗斯称他们开枪是为了警告这艘船。
- 🇸🇪 [[sent-det-är-mycket-ovanligt-att-skjuta]] Det är mycket ovanligt att skjuta mot en civil båt. — 🇨🇳 向民用船只开枪是非常罕见的。

- `sköt skott` = 开了枪（固定搭配，字面义：射出了枪声）
