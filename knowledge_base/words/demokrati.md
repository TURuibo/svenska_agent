# demokrati — substantiv (en)

📖 中文：民主 · English: democracy
发音提示：de-mo-kra-TI；重音在最后一个音节。

## 语法变形 (Forms)

| Form | Swedish |

| Singular obestämd | en demokrati |
| Singular bestämd | demokratin |
| Plural obestämd | demokratier |
| Plural bestämd | demokratierna |

## 词组搭配 (Collocations)

- `demokratin minskar` — 民主在削减
- `hot mot demokratin` — 对民主的威胁
- `frågor om demokratin` — 关于民主的议题

## 例句 (Sentences)

- 🇸🇈 Sverige är en demokrati med fria val. — 🇨🇳 瑞典是一个拥有自由选举的民主国家。
- 🇸🇈 Experter varnar för att demokratin minskar i Europa. — 🇨🇳 专家警告欧洲的民主正在萎缩。
- 🇸🇈 Artisterna ville visa att demokratin är viktig. — 🇨🇳 艺术家们想表明民主的重要性。
