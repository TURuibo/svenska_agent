# leva — verb

📖 中文：生活；活着；生存 · English: to live; to be alive
发音提示：重音在第一音节：**LE-va**。`e` 常读长音。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | att leva |
| Imperativ | lev! |
| Presens | lever |
| Preteritum | levde |
| Supinum | (har) levt |

不规则动词，过去式和 supinum 需要单独记：`levde` / `levt`。

## 词组搭配 (Collocations)

- `leva i Sverige` — 生活在瑞典
- `leva tillsammans` — 一起生活
- `leva kvar` — 继续存在；仍然留存
- `leva på ngt` — 靠某物生活

## 例句 (Sentences)

- 🇸🇪 Hon **lever** i Stockholm nu.
  🇨🇳 她现在住在斯德哥尔摩。
- 🇸🇪 Många gamla traditioner **lever kvar**.
  🇨🇳 很多古老传统依然保留着。
- 🇸🇪 De vill **leva** ett lugnt liv.
  🇨🇳 他们想过平静的生活。

## 用法提示 (Usage Notes)

- `lever` 是 `leva` 的现在时，意思是“活着/生活着”。
- `leva` 既可表示生物意义上的“活着”，也可表示“过某种生活”。
- `leva kvar` 是常见搭配，和 `kvar` 一起表示“仍然存在、依然保留”。
