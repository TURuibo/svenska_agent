# överlägsen — adjektiv

📖 中文：优越的；压倒性的；傲慢的 · English: superior; overwhelming

🇸🇪 Förklaring: som är mycket bättre eller starkare än andra; som beter sig som om man vore bättre än andra

发音提示：/ˈøːvɛrˌleːɡsen/

| Utrum | överlägsen |
| Neutrum / adverb | överlägset |
| Plural / bestämd | överlägsna (去掉 -e-) |
| Komparativ | mer överlägsen |
| Superlativ | mest överlägsen |

## 词组搭配 (Collocations)

- `vinna överlägset` — 以压倒性优势获胜 → [[grammar-adverb-av-adjektiv]]
- `en överlägsen seger` — 压倒性的胜利
- `överlägsen någon` — 优于某人；（态度）高高在上

## 例句 (Sentences)

**义项1 压倒性的、远胜的 (adjektiv / adverb överlägset):**

- 🇸🇪 Han vann överlägset. — 🇨🇳 他以压倒性优势获胜。
- 🇸🇪 Laget var överlägset i andra halvlek. — 🇨🇳 球队在下半场占绝对上风。

**义项2 傲慢的、居高临下的:**

- 🇸🇪 Han log på ett överlägset sätt. — 🇨🇳 他以居高临下的方式笑了笑。
