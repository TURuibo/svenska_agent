# anteckning — substantiv

📖 中文：笔记，记录 · English: note

🇸🇪 Förklaring: kort text som man skriver för att komma ihåg något

发音提示：/ˈanːtɛkˌnɪŋ/ — 重音在 an；k 与 n 分别发音，ing 读 /ɪŋ/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Obestämd singular | en anteckning |
| Bestämd singular | anteckningen |
| Obestämd plural | anteckningar |
| Bestämd plural | anteckningarna |

## 词组搭配 (Collocations)

- `göra anteckningar` — 做笔记
- `ta anteckningar` — 记笔记
- `en utförlig anteckning` — 一条详细的记录

## 例句 (Sentences)

- 🇸🇪 Jag gör anteckningar på lektionen. — 🇨🇳 我在课上做笔记。
- 🇸🇪 Hon läste sina anteckningar före provet. — 🇨🇳 她在考试前看了自己的笔记。
- 🇸🇪 Anteckningen ligger i den gula pärmen. — 🇨🇳 笔记放在黄色文件夹里。
