# stad — substantiv (en-ord)

📖 中文：城市；市镇 · English: city, town
发音提示：/stɑːd/

## 语法变形 (Forms)

| | Singular | Plural |
|---|---|---|
| **Obestämd** | en stad | städer |
| **Bestämd** | staden | städerna |

注意：plural obestämd 为 `städer`（元音变换 a→ä，不规则变化）。

## 词组搭配 (Collocations)

- `populär stad` — 受欢迎的城市 → see [[populär]]
- `central stad` — 中心城市 → see [[central]]
- `in i stan` — 进城（口语 `stan` = `staden`） → see [[stan]]
