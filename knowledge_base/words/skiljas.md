# skiljas — verb (deponens)

📖 中文：离婚 / 分开 · English: to divorce / to separate / to part
发音提示：['ʃɪljas]

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | skiljas |
| Presens | skiljs |
| Preteritum | skildes |
| Supinum | skilts |

Deponensverb: passiv form med aktiv betydelse. Se [[grammar-deponensverb]], [[grammar-passiv-med-s]].

## 词组搭配 (Collocations)

- `skiljas åt` — 分开/分手
- `de skildes för ett år sedan` — 他们一年前离婚了

## 例句 (Sentences)

- 🇸🇪 De skildes efter många år tillsammans. — 🇨🇳 他们在多年共同生活后分开了。
