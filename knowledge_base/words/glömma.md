# glömma — verb

📖 中文：忘记 · English: to forget
发音提示：[ˈɡlœmːa]

## 语法变形 (Forms)

| tid | form |
|-----|------|
| infinitiv | glömma |
| presens | glömmer |
| preteritum | glömde |
| supinum | glömt |

| passiv form | form |
|-------------|------|
| bli glömd | 被遗忘 (singular) |
| bli glömda | 被遗忘 (plural) |

## 词组搭配 (Collocations)

- `glömma bort` — 把…忘掉（强调完全忘记）
- `bli glömd` — 被遗忘
- `glömma att + infinitiv` — 忘记做某事

## 例句 (Sentences)

- 🇸🇪 Jag glömde ta med nyckeln. — 🇨🇳 我忘了带钥匙。
- 🇸🇪 Glöm inte att ringa mig! — 🇨🇳 别忘了给我打电话！
- 🇸🇪 Figurerna kämpar för att inte bli glömda. — 🇨🇳 角色们努力不被遗忘。

## 词族 / 同义 / 反义 (Relations)

- 词族: glömsk (健忘的), bortglömd (被遗忘的)
- 反义词: [[minnas]] (记得)

## 用法提示 (Usage Notes)

- `glömma` (忘记做) vs. `glömma bort` (完全忘掉，强调彻底遗忘)：差别细微，口语常通用。
- 被动式 `bli glömd/glömda` 常用 bli-passiv 表达。
