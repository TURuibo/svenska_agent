# förlåt — interjektion

📖 中文：对不起；打扰一下 · English: excuse me / sorry
发音提示：[fœɾˈloːt] — 重音在第二音节

## 语法变形 (Forms)

作感叹词（interjektion）时不变形：**förlåt**

作动词 **förlåta**（原谅）时：

| form | böjning |
|------|---------|
| infinitiv | förlåta |
| presens | förlåter |
| preteritum | förlät |
| supinum | förlåtit |
| imperativ | förlåt |

## 词组搭配 (Collocations)

- `förlåt att jag stör` — 对不起打扰了 → see [[förlåt-att-jag-stör]]
- `kan du förlåta mig?` — 你能原谅我吗？
- `förlåt, men...` — 打扰一下，但是……（礼貌开场）

## 例句 (Sentences)

**义项1 打招呼/打扰:**
- 🇸🇪 Förlåt, kan du hjälpa mig? Jag letar efter apoteket. — 🇨🇳 打扰一下，你能帮我吗？我在找药店。
- 🇸🇪 Förlåt, vet du var biblioteket är? — 🇨🇳 不好意思，你知道图书馆在哪里吗？

**义项2 道歉:**
- 🇸🇪 Förlåt, jag förstår inte. Kan du upprepa? — 🇨🇳 抱歉，我听不懂。你能重说一遍吗？
- 🇸🇪 Jag är ledsen — förlåt mig. — 🇨🇳 我很抱歉，请原谅我。

**义项3 作动词"原谅":**
- 🇸🇪 Kan du förlåta mig för att jag kom för sent? — 🇨🇳 你能原谅我来晚了吗？

## 用法提示 (Usage Notes)

- **förlåt** 作感叹词，用于礼貌地打断别人或道歉，是问路的常用开场。
- 作动词（原谅）时，完整形式是 **förlåta**，förlåt 是其祈使形。
- 与 **ursäkta** 可互换，都常用于 `förlåt/ursäkta, kan du...` 句型。
