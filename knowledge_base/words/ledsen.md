# ledsen — adjektiv

📖 中文：难过的/伤心的 · English: sad, sorry
发音提示：/ˈleːdsɛn/ — "led-sen"

## 语法变形 (Forms)

| form | exempel |
|------|---------|
| obestämd singular (en-ord) | en **ledsen** person |
| obestämd singular (ett-ord) | ett **ledset** barn |
| bestämd / plural | den **ledsna** personen · **ledsna** barn |
| komparativ | **ledsnare** |
| superlativ (obestämd) | **ledsnast** |
| superlativ (bestämd) | den **ledsnaste** |

⚠️ Oregelbunden böjning: ett-form = **ledset** (inte *ledness*); bestämd/plural = **ledsna**

Se [[grammar-adjektiv-bojning]], [[grammar-adjektiv-kongruens]]

## 词组搭配 (Collocations)

- `vara ledsen` — 感到难过
- `bli ledsen` — 变得难过/伤心
- `ledsen för` — 为……感到难过
- `vara ledsen för att` — 对……感到遗憾

## 例句 (Sentences)

- 🇸🇪 Barnet är ledset för att det tappade sin leksak. — 🇨🇳 孩子因为丢了玩具而很难过。
- 🇸🇪 Jag är ledsen, jag förstår inte. — 🇨🇳 对不起，我听不懂。
- 🇸🇪 Hon blev ledsen när hon hörde nyheten. — 🇨🇳 她听到这个消息后很伤心。

## 词族 / 同义 / 反义 (Relations)

- 反义词: [[glad]], [[lycklig]]

## 用法提示 (Usage Notes)

- *Ledsen* kan också betyda "förlåt/ursäkta" i vardagsspråk: *ledsen* = "sorry" (informal apology).
- Komparation: *ledsnare, ledsnast* (oregelbunden).
- Neutrum (ett-ord): **ledset**, inte *ledness*.
