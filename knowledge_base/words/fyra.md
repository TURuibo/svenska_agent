# fyra — räkneord

📖 中文：四 · English: four

🇸🇪 Förklaring: talet efter tre och före fem

发音提示：/ˈfyːra/ — y 读圆唇 [yː]（类似德语 ü）；重音在第一音节

## 语法变形 (Forms)

| 类型 | 形式 |
|------|------|
| 基数词 | fyra |
| 序数词 | [[fjärde]] (第四) |
| 十四 / 四十 | [[fjorton]] / [[fyrtio]] |

## 词组搭配 (Collocations)

- `fyra av tio` — 十个里有四个
- `klockan fyra` — 四点钟
- `halv fyra` — 三点半 → see [[halv-fyra]]

## 例句 (Sentences)

- 🇸🇪 Vi är fyra personer i familjen. — 🇨🇳 我们家有四口人。
- 🇸🇪 Bussen går klockan fyra. — 🇨🇳 公交车四点开。
- 🇸🇪 Jag köper fyra äpplen. — 🇨🇳 我买四个苹果。
