# sjunga — verb

📖 中文：唱歌 · English: to sing
发音提示：[ˈɧʉŋa]，sj- 发 [ɧ]（类似英语 sh 但更靠后）

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| infinitiv | sjunga |
| presens | sjunger |
| preteritum | sjöng |
| supinum | sjungit |
| imperativ | sjung! |

## 词组搭配 (Collocations)

- `sjunga en sång` — 唱一首歌
- `sjunga "Små grodorna"` — 唱《小青蛙》（仲夏传统）
- `sjunga i kör` — 合唱
- `sjunga falskt` — 唱跑调
- `fåglarna sjunger` — 鸟儿在歌唱

## 例句 (Sentences)

- 🇸🇪 Alla dansar runt stången och sjunger "Små grodorna". — 🇨🇳 所有人都围着花柱跳舞，唱着《小青蛙》。
- 🇸🇪 Fåglarna sjunger tidigt på morgonen. — 🇨🇳 鸟儿在清晨歌唱。
- 🇸🇪 Kan du sjunga den här sången? — 🇨🇳 你能唱这首歌吗？
