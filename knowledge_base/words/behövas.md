# behövas — verb (s-verb，grupp 2)

📖 中文：被需要；有必要 · English: to be needed; to be necessary
发音提示：be-HÖ-vas，重音在第二音节 `hö`（`ö` 读 [øː]）。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | behövas |
| Presens | behövs |
| Preteritum | behövdes |
| Supinum | behövts |

> `behövas` 是 [[behöva]] 的 s-被动形式（见 [[grammar-s-passiv]]）：主语是**被需要的东西**，不是需要的人。

## 词组搭配 (Collocations)

- `Det behövs mer …` — 需要更多……
- `Stödet behövs.` — 这笔补助是需要的
- `behövas för att + inf.` — 为了……而需要
- `Behövs det …?` — 需要……吗？
- `Det behövs inte.` — 不需要。

## 例句 (Sentences)

- 🇸🇪 Det behövs mer pengar till skolan. — 🇨🇳 学校需要更多的钱。
- 🇸🇪 Behövs det en biljett? — 🇨🇳 需要票吗？
- 🇸🇪 Hjälpen behövs mest på vintern. — 🇨🇳 冬天最需要这种帮助。
- 🇸🇪 Socialtjänsten bedömer om stödet behövs för att du ska kunna leva på en rimlig nivå. — 🇨🇳 社会服务处会评估是否需要这笔补助，好让你能过上合理水平的生活。 → [[sent-socialtjänsten-bedömer-om-stödet-behövs-för-att]]

## 用法提示 (Usage Notes)

- 对比：[[behöva]] = **人**需要（`Jag behöver hjälp.`）；`behövas` = **东西/帮助**被需要（`Hjälp behövs.`），主语多是物或抽象事物。
- 现在时 `behövs`，不是 *behövar*；常见于说明书、公告和官方文本。
