# deklaration — substantiv (en)

📖 中文：报税单 · English: tax return

🇸🇪 Förklaring: 1) blankett där man varje år redovisar sina inkomster till Skatteverket; 2) det att man officiellt anmäler något, till exempel i tullen

发音提示：[deklaraˈɧuːn]

## 语法变形 (Forms)

| | 单数 | 复数 |
|---|---|---|
| 不定 | en deklaration | deklarationer |
| 定 | deklarationen | deklarationerna |

## 词组搭配 (Collocations)

- `fylla i deklarationen` — 填写报税单
- `lämna in deklarationen` — 提交报税单 → see [[lämna-in]]

## 例句 (Sentences)

- 🇸🇪 Du ska lämna in din deklaration varje år. — 🇨🇳 你每年都要提交报税单。
- 🇸🇪 Deklarationen kan du fylla i på internet. — 🇨🇳 报税单可以在网上填写。
- 🇸🇪 I deklarationen skriver du hur mycket du har tjänat. — 🇨🇳 在报税单里你写下自己赚了多少。
