# skapa — verb (grupp 1)

📖 中文：创造；造成 · English: to create

🇸🇪 Förklaring: göra något nytt som inte fanns förut; få något att uppstå

发音提示：/ˈskɑːpa/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) skapa |
| Presens | skapar |
| Preteritum | skapade |
| Supinum | skapat |
| Imperativ | skapa! |
| Perfekt particip | skapad |

## 词组搭配 (Collocations)

- `skapa en gemenskap` — 创造一种共同体感
- `skapa problem` — 造成问题

## 例句 (Sentences)

- 🇸🇪 Sången skapar också en gemenskap i klassen. — 🇨🇳 唱歌也在班里营造出一种集体感。
- 🇸🇪 Hon vill skapa något nytt. — 🇨🇳 她想创造些新东西。
- 🇸🇪 Det skapar många problem. — 🇨🇳 这造成了很多问题。
