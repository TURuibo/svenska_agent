# skapa — verb (v.1)

📖 中文：创造 · English: to create
发音提示：SKA-pa

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) skapa |
| Presens | skapar |
| Preteritum | skapade |
| Supinum | skapat |

## 词组搭配 (Collocations)

- `skapa jobb` — 创造工作岗位
- `skapa problem` — 制造问题
- `skapa en kultur` — 创造一种文化

## 例句 (Sentences)

- 🇸🇪 Skapar de rikaste människorna fler jobb? — 🇨🇳 最富有的人创造了更多工作吗？
- 🇸🇪 Företaget vill skapa nya produkter. — 🇨🇳 公司想创造新产品。
- 🇸🇪 Konstnären skapade en vacker målning. — 🇨🇳 艺术家创作了一幅美丽的画。

## 词族 / 同义 / 反义 (Relations)

- 同义词: [[göra]]（更泛用的"做"，skapa 更强调"创造出新事物"）
- 反义词: [[förstöra]]（破坏）

## 用法提示 (Usage Notes)

- Verbgrupp 1, 规则变化：skapar / skapade / skapat（-ar/-ade/-at 词尾）。
- `skapa` vs `göra`：`skapa` 强调"创造出前所未有的东西"，`göra` 是通用的"做"。
