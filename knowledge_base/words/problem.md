# problem — substantiv (ett-ord)

📖 中文：问题、难题 · English: problem
发音提示：[prʊˈbleːm]

## 语法变形 (Forms)

| | obestämd | bestämd |
|---|---|---|
| singular | ett problem | problemet |
| plural | problem | problemen |

> ⚠️ 复数与单数同形（第 5 类：ett-ord 以辅音结尾，不变化）

## 词组搭配 (Collocations)

- `ha ett problem` — 有一个问题
- `lösa ett problem` — 解决问题
- `ett svårt problem` — 难题
- `inga problem` — 没问题（口语）

## 例句 (Sentences)

- 🇸🇪 Vi har ett svårt problem som vi måste lösa. — 🇨🇳 我们有一个必须解决的难题。
- 🇸🇪 Inga problem, jag hjälper dig gärna! — 🇨🇳 没问题，我很乐意帮你！
- 🇸🇪 Det finns alltid en lösning på varje problem. — 🇨🇳 每个问题总有一个解决办法。

## 词族 / 同义 / 反义 (Relations)

- 词族: problematisk（有问题的），problemfri（无问题的）
- 同义词: svårighet（困难），utmaning（挑战）
- 反义词: lösning（解决方案）
- 主题: —

## 用法提示 (Usage Notes)

- ett-ord；复数 problem（第 5 类，不变化）。
- 口语常用 `inga problem`（没问题）作为回应。
