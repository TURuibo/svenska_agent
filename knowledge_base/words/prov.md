# prov — substantiv (ett-ord)

📖 中文：考试/测验/试验 · English: test/exam/trial
发音提示：[pruːv] — 长 u 音

## 语法变形 (Forms)

| | Singular | Plural |
|--|---------|--------|
| Obestämd | ett prov | prov |
| Bestämd | provet | proven |

> 单复数同形！`prov` (singular obestämd) = `prov` (plural obestämd)

## 词组搭配 (Collocations)

- `göra ett prov` — 参加考试
- `skriva ett prov` — 参加笔试
- `klara provet` — 通过考试
- `misslyckas på provet` — 考试不及格
- `ha prov i` — 在某科目有考试
- `nationella prov` — 全国统一考试

## 例句 (Sentences)

**义项1 — 考试 (skolprov):**
- 🇸🇪 Vi har ett svårt prov i matematik på fredag. — 🇨🇳 我们周五有一次困难的数学考试。
- 🇸🇪 Eleverna studerade hårt inför provet. — 🇨🇳 学生们为考试努力备考。

**义项2 — 试验/样本 (provning):**
- 🇸🇪 Läkaren tog ett blodprov för att se om allt var bra. — 🇨🇳 医生抽了血样来查看是否一切正常。

## 用法提示 (Usage Notes)

- `prov` 是 ett-ord，注意 `provet`（特定考试）vs `proven`（考试们）
- 单复数同形（obestämd）
- 区别: `prov`（测验/小考）vs `tentamen`/`tenta`（大学考试，口语）vs `examen`（毕业考试）
- 常见: `göra ett bra prov`（考好了）/ `gå dåligt på provet`（考试发挥不好）
