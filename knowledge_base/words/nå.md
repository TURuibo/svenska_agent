# nå — verb (grupp 3)

📖 中文：达到、够到 · English: to reach

🇸🇪 Förklaring: komma fram till en plats eller ett mål; kunna sträcka sig så att man rör vid något

发音提示：/noː/；nådde /ˈnɔdɛ/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) nå |
| Presens | når |
| Preteritum | nådde |
| Supinum | nått |
| Imperativ | nå! |
| Perfekt particip | nådd |
| S-passiv (presens) | nås |
| S-passiv (preteritum) | nåddes |

## 词组搭配 (Collocations)

- `nå toppen` — 登顶（文中：Om Nils skulle nå toppen）
- `nå sitt mål` — 实现目标
- `nå upp till …` — 够到……
- `nå någon (på telefon)` — 联系上某人
- `nå fram` — 到达

## 例句 (Sentences)

**义项1 达到（目标/高度）:**
- 🇸🇪 Om Nils skulle nå toppen behövde han träna mer. — 🇨🇳 要想登顶，Nils 需要练得更多。
- 🇸🇪 De nådde målet efter tre timmar. — 🇨🇳 他们三小时后到达了目的地。

**义项2 够到:**
- 🇸🇪 Jag når inte upp till hyllan. — 🇨🇳 我够不到架子。

**义项3 联系上、到达:**
- 🇸🇪 Du kan nå mig på telefon efter klockan fem. — 🇨🇳 五点后你可以打电话联系到我。
- 🇸🇪 Tåget når Malmö klockan sex. — 🇨🇳 火车六点到达马尔默。

## 用法提示 (Usage Notes)

- 第 3 组动词（单音节、元音结尾）：nå – når – **nådde** – **nått**。
- `nå` 与 `uppnå` 区别：`nå` 通用（高度、地点、人）；`uppnå` 多指「达成目标/结果」。
- 文中 `Om Nils skulle nå toppen` = 「要想登顶」（om + skulle，见 [[ska]]）。
