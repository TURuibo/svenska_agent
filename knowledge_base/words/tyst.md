# tyst — adjektiv

📖 中文：安静的、沉默的 · English: quiet / silent
发音提示：/tyːst/

## 语法变形 (Forms)

| form | en-form | ett-form | plural/bestämd |
|------|---------|----------|----------------|
| positiv obestämd | en tyst (katt) | ett tyst (djur) | tysta (djur) |
| positiv bestämd | den tysta (katten) | det tysta (djuret) | de tysta (djuren) |
| komparativ | tystare | | |
| superlativ | tystast / tystaste | | |

## 词组搭配 (Collocations)

- `vara tyst` — 保持安静
- `ett tyst djur` — 一只安静的动物
- `tyst som en mus` — 像老鼠一样安静（俗语）
- `hålla tyst` — 保持沉默

## 例句 (Sentences)

- 🇸🇪 Var tyst, barnen sover! — 🇨🇳 安静点，孩子们在睡觉！
- 🇸🇪 Biblioteket är alltid tyst. — 🇨🇳 图书馆总是很安静。
- 🇸🇪 Katten satt tyst och tittade ut genom fönstret. — 🇨🇳 猫安静地坐着，望向窗外。
