# stanna — verb (grupp 1)

📖 中文：停下；停留 · English: to stop; to stay
发音提示：/ˈstanːa/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) stanna |
| Presens | stannar |
| Preteritum | stannade |
| Supinum | stannat |
| Imperativ | stanna! |

## 词组搭配 (Collocations)

- `stanna till (på)` — 顺路停一下（在某处）
- `stanna hemma` — 待在家里
- `stanna kvar` — 继续留在；留下来
- `bussen stannar vid` — 公共汽车停在……

## 例句 (Sentences)

- 🇸🇪 Sara stannar till på ett café för att köpa kaffe att ta med. — 🇨🇳 萨拉顺路在咖啡馆停下买外带咖啡。
- 🇸🇪 Bussen stannar inte här. — 🇨🇳 公共汽车不在这里停。
- 🇸🇈 Kan du stanna lite till? — 🇨🇳 你能再待一会儿吗？

## 用法提示 (Usage Notes)

- `stanna till (på)` = 顺道停一下（途中短暂停留）；强调短暂性。
- `stanna kvar` = 留下来（继续在某处）；强调持续性。
- `stanna` vs `sluta`：`stanna` 是停止运动/停在某处，`sluta` 是停止某个动作或行为。
