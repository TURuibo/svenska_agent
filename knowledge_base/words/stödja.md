# stödja — verb (grupp 2)

📖 中文：支持；支撑 · English: to support; to back; to prop up
发音提示：STÖD-ja，`ö` 读 [øː]（圆唇的"鹅"）；`dj` 读 /j/。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | stödja（变体 `stöda`） |
| Presens | stödjer / stöder |
| Preteritum | stödde |
| Supinum | stött |
| Imperativ | stödj / stöd |
| Perf. particip | stödd / stött / stödda |
| S-passiv | stöds / stödjs |

> 导入块给出的 `stödjer / stödde / stött` 是标准形；日常和新闻里 `stöder` 同样很常见。支持者：`Hon har alltid stött mig.`（supinum 是 **stött**，不是 *stödjat*）。

## 词组搭配 (Collocations)

- `stödja ett förslag / en idé / reglerna` — 支持提议 / 想法 / 规定
- `stödja någon / en person` — 支持某人
- `stödja sig på / mot …` — 靠着……、拄着……（物理支撑）
- `stödja varandra` — 互相支持
- `ett stöd` — 支持；援助；支撑物（名词）

## 例句 (Sentences)

**义项1 支持（人、观点、政策）:**

- 🇸🇪 Jag stödjer reglerna helt. — 🇨🇳 我完全支持这些规则。 → [[sent-jag-stödjer-reglerna-helt]]
- 🇸🇪 Vi stödjer varandra när det är svårt. — 🇨🇳 困难的时候我们互相支持。
- 🇸🇪 Hon har alltid stött mig. — 🇨🇳 她一直支持我。

**义项2 支撑（物理）:**

- 🇸🇪 Han stödde sig på en käpp. — 🇨🇳 他拄着拐杖。

## 词族 / 同义 / 反义 (Relations)

- 词族: [[stöd]]（名词：支持；援助）
- 同义词: [[stötta]]（口语，更温和、更日常）；近义 [[hjälpa]]（帮助——侧重"出力"，`stödja` 侧重"站在某人这一边"）
- 反义词: —（可对比 `motarbeta`、`vara emot`）
- 主题: [[topic-allmänna-verb]]

## 用法提示 (Usage Notes)

- 直接带宾语，**不加介词**：`stödja förslaget`（不是 *stödja på förslaget*）；只有物理义"靠着"才用 `stödja sig på/mot`。
- 对比 [[hjälpa]]：`hjälpa någon att göra något`（实际帮忙）vs `stödja någon`（表态 / 精神与经济上的支持）。
- 新闻里常见：`Majoriteten stöder förslaget.`、`stöd till …`（对……的资助）。
