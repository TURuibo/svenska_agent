# paket — substantiv (ett-ord)

📖 中文：包裹；小包 · English: package, parcel

🇸🇪 Förklaring: sak som är inslagen i papper eller packad i en låda och som skickas eller ges bort

发音提示：/paˈkeːt/ — 重音在第二音节 -ket

## 语法变形 (Forms)

| | obestämd | bestämd |
|---|---|---|
| singular | ett paket | paketet |
| plural | paket | paketen |

## 词组搭配 (Collocations)

- `ett litet paket` — 一个小包裹
- `hämta ett paket` — 取包裹

## 例句 (Sentences)

- 🇸🇪 Max är välkommen att ta med ett litet paket. — 🇨🇳 Max 可以带一个小包裹来。
- 🇸🇪 Jag har fått ett paket från posten. — 🇨🇳 我收到了一个邮局的包裹。
- 🇸🇪 Paketet ligger på bordet. — 🇨🇳 包裹在桌子上。
