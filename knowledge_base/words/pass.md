# pass — substantiv (ett)

📖 中文：班次；轮班（工作语境）· English: shift (work)
发音提示：/pas:/ — 短促的 "a"

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Grundform (obestämd) | ett pass |
| Bestämd form | passet |
| Plural (obestämd) | pass |
| Plural (bestämd) | passen |

## 词组搭配 (Collocations)

- `dagpass` — 白班
- `nattpass` — 夜班
- `mitt pass börjar/slutar` — 我的班次开始/结束
- `jobba ett pass` — 上一个班

## 例句 (Sentences)

**义项1 轮班/班次（职场用语）:**
- [[sent-mitt-pass-borjar-klockan-tva]] 🇸🇪 Mitt pass börjar klockan två på eftermiddagen. — 🇨🇳 我的班次从下午两点开始。
- [[sent-mitt-pass-slutar-klockan-tio]] 🇸🇪 Mitt pass slutar klockan tio på kvällen. — 🇨🇳 我的班次晚上十点结束。
- 🇸🇪 Hon jobbar nattpass tre gånger i veckan. — 🇨🇳 她每周上三次夜班。

**义项2 护照:**
- 🇸🇪 Jag måste förnya mitt pass innan resan. — 🇨🇳 我出发前得更新我的护照。

## 用法提示 (Usage Notes)

- `ett pass` 在职场语境（护理、医院、餐饮等轮班制工作）里最常指"一个班次"，与英语 shift 对应。
- 注意与 `pass`（护照）区分——同形异义词，靠语境判断。
- 另有 `en pass` 用法（如体育中"传球"），本条聚焦职场轮班义项。
