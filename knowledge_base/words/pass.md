# pass — substantiv (ett)

📖 中文：护照 · English: passport

🇸🇪 Förklaring: dokument som visar vem man är och som man behöver när man reser till andra länder

发音提示：PASS（短 a）

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| obestämd singular | ett pass |
| bestämd singular | passet |
| obestämd plural | pass |
| bestämd plural | passen |

## 词组搭配 (Collocations)

- `visa passet` — 出示护照
- `ansöka om pass` — 申请护照
- `giltigt pass` — 有效护照
- `ha passet med sig` — 随身带护照

## 例句 (Sentences)

- 🇸🇪 Wei nickar och visar sitt pass. — 🇨🇳 Wei 点头，出示护照。
- 🇸🇪 Jag måste förnya mitt pass. — 🇨🇳 我得换新护照。
- 🇸🇪 Glöm inte passet! — 🇨🇳 别忘了护照！
