# knappa — verb (grupp 1)

📖 中文：按键输入（knappa in）· English: to key in, type in
⚠️ 同形异义：名词 `knapp`（en，按钮 / 纽扣），复数 `knappar`。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | knappa |
| Presens | knappar |
| Preteritum | knappade |
| Supinum | knappat |
| Imperativ | knappa |

## 词组搭配 (Collocations)

- `knappa in koden` — 输入密码
- `knappa in ett nummer` — 按键输入号码

## 例句 (Sentences)

- 🇸🇪 Han kan inte fokusera utan knappar snabbt in koden till sitt Bank-id på mobilen. — 🇨🇳 他无法集中注意力，就在手机上飞快地输入了 Bank-id 的密码。
- 🇸🇪 Hon knappade in numret. — 🇨🇳 她按键输入了号码。
- 🇸🇪 Du måste knappa in pinkoden. — 🇨🇳 你必须输入 PIN 码。
