# stambyte — substantiv (ett)

📖 中文：总管道更换 · English: pipe/riser replacement
发音提示：STAM-by-te，重音在第一音节

## 语法变形 (Forms)

| 形式 | 写法 |
|------|------|
| 不定式单数 | ett stambyte |
| 定式单数 | stambytet |
| 不定式复数 | stambyten |
| 定式复数 | stambytena |

## 词组搭配 (Collocations)

- `göra ett stambyte` — 进行总管道更换
- `stambyte i huset` — 楼里的总管道更换
- `stora stambyten är vanliga i äldre hus` — 老房子常有大规模的总管道更换

## 例句 (Sentences)

- 🇸🇪 Stambytet i huset börjar nästa vecka. — 🇨🇳 楼里的总管道更换工程下周开始。
- 🇸🇪 Ett stambyte kan ta flera veckor att genomföra. — 🇨🇳 一次总管道更换可能需要几周才能完成。
- 🇸🇪 Vi ber om ert tålamod under stambytet. — 🇨🇳 在总管道更换期间，我们请求您的耐心配合。

## 词族 / 同义 / 反义 (Relations)

## 用法提示 (Usage Notes)

- Compound: stam（主干/总管）+ byte（更换，byta 的名词化形式）。
- 瑞典公寓楼常见大修项目，指更换建筑内老化的给排水立管。
- 常见搭配动词: `genomföra ett stambyte`、`planera ett stambyte`。
