# livnära — verb (grupp 1)

📖 中文：维持生计，靠……谋生 · English: to sustain oneself, to make a living
发音提示：[ˈliːvˌnæːra]

## 语法变形 (Forms)

| form | svenska |
|------|---------|
| infinitiv | livnära (sig) |
| presens | livnär (sig) |
| preteritum | livnärde (sig) |
| supinum | livnärt (sig) |

## 词组搭配 (Collocations)

- `livnära sig på turism` — 靠旅游业为生
- `livnära sig på jordbruk` — 靠农业为生
- `livnära sig på sitt arbete` — 靠自己的工作谋生

## 例句 (Sentences)

- 🇸🇪 Många invånare på Gotland livnär sig på turism. — 🇨🇳 哥特兰岛上的许多居民靠旅游业为生。
- 🇸🇪 På landsbygden livnär sig folk fortfarande på jordbruk. — 🇨🇳 在农村，人们仍然靠农业维持生计。
- 🇸🇪 Konstnären livnär sig på att måla och sälja tavlor. — 🇨🇳 这位艺术家靠绘画和卖画为生。
