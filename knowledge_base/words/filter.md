# filter — substantiv (ett-ord)

📖 中文：过滤网；滤器 · English: filter

🇸🇪 Förklaring: sak som tar bort smuts eller små delar från vatten eller luft

发音提示：/ˈfɪltɛr/ — 重音在第一音节；-er 读轻

- 🇸🇪 Rengör filtret efter varje tvätt. — 🇨🇳 每次洗完后请清洁过滤网。
