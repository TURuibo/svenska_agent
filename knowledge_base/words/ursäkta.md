# ursäkta — verb / interjektion

📖 中文：对不起；打扰一下 · English: excuse me / sorry

🇸🇪 Förklaring: be om förlåtelse; säga "ursäkta" för att få någons uppmärksamhet

发音提示：/ˈʉːʂɛkta/ — 重音第一音节；rs 合成卷舌 [ʂ]

| 形式 | |

| 现在时 | ursäktar |
| 过去时 | ursäktade |

| 命令式 | ursäkta! |

## 词组搭配 (Collocations)

- `Ursäkta mig` — 对不起/请问
- `Ursäkta, var ligger stationen?` — 请问车站在哪
- `ursäkta att jag stör` — 抱歉打扰

## 例句 (Sentences)

- 🇸🇪 Ursäkta, var är toaletten? — 🇨🇳 打扰一下，洗手间在哪里？
- 🇸🇪 Ursäkta mig, jag hörde inte. — 🇨🇳 对不起，我没听清。
- 🇸🇪 Ursäkta att jag är sen. — 🇨🇳 抱歉我迟到了。
