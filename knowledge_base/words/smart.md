# smart — adjektiv

📖 中文：聪明的/机灵的 · English: smart, clever, intelligent
发音提示：/smart/ — 与英语 "smart" 发音相近

## 语法变形 (Forms)

| form | exempel |
|------|---------|
| obestämd singular (en-ord) | en **smart** person |
| obestämd singular (ett-ord) | ett **smart** barn |
| bestämd / plural | den **smarta** personen · **smarta** barn |
| komparativ | **smartare** |
| superlativ (obestämd) | **smartast** |
| superlativ (bestämd) | den **smartaste** |

Se [[grammar-adjektiv-bojning]], [[grammar-adjektiv-kongruens]]

## 词组搭配 (Collocations)

- `en smart lösning` — 一个聪明的解决方案
- `smart nog att` — 聪明到足以（做某事）
- `tänka smart` — 聪明地思考

## 用法提示 (Usage Notes)

- *Smart* är mer informellt och colloquialt än *klok* (klok = wise, smart = clever/quick-witted).
- Kan också betyda "snygg/stilig" i informell svenska: *en smart kostym* (a smart suit).
