# öppna — verb (grupp 1)

📖 中文：开门；打开 · English: to open

🇸🇪 Förklaring: göra så att något inte längre är stängt; börja verksamheten för dagen

发音提示：/ˈœpːna/ — ö 短促、pp 双辅音要顿一下。

## 语法变形 (Forms)

| infinitiv | presens | preteritum | supinum | imperativ |
|---|---|---|---|---|
| öppna | öppnar | öppnade | öppnat | öppna! |

## 词组搭配 (Collocations)

- `öppna dörren` — 开门 → see [[dörr]]
- `förskolan öppnar klockan halv sju` — 幼儿园六点半开门 → see [[förskola]]
- `öppna ett paket / ett fönster` — 拆包裹 / 开窗
- `öppna och stänga` — 开和关 → see [[stänga]]

## 例句 (Sentences)

- 🇸🇪 Vi öppnar klockan halv sju. — 🇨🇳 我们六点半开门。
- 🇸🇪 Kan du öppna dörren? — 🇨🇳 你能开一下门吗？
- 🇸🇪 Affären öppnade klockan tio. — 🇨🇳 商店十点开门了。

- 词族: [[öppen]]（形容词：开着的）

## 用法提示 (Usage Notes)

- 既可及物（*öppna dörren*）也可不及物说营业（*Vi öppnar kl. 6.30* = 我们几点开门）。
- 别把 **öppna**（动词）和 **öppen / öppet**（形容词"开着"）混用：*Är förskolan öppen?*（开着吗？）vs *När öppnar förskolan?*（几点开门？）。
