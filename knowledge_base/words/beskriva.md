# beskriva — verb (grupp 4, 强变化)

📖 中文：描述；形容；叙述 · English: to describe

🇸🇪 Förklaring: berätta hur något eller någon ser ut eller är

发音提示：be-SKRI-va，重音在第二音节 `skri`。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | beskriva |
| Presens | beskriver |
| Preteritum | beskrev |
| Supinum | beskrivit |
| Imperativ | beskriv |
| Perf. particip | beskriven / beskrivet / beskrivna |
| S-passiv | beskrivs |

> 与 `skriva – skrev – skrivit` 同一强变化（i – e – i）。

## 词组搭配 (Collocations)

- `beskriva vägen / en person / en situation` — 描述路线 / 人 / 情况
- `beskriva sig själv` — 描述自己
- `beskriva något för någon` — 向某人描述某事
- `beskriva hur …` / `beskriva att …` — 描述……是怎样的
- `en beskrivning` — 描述（名词）

## 例句 (Sentences)

- 🇸🇪 I en rapport beskriver kommunen hur cyklarna ofta hindrar rullstolar och barnvagnar. — 🇨🇳 市政府在一份报告中描述了滑板车如何常常妨碍轮椅和婴儿车通行。 → [[sent-i-en-rapport-beskriver-kommunen-hur-cyklarna]]
- 🇸🇪 Kan du beskriva din dag? — 🇨🇳 你能描述一下你的一天吗？
- 🇸🇪 Hon beskrev vägen till stationen. — 🇨🇳 她描述了去车站的路。
- 🇸🇪 Han beskrev sin lägenhet för mig. — 🇨🇳 他向我描述了他的公寓。

## 用法提示 (Usage Notes)

- 后面常接 `hur …`（描述"怎样"）：`beskriva hur man gör`，这是间接疑问句，词序见 [[grammar-indirekt-fraga]]。
- 区分：`beskriva` = 描述外观 / 情况；`förklara` = 解释原因 / 道理。
