# springa — verb (grupp 4)

📖 中文：跑 · English: to run
发音提示：/ˈsprɪŋa/；sprang /spraŋ/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) springa |
| Presens | springer |
| Preteritum | sprang |
| Supinum | sprungit |
| Imperativ | spring! |
| Perfekt particip | sprungen |
| Presens particip | springande |

## 词组搭配 (Collocations)

- `springa 3 timmar` — 跑三个小时（文中）
- `springa maraton` — 跑马拉松
- `springa efter bussen` — 追公交
- `springa fritt` — 自由奔跑 → see [[springa-fritt]]

## 例句 (Sentences)

- 🇸🇪 Han kunde till exempel springa 3 timmar för att köpa godis eller cykla flera mil för en pizza. — 🇨🇳 比如他会跑三个小时去买糖，或者骑几十公里去吃一个披萨。
- 🇸🇪 Barnen springer i parken. — 🇨🇳 孩子们在公园里跑。
- 🇸🇪 Jag sprang till bussen men missade den. — 🇨🇳 我跑去赶公交，但还是错过了。
- 🇸🇪 Hon har sprungit ett maraton. — 🇨🇳 她跑过一次马拉松。

## 用法提示 (Usage Notes)

- 强变化动词（元音变化 i – a – u）：springa – springer – **sprang** – **sprungit**（同类：sjunga/sjöng；见 [[grammar-starka-verb]]）。
- `springa` 是日常用语「跑」；运动名词 `löpning`、`jogga` 也指跑步。
- 文中 `springa 3 timmar` = 时间段直接作宾语/状语（跑三小时），不需要 `i`。
