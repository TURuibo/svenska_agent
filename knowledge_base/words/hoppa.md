# hoppa — verb (v.1)

📖 中文：跳 · English: to jump
发音提示：HOP-pa；双写 `pp`，元音 `o` 短促。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | att hoppa |
| Imperativ | hoppa! |
| Presens | hoppar |
| Preteritum | hoppade |
| Supinum | (har) hoppat |

规则的 grupp 1 动词（-ar/-ade/-at）。

## 词组搭配 (Collocations)

- `hoppa i` — 跳进（例：hoppa i vattnet）
- `hoppa i hö` — 在干草里跳
- `hoppa över` — 跳过；跳过（略过）
- `hoppa av` — 跳下；退出/放弃

## 例句 (Sentences)

- 🇸🇪 Barnen **hoppade** i höet på bondgården.
  🇨🇳 孩子们在农场的干草堆里跳来跳去。
- 🇸🇪 **Hoppa** inte på stolen!
  🇨🇳 别在椅子上跳！
- 🇸🇪 Hon **hoppade** över bäcken med ett stort steg.
  🇨🇳 她迈一大步跳过了小溪。
