# tapper — adjektiv

📖 中文：勇敢的；英勇的 · English: brave, courageous

🇸🇪 Förklaring: som inte är rädd och vågar göra svåra eller farliga saker

发音提示：/ˈtɑpːɛr/ — pp 前元音短；重音在首音节

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| en-ord (utr.) | tapper |
| ett-ord (neutr.) | tappert |
| plural / bestämd | tappra |
| komparativ | tappare |
| superlativ | tappraste |

## 词组搭配 (Collocations)

- `en tapper soldat` — 勇敢的士兵
- `tappert kämpa` — 英勇奋战

## 例句 (Sentences)

- 🇸🇪 Den tappra ödlan klättrade upp på berget. — 🇨🇳 那只勇敢的蜥蜴爬上了山。
- 🇸🇪 Hon var tapper när hon gick till tandläkaren. — 🇨🇳 她去看牙医时很勇敢。
- 🇸🇪 De tappra räddningsmännen räddade barnet. — 🇨🇳 勇敢的救援人员救了孩子。
