# överraska — verb (grupp 1)

📖 中文：使惊讶；给……惊喜 · English: to surprise

🇸🇪 Förklaring: göra så att någon blir förvånad, ofta genom något oväntat

发音提示：/ˈøːvɛˌraska/ — 重音在 ö；ö 读长 /øː/；rr 为卷舌区域音

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | överraska |
| Presens | överraskar |
| Preteritum | överraskade |
| Supinum | överraskat |
| Imperativ | överraska |

## 词组搭配 (Collocations)

- `bli överraskad` — 感到惊讶
- `överraska någon med något` — 用某物给某人惊喜
- `Det överraskade mig.` — 这让我吃惊

## 例句 (Sentences)

- 🇸🇪 Ett faktum som överraskade forskarna var att hälften sov för lite. — 🇨🇳 让研究者吃惊的一个事实是一半人睡眠不足。
- 🇸🇪 Hon överraskade mig med en present. — 🇨🇳 她送了我一份礼物，让我惊喜。
- 🇸🇪 Resultatet överraskade alla. — 🇨🇳 结果让所有人吃惊。
