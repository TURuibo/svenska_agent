# klicka — verb

📖 中文：点击 · English: to click

🇸🇪 Förklaring: trycka på musknappen eller skärmen för att välja något

发音提示：/ˈklɪka/ — 重音在 klick；ck 表示前面元音短

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | klicka |
| Presens | klickar |
| Preteritum | klickade |
| Supinum | klickat |
| Imperativ | klicka! |

## 词组搭配 (Collocations)

- `klicka på` — 点击

## 例句 (Sentences)

- 🇸🇪 Klicka på knappen för att fortsätta. — 🇨🇳 点击按钮继续。
- 🇸🇪 Jag klickade fel och raderade filen. — 🇨🇳 我点错了，把文件删了。
- 🇸🇪 Dubbelklicka på ikonen. — 🇨🇳 双击这个图标。
