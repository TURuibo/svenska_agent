# byggmaterial — substantiv (ett)

📖 中文：建筑材料 · English: building material
发音提示：BYGG-ma-te-ri-al，重音在第一音节

## 语法变形 (Forms)

| 形式 | 写法 |
|------|------|
| 不定式单数 | ett byggmaterial |
| 定式单数 | byggmaterialet |
| 不定式复数 | byggmaterial（不变） |
| 定式复数 | byggmaterialen |

## 词组搭配 (Collocations)

- `köpa byggmaterial` — 购买建筑材料
- `containern är bara för byggmaterial` — 集装箱只能装建筑材料
- `hållbart byggmaterial` — 可持续建筑材料

## 例句 (Sentences)

- 🇸🇪 Den är bara för byggmaterial, inte för hushållssopor. — 🇨🇳 只能扔建筑材料，不能扔生活垃圾。
- 🇸🇪 Vi köpte byggmaterial för att renovera köket. — 🇨🇳 我们买了建筑材料来装修厨房。
- 🇸🇪 Byggmaterialet levererades på morgonen. — 🇨🇳 建筑材料是早上送到的。
