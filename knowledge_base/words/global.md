# global — adjektiv

📖 中文：全球的；全世界的 · English: global; worldwide

🇸🇪 Förklaring: som gäller hela jorden eller alla länder

发音提示：/ɡlʊˈbɑːl/ — 重音在 -bal，a 读长音；g 读硬 /ɡ/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| en-form | global |
| ett-form | globalt |
| plural / bestämd | globala |
| komparativ | globalare |
| superlativ | globalast |
| superlativ (bestämd) | globalaste |

> 实际更常用 `mer global / mest global`。

## 词组搭配 (Collocations)

- `global uppvärmning` — 全球变暖 → see [[global-uppvärmning]]
- `ett globalt problem` — 一个全球性问题
- `globalt sett` — 从全球范围看

## 例句 (Sentences)

- 🇸🇪 Fråga efter investeringar som inte bidrar till den globala uppvärmningen. — 🇨🇳 询问不会助长全球变暖的投资。
- 🇸🇪 Klimatförändringarna är ett globalt problem. — 🇨🇳 气候变化是一个全球性问题。
- 🇸🇪 Företaget säljer sina varor globalt. — 🇨🇳 这家公司在全球销售商品。
