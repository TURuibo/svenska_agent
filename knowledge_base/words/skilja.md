# skilja — verb (grupp 2a)

📖 中文：区分；分开；（skilja sig）离婚 / 不同 · English: to separate; to distinguish; reflexive: to differ / divorce
发音提示：/ˈɧɪlja/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) skilja |
| Presens | skiljer |
| Preteritum | skilde |
| Supinum | skilt |
| Imperativ | skilj! |

grupp 2a。⚠️ 词干 `skilj-` 在 preteritum/supinum 里**丢掉 j**：skilde、skilt（不是 *skiljde*）。反身：skiljer sig – skilde sig – skilt sig。

## 词组搭配 (Collocations)

- `skilja sig från` — 与……不同 → see [[skilja-sig-från]]
- `skilja sig` — 离婚
- `skilja på A och B` — 区分 A 和 B
- `skilja A från B` — 把 A 与 B 分开

## 例句 (Sentences)

**义项1 区分/分开:**
- 🇸🇪 Man måste skilja på fakta och åsikter. — 🇨🇳 必须区分事实和观点。

**义项2 skilja sig 不同:**
- 🇸🇪 Svenska skiljer sig från engelska. — 🇨🇳 瑞典语与英语不同。

**义项3 skilja sig 离婚:**
- 🇸🇪 Mina föräldrar skilde sig när jag var tio. — 🇨🇳 我十岁时父母离婚了。
