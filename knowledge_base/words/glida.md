# glida — verb (stark)

📖 中文：滑；滑行；渐渐疏远 · English: glide; slide; drift (apart)

🇸🇪 Förklaring: röra sig mjukt och lätt över en yta; bli mindre nära någon med tiden

发音提示：/ˈɡliːda/ — gl 中 g 读硬 /ɡ/；i 长音

## 语法变形 (Forms)

| 形式 | 瑞典语 |
|------|--------|
| infinitiv | glida |
| presens | glider |
| preteritum | gled |
| supinum | glidit |
| imperativ | glid |
| presens (s-form) | glids |
| preteritum (s-form) | gleds |
| perfekt particip | gliden |

## 词组搭配 (Collocations)

- `glida ifrån varandra` — 渐行渐远 → see [[glida-ifrån]]
- `glida på isen` — 在冰上滑行
- `glida iväg` — 悄悄溜走

## 例句 (Sentences)

**义项1 滑行:**

- 🇸🇪 Båten gled över vattnet. — 🇨🇳 小船在水面上滑行。

**义项2 渐渐疏远:**

- 🇸🇪 De gled ifrån varandra mer och mer. — 🇨🇳 他们越来越疏远了。
- 🇸🇪 Vi har glidit ifrån varandra sedan vi flyttade. — 🇨🇳 自从搬家后我们渐渐疏远了。
