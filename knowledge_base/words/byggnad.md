# byggnad — substantiv (en)

📖 中文：建筑；楼 · English: building
发音提示：BYGG-nad；两音节，gg 发浊音。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Singular obestämd | en byggnad |
| Singular bestämd | byggnaden |
| Plural obestämd | byggnader |
| Plural bestämd | byggnaderna |

## 词组搭配 (Collocations)

- `stor röd byggnad` — 大红楼
- `historisk byggnad` — 历史建筑
- `offentlig byggnad` — 公共建筑
- `byggnadsarbetare` — 建筑工人
