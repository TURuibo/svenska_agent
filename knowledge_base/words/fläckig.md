# fläckig — adjektiv

📖 中文：有斑点的 · English: spotted
发音提示：/ˈflɛkːɪɡ/

## 语法变形 (Forms)

| form | en-form | ett-form | plural/bestämd |
|------|---------|----------|----------------|
| positiv obestämd | en fläckig (hund) | ett fläckigt (djur) | fläckiga (djur) |
| positiv bestämd | den fläckiga (hunden) | det fläckiga (djuret) | de fläckiga (djuren) |
| komparativ | fläckigare | | |
| superlativ | fläckigast / fläckigaste | | |

## 词组搭配 (Collocations)

- `fläckig päls` — 有斑点的皮毛
- `fläckiga djur` — 有斑点的动物
- `en fläckig ko` — 一头有斑点的牛

## 例句 (Sentences)

- 🇸🇪 Dalmatinern är en fläckig hund. — 🇨🇳 斑点狗是一种有斑点的狗。
- 🇸🇪 Giraffen har fläckig päls. — 🇨🇳 长颈鹿有带斑点的皮毛。
- 🇸🇪 Min tröja blev fläckig av maten. — 🇨🇳 我的毛衣被食物弄脏留下了斑点。
