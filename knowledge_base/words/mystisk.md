# mystisk — adjektiv

📖 中文：神秘的 · English: mysterious
发音提示：/ˈmʏstɪsk/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Positiv utrum | en mystisk … |
| Positiv neutrum | ett mystiskt … |
| Positiv plural/def | de/den mystiska … |
| Komparativ | mystiskare |
| Superlativ | mystiskast / den mystiskaste |

## 词组搭配 (Collocations)

- `ett mystiskt äventyr` — 一场神秘的冒险
- `ett mystiskt varelse` — 一个神秘的生物
- `mystiska händelser` — 神秘的事件
- `mystisk försvinnande` — 神秘失踪

## 例句 (Sentences)

- 🇸🇪 Johannes och hans kompis hamnar i ett mystiskt äventyr. — 🇨🇳 约翰内斯和他的伙伴陷入了一场神秘的冒险。
- 🇸🇪 De hittar en skadad och ensam varelse på en ö som heter Svärtan. — 🇨🇳 他们在一座名叫斯瓦尔坦的岛上发现了一只受伤且孤独的生物。
- 🇸🇪 Det händer något mystiskt i den gamla huset. — 🇨🇳 那栋老房子里发生了一些神秘的事情。
- 🇸🇪 Hon hade ett mystiskt leende som ingen förstod. — 🇨🇳 她面带神秘的微笑，没有人能理解。

## 词族 / 同义 / 反义 (Relations)

- 词族: *mystik* (en, 神秘主义/神秘), *mysterium* (ett, 谜/奥秘)
- 主题: [[topic-litteratur-och-kultur]]

## 用法提示 (Usage Notes)

- 形容词三变化：*mystisk* (utrum) / *mystiskt* (neutrum) / *mystiska* (plural & bestämd)
- 比较级：*mystiskare* (较神秘); 最高级：*mystiskast* 或 *mest mystisk*
- 类似词：*hemlighetsfull* = 神秘兮兮的（更口语），*gåtfull* = 令人费解的
