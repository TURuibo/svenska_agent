# rapportera — verb (grupp 1)

📖 中文：报道；汇报 · English: to report

🇸🇪 Förklaring: berätta om nyheter eller händelser för andra, till exempel i tidning eller tv

发音提示：/rapɔˈʈeːra/ — 重音在 -te-，rt 合成卷舌 ʈ

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | rapportera |
| Presens | rapporterar |
| Preteritum | rapporterade |
| Supinum | rapporterat |
| Imperativ | rapportera |

## 词组搭配 (Collocations)

- `rapportera nyheter` — 报道新闻
- `rapportera om` — 就……作报道
- `rapportera till polisen` — 向警方报告

## 例句 (Sentences)

- 🇸🇪 Jag följer många tidningar och tv-program som rapporterar nyheter. — 🇨🇳 我关注很多报道新闻的报纸和电视节目。
- 🇸🇪 Tidningen rapporterar om olyckan. — 🇨🇳 报纸报道了这起事故。
- 🇸🇪 Du ska rapportera felet till läraren. — 🇨🇳 你应该把错误汇报给老师。
