# gymkort — substantiv

📖 中文：健身卡 · English: gym membership card
发音提示：gym 读 /jym/（y 为圆唇 [y]），kort 读 /kɔrt/

## 语法变形 (Forms)

复合词 gym + kort。ett 词。

| | 单数 | 复数 |
|---|---|---|
| 不定 | ett gymkort | gymkort |
| 定 | gymkortet | gymkorten |

## 词组搭配 (Collocations)

- `köpa ett gymkort` — 买健身卡 → see [[köpa]]
- `ha gymkort` — 有健身卡
- `förnya gymkortet` — 续卡

## 例句 (Sentences)

- 🇸🇪 Jag har köpt ett gymkort! — 🇨🇳 我买了一张健身卡！
- 🇸🇪 Mitt gymkort kostar 300 kronor i månaden. — 🇨🇳 我的健身卡每月 300 克朗。
- 🇸🇪 Du måste visa gymkortet vid receptionen. — 🇨🇳 你必须在前台出示健身卡。
