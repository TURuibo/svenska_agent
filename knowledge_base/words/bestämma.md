# bestämma — verb (v.2b)

📖 中文：决定 · English: to decide
发音提示：be-STÄM-ma；重音在第二音节，双写 `mm`。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | att bestämma |
| Imperativ | bestäm! |
| Presens | bestämmer |
| Preteritum | bestämde |
| Supinum | (har) bestämt |

Grupp 2b 动词（-er/-de/-t）。

## 词组搭配 (Collocations)

- `bestämma sig` — 下决心/做决定（反身）
- `bestämma allt` — 决定一切
- `bestämma tid` — 确定时间
