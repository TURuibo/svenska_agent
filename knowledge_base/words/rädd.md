# rädd — adjektiv

📖 中文：害怕的；担心的 · English: afraid, scared
发音提示：/rɛdː/ ä = 短开口的 e；结尾 -dd 双辅音读短促。

## 语法变形 (Forms)

| form | böjning |
|------|---------|
| utrum obestämd | rädd |
| neutrum obestämd | **rätt** ⚠️ (-dd → -tt，与 rätt「对的」同形) |
| bestämd/plural | rädda |
| komparativ | räddare（少用，常说 mer rädd） |
| superlativ | räddast（少用，常说 mest rädd） |

## 词组搭配 (Collocations)

- `rädd för (något)` — 害怕某物（介词用 **för**！）
- `rädd att + infinitiv` — 害怕做某事 (rädd att förlora 害怕失去)
- `bli rädd` — 受惊、害怕起来
- `vara rädd om (något/någon)` — 爱惜、小心呵护（**rädd om ≠ rädd för**，意思完全不同！）
- `jätterädd` — 非常害怕（口语强调）

## 例句 (Sentences)

- 🇸🇪 Jag är rädd för spindlar. — 🇨🇳 我怕蜘蛛。
- 🇸🇪 Var inte rädd, det gör inte ont. — 🇨🇳 别怕，不会疼的。
- 🇸🇪 Barnet blev rätt när hunden skällde. — 🇨🇳 狗叫的时候小孩受惊了。（neutrum: rätt）
- 🇸🇪 Hon är rädd om sin nya cykel. — 🇨🇳 她很爱惜自己的新自行车。（rädd om = 爱惜）

## 用法提示 (Usage Notes)

- ⚠️ **介词陷阱**：「害怕…」用 `rädd för`，不是 rädd av/till。
- ⚠️ **rädd för ≠ rädd om**：`rädd för X` = 怕 X；`rädd om X` = 爱惜/小心对待 X。
- ⚠️ **neutrum 同形陷阱**：ett-form 是 `rätt`，和 rätt「正确的」拼写相同，靠上下文区分。
