# rädd — adjektiv

📖 中文：害怕的 · English: afraid, scared
发音提示：RÄDD（ä 开口，双 d 短促）

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| en-form | rädd |
| ett-form | (rätt)* |
| Plural / bestämd | rädda |
| Komparativ | räddare / mer rädd |
| Superlativ | räddast / mest rädd |

> \* ett-形理论上是 *rätt*，但日常几乎不用（barnet är rädd 更常见）。**rädd** 只作表语，不放名词前。

## 词组搭配 (Collocations)

- `vara rädd för ngt/ngn` — 害怕… → see [[vara-rädd-för]]
- `bli rädd` — 吓到、变得害怕
- `Var inte rädd!` — 别怕！
- `rädd om ngt` — 爱惜/小心对待某物（⚠️ 另一义）

## 例句 (Sentences)

- 🇸🇪 Han är lite rädd för rutschkanan. — 🇨🇳 他有点怕滑梯。
- 🇸🇪 Var inte rädd, pappa är här. — 🇨🇳 别怕，爸爸在这儿。
- 🇸🇪 Barnen blev rädda när hunden skällde. — 🇨🇳 狗一叫，孩子们就吓到了。
- 🇸🇪 Ella är inte rädd för någonting. — 🇨🇳 Ella 什么都不怕。

## 词族 / 同义 / 反义 (Relations)

- 同义词: [[orolig]]（担心的）
- 反义词: [[modig]]（勇敢的）, [[trygg]]（安心的）
- 主题: [[topic-småbarn-känslor-och-beteende]], [[topic-förskola-vardag]]

## 用法提示 (Usage Notes)

- 中文"怕"是动词，瑞典语是 **形容词 + för**：*Jag är rädd för hundar*（不是 *jag räddar*）。
- **bli rädd** = 受惊（变化）；**vara rädd** = 处于害怕状态。
- ⚠️ *rädd om* 意思完全不同 = 爱惜（*Var rädd om dig!* 保重）。
