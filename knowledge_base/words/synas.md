# synas — verb

📖 中文：看得见；显现 · English: to be visible; to show

🇸🇪 Förklaring: kunna ses; visa sig

发音提示：/ˈsyːnas/ — y 读圆唇前高元音 yː；重音在第一音节

## 语法变形 (Forms)

| 形式 | 例 |
|---|---|
| infinitiv | synas |
| presens | syns |
| preteritum | syntes |
| supinum | synts |

## 词组搭配 (Collocations)

- `synas på` — 在……上看得出
- `det syns att …` — 看得出……
- `synas till` — 露面

## 例句 (Sentences)

- 🇸🇪 Det syns inte i priset att trappor kostar extra. — 🇨🇳 价格里看不出爬楼梯要额外收费。
- 🇸🇪 Stjärnorna syns bra i kväll. — 🇨🇳 今晚星星看得很清楚。
- 🇸🇪 Fläcken syns inte på den mörka tröjan. — 🇨🇳 污渍在深色上衣上看不出来。
