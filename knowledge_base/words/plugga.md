# plugga — verb

📖 中文：学习；用功（口语，比 studera 随意） · English: to study (informal)

🇸🇪 Förklaring: läsa och öva för att lära sig något, till exempel inför ett prov

发音提示：/ˈplɵɡːa/ — u 读短音 /ɵ/；gg 使 u 变短，g 拉长

## 语法变形 (Forms)

| 形式 | 变形 |
|------|------|
| infinitiv | plugga |
| presens | pluggar |
| preteritum | pluggade |
| supinum | pluggat |
| imperativ | plugga |

## 词组搭配 (Collocations)

- `plugga till ett prov` — 为考试复习
- `plugga svenska` — 学瑞典语

## 例句 (Sentences)

- 🇸🇪 Jag pluggar varje dag. — 🇨🇳 我每天都学习。
- 🇸🇪 Vi pluggar svenska på kvällen. — 🇨🇳 我们晚上学瑞典语。
- 🇸🇪 Hon pluggar till ett prov i morgon. — 🇨🇳 她在为明天的考试复习。
