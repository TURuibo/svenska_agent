# anse — verb (grupp 4, oregelbundet)

Zh: 认为；觉得（正式意见） · English: to consider; to think; to be of the opinion
发音提示：AN-se（两个音节）

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| infinitiv | anse |
| presens | anser |
| preteritum | ansåg |
| supinum | ansett |
| imperativ | anse! |

## 词组搭配 (Collocations)

- `jag anser att` — 我认为（接 att-bisats）
- `anse det nödvändigt` — 认为有必要
- `anse sig ha rätt` — 认为自己有理
- `allmänt ansett` — 普遍认为

## 例句 (Sentences)

- Jag anser att det behövs fler cykelvägar i staden. — 我认为城市里需要更多自行车道。
- Vi anser att detta är ett problem som måste lösas. — 我们认为这是一个必须解决的问题。
- Hon ansåg att beslutet var fel och protesterade. — 她认为那个决定是错误的，于是提出了抗议。

## 词族 / 同义 / 反义 (Relations)

- 词族: [[åsikt]]（意见；看法）, anseende（声誉）
- 同义词: [[tycka]]（觉得，较口语）, [[mena]]（意指）

## 用法提示 (Usage Notes)

- `anse` vs `tycka`：两者都表示"认为"，但 `anse` 更正式、书面，常用于意见文章/政治表述
- `tycka` 更口语、常用于个人感受（喜欢/不喜欢）；`anse` 侧重理性判断
- 固定句型：`Jag anser att + bisats`（我认为……），常见于 insändare、辩论
- 不规则动词：presens = `anser`，preteritum = `ansåg`（别写成 `ansåde`）
