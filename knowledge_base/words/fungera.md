# fungera — verb (grupp 1)

📖 中文：运转；起作用；工作（正常） · English: to function; to work; to operate
发音提示：[fʊŋˈɡeːra] — "fung-GE-ra"

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| infinitiv | fungera |
| presens | fungerar |
| preteritum | fungerade |
| supinum | fungerat |
| imperativ | fungera! |

## 词组搭配 (Collocations)

- `fungerar inte` — 不工作；坏了
- `fungerar bra` — 运转良好
- `fungera som` — 充当；起到…的作用

## 例句 (Sentences)

- 🇸🇪 Kylskåpet fungerar inte sedan igår. — 🇨🇳 冰箱从昨天起就不工作了。
- 🇸🇪 Det nya systemet fungerar bra. — 🇨🇳 新系统运转良好。
- 🇸🇪 Hissen fungerar inte — ta trappan! — 🇨🇳 电梯坏了——走楼梯吧！

## 词族 / 同义 / 反义 (Relations)

- 词族: [[funktion]] (功能), [[funktionell]] (功能性的)

## 用法提示 (Usage Notes)

- `fungera` 用于描述机器、系统、关系等能否正常运作，不用于人"工作"（那用 `arbeta` 或 `jobba`）。
- `Det fungerar inte` 是报修/投诉时最常用的表达，意思是"坏了/不好使"。
