# så — adverb / konjunktion

📖 中文：这样，那么，如此；所以 · English: so, like that; so (conj.)

🇸🇪 Förklaring: på det här viset; i hög grad, väldigt; och därför, som en följd av det

发音提示：/soː/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| adverb | så |
| konjunktion | så |

## 词组搭配 (Collocations)

- `så här` — 像这样
- `så fort som möjligt` — 尽快
- `så att` — 以便/所以
- `så gott som` — 几乎
- `så ... som` — 和……一样……
- `Är det så?` — 是这样吗？

## 例句 (Sentences)

**义项1 副词：这样/那样（指代方式）:**

- 🇸🇪 "Är det så i alla val?" frågar Sandro. — 🇨🇳 「所有选举都是这样吗？」桑德罗问。
- 🇸🇪 Så gör man. — 🇨🇳 就是这样做的。

**义项2 副词：那么/如此（+ 形容词，程度）:**

- 🇸🇪 Det är så kallt idag! — 🇨🇳 今天好冷！
- 🇸🇪 Hon är så snäll. — 🇨🇳 她人很好。

**义项3 连词：所以（不倒装）:**

- 🇸🇪 Vi var bortresta på valdagen så vi röstade veckan innan. — 🇨🇳 选举日我们不在，所以提前一周投了票。
- 🇸🇪 Det regnade så vi stannade hemma. — 🇨🇳 下雨了，所以我们待在家里。

**义项4 副词：然后/那么（句首，引起倒装）:**

- 🇸🇪 Först äter vi, så går vi hem. — 🇨🇳 我们先吃饭，然后回家。（口语，可与 sedan 近）

## 用法提示 (Usage Notes)

- ⚠️ **连词 så vs 副词 så**：
  - **连词 `så`**（= 所以，连接两个主句）：**不倒装**，主语在动词前 → `…så vi röstade` / `…så jag stannade`。
  - **副词 `så`**（句首，= 那么/这样）：占第一位，引起 **V2 倒装**，动词在主语前 → `Så gör man.`、`Så kan det vara.`
- `så` + 形容词/副词 = 如此（`så stor`）；`så … att …` = 如此……以至于……。
