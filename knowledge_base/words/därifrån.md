# därifrån — adverb

📖 中文：从那里 · English: from there

🇸🇪 Förklaring: från det stället som man nämnde

发音提示：/ˈdæːrˌifrɔn/ — ä 在 r 前读 /æː/；重音在 där

| 形式 | 瑞典语 |

| 相关 | därifrån ↔ härifrån（从这里） |

## 词组搭配 (Collocations)

- `gå därifrån` — 从那里离开
- `komma därifrån` — 来自那里
