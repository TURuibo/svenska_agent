# trygga — verb (grupp 1)

📖 中文：保障、确保（使……安全/有保障） · English: to secure, to safeguard, to ensure
发音提示：/ˈtrʏɡːa/，规则第 1 组动词。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) trygga |
| Imperativ | trygga! |
| Presens | tryggar |
| Preteritum | tryggade |
| Supinum | (har) tryggat |
| Perfekt particip | tryggad / tryggat / tryggade |

## 词组搭配 (Collocations)

- `trygga pensionerna` — 保障养老金
- `trygga jobben` — 保住 / 保障就业
- `trygga välfärden` — 保障福利
- `trygga framtiden` — 保障未来
- `trygga ngns trygghet` — 保障某人的安全

## 例句 (Sentences)

- 🇸🇪 Regeringen vill trygga jobben. — 🇨🇳 政府想保障就业。
- 🇸🇪 Vi måste trygga barnens framtid. — 🇨🇳 我们必须保障孩子们的未来。
- 🇸🇪 Pengarna ska trygga vården. — 🇨🇳 这笔钱将用于保障医疗。

## 用法提示 (Usage Notes)

- 规则第 1 组动词：trygga–tryggar–tryggade–tryggat。
- 常见于**新闻/政治语境**（trygga jobben/pensionerna/välfärden）——"保障某事物"。
- 与形容词 [[trygg]] 同形于"trygga"（复数/定形），靠语境与句法区分：动词后常带宾语。
