# låta — verb (oregelbundet)

📖 中文：①听起来 / 发出声音 ②让、允许 · English: ①to sound ②to let, allow
发音提示：/ˈloːta/，å 发长 [oː]（像中文"奥"）；不规则动词。

## 语法变形 (Forms)

> ⚠️ 不规则（强变化）：preteritum 元音变 å → ä。

| Form | Swedish |
|------|---------|
| Infinitiv | (att) låta |
| Imperativ | låt! |
| Presens | låter |
| Preteritum | lät |
| Supinum | (har) låtit |

## 词组搭配 (Collocations)

**义项① 听起来 / 发声**
- `det låter bra` — 听起来不错
- `det låter konstigt` — 听起来很奇怪
- `låta som` — 听起来像……

**义项② 让 / 允许**
- `låta ngn göra ngt` — 让某人做某事
- `låt mig ...` — 让我……
- `låta bli` — 别做、住手（partikelverb）
- `låta ngt vara` — 别动某物、由它去

## 例句 (Sentences)

**义项① 听起来 / 发声**
- 🇸🇪 Det låter bra! — 🇨🇳 听起来不错！
- 🇸🇪 Musiken lät högt. — 🇨🇳 音乐声很大。

**义项② 让 / 允许**
- 🇸🇪 Låt mig hjälpa dig. — 🇨🇳 让我帮你。
- 🇸🇪 Mina föräldrar lät mig stanna uppe sent. — 🇨🇳 我父母让我熬夜到很晚。
- 🇸🇪 Låt bli att röra mina saker! — 🇨🇳 别碰我的东西！

## 词族 / 同义 / 反义 (Relations)

- 词族: [[ljud]]（声音，名词）、ljuda（发声）
- 同义词: ②义 ≈ tillåta（允许，正式）、låta bli ≈ sluta（停止）
- 反义词: ②义 ≈ förbjuda（禁止）
- 主题: —

## 用法提示 (Usage Notes)

- 一词两义，很高频：①**听起来**（*det låter bra*）②**让/允许**（*låt mig*）。
- 不规则变形要记：låta–låter–**lät**–låtit。
- partikelverb **låta bli**（别做/住手）非常常用：*Låt bli!* = 住手！别碰！
- 命令式 *Låt* + 宾语 + 原形 = "让……"：*Låt honom sova.*（让他睡。）
- ⚠️ 别和名词 *låt*（歌曲，en låt）混——同形不同类。
