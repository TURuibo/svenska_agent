# simhall — substantiv (en)

📖 中文：游泳馆 · English: indoor swimming pool

🇸🇪 Förklaring: byggnad med bassänger inomhus där man kan simma och bada

发音提示：SIM-hall

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Singular obestämd | en simhall |
| Singular bestämd | simhallen |
| Plural obestämd | simhallar |
| Plural bestämd | simhallarna |

## 词组搭配 (Collocations)

- `gå till simhallen` — 去游泳馆
- `simhallens öppettider` — 游泳馆的开放时间 → see [[öppettid]]

## 例句 (Sentences)

- 🇸🇪 Simhallen öppnar klockan sex. — 🇨🇳 游泳馆六点开门。
- 🇸🇪 Vi går till simhallen på lördag. — 🇨🇳 我们周六去游泳馆。
- 🇸🇪 Det finns en stor simhall i stan. — 🇨🇳 城里有一座大游泳馆。
