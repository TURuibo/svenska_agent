# fet — adjektiv

📖 中文：肥的 · English: fat
发音提示：/feːt/

## 语法变形 (Forms)

| form | en-form | ett-form | plural/bestämd |
|------|---------|----------|----------------|
| positiv obestämd | en fet (katt) | ett fett (djur) | feta (djur) |
| positiv bestämd | den feta (katten) | det feta (djuret) | de feta (djuren) |
| komparativ | fetare | | |
| superlativ | fetast / fetaste | | |

**Obs:** ett-form *fett* (dubbel-t), oförändrad komparation.

## 词组搭配 (Collocations)

- `en fet katt` — 一只肥猫
- `fet mat` — 油腻的食物
- `feta djur` — 肥胖的动物

## 例句 (Sentences)

- 🇸🇪 Den feta katten sover hela dagen. — 🇨🇳 那只肥猫整天都在睡觉。
- 🇸🇪 Undvik fet mat om du vill vara frisk. — 🇨🇳 如果你想保持健康，要避免油腻的食物。
- 🇸🇪 Det feta djuret är svårt att flytta. — 🇨🇳 那只肥胖的动物很难移动。
