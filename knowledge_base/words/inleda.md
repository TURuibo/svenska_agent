# inleda — verb (grupp 2a)

📖 中文：开始；开启 · English: to initiate; to open; to start
发音提示：in-LE-da（重音在第二音节）

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| infinitiv | inleda |
| presens | inleder |
| preteritum | inledde |
| supinum | inlett |
| imperativ | inled! |

## 词组搭配 (Collocations)

- `inleda ett samtal` — 开始一段对话 → see [[inleda-ett-samtal]]
- `inleda ett möte` — 开始一个会议
- `inleda ett samarbete` — 开始合作
- `inleda med att` — 以……开始

## 例句 (Sentences)

- 🇸🇪 I Sverige är det vanligt att inleda ett samtal med att prata om vädret. — 🇨🇳 在瑞典，用谈天气来开始一段对话是很常见的。
- 🇸🇪 Mötet inleddes med en kort presentation av projektet. — 🇨🇳 会议以项目的简短介绍开始。
- 🇸🇪 Hon inledde sin karriär som lärare och blev sedan rektor. — 🇨🇳 她以教师生涯开始，后来成为了校长。

## 用法提示 (Usage Notes)

- 比 börja 更正式：常用于会议、演讲、合作等正式场合开始
- inleda + substantiv（名词宾语）：inleda ett samtal/möte/samarbete
- inleda med att + infinitiv：以……方式开始
- 词根：in-（进入）+ leda（引导）
