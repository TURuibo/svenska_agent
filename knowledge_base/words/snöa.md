# snöa — verb (grupp 1)

📖 中文：下雪 · English: to snow
发音提示：[ˈsnøːa] — 两音节

## 语法变形 (Forms)

| form | böjning |
|------|---------|
| infinitiv | (att) snöa |
| presens | snöar |
| preteritum | snöade |
| supinum | snöat |
| imperativ | snöa |

## 词组搭配 (Collocations)

- `det snöar` — 正在下雪（非人称句）
- `det snöade nästan varje dag` — 几乎每天都下雪
- `snöa ymnigt` — 大雪纷飞

## 例句 (Sentences)

- [[sent-vintern-var-mycket-kall]] 🇸🇪 Vintern var mycket kall — det snöade nästan varje dag. 🇨🇳 冬天非常冷——几乎每天都在下雪。
- 🇸🇪 Det snöar igen! Kom in! — 🇨🇳 又下雪了！进来吧！
- 🇸🇪 I norra Sverige snöar det redan i oktober. — 🇨🇳 在瑞典北部，十月就开始下雪了。

## 用法提示 (Usage Notes)

- `snöa` 总以 `det` 作形式主语：**det snöar / det snöade**，类似 `regna` (下雨)。
- 与 `regna` 对比：*det regnar* (下雨) — *det snöar* (下雪) — *det haglar* (下冰雹)。
