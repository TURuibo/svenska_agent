# all — pronomen / adjektiv

📖 中文：所有的，全部的 · English: all, every, everything
发音提示：/al/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| en-ord | all |
| ett-ord | allt |
| plural | alla |
| substantivt (一切) | allt |
| substantivt (所有人) | alla |
| genitiv | allas |

## 词组搭配 (Collocations)

- `alla länder` — 所有国家
- `allt möjligt` — 各种各样的东西
- `i alla val` — 在所有选举中
- `allt jättegott` — 一切都非常好吃
- `trots allt` — 尽管如此

## 例句 (Sentences)

- 🇸🇪 Alla länder påverkas av klimatförändringarna men på olika sätt. — 🇨🇳 所有国家都受气候变化影响，但方式不同。
- 🇸🇪 Om de bjuds på mat så är allt jättegott även om de inte tycker det. — 🇨🇳 如果被请吃饭，即使不喜欢也说一切都很好吃。
- 🇸🇪 Alla barn i klassen fick en bok. — 🇨🇳 班上所有孩子都得到一本书。
- 🇸🇪 Jag har ätit allt. — 🇨🇳 我把一切都吃完了。
- 🇸🇪 All mat är slut. — 🇨🇳 所有食物都吃完了。

## 用法提示 (Usage Notes)

- 形容词式 `all` 修饰不可数/单数：`all mat`（en-ord）、`allt arbete`（ett-ord）、`alla` + 复数名词。名词前常带定冠词时：`all maten`、`alla människorna`。
- 单独作代词：`allt` = 一切（事物），`alla` = 所有人。
- ⚠️ `allting` = 一切（同义，口语），`allt` 也可作副词 `allt fler` = 越来越多。
