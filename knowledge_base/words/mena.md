# mena — verb (grupp 1)

📖 中文：认为；意思是 · English: to mean, think, hold

🇸🇪 Förklaring: 1) tycka eller anse något; 2) vilja säga något med sina ord

发音提示：/ˈmeːna/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) mena |
| Presens | menar |
| Preteritum | menade |
| Supinum | menat |
| Imperativ | mena! |
| Perfekt particip | menad |
| S-passiv (presens) | menas |
| S-passiv (preteritum) | menades |

## 词组搭配 (Collocations)

- `mena att …` — 认为 / 主张……（文中：Han menar att det är bra …）
- `Vad menar du?` — 你是什么意思？
- `mena allvar` — 是认真的 / 说真的
- `Vad menas med …?` — ……是什么意思？

## 例句 (Sentences)

**义项1 认为、主张:**
- 🇸🇪 Han menar att det är bra att få lära sig att både vinna och förlora. — 🇨🇳 他认为学会赢也学会输是好事。
- 🇸🇪 Många var kritiska och menade att man måste tävla för att bli framgångsrik. — 🇨🇳 很多人持批评态度，认为必须参赛才能成功。

**义项2 意思是、指的是:**
- 🇸🇪 Vad menar du med det? — 🇨🇳 你这么说是什么意思？
- 🇸🇪 Vad menas med ordet "satsning"? — 🇨🇳 "satsning" 这个词是什么意思？

**义项3 有意、本意:**
- 🇸🇪 Jag menade inte att göra dig ledsen. — 🇨🇳 我不是有意让你难过的。

## 用法提示 (Usage Notes)

- 规则第 1 组动词：mena – menar – menade – menat。
- 表示「认为」时，`mena att …` 比 `tycka att …` 更像「主张 / 声称」，常用于转述别人的立场（文中即是）。
- 后面接 att 从句：Han menar **att** … 见 [[grammar-att-bisats]]。
