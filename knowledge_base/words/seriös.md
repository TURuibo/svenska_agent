# seriös — adjektiv

📖 中文：认真的、严肃的、正规的 · English: serious
发音提示：/seriˈøːs/；se-ri-ÖS，重音落在最后一个音节，`ö` 读长音。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Utrum | seriös |
| Neutrum / adverb | seriöst |
| Plural / bestämd | seriösa |
| Komparativ | seriösare |
| Superlativ | seriösast |
| Superlativ bestämd | seriösaste |

## 词组搭配 (Collocations)

- `satsa seriöst` — 认真投入（副词用法）
- `ta något seriöst` — 把某事当回事
- `ett seriöst företag` — 一家正规/靠谱的公司
- `en seriös elev` — 一个认真的学生

## 例句 (Sentences)

**义项1 认真地、严肃地 (attityd / adverb):**

- 🇸🇪 Inom många andra idrotter fick barn inte satsa seriöst. — 🇨🇳 在许多其他运动里，孩子不被允许认真投入。
- 🇸🇪 Han är en seriös elev som läser varje dag. — 🇨🇳 他是个认真的学生，每天学习。

**义项2 正规的、可靠的 (om företag, köpare):**

- 🇸🇪 Det här är ett seriöst företag med bra recensioner. — 🇨🇳 这是一家评价很好的正规公司。

## 用法提示 (Usage Notes)

- 文中的 `satsa seriöst` 里，`seriöst` 其实是**形容词的中性 -t 形式当副词用**（瑞典语常这样构成副词：`Han arbetar seriöst`）。参见 [[grammar-adjektiv-bojning]]。
- 想说「（病情/问题）严重」时更常用 [[allvarlig]]；`seriös` 偏「认真、严肃、可信」。
- 副词构成详解: [[grammar-adverb-av-adjektiv]]；词组 [[satsa-seriöst]]。
