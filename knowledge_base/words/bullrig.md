# bullrig — adjektiv

| Form | Exempel |

| Utrum sg. indef. | en bullrig gata |
| Neutrum sg. indef. | ett bullrigt område |
| Definite sg. | den/det bullriga stadsdelen |
| Plural indef. | bullriga gator |
