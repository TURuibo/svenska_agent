# jobbig — adjektiv

📖 中文：累人的、费劲的；麻烦的、难搞的 · English: tough, tiring, troublesome, annoying
发音提示：/ˈjɔbːɪɡ/，j 发 [j]（像英语 y）；bb 短促。口语高频词。

## 语法变形 (Forms)

| Form | Example |
|------|---------|
| En-form (grundform) | jobbig |
| Ett-form | jobbigt |
| Bestämd form / Plural | jobbiga |
| Komparativ | jobbigare |
| Superlativ | jobbigast |

## 词组搭配 (Collocations)

- `en jobbig dag` — 累人的一天
- `det är jobbigt` — 真累 / 真烦人
- `jobbig person` — 难搞的人
- `jobbigt väder` — 难受的天气（太热/太闷）
- `ha det jobbigt` — 日子不好过、过得辛苦
- `vad jobbigt!` — 太糟了 / 真够呛！（表同情）

## 例句 (Sentences)

- 🇸🇪 Det har varit en jobbig dag. — 🇨🇳 今天真累。
- 🇸🇪 Det är jobbigt att vakna så tidigt. — 🇨🇳 这么早起床真难受。
- 🇸🇪 Han kan vara lite jobbig ibland. — 🇨🇳 他有时候挺难搞的。
- 🇸🇪 Vad jobbigt för dig! — 🇨🇳 你真不容易 / 太糟心了！

## 词族 / 同义 / 反义 (Relations)

- 词族: [[jobba]]（工作，口语动词）、[[jobb]]（工作/活儿，名词）
- 同义词: [[besvärlig]]（麻烦的）、ansträngande（费力的）、tröttsam（累人的）
- 反义词: [[lätt]]（轻松的、容易的）、skön（舒服的）
- 主题: [[topic-karaktarsord]]

## 用法提示 (Usage Notes)

- **口语高频词**，从 *jobb*（工作）派生，字面"像工作一样"→ 累/费劲/麻烦。
- 用途极广：累（*jobbig dag*）、难搞的人（*jobbig person*）、烦人的事（*det är jobbigt*）。
- *Vad jobbigt!* 是常见**共情**用语，表示"真够呛/太糟了"，对别人的难处表示同情。
- *ha det jobbigt* = 日子过得辛苦（≈ *ha det svårt*）。
