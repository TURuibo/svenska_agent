# framställa — verb (v.2)

📖 中文：呈现；描绘 · English: to portray / depict
发音提示：FRAM-stäl-la

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) framställa |
| Presens | framställer |
| Preteritum | framställde |
| Supinum | framställt |

## 词组搭配 (Collocations)

- `framställas i media` — 在媒体中被呈现（s-passiv）
- `framställa någon som...` — 把某人描绘成……
- `en falsk bild` — 一幅虚假的画面（常搭配使用）

## 例句 (Sentences)

- 🇸🇪 Hur framställs rika människor i filmer? — 🇨🇳 富人在电影里是怎样被呈现的？
- 🇸🇪 Media framställer honom som en hjälte. — 🇨🇳 媒体把他描绘成英雄。
- 🇸🇪 Boken framställer historien på ett nytt sätt. — 🇨🇳 这本书以新的方式呈现了这段历史。
