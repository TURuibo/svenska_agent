# polcirkel — substantiv (en)

📖 中文：极圈 · English: polar circle, Arctic Circle
发音提示：['puːlˌsɪrkəl]，复合词重音在 pol-

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Obestämd sg | en polcirkel |
| Bestämd sg | polcirkeln |
| Obestämd pl | polcirklar |
| Bestämd pl | polcirklarna |

## 词组搭配 (Collocations)

- `norra polcirkeln` — 北极圈（66.5°N）
- `södra polcirkeln` — 南极圈（66.5°S）
- `norr om polcirkeln` — 北极圈以北 → see [[norr-om-polcirkeln]]
- `söder om polcirkeln` — 南极圈以南

## 例句 (Sentences)

- 🇸🇪 I Kiruna, som ligger norr om polcirkeln, händer något ännu märkligare. — 🇨🇳 在基律纳——位于北极圈以北——会发生更奇特的事。
- 🇸🇪 Polcirkeln ligger på ungefär 66,5 graders nordlig latitud. — 🇨🇳 北极圈大约在北纬66.5度。
- 🇸🇪 Kiruna ligger på 68 grader norr, så staden är norr om polcirkeln. — 🇨🇳 基律纳在北纬68度，所以这座城市在北极圈以北。

## 用法提示 (Usage Notes)

- 复合词：pol（极点）+ cirkel（圆圈）
- 北极圈 = norra polcirkeln；南极圈 = södra polcirkeln
- Kiruna（基律纳）是瑞典最北部的城市，在北极圈以北，极夜约持续28天
