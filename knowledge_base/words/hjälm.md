# hjälm — substantiv (en)

📖 中文：头盔 · English: helmet
发音提示：`hj-` 里的 `h` 不发音，读 "jälm"（[jɛlm]）。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Obestämd sg | en hjälm |
| Bestämd sg | hjälmen |
| Obestämd pl | hjälmar |
| Bestämd pl | hjälmarna |

## 词组搭配 (Collocations)

- `använda / bära hjälm` — 戴头盔
- `ta på sig / ta av sig hjälmen` — 戴上 / 摘下头盔
- `cykelhjälm / skidhjälm / motorcykelhjälm` — 自行车 / 滑雪 / 摩托头盔
- `hjälmplikt` — 强制戴头盔的规定
- `glömma hjälmen hemma` — 把头盔忘在家里

## 例句 (Sentences)

- 🇸🇪 Polisen råder förarna att använda hjälm. — 🇨🇳 警方建议骑行者戴头盔。 → [[sent-polisen-råder-förarna-att-använda-hjälm]]
- 🇸🇪 Barn under femton år måste bära hjälm när de cyklar. — 🇨🇳 十五岁以下的儿童骑自行车时必须戴头盔。
- 🇸🇪 Jag glömde hjälmen hemma. — 🇨🇳 我把头盔忘在家里了。
- 🇸🇪 Hjälmen skyddar huvudet vid fall. — 🇨🇳 头盔在摔倒时保护头部。
