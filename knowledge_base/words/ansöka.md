# ansöka — verb (grupp 2b)

📖 中文：申请 · English: to apply (for)
发音提示：[ˈanˌsøːka]，an- 前缀重读；partikel 型复合动词，不可拆。

## 语法变形 (Forms)

| infinitiv | presens | preteritum | supinum | imperativ |
|-----------|---------|------------|---------|-----------|
| ansöka | ansöker | ansökte | ansökt | ansök! |

## 词组搭配 (Collocations)

- `ansöka om ersättning` — 申请补偿金 → see [[ansöka-om-ersättning]]
- `ansöka om plats på förskola` — 申请幼儿园名额 → see [[förskola]]
- `ansöka om uppehållstillstånd` — 申请居留许可
- `ansöka hos Försäkringskassan` — 向社会保险局申请 → see [[försäkringskassan]]

## 例句 (Sentences)

- 🇸🇪 Sedan ansöker du om ersättning hos Försäkringskassan. — 🇨🇳 然后你向社会保险局申请补偿金。
- 🇸🇪 Vi ansökte om förskoleplats i januari. — 🇨🇳 我们一月份申请了幼儿园名额。
- 🇸🇪 Har du ansökt om föräldrapenning? — 🇨🇳 你申请育儿津贴了吗？
- 🇸🇪 Man kan ansöka digitalt med BankID. — 🇨🇳 可以用 BankID 在线申请。

## 用法提示 (Usage Notes)

- 📐 固定介词 **ansöka om + 名词**（申请某物），向谁申请用 *hos*：*ansöka om X hos Försäkringskassan*。
- *ansöka* 偏正式/书面（官方表格、网站），口语常直接说 *söka*：*söka plats, söka jobb*。
- 名词是 *en ansökan*（bestämd: ansökan，plural: ansökningar）——注意不规则。
