# stoppa — verb

📖 中文：停止；制止；塞入 · English: to stop, halt; to stuff, insert
发音提示：STOP-pa

## 语法变形 (Forms)

| Form | |
|------|-|
| Infinitiv | stoppa |
| Presens | stoppar |
| Preteritum | stoppade |
| Supinum | stoppat |
| Imperativ | stoppa! |
| Passiv presens | stoppas |

## 词组搭配 (Collocations)

- `stoppa någon` — 制止某人
- `stoppa trafiken` — 阻断交通
- `stoppas av polisen` — 被警察拦下
- `stoppa in` — 塞进去；插入

## 例句 (Sentences)

**义项1 — 停止/制止：**
- 🇸🇪 Polisen försökte stoppa bilen som körde för fort. — 🇨🇳 警察试图拦下超速行驶的车辆。
- 🇸🇪 Dammet måste stoppas för att arbetarna ska vara säkra. — 🇨🇳 必须制止粉尘扩散，以确保工人安全。

**义项2 — 塞入/放入：**
- 🇸🇪 Hon stoppade in pengarna i väskan. — 🇨🇳 她把钱塞进包里。

## 用法提示 (Usage Notes)

- "stoppa" (v.1) 是及物动词，接受语为被停止的人/物。
- 被动式：stoppas（正在被制止）；stoppades（被制止了）。
- 注意与 "stanna"（自动停下来）区别：stoppa 是他动（让……停），stanna 是自动（自己停）。
