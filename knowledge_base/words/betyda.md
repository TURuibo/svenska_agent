# betyda — verb (grupp 2)

📖 中文：意思是；意味着；有重要意义 · English: to mean; to signify; to matter

🇸🇪 Förklaring: ha en viss mening; vara viktig för någon

发音提示：be-TY-da，重音在第二音节 `ty`（`y` 读 [yː]，圆唇的"衣"）。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | betyda |
| Presens | betyder |
| Preteritum | betydde |
| Supinum | betytt |
| Imperativ | betyd |

> 导入块里写的是 "v.1"，但实际变位 `betyder / betydde / betytt` 属于**第 2 组**（不是 -ar / -ade / -at）。

## 词组搭配 (Collocations)

- `betyda mycket / lite / ingenting` — 意义很大 / 很小 / 毫无意义
- `betyda något för någon` — 对某人有意义
- `Vad betyder …?` — ……是什么意思？
- `Det betyder att …` — 这意味着……
- `betyda stopp / fara` — 表示"停 / 危险"（标志）

## 例句 (Sentences)

**义项1 意思是 (to mean — of words):**

- 🇸🇪 Vad betyder det här ordet? — 🇨🇳 这个词是什么意思？
- 🇸🇪 Ordet tack betyder thank you på engelska. — 🇨🇳 "tack"这个词在英语里的意思是 thank you。

**义项2 意味着 / 表示 (to imply, signify):**

- 🇸🇪 Rött ljus betyder stopp. — 🇨🇳 红灯表示停。
- 🇸🇪 Det betyder att vi måste vänta. — 🇨🇳 这意味着我们得等。
- 🇸🇪 Det betyder att man bara får lämna elsparkcyklarna på särskilda parkeringsplatser. — 🇨🇳 这意味着人们只能把电动滑板车停放在指定的停车位上。（新闻体：宣布一项规定的后果） → [[sent-det-betyder-att-man-bara-får-lämna]]

**义项3 有重要意义 (to matter):**

- 🇸🇪 Du betyder mycket för mig. — 🇨🇳 你对我很重要。
- 🇸🇪 Det betyder inte så mycket. — 🇨🇳 这没那么重要。
- 🇸🇪 Jag insåg snabbt hur mycket en vuxen som lyssnar kan betyda. — 🇨🇳 我很快就意识到，一个愿意倾听的成年人能起多大的作用。 → [[sent-själv-har-jag-jobbat-som-ledare-i-en]]

## 用法提示 (Usage Notes)

- 三个义项都用同一个动词，看**宾语 / 搭配**判断：问词义 → 义项1；`betyder att` → 义项2；`betyda mycket för` → 义项3。
- 在 `hur mycket … kan betyda`（间接疑问句）里，词序不倒装，见 [[grammar-indirekt-fraga]]。
- `Det betyder att …` 也是新闻里解释**决定 / 规定带来什么后果**的固定句式；`att` 从句里副词 `bara` 放在定式动词 `får` 前（BIFF），见 [[sent-det-betyder-att-man-bara-får-lämna]]。
