# sända — verb (grupp 2)

📖 中文：播送；播出；发送 · English: to broadcast; to send
发音提示：['sɛnda]

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| infinitiv | sända |
| presens | sänder |
| preteritum | sände |
| supinum | sänt |
| imperativ | sänd! |

## 词组搭配 (Collocations)

- `sända tv och radio` — 播送电视和广播
- `sända live` — 直播
- `en sändning` — 一次播出

## 例句 (Sentences)

- 🇸🇪 Det har blivit mycket dyrare för SVT och Sveriges Radio att sända tv och radio. — 🇨🇳 SVT和瑞典广播电台播送电视和广播的成本大幅上涨。
- 🇸🇪 Matchen sänds direkt i kväll klockan åtta. — 🇨🇳 比赛今晚八点直播。
- 🇸🇪 Kan du sända mig dokumentet via mejl? — 🇨🇳 你能通过邮件把文件发给我吗？

## 用法提示 (Usage Notes)

- `sända` 是强变化动词（sände/sänt 无 -de/-t 词尾常规变化，属不规则 2b 组）。
- 区分：`sända` 更正式、常用于广播/媒体语境；`[[skicka]]` 更口语、通用于日常"发送"。
