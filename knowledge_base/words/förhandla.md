# förhandla — verb

📖 中文：谈判；协商 · English: to negotiate

🇸🇪 Förklaring: prata med någon för att komma överens om något

发音提示：/fœrˈhandla/ — 重音在 -hand-；förh- 中 h 要发音

## 语法变形 (Forms)

| infinitiv | förhandla |
| presens | förhandlar |

| supinum | förhandlat |
| imperativ | förhandla |

## 词组搭配 (Collocations)

- `förhandla med någon` — 与某人谈判
- `förhandla om lön` — 就工资谈判

## 例句 (Sentences)

- 🇸🇪 Partierna förhandlar om en ny regering. — 🇨🇳 各政党正在就组建新政府谈判。
- 🇸🇪 Jag vill förhandla om priset. — 🇨🇳 我想就价格谈判。
- 🇸🇪 Facket förhandlar med arbetsgivaren. — 🇨🇳 工会与雇主谈判。
