# hundra — räkneord

📖 中文：一百 · English: hundred

🇸🇪 Förklaring: talet 100, tio gånger tio

发音提示：/ˈhɵndra/ — u 读短央 [ɵ]；重音第一音节

## 语法变形 (Forms)

| 形式 | 说明 |
|------|------|
| hundra | 100，前面不加 "ett"（ett hundra 也可） |
| tvåhundra, trehundra | 200, 300（连写） |
| ett hundra / hundratal (ett) | 作名词 |

## 词组搭配 (Collocations)

- `hundra kronor` — 一百克朗
- `hundratals` — 几百
- `tvåhundrafemtio` — 250

## 例句 (Sentences)

- 🇸🇪 Hundra procent! — 🇨🇳 百分之百！
