# övergångsställe — substantiv (ett)

📖 中文：人行横道、斑马线 · English: pedestrian crossing, crosswalk, zebra crossing
发音提示：Ö-ver-gångs-STÄL-le

## 语法变形 (Forms)

| Form | Exempel |
|------|---------|
| Sg. indef. | ett övergångsställe |
| Sg. def. | övergångsstället |
| Pl. indef. | övergångsställen |
| Pl. def. | övergångsställena |

## 词组搭配 (Collocations)

- `korsa vid övergångsstället` — 在人行横道处过马路
- `välbelyst övergångsställe` — 照明良好的人行横道
- `stanna för fotgängare vid övergångsstället` — 在人行横道处为行人停车

## 例句 (Sentences)

- 🇸🇪 Gå alltid över gatan vid ett övergångsställe. — 🇨🇳 过马路时一定要走人行横道。
- 🇸🇪 Det välbelysta övergångsstället gör det tryggare att gå på kvällen. — 🇨🇳 照明良好的人行横道使夜间步行更安全。
- 🇸🇪 Bilar måste stanna för fotgängare vid övergångsstället. — 🇨🇳 汽车必须在人行横道处为行人停车。

## 用法提示 (Usage Notes)

- A long compound word: *över* (over) + *gång* (walking) + *ställe* (place).
- In Sweden, drivers are legally required to stop for pedestrians at *övergångsställen*.
