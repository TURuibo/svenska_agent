# sund — adjektiv

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Positiv utrum (en-ord) | sund |
| Positiv neutrum (ett-ord) | sunt |
| Positiv plural/bestämd | sunda |
| Komparativ | sundare |
| Superlativ | sundast / sundaste |

## 词组搭配 (Collocations)

- `sund livsstil` — 健康的生活方式
