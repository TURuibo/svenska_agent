# själv — pronomen

📖 中文：自己、本身 · English: oneself, self

🇸🇪 Förklaring: används för att betona en viss person eller sak, eller för att säga att någon gör något utan hjälp

发音提示：/ɧɛlv/；`sj` 读 sj-ljud /ɧ/（舌后摩擦音，类似 sh 与 x 之间），`ä` 在 lv 前读短 /ɛ/。

## 例句 (Sentences)

**义项1 反身代词的强调形式（sig själv）:**

- 🇸🇪 För att göra den monotona träningen roligare och för att motivera sig själv satte han upp mål efter vägen. — 🇨🇳 为了让单调的训练有趣些、也为了激励自己，他一路上给自己设小目标。
- 🇸🇪 Jag tittar på mig själv i spegeln. — 🇨🇳 我看着镜子里的自己。

**义项2 独自、亲自 (by oneself):**

- 🇸🇪 Barnet vill äta själv. — 🇨🇳 孩子想自己吃。
- 🇸🇪 Vi bakade kakorna själva. — 🇨🇳 我们自己烤的饼干。

**义项3 本身 (själva + 名词):**

- 🇸🇪 Själva idén är bra. — 🇨🇳 这个想法本身就很好。

## 用法提示 (Usage Notes)

- **`sig` 与 `sig själv`**：`sig`（反身代词）是必须的宾语；`själv` 加在它后面起**强调**作用：`motivera sig själv` = 激励「他自己」。参见 [[grammar-reflexivt-pronomen]]、[[grammar-sin-sina]]。
- 变形必须与所指对象的数、性一致：`jag själv`（我自己），`barnet självt`（ett-词），`vi själva`（我们自己，复数用 `själva`）。
- 放在名词前/后表示「本身」：`själva idén` / `idén själv`。
