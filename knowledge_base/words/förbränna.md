# förbränna — verb (grupp 2a)

📖 中文：焚烧；燃烧；氧化 · English: to incinerate; to burn; to combust
发音提示：för-BREN-na（重音在第二音节）

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| infinitiv | förbränna |
| presens | förbränner |
| preteritum | förbrände |
| supinum | förbränt |
| passiv presens | förbränns |

## 词组搭配 (Collocations)

- `förbränna avfall` — 焚烧废物
- `som förbränns` — 被焚烧的（关系从句）
- `avfall som förbränns` — 被焚烧的废物
- `förbränning av sopor` — 垃圾焚烧

## 例句 (Sentences)

- 🇸🇪 Källsortering minskar mängden avfall som förbränns. — 🇨🇳 垃圾分类减少了被焚烧的废物量。
- 🇸🇪 Det är bättre att återvinna material än att förbränna det. — 🇨🇳 回收利用材料比焚烧它要好得多。
- 🇸🇪 Restavfall som inte kan återvinnas förbränns oftast för att producera energi. — 🇨🇳 无法回收的残余垃圾通常被焚烧以产生能源。
