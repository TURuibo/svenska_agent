# undvika — verb (grupp 4, oregelbundet)

📖 中文：避免；回避 · English: to avoid

🇸🇪 Förklaring: se till att man inte kommer i kontakt med något eller att något inte händer

发音提示：/ˈɵndˌviːka/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) undvika |
| Presens | undviker |
| Preteritum | undvek |
| Supinum | undvikit |
| Imperativ | undvik! |

## 词组搭配 (Collocations)

- `undvika gluten` — 避免麸质
- `undvika misstag` — 避免错误
- `undvika kontakt` — 回避接触
- `undvika att + infinitiv` — 避免做某事

## 例句 (Sentences)

- 🇸🇪 Jag undviker gluten. — 🇨🇳 我（刻意）不吃麸质。
- 🇸🇪 Han undvek frågan och pratade om något annat. — 🇨🇳 他回避了这个问题，转而谈起别的事。
- 🇸🇪 Det är svårt att undvika socker helt. — 🇨🇳 完全避免糖分是很难的。

## 用法提示 (Usage Notes)

- `undvika` vs `tåla inte`：`undvika` = 主动选择"回避/不吃"；`tåla inte` = 身体不耐受（生理原因）。
  `Jag undviker gluten`（我刻意不吃麸质）vs `Jag tål inte laktos`（我身体不能耐受乳糖）。
- `undvika att + infinitiv`：`undvika att äta gluten`（避免吃麸质）。
