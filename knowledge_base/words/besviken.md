# besviken — adjektiv

📖 中文：失望的 · English: disappointed

🇸🇪 Förklaring: ledsen för att något inte blev som man hoppats

发音提示：/beˈsviːkɛn/ — 重音 sviː；v 轻擦音

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| utrum | besviken |
| neutrum | besviket |
| plural | besvikna |
| komparativ | mer besviken |
| superlativ | mest besviken |

## 词组搭配 (Collocations)

- `besviken på någon` — 对某人失望
- `besviken över något` — 对某事失望

## 例句 (Sentences)

- 🇸🇪 Jag blev besviken på filmen. — 🇨🇳 我对这部电影很失望。
- 🇸🇪 Hon var besviken över resultatet. — 🇨🇳 她对结果感到失望。
- 🇸🇪 Vi är inte besvikna. — 🇨🇳 我们并不失望。
