# pröva — verb

📖 中文：尝试；检验 · English: to try; to test

🇸🇪 Förklaring: göra något för att se hur det är eller om det fungerar

发音提示：/ˈprøːva/ — ö 读长音 øː（嘴唇圆、舌位前）

## 语法变形 (Forms)

| 形式 | 例 |
|---|---|
| infinitiv | pröva |
| presens | prövar |
| preteritum | prövade |
| supinum | prövat |

## 词组搭配 (Collocations)

- `pröva något nytt` — 尝试新东西
- `pröva lyckan` — 碰碰运气

## 例句 (Sentences)

- 🇸🇪 Jag vill pröva något nytt. — 🇨🇳 我想尝试些新东西。
- 🇸🇪 Hon prövade lyckan i Stockholm. — 🇨🇳 她去斯德哥尔摩碰运气。
- 🇸🇪 Domstolen prövar ärendet. — 🇨🇳 法院审理这个案件。
