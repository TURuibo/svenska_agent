# stöta — verb (oregelbundet)

📖 中文：碰撞；撞到 · English: to bump; to knock
发音提示：/ˈstøːta/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) stöta |
| Presens | stöter |
| Preteritum | stötte |
| Supinum | stött |
| Imperativ | stöt! |

## 词组搭配 (Collocations)

- `stöta till` — 撞到 → see [[stöta-till]]
- `stöta på` — 偶然遇到 → see [[stöta-på]]

## 例句 (Sentences)

- 🇸🇪 Det var inte heller någon som bad om ursäkt om de råkade stöta till mig. — 🇨🇳 如果不小心撞到我，也没有人道歉。
- 🇸🇪 Jag stötte på en gammal vän i stan. — 🇨🇳 我在城里碰到一位老朋友。
- 🇸🇪 Han stötte huvudet i dörren. — 🇨🇳 他的头撞到了门。
