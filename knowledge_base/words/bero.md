# bero — verb (grupp 4)

📖 中文：取决于；由……引起 · English: to depend on, be due to
发音提示：/beˈruː/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | bero |
| Presens | beror |
| Preteritum | berodde |
| Supinum | berott |
| Imperativ | bero |

## 词组搭配 (Collocations)

- `bero på` — 取决于/原因在于
- `Det beror på.` — 看情况。

## 例句 (Sentences)

- 🇸🇪 Det kan bero på att man inte har bilder till hjälp. — 🇨🇳 这可能是因为没有图像辅助。
- 🇸🇪 Hon sa att det inte berodde på mig. — 🇨🇳 她说这跟我无关/不是我的原因。
- 🇸🇪 Vad beror katastrofen på? — 🇨🇳 这场灾难是由什么引起的？
