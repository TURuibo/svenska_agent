# bero — verb (grupp 3)

📖 中文：取决于；由……引起 · English: to depend (on), to be due to
发音提示：/beˈruː/，重音在第二音节，结尾长音 -o

> 你输入的 **Beror** 是它的**现在时**（presens）：jag/du/han **beror**…

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) bero |
| Presens | beror |
| Preteritum | berodde |
| Supinum | berott |
| Imperativ | bero (罕用) |

**Grupp 3 动词：** 词干以**重读元音**结尾的短动词（bo, tro, sy, ske, bero…）。
现在时加 `-r`，过去时加 `-dde`，supinum 加 `-tt`。

## 词组搭配 (Collocations)

- **`bero på`** — 取决于 / 视……而定；由……引起（**最核心、几乎必带 på**）
- `Det beror på.` — "看情况 / 不一定。"（独立成句的高频口语回答）
- `Det beror på dig.` — 这取决于你。
- `Olyckan berodde på halka.` — 这场事故是由路滑引起的。

## 例句 (Sentences)

- 🇸🇪 Det beror på vädret. — 🇨🇳 这取决于天气。
- 🇸🇪 — Ska du komma i morgon? — Det beror på. — 🇨🇳 ——你明天来吗？——看情况。
- 🇸🇪 Priset beror på kvaliteten. — 🇨🇳 价格取决于质量。
- 🇸🇪 Förseningen berodde på ett tekniskt fel. — 🇨🇳 延误是由一个技术故障引起的。

## 用法提示 (Usage Notes)

- **几乎永远搭配介词 `på`**：表达"取决于 X"用 `bero på X`，不能漏掉 på。
- 两个意思共用一个结构：
  - "**取决于**"（看情况而定）：`Det beror på hur mycket tid vi har.` 这取决于我们有多少时间。
  - "**由……引起 / 缘于**"（解释原因）：`Sjukdomen beror på en virus.` 这病是由一种病毒引起的。
- `Det beror på.` 单独使用 = 英文 "It depends." —— 极常用的口语回答。
