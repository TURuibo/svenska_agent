# resa — verb (grupp 2)

📖 中文：旅行；出行 · English: to travel
发音提示：/ˈreːsa/，长 e（"ree-sa"）。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | (att) resa |
| Presens | **reser** |
| Preteritum | reste |
| Supinum | rest |
| Imperativ | res! |

## 词组搭配 (Collocations)

- `resa till + 地点` — 去某地旅行
- `resa bort` — 出门远行 / 离开
- `resa hem` — 回家（路途）
- `resa med tåg / buss / flyg` — 坐火车 / 公交 / 飞机出行

## 例句 (Sentences)

- 🇸🇪 Jag **reser** till Spanien i sommar. — 🇨🇳 我今年夏天去西班牙旅行。
- 🇸🇪 Vi **reste** med tåg genom hela landet. — 🇨🇳 我们坐火车穿越了整个国家。
- 🇸🇪 Har du **rest** mycket? — 🇨🇳 你旅行得多吗？

## 词族 / 同义 / 反义 (Relations)

- 词族: en resa（一次旅行，名词同形）、[[resenär]]（旅客）、[[resmål]]（目的地）
- 同义词: [[åka]]（去/乘坐，口语更常用于"去某地"）
- 反义词: —
- 主题: [[topic-fritid-och-resor]]

## 用法提示 (Usage Notes)

- **三个同形词，注意区分：**
  - `resa` (v.) = 旅行 → *jag reser till …*（本条）
  - `en resa` (n.) = 一次旅行/旅程 → *en lång resa*
  - `resa sig` (reflexiv) = 起身/站起来 → *han reste sig upp*
- `resa` vs [[åka]]：日常说"去某地"口语多用 **åka**（åka till stan）；**resa** 更偏"旅行/远行"的语感。
- 是规则动词 grupp 2：reser – reste – rest。
