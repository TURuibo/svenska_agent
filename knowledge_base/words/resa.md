# resa — verb

📖 中文：立起；旅行 · English: to raise; to travel
发音提示：[ˈreːsa]，两音节，重音在前

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| infinitiv | resa |
| presens | reser |
| preteritum | reste |
| supinum | rest |
| imperativ | res! |

## 词组搭配 (Collocations)

- `resa stången` — 立起花柱（仲夏节）
- `resa utomlands` — 出国旅行
- `resa till Sverige` — 去瑞典旅行
- `resa sig` — 站起来（反身）

## 例句 (Sentences)

**义项1 立起 (raise/erect):**
- 🇸🇪 Tillsammans reser de stången. — 🇨🇳 大家一起把花柱立起来。
- 🇸🇪 Vi reser flaggan varje morgon. — 🇨🇳 我们每天早上把旗子升起来。

**义项2 旅行 (travel):**
- 🇸🇪 Hon reser till Stockholm varje vecka. — 🇨🇳 她每周去斯德哥尔摩。
- 🇸🇪 Vi vill resa till Japan nästa sommar. — 🇨🇳 我们想明年夏天去日本旅行。

## 用法提示 (Usage Notes)

- 两个主要义项：(1) 立起/竖起某物 (resa stången); (2) 旅行 (resa till X)
- resa sig = 站起来（非他动用法）
- resa 也作名词：en resa（一次旅行）
