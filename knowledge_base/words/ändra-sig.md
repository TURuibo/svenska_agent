# ändra sig — verb (grupp 1, reflexivt)

📖 中文：改变；变化 · English: to change; to shift
发音提示：ÄND-ra sig（重音在第一音节）

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| infinitiv | ändra sig |
| presens | ändrar sig |
| preteritum | ändrade sig |
| supinum | ändrat sig |
| imperativ | ändra dig! |

## 词组搭配 (Collocations)

- `vädret ändrar sig snabbt` — 天气变化很快
- `han ändrade sig` — 他改变主意了
- `allting ändrar sig` — 一切都在变化

## 例句 (Sentences)

- 🇸🇪 I Sverige kan det ändra sig snabbt — på morgonen sol och på eftermiddagen regn. — 🇨🇳 在瑞典天气可以变化很快——早上晴天，下午下雨。
- 🇸🇪 Jag ändrade mig och bestämde mig för att ta paraplyet med. — 🇨🇳 我改变主意，决定带上雨伞。
- 🇸🇪 Vädret i norra Sverige ändrar sig mer sällan än i söder. — 🇨🇳 瑞典北部的天气比南部变化更少。

## 用法提示 (Usage Notes)

- 反身动词：必须带反身代词（sig/mig/dig）
- ändra sig = 自身改变（天气、人的想法）
- ändra（不带 sig）= 改变某物：ändra planen（改变计划）
- 比较：[[skifta]]（更强调交替变化）、[[förändras]]（更正式）
