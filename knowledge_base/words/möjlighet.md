# möjlighet — substantiv

📖 中文：可能性，机会 · English: possibility, opportunity
发音提示：

## 语法变形 (Forms)

| 形式 | 词形 |
|------|------|
| obestämd singular | en möjlighet |
| bestämd singular | möjligheten |
| obestämd plural | möjligheter |
| bestämd plural | möjligheterna |

## 词组搭配 (Collocations)

- `ha möjlighet att` — 有机会做… → see [[möjlighet-till-förlängning]]
- `få möjlighet till` — 获得…的机会

## 例句 (Sentences)

- 🇸🇪 Kvinnor hade inte samma möjligheter som män att studera. — 🇨🇳 女性没有和男性一样的机会去上学。
- 🇸🇪 Jag har inte haft möjlighet att läsa boken än. — 🇨🇳 我还没有机会读那本书。
- 🇸🇪 Universitetet gav henne en möjlighet att studera filosofi. — 🇨🇳 大学给了她一个学习哲学的机会。
