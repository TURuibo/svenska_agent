# ladda — verb

📖 中文：加载；充电；下载 · English: to load; to charge; to download

🇸🇪 Förklaring: få en fil eller sida att visas på skärmen; fylla ett batteri med el

发音提示：/ˈlɑda/ — 重音在 lad；d 清晰，a 为弱读

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | ladda |
| Presens | laddar |
| Preteritum | laddade |
| Supinum | laddat |
| Imperativ | ladda! |

## 词组搭配 (Collocations)

- `ladda ner` — 下载
- `ladda mobilen` — 给手机充电

## 例句 (Sentences)

- 🇸🇪 Sidan tar lång tid att ladda. — 🇨🇳 页面加载要很久。
- 🇸🇪 Jag måste ladda mobilen innan jag åker. — 🇨🇳 我出发前得给手机充电。
- 🇸🇪 Du kan ladda ner appen gratis. — 🇨🇳 你可以免费下载这个应用。
