# var — adverb (frågeord)

📖 中文：哪里 · English: where
发音提示："VAAR"（与 vara 的过去式 "var" 拼写完全相同，是同形词/homonym）

## 词组搭配 (Collocations)

- `var bor du` — 你住在哪里
- `var finns` — …在哪里
- `varifrån` — 从哪里（合成词）

## 例句 (Sentences)

**义项1 疑问副词 哪里:**
- 🇸🇪 Var fick hon arbete? — 🇨🇳 她在哪里找到了工作？
- 🇸🇪 Var bor du? — 🇨🇳 你住在哪里？

**义项2 (同形词，非同一词) vara 的过去式 是/在(过去):**
- 🇸🇪 Vem var Elin Wägner? — 🇨🇳 埃林·瓦格纳是谁？（"var" = vara 的过去式，不是疑问词"哪里"）

## 用法提示 (Usage Notes)

- ⚠️ "var" 有两个完全不同的词：① 疑问副词"哪里"（本词条）；② 动词 [[vara]]（是/在）的过去式"是了/在了"，二者拼写相同，只能靠上下文和句子结构区分（"Var bor du?" = 哪里 vs "Han var glad." = 曾经是）。疑问词用法见 [[grammar-frageord]]，动词过去式见 [[grammar-preteritum]]。
