# ekonomisk — adjektiv

📖 中文：经济的；经济上的；节省的 · English: economic; financial; economical

🇸🇪 Förklaring: 1) som har med pengar, handel och produktion att göra; 2) som inte kostar mycket eller inte slösar

发音提示：e-ko-NO-misk，重音在第三音节 `no`；`k` 读 /k/。

## 语法变形 (Forms)

| 形式 | Swedish | 说明 |
|------|---------|------|
| en-ord | ekonomisk | en ekonomisk kris |
| ett-ord | ekonomiskt | ett ekonomiskt stöd |
| 复数 / 定形 | ekonomiska | de ekonomiska problemen |
| 副词 | ekonomiskt | Hon tänker ekonomiskt. |
| 比较级 / 最高级 | mer ekonomisk / mest ekonomisk | 以 -isk 结尾的形容词用 mer / mest |

- `ekonomiskt oberoende` — 经济独立

## 例句 (Sentences)

**义项 1 — 经济的、经济上的 (financial / economic):**

- 🇸🇪 Familjen har ekonomiska problem. — 🇨🇳 这家人有经济困难。
- 🇸🇪 Du kan få ekonomiskt bistånd om du inte kan försörja dig själv. — 🇨🇳 如果你无法养活自己，可以获得经济补助。 → [[sent-du-kan-få-ekonomiskt-bistånd-om-du-inte]]
- 🇸🇪 Ekonomiskt bistånd är pengar som du kan ansöka om hos socialtjänsten. — 🇨🇳 经济补助是你可以向社会服务处申请的钱。 → [[sent-ekonomiskt-bistånd-är-pengar-som-du-kan]]

**义项 2 — 节省的、划算的 (economical):**

- 🇸🇪 Det är mer ekonomiskt att laga mat hemma. — 🇨🇳 在家做饭更省钱。

## 用法提示 (Usage Notes)

- 在官方文本里 `ekonomisk` 多指"**钱方面的**"（财务上）：`ekonomiskt bistånd`、`ekonomiska problem`。
- `ekonomisk`（经济的 / 划算的）≠ `billig`（便宜的）：`en ekonomisk bil` 是"开着省钱"，不一定买时便宜。
