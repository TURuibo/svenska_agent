# avrunda — verb (grupp 1)

📖 中文：取整；凑整 · English: to round (off/up/down)
发音提示：av-RUN-da

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | avrunda |
| Presens | avrundar |
| Preteritum | avrundade |
| Supinum | avrundat |
| Imperativ | avrunda! |

## 词组搭配 (Collocations)

- `avrunda uppåt` — 向上取整（往多里凑）
- `avrunda nedåt` — 向下取整
- `avrunda till närmaste tiotal` — 取整到最近的十位数
- `vi avrundar uppåt` — 我们往上凑整（支付小费的方式）

## 例句 (Sentences)

- 🇸🇪 Då avrundar vi uppåt. — 🇨🇳 那我们往上凑整。
- 🇸🇪 Kan du avrunda till närmaste femtio kronor? — 🇨🇳 你能凑整到最近的五十克朗吗？
- 🇸🇪 Jag avrundar alltid uppåt på restaurang. — 🇨🇳 我在餐厅总是向上凑整。

## 词族 / 同义 / 反义 (Relations)

- 词族: runda（圆的），rund（圆），avrundning（取整操作）
- 同义词: runda (av/upp/ned)（同义 partikelverb）
- 反义词: —

## 用法提示 (Usage Notes)

- 在瑞典餐厅，刷卡时终端会询问是否想"avrunda uppåt" (向上取整)，这是给小费的常见方式
- *uppåt* = 向上，*nedåt* = 向下
