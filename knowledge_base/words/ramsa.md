# ramsa — substantiv (en)

📖 中文：一串；顺口溜 · English: rhyme; string (of words)

🇸🇪 Förklaring: 1) kort vers med tydlig rytm som man läser eller sjunger, ofta för barn; 2) lång rad ord som man räknar upp

发音提示：/ˈramsa/ — 重音在第一音节；a 短音
