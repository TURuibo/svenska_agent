# veckoprogram — substantiv (ett)

Zh: 每周课程表；每周活动安排 · English: weekly schedule; weekly program
发音提示：VEK-ko-pro-gram（四个音节）

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| obestämd singular | ett veckoprogram |
| bestämd singular | veckoprogrammet |
| obestämd plural | veckoprogram |
| bestämd plural | veckoprogrammen |

复合词：**vecka**（周）+ **program**（程序；计划）

## 词组搭配 (Collocations)

- `läsa veckoprogrammet` — 查看每周课程表
- `enligt veckoprogrammet` — 根据每周日程
- `detta veckans program` — 本周的安排
- `uppdatera veckoprogrammet` — 更新每周计划

## 例句 (Sentences)

- Här är vårt veckoprogram för sommaren — titta och välj aktivitet! — 这是我们夏季的每周课程表——看看选一个活动吧！
- Veckoprogrammet visar alla aktiviteter som vi erbjuder. — 每周课程表展示了我们提供的所有活动。
- Kan du titta på veckoprogrammet och berätta vilken dag det passar dig? — 你能看看每周安排，告诉我哪天适合你吗？

## 词族 / 同义 / 反义 (Relations)

## 用法提示 (Usage Notes)

- `veckoprogram` 常见于健身房、图书馆、社区中心等展示本周活动的告示板
- 与 `schema`（学校课程表）区别：`veckoprogram` 更偏向活动安排，`schema` 更偏向课程/时间格局
