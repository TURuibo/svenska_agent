# främst — adverb

📖 中文：主要，首先，尤其 · English: mainly, primarily, above all
发音提示：[frɛmst]

## 语法变形 (Forms)

*adverb — 不变形*

## 词组搭配 (Collocations)

- `främst fårskötsel` — 主要是绵羊饲养
- `framför allt / i första hand` — 首先/最重要的是（近义表达）

## 例句 (Sentences)

- 🇸🇪 Jordbruksnäringen, främst fårskötsel, ger många arbetstillfällen på Gotland. — 🇨🇳 农业，主要是绵羊饲养，为哥特兰岛提供了许多就业机会。
- 🇸🇪 Hon är känd främst för sin forskning om klimatförändringar. — 🇨🇳 她主要以气候变化研究而闻名。
- 🇸🇪 Problemet beror främst på brist på personal. — 🇨🇳 这个问题主要是由于人手不足造成的。

## 词族 / 同义 / 反义 (Relations)

- 词族: [[framför]]
- 同义词: [[framför allt]], [[huvudsakligen]]

## 用法提示 (Usage Notes)

- `främst` 是 `fram` 的最高级形式，但作为副词使用时意为"主要地/首要地"。
- 与 `framför allt`（首先/尤其）意思相近，但 `främst` 更简洁。
