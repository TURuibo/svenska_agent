# oklarhet — substantiv (en)

📖 中文：不明确；含糊；不清楚之处 · English: unclarity; uncertainty; ambiguity
发音提示：o-KLAR-het（`o-` 否定前缀 + `klar` + `-het`）。

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Obestämd sg | en oklarhet |
| Bestämd sg | oklarheten |
| Obestämd pl | oklarheter |
| Bestämd pl | oklarheterna |

> 构词：`o-`（不）+ `klar`（清楚）+ `-het`（名词后缀）。单数常作不可数（`oklarhet` = 不明确的状态），复数 `oklarheter` 指一个个不清楚的点。

## 词组搭配 (Collocations)

- `det råder oklarhet (om …)` — （关于……）情况不明确 → [[det-råder-oklarhet]]
- `oklarhet kring / om …` — 关于……的不明确
- `vid oklarheter` — 如有不清楚之处
- `reda ut oklarheter` — 澄清含糊之处
- `skapa oklarhet` — 造成含糊

## 例句 (Sentences)

- 🇸🇪 I dag råder det oklarhet om var man får parkera. — 🇨🇳 目前，关于可以在哪里停车仍然不明确。 → [[sent-i-dag-råder-det-oklarhet-om-var]]
- 🇸🇪 Det finns fortfarande oklarheter i lagen. — 🇨🇳 法律中仍然有一些不明确之处。
- 🇸🇪 Oklarheten gjorde många oroliga. — 🇨🇳 这种不明确让很多人担心。
- 🇸🇪 Vid oklarheter kan du kontakta kommunen. — 🇨🇳 如有不清楚之处，你可以联系市政府。

## 词族 / 同义 / 反义 (Relations)

- 词族: `oklar`（不清楚的）、[[klar]]（清楚的；准备好的）
- 同义词: 近义 `osäkerhet`（不确定）、`otydlighet`（不够清晰）
- 反义词: `klarhet`（清晰）、[[tydlig]] → 名词 `tydlighet`

## 用法提示 (Usage Notes)

- 新闻 / 公文常和 [[råda]] 搭配：`Det råder oklarhet / förvirring / osäkerhet om …`。
- 与 `osäkerhet` 区别：`oklarhet` = **信息 / 规则本身不明确**；`osäkerhet` = **人的不确定感**。
