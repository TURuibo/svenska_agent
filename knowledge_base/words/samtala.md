# samtala — verb (grupp 1)

📖 中文：交谈；谈话 · English: to converse

🇸🇪 Förklaring: prata med någon om ett ämne

发音提示：/ˈsamˌtɑːla/ — 重音在 sam-，ta 长音

| Form | Swedish |

| Preteritum | samtalade |
| Supinum | samtalat |

## 词组搭配 (Collocations)

- `samtala om` — 就……交谈
- `ämnen att samtala om` — 可聊的话题

## 例句 (Sentences)

- 🇸🇪 Caféet skulle kunna erbjuda ämnen att samtala om. — 🇨🇳 咖啡馆可以提供一些可聊的话题。
- 🇸🇪 Vi samtalar om vädret. — 🇨🇳 我们在聊天气。
- 🇸🇪 Eleverna samtalade i små grupper. — 🇨🇳 学生们分小组交谈。
