# kyssas — verb (deponens)

📖 中文：（互相）接吻 · English: to kiss (each other)

🇸🇪 Förklaring: ge varandra kyssar på munnen

发音提示：/ˈɕʏsːas/ — ky 读 [ɕʏ]；ss 前短元音

## 语法变形 (Forms)

| Form | Swedish |
|--|--|
| Infinitiv | kyssas |
| Presens | kyssas |
| Preteritum | kysstes |
| Supinum | kysstes → kysstats |

⚠️ s-动词表示“互相”（reciprok），主动 kyssa = 吻某人，见 [[grammar-deponensverb]]、[[grammar-s-verb-reciprok]]。

## 词组搭配 (Collocations)

- `vara dålig på att kyssas` — 不擅长接吻
- `kyssas och kramas` — 亲吻拥抱

## 例句 (Sentences)

- 🇸🇪 Paret kysstes på bröllopet. — 🇨🇳 这对新人在婚礼上接吻。
- 🇸🇪 De kysstes länge vid stationen. — 🇨🇳 他们在车站吻了很久。
- 🇸🇪 De pratade om rädslan att vara dåliga på att kyssas. — 🇨🇳 他们聊起了怕自己不会接吻的担心。
