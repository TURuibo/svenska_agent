# diskutera — verb (grupp 1)

📖 中文：讨论 · English: to discuss
发音提示：/dɪskɵˈteːra/

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Infinitiv | diskutera |
| Presens | diskuterar |
| Preteritum | diskuterade |
| Supinum | diskuterat |
| Imperativ | diskutera |

## 词组搭配 (Collocations)

- `diskutera något` — 讨论某事（直接带宾语，无介词）
- `diskutera med någon` — 与某人讨论

## 例句 (Sentences)

- 🇸🇪 Alla medarbetare ska vara med och diskutera förändringar på arbetsplatsen. — 🇨🇳 所有同事都要参与讨论工作场所的变化。
- 🇸🇪 Vi diskuterar problemet på mötet. — 🇨🇳 我们在会上讨论这个问题。
- 🇸🇪 Jag vill inte diskutera det nu. — 🇨🇳 我现在不想讨论这个。
