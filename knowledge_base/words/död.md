# död — substantiv / adjektiv

📖 中文：死亡；死的 · English: death; dead

🇸🇪 Förklaring: tillstånd när en människa eller ett djur inte lever längre; som inte lever

发音提示：/døːd/ — ö 读长音；d 在词尾轻读

## 语法变形 (Forms)

| Form | Swedish |
|------|---------|
| Substantiv obestämd | en död |
| Substantiv bestämd | döden |
| Adjektiv en/ett/pl | död / dött / döda |

## 词组搭配 (Collocations)

- `döden` — 死亡
- `dö` — 死（动词）→ see [[dö]]

## 例句 (Sentences)

- 🇸🇪 Döden är något som alla människor måste tänka på någon gång. — 🇨🇳 死亡是每个人迟早要思考的事。
- 🇸🇪 Influensan kan leda till död för svaga personer. — 🇨🇳 流感可能导致体弱的人死亡。
- 🇸🇪 Fisken i sjön var död. — 🇨🇳 湖里的鱼死了。
- 🇸🇪 Blommorna är döda eftersom ingen har vattnat dem. — 🇨🇳 花死了，因为没人浇水。
