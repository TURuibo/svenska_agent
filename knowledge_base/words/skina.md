# skina — verb

📖 中文：照耀；发光 · English: to shine
发音提示：/²ʃiːna/

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| infinitiv | skina |
| presens | skiner |
| preteritum | **sken** (强变化) |
| supinum | skinit |
| imperativ | skin! |

强变化 (stark verb)：skina – sken – skinit

## 词组搭配 (Collocations)

- `solen skiner/sken` — 太阳照耀 → 常用于天气描述
- `skina som en sol` — 笑容灿烂（比喻）

## 例句 (Sentences)

- 🇸🇪 Solen sken och himlen var blå hela dagen. — 🇨🇳 太阳照耀，整天都是蓝天。
- 🇸🇪 Det skiner starkt ute — du behöver solglasögon. — 🇨🇳 外面阳光很强——你需要墨镜。
- 🇸🇪 Imorgon skiner solen igen, säger väderlekstjänsten. — 🇨🇳 天气预报说明天太阳又会出来。

## 词族 / 同义 / 反义 (Relations)

- 词族: [[lysa]] (发光/照亮，更通用)
- 主题: [[topic-vader-och-arstider]]

## 用法提示 (Usage Notes)

- 注意强变化过去式：preteritum = **sken**（不是 skinade）。
- `solen skiner`（presens）/ `solen sken`（preteritum）是讲天气最常用的句型。
- 与 `lysa` 的区别：`skina` 侧重自然光（太阳、星星）；`lysa` 侧重人造光（灯）或发亮。
