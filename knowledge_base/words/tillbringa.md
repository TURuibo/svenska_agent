# tillbringa — verb (grupp 2a)

📖 中文：度过（时间）；消磨（时间） · English: to spend (time)
发音提示：/tɪlˈbrɪŋa/

## 语法变形 (Forms)

| form | exempel |
|------|---------|
| infinitiv | tillbringa |
| presens | tillbringar |
| preteritum | tillbringade |
| supinum | tillbringat |
| imperativ | tillbringa! |

## 词组搭配 (Collocations)

- `tillbringa tid` — 度过时间
- `tillbringa semestern` — 度过假期
- `tillbringa helgen vid sjön` — 在湖边度过周末
- `tillbringa natten` — 度过夜晚

## 例句 (Sentences)

- 🇸🇪 Många svenskar tillbringar semestern vid sjön eller havet. — 🇨🇳 许多瑞典人在湖边或海边度过假期。 → [[sent-manga-svenskar-tar-semester-tillbringar]]
- 🇸🇪 Vi tillbringade hela dagen på stranden. — 🇨🇳 我们在海滩上度过了整整一天。
- 🇸🇪 Hur tillbringar du din fritid? — 🇨🇳 你怎么度过你的空闲时间？

## 用法提示 (Usage Notes)

- *tillbringa* 专门用于"度过时间"，后面通常接时间宾语（*tid, semestern, natten*）。
- 不要与 *spendera* 混淆——*spendera* 也可以指"花钱"，而 *tillbringa* 只用于时间。
- 规则 2a 动词：tillbringa → tillbringar → tillbringade → tillbringat。
