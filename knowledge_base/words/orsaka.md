# orsaka — verb

📖 中文：导致；引起 · English: to cause

🇸🇪 Förklaring: vara anledningen till att något händer

发音提示：UR-sa-ka，重音在第一音节

## 语法变形 (Forms)

| 形式 | 瑞典语 |
|------|--------|
| infinitiv | orsaka |
| presens | orsakar |
| preteritum | orsakade |
| supinum | orsakat |

## 词组搭配 (Collocations)

- `orsaka skada` — 造成损害
- `orsaka problem` — 引起问题
- `orsaka förseningar` — 造成延误

## 例句 (Sentences)

- 🇸🇪 Ensamhet kan orsaka dålig hälsa. — 🇨🇳 孤独可能导致健康不佳。
- 🇸🇪 Olyckan orsakade stora problem i trafiken. — 🇨🇳 事故在交通中造成了很大问题。
- 🇸🇪 Vad orsakade branden? — 🇨🇳 是什么引起了火灾？
