# ärende — substantiv (ett)

📖 中文：事项；主题（正式信件）；差事 · English: matter; subject; errand
发音提示：[ˈæːrɛndə] — "ÄR-en-de"

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| obestämd singular | ett ärende |
| bestämd singular | ärendet |
| obestämd plural | ärenden |
| bestämd plural | ärendena |

## 词组搭配 (Collocations)

- `ärende:` — （信件主题行）主题：
- `hantera ett ärende` — 处理一个事项
- `gå ett ärende` — 跑一趟差事

## 例句 (Sentences)

- 🇸🇪 Ärende: Felanmälan — kylskåpet fungerar inte. — 🇨🇳 主题：报修——冰箱无法使用。
- 🇸🇪 Jag skriver angående ett ärende som gäller min lägenhet. — 🇨🇳 我写信是关于我公寓的一件事情。
- 🇸🇪 Kan du hjälpa mig med det här ärendet? — 🇨🇳 你能帮我处理这件事吗？

## 词族 / 同义 / 反义 (Relations)

- 同义词: [[sak]]

## 用法提示 (Usage Notes)

- 在正式信件/电子邮件中，`Ärende:` 相当于英文的 `Subject:` 或中文的"主题："，是邮件开头固定格式。
- 也可指日常"差事"：`Jag måste gå ett ärende` = 我得出去跑一趟。
