# intyg — substantiv

📖 中文：证明 · English: certificate

🇸🇪 Förklaring: papper som visar att något är sant eller att man har gjort något

发音提示：/ˈɪnˌtyːɡ/ — 重音在 in；y 读长音，类似"于"

## 语法变形 (Forms)

| 形式 | 瑞典语 |
|------|--------|
| 单数不定 | ett intyg |
| 单数定 | intyget |
| 复数不定 | intyg |
| 复数定 | intygen |

## 词组搭配 (Collocations)

- `läkarintyg` — 医生证明
- `få ett intyg från skolan` — 从学校获得证明
- `skriva ut ett intyg` — 开具证明

## 例句 (Sentences)

- 🇸🇪 Jag behöver ett intyg från läkaren. — 🇨🇳 我需要医生开的证明。
- 🇸🇪 Du får ett intyg när kursen är klar. — 🇨🇳 课程结束时你会得到证明。
- 🇸🇪 Arbetsgivaren skriver ett intyg om att jag har jobbat där. — 🇨🇳 雇主开具我曾在那里工作的证明。
