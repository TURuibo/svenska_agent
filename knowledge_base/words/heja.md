# heja — verb

📖 中文：为……加油，喝彩，呐喊助威 · English: to cheer for, to root for
发音提示：/ˈheːja/

## 语法变形 (Forms)

| form | Swedish |
|------|---------|
| infinitiv | heja |
| presens | hejar |
| preteritum | hejade |
| supinum | hejat |
| imperativ | heja! |

## 词组搭配 (Collocations)

- `heja på ngn` — 为某人/某队加油（最常见）
- `heja på Sverige!` — 为瑞典加油！
- `hejarop` — 加油喊声，助威口号
- `hejarklack` — 拉拉队，球迷团

## 例句 (Sentences)

- 🇸🇪 Det var många i Sverige som hejade inatt. — 🇨🇳 昨晚瑞典有很多人在为球队加油喝彩。
- 🇸🇪 Heja på ditt lag! — 🇨🇳 为你的队伍加油！
- 🇸🇪 Alla i publiken hejade på Sverige och ropade "Sverige! Sverige!". — 🇨🇳 观众席上所有人都在为瑞典加油，高喊"瑞典！瑞典！"。

## 词族 / 同义 / 反义 (Relations)

- 词族: hejarklack（拉拉队），hejarop（加油声）
- 同义词: peppa（激励，打气），uppmuntra（鼓励）
- 主题: [[topic-fotboll]]

## 用法提示 (Usage Notes)

- `heja på ngn` 是最固定的用法，介词 `på` 不可省略
- `Heja!` 也可单独用作感叹词：加油！太棒了！（非正式）
- 区别：`heja` = 喊加油/助威；`jubla` = 欢呼（庆祝胜利时用）
