# prova — verb

📖 中文：试穿；试用 · English: to try on; to try out

🇸🇪 Förklaring: ta på sig, smaka på eller använda något för att se om det är bra

发音提示：/ˈproːva/ — o 读长音 oː（接近「欧」）

## 语法变形 (Forms)

| 形式 | 例 |
|---|---|
| infinitiv | prova |
| presens | provar |
| preteritum | provade |
| supinum | provat |

## 词组搭配 (Collocations)

- `prova kläder` — 试穿衣服
- `prova på` — 尝试一下

## 例句 (Sentences)

- 🇸🇪 Jag gick till en butik för att prova vinterjackor. — 🇨🇳 我去商店试穿冬季外套。
- 🇸🇪 Vill du prova kakan? — 🇨🇳 你想尝尝这块蛋糕吗？
- 🇸🇪 Hon provade skorna. — 🇨🇳 她试了试鞋。
