# protestera — verb (grupp 1)

📖 中文：抗议 · English: to protest
发音提示：[pro-tes-TE-ra] — 重音在第三音节

## 语法变形 (Forms)

| 形式 | 变形 |
|------|------|
| infinitiv | protestera |
| presens | protesterar |
| preteritum | protesterade |
| supinum | protesterat |
| imperativ | protestera! |

## 词组搭配 (Collocations)

- `protestera mot` — 抗议……
- `protestera mot klimatförändringar` — 抗议气候变化
- `unga protesterar` — 年轻人抗议

## 例句 (Sentences)

- 🇸🇪 Många ungdomar protesterar mot klimatförändringarna. — 🇨🇳 许多年轻人在抗议气候变化。
- 🇸🇪 Folket protesterade mot den nya lagen. — 🇨🇳 人们抗议这项新法律。
- 🇸🇪 Vi protesterar för att politikerna ska lyssna. — 🇨🇳 我们抗议是为了让政客们倾听。
