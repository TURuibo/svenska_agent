# 🇸🇪 Du kan också få stöd att klara din ekonomi i framtiden.

🇨🇳 你还可以获得帮助，让你将来能管好自己的经济。

## 结构 (Structure)

```
[Du] [kan] [också] [få stöd] [att klara din ekonomi] [i framtiden].
 主语  助动词 副词    不定式+宾语  名词的不定式补语        时间状语
```

## 语法点 (Grammar)

- 📌 [[grammar-infinitiv]] — `stöd att + 不定式`：**名词 + att + 不定式**（……的帮助去做……），说明帮助的目的。
- 💡 `din ekonomi`：主语是第二人称 `du`，所以用 `din`（反身物主代词 `sin / sitt / sina` 只用于**第三人称**主语）。
