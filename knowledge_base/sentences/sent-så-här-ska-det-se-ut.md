# 🇸🇪 Så här ska det se ut på ditt barns krok och i lådan:

🇨🇳 你孩子的挂钩上和箱子里应该是这样的：

## 结构 (Structure)

```
Så här  ska   det  se ut   på ditt barns krok   och  i lådan
方式状语  助动词 主语  不定式   介词短语(所有格)     连词  介词短语
```

## 语法点 (Grammar)

- 📌 [[grammar-ska-infinitiv]] — ska + se ut（应该看起来）
- 📌 [[grammar-v2-ordfoljd]] — *Så här* 占首位，主语 *det* 后移
- 📌 [[grammar-genitiv-s]] — *ditt barns krok*：barn + s = 你孩子的；所有格后名词不加定式（krok，不是 kroken）
