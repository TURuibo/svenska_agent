# 🇸🇪 Men är inte lugnet en fördel?

🇨🇳 但安静不也是个优点吗？

## 结构 (Structure)

```
[Men] [är] [inte] [lugnet] [en fördel]?
 连词  动词  否定   主语      表语
```

## 语法点 (Grammar)

- 📌 [[grammar-negation-i-fraga]] — 否定疑问句："Är inte X en fördel?" = "Isn't X an advantage?" 用于寻求对方确认。回答 "jo" 表示是（反驳否定），"nej" 表示否（确认否定）。
- "lugnet" = "lugn" (calm/quiet) 的定冠词形式：det lugn → lugnet。
