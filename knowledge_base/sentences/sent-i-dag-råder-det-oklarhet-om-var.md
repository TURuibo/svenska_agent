# 🇸🇪 I dag råder det oklarhet om var man får parkera.

🇨🇳 目前，关于可以在哪里停车仍然不明确。

## 结构 (Structure)

```
[I dag] [råder] [det] [oklarhet] [om var man får parkera].
 时间状语  动词   虚主语   真正的主语    介词 + 间接疑问从句
```

## 语法点 (Grammar)

- 📌 [[grammar-v2-ordfoljd]] — 句首 `I dag`，动词 `råder` 第二，`det` 紧随其后。
- 📌 [[grammar-indirekt-fraga]] — `om var man får parkera`：疑问词 `var`（哪里）引导的**间接疑问句**，语序为 主语 + 动词（`man får`），**不倒装**。
- 💡 `det råder + 抽象名词` = "存在……的状况"，见 [[det-råder-oklarhet]]。
