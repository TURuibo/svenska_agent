# 🇸🇪 Vad som är rimligt beror på olika saker.

🇨🇳 什么算合理取决于不同情况。

## 结构 (Structure)

```
[Vad som är rimligt]  [beror på]  [olika saker].
 主语从句（疑问词 + som + 动词 + 表语）  动词+介词  宾语
```

## 语法点 (Grammar)

- 📌 [[grammar-indirekt-fraga]] — `vad` 引导的从句充当**整句主语**。
- 📌 [[grammar-bisats-med-vem-som]] — 疑问词本身是从句主语时必须加 **`som`**：`vad **som** är rimligt`。
- 📌 [[grammar-adjektiv-som-predikat]] — 表语 `rimligt`（中性）：`vad som` 指"某件事"，用中性形式。
- 💡 `bero på` = 取决于 → [[bero-på]]。
