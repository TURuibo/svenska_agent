# 🇸🇈 I Skåne har jag aldrig varit.

🇨🇳 我从没去过 Skåne。

## 结构 (Structure)

```
[I Skåne]       [har]     [jag]   [aldrig]   [varit]
 位置1: 地点状语   位置2: 助动词  位置3: 主语  satsadv.   supinum
```

## 语法点 (Grammar)

- 📌 [[grammar-v2-ordfoljd]] — *I Skåne* 在句首（位置1），有限助动词 *har* 第二，主语 *jag* 第三
- 📌 [[grammar-platsadverb]] — *I Skåne* = 地名作地点状语
- 📌 [[grammar-perfekt]] — *har … varit* = 现在完成时（perfekt），表示从未有过的经历
- 📌 [[grammar-satsadverbial]] — *aldrig* = 从不，satsadverbial，在主句中位于主语 *jag* 之后、supinum 之前
- 📌 [[grammar-aldrig-v2-inversion]] — *aldrig* 不触发 V2（须区分 satsadverbial 与 platsadverbial）；是 *I Skåne* 触发了本句的倒装
