# 🇸🇪 Du kan få tolk gratis.

🇨🇳 你可以免费获得口译员。


## 语法点 (Grammar)

- 📌 [[grammar-modala-hjalpverb]]
- 📌 *kan få* = 可以得到；*få tolk* 无冠词（泛指服务）。
- 📌 *gratis* 既是形容词也是副词，不变形。
- 📌 瑞典公共机构（幼儿园、医院、市政）在重要谈话中有义务提供免费口译。
