# 🇸🇪 Den låg på hyllan vid Minas krok.

🇨🇳 它就放在 Mina 挂钩旁边的架子上。

## 语法点 (Grammar)

- 📌 [[grammar-preteritum]] — *låg*（ligga 的过去式，v.4 不规则）：只讲过去那一刻的位置，所以不用 perfekt
- 📌 [[grammar-genitiv-s]] — *Minas krok*：人名 + -s 表所属，无撇号
- 📌 [[grammar-bestämd-form]] — *hyllan*：双方都知道的那个架子
- ⚠️ 中文「放在」→ 瑞典语常用 *ligga*（平放的东西）而不是「放」
