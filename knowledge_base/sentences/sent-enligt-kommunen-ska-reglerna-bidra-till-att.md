# 🇸🇪 Enligt kommunen ska reglerna bidra till att fler känner sig trygga i centrum.

🇨🇳 据市政府称，这些规则将有助于让更多人在市中心感到安全。

## 结构 (Structure)

```
[Enligt kommunen] [ska] [reglerna] [bidra till] [att fler känner sig trygga i centrum].
   状语(句首)      助动词   主语       动词+介词    att 从句
```

## 语法点 (Grammar)

- 📌 [[grammar-enligt-substantiv]] — `Enligt kommunen` = "据市政府（所说）"，引出消息来源。
- 📌 [[grammar-v2-ordfoljd]] — 状语 `Enligt kommunen` 在句首，助动词 `ska` 第二，主语 `reglerna` 在后。
- 📌 [[grammar-att-bisats]] — `bidra till att + 从句`：介词 `till` 后接从句必须加 `att`（不是 *bidra till fler känner*）。
- 💡 `känna sig trygg`：反身动词 `känna sig` + 形容词，`trygga` 是复数形式（与 `fler` 一致）。
