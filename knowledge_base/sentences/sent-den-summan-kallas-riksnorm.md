# 🇸🇪 Den summan kallas riksnorm.

🇨🇳 这个金额叫作「全国标准」。

## 结构 (Structure)

```
[Den summan] [kallas] [riksnorm].
 主语（指示词+定形名词）  s-被动动词  名称（表语补足语）
```

## 语法点 (Grammar)

- 📌 [[grammar-s-passiv]] — `kallas`（s-被动，现在时）：**被称为**；主动 `Man kallar summan riksnorm`。
- 📌 [[grammar-s-passiv-kallas-for]] — 比较：`kallas för X` 也常见，这里**省略 `för`** 直接接名称。
- 💡 `Den summan`：`den` + 名词的指示形式（"那笔金额"），指前一句 `hur mycket pengar`。
