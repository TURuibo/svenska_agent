# 🇸🇪 Vattnet stängs av varje dag mellan klockan 08.00 och 16.00.

🇨🇳 每天上午8点到下午16点之间停水。

```
Vattnet   stängs av           varje dag   mellan klockan 08.00 och 16.00
主语      动词(s-被动+小品词)   频率状语     时间区间状语
```

## 语法点 (Grammar)

- 📌 [[grammar-s-passiv]] — `stängs`（stänga 的 s-被动形式），无需说明施动者
- 📌 [[grammar-tidsprepositioner]] — `mellan...och` 表示时间区间
