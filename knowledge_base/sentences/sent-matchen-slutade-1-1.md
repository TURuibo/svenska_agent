# 🇸🇪 Matchen slutade 1–1.

🇨🇳 比赛以 1–1 平局结束。

## 结构 (Structure)

```
[Matchen] [slutade] [1–1]
   主语      动词     结果（比分）
```

## 语法点 (Grammar)

- 动词 `sluta` 此处作不及物动词，表示"结束（以某结果）"
- 比分 1–1 读作 `ett–ett`；结果为 `oavgjort`（平局）

## 生词 & 词组 (Words & Phrases)

- 词: [[match]] (比赛) · [[oavgjort]] (平局)
- 注: sluta = 结束（此处为 sluta 的一个义项，区别于 sluta = 停止做某事）
