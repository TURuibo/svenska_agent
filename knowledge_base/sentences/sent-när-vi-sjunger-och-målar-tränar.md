# 🇸🇪 När vi sjunger och målar tränar vi både språk och motorik.

🇨🇳 我们唱歌、画画的时候，既锻炼了语言，也锻炼了运动能力。

## 结构 (Structure)

```
[När vi sjunger och målar] [tränar] [vi] [både språk och motorik].
 时间从句(句首=fundament)   主句动词  主语  宾语(både … och …)
```

## 语法点 (Grammar)

- 📌 [[grammar-nar-bisats]] — när + 主语 + 动词：「……的时候」
- 📌 [[grammar-bisats-forst-inversion]] — 从句放句首后，主句必须倒装：tränar vi
- 📌 [[grammar-v2-ordfoljd]] — 主句动词 tränar 位于第二位（整个 när-从句算第一位）
