# Ni är välkommen att kontakta mig.

🇨🇳 欢迎与我联系。

## 结构 (Structure)

```
[Ni]  [är välkommen]  [att kontakta mig]
 主语     形容词谓语        不定式补语
```

## 语法点 (Grammar)

- 📌 [[grammar-formellt-brev]] — 正式信件联系方式结尾固定句式
- 📌 `välkommen att + infinitiv` — 欢迎（对方）做某事（礼貌邀请）
- 📌 注意：写给多人/公司时用 `Ni är välkommen`（ni 对应的形容词不变格）
