# 🇸🇪 Vilken uppgift i livet hade kvinnorna när Elin växte upp?

🇨🇳 埃林长大时女性在人生中承担着怎样的任务？

## 结构 (Structure)

```
Vilken uppgift i livet   hade    kvinnorna   [när Elin växte upp]?
疑问词短语(宾语)          动词(过去式) 主语        时间状语从句(bisats)
```

## 语法点 (Grammar)

- 📌 [[grammar-frageord]] — "vilken" 与阳性/共性名词 "uppgift" 一致
- 📌 [[grammar-nar-bisats]] — "när Elin växte upp" 是时间状语从句，遵循 bisats 语序（不倒装）
- 📌 [[grammar-partikelverb]] — "växte upp"（växa upp 的过去式）
- 📌 [[grammar-preteritum]] — hade / växte 均为过去式
