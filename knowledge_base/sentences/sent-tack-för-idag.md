# 🇸🇪 Tack för idag!

🇨🇳 今天谢谢了！

## 结构 (Structure)

```
[Tack] [för idag]!
 谢     för + 时间
```

## 语法点 (Grammar)

- 📌 无语法难点。接园时家长和老师**互相**说这句（老师也回 *Tack för idag!*），是固定告别仪式，不是单向道谢。
