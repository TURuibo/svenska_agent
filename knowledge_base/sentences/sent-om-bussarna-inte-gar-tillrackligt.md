# 🇸🇪 Om bussarna inte går tillräckligt ofta, blir hela dagen stressig.

🇨🇳 如果公交车不够频繁，整天就会很紧张。

```
[Om bussarna inte går tillräckligt ofta,] [blir] [hela dagen] [stressig]

```

## 语法点 (Grammar)

- 📌 [[grammar-bisats-om]] — om-bisats (条件从句) 放在主句之前，主句保持 V2 语序（"blir" 在前，"hela dagen" 在后）。注意 "inte" 在 bisats 中位于动词 "går" 之前。
- "tillräckligt ofta" 修饰动词 "går"，表示频率是否足够。
