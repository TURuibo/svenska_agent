# 🇸🇪 Kan ni ta med ett större par?

🇨🇳 你们能带一条大一号的来吗？

## 结构 (Structure)

```
Kan   ni   ta med   ett större par
助动词 主语  不定式+小品词  宾语(比较级)
```

## 语法点 (Grammar)

- 📌 [[grammar-ja-nej-fraga]] — 是非问句：动词提到句首 *Kan ni …?*，这是礼貌请求的标准句型
- 📌 [[grammar-modalt-hjalpverb-infinitiv]] — *kan* + 不定式 *ta*（无 att）
- 📌 [[grammar-partikelverb]] — *ta med*（带来）
- 📌 [[grammar-komparativ]] — *stor → större*；*ett större par* 省略了 *galonbyxor*
- 📌 老师对家长说 **ni** = 你们（全家），不是敬称

- 词: [[par]] · [[stor]]
- 词组: [[ta-med]] · [[ett-par-vantar]]
