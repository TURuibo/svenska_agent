# 🇸🇪 Vilket stöd du kan få beror på vad du behöver hjälp med.

🇨🇳 你能得到哪种帮助，取决于你需要哪方面的帮助。

## 结构 (Structure)

```
[Vilket stöd du kan få]  [beror på]  [vad du behöver hjälp med].
 主语（疑问词从句）         动词+介词   宾语（疑问词从句）
   疑问词  主语 动词                    疑问词 主语 动词   介词
```

## 语法点 (Grammar)

- 📌 [[grammar-indirekt-fraga]] — 两个疑问词从句：**主语在动词前**（`du kan få`、`du behöver`），不倒装；整个从句作主语和宾语。
- 📌 [[grammar-preposition-i-slutet]] — 疑问词 `vad` 的介词 `med` 留在从句末尾：`hjälp med`。
- 💡 `bero på` = 取决于，介词 `på` 固定 → [[bero-på]]。
