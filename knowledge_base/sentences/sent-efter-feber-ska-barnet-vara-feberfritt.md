# 🇸🇪 Efter feber ska barnet vara feberfritt en dag hemma.

🇨🇳 发烧之后孩子要在家退烧一天。

## 结构 (Structure)

```
[Efter feber] [ska] [barnet] [vara] [feberfritt] [en dag] [hemma].
 时间状语   情态  主语    不定式  表语(ett-形)  时长   地点
```

## 语法点 (Grammar)

- 📌 [[grammar-inversion-efter-fundament]]
- 📌 [[grammar-modalt-hjalpverb-infinitiv]]

- 📐 状语 *Efter feber* 开头 → *ska* 提前，主语 *barnet* 在后（V2）。
- ⚠️ *barnet* 是 ett-词 → 形容词要加 -t：*feberfritt*（不是 ✗ *feberfri*）。
- 📌 园所规则：发烧后要有 *en feberfri dag hemma*。
