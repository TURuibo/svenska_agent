# 🇸🇪 Titta, nu delar ni med er.

🇨🇳 看，你们现在分着玩了。

## 结构 (Structure)

```
Titta,  nu   delar  ni   med  er.
命令式   时间  动词    主语  介词  反身宾语
```

## 语法点 (Grammar)

- 📌 [[grammar-imperativ]] — titta!
- 📌 [[grammar-v2-ordfoljd]] — nu 句首 → delar 第二位 → ni 后置。
- 📌 [[grammar-reflexivt-pronomen]] — dela med **sig** 随主语变：ni → med er，jag → med mig。

## 生词 & 词组 (Words & Phrases)

- 词: [[titta]]
- 词: [[dela]]
- 词组: [[dela-med-sig]]

## 用法提示 (Notes)

- 家长表扬孩子分享时的固定句；**dela med sig** 强调"把自己的东西分给别人"。
- 不能说 *ni delar med sig*：sig 只用于第三人称。
