# 🇸🇪 Vi rekommenderar fyra veckors sammanhängande ledighet för barnet.

🇨🇳 我们建议让孩子连续休假四周。

```

 主语     动词              宾语（数量所有格 + 形容词 + 名词）      受益者
```

## 语法点 (Grammar)

- 📌 [[grammar-genitiv-s]] — **量词所有格**：*fyra veckors ledighet* = 四周的假期（*två timmars sömn*, *en veckas semester*）。数量 + 名词 + **-s** 作定语。
- 📌 [[grammar-plural-substantiv]] — *fyra veckor* 复数（en vecka → veckor）。
- 📌 *sammanhängande* 分词作形容词，不变形；"连续"= 不能拆开休。
