# 🇸🇪 Barnet får ofta stå i kö, men kommunen måste erbjuda plats inom fyra månader.

🇨🇳 孩子常常要在等候名单上排一阵，但市政必须在四个月内提供名额。

## 结构 (Structure)

```
[Barnet] [får] [ofta] [stå i kö],  men  [kommunen] [måste] [erbjuda plats] [inom fyra månader]
  主语   情态  副词  不定式        连词   主语    情态     不定式+宾语    时间状语
```

## 语法点 (Grammar)

- 📌 [[grammar-modala-hjalpverb]]
- 📌 [[grammar-modal-fa-permission]]
- 📌 两个主句由 *men* 连接，各自 V2。
- 📌 *får … stå* 这里的 *få* = 不得不 / 会（被迫），不是「可以」。*måste erbjuda* = 必须提供。
- 📌 *inom fyra månader* = 四个月之内。
