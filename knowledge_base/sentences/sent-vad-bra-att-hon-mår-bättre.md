# 🇸🇪 Vad bra att hon mår bättre!

🇨🇳 她好多了，太好了！

## 结构 (Structure)

```
[Vad bra] [att hon mår bättre]!
 感叹（vad + 形容词） att-从句（为什么好）
```

## 语法点 (Grammar)

- 📌 [[grammar-vad-utrop]] — `Vad + 形容词!` = 太…了！（Vad bra! Vad kul! Vad roligt!）
- 📌 [[grammar-att-bisats]] — 后面用 att-从句说明高兴的内容，从句语序（主语 + 动词）。

## 生词 & 词组 (Words & Phrases)

- 词: [[bra]] · [[må]] · [[bättre]] · [[vad]]
