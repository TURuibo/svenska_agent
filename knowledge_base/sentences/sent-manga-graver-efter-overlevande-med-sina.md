# 🇸🇪 Många gräver efter överlevande med sina bara händer eftersom maskiner saknas.

🇨🇳 许多人用双手徒手挖掘寻找幸存者，因为缺少机械设备。

## 结构 (Structure)

```
[Många]  [gräver]  [efter överlevande]  [med sina bara händer]  [eftersom maskiner saknas]
  主语     动词         介词短语              方式状语               原因从句（bisats）
```

## 语法点 (Grammar)

- 📌 [[grammar-bisats-eftersom]] — `eftersom maskiner saknas`：因为从句，eftersom 引导
- 📌 [[grammar-s-passiv]] — `saknas`：s-被动，"被缺乏"= 缺少

## 生词 & 词组 (Words & Phrases)

- 词: `gräva` (verb v.1 — 挖掘)，`överlevande` (substantiv — 幸存者)
- 词: `bara händer`（徒手，bare hands），`maskin` (en — 机器/机械)
- 词: `sina`（自己的，reflexivt possessivt pronomen）
