# 🇸🇪 Handsprit hjälper inte mot magsjuka.

🇨🇳 免洗洗手液对肠胃炎不管用。

## 结构 (Structure)

```
[Handsprit] [hjälper] [inte] [mot magsjuka]
 主语(不可数) 动词     否定   介词短语（对…）
```

## 语法点 (Grammar)

- 📌 [[grammar-v2-ordfoljd]] — 否定 inte 在动词后。
- 📌 `hjälpa mot + 病`：对某病有效/管用（Alvedon hjälper mot feber）——介词固定用 **mot**。
- 📌 不可数名词 handsprit 作主语无冠词；magsjuka 泛指也无冠词。

## 生词 & 词组 (Words & Phrases)

- 词: [[handsprit]] · [[hjälpa]] · [[magsjuka]]
- 用法: 常识提醒：诺如病毒类要用肥皂水，酒精无效。
