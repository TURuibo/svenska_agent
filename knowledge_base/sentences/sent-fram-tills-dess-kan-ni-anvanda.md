# 🇸🇪 Fram tills dess kan ni använda torktumlare nummer 1 eller hänga tvätten på tork i källaren.

🇨🇳 在此之前，您可以使用1号烘干机，或把衣物挂到地下室的晾衣处晾干。

## 结构 (Structure)

```
Fram tills dess   kan   ni   använda ... eller hänga ...
   前置状语        V2助动词  主语      并列谓语（两个选项）
```

## 语法点 (Grammar)

- 📌 [[grammar-v2-ordfoljd]] — 状语 `Fram tills dess` 前置到句首时，助动词 `kan` 仍占第二位（V2倒装），主语 `ni` 后移。
