# 🇸🇪 Noah kan ta hinken så länge.

🇨🇳 Noah 可以先玩小桶。

## 结构 (Structure)

```
Noah  kan   ta    hinken    så länge.
主语   情态   不定式  宾语(定式)  时间短语
```

## 语法点 (Grammar)

- 📌 [[grammar-modala-hjalpverb]] — kan + ta（无 att）。
- 📌 [[grammar-bestämd-form]] — hinken：在场那只桶。

## 生词 & 词组 (Words & Phrases)

- 词: [[hink]]
- 词: [[länge]]
- 词组: [[så-länge]]

## 用法提示 (Notes)

- **så länge** = "在这期间/暂时"，不是"这么久"——这是中文母语者最容易误解的地方。
- **ta** 这里是"拿着玩"，比 leka med 更简短。
