# 🇸🇪 En dag kommer våra barn fråga oss varför vi inte gjorde något för att stoppa en klimatkatastrof.

🇨🇳 总有一天，我们的孩子会问我们，当初为什么没有为阻止气候灾难做任何事。

## 结构 (Structure)

```
[En dag] [kommer] [våra barn] [(att) fråga] [oss] [varför vi inte gjorde något [för att stoppa …]]
 fundament   V       主语        不定式       间接宾语   间接疑问从句 (inte 在动词前)
```

## 语法点 (Grammar)

- 📌 [[grammar-inversion-efter-fundament]] — 时间状语 `En dag` 在句首 → `kommer` 在主语 `våra barn` 之前。
- 📌 [[grammar-kommer-att-infinitiv]] — `kommer … fråga`：口语/书面中常省略 `att`（正式写法 `kommer att fråga`）。
- 📌 [[grammar-indirekt-fraga]] / [[grammar-bisats-ordfoljd]] — `varför vi inte gjorde`：从句中 `inte` 在动词前（主句：*vi gjorde inte*）。
- 📌 [[grammar-possessiva-pronomen]] — `våra barn`（我们的孩子）。
- 📌 [[grammar-for-att-syfte]] — `för att stoppa` 表目的。
