# 🇸🇪 Förlåt, han blir arg när någon tar hans saker.

🇨🇳 抱歉，有人拿他的东西他就生气。

## 结构 (Structure)

```
Förlåt,  han  blir   arg   [när  någon  tar  hans saker].
道歉      主语  系动词  形容词  när-从句(主语+动词+宾语)
```

## 语法点 (Grammar)

- 📌 [[grammar-nar-bisats]] — när 引导的时间从句，从句内正常语序（主语 någon 在动词 tar 前）。
- 📌 [[grammar-possessiva-pronomen]] — hans saker：hans 不变形，saker 复数。
- 📌 [[grammar-modal-verb-kan-bli]] — *bli arg* = 变得生气（变化），对比 *vara arg*（状态）。

## 生词 & 词组 (Words & Phrases)

- 词: [[förlåt]]
- 词: [[bli]]
- 词: [[arg]]
- 词: [[när]]
- 词: [[någon]]

## 用法提示 (Notes)

- 家长为孩子推人道歉的典型句：**Förlåt + 解释原因**。
- 注意用 **hans**（他人的）而不是 sina：主语是 någon，不是 han。
