# 🇸🇪 Ja men så är det.

🇨🇳 唉，就是这样的。

## 结构 (Structure)

```
[Ja men] [så] [är] [det].
 语气    副词  动词  主语
```

## 语法点 (Grammar)

- 📌 [[grammar-inversion-efter-fundament]]

- 📌 *Så är det.* = 「就是这样 / 没办法」，表示无奈地接受现实。*så* 提前 → 动词在主语前。
- 📌 *Ja men* 开头是口语语气词，≈「唉，是啊」。
