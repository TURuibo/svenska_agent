# Vintern var mycket kall — det snöade nästan varje dag.

🇨🇳 冬天非常冷——几乎每天都在下雪。

## 结构 (Structure)

```
[Vintern] [var] [mycket kall] — [det] [snöade] [nästan varje dag]
   主语    动词    表语           形式主语  动词      时间状语
```

## 语法点 (Grammar)

- 📌 [[grammar-preteritum]] — `var` 和 `snöade` 都是过去时，描述已过去的冬季
- 非人称句：`det snöade` 中 `det` 是形式主语，没有实际意义

## 生词 & 词组 (Words & Phrases)

- 词: [[snöa]] (下雪，presens: snöar, preteritum: snöade)
- 词: `vinter` (冬天), `kall` (冷的)
