# Varför kan inte vi göra samma sak?

**为什么我们不能做同样的事情？**

## 语法注解

- 反问句（rhetorical question），用于加强论证语气
- `kan inte vi` — 否定词位于动词后（因为 `Varför` 已经占V2位，主语 `vi` 在否定词前）
- `samma sak` — 同样的事情

## 关键词

- `varför` — 为什么
- `samma` — 相同的；同样的
