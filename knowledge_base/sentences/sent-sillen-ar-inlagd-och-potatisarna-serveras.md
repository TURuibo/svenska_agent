# 🇸🇪 Sillen är inlagd och potatisarna serveras med dill.

🇨🇳 鲱鱼是腌制的，土豆配莳萝一起上桌。

## 结构 (Structure)

```
[Sillen]  [är inlagd]   och  [potatisarna] [serveras]  [med dill]
  主语1    动词+形容词  连词    主语2          被动动词     伴随状语
```

## 语法点 (Grammar)

- 📌 [[grammar-participial-adjektiv]] — `inlagd` 是过去分词用作述语形容词（predikativt adjektiv），`sillen` 是 en-ord，所以用基础形 `inlagd`
- 📌 [[grammar-s-passiv]] — `serveras` 是 `servera` 的 s-被动式（"is served"）
- 📌 [[grammar-presens]] — 两个谓语均为现在时
