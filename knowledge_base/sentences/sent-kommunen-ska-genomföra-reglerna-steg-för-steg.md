# 🇸🇪 Kommunen ska genomföra reglerna steg för steg.

🇨🇳 市政府将逐步实施这些规则。

## 结构 (Structure)

```
[Kommunen] [ska genomföra] [reglerna] [steg för steg].
  主语       助动词+不定式      宾语       方式状语
```

## 语法点 (Grammar)

- 📌 [[grammar-modala-hjalpverb]] — `ska` + 不定式表示**计划 / 将要做**（官方计划常用）。
- 📌 [[grammar-bestämd-form]] — `Kommunen`、`reglerna` 都是定形：说话对象是已知的、具体的那些规则。
- 💡 `steg för steg` 是固定副词短语，放在句末说明方式，见 [[steg-för-steg]]。
