# 🇸🇪 Prata ert modersmål hemma!

🇨🇳 在家请说你们的母语！

## 结构 (Structure)

```
[Prata] [ert modersmål] [hemma] !
 祈使式      宾语         状语
```

## 语法点 (Grammar)

- 📌 [[grammar-imperativ]]
- 📌 [[grammar-possessiva-pronomen]]
- 📌 祈使式 *prata!*（v.1）。
- 📌 *ert* = 你们的（ett 形，因为 *modersmål* 是 ett 词）。
- 📌 瑞典幼儿园鼓励家长在家说母语——多语对孩子的语言发展是优势。
