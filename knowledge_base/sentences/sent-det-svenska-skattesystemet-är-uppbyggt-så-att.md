# 🇸🇪 Det svenska skattesystemet är uppbyggt så att de som tjänar mer pengar betalar mer i skatt.

🇨🇳 瑞典的税制设计成赚得多的人交更多税。

## 结构 (Structure)

```
Det svenska skattesystemet är uppbyggt [så att de [som tjänar mer pengar] betalar mer i skatt].
 主语                      动词+表语    结果从句 (så att) + 关系从句 (som)
```

## 语法点 (Grammar)

- 📌 [[grammar-sa-att-konsekvens]] — *så att* 表结果/设计目的。
- 📌 [[grammar-relativbisats]] — *de som* … = 那些……的人。
