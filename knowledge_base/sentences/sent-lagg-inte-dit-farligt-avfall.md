# Lägg inte dit farligt avfall, elektronik eller vitvaror.

中文：请勿放入危险废物、电子产品或大型家电。

## 结构 (Structure)

```
[Lägg] [inte] [dit] [farligt avfall, elektronik eller vitvaror]
 命令式  否定词  方向副词          宾语（禁止放入的物品）
```

## 语法点 (Grammar)

- 📌 [[grammar-imperativ]] — *Lägg* 是 *lägga* 的命令式，此处为否定命令：*Lägg inte dit* = "不要放入"。
- 否定命令语序：*命令式 + inte*（否定词紧跟动词后）。

## 生词 & 词组 (Words & Phrases)

- 词: [[elektronik]] (电子产品), [[vitvaror]] (大型家电)
- 词组: [[lägga-dit]] (放进去), [[farligt-avfall]] (危险废物)
