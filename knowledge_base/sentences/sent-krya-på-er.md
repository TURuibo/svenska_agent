# 🇸🇪 Krya på er!

🇨🇳 祝你们早日康复！

## 结构 (Structure)

```
[Krya] [på] [er]!
 祈使式  小品词 反身宾格
```

## 语法点 (Grammar)

- 📌 [[grammar-imperativ]]

- 📐 *krya på sig* 是反身 partikelverb，宾格随对方变化：*krya på dig*（一个人）/ *krya på er*（多人）。
- 📌 对整家人（孩子 + 家长）说时用 *er*。
