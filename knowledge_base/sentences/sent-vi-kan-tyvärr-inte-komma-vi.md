# 🇸🇪 Vi kan tyvärr inte komma, vi är bortresta den helgen.

🇨🇳 我们很遗憾不能来，那个周末我们出门在外。

## 结构 (Structure)

```
[Vi] [kan] [tyvärr] [inte] [komma], [vi] [är] [bortresta] [den helgen]
 主语 助动词 句副词  否定   不定式    主语 动词  表语(复数-a) 时间状语
```

## 语法点 (Grammar)

- 📌 [[grammar-satsadverbial]] — 句副词 `tyvärr`、`inte` 都放在助动词 kan 之后、不定式 komma 之前。
- 📌 [[grammar-modalt-hjalpverb-infinitiv]] — `kan … komma`：情态动词 + 不定式。
- 📌 [[grammar-adjektiv-plural-kongruens]] — 主语 vi 复数 → `bortresta`。
- 📌 `den helgen` = 那个周末（den + 定式名词，指前面提到的日期）。

- 词: [[tyvärr]] · [[bortrest]] · [[helg]]
