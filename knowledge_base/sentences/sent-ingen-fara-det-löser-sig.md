# 🇸🇪 Ingen fara, det löser sig.

🇨🇳 没事，会解决的。

## 结构 (Structure)

```
[Ingen fara], [det] [löser] [sig].
 应答短语   主语 动词  反身代词
```

## 语法点 (Grammar)

- 📌 [[grammar-reflexivt-verb]] — *lösa sig* = 自行解决（反身：事情「把自己解开」）

## 生词 & 词组 (Words & Phrases)

- 词: [[lösa]]
- 词组: [[ingen-fara]], [[det-löser-sig]]

## 用法提示 (Notes)

- 🗣️ 两个安慰语连用：*Ingen fara*（回应道谢/道歉都行）+ *Det löser sig*（会有办法的）。瑞典人很爱说 *det löser sig*，表达乐观、别担心。
