# 🇸🇪 Jag sitter fast på tunnelbanan, tåget står stilla.

🇨🇳 我被困在地铁上了，车停着不动。

## 结构 (Structure)

```
[Jag] [sitter fast] [på tunnelbanan], [tåget] [står] [stilla].
 主语 动词+小品词  地点状语      主语   动词  状语
```

## 语法点 (Grammar)

- 📌 [[grammar-partikelverb]] — *sitta **fast*** 重音在 fast，意思「被困住」，不是「坐得牢」
- 📌 [[grammar-v2-ordfoljd]] — 两个并列主句，各自主语在前动词第二

## 生词 & 词组 (Words & Phrases)

- 词: [[sitta]], [[tunnelbana]], [[tåg]], [[stå]], [[stilla]]
- 词组: [[sitta-fast]]

## 用法提示 (Notes)

- 📌 *stå stilla* = 停着不动（车、队伍、时间都可以 stå stilla）。*på tunnelbanan* 用 **på** 不用 i——交通工具「上」多用 på（på bussen, på tåget）。
