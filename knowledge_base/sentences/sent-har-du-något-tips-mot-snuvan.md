# 🇸🇪 Har du något tips mot snuvan?

🇨🇳 对流鼻涕你有什么建议吗？

## 结构 (Structure)

```
[Har] [du] [något tips] [mot snuvan]?
 动词  主语  宾语(ett-词)  介词短语
```

## 语法点 (Grammar)

- 📌 [[grammar-ja-nej-fraga]]

- 📐 *tips* 是 ett-词 → *något tips*（不是 ✗ *någon tips*）。
- 📌 *tips mot + 病症* = 「对付……的窍门」，*mot* 表示「针对/对抗」（*medicin mot hosta*）。
- 📌 *snuvan* 用定形：指「（她的）这个鼻涕问题」。
