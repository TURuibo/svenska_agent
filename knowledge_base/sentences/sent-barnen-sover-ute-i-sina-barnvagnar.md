# 🇸🇪 Barnen sover ute i sina barnvagnar under taket, från kvart i tolv till halv två.

🇨🇳 孩子们在屋檐下的婴儿车里睡，在户外，从十一点三刻睡到一点半。

## 结构 (Structure)

```
[Barnen] [sover] [ute] [i sina barnvagnar] [under taket], [från kvart i tolv] [till halv två]
 主语      动词    地点副词  地点(反身所有格)     地点           时间起点            时间终点
```

## 语法点 (Grammar)

- 📌 [[grammar-sin-sina]] — **sina** barnvagnar：主语自己的（复数用 sina）；用 deras 就变成"别人的"。
- 📌 [[grammar-platsadverb]] — **ute**（位置：在外面）vs ut（方向：出去）。
- ⚠️ [[grammar-klockslag-kvart]] — kvart i tolv = 11:45；[[grammar-klockan-halv]] — halv två = 13:30。
- 📌 [[grammar-tidsprepositioner]] — **från … till …** 表时段。
- 📌 瑞典特色：小班孩子常年**在户外婴儿车里午睡**（也见 [[sova-ute-i-vagn]]）。
