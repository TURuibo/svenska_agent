# 🇸🇪 Tack för info!

🇨🇳 谢谢告知！

## 结构 (Structure)

```
[Tack] [för info]
 感叹   介词短语（谢什么）
```

## 语法点 (Grammar)

- 📌 固定寒暄，省略主语和动词（完整 = Jag tackar för informationen），无 V2 问题。
- 📌 `tack för + 名词`：谢某事用 för。

## 生词 & 词组 (Words & Phrases)

- 词组: [[tack-för-info]]
- 用法: 老师收到家长病假消息后最常见的第一反应。
