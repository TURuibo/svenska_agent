# Nu kan jag handla, ringa och berätta om mitt liv på svenska.

🇨🇳 现在我可以用瑞典语购物、打电话和讲述我的生活。

## 结构 (Structure)

```
[Nu] [kan] [jag] [handla, ringa och berätta om mitt liv] [på svenska].
 时间  情态  主语         三个并列不定式动词                   语言状语
```

## 语法点 (Grammar)

- 📌 [[grammar-modala-hjalpverb]] — *kan* = modal "can/be able to" + infinitiv (无 att)
- Three coordinated infinitives: *handla, ringa, berätta*
- V2 语序：时间副词 *Nu* 前置 → 动词 *kan* → 主语 *jag*
