# 🇸🇪 Har hon själv blivit biten?

🇨🇳 她自己有没有被咬过？

## 结构 (Structure)

```
[Har] [hon] [själv] [blivit biten]?
 助动词 主语  强调    bli 完成时 + 分词
```

## 语法点 (Grammar)

- 📌 [[grammar-ja-nej-fraga]] — 助动词 har 提前，是非问句。
- 📌 [[grammar-bli-passiv-perfekt]] — *har blivit biten*：bli 被动的完成时。
- 📌 [[grammar-perfekt-particip]] — biten 与 hon 一致（ett → bitet, 复数 → bitna）。
- 💡 *själv* 紧跟主语 = "她自己（也）……"。
