# 🇸🇪 Det kan till exempel vara kostnader för tandvård, glasögon, sjukvård och medicin.

🇨🇳 例如可以是看牙、眼镜、医疗和药品方面的费用。

## 结构 (Structure)

```
[Det] [kan] [till exempel] [vara] [kostnader för tandvård, glasögon, sjukvård och medicin].
 形式主语 助动词 语气副词     不定式   表语（清单）
```

## 语法点 (Grammar)

- 📌 [[grammar-satsadverbial]] — `till exempel` 作句子副词，放在助动词 `kan` **之后**、不定式 `vara` 之前。
- 📌 [[grammar-modalt-hjalpverb-infinitiv]] — `kan vara` = 可以是 / 可能是。
- 📌 [[grammar-sammansatt-ord]] — `tandvård`（tand + vård）、`sjukvård`（sjuk + vård）。
- 💡 `Det kan vara …` 中 `det` 泛指"情况 / 事物"，用来引出例子。
