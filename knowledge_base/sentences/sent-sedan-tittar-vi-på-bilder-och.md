# 🇸🇪 Sedan tittar vi på bilder och sjunger fler sånger.

🇨🇳 然后看图片，再唱几首别的歌。

## 结构 (Structure)

```
[Sedan] [tittar] [vi] [på bilder]  och  [sjunger] [fler sånger]
 状语     动词1    主语  介词宾语          动词2(共用主语) 宾语
```

## 语法点 (Grammar)

- 📌 [[grammar-v2-ordfoljd]] — sedan 句首 → tittar vi。
- 📌 **titta på** + 宾语（看……必须带 på，中文没有）。
- 📌 [[grammar-substantiv-plural]] — bild → bilder，sång → sånger（-er 复数）。
- 📌 [[grammar-komparativ]] — **fler** = 更多（可数，många 的比较级）；不可数用 mer。
- 📌 och 连接两个动词共用主语 vi，第二个动词前不重复 vi。
