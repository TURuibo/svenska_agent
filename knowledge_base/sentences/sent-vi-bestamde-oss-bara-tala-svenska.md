# Vi bestämde oss för att bara tala svenska.

**我们决定只说瑞典语。**

## 语法注解

- `bestämde oss för att` — 决定做某事（`bestämma sig för att + infinitiv`，反身）
- `bara tala svenska` — 只说瑞典语（`bara` = 仅仅；只）

## 关键词

- `bestämma sig` — 决定（反身动词）
- [[tala]] — 说话；讲（语言）
