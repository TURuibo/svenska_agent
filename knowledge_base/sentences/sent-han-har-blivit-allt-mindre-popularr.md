# 🇸🇪 Han har blivit allt mindre populär.

🇨🇳 他变得越来越不受欢迎。

## 结构 (Structure)

```
[Han] [har blivit] [allt mindre populär]
 主语   perfekt时态    副词+比较级+形容词
```

## 语法点 (Grammar)

- 📌 [[grammar-komparativ]] — *mindre populär* = less popular（比较级）
- 📌 *allt* + 比较级 = 越来越… (*allt mer* = more and more, *allt mindre* = less and less)
- 📌 [[grammar-perfekt]] — *har blivit* 表示变化结果持续到现在
