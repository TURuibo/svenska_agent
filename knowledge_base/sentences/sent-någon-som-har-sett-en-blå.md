# 🇸🇪 Någon som har sett en blå vante med namnlapp "Olle"?

🇨🇳 有人看到一只蓝色的、写着姓名标签"Olle"的手套吗？

## 结构 (Structure)

```
[Någon] [som] [har sett] [en blå vante] [med namnlapp "Olle"]?
 主语    关系词  perfekt    宾语(en-ord+形容词)  介词短语(附加说明)
```

## 语法点 (Grammar)

- 📌 [[grammar-perfekt]] — *har sett*（se 的 supinum *sett*）：看到了→现在知道在哪
- 📌 [[grammar-adjektiv-kongruens]] — *en blå vante*：blå 与 en-ord 一致（ett blått paraply）
- 📌 口语省略：完整句是 *Är det någon som har sett …?*，群聊里省去 *Är det*
