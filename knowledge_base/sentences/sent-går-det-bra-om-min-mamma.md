# 🇸🇪 Går det bra om min mamma hämtar i stället?

🇨🇳 能让我妈妈来接吗？

## 结构 (Structure)

```
[Går] [det] [bra] [om min mamma hämtar i stället]?
 动词 主语 表语  om-从句(条件)
```

## 语法点 (Grammar)

- 📌 [[grammar-bisats-om]] — *om* 引导条件从句，从句用 presens 表将来
- 📌 [[grammar-ja-nej-fraga]] — 动词 *går* 提到句首 = 是非疑问句
- 📌 [[grammar-possessiva-pronomen]] — *min mamma*（en 词用 min）
