# 🇸🇪 På sommaren åker vi alltid till kusten.

🇨🇳 夏天我们总是去海边。

## 结构 (Structure)

```
[På sommaren] – åker – vi  – alltid – till kusten
  前置状语      动词   主语  satsadv    其余
```

**倒装结构（V2 规则）：** 句首前置状语 `På sommaren` 占第一位，动词 `åker` 被拉到第二位，主语 `vi` 退到第三位，satsadverbial `alltid` 紧跟主语之后。

## 语法点 (Grammar)

- 📌 [[grammar-satsadverbial]] — 倒装句中，satsadverbial 位于主语**之后**（不是紧跟前置成分后）
- 📌 [[grammar-v2-ordfoljd]] — V2 规则：动词必须在第二位；前置状语 → 动词 → 主语
