# Jag har bott här i sex månader.

🇨🇳 我已经在这里住了六个月了。

## 结构 (Structure)

```
[Jag] [har] [bott] [här] [i sex månader]
 主语  助动词  主动词  地点    时间状语
       (perfekt: har + supinum)
```

## 语法点 (Grammar)

- 📌 [[grammar-perfekt]] — `har bott` = `har` + supinum `bott`，表示从过去延续到现在的状态（"一直住在这里"）

## 生词 & 词组 (Words & Phrases)

- 词: `bo` (居住，supinum: `bott`), `månad` (月份; `månader` = 复数)
- 搭配: `i + 时间段`（表示持续时间）
