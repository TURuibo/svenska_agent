# 🇸🇪 I lördags vaknade jag tidigt, fast jag inte behövde gå till jobbet.

🇨🇳 上周六我醒得很早，尽管我不用去上班。

## 结构 (Structure)

```
[I lördags] [vaknade] [jag] [tidigt], [fast] [jag] [inte behövde] [gå till jobbet]
  时间状语     动词      主语   副词       连词   主语    否定+动词         不定式短语
```

## 语法点 (Grammar)

- 📌 [[grammar-i-lordags-vs-pa-lordag]] — `i lördags` = 上周六（过去），vs `på lördag` = 下周六（未来）
- 📌 [[grammar-bisats-biff]] — `fast` 引导让步从句，从句中否定词 `inte` 置于动词前（BIFF 规则）
- 📌 [[grammar-v2-ordfoljd]] — 时间状语 `I lördags` 开头 → 倒装 `vaknade jag`
