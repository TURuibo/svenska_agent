# 🇸🇪 Om ni behöver ändra schemat gör ni det i e-tjänsten minst två veckor i förväg.

🇨🇳 如果需要更改时间表，请在电子服务里至少提前两周修改。

## 结构 (Structure)

```
[Om ni behöver ändra schemat] [gör] [ni] [det] [i e-tjänsten] [minst två veckor i förväg]
        om-条件从句（句首）      动词  主语  宾语    地点            时间
```

## 语法点 (Grammar)

- 📌 [[grammar-bisats-om]] — *Om …* 条件从句放句首。
- 📌 [[grammar-inversion-efter-fundament]] / [[grammar-v2-ordfoljd]] — 从句整体是第一成分，主句必须动词先行：**gör ni**（✗ *ni gör*）。这是中文母语者最常错的一条。
- 📌 *det* 代指"改时间表"这件事。
