# 🇸🇪 Ja, hon börjar på Björnen i augusti, direkt efter semestern.

🇨🇳 对，她八月就去 Björnen 班了，一放完暑假就去。

## 结构 (Structure)

```
[Ja], [hon] [börjar] [på Björnen] [i augusti], [direkt efter semestern].
      主语  动词   地点(班名)  时间(月份)   时间补充
```

## 语法点 (Grammar)

- 📌 [[grammar-presens-for-framtid]] — börjar + 时间状语 = 将来
- 📌 [[grammar-tidsprepositioner]] — i augusti（月份用 i）；efter semestern
- 📌 班名/部门用 **på**：börja på Björnen
