# 🇸🇪 Socialtjänsten bedömer om stödet behövs för att du ska kunna leva på en rimlig nivå.

🇨🇳 社会服务处会评估是否需要这笔补助，好让你能过上合理水平的生活。

## 结构 (Structure)

```
[Socialtjänsten] [bedömer] [om stödet behövs]  [för att du ska kunna leva på en rimlig nivå].
 主语              动词       宾语从句（om = 是否）  目的从句（för att + 主语 + ska kunna + 不定式）
```

## 语法点 (Grammar)

- 📌 [[grammar-bisats-om]] — `om stödet behövs` = 是否需要这笔补助（间接是非问句）。
- 📌 [[grammar-s-passiv]] — `behövs`（`behövas` 的现在时 s-形式）：**被需要**，主语是 `stödet`。
- 📌 [[grammar-for-att-infinitiv]] / [[grammar-for-att-syfte]] — `för att` 表目的；因为从句主语 `du` 与主句主语 `socialtjänsten` **不同**，所以用 `för att + du ska kunna + 不定式`，而不是直接 `för att + 不定式`。
- 💡 `leva på en rimlig nivå` → [[leva-på-en-rimlig-nivå]]。
