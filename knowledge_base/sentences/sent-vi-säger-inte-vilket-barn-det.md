# 🇸🇪 Vi säger inte vilket barn det var, det handlar om barnens integritet.

🇨🇳 我们不说是哪个孩子，这关系到孩子们的隐私。

## 结构 (Structure)

```
[Vi] [säger] [inte] [vilket barn det var], [det] [handlar om] [barnens integritet].
 主语  动词    否定    间接疑问从句           主语   动词+介词   属格 + 名词
```

## 语法点 (Grammar)

- 📌 [[grammar-bisats-ordfoljd]] — *vilket barn det var* 是间接疑问句（从句），主语 det 在动词 var 前，不倒装（直接问句是 *Vilket barn var det?*）。
- 📌 [[grammar-handla-om]] — *det handlar om* = 这关系到/涉及。
- 📌 [[grammar-genitiv-s]] — *barnen**s** integritet*：复数定式 + s 属格。
- 📌 [[grammar-vilket-vilken-vilka]]

## 生词 & 词组 (Words & Phrases)

- 词: [[integritet]] · [[barn]] · [[vilken]]
- 词组: [[handla-om]]
- 💡 瑞典园所固定惯例：不点名另一个孩子，追问无用。
