# 🇸🇪 Om ni ändå vill ge något går det bra med en liten bok (max 100 kr).

🇨🇳 如果你们还是想送点什么，一本小书（最多 100 克朗）就很好。

## 结构 (Structure)

```
[Om ni ändå vill ge något] [går] [det] [bra] [med en liten bok]
 条件从句(fundament)        动词  主语  表语   介词短语
                           ↑ 从句放句首 → 主句主语 det 倒装到动词 går 之后
```

## 语法点 (Grammar)

- 📌 [[grammar-bisats-forst-inversion]] — 从句前置占据第一位，主句动词 `går` 必须第二位，主语 `det` 后移。
- 📌 [[grammar-bisats-om]] — `om` 条件从句；句副词 `ändå` 在从句里放主语后、动词前（BIFF）。
- 📌 [[grammar-modalt-hjalpverb-infinitiv]] — `vill ge`：情态动词 + 不定式。
- 📌 `det går bra med X` = X 就可以/就好。
