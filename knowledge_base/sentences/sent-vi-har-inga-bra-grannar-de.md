# 🇸🇪 Vi har inga bra grannar — de bråkar ofta.

🇨🇳 我们没有好邻居——他们经常吵架。

## 结构 (Structure)

```
Vi   har   inga bra grannar   —   de   bråkar   ofta
主语  动词   否定宾语(inga + adj + plural)     主语(de=grannarna)  动词(presens)  frekvensadverb
```

## 语法点 (Grammar)

- `inga` 是复数否定限定词（对应单数 `ingen`/`inget`），修饰 `bra grannar`。
- 📌 [[grammar-presens]] — `bråkar` 现在时，表示反复/习惯性行为，常与 `ofta` 搭配。
