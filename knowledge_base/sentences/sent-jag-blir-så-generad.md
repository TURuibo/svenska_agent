# 🇸🇪 Jag blir så generad.

🇨🇳 我好尴尬。

## 结构 (Structure)

```
[Jag] [blir] [så generad].
 主语  bli    程度 + 分词形容词
```

## 语法点 (Grammar)

- 📌 [[grammar-bli-passiv]] — *bli + 形容词* = 状态变化"变得……"（此刻正变得尴尬），对比 *är generad* 静态。
- 📌 [[grammar-adjektiv-som-predikat]] — generad 随主语变形（generat / generade）。
- ⚠️ 人尴尬 = **generad**，事尴尬 = **pinsam**。见上一句 [[sent-nej-men-gud-vad-pinsamt]]。
