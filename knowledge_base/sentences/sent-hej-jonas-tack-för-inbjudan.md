# 🇸🇪 Hej Jonas, tack för inbjudan!

🇨🇳 Jonas 你好，谢谢邀请！

## 结构 (Structure)

```
[Hej Jonas], [tack] [för inbjudan]
 问候+称呼      感谢   för + 名词(定式)
```

## 语法点 (Grammar)

- 📌 `tack för + 名词`：谢某事固定用 för（tack för hjälpen / tack för maten）。
- 📌 [[grammar-bestämd-form]] — `inbjudan`（en inbjudan → 定式 inbjudan，以 -an 结尾的词定式不变）。
