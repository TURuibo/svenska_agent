# 🇸🇪 Då känner de ansvar för platsen, och därmed blir det också färre problem.

🇨🇳 这样他们就会对这个地方有责任感，因此问题也会减少。

## 结构 (Structure)

```
[Då] [känner] [de] [ansvar för platsen], och [därmed] [blir] [det] [också] [färre problem].
 fundament 动词   主语   宾语                   fundament  动词   主语   副词    表语
```

## 语法点 (Grammar)

- 📌 [[grammar-inversion-efter-fundament]] — 两个分句都以非主语开头：`Då känner de …`、`därmed blir det …`，动词都在主语之前。`Då` = "那样的话 / 这样一来"。
- 📌 [[grammar-komparativ-med-färre]] — `färre`（较少，修饰可数复数 `problem`）。
- `därmed` 表示**行动带来的结果**：他们有责任感 → 因此问题减少。
- `och` 前加逗号：两个分句，各有自己的主语。
