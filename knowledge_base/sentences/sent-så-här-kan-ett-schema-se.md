# 🇸🇪 Så här kan ett schema se ut:

🇨🇳 时间表可以是这样的：

## 结构 (Structure)

```
[Så här] [kan] [ett schema] [se ut]
  状语   情态动词   主语      不定式+小品词
```

## 语法点 (Grammar)

- 📌 [[grammar-modalt-hjalpverb-infinitiv]] — *kan + se ut*：情态动词后接不带 att 的不定式；小品词 *ut* 留在句尾。
- 📌 [[grammar-v2-ordfoljd]] — *Så här* 占句首 → 动词 *kan* 第二位 → 主语 *ett schema* 在后。
- 📌 *så här* = 这样（介绍示例、示范时的开场词）；冒号后接示例。
