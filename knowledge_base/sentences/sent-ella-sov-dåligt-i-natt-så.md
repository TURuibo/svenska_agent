# 🇸🇪 Ella sov dåligt i natt, så hon kan vara lite gnällig idag.

🇨🇳 Ella 昨晚睡得不好，所以她今天可能有点闹别扭。

## 结构 (Structure)

```
[Ella] [sov] [dåligt] [i natt], [så] [hon] [kan vara] [lite gnällig] [idag].
 主语  动词(过去) 副词  时间     连词  主语  情态+不定式  表语       时间
```

## 语法点 (Grammar)

- 📌 [[grammar-preteritum]] — sov（sova 第 4 组，i natt = 昨夜 → 过去时）
- 📌 [[grammar-sa-att-konsekvens]] — så = 所以，引出结果的主句（V2 保持正常语序）
- 📌 [[grammar-modala-hjalpverb]] — kan + vara（不定式，无 att）= 可能会
