# 🇸🇪 Hej Karin!

🇨🇳 你好 Karin！

## 结构 (Structure)

```
[Hej] [Karin]
 问候  称呼
```

## 语法点 (Grammar)

- 📌 短信/邮件开头：`Hej + 名字!`——瑞典职场对上司也直呼其名，不加头衔。
