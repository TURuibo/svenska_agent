# 🇸🇪 Men med bara snuva får man komma om barnet orkar.

🇨🇳 不过要是只流鼻涕，孩子有精神的话就可以来。

## 结构 (Structure)

```
[Men] [med bara snuva] [får] [man] [komma] [om barnet orkar].
 连词  介词短语(前置)   情态  主语  不定式  om-从句
```

## 语法点 (Grammar)

- 📌 [[grammar-bisats-om]]
- 📌 [[grammar-inversion-efter-fundament]]

- 📐 *får + 不定式* = 「可以/被允许」（和上一句 *fick vabba* 的「只好」不同）。
- 📐 *om barnet orkar* 是条件从句（bisats），放在句尾时主句不倒装。
- 📌 *orka* = 有精神/有力气，是园方判断孩子能否入园的标准词。
