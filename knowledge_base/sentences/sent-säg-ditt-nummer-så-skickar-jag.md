# 🇸🇪 Säg ditt nummer, så skickar jag ett sms – då har du mitt.

🇨🇳 你把号码告诉我，我发个短信给你——你就有我的号了。

## 结构 (Structure)

```
Säg   ditt nummer,  så   skickar  jag  ett sms  –  då   har   du   mitt.
命令式  宾语          结果  动词     主语  宾语       然后  动词   主语  物主(独立)
```

## 语法点 (Grammar)

- 📌 [[grammar-imperativ]] — säg（säga 的命令式）。
- 📌 [[grammar-sa-att-konsekvens]] — 命令式 + **så** + 主句 = "你…，我就…"。
- 📌 [[grammar-v2-ordfoljd]] — så / då 占首位 → 动词第二位 → 主语后置（skickar jag, har du）。
- 📌 [[grammar-possessiva-pronomen]] — ditt nummer（ett-词 → ditt）；句尾 **mitt** 独立使用 = mitt nummer。

## 用法提示 (Notes)

- 瑞典人交换号码的标准做法：一方念号码，另一方发一条 sms，双方就都有了。
- **säg** 是 säga 的命令式（不是 säga！）。
