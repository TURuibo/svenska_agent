# 🇸🇪 Det blir ett klassiskt svenskt sommarväder imorgon.

🇨🇳 明天将是典型的瑞典夏季天气。

## 结构 (Structure)

```
Det   blir   ett klassiskt svenskt sommarväder   imorgon
形式主语 动词(将来时态blir) 表语                    时间状语
```

## 语法点 (Grammar)

- 📌 `bli` 用于天气预报的将来时表达：`det blir + 形容词/名词` = "将会是……"，是天气预报中的固定句式。

(天气预报常用词汇，复合词 `sommarväder` = sommar + väder)
