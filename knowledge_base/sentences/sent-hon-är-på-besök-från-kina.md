# 🇸🇪 Hon är på besök från Kina och pratar inte svenska.

🇨🇳 她从中国来探亲，不会说瑞典语。

## 结构 (Structure)

```
[Hon] [är] [på besök] [från Kina] [och] [pratar] [inte] [svenska].
 主语 动词 介词短语  来源状语  连词 动词  否定  宾语
```

## 语法点 (Grammar)

- 📌 [[grammar-v2-ordfoljd]] — 并列谓语共用主语 *hon*；主句否定 *inte* 放动词后（pratar inte）

## 生词 & 词组 (Words & Phrases)

- 词: [[vara]], [[besök]], [[prata]]
- 词组: [[på-besök]]

## 用法提示 (Notes)

- 📌 *vara på besök* = 在做客/来访（状态）；*komma på besök* = 来访（动作）。「不会说瑞典语」口语用 *pratar inte svenska* 就够，不必 *kan inte*。
