# 🇸🇪 Dricks är helt frivilligt i Sverige, men det uppskattas.

🇨🇳 在瑞典小费完全是自愿的，不过会很受欢迎。

## 结构 (Structure)

```
Dricks  är  helt  frivilligt  i  Sverige,  |  men  det  uppskattas.
小费    是   完全  自愿的    在  瑞典      |  但   它   会受欢迎
```

## 语法点 (Grammar)

- 📌 [[grammar-adjektiv-bojning]] — *frivilligt*（ett-ord 中性形式，因为 *dricks* 是 en-ord，这里用 predikativt/述语用法的中性形式 — 实际上 *dricks* 是 en-ord，故应为 *frivillig*；口语中 *frivilligt* 常作副词/述语形式，参见用法提示）
- 📌 *uppskattas* — passiv med -s：被欣赏/受欢迎 → [[grammar-passiv-med-s]]
- 📌 *helt* — 强化副词"完全地"
