# 🇸🇪 Skriv in lämningstid och hämtningstid för varje dag.

🇨🇳 填写每天的送园时间和接园时间。

## 结构 (Structure)

```
[Skriv in] [lämningstid och hämtningstid] [för varje dag]
 祈使动词+小品词        宾语                    状语（每天）
```

## 语法点 (Grammar)

- 📌 [[grammar-imperativ]] — 祈使式 *Skriv*（skriva 去 -a）开头，无主语；通知/表格说明常用。
- 📌 [[grammar-partikelverb]] — *skriva in*：小品词 *in* 重读、紧跟动词，宾语放后面。
- 📌 *för varje dag* = 每一天；*varje* + 单数不定式名词。
