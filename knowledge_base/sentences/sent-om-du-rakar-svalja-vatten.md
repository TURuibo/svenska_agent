# 🇸🇪 Om du råkar svälja vatten kan du bli sjuk.

🇨🇳 如果不小心吞入水，可能会生病。

## 结构 (Structure)

```
[Om du råkar svälja vatten]  [kan du bli sjuk]
     条件从句 (om-bisats)       主句（倒装）
```

## 语法点 (Grammar)

- 📌 [[grammar-om-raka-infinitiv]] — "råka + infinitiv" = happen to (accidentally do sth)
- 📌 [[grammar-bisats-om]] — om + bisats = if/conditional clause
- 主句中的倒装: om-从句在前 → 主句 V2 倒装 → "kan du" 而非 "du kan"
