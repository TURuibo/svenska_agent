# 🇸🇪 Kritiker säger att partierna sänker priset för att det snart är val i Sverige.

🇨🇳 批评者认为各党派降价是因为瑞典即将举行选举。

## 结构 (Structure)

```
Kritiker   säger   att partierna sänker priset för att det snart är val i Sverige.
主语        动词     att-从句（内含 för att，此处表原因而非目的）
```

## 语法点 (Grammar)

- 📌 [[grammar-att-sats]] — `säger att...` 引导宾语从句。
- 📌 [[grammar-for-att-syfte]] — 此处 `för att` 表原因（"因为快要选举了"），需结合语境与"目的"用法区分。
