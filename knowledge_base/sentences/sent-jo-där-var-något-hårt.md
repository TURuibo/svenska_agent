# 🇸🇪 Jo, där var något hårt.

🇨🇳 果然，那儿有个硬硬的东西。

## 结构 (Structure)

```
[Jo,]  [där] [var] [något hårt]
 语气词  地点   动词   不定代词+形容词(ett 形)
```

## 语法点 (Grammar)

- 📌 [[grammar-adjektiv-bojning]] — *något* 后形容词用 **-t** 形：*något hårt*、*något gott*。
- 📌 *Jo* 在这里不是回答否定问句，而是"果然/没错"的确认语气。*där var* = *det fanns*（口语存在句）。
