# 🇸🇪 Ja, hon har börjat krama Olle, och ibland turas de om med bilarna.

🇨🇳 有，她开始抱 Olle 了，他们有时候会轮流玩小汽车。

## 结构 (Structure)

```
[hon] [har börjat] [krama Olle], och [ibland] [turas] [de] [om] [med bilarna].
 主语  perfekt      不定式宾语       状语   动词   主语 小品词  介词短语
```

## 语法点 (Grammar)

- 📌 [[grammar-perfekt]] — *har börjat + 不定式*（börja 后直接跟动词原形，不加 att 也可）
- 📌 [[grammar-partikelverb]] — *turas om*：重音在 *om*；主语 *de* 插在 turas 和 om 之间
- 📌 [[grammar-inversion-efter-fundament]] — *ibland* 句首 → *turas de om*

## 生词 & 词组 (Words & Phrases)

- 词: [[börja]], [[krama]], [[ibland]], [[bil]]
- 词组: [[turas-om]]

## 用法提示 (Notes)

- *turas om med + 物* / *turas om att + 动词* = 轮流。
