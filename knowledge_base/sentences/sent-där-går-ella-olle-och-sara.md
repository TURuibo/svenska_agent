# 🇸🇪 Där går Ella, Olle och Sara.

🇨🇳 Ella、Olle 和 Sara 都在我们班。

## 结构 (Structure)

```
[Där]  [går]  [Ella, Olle och Sara]
 地点状语 动词   主语(倒装到动词后)
```

## 语法点 (Grammar)

- 📌 [[grammar-v2-ordfoljd]] — 地点副词 där 放句首，动词 går 第二位，主语后移。
- 📌 [[grammar-platsadverb]] — där = 在那里（指前文的 Solrosen）。
- 📌 **gå på förskolan / gå där** = "上（那所）幼儿园"，gå 在这里不是"走"，而是"就读"。
