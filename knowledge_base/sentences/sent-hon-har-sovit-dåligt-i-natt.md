# 🇸🇪 Hon har sovit dåligt i natt.

🇨🇳 她昨晚睡得不好。

## 结构 (Structure)

```
[Hon] [har] [sovit] [dåligt] [i natt]
 主语  助动词  supinum  方式副词  时间
```

## 语法点 (Grammar)

- 📌 [[grammar-perfekt]] — *har + sovit*：昨晚的事对现在（今天会累）有影响 → 用完成时汇报；叙事回忆才用 *sov*。
- 📌 [[grammar-tidsadverbial]] — 早上说 *i natt* = 昨夜/今天夜里；*i går* = 昨天。
- 📌 *dåligt* 副词形（-t）修饰动词 *sovit*。这是回答老师 *Hur har natten varit?* 的标准句。
