# 🇸🇪 Jag som aldrig satt min fot på ett gym.

🇨🇳 我这个从来没进过健身房的人（居然买了健身卡）。

## 结构 (Structure)

```
Jag  som  aldrig  satt   min fot  på ett gym.
代词 som  副词    动词(pret.) 宾语    地点
       └──── som-从句，主句省略 ────┘
```

## 语法点 (Grammar)

- 📌 [[grammar-pronomen-som-utrop]] — “Jag som …” 表惊讶/反差的感叹式片段
- 📌 [[grammar-preteritum]] — satt（sätta 的 preteritum）。注意：按标准用法这里 “aldrig har satt” (perfekt) 或 “aldrig hade satt” 更常规；口语/非正式书写中用 preteritum 表示“（在此之前）从来没有”，属口语化用法。
- 📌 [[grammar-possessiva-pronomen]] — min fot（主语 jag → min，不用 sin）
- bisats 语序：aldrig 在动词前。
