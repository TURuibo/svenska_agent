# 🇸🇪 Min mamma föll förra månaden när hon snubblade över en cykel som låg mitt på trottoaren, berättar han.

🇨🇳 我妈妈上个月被一辆躺在人行道中间的自行车绊了一下，摔倒了，他说。

## 结构 (Structure)

```
"[Min mamma] [föll] [förra månaden] [när hon snubblade över en cykel [som låg mitt på trottoaren]]," [berättar] [han].
    主语       动词      时间状语        when 从句（含 som 关系从句）                                 引语动词    说话人
```

## 语法点 (Grammar)

- 📌 [[grammar-preteritum-oregelbundna]] — `föll`（falla）、`låg`（ligga）是**强变化过去式**：`falla – föll – fallit`，`ligga – låg – legat`。
- 📌 [[grammar-preteritum]] — `snubblade`（snubbla，第 1 组）是规则过去式。
- 📌 [[grammar-bisats-tidskonnektor]] — `när hon snubblade …`：`när`（当……时）引导时间从句，说明"摔倒"的原因 / 时刻。
- 📌 [[grammar-bisats-med-som]] — `en cykel som låg …`：`som` 引导关系从句修饰 `cykel`。
- 📌 [[grammar-v2-ordfoljd]] — 引语在前时，`berättar han` 动词在主语之前（倒装）。
- 💡 `mitt på trottoaren`：见 [[mitt-på]]（`mitt på` + 表面）。
