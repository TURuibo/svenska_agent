# 🇸🇪 Vi lämnar bara ut barnen till anmälda hämtare, även om det är farmor eller mormor.

🇨🇳 我们只把孩子交给已登记的接送人，哪怕是奶奶或外婆也一样。

## 结构 (Structure)

```
[Vi] [lämnar] [bara] [ut] [barnen] [till anmälda hämtare], [även om det är farmor eller mormor].
 主语 动词  副词 小品词 宾语   介词短语(复数形容词)   让步从句
```

## 语法点 (Grammar)

- 📌 [[grammar-partikelverb]] — *lämna **ut*** = 交出/放行；副词 *bara* 插在动词和小品词之间
- 📌 [[grammar-även-om]] — *även om* = 即使/哪怕，引导让步 bisats
- 📌 [[grammar-perfekt-particip]] + [[grammar-adjektiv-kongruens]] — *anmälda hämtare*：过去分词作定语，复数用 -a

## 生词 & 词组 (Words & Phrases)

- 词: [[lämna]], [[anmäld]], [[hämtare]], [[farmor]], [[mormor]]
- 词组: [[lämna-ut]]

## 用法提示 (Notes)

- ⚠️ 园所安全规则原话：只交给 *anmälda hämtare*。新接送人要先在 app 里 *lägga till*、第一次 *visa legitimation*。**farmor** = 奶奶（父方），**mormor** = 外婆（母方）——瑞典语区分，中文也区分，一一对应。
