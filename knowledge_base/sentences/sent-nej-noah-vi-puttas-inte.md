# 🇸🇪 Nej, Noah, vi puttas inte!

🇨🇳 不行，Noah，我们不推人！

## 结构 (Structure)

```
Nej, Noah,  vi   puttas     inte!
           主语  -s 动词(互相)  否定
```

## 语法点 (Grammar)

- 📌 [[grammar-s-verb-reciprok]] — puttas 不是被动，是"互相推"；家长立规矩固定用 **vi + -s 动词 + inte**。

## 生词 & 词组 (Words & Phrases)

- 词: [[putta]]
- 词组: [[vi-puttas-inte]]

## 用法提示 (Notes)

- 同类规矩句：*Vi bits inte. Vi slåss inte. Vi skriker inte.*
- 用 **vi** 而不是 du：语气是"我们大家都不这么做"，不是单独训斥。
