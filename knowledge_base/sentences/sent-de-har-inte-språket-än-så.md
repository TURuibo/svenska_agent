# 🇸🇪 De har inte språket än, så de blir frustrerade, och så kommer tänderna.

🇨🇳 他们还没有语言表达，所以会受挫，再加上在长牙。

## 结构 (Structure)

```
[De] [har] [inte] [språket] [än], så [de] [blir] [frustrerade], och så [kommer] [tänderna].
 主语  动词  否定   定式宾语   还    所以 主语 bli   复数形容词      再加上  动词   主语(倒装)
```

## 语法点 (Grammar)

- 📌 [[grammar-sa-att-konsekvens]] — *så* = 所以（结果）；第二个 *och så* = 再加上/然后。
- 📌 [[grammar-bli-passiv]] — *blir frustrerade*：状态变化。
- 📌 [[grammar-adjektiv-kongruens]] — de 复数 → frustrerad**e**。
- 📌 [[grammar-bestämd-form]] — *språket*, *tänderna* 泛指概念用定式。
- 💡 *och så kommer tänderna*：句首是 så，动词 kommer 第二位，主语 tänderna 倒到后面（V2）。
