# 🇸🇪 ett svullet knä / det svullna knäet / svullna knän / de svullna knäna

🇨🇳 肿的膝盖（四式变形）

## 结构 (Structure)

```
obestämd sg:  ett  svullet  knä
              art  adj(n)   subst(ett)

bestämd sg:   det  svullna  knäet
              art  adj+na   subst+et  ⚠️ knäet 不是 knän!

obestämd pl:  svullna  knän
              adj+na   subst+n

bestämd pl:   de   svullna  knäna
              art  adj+na   subst+na
```

## 语法点 (Grammar)

- 📌 [[grammar-adjektivbojning]] — 形容词与 ett-ord 名词的四式变格
  - utrum obestämd: svullen
  - neutrum obestämd: **svullet**
  - bestämd/plural: **svullna**
- 过去分词用作形容词（svälla → svullen / svullet / svullna）
- ⚠️ knäet（bestämd sg）= knä + et，不要混淆 knän（obestämd pl）

## 生词 & 词组 (Words & Phrases)

- 词: [[svullen]] — 肿的；肿胀的（svälla 的过去分词）
- 词: [[knä]] — 膝盖
