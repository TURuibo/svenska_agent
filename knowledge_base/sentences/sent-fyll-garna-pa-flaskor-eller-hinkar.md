# Fyll gärna på flaskor eller hinkar med vatten på fredagskvällen.

中文：建议在周五晚上提前将水瓶或水桶装满水备用。

## 结构 (Structure)

```
[Fyll] [gärna] [på] [flaskor eller hinkar] [med vatten] [på fredagskvällen]
 命令式  情态副词  粒子      宾语1 或 宾语2       用水          时间状语
```

## 语法点 (Grammar)

- 📌 [[grammar-imperativ]] — *Fyll* 是命令式，用于礼貌建议（搭配 *gärna* 使语气柔和）。
- *gärna* 在命令式中表示"请……/建议……"，使语气更友好而非强制。

## 生词 & 词组 (Words & Phrases)

- 词: [[hink]] (水桶), *flaska* (瓶子), *fredagskvällen* (周五晚上)
- 词组: [[fyll-på-med]] (装满……)
