# 🇸🇪 Vi hoppas att du kan komma och fira med oss!

🇨🇳 我们希望你能来和我们一起庆祝！

## 结构 (Structure)

```
[Vi]  [hoppas]  [att du kan komma och fira med oss]
 主语   动词           att-从句（宾语从句）
```

att-从句内部：`du`（主语）+ `kan`（情态动词）+ `komma och fira`（不定式并列）+ `med oss`

## 语法点 (Grammar)

- 📌 [[grammar-att-sats]] — att-从句作宾语（宾语从句）：*hoppas att* = 希望……
- `kan` 是情态动词，后接不定式 `komma`。

## 生词 & 词组 (Words & Phrases)

- `fira` = 庆祝（动词）
