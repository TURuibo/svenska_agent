# 🇸🇪 Det är någon som hjälper dig att få bättre koll på din ekonomi och hantera dina skulder.

🇨🇳 这是一个帮助你更好地掌握财务状况、处理债务的人。

## 结构 (Structure)

```
[Det är] [någon] [som hjälper dig] [att få bättre koll på din ekonomi] [och (att) hantera dina skulder].
 主句      先行词   关系从句          不定式 1                              不定式 2（省略 att）
```

## 语法点 (Grammar)

- 📌 [[grammar-relativ-bisats-med-som]] — `någon som hjälper dig`：`som` 作从句主语，不能省略。
- 📌 [[grammar-infinitiv]] — `hjälpa någon att + 不定式`；两个不定式用 `och` 并列，第二个的 `att` 可省略。
- 💡 `Det är någon som …` — "这是一个……的人"，引出人物的定义句。
