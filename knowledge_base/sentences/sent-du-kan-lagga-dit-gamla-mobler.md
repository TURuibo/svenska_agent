# Du kan lägga dit gamla möbler, kartonger och annat skräp.

中文：您可以将旧家具、纸箱和其他杂物放入其中。

## 结构 (Structure)

```
[Du] [kan] [lägga] [dit] [gamla möbler, kartonger och annat skräp]
 主语  情态  动词    方向副词          宾语（列举）
```

## 语法点 (Grammar)

- 📌 [[grammar-modala-hjalpverb]] — *kan* = "可以"，表示许可。*lägga* 是不定式。
- *dit* 是方向副词，指向前文已提及的 container（废料箱）。

## 生词 & 词组 (Words & Phrases)

- 词: [[skräp]] (杂物), *möbler* (家具, pl.), *kartong* (纸箱)
- 词组: [[lägga-dit]] (放进去)
