# 🇸🇪 Vi ses på söndag!

🇨🇳 周日见！

## 结构 (Structure)

```
[Vi] [ses] [på söndag]
 主语  相互动词(-s)  时间状语（将来的星期日）
```

## 语法点 (Grammar)

- 📌 [[grammar-s-verb-reciprok]] — `ses` = 互相见面（se + -s 表相互）。
- 📌 [[grammar-i-lordags-vs-pa-lordag]] — `på söndag` = 下个星期日（将来）；`i söndags` = 上个星期日。
