# 🇸🇪 Hemma kan ni sätta ord på känslorna, till exempel "Du blev arg", och lära henne att säga stopp.

🇨🇳 在家你们可以帮她把情绪说出来，比如"你生气了"，然后教她说"停"。

## 结构 (Structure)

```
[Hemma] [kan] [ni] [sätta ord på känslorna], …, och [lära] [henne] [att säga stopp].
 前置状语 情态(V2) 主语 不定式短语              并列  不定式  宾语   att + 不定式
```

## 语法点 (Grammar)

- 📌 [[grammar-v2-ordfoljd]] — 句首是 *Hemma*，所以动词 kan 第二位、主语 ni 倒到后面。
- 📌 [[grammar-modala-hjalpverb]] — *kan sätta … och (kan) lära*：两个不定式共用一个 kan，语气比命令式客气（老师对家长）。
- 📌 [[grammar-infinitiv]] — *lära henne **att** säga*：lära någon att + 动词。
- 📌 [[grammar-bli-passiv]] — 引语 *Du blev arg*：bli + 形容词表变化。
