# 🇸🇪 Vi hörs!

🇨🇳 回头联系！

## 结构 (Structure)

```
Vi   hörs!
主语  -s动词(互相听到=联系)
```

## 语法点 (Grammar)

- 📌 [[grammar-s-verb-reciprok]] — hörs = 互相联系，不是被动。

## 生词 & 词组 (Words & Phrases)

- 词: [[höra]]
- 词组: [[vi-hörs]]

## 用法提示 (Notes)

- 和 *Vi ses!* 并列的最常见告别语；hörs 偏"打电话/发消息联系"，ses 偏"见面"。
