# 🇸🇪 Vi vill inte förbjuda elsparkcyklar, men vi måste skydda människor som går, säger Maria Lindqvist, ordförande i tekniska nämnden.

🇨🇳 “我们不想禁止电动滑板车，但必须保护步行的人，”技术委员会主席玛丽亚·林德奎斯特说。

## 结构 (Structure)

```
"[Vi] [vill inte förbjuda] [elsparkcyklar], men [vi] [måste skydda] [människor som går]," [säger] [Maria Lindqvist], [ordförande i tekniska nämnden].
  主语   情态+否定+不定式      宾语         转折    主语   情态+不定式       宾语(含 som 从句)       引语动词    主语（说话人）   同位语（身份）
```

## 语法点 (Grammar)

- 📌 [[grammar-modala-hjalpverb]] — `vill … förbjuda`、`måste skydda`：情态动词 + 不带 att 的不定式；`vill inte`（不想）与 `måste`（必须）形成对比。
- 📌 [[grammar-v2-ordfoljd]] — 引语放句首，之后 `säger` 紧跟在引语后、主语 `Maria Lindqvist` 在其后（倒装）：新闻引语的固定格式。
- 📌 [[grammar-bisats-med-som]] — `människor som går`：`som` 引导关系从句修饰 `människor`。
- 💡 `Maria Lindqvist, ordförande i tekniska nämnden`：两个逗号之间是**同位语**，交代说话人的身份；`ordförande i …`（介词用 `i`）。
