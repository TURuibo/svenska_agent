# 🇸🇪 Får hon komma tillbaka på torsdag?

🇨🇳 她星期四可以回来吗？

## 结构 (Structure)

```
[Får] [hon] [komma tillbaka] [på torsdag]?
 情态动词 主语  不定式（小品词动词）  时间
```

## 语法点 (Grammar)

- 📌 [[grammar-modal-fa-permission]] — `få` 这里 = 被允许（may），不是「得到」。
- 📌 [[grammar-ja-nej-fraga]] — 是非问句：动词提到句首，主语第二。
- 📌 [[grammar-tidsprepositioner]] — 星期几用 `på`：på torsdag / på fredag。
