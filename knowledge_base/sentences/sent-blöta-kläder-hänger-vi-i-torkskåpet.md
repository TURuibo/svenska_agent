# 🇸🇪 Blöta kläder hänger vi i torkskåpet.

🇨🇳 湿衣服我们挂在烘干柜里。

## 结构 (Structure)

```
Blöta kläder   hänger   vi   i torkskåpet
宾语(首位)      V2       主语  地点状语(定式)
```

## 语法点 (Grammar)

- 📌 [[grammar-v2-ordfoljd]] / [[grammar-inversion-efter-fundament]] — 宾语 *blöta kläder* 提前 → 动词第二、主语 *vi* 第三；中文语序"湿衣服我们挂…"恰好也宾语前置，但瑞典语动词必须紧跟其后
- 📌 [[grammar-adjektiv-plural-kongruens]] — *kläder* 只有复数 → *blöta*
- 📌 *i torkskåpet* 定式：说话双方都知道的那个柜子
