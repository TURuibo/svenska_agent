# 🇸🇪 Nej, nästan inte alls.

🇨🇳 没有，几乎完全没哭。

## 结构 (Structure)

```
Nej, | nästan | inte alls.
 否定应答 | 程度副词 | 「完全不」
```

## 语法点 (Grammar)

- （无特别语法点）
- 📐 *inte alls* = 完全不；前加 *nästan* = 几乎完全不。省略了动词（*hon grät nästan inte alls*）。
