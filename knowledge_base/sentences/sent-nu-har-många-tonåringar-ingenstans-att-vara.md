# 🇸🇪 Nu har många tonåringar ingenstans att vara på kvällarna.

🇨🇳 现在很多青少年晚上无处可去。

## 结构 (Structure)

```
[Nu] [har] [många tonåringar] [ingenstans att vara] [på kvällarna]
 时间  动词   主语               宾语(无处可待)           时间状语
```

## 语法点 (Grammar)

- 📌 [[grammar-inversion-efter-fundament]] — `Nu` 占首位 → `har` 在主语前。
- 📌 [[grammar-infinitivkonstruktion]] — `ingenstans att vara` = "没有地方可以待"，`att + 动词原形` 修饰 `ingenstans`。
- `på kvällarna`：定指复数 = "每天晚上 / 在晚间时段"（习惯性）。
