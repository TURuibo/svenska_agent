# 🇸🇪 Kommunens politiker hävdar att vi inte har råd med fler fritidsgårdar.

🇨🇳 市里的政治家们声称，我们负担不起更多的青少年活动中心。

## 结构 (Structure)

```
[Kommunens politiker] [hävdar] [att [vi] [inte] [har] [råd med fler fritidsgårdar]]
 主语(属格)             动词      att-从句：主语 否定词 动词 宾语
```

## 语法点 (Grammar)

- 📌 [[grammar-att-bisats]] — `hävdar att …`：att-从句作宾语。
- 📌 [[grammar-bisats-biff]] — 从句里 `inte` 在定式动词 `har` **之前**（对比主句 `Vi har inte råd`）。
- 📌 [[grammar-genitiv-s]] — `Kommunens` = 市政府的（-s 属格，无撇号）。
- 引出**对方的观点**：说话者在转述政治家的主张，随后在下一句里用 `Å ena sidan … å andra sidan` 展开权衡。
