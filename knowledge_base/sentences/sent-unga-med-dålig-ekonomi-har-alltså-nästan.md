# 🇸🇪 Unga med dålig ekonomi har alltså nästan inga alternativ.

🇨🇳 所以经济条件不好的年轻人几乎没有选择。

## 结构 (Structure)

```
[Unga med dålig ekonomi] [har] [alltså] [nästan inga alternativ]
 主语(名词化形容词+后置修饰)  动词   副词     宾语
```

## 语法点 (Grammar)

- 📌 [[grammar-satsadverbial]] — `alltså` 放在**定式动词 `har` 之后**，表示"由前文推出的结论"。
- 📌 [[grammar-v2-ordfoljd]] — 主语在首位，动词第二位。
- `unga` = 形容词名词化（"年轻人"）；`med dålig ekonomi` 后置修饰（"经济状况差的"）。
- `nästan inga` = "几乎没有"。
- 论说文的**结论句**：前面列了"在家没地方、咖啡馆要花钱"，用 `alltså` 收束。
