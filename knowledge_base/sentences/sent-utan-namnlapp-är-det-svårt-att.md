# 🇸🇪 Utan namnlapp är det svårt att hitta rätt tröja.

🇨🇳 没有姓名标签，很难找到对的那件上衣。

## 结构 (Structure)

```
Utan namnlapp   är   det   svårt   att hitta rätt tröja
介词短语(首位)   V2   形式主语  表语   att + 不定式(真正主语)
```

## 语法点 (Grammar)

- 📌 [[grammar-v2-ordfoljd]] — *Utan namnlapp* 占首位 → *är det* 倒装
- 📌 [[grammar-opersonligt-det]] / [[grammar-infinitiv-subjekt]] — *det är svårt att + 不定式*（做…很难），形容词用 ett 形 *svårt*
- 📌 *utan* + 名词不定式无冠词：*utan namnlapp*（没有标签）
