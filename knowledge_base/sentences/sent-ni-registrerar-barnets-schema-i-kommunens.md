# 🇸🇪 Ni registrerar barnets schema i kommunens e-tjänst.

🇨🇳 请在市政的电子服务里登记孩子的在园时间表。

## 结构 (Structure)

```
[Ni] [registrerar] [barnets schema] [i kommunens e-tjänst]
 主语     动词          宾语              地点状语
```

## 语法点 (Grammar)

- 📌 [[grammar-presens]] — 通知里用 presens 陈述句表示"你们（应该）这样做"，比祈使句更客气：*Ni registrerar …* ≈ 请登记。
- 📌 [[grammar-genitiv-s]] — 两个所有格：*barnets schema*（孩子的时间表）、*kommunens e-tjänst*（市政的电子服务）：定式 + -s。
- 📌 *ni* 在通知里指全体家长（你们），大写 *Ni* 只是句首。
