# 🇸🇪 Jaha, okej.

🇨🇳 啊，这样。

## 结构 (Structure)

```
[Jaha], [okej].
 反应词  接受
```

## 语法点 (Grammar)

- 📌 无语法结构。*jaha* = "哦，原来如此"（接收到新信息），*okej* = 接受。两者连用 = "啊，明白了"。
- 💡 jaha 的语调决定含义：平调 = 明白了；升调 = 有点惊讶/怀疑。
