# 🇸🇪 Man vet inte i förväg vad som kommer att finnas där.

🇨🇳 事先不知道那里会有什么。

## 结构 (Structure)

```
[Man] [vet] [inte] [i förväg] [vad som kommer att finnas där]
 主语   V    否定    时间状语     间接疑问从句 (vad = 宾语, som = 主语标记)
```

## 语法点 (Grammar)

- 📌 [[grammar-indirekt-fraga]] — `vad som kommer …`：疑问词引导的间接问句，词序同陈述句。因为 `vad` 是宾语，主语位置需要 `som`。
- 📌 [[grammar-kommer-att-infinitiv]] — `kommer att finnas` 表示将来。
- 📌 [[grammar-bisats-ordfoljd]] — 主句 `inte` 在动词后（vet inte），从句中副词在动词前。
- 📌 [[grammar-man-generellt]] — 泛指的 `man`。
