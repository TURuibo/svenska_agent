# 🇸🇪 Du kan också få ekonomiskt bistånd för vissa kostnader som inte kommer varje månad.

🇨🇳 对于不是每个月都会发生的某些费用，你也可以获得经济补助。

## 结构 (Structure)

```
[Du kan också få ekonomiskt bistånd] [för vissa kostnader] [som inte kommer varje månad].
 主句                                 对象                  关系从句：som + inte + 动词 + 时间
```

## 语法点 (Grammar)

- 📌 [[grammar-relativ-bisats-med-som]] — `kostnader som inte kommer varje månad`：`som` 作从句主语，限定 `kostnader`（不是每月都有的费用）。
- 📌 [[grammar-bisats-biff]] — 从句里 `inte` 在动词 `kommer` **之前**（`som inte kommer`）。
- 💡 `vissa kostnader som …` = "某些……的费用"（限定范围）。
