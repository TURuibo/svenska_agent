# 🇸🇪 Är språket formellt eller informellt? Kan du ge några exempel?

🇨🇳 语言是正式的还是非正式的？你能举几个例子吗？

```
[Är] [språket] [formellt eller informellt]?   [Kan] [du] [ge] [några exempel]?
 动词  主语      表语（二选一）                   情态  主语  不定式  宾语
```

## 语法点 (Grammar)

- 📌 [[grammar-ja-nej-fraga]] — 动词在前的是非问句（Är …? Kan …?），`eller` 给出二选一
- 📌 [[grammar-formellt-brev]] — 判断正式/非正式文体
- 表语形容词用 ett-形 formellt（språket 是 ett-词）
