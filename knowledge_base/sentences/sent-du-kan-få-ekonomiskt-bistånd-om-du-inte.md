# 🇸🇪 Du kan få ekonomiskt bistånd om du inte kan försörja dig själv eller din familj.

🇨🇳 如果你无法养活自己或家人，就可以获得经济补助。

## 结构 (Structure)

```
[Du kan få ekonomiskt bistånd]  [om du inte kan försörja dig själv eller din familj].
 主句（kan + 不定式）             条件从句：om + 主语 + inte + 动词 …
```

## 语法点 (Grammar)

- 📌 [[grammar-bisats-om]] — `om` 引导条件从句：如果……。
- 📌 [[grammar-bisats-biff]] — 从句里 **`inte` 放在限定动词 `kan` 之前**（`om du inte kan`），主句则是 `Du kan inte …`。
- 📌 [[grammar-reflexivt-pronomen]] — `försörja dig själv`：反身代词 `dig`（`själv` 强调）；`din familj` 是另一个宾语。
- 📌 [[grammar-modalt-hjalpverb-infinitiv]] — `kan` + 不定式 `få` / `försörja`。
