# 🇸🇪 Vi ska sluta med nappen snart, det säger vi varje vecka!

🇨🇳 我们说很快就要戒奶嘴了——每周都这么说！

## 结构 (Structure)

```
[Vi] [ska] [sluta med nappen] [snart], [det] [säger] [vi] [varje vecka]
 主语 情态  动词短语        时间   宾语(句首) 动词 主语  频率
```

## 语法点 (Grammar)

- 📌 [[grammar-modala-hjalpverb]]
- 📌 [[grammar-v2-ordfoljd]]
- ska + 动词原形 = 打算/将要。
- 第二分句把宾语 det 放句首 → 动词 säger 第二位、主语 vi 在后（V2）。
- 自嘲语气：每周都说要戒，一直没戒。
