# 🇸🇪 Å ena sidan förstår jag den tanken, för pengarna måste räcka till både skolor och äldreomsorg.

🇨🇳 一方面，我理解这种想法，因为钱必须同时够用于学校和养老服务。

## 结构 (Structure)

```
[Å ena sidan] [förstår] [jag] [den tanken], för [pengarna] [måste räcka till] [både skolor och äldreomsorg].
 fundament     动词      主语   宾语            主语         情态+动词+小品词      宾语(both…and)
```

## 语法点 (Grammar)

- 📌 [[grammar-inversion-efter-fundament]] — `Å ena sidan` 占首位 → `förstår` 在 `jag` 之前，不能写 ~~Å ena sidan jag förstår~~。
- 📌 [[grammar-modala-hjalpverb]] — `måste` + 动词原形 `räcka till`。
- `för` 在这里是**并列连词"因为"**，后接**正常主句语序**（主语 – 动词），不触发从句语序。
- `den tanken` = 指示词 `den` + 定指形式 `tanken`。
