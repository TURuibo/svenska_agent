# 🇸🇪 Men vid magsjuka gäller 48-timmarsregeln: barnet ska vara symtomfritt i 48 timmar efter sista kräkningen eller diarrén.

🇨🇳 不过肠胃炎适用 48 小时规则：孩子在最后一次呕吐或腹泻之后要 48 小时没有症状。

## 结构 (Structure)

```
[Men] [vid magsjuka] [gäller] [48-timmarsregeln]:
 连词   状语（前置）   动词    主语（倒装）
[barnet] [ska] [vara] [symtomfritt] [i 48 timmar] [efter sista kräkningen eller diarrén]
 主语     情态  不定式  表语(ett→-t)  持续时间     时间起点
```

## 语法点 (Grammar)

- 📌 [[grammar-inversion-efter-fundament]] — 状语 `vid magsjuka` 放句首 → 动词 gäller 第二位，主语 48-timmarsregeln 退到动词后。
- 📌 [[grammar-adjektiv-kongruens]] — barnet 是 ett-词 → symtomfri**t**；hon 是人 → symtomfri。
- 📌 [[grammar-modalt-hjalpverb-infinitiv]] — `ska vara`：情态动词 + 不定式，ska 表规定/应当。
- 📌 [[grammar-tidsprepositioner]] — `i 48 timmar` 持续多久；`efter + 定式` 在…之后。
- 📌 定式：48-timmarsregeln、sista kräkningen、diarrén——已知/特指的规则和事件用定式。
