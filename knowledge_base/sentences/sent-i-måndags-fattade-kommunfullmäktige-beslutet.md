# 🇸🇪 I måndags fattade kommunfullmäktige beslutet om de nya reglerna.

🇨🇳 周一，市议会就新规做出了决定。


## 语法点 (Grammar)

- 📌 [[grammar-v2-ordfoljd]] — 时间状语 `I måndags` 放句首，动词 `fattade` 紧跟其后，主语退后。
- 📌 [[grammar-preteritum]] — `fattade` 是 `fatta`（第 1 组）的过去式：`fatta – fattade – fattat`。
- 📌 [[grammar-bestämd-form]] — `beslutet`、`reglerna` 是定形（`ett beslut → beslutet`，`regler → reglerna`）；`de nya reglerna` 用**双重定形**（`de` + 形容词 + 名词定形）。
