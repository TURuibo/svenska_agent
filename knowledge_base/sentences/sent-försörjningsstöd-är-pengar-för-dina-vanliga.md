# 🇸🇪 Försörjningsstöd är pengar för dina vanliga utgifter varje månad.

🇨🇳 生活费补助是用于你每个月日常开支的钱。

## 结构 (Structure)

```
[Försörjningsstöd] [är] [pengar] [för dina vanliga utgifter] [varje månad].
 主语                动词   表语     用途（för + 名词短语）       时间（频率）
```

## 语法点 (Grammar)

- 📌 [[grammar-sammansatt-ord]] — `försörjningsstöd` = `försörjning` + `s` + `stöd`；无冠词，因为它是不可数的统称。
- 💡 `varje månad`（每个月）：时间状语不需要介词。`dina` 物主代词与复数名词 `utgifter` 一致。
