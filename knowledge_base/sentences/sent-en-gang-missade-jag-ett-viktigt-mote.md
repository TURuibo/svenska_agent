# En gång missade jag ett viktigt möte för att jag inte hittade rätt.

🇨🇳 有一次，因为找不到地方，我错过了一个重要的会面。

## 结构 (Structure)

```
[En gång] [missade] [jag] [ett viktigt möte] [för att jag inte hittade rätt].
  时间状语   动词(V2)  主语      宾语                    原因从句
```

## 语法点 (Grammar)

- 📌 [[grammar-preteritum]] — *missade* = preteritum of *missa* (v.1); *hittade* = preteritum of *hitta*
- 📌 [[grammar-orsakskonjunktion]] — *för att* here = "because" (causal, not purposive)
- V2 语序：句首时间状语 *En gång* → 动词 *missade* → 主语 *jag*
