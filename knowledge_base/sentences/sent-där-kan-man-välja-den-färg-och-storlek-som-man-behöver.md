# 🇸🇪 Där kan man titta på bilder och välja den färg och storlek som man behöver.

🇨🇳 在那里可以看图片，选择自己需要的颜色和尺码。

## 结构 (Structure)

```
[Där] [kan] [man] [titta på bilder och välja [den färg och storlek] [som man behöver]]
 fundament V  S         两个不定式                 先行词      关系从句
```

## 语法点 (Grammar)

- 📌 [[grammar-v2-ordfoljd]] — `Där`（指"在网上"）在句首，动词 `kan` 第二位，主语 `man` 随后。
- 📌 [[grammar-man-generellt]] — `man` = 泛指的"人们/你"。
- 📌 [[grammar-den-som-relativ]] / [[grammar-relativ-bisats-med-som]] — `den färg och storlek som man behöver`：`den` 先行词 + `som` 引导的关系从句（som 是宾语，口语中可省）。

## 生词 & 词组 (Words & Phrases)

- 词: [[färg]], [[storlek]], [[nät]]
- 词组: [[på-nätet]]（上一句 `på nätet`，`Där` 指代它）
