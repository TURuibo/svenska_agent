# 🇸🇪 De var oroliga att barn som läste om Pippi skulle börja göra som henne.

🇨🇳 他们担心读了皮皮故事的孩子会开始模仿她。

## 结构 (Structure)

```
[De]   [var]   [oroliga]   [att]   [barn som läste om Pippi]   [skulle börja göra som henne]
 主语   V2      表语          att-     名词 + 关系从句 (som-sats)    情态动词+双重不定式
(位置1) (位置2)               sats引导词
```

**关键点：**
- `De var oroliga` = 主句（V2 正常语序）
- `att` 引导宾语 att-sats（相当于英语 that-clause）
- `barn som läste om Pippi` = 名词 + 关系从句 (`som` = 关系代词 who/that)
- `skulle börja göra som henne` = 情态动词 + 双重不定式（should start to do like her）

## 语法点 (Grammar)

- 📌 [[grammar-att-sats]] — `att` 引导宾语从句，内含 `som`-关系从句，结构较复杂（B1级）
- 📌 [[grammar-v2-ordfoljd]] — 主句 `De var` 正常 V2 语序
