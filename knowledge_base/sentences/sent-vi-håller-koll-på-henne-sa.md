# 🇸🇪 Vi håller koll på henne, sa Anna.

🇨🇳 "我们会留意她的，"Anna 说。

## 结构 (Structure)

```
[Vi] [håller koll på] [henne],  [sa] [Anna]
 主语  固定表达(现在时)  宾语      引述动词  说话人
```

## 语法点 (Grammar)

- 📌 [[grammar-presens-for-framtid]] — 现在时 *håller* 表示"接下来会（一直）留意"，不必用 *ska/kommer att*。
- 📌 [[grammar-presens-preteritum-ram]] — 引语现在时 + *sa Anna*。
- 📌 *hålla koll på någon/något* = 盯着、留意；老师对家长的安抚固定句。
