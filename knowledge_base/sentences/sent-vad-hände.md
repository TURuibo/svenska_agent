# 🇸🇪 Vad hände?

🇨🇳 怎么了？

## 结构 (Structure)

```
[Vad] [hände]?
 疑问词 动词(preteritum)
```

## 语法点 (Grammar)

- 📌 [[grammar-frageord]] — vad 作主语时后面直接接动词，无倒装问题。
- 📌 [[grammar-preteritum]] — hände（hända 的过去式，v.2a）。
- 💡 最短的追问句，比 *Vad har hänt?* 更口语。
