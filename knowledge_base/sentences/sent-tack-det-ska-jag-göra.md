# 🇸🇪 Tack, det ska jag göra!

## 结构 (Structure)


## 语法点 (Grammar)

- 📌 [[grammar-inversion-efter-fundament]]
- 📌 [[grammar-presens-for-framtid]]

- 📐 宾语 *det* 提前到句首 → *ska* 在第二位，主语 *jag* 在后（V2）。
- 📌 *Det ska jag göra!* 是接受建议的固定回应：「我会这么做的」。
- 📐 *ska + 不定式* 这里表示打算/将来。
