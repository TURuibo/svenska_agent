# 🇸🇪 Vi bygger med klossar, lägger pussel, ritar, målar och läser böcker.

🇨🇳 我们搭积木、拼拼图、画画、涂颜色、读书。

## 结构 (Structure)

```
[Vi] [bygger med klossar], [lägger pussel], [ritar], [målar] och [läser böcker]
 主语  动词短语1             动词短语2        动词3    动词4      动词短语5   ← 并列，共用主语
```

## 语法点 (Grammar)

- 📌 [[grammar-presens]] — 五个动词并列（逗号 + 最后 och），都是现在时、共用主语 vi。
- 📌 [[grammar-substantiv-plural]] — kloss → klossar；bok → **böcker**（不规则，变元音）。
- 📌 固定搭配：bygga **med** klossar（用 med）· **lägga** pussel（不是 göra）· läsa böcker。
- 📌 **rita**（线条画/画画）vs **måla**（颜料涂画）——中文都是"画"。
