# 🇸🇪 Det spelar ingen roll vem som äger marken.

🇨🇳 无论谁拥有那片土地都没关系。

```
[Det spelar ingen roll] [vem som äger marken]
      主句                    宾语从句
  （无所谓）           （谁拥有那片土地）
```

- 📌 固定短语 **det spelar ingen roll** = "无所谓/没关系"
