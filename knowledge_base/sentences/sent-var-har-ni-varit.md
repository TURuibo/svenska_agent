# 🇸🇪 Var har ni varit?

🇨🇳 你们去哪儿了？

## 结构 (Structure)

```
[Var]  [har]  [ni]  [varit]?
 疑问词  助动词  主语  supinum
```

## 语法点 (Grammar)

- 📌 [[grammar-presens-perfekt]]

- 📐 疑问词 *var* 开头 → 动词 *har* 紧跟在第二位（V2），主语 *ni* 在动词后。
- 📌 *har varit* = presens perfekt：问的是「这一段时间你们（一直）在哪」，中文用「去哪儿了」。
- ⚠️ *var*（哪里）≠ *vart*（去哪，方向）：这里问的是「待在哪」，所以用 *var*。
