# 🇸🇪 Två glas vatten räcker, tack.

🇨🇳 两杯水就够了，谢谢。

## 结构 (Structure)

```
Två  glas  vatten  räcker,  tack.
两   杯    水      够了     谢谢
```

## 语法点 (Grammar)

- 📌 *räcker* — 动词 *räcka*（够，足够）presens；主语是 *två glas vatten*
- 📌 量词结构：*två glas* = 两杯（glas 既是"杯子"也是"玻璃"）
