# 🇸🇪 Vad var det för något?

🇨🇳 是什么病呀？

## 结构 (Structure)

```
[Vad] [var] [det] [för något]?
 疑问词 preteritum 主语  「什么样的」
```

## 语法点 (Grammar)

- 📌 [[grammar-preteritum]]

- 📐 *vad … för (något)* = 「什么样的 / 到底是什么」，*för* 与 *vad* 分开放：*Vad är det för bok?*
- 📌 用 preteritum *var*：问已经发生的病。
- 📌 口语里 *för något* 可以省成 *Vad var det?*，加上 *för något* 更自然。
