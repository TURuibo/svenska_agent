# 🇸🇪 Tack så mycket!

🇨🇳 非常感谢！

## 结构 (Structure)

```
[Tack] [så mycket] !
  谢谢   非常/很多（强调）
```

## 语法点 (Grammar)

- 固定感谢表达，*tack* = 谢谢，*så mycket* = 非常多（强调程度）。
- 比单独的 *tack* 更强烈的感谢。
