# 🇸🇪 Det är ett ledigt bord vid fönstret.

🇨🇳 窗边有张空桌。

## 结构 (Structure)

```
[Det]  [är]   [ett ledigt bord]  [vid fönstret].
 这     是      一张空桌子           在窗边
```

## 语法点 (Grammar)

- 📌 [[grammar-det-finns]] — `det är` 用来指出某处存在某物
- 📌 `ledigt` = `ledig`（空闲的）的中性形，因为 `bord` 是 ett-词
