# 🇸🇪 Det känns inte alltid tryggt.

🇨🇳 感觉不总是安全的。

## 结构 (Structure)

```
[Det] [känns] [inte] [alltid] [tryggt]
 形主  动词    否定   频率副词   形容词补语
```

## 语法点 (Grammar)

- 📌 [[grammar-satsadverbial]] — "inte" 是否定副词，"alltid" 是频率副词，在 bisats 中需排在动词后（但这是主句语序）。
- 📌 [[grammar-deponensverb]] — "kännas" 是反身/非人称动词（s-verb），"det känns" = "it feels"。形容词 "tryggt" 是补语，用 ett-形式因为指代的主语 "det" 是中性。
