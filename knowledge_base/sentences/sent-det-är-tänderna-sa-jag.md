# 🇸🇪 Det är tänderna, sa jag.

🇨🇳 "是牙的事，"我说。

## 结构 (Structure)

```
[Det] [är] [tänderna],  [sa] [jag]
 主语  动词  表语(定复)   引述动词  说话人（倒装）
```

## 语法点 (Grammar)

- 📌 [[grammar-bestämd-form]] — *tänderna*（定形复数，umlaut a→ä）= "（她的）牙"，指双方都明白的原因。
- 📌 [[grammar-presens-preteritum-ram]] — 引语现在时 *är* + 引述过去时 *sa jag*（倒装）。
- 📌 家长解释症状原因的极简模板：*Det är + 定形名词*（*Det är tänderna / magen / örat*）。
