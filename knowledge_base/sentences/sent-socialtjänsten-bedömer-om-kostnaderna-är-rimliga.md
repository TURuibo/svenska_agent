# 🇸🇪 Socialtjänsten bedömer om kostnaderna är rimliga.

🇨🇳 社会服务处会评估这些费用是否合理。

## 结构 (Structure)

```
[Socialtjänsten] [bedömer] [om kostnaderna är rimliga].
 主语（定形）      动词        宾语从句（om = 是否）
                            om + 主语 + 动词 + 表语
```

## 语法点 (Grammar)

- 📌 [[grammar-bisats-om]] — 这里的 `om` = **是否**（间接是非问句），不是"如果"。
- 📌 [[grammar-indirekt-fraga]] — 从句语序：`kostnaderna`（主语）在 `är` 前，不倒装。
- 📌 [[grammar-adjektiv-plural-kongruens]] — 主语 `kostnaderna` 是复数 → 表语 `rimliga`（加 -a）。
