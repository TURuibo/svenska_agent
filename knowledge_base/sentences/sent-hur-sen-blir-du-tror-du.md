# 🇸🇪 Hur sen blir du, tror du?

🇨🇳 你觉得会晚多久？

## 结构 (Structure)

```
[Hur sen] [blir] [du], [tror du]?
 疑问短语  动词  主语   附加问句
```

## 语法点 (Grammar)

- 📌 [[grammar-frageord]] — *hur* + 形容词 = 「多……」（hur sen / hur länge / hur mycket）
- 📌 [[grammar-presens-for-framtid]] — *blir* 指将来会晚多少

## 生词 & 词组 (Words & Phrases)

- 词: [[sen]], [[bli]]
- 词组: [[bli-sen]]

## 用法提示 (Notes)

- 📌 句尾 *tror du?* 是软化语气的附加问，相当于「你估计……？」。中文说「晚多久」，瑞典语常说 *hur sen*（多晚）而不是 *hur länge*。
