# 🇸🇪 Vi väntar på dig!

🇨🇳 我们在等你！

## 结构 (Structure)

```
[Vi]  [väntar]  [på]  [dig]!
 主    动词      介词   代词宾语
```

`vänta på ngn` = 等待某人（介词 `på` 不可省略）。

## 语法点 (Grammar)

- 动词短语：`vänta på` + 人 = wait for someone
- `dig` = 你（宾格，二人称单数）
