# 🇸🇪 Vi ses!

🇨🇳 回见！

## 结构 (Structure)

```
[Vi] [ses]!
 主语 s-动词(相互)
```

## 语法点 (Grammar)

- 📌 [[grammar-s-verb-reciprok]] — *ses* = se + s，「互相见」→ 我们（会）见

## 生词 & 词组 (Words & Phrases)

- 词: [[ses]]
- 词组: [[vi-ses]]

## 用法提示 (Notes)

- 🗣️ 最常用的告别语之一，= 「回头见」。电话结束、门口道别都可以。变体：*Vi ses i morgon!* / *Vi hörs!*（电话/信息里「回头联系」）。
