# 🇸🇪 Fick ni vabba hela veckan?

🇨🇳 你们整周都得请假照顾他吗？

## 结构 (Structure)

```
[Fick] [ni] [vabba] [hela veckan]?
 助动词(pret.) 主语 不定式  时长
```

## 语法点 (Grammar)

- 📌 [[grammar-ja-nej-fraga]]
- 📌 [[grammar-preteritum]]

- 📐 是非问句：动词 *Fick* 放句首，主语 *ni* 在后。
- 📌 *få + 不定式* 这里的意思接近「不得不 / 结果只好」（*fick vabba* = 只好请假照顾），不是「被允许」。
- 📌 *vabba* 见 [[vabba]]：VAB = vård av barn。
