# 🇸🇪 Vi öppnar klockan halv sju.

🇨🇳 我们六点半开门。

## 语法点 (Grammar)

- ⚠️ [[grammar-klockan-tidsuttryck]] — **halv sju = 6:30**，不是 7:30！halv = "到下一个整点差半小时"。
- 📌 [[grammar-klockan-tidsuttryck]] — klockan + 时刻，可省略为 *halv sju*。
- 📌 [[grammar-presens]] — 描述固定作息用现在时。
- 📌 öppna 不带宾语 = "开门营业"（反义 stänga）。
