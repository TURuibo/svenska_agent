# 🇸🇪 Jag tycker om mitt jobb, för jag känner att jag gör nytta.

🇨🇳 我喜欢我的工作，因为我觉得自己在做有意义的事。

## 结构 (Structure)

```
Jag  tycker om  mitt jobb,  för  jag  känner  att jag gör nytta.
主语   partikelverb  宾语     并列连词  主语   动词     att-宾语从句
```

`för`（因为）后的从句保持**正常语序**（主语+动词），因为它是并列连词，不是从属连词。

## 语法点 (Grammar)

- 📌 [[grammar-for-konjunktion]] — `för` 是并列连词，只能放在两个主句之间，后接正常主句语序
- 📌 [[grammar-att-bisats]] — `känner att jag gör nytta` 中 `att`-宾语从句
