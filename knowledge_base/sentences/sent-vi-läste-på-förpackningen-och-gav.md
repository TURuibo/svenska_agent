# 🇸🇪 Vi läste på förpackningen och gav rätt dos efter vikt.

🇨🇳 我们看了包装说明，按体重给了正确的剂量。


## 语法点 (Grammar)

- 📌 [[grammar-preteritum]] — *läsa → läste*（v.2 -te）；*ge → gav*。
- 📌 [[grammar-bestamd-form]] — *på förpackningen*（那个包装）。
- 📌 *läsa på något* = 读某物上的文字；*efter* 此处 = 按照。*rätt dos* 无冠词（固定搭配）。
