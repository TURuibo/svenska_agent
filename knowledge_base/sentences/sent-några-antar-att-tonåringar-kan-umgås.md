# 🇸🇪 Några antar att tonåringar kan umgås hemma eller i centrum.

🇨🇳 有些人认为青少年可以在家或在市中心聚在一起。

## 结构 (Structure)

```
[Några] [antar] [att [tonåringar] [kan umgås] [hemma eller i centrum]]
 主语    动词     att-从句：主语      情态+动词      地点状语
```

## 语法点 (Grammar)

- 📌 [[grammar-att-bisats]] — `antar att …`：假设 / 以为……
- 📌 [[grammar-deponensverb]] — `umgås` 只有 -s 形式（形式被动、意思主动）。
- 📌 [[grammar-modala-hjalpverb]] — `kan` + 动词原形 `umgås`。
- `Några` = "一些人"（代词作主语）。用 `Några antar att …` 引出**对方的看法**，随后用 `Men …` 反驳。
