# Maten håller sig inte kall och jag tvingas kasta bort mat varje dag.

🇨🇳 食物无法保持低温，我每天都不得不扔掉食物。

```
[Maten]  [håller sig inte kall]  och  [jag]  [tvingas]  [kasta bort mat]  [varje dag]
  主语       谓语（否定状态保持）        主语      被迫          动词短语          时间状语
```

- 📌 [[grammar-passiv-med-s]] — `tvingas` 是 `tvinga` 的 -s 被动形式，意为"被迫/不得不"
- 📌 `hålla sig + adjektiv` — 保持某状态（`hålla sig kall` = 保持低温）
