# 🇸🇪 Ge inte upp!

🇨🇳 不要放弃！

## 结构 (Structure)

```
[Ge] [inte] [upp]!
 祈使  否定词  小品词
```

## 语法点 (Grammar)

- 📌 [[grammar-imperativ]] — `Ge` 是 `ge` 的祈使句形式（irregular: `ge → ge`）
- 📌 否定祈使句：`verb + inte + partikel`（`ge inte upp`）
- 📌 `ge upp` 是 partikelverb（放弃）；否定时 `inte` 插入动词与小品词之间
