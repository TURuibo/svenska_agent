# 🇸🇪 Han gillade egentligen inte konditionsträning utan det som lockade var saften och kakorna efter träningen och att barn tilläts tävla.

🇨🇳 其实他并不喜欢耐力训练，吸引他的是训练后的果汁和饼干，以及孩子可以参加比赛。

## 结构 (Structure)

```
[Han gillade egentligen INTE konditionsträning]  UTAN  [det som lockade]  VAR  [saften och kakorna … och att barn tilläts tävla]
 否定句（他其实不喜欢耐力训练）                   而是   主语（吸引他的东西）  是    表语（两个并列成分）
                                                           └ det + som-relativsats = "…的东西"(英 what)
```

## 语法点 (Grammar)

- 📌 [[grammar-utan-vs-men]] — 前半句有 `inte` → 纠正/替代用 **utan**（而是），不能用 *men*。
- 📌 [[grammar-relativ-bisats-med-som]] — **det som lockade** = "吸引（他）的东西"，相当于英语 *what attracted (him)*。`som` 在从句里作主语，所以紧接动词。
- 📌 [[grammar-preteritum-s-form]] / [[grammar-s-passiv]] — **tilläts** = tillåta 的过去式 s-形式（被允许）：*att barn tilläts tävla* = 孩子们被允许参加比赛。
- 📌 *var* 后面的表语由 `och` 并列两种成分：名词短语 *saften och kakorna* + att-从句 *att barn tilläts tävla*。
