# 🇸🇪 Det betyder att man bara får lämna elsparkcyklarna på särskilda parkeringsplatser.

🇨🇳 这意味着人们只能把电动滑板车停放在指定的停车位上。

## 结构 (Structure)

```
[Det] [betyder] [att] [man] [bara] [får lämna] [elsparkcyklarna] [på särskilda parkeringsplatser].
 主语    动词      连词    主语   副词    定式动词+不定式    宾语                 地点
```

## 语法点 (Grammar)

- 📌 [[grammar-att-bisats]] — `Det betyder att …`（"这意味着……"）：`att` 从句交代含义。
- 📌 [[grammar-bisats-biff]] — 从句里副词 `bara` 放在定式动词 `får` **之前**；对比主句 `Man får bara lämna …`。
- 📌 [[grammar-man-generellt]] — `man` = 泛指的"人们 / 一个人"。
- 📌 [[grammar-modal-fa-permission]] — `bara får lämna` = 只被允许把……放在（规则意义）。
- 💡 `särskilda` 是 `särskild` 的复数形式，修饰 `parkeringsplatser`。
