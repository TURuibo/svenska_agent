# 🇸🇪 Hon pekar på det hon vill ha, och hon förstår enkla instruktioner.

🇨🇳 她想要什么就用手指，而且能听懂简单的指令。

## 结构 (Structure)

```
[Hon] [pekar på] [det (som) hon vill ha], och [hon] [förstår] [enkla instruktioner].
 主语  动词+介词   宾语=关系从句(som 省略)        主语  动词    形容词复数+名词复数
```

## 语法点 (Grammar)

- 📌 [[grammar-relativbisats]] — *det hon vill ha* = *det som hon vill ha*，som 作宾语时可省
- 📌 [[grammar-adjektiv-plural-kongruens]] — *enkla instruktioner*（复数一致）

## 生词 & 词组 (Words & Phrases)

- 词: [[peka]], [[förstå]], [[enkel]], [[instruktion]]
- 词组: [[peka-på]]

## 用法提示 (Notes)

- *peka på något* = 指向某物。
