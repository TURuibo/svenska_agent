# Föräldrar och skolor kan inte lösa detta problem ensamma...

🇸🇪 Föräldrar och skolor kan inte lösa detta problem ensamma – det krävs politiska åtgärder.
🇨🇳 父母和学校无法单独解决这个问题——需要政治行动。

## 语法分析 (Grammar Notes)

- `kan inte lösa` — 情态动词否定：不能解决
- `ensamma` — 副词："单独地/自己"（bestämd form av *ensam*，作副词修饰）
- `det krävs politiska åtgärder` — 非人称被动（[[grammar-det-kravs]]）
