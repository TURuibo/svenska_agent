# 🇸🇪 Vår äldsta gjorde likadant, och det gick över.

🇨🇳 我家老大以前也一样，后来就过去了。

## 结构 (Structure)

```
[Vår äldsta] [gjorde] [likadant], och [det] [gick] [över]
 主语(最高级作名词) 过去时  副词      连词  主语 过去时 小品词
```

## 语法点 (Grammar)

- 📌 [[grammar-preteritum]]
- 📌 [[grammar-preteritum-oregelbundna]]
- vår äldsta = 我家老大（äldst 是 gammal 的最高级，作名词用，省略 barn）。
- gjorde / gick 都是不规则过去时。
- gå över = 过去/消失（partikelverb）。
