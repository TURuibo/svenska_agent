🇨🇳 《一闪一闪小星星》我大概唱了十遍。


## 语法点 (Grammar)

- 📌 [[grammar-starka-verb]] — *sjunga → sjöng → sjungit*。
- 📌 [[grammar-tidsadverbial]] — *tio gånger*（十遍/十次）无介词，放句尾。
- 📌 *säkert* 在这里 = "起码、少说也有"（夸张语气），不是"安全地"。
