# 🇸🇪 Om barnet behöver specialkost av medicinska skäl behövs ett läkarintyg.

🇨🇳 如果孩子因医学原因需要特殊饮食，就需要医生证明。

## 结构 (Structure)

```
[Om barnet behöver specialkost av medicinska skäl] [behövs] [ett läkarintyg]
            条件从句（bisats）                      动词(s-被动)   主语
```

## 语法点 (Grammar)

- 📌 [[grammar-bisats-om]]
- 📌 [[grammar-s-passiv]]
- 📌 条件从句在前 → 主句动词 *behövs* 紧随其后（从句整体占第一位）。
- 📌 *behövs* = behöver + s：「被需要」，主语是 *ett läkarintyg*。*behöver → behövs*（-er 去 e 加 s）。
- 📌 主句无逗号也可以（瑞典语从句后常不加逗号）。
