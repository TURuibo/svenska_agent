# 🇸🇪 Barn som behöver omsorg de veckorna går på förskolan Ekbacken.

🇨🇳 那几周需要托管的孩子去 Ekbacken 幼儿园。

## 结构 (Structure)

```
[Barn [som behöver omsorg de veckorna]] [går] [på förskolan Ekbacken]
  主语 + som-关系从句                      动词      地点
```

## 语法点 (Grammar)

- 📌 [[grammar-relativ-bisats-med-som]] — *som* 引导关系从句修饰 *barn*（那些需要托管的孩子）；从句嵌在主语里，主句动词 *går* 紧跟其后，不倒装。
- 📌 [[grammar-bestämd-form]] — *de veckorna* = 那几周（de + 定式复数 = 指示）；*förskolan Ekbacken* 通名定式 + 专名。
- 📌 *barn* 复数与单数同形（ett barn / flera barn）。
