# 🇸🇪 Passar det klockan tio?

🇨🇳 十点合适吗？

## 结构 (Structure)

```
Passar  det   klockan tio?
动词     主语   时间
```

## 语法点 (Grammar)

- 📌 [[grammar-ja-nej-fraga]] — 动词 passar 放句首。
- 📌 [[grammar-datum-och-tid]] — klockan tio = 十点（整点直接 klockan + 数字）。

## 生词 & 词组 (Words & Phrases)

- 词: [[passa]]
- 词组: [[passar-det]]

## 用法提示 (Notes)

- **passa** 这里 = 时间上合适（不是"看管/照看"那个义项）。
- 回答：*Det passar bra* / *Det passar inte, kan vi ta elva?*
