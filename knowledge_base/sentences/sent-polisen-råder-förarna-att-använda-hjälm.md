# 🇸🇪 Polisen råder förarna att använda hjälm.

🇨🇳 警方建议骑行者戴头盔。

## 结构 (Structure)

```
[Polisen] [råder] [förarna] [att använda] [hjälm].
  主语      动词    间接宾语(人)  att + 不定式    宾语
```

## 语法点 (Grammar)

- 📌 [[grammar-infinitivkonstruktion]] — `råda + 人 + att + 不定式`：人（`förarna`）是直接宾语，`att använda hjälm` 是建议的内容。
- 📌 [[grammar-bestämd-form]] — `polisen`、`förarna` 定形（`polis → polisen`，`förare → förarna`）。
- 💡 `använda hjälm`（不带冠词）：泛指"戴头盔"这一习惯，名词用无冠词形式。
- ⚠️ 这里的 `råda` 是"建议"义，不是 `det råder …`（情况存在），见 [[råda]]。
