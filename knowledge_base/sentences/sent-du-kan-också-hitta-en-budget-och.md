# 🇸🇪 Du kan också hitta en budget- och skuldrådgivare via Konsumentverket.

🇨🇳 你也可以通过消费者事务局找到预算与债务顾问。

## 结构 (Structure)

```
[Du] [kan] [också] [hitta] [en budget- och skuldrådgivare] [via Konsumentverket].
 主语  助动词 语气副词  不定式    宾语（省略式复合词）          途径
```

## 语法点 (Grammar)

- 📌 [[grammar-sammansatt-ord]] — `budget- och skuldrådgivare`：并列复合词省略第一个的 `rådgivare`，用连字符 `budget-` 代替。
- 📌 [[grammar-satsadverbial]] — `också`（也）放在助动词 `kan` 之后。
- 💡 `Konsumentverket` = 瑞典消费者事务局（专有名词，不译）；`via` = 通过。
