# 🇸🇪 En förskola kan vara kommunal eller fristående.

🇨🇳 幼儿园可以是公立的，也可以是私立的。

## 结构 (Structure)

```
[En förskola] [kan] [vara] [kommunal eller fristående]
    主语      情态  不定式    表语（形容词，en 形）
```

## 语法点 (Grammar)

- 📌 [[grammar-modala-hjalpverb]]
- 📌 [[grammar-adjektiv-som-predikat]]
- 📌 *kan vara* = 可以是；情态动词 + 不定式 *vara*。
- 📌 表语形容词与主语 *en förskola* 一致：*kommunal*（en 形）；*fristående* 不变形。
- 📌 *eller* = 或者。
