# 🇸🇪 Jag stödjer reglerna helt.

🇨🇳 我完全支持这些规则。

## 结构 (Structure)

```
[Jag] [stödjer] [reglerna] [helt].
 主语    动词       宾语      程度副词
```

## 语法点 (Grammar)

- 📌 [[grammar-bestämd-form]] — `reglerna` 是定形复数，指"上文说的那些规则"。
- 💡 `stödja` 直接带宾语，**不加介词**；程度副词 `helt`（完全）放在句末加强语气。
- 💡 变位：`stödjer`（现在）、`stödde`（过去）、`stött`（完成），见 [[stödja]]。
