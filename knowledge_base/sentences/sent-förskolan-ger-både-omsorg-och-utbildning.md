# 🇸🇪 Förskolan ger både omsorg och utbildning.

🇨🇳 幼儿园既提供照护，也提供教育。

## 结构 (Structure)

```
[Förskolan] [ger] [både omsorg och utbildning]
 主语(定)   动词     宾语（både … och …）
```

## 语法点 (Grammar)

- 📌 [[grammar-presens]]
- 📌 [[grammar-bestämd-form]]
- 📌 *både … och …* = 既…又…，连接两个并列名词。
- 📌 *förskolan* 定冠形——泛指「瑞典的幼儿园（这个制度）」。
- 📌 *ger* 是 *ge* 的 presens（v.4 不规则：ge–ger–gav–gett）。
