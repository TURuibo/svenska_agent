# 🇸🇪 Det är ett misstag, och jag vill förklara mina skäl.

🇨🇳 这是个错误，我想解释一下我的理由。

## 结构 (Structure)

```
[Det] [är] [ett misstag], och [jag] [vill förklara] [mina skäl].
 主语  动词   表语              主语   情态+动词原形    宾语
```

## 语法点 (Grammar)

- 📌 [[grammar-modala-hjalpverb]] — `vill` + 动词原形 `förklara`（不加 att）。
- 两个主句用 `och` 连接，各有自己的主语时，`och` 前常加逗号。
- 论说文**开头段**的典型套路：先亮出观点（`Det är ett misstag`），再预告"我要解释理由"。
