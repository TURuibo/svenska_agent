# 🇸🇪 Ett kort och tydligt avsked är bäst, dra inte ut på det.

🇨🇳 简短、明确的告别最好，别拖太久。

## 结构 (Structure)

```
[Ett kort och tydligt avsked]  [är]  [bäst]  [, dra]  [inte]  [ut]  [på det]
   主语(ett-词+形容词)        系动词 最高级   命令式   否定  小品词  介词短语
```

## 语法点 (Grammar)

- 📌 [[grammar-adjektiv-kongruens]] — *avsked* 是 ett-词 → *tydligt*
- 📌 [[grammar-imperativ]] — 否定命令式：*inte* 紧跟动词 *dra* 之后
- 📌 [[grammar-partikelverb]] — *dra ut på ngt* 拖长某事
