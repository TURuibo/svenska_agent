# 🇸🇪 De förstod också att barn behöver leka för att må bra.

🇨🇳 他们也理解孩子需要玩耍才能身心健康。

## 结构 (Structure)

```
[De]   [förstod]   [också]   [att barn behöver leka]   [för att må bra]
 主语    V2-动词     副词          att-sats（宾语从句）         för att + 不定式（目的）
(位置1)  (位置2)
```

**关键点：**
- `förstod` 是 `förstå` 的不规则 preteritum（V2 位置）
- `att barn behöver leka` = att-sats 作宾语（that-clause）
- `för att må bra` = 目的从句（in order to feel well）— 不含主语，用不定式

## 语法点 (Grammar)

- 📌 [[grammar-att-sats]] — `att` 引导宾语从句；`för att` 引导目的不定式（两种用法对比）
- 📌 [[grammar-v2-ordfoljd]] — `De förstod` 正常语序（主语在位置1，动词在位置2）
