# 🇸🇪 Meddela gärna om ert barn har någon allergi.

🇨🇳 如果你们的孩子有什么过敏，请告诉我们。

## 结构 (Structure)

```
[Meddela] [gärna] [om ert barn har någon allergi]
 命令式    软化副词  om-从句（此处 om = 是否/如果）
```

## 语法点 (Grammar)

- 📌 [[grammar-imperativ]] — `Meddela`（v.1 动词命令式 = 词干 meddela）；加 `gärna` 让请求变得客气。
- 📌 [[grammar-bisats-om]] — `om ert barn har någon allergi`：从句语序，主语 ert barn 在前。
- 📌 [[grammar-possessiva-pronomen]] — `ert barn`：er/ert/era 随名词性数变化，barn 是 ett-词 → ert。
