# Forskare varnar för att ännu fler kan dö i framtiden om jorden blir varmare.

🇨🇳 研究人员警告说，如果地球继续变暖，未来可能会有更多人死亡。

## 语法分析 (Grammar)

- `varnar för att` — 警告（关于）……，固定搭配
- `om jorden blir varmare` → [[grammar-bisats-om]] — 条件从句（如果……）
- `kan dö` → [[grammar-modala-hjalpverb]] — 情态动词（可能会）
- `varmare` → 比较级

## 关键词 (Key Words)

- [[forskare]] — 研究者
- [[varna]] — 警告
- [[jord]] — 地球（jorden = 地球，定冠词形）
- [[varm]] — 热的（varmare = 比较级）
