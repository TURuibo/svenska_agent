# 🇸🇪 Ella, vill du låna spaden?

🇨🇳 Ella，你想借这把小铲子吗？

## 结构 (Structure)

```
Ella,  vill   du   låna   spaden?
呼语    情态   主语  不定式   宾语(定式)
```

## 语法点 (Grammar)

- 📌 [[grammar-ja-nej-fraga]] — vill 提前，是非问句。
- 📌 [[grammar-modala-hjalpverb]] — vill + låna（无 att）。
- 📌 [[grammar-bestämd-form]] — spaden：双方都知道的那把铲子 → 定式。

## 生词 & 词组 (Words & Phrases)

- 词: [[låna]]
- 词: [[spade]]

## 用法提示 (Notes)

- **låna** 既可"借入"也可"借出"（这里是借出给 Ella）；明确借出说 *låna ut*。
- 用提问（vill du…?）而不是命令，是瑞典家长化解争抢的常见方式。
