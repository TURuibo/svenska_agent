# 🇸🇪 Lägger man ihop Polens och Sveriges förmågor så blir de mycket imponerande.

🇨🇳 如果把波兰和瑞典的军事能力加在一起，那将会非常令人印象深刻。

## 结构 (Structure)

```
Lägger   man   ihop   Polens och Sveriges förmågor   så   blir de mycket imponerande
动词     主语   小品词  宾语                          连接词 主句2(条件结果)
```

## 语法点 (Grammar)

- 📌 隐含条件句：动词提前（`Lägger man ihop...`）相当于"如果……"，无需 `om`，后接 `så` 引出结果分句——口语化的条件句变体。
