# 🇸🇪 Att man bor nära sin familj.

🇨🇳 住在家人附近。（作为主语从句：住在家人附近【是重要的】）

## 结构 (Structure)

```
[Att man bor]  [nära]  [sin familj]
  主语从句      介词      反身所有格+名词
(= Att-sats作主语)
```

## 语法点 (Grammar)

- 📌 [[grammar-att-sats]] — **att-sats 作主语**:
  全句来自 Q4 列表 *Vad är viktigt för att trivas...?* 的选项。
  *Att man bor nära sin familj* = 这件事（住在家人附近）是重要的。
  att 从句直接作主语，相当于英语 gerund "Living near one's family."

- 📌 [[grammar-sin-sina]] — **反身所有格代词 sin/sitt/sina（★高频考点）**:
  | 指代主语 | en-词 | ett-词 | 复数 |
  |---------|-------|--------|------|
  | 第三人称主语（同句） | **sin** | **sitt** | **sina** |
  
  本课提供三个对比例子：
  - *Att man bor nära **sin** familj.* — familj 是 en-词 → **sin**
  - *Att man bor nära **sitt** jobb.* — jobb 是 ett-词 → **sitt**
  - *Att man bor nära **sina** vänner.* — vänner 是复数 → **sina**
  
  ⚠️ 与 hans/hennes/deras 区别：sin/sitt/sina 指向主语本身（reflexivt），hans/hennes/deras 指向第三方。
  - *Hon hälsar på sin granne.* — 她拜访她自己的邻居（sin = 她自己的）
  - *Hon hälsar på hennes granne.* — 她拜访她（别人的）邻居（hennes = 另一个人的）
