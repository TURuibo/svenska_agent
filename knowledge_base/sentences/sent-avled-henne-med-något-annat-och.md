# 🇸🇪 Avled henne med något annat, och skäll inte på henne.

🇨🇳 用别的东西转移她的注意力，不要训斥她。

## 结构 (Structure)

```
[Avled] [henne] [med något annat], och [skäll] [inte] [på henne].
 命令式  宾语    方式               并列  命令式  否定   på + 宾语
```

## 语法点 (Grammar)

- 📌 [[grammar-imperativ]] — v.2 动词命令式 = 去掉 -a：avleda → **avled!**, skälla → **skäll!**（v.1 则保留 -a：trösta!）。否定直接接 inte：*Skäll inte.*
- 💡 *något annat* = 别的东西（annat 是 annan 的中性形式，配 något）。
- 💡 与上一句 *ni kan …* 对比：命令式更直接，作为建议时通常用于简短、具体的动作。
