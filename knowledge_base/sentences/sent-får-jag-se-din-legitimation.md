# 🇸🇪 Får jag se din legitimation?

🇨🇳 我能看一下你的证件吗？

## 结构 (Structure)

```
[Får] [jag] [se] [din legitimation]?
 情态动词(请求许可) 主语 不定式 宾语(物主代词)
```

## 语法点 (Grammar)

- 📌 [[grammar-modal-fa-permission]] — *Får jag …?* = 我可以……吗？（礼貌请求）
- 📌 [[grammar-ja-nej-fraga]] — 情态动词提前
- 📌 [[grammar-possessiva-pronomen]] — *din legitimation*（en 词用 din）

## 生词 & 词组 (Words & Phrases)

- 词: [[legitimation]]
- 词组: [[visa-legitimation]]

## 用法提示 (Notes)

- 📌 *Får jag se …?* 是礼貌查看的固定句。园所第一次见新接送人必问，回答就是出示 *pass* 或 *id-kort*。
