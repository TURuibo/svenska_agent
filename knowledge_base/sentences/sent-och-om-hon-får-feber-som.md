# 🇸🇪 Och om hon får feber som inte går över?

🇨🇳 那要是她发烧一直不退呢？

## 结构 (Structure)

```
[Och] [om] [hon] [får] [feber] [som inte går över]?
 连词  连词  主语  动词  宾语   som-从句(否定在动词前)
```

## 语法点 (Grammar)

- 📌 [[grammar-bisats-om]]
- 📌 [[grammar-relativsats-som]]

- 📐 *om*-从句 + *som*-从句叠加，都是 bisats。
- ⚠️ bisats 里 *inte* 放在动词**前**：*som inte går över*（主句才是 *går inte över*）。
- 📌 只说从句当问句（*Och om …?*）= 「那要是……呢？」，口语常见。
