# 🇸🇪 Kom, Ella, så tar jag dig i famnen.

🇨🇳 来，Ella，我抱抱你。

## 结构 (Structure)

```
[Kom,]  [Ella,]  [så]  [tar]  [jag]  [dig]  [i famnen]
 命令式   呼语    连接   动词(V2)  主语   宾语   状语
```

## 语法点 (Grammar)

- 📌 [[grammar-imperativ]] — *Kom!* 命令式 = 动词原形去 -a（komma → kom）
- 📌 [[grammar-v2-ordfoljd]] — *så* 在句首 → *tar jag* 倒装

## 生词 & 词组 (Words & Phrases)

- 词: [[famn]]
- 词组: [[ta-i-famnen]]

## 备注 (Notes)

- 「命令式 + så + 主句」= 「你……，然后我就……」，非常口语。
