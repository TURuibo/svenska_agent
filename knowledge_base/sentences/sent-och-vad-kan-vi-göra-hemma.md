# 🇸🇪 Och vad kan vi göra hemma?

🇨🇳 还有，我们在家能做什么？

## 结构 (Structure)

```
Och [vad] [kan] [vi] [göra] [hemma]?
     疑问词 情态(V2) 主语 不定式  地点副词
```

## 语法点 (Grammar)

- 📌 [[grammar-frageord]] — vad 在句首，动词 kan 第二位，主语 vi 在其后。
- 📌 [[grammar-modala-hjalpverb]] — kan + göra（不加 att）。
- 💡 句首 *Och* 表示"还有一个问题"，口语里很自然。
