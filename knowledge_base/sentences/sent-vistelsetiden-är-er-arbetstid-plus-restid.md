# 🇸🇪 Vistelsetiden är er arbetstid plus restid.

🇨🇳 在园时间是你们的工作时间加通勤时间。

## 结构 (Structure)

```
[Vistelsetiden] [är] [er arbetstid plus restid]
     主语（定式）  系动词        表语
```

## 语法点 (Grammar)

- 📌 [[grammar-bestamd-form]] — 主语 *vistelsetiden* 用定式（前文已提及的概念）；*er arbetstid* 前有所有格 *er*（你们的）所以不加定式后缀。
- 📌 *plus* 直接借用数学"加"，通知里常见；口语也说 *och*。
- 📌 三个 -tid 复合词：vistelse+tid / arbets+tid / res+tid（res- 来自 resa）。
