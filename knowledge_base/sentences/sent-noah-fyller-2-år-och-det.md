# 🇸🇪 Noah fyller 2 år och det vill vi fira med ett litet barnkalas.

🇨🇳 Noah 要满两岁了，我们想办一个小小的儿童生日会来庆祝。

## 结构 (Structure)

```
[Noah] [fyller] [2 år]  och  [det] [vill] [vi] [fira] [med ett litet barnkalas]
 主语   动词   宾语        宾语前置 助动词 主语 不定式  方式状语
                            ↑ 宾语 det 放句首 → 主语 vi 移到动词后（V2）
```

## 语法点 (Grammar)

- 📌 [[grammar-presens-for-framtid]] — `fyller`（presens）表示即将到来的生日；瑞典语不用将来时。
- 📌 [[grammar-inversion-efter-fundament]] — 第二个分句以宾语 `det` 开头，动词 `vill` 保持第二位，主语 `vi` 倒装到动词后。
- 📌 [[grammar-modalt-hjalpverb-infinitiv]] — `vill fira`：情态助动词 + 不带 att 的不定式。
- 📌 `ett litet barnkalas`：ett-词 → 形容词 liten 变 litet。
