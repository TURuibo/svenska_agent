# 🇸🇪 Efter samlingen är det utevistelse på gården, varje dag oavsett väder.

🇨🇳 晨会之后是在园子里的户外活动时间，每天都有，无论天气如何。

## 结构 (Structure)

```
[Efter samlingen] [är] [det] [utevistelse] [på gården], [varje dag] [oavsett väder]
 时间状语(定形)     动词  形式主语 表语         地点          频率       让步
```

## 语法点 (Grammar)

- 📌 [[grammar-opersonligt-det]] — **det är + 活动** = "接下来是……"（老师说日程的固定句型：det är sovvila / mellanmål）。
- 📌 [[grammar-bestämd-form]] — efter samling**en**、på gård**en**：介词后定形。
- 📌 [[grammar-v2-ordfoljd]] — 状语句首 → är det。
- 📌 varje dag（每天）无冠词；oavsett väder 见词组。
