# 🇸🇪 Ekonomiskt bistånd kan vara två typer av stöd: försörjningsstöd och stöd för andra levnadskostnader.

🇨🇳 经济补助可以是两种补助：生活费补助和其他生活开支补助。

## 结构 (Structure)

```
[Ekonomiskt bistånd] [kan vara] [två typer av stöd]: [försörjningsstöd] och [stöd för andra levnadskostnader].
 主语                 助动词+vara  表语                  类型 1               类型 2
```

## 语法点 (Grammar)

- 📌 [[grammar-sammansatt-ord]] — `försörjningsstöd`（försörjning + **s** + stöd）、`levnadskostnader`（levnad + **s** + kostnader）：连接音 `-s-`。
- 📌 [[grammar-modalt-hjalpverb-infinitiv]] — `kan vara`：可能是／可以是。
- 💡 冒号后用 `och` 并列列举两种类型。
