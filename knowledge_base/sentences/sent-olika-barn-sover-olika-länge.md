# 🇸🇪 Olika barn sover olika länge.

🇨🇳 不同的孩子睡的时间长短不一样。

## 结构 (Structure)


## 语法点 (Grammar)

- 📌 **olika 两种词性**：第一个 olika 是形容词（不同的孩子），第二个是副词修饰 länge（"不同程度地久"）。
- 📌 [[grammar-adjektiv-kongruens]] — olika 只有一种形式（复数/不定形），不随 en/ett 变。
- 📌 [[grammar-presens]] — 一般规律用现在时。
- 📌 常见句型 **olika X … olika Y** = "不同的 X 各有不同的 Y"：*Olika barn gillar olika saker.*
