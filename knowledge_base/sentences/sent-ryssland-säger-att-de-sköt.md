# Ryssland säger att de sköt för att varna båten.

🇨🇳 俄罗斯称他们开枪是为了警告这艘船。

## 语法分析 (Grammar)

- `säger att` → [[grammar-att-sats]] — 宾语从句（att引导）
- `att de sköt` — 从句，bisats语序（主语 de 在有限动词 sköt 前）
- `för att varna` → [[grammar-for-att-infinitiv]] — 目的不定式（为了警告）
- `sköt` = preteritum av [[skjuta]]

## 关键词 (Key Words)

- [[skjuta]] — 射击（sköt = 过去时）
- [[varna]] — 警告
- [[båt]] — 船
