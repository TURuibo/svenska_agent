# 🇸🇪 Men experterna varnar för att det kan bli åska och mycket regn.

🇨🇳 但专家警告可能有雷暴和大雨。

## 结构 (Structure)

```
[Men] [experterna] [varnar] [för att det kan bli åska och mycket regn]
 连词     主语         动词            宾语从句（varna för att...）
```

## 语法点 (Grammar)

- 📌 [[grammar-for-att-infinitiv]] — 注意这里 `för att` 引导宾语从句（此处 `att` 引导陈述句），非目的状语。
- 📌 `varna för` + att-sats：固定搭配，`för` 不能省略。
- 📌 `det kan bli` — 情态动词 `kan` + bli，表可能性。
