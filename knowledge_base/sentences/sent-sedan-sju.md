# 🇸🇪 Sedan sju.

🇨🇳 从七点开始。

## 结构 (Structure)

```
[Sedan]  [sju]
  介词     时间数词（省略 klockan）
```

省略句：回答 `Hur länge har ni varit där?`，完整形式为 `Sedan klockan sju.`

## 语法点 (Grammar)

- `sedan` 作介词 = since（自从）；省略 `klockan`（点钟）是口语习惯
- 对比：`sedan` 作副词/连词 = then/after that（然后）
