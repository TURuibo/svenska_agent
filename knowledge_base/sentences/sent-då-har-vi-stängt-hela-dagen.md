# 🇸🇪 Då har vi stängt hela dagen.

🇨🇳 那两天我们全天关门。

## 结构 (Structure)

```
[Då] [har] [vi] [stängt] [hela dagen]
 状语  动词  主语   补语      时间
```

## 语法点 (Grammar)

- 📌 [[grammar-v2-ordfoljd]] — *Då*（那时）占句首 → **har vi** 倒装。
- 📌 [[grammar-bestämd-form]] — *hela dagen*：hela + 定式。
- 📌 *då* 回指上一句的日期（教研日）；不是 *sedan*。
