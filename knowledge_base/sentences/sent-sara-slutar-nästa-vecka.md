# 🇸🇪 Sara slutar nästa vecka.

🇨🇳 Sara 下周离职。

## 结构 (Structure)

```
[Sara] [slutar] [nästa vecka].
 主语   presens   时间(无介词)
```

## 语法点 (Grammar)

- 📌 [[grammar-presens-for-framtid]] — *slutar* 现在时 + 将来时间状语
- 📌 *sluta* 不带宾语 = 离职/辞职；*nästa vecka* 前不加介词（≠ 中文「在下周」）
