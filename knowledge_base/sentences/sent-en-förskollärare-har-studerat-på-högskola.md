# 🇸🇪 En förskollärare har studerat på högskola.

🇨🇳 幼儿园教师在高等学院学习过。

## 结构 (Structure)

```
[En förskollärare] [har studerat] [på högskola]
      主语          perfekt         地点状语
```

## 语法点 (Grammar)

- 📌 [[grammar-perfekt]]
- 📌 perfekt：*har + supinum*（studera → studerat），表示已完成的经历。
- 📌 *på högskola* 无冠词——泛指「上过大学」这种经历（同 *gå i skolan* 但 *studera på universitet*）。
- 📌 *förskollärare* 有学位（3.5 年）；*barnskötare* 是职业高中学历——这是句子隐含的对比。
