# 🇸🇪 Vad är viktigt för att trivas där man bor?

🇨🇳 住的地方什么最重要？

## 结构 (Structure)

```
[Vad] [är] [viktigt] [för att trivas] [där man bor]
 疑问词  系动词  表语      目的状语          关系副词从句
```

## 语法点 (Grammar)

- 📌 [[grammar-for-att-infinitiv]] — **för att + infinitiv** 表达目的（in order to）:
  *för att **trivas*** = 为了感到舒适/为了喜欢待在那里。
  公式：*för att* + 动词原形（infinitiv）= 目的状语。

- 📌 [[grammar-att-sats]] — **där man bor** 是关系副词从句:
  *man* 在这里作泛指主语（= one / you），意为"人们居住的地方"。
  从句词序：*där man bor*（bisats 词序，主语在动词前）。

- 📌 **trivas** — 反身性 s-动词（deponens），意为"感到舒适/快乐"，无被动含义，但形式带 -s。
  参见 [[grammar-deponensverb]]。
