# 🇸🇪 Hon vaknade tidigt i morse, redan vid fem.

🇨🇳 她今天早上醒得早，五点就醒了。

## 结构 (Structure)

```
[Hon]  [vaknade]  [tidigt]  [i morse]  [, redan vid fem]
 主语   preteritum   方式副词   时间副词    补充说明
```

## 语法点 (Grammar)

- 📌 [[grammar-preteritum]] — *vaknade*（v.1 -ade）：讲今早已发生的事
- 📌 [[grammar-tidsadverbial]] — *i morse* = 今早（已过去）；*vid fem* = 五点左右
