# 🇸🇪 Vad kul att se er!

🇨🇳 见到你们真高兴！

## 结构 (Structure)

```
Vad  kul    [att se er]
vad  形容词  att-不定式短语
```

## 语法点 (Grammar)

- 📌 [[grammar-vad-utrop]] — vad + 形容词 的感叹句，省略 det är。
- 📌 [[grammar-infinitiv]] — att se er 不定式补语。

## 生词 & 词组 (Words & Phrases)

- 词: [[kul]]
- 词: [[vad]]
- 词组: [[vad-kul-att-se-er]]

## 用法提示 (Notes)

- 完整形式 *Vad kul det är att se er*，日常一律省略 det är。
- **er** = ni 的宾格（你们）；对一个人说 *Vad kul att se dig*。
