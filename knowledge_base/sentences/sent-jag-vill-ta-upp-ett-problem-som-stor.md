# Jag vill ta upp ett problem som stör mig, och jag tror att fler av er märker det också.

**我想提出一个让我困扰的问题，我想你们中有更多人也注意到了。**

## 语法注解

- `ta upp` — partikelverb（提出；讨论）
- `som stör mig` — 关系从句修饰 `problem`
- `jag tror att fler märker det` — att 引导宾语从句
- `fler av er` — 你们中的更多人

## 关键词

- [[störa]] — 打扰；妨碍
- [[märka]] — 注意到
