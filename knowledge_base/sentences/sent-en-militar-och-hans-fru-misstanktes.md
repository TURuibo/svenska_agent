# 🇸🇪 En militär och hans fru misstänktes för att ha använt hemlig information om Sverige.

🇨🇳 一名军人和他的妻子曾被怀疑使用瑞典的秘密信息。

## 结构 (Structure)

```
En militär och hans fru   misstänktes   för att ha använt hemlig information om Sverige.
主语                        s-被动谓语      för att + 完成时不定式（"曾使用"）
```

## 语法点 (Grammar)

- 📌 [[grammar-s-passiv]] — `misstänktes` 是 `misstänka` 的过去时 s-被动形式。
- 📌 [[grammar-perfekt-infinitiv]] — `för att ha använt` = 完成式不定式，表示"曾经做过"的动作。
