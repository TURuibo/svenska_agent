# 🇸🇪 Därför skriver jag för att fråga om jag får hyra ut lägenheten i andra hand under den tiden.

🇨🇳 因此我写信是想询问，这段时间我是否可以把公寓转租出去。

## 结构 (Structure)

```
Därför  skriver  jag   för att fråga  om  jag får hyra ut lägenheten i andra hand ...
时间/因果状语(V2倒装) 动词 主语  目的从句       间接疑问从句(om)
```

## 语法点 (Grammar)

- 📌 [[grammar-for-att-syfte]] — `för att fråga` = "为了询问"，`för att` + 不定式表目的。
- 📌 [[grammar-bisats-om]] — `om jag får hyra ut...` 是由 `om` 引导的间接疑问从句（是否可以）。
