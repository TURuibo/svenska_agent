# 🇸🇪 Om vi ska klara klimatmålen och stoppa jordens uppvärmning måste vi göra något nu.

🇨🇳 如果我们要实现气候目标并阻止地球变暖，我们现在就必须行动。

## 结构 (Structure)

```
[Om vi ska klara klimatmålen och stoppa jordens uppvärmning] [måste] [vi] [göra något nu]
 ← 条件从句作 fundament (位置1)                              V    S    其余
```

## 语法点 (Grammar)

- 📌 [[grammar-bisats-om]] / [[grammar-konditionalis-med-om]] — `om vi ska …` 条件从句；这里用 `ska`（目标/意图）而非 presens 表示将来的条件。
- 📌 [[grammar-inversion-efter-fundament]] — 从句占据句首，主句动词 `måste` 紧随其后，主语 `vi` 在动词之后（V2 倒装）。
- 📌 [[grammar-modala-hjalpverb]] — `måste` + 不定式 `göra`。
