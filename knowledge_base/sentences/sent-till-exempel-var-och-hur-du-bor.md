# 🇸🇪 Till exempel var och hur du bor.

🇨🇳 例如你住在哪里、怎么住。

## 结构 (Structure)

```
[Till exempel] [var och hur du bor].
 举例短语        并列的疑问词从句（共用主语 + 动词）
                var (du bor) + och + hur du bor
```

## 语法点 (Grammar)

- 📌 [[grammar-indirekt-fraga]] — `var och hur du bor`：两个疑问词 `var`（哪里）和 `hur`（怎样）共用同一个从句 `du bor`；主语在动词前。
- 💡 这是**不完整句**（承接上一句 `Vad som är rimligt beror på olika saker.`），省略了 `Det kan vara …`。
