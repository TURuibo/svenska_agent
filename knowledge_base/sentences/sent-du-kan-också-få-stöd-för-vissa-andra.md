# 🇸🇪 Du kan också få stöd för vissa andra kostnader, till exempel boende, el, hemförsäkring, resor till arbete, fackförening och a-kassa.

🇨🇳 你也可以就某些其他费用获得补助，例如住房、电费、家庭财产保险、上班交通费、工会会费和失业保险基金会费。

## 结构 (Structure)

```
[Du] [kan] [också] [få stöd] [för vissa andra kostnader], [till exempel boende, el, hemförsäkring, resor till arbete, fackförening och a-kassa].
 主语  助动词 语气副词 不定式+宾语  对象（för + 名词短语）          举例清单
```

## 语法点 (Grammar)

- 📌 [[grammar-satsadverbial]] — `också` 在助动词 `kan` 之后（主句里，限定动词后）。
- 📌 [[grammar-sammansatt-ord]] — `hemförsäkring`（hem + försäkring）、`fackförening`（fack + förening）、`a-kassa`。
- 💡 `vissa andra kostnader`：`vissa`（某些）+ `andra`（其他）+ 复数名词。
- 💡 `till exempel` 引出清单，各项之间用逗号，最后一项前用 `och`。
