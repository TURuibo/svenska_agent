# Därför bör lagstiftarna sätta åldersgränser...

🇸🇪 Därför bör lagstiftarna sätta åldersgränser och kräva att plattformarna anpassar sina algoritmer för att minska skadligt innehåll för unga.
🇨🇳 因此，立法者应该设定年龄限制，并要求平台调整算法以减少对年轻人有害的内容。

## 语法分析 (Grammar Notes)

- `Därför bör` — V2 倒装：*därför*（因此）置首 → *bör* 在第二位（[[grammar-v2-ordfoljd]]）
- `bör sätta / bör kräva` — 情态动词 *bör* + infinitiv（[[grammar-bör-modal]]）
- `för att minska` — 目的不定式（[[grammar-for-att-infinitiv]]）
