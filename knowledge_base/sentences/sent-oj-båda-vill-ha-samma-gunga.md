# 🇸🇪 Oj, båda vill ha samma gunga.

🇨🇳 哎呀，两个都想要同一个秋千。

## 结构 (Structure)

```
Oj,  båda  vill    ha    samma gunga.
     主语  情态动词  不定式  宾语
```

## 语法点 (Grammar)

- 📌 [[grammar-modala-hjalpverb]] — vill + 不定式（ha）无 att。

## 生词 & 词组 (Words & Phrases)

- 词: [[oj]]
- 词: [[gunga]]

## 用法提示 (Notes)

- **båda** = 两个都（指两个孩子），可单独作主语。
- **samma** 后接名词不定式（samma gunga，不是 samma gungan）。
- "想要某物" = *vill ha* + 名词，不能只说 *vill gungan*。
