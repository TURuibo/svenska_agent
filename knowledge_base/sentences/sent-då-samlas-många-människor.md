# 🇸🇪 Då samlas många människor för att fira utomhus.

🇨🇳 那时许多人聚在一起在户外庆祝。

```
[Då] [samlas] [många människor] [för att fira] [utomhus]
 时间   动词(V2)     主语              目的状语        地点状语
```

## 语法点 (Grammar)

- 📌 [[grammar-deponensverb]] — `samlas` 是 deponens 动词，-s 结尾但意义主动（聚集）。
- 📌 [[grammar-for-att-infinitiv]] — `för att fira` 表目的：为了庆祝。
- 📌 V2 语序：时间副词 `Då` 置首，动词 `samlas` 紧随（V2 规则）。
