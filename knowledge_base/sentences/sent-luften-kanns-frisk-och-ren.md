# Luften känns frisk och ren.

空气感觉清新而纯净。

## 结构 (Structure)

```
Luften  |  känns  |  frisk och ren
  主语    s-verb动词   形容词表语（中性/复数 ren）
```

## 语法点 (Grammar)

- 📌 [[grammar-reflexivt-verb]] — *känns* 是 *känna* 的 s-形式，意为"感觉……（自身被感知）"
- *frisk* 在这里的语义：清新的（而非"健康的"）——注意多义词！
- *ren*（纯净的）的 en-词形，与主语 *luften*（en-词）一致。

## 生词 & 词组 (Words & Phrases)

- 词: [[luft]]（空气），[[frisk]]（清新的；健康的），[[ren]]（纯净的；干净的）
