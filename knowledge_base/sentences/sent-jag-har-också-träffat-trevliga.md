# Jag har också träffat trevliga grannar.

🇨🇳 我也认识了一些友好的邻居。

## 结构 (Structure)

```
[Jag] [har] [också] [träffat] [trevliga grannar]
 主语  助动词  satsadverbial  主动词(supinum)   宾语（形容词+名词）
       |——— perfekt ——————|
```

## 语法点 (Grammar)

- 📌 [[grammar-perfekt]] — `har träffat` = `har` + supinum `träffat`，表示已发生的动作
- `också` (也) 是 satsadverbial，在 perfekt 结构中位于 `har` 后、supinum 前

## 生词 & 词组 (Words & Phrases)

- 词: [[granne]] (邻居，复数 `grannar`)
- 词: `trevlig` (友好的/可爱的，复数 `trevliga`)
