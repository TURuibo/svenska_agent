# 🇸🇪 Det tar tid att lära sig ett nytt språk och alla gör fel i början.

🇨🇳 学会一门新语言需要时间，每个人一开始都会犯错。

## 结构 (Structure)

```
[Det] [tar tid] [att lära sig ett nytt språk] [och] [alla] [gör fel] [i början]
形式主语  谓语    att不定式（真实主语）            连词   主语    动词    时间副词
```

## 语法点 (Grammar)

- 📌 `Det tar tid att...` — 固定结构，"……需要时间"（形式主语 det）
- 📌 `lära sig` — 反身动词，"学会"（learn [for oneself]）→ [[grammar-reflexivt-verb]]
- 📌 `göra fel` — 犯错（`fel` = 错误）→ [[göra-misstag]]
- 📌 `i början` — 固定时间副词短语，"一开始/起初"
