# 🇸🇪 Mitt förslag är att skatten sänks för företagare som säljer begagnade varor.

🇨🇳 我的建议是，对出售二手商品的企业主降低税收。

## 结构 (Structure)

```
[Mitt förslag] [är] [att-sats: skatten sänks för företagare [som säljer begagnade varor]]
```

## 语法点 (Grammar)

- 📌 [[grammar-s-passiv]] — `skatten sänks` = 税被降低（不说明谁降）；主动形式 `staten sänker skatten`。
- 📌 [[grammar-att-sats]] — `förslaget är att …` 用 att-从句说明建议的内容。
- 📌 [[grammar-relativbisats]] — `företagare som säljer …` 限定哪些企业主。
