# 🇸🇪 ett brutet ben / det brutna benet / brutna ben / de brutna benen

🇨🇳 骨折的腿/骨头（四式变形）

## 结构 (Structure)

```
obestämd sg:  ett  brutet  ben
              art  adj(n)  subst(ett)

bestämd sg:   det  brutna  benet
              art  adj+na  subst+et

obestämd pl:  brutna  ben
              adj+na  subst (pl=sg for ett-ord)

bestämd pl:   de   brutna  benen
              art  adj+na  subst+en
```

## 语法点 (Grammar)

- 📌 [[grammar-adjektivbojning]] — 形容词与 ett-ord 名词的四式变格
  - utrum obestämd: bruten
  - neutrum obestämd: **brutet** (particip adj 的中性形)
  - bestämd/plural: **brutna** (加 -na)
- 过去分词用作形容词（perfekt particip som adjektiv）：bryta → bruten / brutet / brutna

## 生词 & 词组 (Words & Phrases)

- 词: [[bruten]] — 断的；骨折的（bryta 的过去分词）
- 词: [[ben]] — 腿；骨头 ⚠️ 双义词
