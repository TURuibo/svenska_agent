# 🇸🇪 OSA senast onsdag 7 oktober via sms till Jonas: 070-123 45 67.

🇨🇳 请最晚于 10 月 7 日星期三前发短信回复 Jonas：070-123 45 67。

## 结构 (Structure)

```
[OSA] [senast onsdag 7 oktober] [via sms] [till Jonas]: [070-123 45 67]
 请回复  截止日期                   方式      对象         电话号码
```

## 语法点 (Grammar)

- 📌 [[grammar-imperativ-anslag]] — 通知/告示语体：缩写 OSA 起句，无主语无动词。
- 📌 [[grammar-datum-och-tid]] — `senast + 日期` = 最晚……前；日期口语写法可省 den：onsdag 7 oktober。
- 📌 瑞典手机号写法：070-123 45 67（三位-三位 两位 两位）。
