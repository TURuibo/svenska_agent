# 🇸🇪 Vantarna blir ofta blöta, så det är bra med två par.

🇨🇳 手套经常会湿，所以有两双比较好。

## 结构 (Structure)

```
Vantarna  blir  ofta  blöta ,  så   det är bra  med två par
主语(定复) 动词  副词  表语(复)   连词  形式主语+表语  介词短语
```

## 语法点 (Grammar)

- 📌 [[grammar-plural-substantiv]] — 成对衣物用复数 + *par* 计数：*två par*（省略了 vantar）
- 📌 [[grammar-adjektiv-plural-kongruens]] — 复数主语 *vantarna* → 形容词复数 *blöta*
- 📌 [[grammar-sa-att-konsekvens]] — *så*（所以）连接结果句，后面是正常主句语序
- 📌 *det är bra med X* = 有 X 是好的（建议常用句型）
