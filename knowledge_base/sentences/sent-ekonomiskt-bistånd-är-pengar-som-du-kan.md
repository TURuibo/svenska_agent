# 🇸🇪 Ekonomiskt bistånd är pengar som du kan ansöka om hos socialtjänsten.

🇨🇳 经济补助是你可以向社会服务处申请的钱。

## 结构 (Structure)

```
[Ekonomiskt bistånd] [är] [pengar] [som du kan ansöka om] [hos socialtjänsten].
 主语                  动词   表语     关系从句（介词 om 在句末）  机构
```

## 语法点 (Grammar)

- 📌 [[grammar-relativ-bisats-med-som]] — `pengar som du kan ansöka om`：`som` 在从句里作 `ansöka om` 的**宾语**。
- 📌 [[grammar-preposition-i-slutet]] — 介词 `om` 留在从句末尾，不像英语 *which you can apply for* 那样可前置。
- 💡 `ansöka om X hos Y`：`om` 接申请物，`hos` 接机构 → [[ansöka-om]]。
