# 🇸🇪 Ring alltid om ni blir sena vid hämtning!

🇨🇳 接园如果会晚到，请一定打电话给我们！

## 结构 (Structure)

```
[Ring] [alltid] [om ni blir sena vid hämtning]
 祈使   副词          om-条件从句（句尾）
```

## 语法点 (Grammar)

- 📌 [[grammar-imperativ]] — *Ring!* 祈使式（ringa 去 -a）。
- 📌 [[grammar-bisats-om]] — 条件从句在句尾时主句不倒装（对比 [[sent-om-ni-behöver-ändra-schemat-gör]]）。
- 📌 [[grammar-adjektiv-plural-kongruens]] — *ni blir sen**a***：主语 *ni* 复数 → 形容词复数形 *sena*。
- 📌 [[bli-sen]] = 迟到（"变晚"），不是 *vara sen*。
