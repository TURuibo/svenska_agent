# 🇸🇪 Oj, vad modig hon är!

🇨🇳 哇，她真勇敢！

## 结构 (Structure)

```
Oj,  vad  modig   hon   är!
感叹  vad  形容词   主语   动词
(形容词提前，主语+动词殿后)
```

## 语法点 (Grammar)

- 📌 [[grammar-vad-utrop]] — vad + 形容词 + 主语 + 动词：形容词在前，*hon är* 在后。
- 📌 [[grammar-adjektiv-kongruens]] — hon → modig（en-形），不是 modigt。

## 生词 & 词组 (Words & Phrases)

- 词: [[oj]]
- 词: [[modig]]

## 用法提示 (Notes)

- ❌ *Hon är vad modig* — 感叹句必须把 vad + 形容词 放句首。
- 夸别人的孩子时先说 *Oj* 再感叹，是很自然的语气。
