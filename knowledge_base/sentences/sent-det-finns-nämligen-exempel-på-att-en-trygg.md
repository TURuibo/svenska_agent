# 🇸🇪 Det finns nämligen exempel på att en trygg mötesplats ger mindre skadegörelse och bättre stämning i området.

🇨🇳 因为有不少例子表明，一个安全的聚会场所会带来更少的破坏公物现象和更好的社区氛围。

## 结构 (Structure)

```
[Det] [finns] [nämligen] [exempel] [på att [en trygg mötesplats] [ger] [mindre skadegörelse och bättre stämning] [i området]]
 形式主语 动词   副词       真主语     att-从句：主语                  动词   宾语(比较级)                         地点
```

## 语法点 (Grammar)

- 📌 [[grammar-satsadverbial]] — `nämligen` 是副词，放在**定式动词 `finns` 之后**，不能放句首。它交代**上一句主张的理由**（"因为有不少例子……"）。
- 📌 [[grammar-det-finns]] — `det finns + 名词` = 存在句。
- 📌 [[grammar-komparativ]] — `mindre`（less，`lite` 的比较级）、`bättre`（better，`bra` 的比较级）。
- `exempel på att + 从句` = "……的例子（表明……）"。
