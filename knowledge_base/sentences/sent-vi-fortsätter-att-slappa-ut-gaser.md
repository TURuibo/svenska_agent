# 🇸🇪 Vi fortsätter att släppa ut gaser som påverkar klimatet.

🇨🇳 我们持续排放影响气候的气体。

## 结构 (Structure)

```
[Vi]  [fortsätter att släppa ut]  [gaser]  [som påverkar klimatet]
 主语      谓语（动词 + 不定式）       宾语          关系从句
```

## 语法点 (Grammar)

- 📌 [[grammar-relativ-bisats-med-som]] — `som påverkar klimatet` 修饰 *gaser*
- `fortsätta att + infinitiv` — 继续做某事（固定结构，`att` 不可省略）

## 生词 & 词组 (Words & Phrases)

- 词: klimat（气候）
- 短语 `släppa ut` = 排放（partikelverb）
