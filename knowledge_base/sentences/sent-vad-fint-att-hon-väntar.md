# 🇸🇪 Vad fint att hon väntar.

🇨🇳 她愿意等，真好。

## 结构 (Structure)

```
Vad  fint   [att hon väntar].
vad  形容词  att-从句(主语+动词)
```

## 语法点 (Grammar)

- 📌 [[grammar-vad-utrop]] — vad + 形容词（ett-形 fint，因为评价的是"这件事"）。
- 📌 [[grammar-att-bisats]] — att 从句说明"好"的内容。

## 生词 & 词组 (Words & Phrases)

- 词: [[fin]]
- 词: [[vänta]]

## 用法提示 (Notes)

- 夸别人孩子的行为用 *Vad fint att …* / *Vad bra att …*，非常瑞典式的礼貌。
- 形容词用 **fint**（ett-形）而不是 fin，因为主语是抽象的"事情"。
