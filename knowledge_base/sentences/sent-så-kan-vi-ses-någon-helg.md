# 🇸🇪 Så kan vi ses någon helg igen.

🇨🇳 这样我们可以再找个周末见。

## 结构 (Structure)

```
Så   kan   vi   ses      någon helg   igen.
结果  情态   主语  -s动词    时间(不定)   再次
(så 句首 → 倒装)
```

## 语法点 (Grammar)

- 📌 [[grammar-sa-att-konsekvens]] — 句首 **så** = "这样一来"，承接上一句。
- 📌 [[grammar-v2-ordfoljd]] — så 占首位 → kan 第二位 → vi 后置。
- 📌 [[grammar-s-verb-reciprok]] — ses = 互相见面。

## 生词 & 词组 (Words & Phrases)

- 词: [[ses]]
- 词: [[helg]]

## 用法提示 (Notes)

- **någon helg** = 某个周末（不确定哪个）；*i helgen* 则是"这个周末"。
