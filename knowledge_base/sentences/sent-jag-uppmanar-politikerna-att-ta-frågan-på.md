# 🇸🇪 Jag uppmanar politikerna att ta frågan på allvar innan nästa budgetmöte.

🇨🇳 我呼吁政治家们在下一次预算会议之前认真对待这个问题。

## 结构 (Structure)

```
[Jag] [uppmanar] [politikerna] [att ta frågan på allvar] [innan nästa budgetmöte]
 主语   动词       宾语(人)       att + 动词原形短语          时间状语
```

## 语法点 (Grammar)

- 📌 [[grammar-infinitivkonstruktion]] — `uppmana + 人 + att + 动词原形`：`att` 后面**没有主语**，动作的执行者就是前面的宾语 `politikerna`。
- `innan nästa budgetmöte`：这里 `innan` 当**介词**用（"在……之前" + 名词），不引导从句。
- 论说文的**收尾呼吁**：`Jag uppmanar … att …`，见 [[grammar-insandare-styckelogik]]。
