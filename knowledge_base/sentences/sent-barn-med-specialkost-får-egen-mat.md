# 🇸🇪 Barn med specialkost får egen mat.

🇨🇳 有特殊饮食的孩子吃单独准备的饭。

## 结构 (Structure)

```
[Barn med specialkost] [får] [egen mat]
 主语(泛指,不定形复数)   动词   宾语
```

## 语法点 (Grammar)

- 📌 [[grammar-obestämd-form]] — **barn**（泛指"凡是……的孩子"）用不定形复数（barn 单复同形）。
- 📌 **med + 名词** 作后置定语："有特殊饮食的"。
- 📌 [[grammar-adjektiv-kongruens]] — egen mat（en-词）/ eget bröd / egna tallrikar。
- 📌 få 这里 = 得到（不是"允许"）。
