# 🇸🇪 Tack för ett bra samtal, Anna!

```
[Tack] [för] [ett bra samtal], Anna!
 谢谢   介词  ett-词+形容词+名词
```

- 📌 [[grammar-en-ord-ett-ord]] — *samtal* 是 ett-词 → *ett bra samtal*

- 词组: [[tack-för-ett-bra-samtal]]
