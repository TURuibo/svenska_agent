# 🇸🇪 Men alla har inte plats hemma, och på ett café i centrum kostar det pengar att sitta.

🇨🇳 但并不是每个人家里都有地方，而且在市中心的咖啡馆里坐着是要花钱的。

## 结构 (Structure)

```
Men [alla] [har] [inte] [plats hemma], och [på ett café i centrum] [kostar] [det] [pengar att sitta].
    主语    动词  否定    宾语+地点          fundament(地点)           动词   形式主语 宾语 + 真主语(att-不定式)
```

## 语法点 (Grammar)

- 📌 [[grammar-inversion-efter-fundament]] — 第二个分句以地点状语 `på ett café i centrum` 开头 → `kostar det`（动词先于主语）。
- 📌 [[grammar-opersonligt-det]] — `det kostar pengar att sitta`：`det` 是形式主语，真正的主语是后面的 `att sitta`（"坐着要花钱"）。
- `Men` 和 `och` 是并列连词，不占 fundament。
- `alla har inte` = "并非所有人都有"（部分否定）。
