# 🇸🇪 Då måste du ändra schemat i e-tjänsten.

🇨🇳 那你得在电子服务里改在园时间表。

## 结构 (Structure)

```
[Då] [måste] [du] [ändra] [schemat] [i e-tjänsten].
 连接副词 情态动词 主语 不定式 宾语(定式) 地点状语(定式)
```

## 语法点 (Grammar)

- 📌 [[grammar-modalt-hjalpverb-infinitiv]] — *måste ändra*
- 📌 [[grammar-v2-ordfoljd]] — *Då* 占首位 → 动词第二、主语第三
- 📌 [[grammar-bestamd-form]] — *schemat*、*e-tjänsten*：双方都知道的那份表/那个系统 → 定式

## 生词 & 词组 (Words & Phrases)

- 词: [[ändra]], [[schema]], [[e-tjänst]]
- 词组: —

## 用法提示 (Notes)

- 📌 *schema* 是 ett 词：*schemat / scheman / schemana*。园所的 *schema* = 孩子每周的在园时间，改动要在市政 *e-tjänst* 里提交。
