# 超市购物 (Mataffären)

本主题涵盖超市购物场景中的核心词汇与表达：找商品位置、问特价、付款、要购物袋等。

## 文化提示 (Cultural Notes)

- 瑞典超市购物袋（kasse）**收费**，鼓励自带袋子
- 散装水果需顾客**自己称重**（väga vid vågen）并打印价签
- 付款方式：**kort**（银行卡）和 **Swish**（手机支付 APP）极为普遍，现金越来越少见
