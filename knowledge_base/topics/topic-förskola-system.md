# 🗂️ förskola-systemet — 瑞典幼儿园制度（主题场）

类型: thematic

## 成员 (Members)

- [[förskola]] — 幼儿园 (preschool)
- [[erbjudande]] — 名额邀约 (offer/invitation)
- [[placering]] — 名额/安置 (placement)
- [[garantiplacering]] — 保证名额 (guaranteed placement)
- [[byteskö]] — 换位等候队列 (transfer queue)
- [[e-tjänst]] — 电子服务平台 (online service portal)

## 场景说明 (Context)

瑞典幼儿园申请流程关键词汇组。来源：[[source-2026-06-03-sundbyberg-forskola]]

**典型流程：**
1. 家长通过 [[e-tjänst]] 提交意愿名额（`önskade val`）申请 [[förskola]]。
2. 市政府发送 [[erbjudande]] 通知。
3. 若获得非意愿园所的 [[placering]]，即为 [[garantiplacering]]（所有首选均满）。
4. 接受后，孩子仍留在 [[byteskö]] 中等待首选名额空缺。

## 备注 (Notes)

- 可扩充：kö（队列）, ansökan（申请）, kommunen（市政府）, önskemål（愿望/意愿）...
