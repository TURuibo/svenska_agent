# 🗂️ vardagsrutin — 日常生活与日常行为

类型: semantic-field

## 成员 (Members)

### 晨间例行（morgonrutin）
- [[vakna]] — 醒来
- [[stiga]] — 迈步/起来 → [[stiga-upp]] 起床
- [[dricka]] — 喝（咖啡）
- [[äta]] — 吃 → [[frukost]] 早餐
- [[snabbt]] — 快速地
- [[tidigt]] — 早

### 出行（resa）
- [[tunnelbana]] — 地铁 → [[ta-tunnelbanan]] 坐地铁
- [[stan]] — 城里/市中心
- [[centralstation]] — 中央车站 → [[komma-fram]] 到达

### 意外事件（oväntad händelse）
- [[bokhandel]] — 书店 → [[titta]] 看书
- [[plånbok]] — 钱包 → [[borta]] 不见了
- [[märka]] — 发现/注意到
- [[plötsligt]] — 突然
- [[orolig]] — 担心的
- [[tänka]] — 想/思考
- [[tappa]] — 丢失 → [[tappa-bort]] 弄丢

### 应对处理（hantera situationen）
- [[personal]] — 工作人员
- [[vänta]] — 等待
- [[ringa]] — 打电话
- [[bank]] — 银行 → [[spärra]] 冻结 → [[spärra-kort]] 冻结银行卡
- [[kort]] — 卡
- [[polis]] — 警察
- [[anmäla]] — 报案 → [[anmäla-förlusten]] 报告丢失
- [[förlust]] — 损失/丢失
- [[samtal]] — 电话
- [[hitta]] — 找到

### 结尾（avslutning）
- [[andas]] — 呼吸 → [[andas-ut]] 松一口气
- [[äntligen]] — 终于
- [[lägga]] — 放 → [[lägga-sig]] 躺下/睡觉
- [[på-kvällen]] — 在晚上
- [[oväntad]] — 意外的

## 备注 (Notes)

- 本主题词汇来自 A2 叙事范文《En oväntad dag》——一次丢钱包的经历。
- 词汇按事件顺序组织，适合写作时按步骤查阅。
- 相关语法：[[grammar-preteritum]]（叙事用过去时），[[grammar-presens-preteritum-ram]]（叙事框架）。
