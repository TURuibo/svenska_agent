# 📗 Genitiv -s (utan apostrof) — -s 属格（无撇号） (Genitive -s, no apostrophe)

级别: A1
一句话: 瑞典语的所有格只在名词后加 "-s"，**不加撇号**（与英语的 's 不同）。

## 规则说明 (Rules)

📐 结构公式:
```
[Ägare]+s [ägd sak]
kvinnor + s  rättigheter  →  kvinnors rättigheter
```

与中文对比: 中文用"的"（女性的权利），结构是"所有者 + 的 + 被拥有物"，与瑞典语顺序一致（所有者在前）。
与英文对比: 英语用 's（women**'**s rights），**带撇号**；瑞典语用 -s，**不带撇号**（kvinnors rättigheter）——这是中国学习者最容易搬错格式的地方。

## 详细讲解 (Detail)

给名词加 -s 即可表示所属关系，无论该名词是单数还是复数、有生命还是无生命：

```
en kvinna → kvinnans hatt        (一个女人的帽子，单数定形 + s)
kvinnor  → kvinnors rättigheter   (复数不定形 kvinnor + s，无需先变定形)
Elins bok                         (专有名词 + s)
```

若名词本身已以 -s/-x/-z 等结尾，则通常只加撇号而不再加 -s（如 Andreas' bok），但这种情况较少见，本页不展开。

## 例句 (Examples)

- ✅ [[sent-hur-kämpade-elin-för-kvinnors]] 🇸🇪 Hur kämpade Elin för kvinnors rättigheter? 🇨🇳 埃林是如何为女性权利而斗争的？
- ❌ kvinnor's rättigheter ← 常见错误：搬用英语撇号写法，瑞典语中没有撇号

## 常见错误 (Common Mistakes)

- ⚠️ 加了英语式撇号：kvinnor's（错）→ kvinnors（对）。
- ⚠️ 忘记加 -s：kvinnor rättigheter（错，缺少所有格标记）→ kvinnors rättigheter（对）。
