# ända till — 极限副词 + 介词

## 核心用法

`ända till` 强调延伸或持续到某个极限时间/地点，隐含"甚至到那么晚/远"的语气。

```
ända till + tidsuttryck / plats
```

| 搭配 | 翻译 | 隐含语气 |
|------|------|----------|
| `ända till klockan 02` | 一直到凌晨2点 | 甚至那么晚 |
| `ända till Sverige` | 一直到瑞典 | 甚至那么远 |
| `ända till sist` | 一直到最后 | 坚持到底 |
| `ända tills` | 一直到……（时间点） | 持续至 |

## `ända` 的语法角色

- `ända` 本身是加强副词（intensifierande adverb），不单独成句
- 常见搭配：`ända till`（时间/空间）、`ända tills`（直到）、`ända ut`（一直到头）
- 与 `till` 区别：`till klockan 02` = 到2点（中性）；`ända till klockan 02` = 甚至到凌晨2点（强调）

## 例句

- Musiken hörs ända till klockan två på natten. — 音乐声一直响到凌晨两点。
- Hon gick ända till stationen utan att ta buss. — 她一路步行到火车站，没坐公共汽车。
- Vi väntade ända tills det slutade regna. — 我们一直等到雨停了。
