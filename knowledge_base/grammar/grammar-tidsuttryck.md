# tidsuttryck — 时间表达

| 表达 | 含义 | 规则 |
|---|---|---|
| i lördags | 上周六 | i + 星期名 + -s = 刚过去的那天 |
| på söndagen | 在周日 | 星期用 på |
| på eftermiddagen | 在下午 | 一天中的时段用 på |
| klockan fem | 五点钟 | klockan + 数字，见 [[grammar-klockan-tidsuttryck]] |
| i helgen | 这个/上个周末 | i + helg |
