# 📗 så … som möjligt — 尽可能……结构 (as … as possible)

级别: SFI B / CEFR A2-B1
一句话: `så + 形容词/副词(原级) + som möjligt` 表示"尽可能……"。

## 规则说明 (Rules)

📐 结构公式:
```
så + ADJ/ADV (原级) + som möjligt
Jag vill göra kungen så sann som möjligt.
我 想  把国王演得  如此真实 尽可能
```

与中文对比: 中文"尽可能 + 形容词"，瑞典语把形容词夹在 så 和 som möjligt 之间。
与英文对比: 完全对应 as … as possible。

## 详细讲解 (Detail)

- 形容词要与被修饰名词一致：kungen（en-词）→ sann；ett-词用 sant。
- 副词形式不变：så snabbt som möjligt。
- 同义变体：så … som det går；固定搭配 [[så-fort-som-möjligt]]、[[så-snart-som-möjligt]]。

## 例句 (Examples)

- ✅ [[sent-jag-vill-göra-kungen]] 🇸🇪 Jag vill göra kungen så sann som möjligt. 🇨🇳 我想把国王演得尽可能真实。
- ✅ Kom så snart som möjligt. 🇨🇳 请尽快来。
- ❌ Jag vill göra kungen så sann som möjlig. ← möjligt 固定不变

## 常见错误 (Common Mistakes)

- ⚠️ möjligt 不随性数变化，始终用 -t 形式。
