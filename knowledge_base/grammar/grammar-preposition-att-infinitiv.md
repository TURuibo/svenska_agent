# 📗 Preposition + att + infinitiv — 介词后接 att + 不定式

级别: SFI B / CEFR A2–B1
一句话: 瑞典语中介词后不能直接接动词，必须用 **att + 不定式**（中文/英文 -ing 的位置）。

## 规则说明 (Rules)

📐 结构公式:
```
名词/动词/形容词 + 介词 + att + 不定式
motivation  till  att  träna
börja       med   att  planera
tänka       på    att  äta
```

与中文对比: 中文直接动词接动词；瑞典语多一个 att。
与英文对比: 英文用 -ing（start by planning），瑞典语用 att + inf。

## 详细讲解 (Detail)

| 搭配 | 例 |
|---|---|
| motivation till att | motivation till att träna |
| börja med att | Börja med att planera → [[börja-med-att]] |
| tack för att | Tack för att du kom → [[tack-för-att]] |
| tänka på att | Tänk på att ta med pass |
| för att (目的) | → [[grammar-for-att-infinitiv]] |
| genom att / i stället för att | → [[grammar-genom-att-infinitiv]], [[grammar-istallet-for-att-infinitiv]] |

- 注意区分：`ha svårt att + inf`（att 直接接形容词/名词，无介词）→ [[ha-svårt-att]]。

## 例句 (Examples)

- ✅ [[sent-du-känner-ju-mig-och-vet-att-jag-har]] … motivation till att träna.
- ✅ [[sent-börja-med-att-planera-svaret-med-hjälp-av]] Börja med att planera svaret …
- ❌ Jag har motivation till träna. ← 缺少 att

## 常见错误 (Common Mistakes)

- ⚠️ 介词后直接接不定式（漏 att）。
- ⚠️ 忘记 till 或用错介词（motivation *för/av*）。
