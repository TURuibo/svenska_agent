# 📗 Om X råkar + infinitiv — 条件句 + råka（不小心做某事）

级别: B1
一句话: "råka + infinitiv" 表示意外/不小心做了某事；配合 "om" 构成"如果不小心……"的条件句

## 规则说明 (Rules)

📐 结构公式:
```
Om [主语] råkar + infinitiv, [主句]
如果……不小心……，那么……
```

与中文对比: 相当于"如果不小心……"或"万一……"
与英文对比: "If X happens to + verb" / "If X accidentally + verb"

## 详细讲解 (Detail)

**råka + infinitiv** 是一个固定结构，表示某事是意外发生的、无意中做了某事：

| 表达 | 含义 |
|------|------|
| råka svälja | 不小心吞了 |
| råka tappa | 不小心掉了 |
| råka stöta ihop med | 碰巧遇到了 |
| råka göra fel | 不小心做错了 |

**配合 om（条件句）:**
- "om du råkar..." = "if you happen to..." / "if you accidentally..."
- 主句可以是推断/警告：kan du bli sjuk（你可能会生病）

**时态变化:**
- Presens: råkar + infinitiv
- Preteritum: råkade + infinitiv
- Perfekt: har råkat + infinitiv

## 例句 (Examples)

- ✅ [[sent-om-du-rakar-svalja-vatten]] 🇸🇪 Om du råkar svälja vatten kan du bli sjuk. 🇨🇳 如果不小心吞入水，可能会生病。
- ✅ 🇸🇪 Om du råkar tappa telefonen, kontakta butiken direkt. 🇨🇳 如果你不小心摔了手机，请立即联系商店。
- ✅ 🇸🇪 Han råkade stöta ihop med sin gamla lärare. 🇨🇳 他碰巧遇到了以前的老师。
- ❌ Han råkade för att tappa nyckeln. ← 错：råka 后直接跟 infinitiv，不加 för att

## 常见错误 (Common Mistakes)

- ⚠️ 不要在 råka 后面加 "för att"：råka svälja ✓ / råka för att svälja ✗
- ⚠️ råka 本身无被动形式；被动语境用其他说法
