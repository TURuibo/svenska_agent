# Modala hjälpverb — 情态助动词 (Modal auxiliary verbs)

级别: A2–B1
一句话: 情态助动词在瑞典语中后接**不带 att 的不定式**，表达能力、意愿、义务、可能性等。

## 规则说明 (Rules)

📐 结构公式:
```
主语 + 情态助动词（presens/preteritum）+ 动词不定式（原形）
Hon  kan              inte tåla             laktos.
Hon  skulle           vilja betala          notan.
```

与中文对比: 中文助动词也前置于动词（"能/想/要/应该"），结构相近。
与英文对比: 英文 "can/will/would/should + V" 结构相同；瑞典语同样不加 "to"（att）。

## 核心情态助动词 (Core modals)

| 动词 | Presens | Preteritum | 基本含义 |
|------|---------|------------|----------|
| kunna | kan | kunde | 能够（能力/可能）|
| vilja | vill | ville | 想要（意愿）|
| ska (skola) | ska | skulle | 将要；应该（意图/义务）|
| måste | måste | var tvungen att | 必须（强制义务）|
| böra | bör | borde | 应当（建议/道义）|
| få | får | fick | 被允许（许可）|

## 详细讲解 (Detail)

### 礼貌用法：*skulle vilja*

*skulle vilja* 是 *vill*（想要）的条件语气形式，语气更礼貌、更委婉：

```
Jag vill ha vatten.        → 我要水。（直接，稍微生硬）
Jag skulle vilja ha vatten. → 我想要水。（有礼貌，餐厅/正式场合首选）
```

→ 例句: [[sent-skulle-vi-vilja-betala-dela-på-notan]]

### *kan* — 询问许可或能力

```
Kan vi dela på notan?  → 我们能分开付账吗？（询问许可）
Vad kan ni rekommendera? → 你们有什么推荐？（能力/提供）
```

### *ska* — 意图/将来

```
Ska man lägga till dricks? → 需要加小费吗？
```

### *vill* — 意愿

```
Vill ni betala med kort eller Swish? → 你们想用卡还是 Swish 付？
```

## 例句 (Examples)

- ✅ [[sent-skulle-vi-vilja-betala-dela-på-notan]] 🇸🇪 Sen skulle vi vilja betala — kan vi dela på notan? 🇨🇳 然后我们想买单——可以分开付吗？
- ✅ [[sent-jag-är-allergisk-mot-nötter-vad-kan-ni]] 🇸🇪 Vad kan ni rekommendera? 🇨🇳 你们有什么推荐？
- ✅ [[sent-vill-ni-betala-med-kort-eller-swish]] 🇸🇪 Vill ni betala med kort eller Swish? 🇨🇳 你们想用卡还是 Swish 付？
- ❌ *Hon skulle vilja att betala.* ← 错误：情态动词后不加 att

## 常见错误 (Common Mistakes)

- ⚠️ 勿在情态动词后加 *att*：*kan att göra* ✗ → *kan göra* ✓
- ⚠️ *måste* 的 preteritum 不是 *måstade*，而是 *var tvungen att*
- ⚠️ *skulle vilja* 中，*skulle* 本身是 *ska* 的 preteritum，但这里是条件/礼貌用法，不表示过去
