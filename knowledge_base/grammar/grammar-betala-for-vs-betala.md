# betala för vs betala — 介词用法辨析

## 核心区别

| 构型 | 含义 | 示例 |
|------|------|------|
| `betala + 直接宾语` | 付……的钱（价格） | `betala hundra kronor` = 付100克朗 |
| `betala för + 宾语` | 为……付钱（对象） | `betala för kaffet` = 为咖啡付钱 |
| `betala + 人/机构` | 向……付款 | `betala kassan` = 在收银台付款 |

## 详解

**① `betala` + 直接宾语（金额/款项）**
```
Jag betalade tio kronor.  → 我付了10克朗。
Vi betalade notan.        → 我们付了账单。
```

**② `betala för` + 被付款的物品/事情**
```
Han betalade för kaffet.     → 他为咖啡付了钱。（kaffet 是付款对象，非金额）
Vem betalar för middagen?    → 谁付晚餐的钱？
```

**③ `betala` + 对象（向谁付）**
```
Betala i kassan.         → 在收银台付款。
Betala till leverantören.→ 向供应商付款。
```

## 陷阱提示

- ❌ `Jag betalade kaffet` — 错误（没有 `för`，意思变成"我付了咖啡"这件事本身，不自然）
- ✅ `Jag betalade för kaffet` — 正确
- ✅ `Jag betalade kaffepriset` — 正确（直接宾语是价格）
