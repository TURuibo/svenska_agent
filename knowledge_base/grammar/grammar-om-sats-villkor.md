# 📗 om-sats (villkor) — om 引导条件从句 (conditional om-clause)

级别: SFI C / CEFR B1
一句话: `om` 引导一个条件从句，说明主句成立的前提条件，可放句首或句中。

## 规则说明 (Rules)

📐 结构公式:
```
Om + [条件, 从句语序 (bisats-ordföljd)], + huvudsats (V2)
```

与中文对比: 相当于中文"如果……（的话），就……"，语序结构类似。
与英文对比: 相当于英语 "If ..., then ..."，从句内部动词位置不同（瑞典语从句中否定词/时间副词位于动词之前）。

## 详细讲解 (Detail)

- `om` 从句属于副词性从句（adverbiell bisats），内部遵循从句语序（bisats-ordföljd）：主语 + 副词/否定词 + 动词。
- 若 `om`-从句放在句首，主句需遵循 V2 语序，动词紧跟在逗号之后。
- 与"是否"义的 `om`（如 `undrar om`，宾语从句）不同，这里的 `om` 表示条件（"如果"），常可与 `ifall` 互换。

## 例句 (Examples)

- ✅ 🇸🇪 Om Nils skulle nå toppen behövde han träna mer. 🇨🇳 如果 Nils 想要登顶，他需要练得更多。
- ✅ 🇸🇪 Om det regnar imorgon stannar vi hemma. 🇨🇳 如果明天下雨，我们就待在家。
- ❌ Om det regnar imorgon, vi stannar hemma. ← 常见错误：漏掉主句 V2 倒装（应为 stannar vi）

## 常见错误 (Common Mistakes)

- ⚠️ 主句忘记倒装：`om`-从句在前时，主句动词必须紧跟逗号，不能保持"主语+动词"顺序。
- ⚠️ 与表示"是否"的宾语从句 `om`（如 `jag vet inte om han kommer`）混淆——那是名词性从句，不表条件。
