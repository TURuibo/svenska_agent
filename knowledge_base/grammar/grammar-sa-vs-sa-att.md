# 📗 så vs så att — 所以 vs 以便/以至于

级别: A2–B1
一句话: **så** 后面接**主句**（所以……）；**så att** 后面接**从句 bisats**（以便…… / 结果……）。判断方法：看 `inte` 放在动词前面还是后面。

## 规则说明 (Rules)

### 三种「så」+ 一种 så … att

| | 词性 | 意思 | 后面的语序 | 例句 |
|---|---|---|---|---|
| ① **så** | 并列连词 (konjunktion) | 所以 | 主句：S + V + **inte** | Det regnade, **så** vi stannade **inte** ute. |
| ② **så att** | 从属连词 (subjunktion) | 以便（目的）/ 使得（结果） | 从句：S + **inte** + V | Jag går tidigt **så att** jag **inte** missar bussen. |
| ③ **så** | 副词 (= då) | 那么、然后 | 占句首位置 → **V + S** 倒装 | Om det regnar, **så stannar vi** hemma. |
| ④ **så** + adj … **att** | 程度结构 | 如此……以至于 | att 后是从句 | Det var **så** kallt **att** vi stannade inne. |

📐 结构公式:
```
① A-句 , så  + S + V (+ inte) …            所以
② A-句   så att + S (+ inte) + V …         以便 / 使得
③ (Om-从句 / Först …) , så + V + S …      那么 / 然后
④ … så + adj/adv + att + S (+ inte) + V   如此……以至于
```

### 判断口诀

```
看到 så ─┬─ 后面紧跟 att？ ──是──▶ ② 从句：inte 在动词前
         │                         （或 ④：så 和 att 中间夹着形容词）
         └─ 否 ─┬─ 后面是 V + S（动词先）？ ──▶ ③ 副词 så = då
                └─ 后面是 S + V（主语先）？ ──▶ ① 连词 så = 所以
```

## 中英对比 (Contrast)

| 瑞典语 | 中文 | English |
|---|---|---|
| så (konj) | 所以 | so (= therefore) |
| så att | 以便 / 以至于 | so that |
| så (adv) | 那么、然后 | then |
| så … att | 如此……以至于 | so … that |

⚠️ 英语 *so* 两种都能说（*I was tired, so I slept* / *Speak louder so I can hear*），瑞典语把它们分开：前者 `så`，后者书面上用 `så att`。

## 详细讲解 (Detail)

- **意义上的区别**：
  - `så` = 先给原因，再说**结论/结果**：Bussen var sen, så jag tog en taxi.（公交晚了，所以我打了车。）
  - `så att` 常表示**目的**（多和 `ska / kan` 连用）：Jag tar en taxi så att jag hinner.（我打车，好赶得上。）
  - `så att` 也可以表示**结果**：Det snöade mycket, så att vägarna stängdes.（下了大雪，以致道路关闭。）
- **`inte` 的位置是最可靠的测试**：
  - Jag var sjuk, **så** jag kom **inte**.（主句：inte 在动词后）
  - Jag ringde, **så att** du **inte** skulle oroa dig.（从句：inte 在动词前）→ [[grammar-bisats-ordfoljd|📗从句语序]]
- **口语里** 常把 `så att` 说成 `så`：*Prata högre så jag hör.*（大声点，让我听得见）。看语序：若是从句语序或明显是目的，它实际上就是 `så att`。写作时建议写全 `så att`。
- **③ 副词 så 引起倒装**：它占了句首位置，所以动词必须第二位 → [[grammar-inversion-efter-fundament|📗句首成分后倒装]]。常见于 `Om …, så …` 和 `Först …, så …`。
- **Gotland 课文里的 så**：*Ön har ingen broförbindelse **så** för att ta sig dit **tar man** flyg eller båt.* —— 这是 ① 连词「所以」。它本身不占句首；后面的新主句以 `för att ta sig dit` 开头，所以才有 `tar man` 倒装。不是 ③。
- 和 `för att` 的区别：`för att` + **不定式**（主语相同）→ [[grammar-for-att-syfte|📗för att 表目的]]；`så att` + **完整从句**（可换主语）。
  - Jag skriver upp det **för att** komma ihåg.（我记下来，为了记住）
  - Jag skriver upp det **så att** du kommer ihåg.（我记下来，好让你记住）

## 例句 (Examples)

- 🇸🇪 Ön har ingen broförbindelse så för att ta sig dit tar man flyg eller båt. — 🇨🇳 岛没有桥，所以要去那里得坐飞机或船。（① 所以）
- 🇸🇪 Det regnade, så vi stannade hemma. — 🇨🇳 下雨了，所以我们待在家里。（①）
- 🇸🇪 Kommunerna bygger nya cykelbanor så att det ska bli säkrare i trafiken. — 🇨🇳 市政当局修新的自行车道，好让交通更安全。（② 目的）
- 🇸🇪 Jag går tidigt så att jag inte missar bussen. — 🇨🇳 我早点出门，免得错过公交。（② 目的，inte 在动词前）
- 🇸🇪 Om du är hungrig, så finns det mat i kylen. — 🇨🇳 你要是饿了，冰箱里有吃的。（③ 那么）
- 🇸🇪 Det var så kallt att vi stannade inne. — 🇨🇳 太冷了，我们就待在室内。（④ 如此……以至于）

## 常见错误 (Common Mistakes)

- ❌ Jag var sjuk, så att jag kom inte. → ✅ Jag var sjuk, **så** jag kom inte.（单纯"所以"用 så；用了 så att 就必须 *så att jag inte kom*）
- ❌ Jag går tidigt så att jag missar inte bussen. → ✅ … så att jag **inte missar** bussen.（从句里 inte 在动词前）
- ❌ Om det regnar, så vi stannar hemma. → ✅ Om det regnar, så **stannar vi** hemma.（副词 så 后倒装）
- ❌ Det var så kallt vi stannade inne.（书面）→ ✅ Det var så kallt **att** vi stannade inne.
