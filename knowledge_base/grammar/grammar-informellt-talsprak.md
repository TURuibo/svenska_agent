# 📗 Informellt talspråk — 非正式口语标记 (Informal language markers)

级别: SFI B / A2–B1
一句话: 写给朋友的信里可以用口语形式（plugga、nån、nåt、sen、kolla）、强化前缀和表情符号。

## 规则说明 (Rules)

📐 对照:
```
正式/中性        →  非正式/口语
studera, läsa    →  plugga
någon / något    →  nån / nåt
sedan            →  sen
titta / se       →  kolla
mycket trevlig   →  supertrevlig
mycket bra       →  toppen-
kommer att + inf →  kommer + inf  (att 省略)
```

与中文对比: 类似书面语 vs 口语（"学习"vs"啃书"）。
与英文对比: 像 gonna/wanna、cram、super-nice。

## 详细讲解 (Detail)

| 正式 | 非正式 | 例子 |
|------|--------|------|
| studera | [[plugga]] | När jag ska plugga … |
| någon | [[nån]] | i nån timme |
| något | [[nåt]] | på nåt kafé |
| sedan | [[sen]] | och sen ta en fika |
| titta på | [[kolla]] | Då kollar jag mest mobilen |
| mycket trevlig | [[supertrevlig]] | supertrevliga människor |
| mycket bra betyg | [[toppenbetyg]] | toppenbetyg |
| kommer att få | kommer få | Du kommer få så kul! |
| （书面无） | 😊 | emoji 表情 |

- **省略 att**：`kommer att + 不定式` → 口语常 `kommer + 不定式`（见 [[grammar-kommer-att-infinitiv]]）。教材范例 "Du kommer få så kul!"、"Du kommer gå ut gymnasiet…"。但原文里 "Jag vet att du kommer att klara det!" 保留 att——两者并存。
- **强化前缀** super-、toppen- 加强语气。
- 形容词 [[informell]]、[[talspråklig]] 是教材对这类词的描述。

## 例句 (Examples)

- ✅ [[sent-när-jag-ska-plugga-brukar-jag]] 🇸🇪 … sätta mig … på nåt kafé. 🇨🇳 …找家咖啡馆坐下。
- ✅ [[sent-jag-vet-att-du-kommer-gå-ut-gymnasiet]] 🇸🇪 … kommer gå ut gymnasiet … 🇨🇳 att 省略。
- ❌ 正式信/申请中不要用：*Jag pluggar nåt.*

## 常见错误 (Common Mistakes)

- ⚠️ 在正式信（[[grammar-formellt-brev]]、[[grammar-formellt-mejl]]）里别用 nån/nåt/plugga。
- ⚠️ nån/nåt 只是书写缩略，读音与 någon/något 相近。
