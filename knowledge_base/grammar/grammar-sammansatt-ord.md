# 📗 sammansatt ord — 复合词 (compound word)

级别: A1
一句话: 瑞典语将两个或多个词拼合成一个词，整体意义由末尾词决定，书写为一个单词（不分开写）。

## 规则说明 (Rules)

📐 结构公式:
```
(förled1 +) förled2 + huvudled = sammansatt ord
bad        + strand             = badstrand
soffan     + bord               = soffbord
arbets     + rum                = arbetsrum
```

**关键规则：**
1. 最后一个词（huvudled）决定词性和变形。
2. 多个词拼合时书写为一个单词——不可分开（区别于英语/中文）。
3. 有时两词之间加连接字母 `s`（s-fogen）：arbetsrum（不是 arbetrum）。

与中文对比: 中文也有合成词（工作室），但不加变化；瑞典语复合词按末尾词词性变形。
与英文对比: 英语有时用空格（ice cream）或连字符（ice-cream）；瑞典语总是写成一个词。

## 详细讲解 (Detail)

**词性由 huvudled 决定：**
- en badstrand → badstranden（en-genus）
- ett soffbord → soffbordet（ett-genus）

**常见合成模式：**
- bad + byxor → badbyxor（游泳裤）
- fåtölj + …（椅）：fåtöljsarm 等
- s-foge 示例：arbete + rum → **arbetsrum**, dagis + plats → **dagisplats**

## 例句 (Examples)

- ✅ Vi köpte ett **soffbord** till vardagsrummet. — 🇨🇳 我们给客厅买了一张茶几。
- ✅ Var kan jag hitta **badbyxor**? — 🇨🇳 我在哪里能找到游泳裤？
- ✅ [[sent-ekonomiskt-bistånd-kan-vara-två-typer-av]] 🇸🇪 Ekonomiskt bistånd kan vara två typer av stöd: försörjningsstöd och stöd för andra levnadskostnader. 🇨🇳 经济补助可以是两种补助：生活费补助和其他生活开支补助。（`försörjning` + **s** + `stöd`；`levnad` + **s** + `kostnader`：连接音 -s-）
- ✅ [[sent-du-kan-också-hitta-en-budget-och]] 🇸🇪 Du kan också hitta en budget- och skuldrådgivare via Konsumentverket. 🇨🇳 你也可以通过消费者事务局找到预算与债务顾问。（**省略式复合词**：`budget-` 代替 `budgetrådgivare`）
- ✅ [[sent-reglerna-om-ekonomiskt-bistånd-finns-i]] 🇸🇪 Reglerna om ekonomiskt bistånd finns i socialtjänstlagen. 🇨🇳 关于经济补助的规定写在《社会服务法》里。（`social` + `tjänst` + `lag`：三段式长复合词）
- ✅ [[sent-försörjningsstöd-är-pengar-för-dina-vanliga]] 🇸🇪 Försörjningsstöd är pengar för dina vanliga utgifter varje månad. 🇨🇳 生活费补助是用于你每个月日常开支的钱。
- ❌ Vi köpte ett soffa bord. ← 瑞典语不分开写

## 常见错误 (Common Mistakes)

- ⚠️ 最常见错误：分开写复合词（särsrivningsfel）— 如写 "bad strand" 而非 "badstrand"。
- ⚠️ 忘记 s-fogen：写 "arbete rum" 而非 "arbetsrum"。
