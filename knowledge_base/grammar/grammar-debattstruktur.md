# grammar-debattstruktur — 辩论文结构

📐 中文：辩论文（debattinlägg）四段式结构 · English: debate text structure

## 规则说明 (Rule)

瑞典语正式辩论文（**debattinlägg**）遵循固定的四段式结构，适用于 Sva/SFI 国家考试「Skriva」写作部分：

| 段落 | 名称 | 功能 | 典型表达 |
|------|------|------|----------|
| ① | **Tes / Inledning** | 论点引入，提出核心主张 | *Jag anser att…* / *Bör X regleras?* |
| ② | **Argument** | 支持论据，提供数据/事实 | *Forskning visar att…* / *Algoritmerna är…* |
| ③ | **Motargument + Bemötande** | 承认对方观点，然后反驳 | *Visserligen…, men…* |
| ④ | **Slutsats + Uppmaning** | 结论 + 呼吁行动 | *Därför bör…* / *Det krävs…* |

## 常用连接词和标志语

- **Inledning**: *Jag anser att / Jag menar att / Det är viktigt att*
- **Argument**: *Forskning visar att / Det är ett faktum att / Dessutom*
- **Motargument**: *Visserligen … men / Det stämmer att … men ändå*
- **Slutsats**: *Därför bör / Sammanfattningsvis / Det krävs att*
