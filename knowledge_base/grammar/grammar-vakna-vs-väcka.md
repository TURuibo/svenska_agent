# 📗 vakna vs väcka — 自动词与他动词（醒/叫醒）

级别: A2
一句话: `vakna` = 自己醒来（不及物）；`väcka` = 叫醒别人（及物）。

## 规则说明 (Rules)

📐 结构公式:
```
vakna (intransitiv):  Subjekt + vaknar/vaknade  (无宾语)
väcka (transitiv):   Subjekt + väcker/väckte + OBJEKT
```

与中文对比: 中文"醒"和"叫醒"也是不同的词（或"把……叫醒"），与瑞典语的分工相似。
与英文对比: 英语 "wake up" 既可不及物（I wake up）也可及物（I wake you up），但瑞典语用两个不同词区分。

## 详细讲解 (Detail)

| | **vakna** | **väcka** |
|---|---|---|
| 词类 | 不及物动词 v.1 | 及物动词 v.2a |
| 主体 | 醒来的人本身 | 去叫醒别人的人 |
| 需要宾语 | 否 | 是 |
| 例 | Jag vaknar kl. 6. | Jag väcker barnen kl. 6. |

**变形对比:**

| Form | vakna | väcka |
|------|-------|-------|
| Presens | vaknar | väcker |
| Preteritum | vaknade | väckte |
| Supinum | vaknat | väckt |

## 例句 (Examples)

- ✅ [[sent-varje-morgon-vaknar-jag-klockan]] 🇸🇪 Varje morgon vaknar jag klockan sex. 🇨🇳 每天早上我六点醒来。
- ✅ [[sent-jag-vacker-barnen-och-lagar]] 🇸🇪 Jag väcker barnen och lagar frukost. 🇨🇳 我叫孩子们起床，做早饭。
- ❌ *Jag vaknar barnen.* ← 错误：vakna 不能带宾语
- ❌ *Barnen väcker kl. 6.* ← 错误：väcka 需要宾语（叫醒谁？）

## 常见错误 (Common Mistakes)

- ⚠️ 不要用 `vakna` 表示"叫醒别人"——应用 `väcka`。
- ⚠️ `väcka` 的 preteritum 是 `väckte`（不规则，v.2a），不是 `väckade`。
