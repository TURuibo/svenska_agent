# 📗 dubbelt så ... som — 比较结构"比……多一倍/两倍" (Comparative structure meaning 'twice as ... as')

级别: B1
一句话: `dubbelt så + 形容词/副词 + som` 表示"比……多一倍"，是瑞典语倍数比较的标准结构。

## 规则说明 (Rules)

📐 结构公式:
```
dubbelt så + ADJEKTIV/ADVERB + som + [比较对象]
dubbelt   så   många          som   under samma period för fem år sedan
两倍地    那么  多             比     五年前同期
→ "几乎是五年前同期的两倍"
```

与中文对比: 中文用"是……的两倍"或"比……多一倍"；瑞典语字面是"两倍地那么多，比……"。
与英文对比: 对应英文 "twice as many/much as"。

## 详细讲解 (Detail)

- `dubbelt` (两倍地) 可替换为其他倍数副词：`tre gånger så ... som` (三倍)。
- 中间的形容词/副词随被比较的内容变化：`dubbelt så stor som` (大一倍)、`dubbelt så många som` (多一倍数量)。
- 常加程度副词修饰：`nästan dubbelt så många som...` (几乎是……的两倍)。
- 与单纯比较级 `större än` 不同，`dubbelt så stor som` 强调具体的倍数关系。

## 例句 (Examples)

- ✅ [[sent-det-ar-nastan-dubbelt-sa]] 🇸🇪 Det är nästan dubbelt så många som under samma period för fem år sedan. 🇨🇳 这几乎是五年前同期的两倍。
- ✅ 🇸🇪 Den nya bilen är dubbelt så dyr som den gamla. 🇨🇳 这辆新车的价格是旧车的两倍。
- ❌ `Det är dubbelt mer än fem år sedan.` ← 缺少 `så ... som` 结构，不符合瑞典语习惯

## 常见错误 (Common Mistakes)

- ⚠️ 漏掉 `så`：误写成 `dubbelt many som` 而非 `dubbelt så många som`。
- ⚠️ 混淆 `dubbelt så X som` 与普通比较级 `X-are än`，二者侧重点不同。
