# 📗 Superlativ — 最高级 (Superlative)

级别: A2
一句话: 最高级表示"最……的"，瑞典语有综合式（加 `-ast`/`-st`）和分析式（`mest` + 形容词）两种形式。

## 规则说明 (Rules)

📐 结构公式:
```
1. 综合式（短形容词，多数）:
   grundform → superlativ (indefinit) → superlativ (definit/attributiv)
   stor → störst → störst-a
   lång → längst → längst-a
   gammal → äldst → äldst-a

2. 分析式（多音节形容词）:
   mest + adjektiv (definit -a)
   solsäker → de mest solsäkra platserna
   populär → de mest populära

3. 不规则最高级:
   bra/god → bäst/bästa
   dålig → sämst/sämsta
   liten → minst/minsta
   stor → störst/största
   gammal → äldst/äldsta
   ung → yngst/yngsta
   många → flest/flesta
```

与中文对比: 中文用"最…"（最大、最好），瑞典语则加 `-ast`/`-st` 后缀或加 `mest`。
与英文对比: 英语 `-est`（biggest）/ `most`（most beautiful）；瑞典语规律类似。

## 详细讲解 (Detail)

### 1. 综合式 superlativ（suffixform）

| grundform | komparativ | superlativ (indefinit) | superlativ (definit/attributiv) |
|-----------|-----------|----------------------|--------------------------------|
| stor | större | störst | störst**a** |
| lång | längre | längst | längst**a** |
| gammal | äldre | äldst | äldst**a** |
| ung | yngre | yngst | yngst**a** |
| bra | bättre | bäst | bäst**a** |
| dålig | sämre | sämst | sämst**a** |

**規則：** 定式（attributiv/bestämd）最高级加 `-a`：`den störst**a** ön`.

### 2. 分析式 superlativ（analytisk form）

多音节形容词（3个以上音节）通常用 `mest`:

```
solsäker → de mest solsäkra
populär → det mest populära
välbevarad → de mest välbevarade
intressant → den mest intressanta
```

### 3. Predikativ vs Attributiv 用法

| 用法 | 形式 |
|------|------|
| Predikativ（表语）: `Ön är störst.` | indefinit（`störst`） |
| Attributiv（定语）: `den störst-a ön` | definit（`störst-a`） |
| `en av de störst-a öarna` | definit + 复数 |

### 4. 结构：`en av de + superlativ`

```
Gotland är en av de mest solsäkra platserna i Sverige.
（哥特兰岛是瑞典最阳光充足的地方之一）

Sveriges + superlativ + substantiv:
Sveriges största ö（瑞典最大的岛）
Sveriges bästa mat（瑞典最好的食物）
```

注意：所有格（`Sveriges`）+ 最高级用 definit 形式（`störst-a`）。

## 例句 (Examples)

- ✅ [[sent-sveriges-största-ö-heter-gotland]] 🇸🇪 Sveriges största ö heter Gotland. 🇨🇳 瑞典最大的岛叫哥特兰。
- ✅ [[sent-gotland-är-också-en-av-de-mest]] 🇸🇪 Gotland är en av de mest solsäkra platserna i Sverige. 🇨🇳 哥特兰是瑞典日照最充足的地方之一。
- ✅ 🇸🇪 Vad är det bästa sättet att lära sig svenska? 🇨🇳 学瑞典语最好的方法是什么？
- ❌ `den störst ön` ← 缺少定式 `-a` 后缀
- ❌ `mest stor` ← 单音节词不用 `mest`（应用 `-ast`：`störst`）

## 常见错误 (Common Mistakes)

- ⚠️ 定式最高级忘记加 `-a`：`den bäst dagen` → 应为 `den bäst**a** dagen`。
- ⚠️ 多音节词误用后缀：`mest+ful → `de mestfulaste` → 应为 `de mest fulländade`。
- ⚠️ 不规则最高级要记住：`bra → bäst`（不是 `bra-ast`）。
