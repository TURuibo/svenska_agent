# 📗 Komparativ med än — 比较两个行为/情况

级别: SFI B / A2–B1
一句话: 比较级 + än 后可跟名词、att + 不定式或 om 从句，用来对比两种做法。

## 规则说明 (Rules)

📐 结构公式:
```
mer + 名词/过去分词 + än + 名词          mer fika än plugg
mer gjort än om + 从句                   mer gjort än om jag sitter hemma
(mycket) + 比较级 + att + inf + än att + inf   smartare att läsa lite … än att stressläsa
```

与中文对比: "比…更…"，中文无需重复 att；瑞典语对比两个不定式时两边都带 att。
与英文对比: more X than Y / smarter to … than to …。

## 详细讲解 (Detail)

| 句型 | 例子 | 中文 |
|------|------|------|
| mer N än N | Det blir **mer fika än plugg** | 咖啡多于学习 |
| mer gjort än om … | Där får jag **mer gjort än om** jag sitter hemma | 比在家效率高 |
| 比较级 att … än att … | **smartare att** läsa lite varje dag **än att** stressläsa | 每天读一点比突击聪明 |

- 加 **mycket** 强化比较级：mycket smartare（聪明得多）。
- **än om** = 比"如果…"的情况更…；从句仍用现在时（sitter）。
- 比较级形式见 [[grammar-komparativ]]；smart → smartare → smartast，见 [[smart]]。

## 例句 (Examples)

- ✅ [[sent-där-får-jag-mer-gjort]] 🇸🇪 Där får jag mer gjort än om jag sitter hemma. 🇨🇳 在那儿我比在家效率高。
- ✅ [[sent-men-se-till-så-att-det]] 🇸🇪 … inte blir mer fika än plugg. 🇨🇳 别让喝咖啡比学习还多。
- ✅ [[sent-då-är-det-mycket-smartare-att-läsa]] 🇸🇪 … smartare att läsa lite varje dag än att stressläsa … 🇨🇳 …
- ❌ *mer fika som plugg* ← 应用 än，不用 som。

## 常见错误 (Common Mistakes)

- ⚠️ 比较级后接 än，不接 som/ än som（lika … som 才用 som）。
- ⚠️ 对比两个不定式时漏掉第二个 att。
