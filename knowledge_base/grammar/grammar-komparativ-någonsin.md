# 📗 komparativ-någonsin — 比较级 + någonsin (comparative + 'någonsin')

级别: B1
一句话: 用「比较级 + än + 主语 + någonsin (+ varit/gjort)」表达"比以往任何时候都更……"。

## 规则说明 (Rules)

📐 结构公式:
```
Subjekt + vara/verb(komparativ-kontext) + ... + än + subjekt + någonsin + varit/skett

De stora haven ... var varmare ... än de någonsin varit (sedan mätningarna började)
海洋                  更温暖         比    它们  曾经/以往   曾是（有记录以来）
```

与中文对比: 中文用"比以往任何时候都更……"；瑞典语用 `komparativ + än + ... + någonsin (+ varit)`。
与英文对比: 与英语 "warmer than it has ever been" 完全平行：`någonsin` = "ever"。

## 详细讲解 (Detail)

- `någonsin`（曾经；ever）通常用于**否定句、疑问句、比较级/最高级句**中，表示"在任何时候"。
- 常见搭配动词：`vara`（是/曾是）、`ha varit`（曾经是过，perfekt）、`hänt`（发生过）。
- 完整句型：`X är/var + komparativ + än + X + någonsin + varit`，`varit` 常可省略于口语但书面语倾向保留。
- 类似结构也用于最高级：`den bästa filmen jag någonsin sett`（我看过的最好的电影）。

## 例句 (Examples)

- ✅ [[sent-de-stora-haven-i-världen-var-varmare]] 🇸🇪 De stora haven i världen var varmare i juni i år än de någonsin varit sedan temperaturen började mätas. 🇨🇳 今年六月，世界大洋比自有温度记录以来的任何时候都更温暖。
- ✅ 🇸🇪 Det här är den bästa filmen jag någonsin sett. 🇨🇳 这是我看过的最好的电影。
- ❌ `Haven var varmare än de varit.` ← 缺少 `någonsin`，失去"比以往任何时候"的强调含义。

## 常见错误 (Common Mistakes)

- ⚠️ `någonsin` 一般不用于简单肯定陈述句（如 *Jag var någonsin glad* 是错误的），只用于否定句/疑问句/比较级或最高级语境。
- ⚠️ 别把 `någonsin`（曾经，任意时刻）和 `alltid`（总是）搞混。
