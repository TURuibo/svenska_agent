# enligt + substantiv — 引据介词

## 核心用法

`enligt` 是介词，意为"根据；按照"，直接接名词短语（不接 att-bisats）。

```
enligt + substantivfras
```

| 搭配 | 翻译 |
|------|------|
| `enligt husreglerna` | 根据房屋规定 |
| `enligt lagen` | 根据法律 |
| `enligt mig` | 据我看来；我认为 |
| `enligt rapporten` | 根据报告 |
| `enligt schema` | 按计划；按时间表 |

## 句型位置

`enligt` 短语通常置于句首或主语后：

```
Enligt husreglerna ska det vara tyst efter kl 22.
（根据房屋规定，晚上10点后应保持安静。）

Det ska, enligt husreglerna, vara tyst efter kl 22.
（插入语位置，更正式）
```

## 与其他引据词的对比

| 词 | 用法 | 例句 |
|----|------|------|
| `enligt` | 根据（客观引据）| `Enligt tidningen...` |
| `efter` | 根据；依照 | `efter din önskan`（根据你的意愿）|
| `utifrån` | 基于；从……出发 | `utifrån forskningen`（基于研究）|

## 例句

- Enligt husreglerna ska det vara tyst i fastigheten efter klockan 22. — 根据房屋规定，晚上10点后楼内应保持安静。
- Enligt schemat börjar kursen klockan 9. — 根据时间表，课程9点开始。
- Enligt mig är det viktigt att lyssna på grannarna. — 我认为倾听邻居的意见是重要的。
