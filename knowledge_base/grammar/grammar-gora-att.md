# 📗 göra att — 使得，导致 (to cause, to result in)

级别: B1
一句话: "X gör att Y" = "X 这件事使得/导致 Y 发生"，用来表达因果关系，"att" 引导的从句说明结果。

## 规则说明 (Rules)

📐 结构公式:
```
[Orsak/Subjekt] + gör/gjorde + att + [bisats: resultat]
   原因/主语        做(现在/过去)   使得    结果从句
```

与中文对比: 与中文"使得/导致"结构基本对应——"这件事**使得**工作停滞了"，语序相同（原因在前，"使得"居中，结果在后）。
与英文对比: 类似英语 "X caused Y to..." 或 "X made Y...", 但瑞典语固定用 "göra att + 从句"（完整分句），而不是像英语那样用不定式 "cause someone **to do**"。

## 详细讲解 (Detail)

"göra att" 是常见的因果连接结构，后面必须接一个完整的 att-bisats（从句），而不是不定式：

```
Vilken händelse gjorde att arbetet stannade av?
   什么事件        使得       工作      停滞了？
```

时态上 "göra" 可以是 presens (gör) 或 preteritum (gjorde)，取决于叙述的时间框架；bisats 中的动词时态通常与主句一致或稍晚。

## 例句 (Examples)

- ✅ [[sent-vilken-händelse-gjorde-att-arbetet]] 🇸🇪 Vilken händelse gjorde att arbetet för kvinnlig rösträtt stannade av? 🇨🇳 什么事件使得争取女性选举权的工作停滞了？
- ❌ Vilken händelse gjorde arbetet att stanna av? ← 常见错误：把从句结构和不定式结构混用，应为 "gjorde att arbetet stannade av"

## 常见错误 (Common Mistakes)

- ⚠️ 混淆 "göra att + 从句" 与 "få + 宾语 + 不定式"（få ngn att göra ngt）两种因果结构，二者语法形式不同，不能混用。
- ⚠️ 忘记 att-bisats 需要完整的主谓结构（不能只用不定式）。
