# 📗 särskilt om — 尤其当 (especially if)

级别: B1
一句话: "särskilt om + 从句" 用来强调某规则或行为在特定条件下尤其成立/尤其明显。

## 规则说明 (Rules)

📐 结构公式:
```
[huvudsats], särskilt om + [bisats (bisats-ordföljd)]
```

与中文对比: 中文"尤其是（当）……的时候"，条件从句通常放在后面，与瑞典语语序一致。
与英文对比: "especially if ..." —— 用法基本对应，都是把强调条件放在从句里。

## 详细讲解 (Detail)

- "särskilt om" 由副词 särskilt（尤其）+ 连词 om（如果/是否）组成，引导一个表条件的 bisats。
- 与 [[grammar-även-om]]（即使）常被放在一起对比记忆：
  - **även om** = 即使（让步，条件不影响结果）
  - **särskilt om** = 尤其当（强调，条件加强某结果）
- bisats 内遵循 bisats 语序：先主语，再否定词/情态副词，再动词（如 "om man **inte** känner personen väl"）。

## 例句 (Examples)

- ✅ [[sent-i-sverige-hälsar-man-oftast-med]] 🇸🇪 I Sverige hälsar man oftast med ett handslag eller en nick, särskilt om man inte känner personen väl. 🇨🇳 在瑞典通常用握手或点头打招呼，尤其是不太熟的人。
- ❌ *Särskilt om man inte känner personen väl, man hälsar med ett handslag.* ← bisats 提前时主句需倒装：应为 "...hälsar man med..."

## 常见错误 (Common Mistakes)

- ⚠️ 与 "även om"（即使）混淆——"särskilt om" 是加强条件，不是让步条件。
- ⚠️ bisats 内否定词位置放错（应紧跟在主语后面：man **inte** känner，而非 inte man känner）。
