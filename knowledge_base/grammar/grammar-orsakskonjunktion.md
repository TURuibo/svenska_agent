# grammar-orsakskonjunktion — 原因连词

**语法类别:** Bisatskonnektiv / 从属连词
**中文:** 原因连词（因为……）
**English:** Causal conjunction (because, since)
**CEFR:** A2

## 主要原因连词 (Main Causal Conjunctions)

| 连词 | 含义 | 用法 |
|------|------|------|
| **för att** | 因为 | 最常用（日常口语和书面均可）|
| **eftersom** | 因为；由于 | 稍正式，常放句首 |
| **därför att** | 因为 | 正式书面语 |

## 语法结构 (Grammar)

```
[主句] + [för att / eftersom / därför att] + [从句（BIFF 语序）]
                     原因连词                    从句内副词在动词前
```

> **注意：** *för att* 在这里是原因连词（= because），不要与 *för att + infinitiv*（= 为了，表目的）混淆！
> - 原因：*Jag missade mötet för att jag inte hittade rätt.* = 我错过了会议，因为我没找到路。
> - 目的：*Jag cyklar för att hålla mig frisk.* = 我骑车是为了保持健康。

## 例句 (Example Sentences)

1. *Jag missade mötet för att jag inte hittade rätt.* — 因为我没找到路，我错过了会议。
2. *Eftersom det regnar, stannar vi hemma.* — 因为在下雨，我们待在家里。
3. *Han gick hem därför att han var trött.* — 他回家了，因为他累了。
4. *Jag studerar svenska för att jag bor i Sverige.* — 我学瑞典语，因为我住在瑞典。

## 对比：原因 vs 目的 (Cause vs Purpose)

```
för att + bisats  → 原因 (because)
för att + infinitiv → 目的 (in order to)
```

- *Hon stannade hemma för att hon var sjuk.* (原因：因为生病)
- *Hon stannade hemma för att vila.* (目的：为了休息)
