# 📗 konjunktiv vore — 虚拟式 vore (subjunctive "vore")

级别: SFI C / CEFR B1-B2
一句话: vore 是 vara 的虚拟式（konjunktiv），用于婉转、假设或书面的判断："要是……就会……"。

## 规则说明 (Rules)

📐 结构公式:
```
Det vore + 形容词 + att + 不定式 / att 从句
```

与中文对比: 相当于"若……则不……""……恐怕不合适"，语气比 är 更委婉、更假设。
与英文对比: 类似 "It would be unreasonable to …"（would be）。

## 详细讲解 (Detail)

- vore = vara 的 konjunktiv，只在固定书面搭配中保留：det vore bra/synd/fel att …；som om det vore …
- 常用于报告、评论，表达谨慎的判断。口语多用 skulle vara 替代。

## 例句 (Examples)

- ✅ [[sent-det-vore-dock-orimligt-att-påstå]] 🇸🇪 Det vore dock orimligt att påstå att sömn är den enda förklaringen. 🇨🇳 不过，断言睡眠是唯一的解释并不合理。
- ❌ Det vara orimligt att påstå … ← 不能用不定式 vara

## 常见错误 (Common Mistakes)

- ⚠️ 不要把 vore 当作过去时：过去时是 var；vore 表示假设/委婉。
