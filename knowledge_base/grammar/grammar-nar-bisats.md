# när-bisats — when从句（temporal subordinate clause with när）

级别: A2
一句话: *när* 引导时间状语从句，主句仍须遵守 V2 语序。

## 规则说明 (Rules)

📐 结构公式:
```
[när + 从句] + [主句（V2 语序）]
  ↑时间状语     ↑谓语在第二位
```

或：
```
[主句] + [när + 从句]
```

与中文对比: 中文"当……的时候"= *när* 引导的从句，位置更灵活。
与英文对比: 英文 *when-clause* 结构类似；关键区别在于主句仍需 V2 语序（谓语第二）。

## 详细讲解 (Detail)

- *när* 是从属连词（subjunktion），引导时间状语从句（tidsadverbial-bisats）。
- 从句本身遵守 BIFF 语序（否定副词 *inte* 等在动词前）。
- 主句无论 *när*-从句在前或在后，都必须保持 V2 语序。

**当 när-从句在句首时（前置状语）:**
主句谓语必须紧跟从句之后（第二位），主语在谓语之后（主谓倒装）：

```
När våren kommer  |  börjar  dagarna bli ljusare.
    从句（状语）     动词(V2)  主语
```

## 例句 (Examples)

- ✅ [[sent-nar-varen-kommer-borjar-dagarna]] 🇸🇪 När våren kommer börjar dagarna bli ljusare. 🇨🇳 当春天来临，白天开始变得越来越明亮。
- ✅ 🇸🇪 När jag kom hem sov katten. — 🇨🇳 当我回家时，猫在睡觉。（主谓倒装：动词 *sov* 在主语 *katten* 前）
- ❌ *När våren kommer dagarna börjar bli ljusare.* ← 错误：主句未倒装，动词 *börjar* 不在第二位。

## 常见错误 (Common Mistakes)

- ⚠️ *när*-从句置前时，忘记主句倒装（主谓倒装）。
- ⚠️ 混淆 *när*（什么时候/当……时）和 *om*（如果/是否）。
