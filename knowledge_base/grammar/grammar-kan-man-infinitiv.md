# 📗 kan man + infinitiv — 泛指主语"man"加情态动词

级别: A2
一句话: man 是瑞典语泛指代词（相当于英语的 "one/you/people"），与情态动词 kan 结合，表示"可以/能……"的一般性陈述。

## 规则说明 (Rules)

📐 结构公式:
```
man + modal + infinitiv
man + kan   + se/göra/...

倒装（V2语序）时：
[fronted element] + modal + man + infinitiv
Från broarna      + kan   + man + se vatten
```

- man 没有宾格/所有格：man（主语）→ en（宾格/口语）→ ens（所有格）
- 与 kan 组合：kan man（能/可以）；måste man（必须）；bör man（应该）
- V2规则：当非主语成分放到句首，情态动词提前，man 紧跟在情态动词后

与中文对比: 中文常省略泛指主语（"从桥上可以看到水"），而瑞典语必须用 man 填补主语位置
与英文对比: 英语 "one can" / "you can"（泛指）

## 详细讲解 (Detail)

man 是瑞典语泛指代词：
- 不特指某人，表示"一般人/人们/你"
- 动词仍用第三人称单数形式
- 常见搭配：kan man, måste man, får man, bör man, ska man, brukar man

**倒装示例：**
- 正常语序：Man kan se vatten från broarna.
- 倒装（地点前置）：Från broarna kan man se vatten. ← V2 语序

## 例句 (Examples)

- ✅ [[sent-från-broarna-kan-man-se-vatten]] 🇸🇪 Från broarna kan man se vatten på alla sidor. 🇨🇳 从桥上望去，四面都是水。
- ✅ 🇸🇪 I Sverige kan man dricka kranvatten. 🇨🇳 在瑞典，人们可以喝自来水。
- ✅ 🇸🇪 Man måste köpa biljett. 🇨🇳 （人们/你）必须买票。
- ❌ Kan vi se vatten? ← 不是泛指，而是特指"我们"，语义不同

## 常见错误 (Common Mistakes)

- ⚠️ 倒装后忘记将动词提前（*Från broarna man kan se... ← 错误）
- ⚠️ 混淆 man（泛指）与 man（丈夫，名词）
