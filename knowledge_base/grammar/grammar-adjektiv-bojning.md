# 📗 adjektiv-bojning — 形容词变化 (adjective declension)

级别: A2
一句话: 瑞典语形容词有四种形式，随所修饰名词的性（utrum/neutrum）、数（singular/plural）和确定性（obestämd/bestämd）变化。

## 规则说明 (Rules)

📐 结构公式:
```
en-ord (utrum):      stor pojke      → grundform (stor)
ett-ord (neutrum):   stort hus       → +t  (stort)
plural/bestämd:      stora barn      → +a  (stora)
                     den stora bilen → +a  (stora)
                     det stora huset → +a  (stora)
```

与中文对比: 中文形容词不变形（大男孩、大房子都用"大"）；瑞典语必须随名词变形。
与英文对比: 英文形容词也不变形（big boy / big house / big children）；瑞典语有更多形式。

## 详细讲解 (Detail)

### 四形式图表 (Four-form pattern)

| Kontext | Form | Exempel |
|---------|------|---------|
| en-ord, obestämd sg. | grundform | en **stor** pojke |
| ett-ord, obestämd sg. | +t | ett **stort** hus |
| plural, obestämd | +a | **stora** barn |
| bestämd form (alla genus) | +a | den/det/de **stora** … |

### Oregelbundenheter (Irregularities)

**liten / litet / lilla / små**
- en liten flicka → ett **litet** barn → den/det **lilla** … → **små** barn
- Bestämd singular: `lilla` (not `litena`)

**Slutar på -d → neutrum -tt**
- trött / **trött**t / trötta *(samma form)*
- röd → **rött** (umlaut + tt) / röda
- god → **gott** / goda

**gammal → gammalt → gamla (synkope)**
- `gammal` (en-ord) → `gammalt` (ett-ord) → `gamla` (pl./best.)
- Bestämd sg.: `gamla` (den **gamla** mannen)

**Oböjliga adjektiv (indeclinable)**
- Adjektiv som slutar på -a eller -e böjs inte: `bra`, `extra`, `kul`, `lila`, `beige`
- Exempel: en **bra** idé / ett **bra** beslut / **bra** resultat

### Rätta vs. höger/vänster
- `rätt` (correct) böjs normalt: rätt / rätt / rätta
- `höger` och `vänster` är oböjliga: höger hand / höger öga / höger sida

## 例句 (Examples)

- ✅ [[stor]] 🇸🇪 Det är ett **stort** hus med en **stor** trädgård. 🇨🇳 这是一座大房子，有一个大花园。
- ✅ [[liten]] 🇸🇪 Den **lilla** bebisen sover i ett **litet** rum. 🇨🇳 那个小婴儿在一个小房间里睡觉。
- ❌ *ett stor hus* ← neutrum-form måste vara `stort`

## 常见错误 (Common Mistakes)

- ⚠️ Glömmer +t för ett-ord: `ett stor hus` → ska vara `ett **stort** hus`
- ⚠️ Använder grundform efter bestämd artikel: `den stor bilen` → ska vara `den **stora** bilen`
- ⚠️ Böjer oböjliga adjektiv: `ett kult spel` → ska vara `ett **kul** spel`
- ⚠️ `liten` i bestämd form: `den litena flickan` → ska vara `den **lilla** flickan`
