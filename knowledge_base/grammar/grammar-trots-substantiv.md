# 📗 trots + substantiv — "尽管"介词用法（接名词） (despite + noun phrase)

级别: B1
一句话: *trots* 作介词时直接接名词短语（无 *att*）；作连词时接 *trots att + bisats*。

## 规则说明 (Rules)

📐 结构公式:
```
trots + substantivfras (NP)          ← 介词用法
trots att + bisats (全句)             ← 连词用法
```

例：
- *Trots förlusten kan Sverige gå vidare.* — 尽管失利，瑞典仍可晋级。（介词 + NP）
- *Trots att Sverige förlorade, kan de gå vidare.* — 尽管瑞典输了，他们仍可晋级。（连词 + bisats）

与中文对比: 中文"尽管"后接完整句子；*trots* 接名词时无需附加动词。
与英文对比: 等同于 *despite + NP* vs. *even though + clause*。

## 详细讲解 (Detail)

**trots 的两种用法：**

| 用法 | 接什么 | 例子 |
|------|--------|------|
| 介词 (preposition) | + substantivfras | *Trots regnet gick vi ut.* |
| 连词 (konjunktion) | + att + bisats | *Trots att det regnade gick vi ut.* |

关键规则：
- *trots* 作介词 → 直接接名词（无 *att*）
- *trots att* 是固定连词短语 → 后接完整子句
- 两者语义相同，可互换（只要语法结构正确）
- 注意语序：*trots*-frasen 放句首时，主句遵循 V2 规则（动词在第二位）

## 例句 (Examples)

- ✅ [[sent-trots-forlusten-kan-sverige-ga-vidare]] 🇸🇪 Trots förlusten kan Sverige fortfarande gå vidare. 🇨🇳 尽管失利，瑞典仍可晋级。
- ✅ Trots regnet gick vi ut. 🇨🇳 尽管下雨，我们还是出去了。
- ✅ Trots värmen åt de lunch utomhus. 🇨🇳 尽管天气炎热，他们还是在户外吃午饭。
- ✅ Trots att det var varmt åt de lunch utomhus. 🇨🇳 （同义，连词用法）
- ❌ *Trots av regnet* ← 错误：*trots* 不与 *av* 搭配
- ❌ *Trots det regnade* ← 错误：连词必须用 *trots att*

## 常见错误 (Common Mistakes)

- ⚠️ 用 *trots* 直接接动词句而不加 *att*：❌ *Trots Sverige förlorade* → ✅ *Trots att Sverige förlorade*
- ⚠️ *trots*-frasen在句首后忘记V2语序：❌ *Trots förlusten Sverige kan gå* → ✅ *Trots förlusten kan Sverige gå*
