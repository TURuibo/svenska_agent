# 📗 att + infinitiv — att 不定式 (infinitive with att)

级别: SFI B / CEFR A2
一句话: 许多名词、形容词、动词后面用 att + 动词原形，相当于中文的"去做…/做…"。

## 规则说明 (Rules)

📐 结构公式:
```
sätt / dags / svårt / börja med + att + infinitiv
```

与中文对比: 中文直接说"开始写"，瑞典语要加 att：börja med att skriva。
与英文对比: 相当于 to + infinitive（a way to get ...）。

## 详细讲解 (Detail)

- 名词后：ett sätt att få kontroll（一个获得掌控的办法）
- 介词后：börja med att skriva upp（从记下来开始）
- 否定：att inte glömma（inte 放在 att 之后、动词之前）
- 情态动词 / hjälpverb 后不加 att：kan skriva, ska spara
