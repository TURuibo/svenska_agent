# 📗 reflexivt verb — 反身动词 (reflexive verb)

级别: A2
一句话: 动作的发出者和承受者是同一个人时，用反身代词（mig/dig/sig/oss/er）。

## 规则说明 (Rules)

📐 结构公式:
```
主语 + 动词 + 反身代词
jag   tar    mig   (dit)
du    tar    dig   (dit)
han   tar    sig   (dit)
vi    tar    oss   (dit)
ni    tar    er    (dit)
de    tar    sig   (dit)
```

反身代词变位表：

| Person | Reflexiv |
|--------|---------|
| jag | mig |
| du | dig |
| han/hon/den/det | sig |
| vi | oss |
| ni | er |
| de | sig |

与中文对比: 中文"我自己去"用"自己"，瑞典语用独立的反身代词系统。
与英文对比: 英语 myself/yourself/himself 类似，但瑞典语三四人称统一用 `sig`。

## 详细讲解 (Detail)

常见反身动词：
- `ta sig dit` — 到达那里（自行前往）
- `skynda sig` — 赶快
- `sätta sig` — 坐下
- `klä sig` — 穿衣
- `känna sig` — 感觉（情感）
- `se sig om` — 环顾四周

互相动词（reciprocal）也用同一结构：
- `vi ses` = we see each other（我们互相看到 → 见面）
- `vi hörs` = we hear each other（互相联系）

## 例句 (Examples)

- ✅ [[sent-hur-tar-jag-mig-dit]] 🇸🇪 Hur tar jag mig dit? 🇨🇳 我怎么去那里？
- ✅ [[sent-skynda-dig-lite]] 🇸🇪 Skynda dig lite. 🇨🇳 稍微快点。
- ✅ [[sent-vi-ses-snart]] 🇸🇪 Vi ses snart. 🇨🇳 待会见。
- ❌ *Hur tar jag dit?* ← 缺少反身代词 mig

## 常见错误 (Common Mistakes)

- ⚠️ 忘记加反身代词：*Skynda lite!* → 正确：*Skynda dig lite!*
- ⚠️ 混淆 `mig/dig/sig`：第三人称统一用 `sig`（他/她/它/他们）
