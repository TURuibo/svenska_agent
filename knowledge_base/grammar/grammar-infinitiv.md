# 📗 infinitiv — 不定式 (infinitive)

级别: SFI A / A1
一句话: Infinitiv är verbets grundform — används efter "att" och modala hjälpverb (ska, vill, kan, måste).

## 规则说明 (Rules)

📐 结构公式:
```
att + infinitiv          (Han vill att spela är fel — "att" direkt med infinitiv vid komplementsats)
Modal/hjälpverb + infinitiv  (ska/vill/kan/måste/behöver + infinitiv, utan "att")
```

与中文对比: 中文动词无需变化为不定式；瑞典语动词在 att/modal 后用基本形式（infinitiv）。
与英文对比: "to play" = "att spela". Efter modaler saknas "att" precis som "to" saknas efter "can/will/shall" på engelska.

## 详细讲解 (Detail)

| Verb | Infinitiv | Presens |
|------|-----------|---------|
| spela | spela | spelar |
| börja | börja | börjar |
| vara | vara | är |
| ge | ge | ger |
| slippa | slippa | slipper |

Typiska konstruktioner:
- att + infinitiv (subjekt/objekt): Det är kul att spela fotboll.
- modal + infinitiv: Han kan spela fotboll. / Du behöver inte börja nu.
- "slippa" + infinitiv (utan att): Han slipper träna.

## 例句 (Examples)

- ✅ Han vill börja spela fotboll. — 🇨🇳 他想开始踢足球。
- ✅ Du behöver inte avsluta nu. — 🇨🇳 你不必现在结束。

## 常见错误 (Common Mistakes)

- ⚠️ "vill att spela" är fel → "vill spela".
- ⚠️ Att böja verbet efter modal: "kan spelar" är fel → "kan spela".
