# 📗 infinitiv-subjekt — 不定式作主语（Att + infinitiv）(infinitive as subject)

级别: B1
一句话: 用 `att + 动词`（不定式短语）作为句子的主语，表达某件事/某种行为本身。

## 规则说明 (Rules)

📐 结构公式:
```
Att + [动词 grundform] + (宾语/补语) + är/verkar + [形容词/名词]
Att källsortera = 垃圾分类（这件事）
Att källsortera är viktigt = 垃圾分类很重要
```

与中文对比: 中文直接用动词短语作主语（"垃圾分类很重要"）；瑞典语需要 `att` 引导不定式
与英文对比: 类似 "Recycling is important"（英语可用动名词/-ing），瑞典语用 `att + infinitiv`

## 详细讲解 (Detail)

当一个动词（或动词短语）需要充当句子的主语时，在瑞典语中：
1. 在动词前加 `att`
2. 动词保持原形（grundform / infinitiv）
3. 谓语动词按中性（ett）形式变化（因为 `att + verb` 视为 ett-ord）

| 结构 | 例句 |
|------|------|
| Att + verb + är + adj(neutrum) | Att källsortera är viktigt |
| Att + verb + är + adj(neutrum) | Att simma är kul |
| Att + verb + verkar + adj | Att lära sig svenska verkar svårt |

注意：谓语形容词用**中性形式**（viktigt, kul, svårt），因为主语是 ett-genus。

## 例句 (Examples)

- ✅ [[sent-att-källsortera-är-viktigt]] 🇸🇪 Att källsortera är viktigt — det minskar avfall och sparar naturresurser. 🇨🇳 垃圾分类很重要——它减少废物并节省自然资源。
- ✅ 🇸🇪 Att cykla till jobbet är bra för hälsan. 🇨🇳 骑车上班对健康有益。
- ❌ *Källsortera är viktigt* ← 缺少 `att`，语法不完整（口语中有时可省略，但书面语需要）

## 常见错误 (Common Mistakes)

- ⚠️ 忘记 `att`：直接用动词原形作主语在书面语中是错误的
- ⚠️ 形容词形式：主语是不定式短语时，谓语形容词用**中性（ett）形式**：viktigt（非 viktig）
