# 📗 klockan halv — 钟点表达 halv (telling time with *halv*)

级别: SFI B / CEFR A1
一句话: **halv X = X 点差半小时**，即 (X−1):30 —— *halv fyra* = 3:30，不是 4:30。

## 规则说明 (Rules)

📐 结构公式:
```
klockan  halv  <下一个整点>      →  (下一个整点 − 1):30
klockan  halv  fyra              →  3:30
klockan  halv  sju               →  6:30
klockan  halv  tolv              →  11:30
```

| 瑞典语 | 时间 | 直觉陷阱 |
|---|---|---|
| klockan två | 2:00 | — |
| halv tre | 2:30 | 不是 3:30 |
| halv fyra | 3:30 | 不是 4:30 |
| kvart i fyra | 3:45 | 差一刻到四点 |
| kvart över fyra | 4:15 | 四点过一刻 |
| vid sex / vid sextiden | 六点左右 | 约数用 *vid* |

与中文对比: 中文「三点半」= 已过的整点 + 半；瑞典语 *halv fyra* = **将到的整点** − 半。思维方向相反，每次先在脑中减 1。
与英文对比: 英文 "half past three" = 3:30，看的是过去的整点；瑞典语 *halv fyra* 看的是下一个整点（同德语 halb vier）。

## 详细讲解 (Detail)

- *klockan* 可省：*Vi ses halv fyra.* 24 小时制口语少用，*halv fyra* 说的是 3:30 或 15:30 看语境。
- 配 *på morgonen / på eftermiddagen / på natten* 区分上下午：*halv fyra på natten* = 凌晨 3:30。
- 「几点左右」用 *vid* + 时间：*vid sex* / *vid sextiden*。「几点整」用 *klockan* + 数字。
- 问时间：*Hur mycket är klockan?* — *Den är halv fyra.*

## 例句 (Examples)

- ✅ [[sent-klockan-halv-fyra-somnade-hon-om]] 🇸🇪 Klockan halv fyra somnade hon om. 🇨🇳 三点半，她重新睡着了。
- ✅ [[sent-mitt-i-natten-klockan-två-vaknade]] 🇸🇪 Mitt i natten, klockan två, vaknade Ella och skrek. 🇨🇳 半夜两点，Ella 醒了，大哭大叫。
- ✅ [[sent-vid-sex-på-morgonen-vaknade-hon]] 🇸🇪 Vid sex på morgonen vaknade hon igen. 🇨🇳 早上六点她又醒了。
- ✅ 🇸🇪 Förskolan öppnar halv sju. 🇨🇳 幼儿园六点半开门。
- ❌ *halv fyra* = 4:30 ← 常见错误（差一小时）

## 常见错误 (Common Mistakes)

- ⚠️ 把 *halv fyra* 理解成 4:30。记：**halv = 半路去往 fyra**，还没到四点。
- ⚠️ 说 *halv efter tre* / *tre och halv* —— 瑞典语不这么说，只说 *halv fyra*。
- ⚠️ 混淆 *vid sex*（六点左右）和 *klockan sex*（六点整）。
