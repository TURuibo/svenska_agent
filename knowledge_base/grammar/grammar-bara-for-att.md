# 📗 bara för att — 仅仅因为 (just because)

级别: SFI B / CEFR A2-B1
一句话: `bara för att` 引出理由从句，强调"仅仅这个理由"，常用于否定结论。

## 规则说明 (Rules)

📐 结构公式:
```
主句 (常否定) + bara för att + 从句 (主语 + 动词 ...)
```

与中文对比: 相当于"仅仅因为…就…"。
与英文对比: 对应 "just because ...".

## 详细讲解 (Detail)

- 从句是 bisats：词序为 主语 + (inte) + 动词，见 [[grammar-bisats]]。
- 与 [[grammar-bisats-eftersom]] 相比，bara för att 带有"理由不足"的语气。

## 例句 (Examples)

- ✅ [[sent-kriget-är-inte-över-bara-för]] 🇸🇪 Kriget är inte över bara för att det är VM i skidor. 🇨🇳 战争并没有因为办滑雪世锦赛就结束。
- ✅ Du kan inte säga nej bara för att du är trött. — 你不能仅仅因为累就拒绝。

## 常见错误 (Common Mistakes)

- ⚠️ 从句里 att 不能省略。
