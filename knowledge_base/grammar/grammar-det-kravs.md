# grammar-det-kravs — 非人称被动结构

📐 中文：非人称被动——det krävs（需要/要求）· English: impersonal passive: det krävs

## 规则说明 (Rule)

**det krävs** 是动词 *kräva*（要求）的**非人称被动（opersonlig passiv）**形式，即 s-被动 + 形式主语 *det*：

```
det + kräv-s = det krävs = "it is required / what is needed"
```

### 两种用法

1. `det krävs + substantiv(frasfras)` — 需要…… (名词短语)
   - *Det krävs politiska åtgärder.* — 需要政治措施。

2. `det krävs att + bisats` — 要求（某人/某事）……
   - *Det krävs att alla bidrar.* — 要求所有人做出贡献。

### 为什么比 "man behöver" 更有力？

| 表达 | 语气 | 场景 |
|------|------|------|
| *man behöver X* | 中性 | 日常口语 |
| *det krävs X* | 正式/有力 | 议论文、政策文本 |
| *det är nödvändigt med X* | 正式 | 书面论述 |

## 例句 (Sentences)

- 🇸🇪 Det krävs politiska åtgärder för att lösa detta. — 🇨🇳 解决这个问题需要政治措施。
- 🇸🇪 Det krävs tålamod och hårt arbete. — 🇨🇳 需要耐心和努力。
