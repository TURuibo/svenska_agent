# 📗 var + ordningstal — var + 序数词表间隔 (var + ordinal for intervals)

级别: B1
一句话: 用 `var` + 序数词表达"每隔几个/每第几个"的频率，如 `var tionde kaffe`（每第十杯咖啡）。

## 规则说明 (Rules)

📐 结构公式:
```
var + ordningstal (序数词) + 名词
var tionde  kaffe   → 每第十杯咖啡（每第十个就免费）
var tredje  dag     → 每三天（每第三天）
var fjärde  vecka   → 每四周
varannan    dag     → 每隔一天（var + annan 合并）
```

与中文对比:
- 中文用"每……个/次"：每第十杯 = `var tionde kaffe`。
- `var` 相当于中文的"每第"，序数词说明间隔数。

与英文对比:
- 英语 "every tenth coffee" = `var tionde kaffe`（一一对应）。
- 英语有时用 "every other day"（每隔一天），瑞典语对应 `varannan dag`。

## 详细讲解 (Detail)

- `var` 在这里不是疑问词"哪里"，而是分配词（distributivt pronomen）。
- 序数词需要与名词在性/数上一致（但 `var` 本身不变形）：
  - `en-ord`：`var tionde kaffe`（kaffe 是 ett-ord → tionde，形容词定指形）
  - `ett-ord`：`var tionde gång`（gång 是 en-ord → tionde，同形）
  - 注意：序数词在 `var` 结构中用**定指形**（-e/-a 结尾）。
- `varannan` 是 `var annan` 的合并形式，专用于"每隔一个"。

## 例句 (Examples)

- ✅ [[sent-forresten-har-du-vart-stampelkort]] 🇸🇪 Var tionde kaffe är gratis. 🇨🇳 每第十杯咖啡免费。
- ✅ Var tredje dag träffas vi. 🇨🇳 我们每三天见一次面。
- ✅ Varannan vecka har vi möte. 🇨🇳 我们每隔一周开一次会。
- ❌ *Varje tionde kaffe är gratis.* ← `varje`（每个）不用于间隔表达，`var` 才对。

## 常见错误 (Common Mistakes)

- ⚠️ 混用 `varje` 和 `var`：`varje tionde`（错）vs `var tionde`（对）。
  `varje` = every single one（每一个）；`var` + 序数词 = every Nth one（每第N个）。
- ⚠️ 忘记序数词用定指形：`var tio`（错）vs `var tionde`（对）。
