# 📗 genom att + infinitiv — 通过做……（方式状语） ("by doing (something)")

级别: B1
一句话: "genom att" + 动词不定式，表示达成某事的**方式/手段**，区别于表**目的**的 "för att"。

## 规则说明 (Rules)

📐 结构公式:
```
[huvudsats] genom att + infinitiv (+ och + infinitiv...)
```

与中文对比: "通过...的方式"
与英文对比: "by + -ing"

## 详细讲解 (Detail)

对比 `för att` (目的, purpose, "in order to") vs `genom att` (方式, means, "by doing")：
`De kämpade för att vinna rösträtt (目的) genom att skriva artiklar (方式).`
（她们为了赢得选举权 [目的] 而斗争，通过写文章 [方式]。）

## 例句 (Examples)

- ✅ [[sent-deras-kamp-var-fredlig-och]] 🇸🇪 De spred sitt budskap genom att skriva artiklar och dela ut flygblad. 🇨🇳 她们通过写文章、发传单来传播理念。
- ❌ De spred sitt budskap för att skriva artiklar. ← 混淆了方式与目的

## 常见错误 (Common Mistakes)

- ⚠️ `genom att` 后面必须接不定式（动词原形），不要写成 `genom skriva`。
- ⚠️ 不要把表示"方式"的 `genom att` 和表示"目的"的 `för att` 搞混。
