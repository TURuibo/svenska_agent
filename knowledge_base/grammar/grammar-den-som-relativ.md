# 📗 den som (relativsats) — den som = 那个……的人 (relative clause: den som = the one who)

级别: B1
一句话: *Den som + verb* = the one who / the person who，常用于泛指某类人。

## 规则说明 (Rules)

📐 结构公式:
```
det är + noun phrase + för den som + verb phrase
den som + verb                             (as subject)
```

与中文对比: 中文用"……的人"，瑞典语用 *den som* 引导关系从句，后接动词。
与英文对比: "the one who" / "whoever" / "anyone who" — same idea, but in Swedish the bisats word order applies.

## 详细讲解 (Detail)

- *Den som* is a demonstrative pronoun + relative particle. It generalizes to "whoever / the person who."
- For things: *det som* (= what / that which). E.g. *Det som är svårt är arbetstiderna.*
- Bisats word order inside the relative clause: negations and adverbs come before the verb.
  - *den som **inte** räds tidiga mornar* ✅ (negation before verb in bisats)
  - *den som **inte** **har** upplevt det* ✅

## 例句 (Examples)

- ✅ [[sent-det-ar-ett-yrke]] 🇸🇪 Det är ett yrke för den som gillar att skapa med händerna. 🇨🇳 这是一个适合喜欢用双手创造的人的职业。
- ✅ [[sent-det-ar-svart-att-forklara]] 🇸🇪 Det är svårt att förklara för den som inte har upplevt det. 🇨🇳 没体验过的人很难解释。
- ✅ 🇸🇪 Den som arbetar hårt lyckas ofta. 🇨🇳 努力工作的人通常会成功。
- ❌ *Den som inte räds tidiga mornar.* ← (sentence fragment, needs a main clause)

## 常见错误 (Common Mistakes)

- ⚠️ Using *som* alone without *den*: *som inte räds* doesn't work as a standalone generalized subject — needs *den som*.
- ⚠️ Forgetting bisats word order inside the clause: *den som räds inte* ← wrong; should be *den som inte räds*.
