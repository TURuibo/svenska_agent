# 📗 relativt adverb där — 地点从句 där (locative där-clause)

级别: SFI B / CEFR A2
一句话: `där` 引出说明地点的从句，相当于中文「在……的地方」。

## 规则说明 (Rules)

📐 结构公式:
```
主句（含地点名词）, där + 主语 + 动词 + …
Göteborg ligger på västkusten, där Göta älv möter havet.
```

与中文对比: 中文「在……的地方」放前面；瑞典语 där 从句放在地点之后。
与英文对比: 相当于 where。

## 例句 (Examples)

- ✅ [[sent-göteborg-ligger-på-sveriges-västkust-där]] 🇸🇪 Göteborg ligger på Sveriges västkust, där Göta älv möter havet. 🇨🇳 哥特堡位于瑞典西海岸，约塔河在这里汇入大海。

## 常见错误 (Common Mistakes)

- ⚠️ 别用 `som` 代替 där：×…västkust, som Göta älv möter havet。
- ⚠️ där（在那里）与 dit（到那里）：静止用 där，移动用 dit。
