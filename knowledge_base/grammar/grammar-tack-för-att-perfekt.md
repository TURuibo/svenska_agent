# 📗 tack för att + preteritum — 感谢从句结构 (thank-you clause with past tense verb)

级别: A2
一句话: "tack för att" 后面的动词用**过去时（preteritum）**，因为感谢的是已经发生的事。

## 规则说明 (Rules)

📐 结构公式:
```
tack för att + 主语 + 动词（preteritum）
```

例：
- tack för att **du hjälpte** mig → 感谢你（已经）帮助了我
- tack för att **ni kallade** mig → 感谢你们（已经）邀请了我
- tack för att **han kom** → 感谢他（已经）来了

与中文对比: 中文"感谢你…"后直接跟动词，不需要时态变化；瑞典语中 att-sats 里的动词需要用过去时反映动作已完成。

与英文对比: 英语 "thank you for helping me" 用动名词（-ing）；瑞典语 "tack för att du hjälpte" 用 att + 完整从句（bisats）。

## 详细讲解 (Detail)

- `tack för att` 引导一个 att-从句（bisats）
- att-从句里动词用 preteritum（过去时），因为动作在感谢之前发生
- `för att` 这里是 `för + att`（介词+连词），不是表目的的 `för att + infinitiv`
- 有时也可用 perfekt：`tack för att du har hjälpt mig`（感谢你帮助了我），两者均正确

## 例句 (Examples)

- ✅ [[sent-tack-för-att-ni-kallade-mig-till-intervju]] 🇸🇪 Tack för att ni kallade mig till intervju. 🇨🇳 感谢您邀请我来面试。
- ✅ 🇸🇪 Tack för att du kom på festen. 🇨🇳 感谢你来参加派对。
- ❌ Tack för att du hjälper mig. ← 动词应用过去时，不用现在时

## 常见错误 (Common Mistakes)

- ⚠️ 不要用现在时：Tack för att du **hjälper** → 应为 Tack för att du **hjälpte**
- ⚠️ 不要用不定式：Tack för att **hjälpa** → 应为 Tack för att du **hjälpte**
