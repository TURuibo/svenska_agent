# 📗 en-ord och ett-ord — en词与ett词（共性 vs 中性） (common vs neuter gender)

级别: A2
一句话: ett 词在不定单数时形容词加 -t：brutet, svullet, blått, stort, rakt, djupt, modernt, blekt。

## 规则说明 (Rules)

名词分 en 词（共性 utrum）与 ett 词（中性 neutrum）。修饰 ett 词不定单数的形容词要加 -t：
ett brutet ben / ett stort öra / ett blått öga / ett modernt sjukhus。

## 例句 (Examples)

- ✅ [[sent-ett-brutet-ben]] 🇸🇪 ett brutet ben → det brutna benet → brutna ben → de brutna benen 🇨🇳 骨折的腿
- ✅ [[sent-ett-svullet-knä]] 🇸🇪 ett svullet knä → det svullna knäet → svullna knän → de svullna knäna 🇨🇳 肿的膝盖
- ✅ [[sent-ett-friskt-hjärta]] 🇸🇪 ett friskt hjärta → det friska hjärtat → friska hjärtan → de friska hjärtana 🇨🇳 健康的心脏
- ✅ [[sent-ett-blått-öga]] 🇸🇪 ett blått öga → det blå ögat → blå ögon → de blå ögonen 🇨🇳 蓝眼睛
- ✅ [[sent-ett-stort-öra]] 🇸🇪 ett stort öra → det stora örat → stora öron → de stora öronen 🇨🇳 大耳朵
- ✅ [[sent-ett-rakt-hår]] 🇸🇪 ett rakt hår → det raka håret → raka hår → de raka håren 🇨🇳 直发
- ✅ [[sent-ett-djupt-sår]] 🇸🇪 ett djupt sår → det djupa såret → djupa sår → de djupa såren 🇨🇳 深的伤口
- ✅ [[sent-ett-modernt-sjukhus]] 🇸🇪 ett modernt sjukhus → det moderna sjukhuset → moderna sjukhus → de moderna sjukhusen 🇨🇳 现代化的医院
- ✅ [[sent-ett-blekt-ansikte]] 🇸🇪 ett blekt ansikte → det bleka ansiktet → bleka ansikten → de bleka ansiktena 🇨🇳 苍白的脸
