# 📗 även om (jfr trots att) — koncessiva bisatser — 让步从句：即使／尽管 (concessive clauses)

级别: SFI C/D · B1
一句话: "även om" 引导让步 bisats，说明"即使发生 X，Y 依然成立"，遵循 bisats 词序。

## 规则说明 (Rules)

📐 结构公式:
```
Även om + [subjekt + (inte) + verb + ...],  huvudsats (V2: verb-subjekt om bisatsen står först)
huvudsats,  även om + [subjekt + (inte) + verb + ...]   (om huvudsatsen står först, ingen extra inversion)
```

与中文对比: 中文"即使/尽管...，也/还是..." — 结构类似，但瑞典语的 bisats 内部词序固定（satsadverbial 如 "inte" 必须在动词前）。
与英文对比: "even if / even though" — 英语从句词序与主句相同；瑞典语的 bisats 词序与主句不同（inte 前置）。

## 详细讲解 (Detail)

- "även om" 比 [[grammar-trots-att]] 语气更开放：既可表示"即使（假设）"，也可表示"尽管（事实）"，而 "trots att" 通常指已确定发生的事实。
- 当让步 bisats 放在句首（作为 fundament）时，紧随其后的 huvudsats 必须使用 V2 语序，即动词紧跟在逗号之后、主语之前的倒装：
  "Även om vi pratar om svensk kultur, **finns det** traditioner som inte delas..."
- Bisats 内部词序：satsadverbial（如 inte）位于主语和动词之间，而非动词之后（这是与 huvudsats 最大的区别）。

## 例句 (Examples)

- ✅ [[sent-även-om-vi-pratar-om-svensk]] 🇸🇪 Även om vi pratar om svensk kultur finns det traditioner som inte delas av hela befolkningen. 🇨🇳 即使我们谈瑞典文化，也有一些传统并非全体人口共享。
- ✅ 🇸🇪 Även om det regnar går vi ut och promenerar. 🇨🇳 即使下雨我们也出去散步。
- ❌ Även om vi pratar inte om svensk kultur... ← 常见错误（bisats 中 inte 应在动词前："även om vi **inte** pratar om..."）

## 常见错误 (Common Mistakes)

- ⚠️ 把 huvudsats 词序（inte 放在动词后）误用在 bisats 里。
- ⚠️ 忘记在让步 bisats 作为 fundament 时，huvudsats 要倒装（V2）。
