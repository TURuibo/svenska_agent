# 📗 prepositioner-rum — 空间介词 (spatial prepositions)

级别: CEFR A1-A2
一句话: 瑞典语空间介词描述物体的位置关系；最常见的有 på, i, under, över, mellan, vid, bredvid, framför, bakom, mitt emot, längs, mitt i。

## 规则说明 (Rules)

📐 结构公式:
```
[位置动词] + [空间介词] + [名词（通常为定形）]
```

| 介词 | 中文 | 典型搭配 |
|------|------|---------|
| **på** | 在……上面（表面接触） | *på bordet* / *på väggen* |
| **i** | 在……里面 | *i rummet* / *i hörnet* / *i bokhyllan* |
| **under** | 在……下面 | *under sängen* / *under fönstret* |
| **över** | 在……上方（不接触） | *lampan hänger över bordet* |
| **mellan** | 在……之间 | *mellan sängen och skrivbordet* |
| **vid** | 靠近；在……旁边 | *vid väggen* / *vid dörren* |
| **bredvid** | 紧靠；在……旁边 | *bredvid sängen* |
| **framför** | 在……前面 | *framför skrivbordet* |
| **bakom** | 在……后面 | *bakom soffan* |
| **mitt emot** | 正对面 | *mitt emot sängen* |
| **längs** | 沿着；靠着 | *längs väggen* |
| **mitt i** | 在……中央 | *mitt i rummet* |
| **runt** | 围绕；在……周围 | *runt fontänen* |
| **utanför** | 在……外面 | *utanför kaféet* |
| **till höger om** | 在……右边 | *till höger om parken* |
| **till vänster om** | 在……左边 | *till vänster om banken* |

与中文对比: 中文的"在……上/里/旁/前/后"对应不同的瑞典语介词；"在墙上"= *på väggen*（表面），"在房间里"= *i rummet*（内部）。
与英文对比: 大致类似，但 *på väggen*（英语 on the wall）= 在墙上，而 *i rummet* = in the room。

## 详细讲解 (Detail)

**på vs i 辨析：**
- `på` = 表面（物体在某表面上）：*på bordet*（在桌面上）, *på väggen*（在墙面上）
- `i` = 内部（物体在某空间内）：*i rummet*（在房间里）, *i hörnet*（在角落里）, *i bokhyllan*（在书架上/书架的格子里）

**vid vs bredvid 辨析：**
- `vid` = 靠近（较宽泛的"在……附近"）：*vid väggen*（靠墙）, *vid dörren*（门口）
- `bredvid` = 紧靠旁边（英语 next to）：*bredvid sängen*（紧靠床边）

**till höger om / till vänster om：**
- 必须加 `om` + 参照物：*till höger om soffan*（沙发右边）
- 省略 `om` 是常见错误：~~*till höger soffan*~~

## 例句 (Examples)

- ✅ [[sent-sangens-star-langs-vaggen-under-sangen]] 🇸🇈 Sängen står **längs** väggen, och **under** sängen ligger ett par skor. 🇨🇳 床靠墙摆放，床下躺着几双鞋。
- ✅ [[sent-bredvid-sangen-star-ett-litet-nattduksbord]] 🇸🇈 **Bredvid** sängen står ett litet nattduksbord. 🇨🇳 床边站着一张小床头柜。
- ✅ [[sent-i-hornet-till-vanster-om-dorren-star-kladskap]] 🇸🇈 **I** hörnet **till vänster om** dörren står ett klädskåp. 🇨🇳 门左边的角落里立着一个衣柜。
- ✅ [[sent-pa-golvet-mellan-sangen-skriv-stor-matta]] 🇸🇈 **På** golvet, **mellan** sängen och skrivbordet, ligger en stor matta. 🇨🇳 床和书桌之间的地板上铺着一块大地毯。
- ✅ [[sent-framfor-fonster-vid-vaggen-stor-krukvaxt]] 🇸🇈 **Framför** fönstret, **vid** väggen, står en stor krukväxt. 🇨🇳 窗户前面，靠墙的地方，立着一棵大盆栽植物。
- ✅ [[sent-mitt-emot-parken-pa-andra-sidan-gatan-livsmedelsbutik]] 🇸🇈 **Mitt emot** parken, **på andra sidan** gatan, ligger en stor livsmedelsbutik. 🇨🇳 公园对面，街道另一侧，是一家大型食品超市。
- ✅ [[sent-langs-parken-vaxer-hoga-trad-sitter-man-tidning]] 🇸🇈 **Längs** parken **växer** höga träd. 🇨🇳 沿着公园生长着高大的树木。
- ❌ *till höger soffan* ← 漏掉 `om`，正确：*till höger **om** soffan*

## 常见错误 (Common Mistakes)

- ⚠️ *på rummet* ← 应用 `i rummet`（房间是内部空间，不是表面）
- ⚠️ *i bordet* ← 应用 `på bordet`（在桌子表面上）
- ⚠️ *till höger soffan* ← 漏掉 `om`：应说 *till höger om soffan*
