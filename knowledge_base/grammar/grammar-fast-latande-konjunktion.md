# fast — 让步连词（concessive conjunction）

## 核心用法

`fast` 在口语中常作**让步连词**，相当于 `även om`（即使）或 `fastän`（虽然）。

```
Fast + bisats, + huvudsats.
Huvudsats, fast + bisats.
```

## `fast` 的三种词性

| 词性 | 用法 | 例句 |
|------|------|------|
| 连词（让步）| "虽然" | `Fast det var svårt, lyckades han.` |
| 副词 | "牢牢地；固定地" | `Det sitter fast.`（卡住了）|
| 形容词 | "牢固的；坚定的" | `ett fast beslut`（坚定的决定）|

## 让步连词用法详解

**① `fast` + bisats 在句首（bisats 语序！）**
```
Fast söndagen var grå, var vi glada.
（虽然周日天气阴沉，我们依然很开心。）
```

**② `fast` + bisats 在句末（主句正常语序）**
```
Vi var glada, fast söndagen var grå.
（我们很开心，虽然周日天气阴沉。）
```

## bisats 语序提醒

`fast` 引导从句，从句语序：`S + (adv) + V + O`，负词 `inte` 在动词前。
```
Fast hon inte förstod svenska, försökte hon.
（虽然她不懂瑞典语，她还是努力了。）
```

## 与 `även om` / `fastän` 的区别

| 连词 | 语域 | 备注 |
|------|------|------|
| `fast` | 口语 | 最常用，非正式 |
| `fastän` | 书面/正式 | 更传统，写作用 |
| `även om` | 中性 | 也可口语 |
