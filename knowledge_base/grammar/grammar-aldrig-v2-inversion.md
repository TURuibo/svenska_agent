# 📗 aldrig + V2-topikalisering — 否定词 aldrig 引发的主谓倒装（强调语气）

级别: B1
一句话: 当话题（非主语）前置时，动词保持 V2 位置，`aldrig` 等否定词加强禁止语气。

## 规则说明 (Rules)

📐 结构公式:
```
[话题/宾语/状语] + V(动词) + 主语 + aldrig + ...
```

与中文对比: 中文"危险废品绝不能放进普通垃圾桶"——语序与瑞典语相近，`绝不` 对应 `aldrig`。
与英文对比: 英文通常不强制倒装，"You never put hazardous waste in regular bins"；瑞典语话题前置时 V2 是硬性规则。

## 详细讲解 (Detail)

瑞典语遵守 **V2 规则**：无论句子以什么元素开头，有限动词（finite verb）必须排在句中第二位。

当句子以**非主语成分**（话题、宾语、状语等）开头时，主语会被"推后"到动词之后。若谓语部分还含有否定词 `aldrig`（永远不）、`inte`（不）等，否定词紧跟在主语之后（在 satsadverbial 位置），进一步强化否定语气。

**示例分析：**
```
Farligt avfall  lämnar    du      aldrig    i vanliga sopor.
   话题（宾语）    V2(动词)  主语    否定satsadv   介词短语
```
→ "危险废品，你绝不能放进普通垃圾桶。"

**相比普通否定句：**
```
Du lämnar aldrig farligt avfall i vanliga sopor.  (普通主谓序)
Farligt avfall lämnar du aldrig i vanliga sopor.  (话题前置，强调)
```
话题前置版强调"危险废品"这个主题，更有警示感。

## 例句 (Examples)

- ✅ [[sent-farligt-avfall-lämnar-du-aldrig]] 🇸🇪 Farligt avfall lämnar du aldrig i vanliga sopor. 🇨🇳 危险废品绝不能放进普通垃圾桶。
- ✅ 🇸🇪 Det lämnar vi aldrig obesvarat. 🇨🇳 那个我们绝不会置之不理。
- ❌ *Farligt avfall du lämnar aldrig i vanliga sopor.* ← 话题前置后忘了倒装

## 常见错误 (Common Mistakes)

- ⚠️ 话题前置后忘记 V2 倒装：以非主语开头时，动词必须紧随其后
- ⚠️ 把 `aldrig` 放在动词前：`aldrig` 是 satsadverbial，应在主语之后
