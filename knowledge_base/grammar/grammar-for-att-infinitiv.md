# för att-infinitiv — för att + 不定式（purpose infinitive）

级别: A2
一句话: *för att* + 动词不定式表示目的（为了做某事），相当于中文"为了……"。

## 规则说明 (Rules)

📐 结构公式:
```
[主句] + för att + [动词原形]
  ↑行为           ↑目的
```

与中文对比: 中文"为了"+ 动词 ≈ 瑞典语 *för att* + 不定式，结构非常相似。
与英文对比: 英文 *in order to* / *to*（目的不定式）。瑞典语必须用 *för att*，不能只用 *att*（那是 att-从句的标志）。

## 详细讲解 (Detail)

- *för att* 是两个词合并的目的连词，后接动词原形（不加 *att* 的 infinitiv）。
- 否定目的：*för att inte* + 动词原形（为了不……）。
- 主句和目的状语的主语通常相同。如果主语不同，改用 *så att* + 从句。

**常用句型：**
```
Man klär på sig tjocka jackor för att hålla värmen.
    ↑主句行为                    ↑目的（为了保暖）
```

## 例句 (Examples)

- ✅ [[sent-man-klar-pa-sig-tjocka-jackor]] 🇸🇪 Man klär på sig tjocka jackor och stövlar för att hålla värmen. 🇨🇳 人们穿上厚夹克和靴子，为了保暖。
- ✅ 🇸🇪 Jag studerar svenska för att kunna arbeta i Sverige. — 🇨🇳 我学瑞典语是为了能在瑞典工作。
- ✅ 🇸🇪 Han tränar varje dag för att bli starkare. — 🇨🇳 他每天训练，为了变得更强。
- ❌ *Jag äter för bli stark.* ← 错误：必须用 *för att* 而不是单独 *för*。

## 常见错误 (Common Mistakes)

- ⚠️ 不能只用 *att* 表达目的：*Jag gick dit att hjälpa.* 是错误的，应该是 *för att hjälpa*。
- ⚠️ 如果目的状语的主语与主句不同，要改用 *så att* + 从句：*Jag talar långsamt så att du förstår.*
