# 📗 istället för att + infinitiv — 而不是做…… (instead of doing)

级别: B1
一句话: `istället för att + infinitiv` 表示"做某事而不是做另一件事"。

## 规则说明 (Rules)

📐 结构公式:
```
… istället för att + infinitiv-verb …
```

与中文对比: 相当于中文"而不是……"。
与英文对比: 相当于英语 "instead of doing"（英语后接 -ing 形式，瑞典语后接 att + infinitiv）。

## 详细讲解 (Detail)

- `istället för` 单独接名词（istället för kaffe），接动词时必须加 `att`：`istället för att sjunga`。

## 例句 (Examples)

- ✅ 🇸🇪 Vi gör något tillsammans istället för att alla sitter själva med sin bok. 🇨🇳 我们一起做一件事，而不是各自捧着书读。
- ✅ 🇸🇪 Han cyklade till jobbet istället för att ta bussen. 🇨🇳 他骑自行车去上班，而不是坐公交车。
- ❌ istället för sjunga ← 缺少 att

## 常见错误 (Common Mistakes)

- ⚠️ 忘记加 `att`：动词前必须有 `att`。
