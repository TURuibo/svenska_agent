# 📗 bisats-biff — 从句语序（BIFF 规则）(subordinate clause word order)

级别: B1
一句话: 在从句（bisats）中，否定词/副词紧跟在主语之后、动词之前（BIFF = Bisatsen Inte Före Finitverbet）。

## 规则说明 (Rules)

📐 结构公式:
```
主句 (V2):  Subjekt  VERB        Adverb  ...
             Jag      vet         inte    var det är.
从句 (BIFF): (att)    Subjekt  Adverb  VERB    ...
             att      jag      inte    vet     ...
             när      jag      kommer  till    Slussen
```

BIFF 记忆法：**B**isatsen **I**nte **F**öre **F**initverbet = 从句中否定词/副词在动词之前。

与中文对比: 中文语序不受主从句影响（都是"我不知道"）；瑞典语从句需变换 inte 位置。
与英文对比: 英语从句语序不变（I don't know where it is）；瑞典语从句 inte 必须前移。

## 详细讲解 (Detail)

触发从句语序的连词（bisatsinledare）：
- `att` — that（我知道他来了）
- `när` — when（当我到达时）
- `om` — if/whether（如果/是否）
- `var` — where（在哪里）
- `hur` — how（怎样）
- `eftersom` — because
- `som` — that/which/who

例：
- 主句：*Jag vet **inte** var det är.* ← `inte` 在主句中跟 `vet` 后面→ 不，这里 `vet` 是主句动词，`var det är` 是从句
- 从句内部：*var **det** är*（从句中 det 是主语，är 是动词，无需移位，因为无否定词）

实际从对话的例子：
- `när jag kommer till Slussen` — 当我到达 Slussen 时（bisats，语序 S-V）
- `Vet du var det är?` — 你知道那在哪里吗？（`var det är` 是 bisats：var + det(S) + är(V)）

## 例句 (Examples)

- ✅ [[sent-vet-du-var-det-ar]] 🇸🇪 Vet du var det är? 🇨🇳 你知道在哪里吗？
- ✅ [[sent-vilken-riktning-ska-jag-ga]] 🇸🇪 Vilken riktning ska jag gå? 🇨🇳 我该往哪个方向走？（疑问词从句）
- ❌ *Jag vet var är det.* ← 从句不用疑问语序（不能用 V2 倒装）

## 常见错误 (Common Mistakes)

- ⚠️ 从句中用疑问语序：*Jag vet inte var är det.* → 正确：*Jag vet inte var det är.*
- ⚠️ 主从句混淆 `inte` 位置：主句 *Jag vet **inte**…* vs 从句中 *…att jag **inte** vet…*
