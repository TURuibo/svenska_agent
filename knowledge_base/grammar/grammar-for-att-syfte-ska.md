# 📗 för att + ska (syfte) — för att + ska 表目的 ("för att" introducing a purpose clause with "ska")

级别: B1
一句话: 当目的从句的主语与主句主语**不同**时，"för att" 后接一个完整的**从句**（带 `ska`），而不是不定式。

## 规则说明 (Rules)

📐 结构公式:
```
主句 + för att + [从句主语] + ska + 动词原形 (+ 其余成分)
Jag börjar baka tidigt för att brödet ska vara klart när kunderna kommer.
```

与中文对比: 中文"为了让……"同样需要给出新的主语（"为了让面包在顾客来时准备好"）。
与英文对比: 英语用 "so that + subject + will/can" 表达同样的意思：
"I start baking early **so that** the bread **will** be ready when customers arrive."

## 详细讲解 (Detail)

- 对比 [[grammar-for-att-syfte]]：当目的从句主语与主句主语**相同**时，用 `för att` + 不定式（无 att）：
  - ✅ Jag studerar svenska för att hitta ett jobb.（Jag = 找工作的人，同主语 → 不定式）
- 当主语**不同**时，必须用 `för att` + **带 ska 的完整从句**：
  - ✅ Jag börjar baka tidigt **för att brödet ska vara klart**.（Jag ≠ brödet，不同主语 → för att + 从句 + ska）
- `ska` 在这类目的从句中几乎是固定搭配，表达"意图使……发生"，而不是简单现在时。
- 从句语序遵循 bisats（从句）语序：`för att + 主语 + ska + 动词`（非 V2）。

## 例句 (Examples)

- ✅ [[sent-degen-måste-jäsa-hela-natten]] 🇸🇪 Jag börjar baka tidigt för att brödet ska vara klart när kunderna kommer. 🇨🇳 我很早就开始烤，好让顾客来的时候面包已经准备好了。
- ✅ 🇸🇪 Hon viskade för att ingen skulle höra henne. 🇨🇳 她小声说话，为了不让任何人听到她。
- ✅ 🇸🇪 Vi stänger dörren för att katten inte ska komma ut. 🇨🇳 我们把门关上，好让猫不跑出去。
- ❌ *Jag börjar baka tidigt för att brödet vara klart.* ← 错误：从句需要 `ska`，不能直接用不定式

## 常见错误 (Common Mistakes)

- ⚠️ 主语不同却错误使用不定式（漏掉 `ska` 和新主语）。
- ⚠️ 从句语序错误：应为 `för att brödet ska vara`，不是 `för att brödet vara ska`。
