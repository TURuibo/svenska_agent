# 📗 relativ bisats med som — som引导的关系从句 (relative clause with 'som')

级别: A2
一句话: 瑞典语用 **som** 引导关系从句，**放在被修饰名词之后**，与中文的前置定语顺序相反。

## 规则说明 (Rules)

📐 结构公式:
```
名词 + som + [关系从句（主语/宾语由 som 充当）]
```

例：
```
vuxna  som  lyssnar  på deras berättelser
  ↑          ↑
被修饰词   som 既做连接词，又作从句的主语（those adults who listen）
```

与中文对比:
- 🇨🇳 **倾听他们的**大人（定语前置）
- 🇸🇪 vuxna **som lyssnar på dem**（定语后置）
- 关键差异：瑞典语关系从句**永远后置**于被修饰名词。

与英文对比: 与英语 "who/that/which" 结构相同，区别在于瑞典语统一用 **som**（不区分人/物/主格/宾格）。

## 详细讲解 (Detail)

**som 可以做从句中的：**

| 角色 | 例子 | 说明 |
|------|------|------|
| 主语 | en plan **som** fungerar | som 作从句主语（一个有效的计划） |
| 宾语 | nåt **som** jag tyckte | som 作从句宾语（我认为的某事） |

**省略 som（非正式口语）：**
在非正式口语中，当 som 作宾语时常被省略：
- 正式：nåt **som** jag tyckte hon hade fel om
- 口语：nåt [som省略] jag tyckte hon hade fel om

## 例句 (Examples)

- ✅ [[sent-barn-och-unga-behover-mota-vuxna]] 🇸🇪 vuxna **som** lyssnar på deras berättelser 🇨🇳 倾听他们故事的大人
- ✅ [[sent-jag-och-storasyrran-borjade-tjafsa]] 🇸🇪 nåt jag tyckte hon hade helt fel om 🇨🇳 我认为她完全搞错了的那件事（省略了som）
- ❌ *de vuxna lyssnar* (省略som同时保留名词，中文式前置，错误)

## 常见错误 (Common Mistakes)

- ⚠️ 中文学习者常把修饰语放在名词前：*det *lyssnande* vuxna* ← 错误（如果是完整从句必须后置）
- ⚠️ 混淆 **som**（关系代词）和 **som**（比较连词：Han är lika gammal **som** jag = He is as old as me）
