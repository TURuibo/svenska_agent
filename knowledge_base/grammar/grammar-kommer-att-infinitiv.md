# 📗 kommer att + infinitiv — 将来时（预期/自然将来）(Future with 'kommer att')

级别: A2
一句话: 用 `kommer att + 动词原形` 表达"（预期/按自然发展）将会发生"的事，语气比 `ska` 更中立客观。

## 规则说明 (Rules)

📐 结构公式:
```
主语 + kommer att + 动词原形（infinitiv）
Antalet döda  kommer att  öka.
死亡人数      将会         增加。
```

与中文对比:
- 中文用"会/将会"表将来，瑞典语有两种主要方式：`ska` 和 `kommer att`

与英文对比:
- `kommer att` ≈ "will" / "is going to"（客观预期）
- `ska` ≈ "will"（意愿/计划/传说）

## 详细讲解 (Detail)

### kommer att vs. ska

| 结构 | 语义重心 | 典型语境 |
|------|---------|---------|
| `kommer att` | 预期自然发生，客观推断 | 新闻预测、天气预报、研究结论 |
| `ska` | 意愿、计划、安排 | 个人计划、规则要求、传闻转述 |

- `Antalet döda **kommer att** öka.` — 死亡人数将会增加（客观预期，记者/专家用语）
- `Jag **ska** resa till Sverige.` — 我要去瑞典（个人计划/意愿）

### 否定形式
```
kommer inte att + infinitiv
Det kommer inte att regna imorgon.  明天不会下雨。
```

### 常见副词插入位置
副词（troligtvis, säkert, antagligen）可插在 `att` 与动词之间：
```
Antalet döda kommer troligtvis att öka mycket.
死亡人数很可能还会大幅增加。
```

## 例句 (Examples)

- ✅ [[sent-antalet-doda-kommer-troligtvis-att-oka]] 🇸🇪 Antalet döda kommer troligtvis att öka mycket. 🇨🇳 死亡人数很可能还会大幅增加。
- ✅ 🇸🇪 Det kommer att bli varmt i helgen. 🇨🇳 周末将会很热。
- ✅ 🇸🇪 Imorgon kommer det att regna i norr. 🇨🇳 明天北部将会下雨。
- ❌ *Jag kommer att vilja gå dit.* ← 意愿动词不与 `kommer att` 组合，改用 `vill gå dit`

## 常见错误 (Common Mistakes)

- ⚠️ 省略 `att`：*Jag kommer gå dit.* — 在瑞典语中这是错误的（英语 "I'm going to go" 影响）；必须说 `kommer att gå`
- ⚠️ 混淆 `ska` 和 `kommer att`：新闻中描述"预计发生"的事用 `kommer att` 更自然
