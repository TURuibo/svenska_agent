# 📗 vilja + infinitiv — vill + 动词原形（不加 att）表示“想要做” (want + infinitive)

级别: A2
一句话: 模态动词 vill 后面直接接动词原形，中间**不加** att。

## 规则说明 (Rules)

📐 结构公式:
```
Jag/Du/Han... + vill + [infinitiv]
```
例：Jag vill resa. (不是 "Jag vill att resa")

与中文对比: 类似中文"我想 + 动词"，动词直接跟在"想"后面。
与英文对比: 类似英语 "want to + verb"，但瑞典语**没有相当于 "to" 的 att**。

## 详细讲解 (Detail)

vilja 是模态助动词（modalt hjälpverb），后面直接跟不带 att 的动词原形（bar infinitiv）。
这与 "hoppas att" "tycka att" 等接 att-sats 的动词不同。

## 例句 (Examples)

- ✅ [[sent-jag-vill-resa-och-upptacka-nya-platser]] 🇸🇪 Jag vill resa och upptäcka nya platser. 🇨🇳 我想旅行、探索新的地方。
- ✅ [[sent-jag-vill-bidra-till-en-battre-varld]] 🇸🇪 Jag vill bidra till en bättre värld. 🇨🇳 我想为一个更好的世界做贡献。
- ❌ Jag vill att resa. ← 常见错误（多加了 att）

## 常见错误 (Common Mistakes)

- ⚠️ 在 vill 后面误加 "att"：应为 "vill resa" 而非 "vill att resa"。
