# 📗 ju-desto-konstruktion — ju…desto + 比较级 (the more … the more)

级别: SFI C / CEFR B1
一句话: ju + 比较级 + 从句，desto + 比较级 + 主句，表示「越……越……」。

## 规则说明 (Rules)

📐 结构公式:
```
Ju + 比较级 (+ 主语 + 动词), desto + 比较级 + 主句 (正常 V2)
Ju fler som cyklar, desto färre bilar blir det.
```

与中文对比: 「越……越……」，两部分对称；瑞典语两处都要用比较级。
与英文对比: the more …, the more … ；ju = the（从句），desto = the（主句）。

## 详细讲解 (Detail)

- ju 部分是 bisats：动词在主语之后（Ju fler människor som cyklar）。
- desto 之后是主句，因 desto + 比较级 是句首成分，主句动词紧随其后。
- 口语中 desto 可换成 ju 或 så：*Ju förr, desto bättre* / *ju förr, ju bättre*。

## 例句 (Examples)

- ✅ [[sent-ju-fler-människor-som-cyklar-desto]] 🇸🇪 Ju fler människor som cyklar, desto färre bilar blir det på gatorna. 🇨🇳 骑车的人越多，街上的汽车就越少。
- ❌ Ju mer sover du, desto bättre mår du ← 应为 Ju mer du sover …

## 常见错误 (Common Mistakes)

- ⚠️ 忘记用比较级（✗ Ju bra, desto bra）。
- ⚠️ ju 从句里主语在动词前。
