# för ... sedan — 时间表达（多久以前）

## 核心结构

```
för + [siffra] + [tidsenhet] + sedan
```

| 时间 | 例句 |
|------|------|
| 3年前 | `för tre år sedan` |
| 6个月前 | `för sex månader sedan` |
| 一周前 | `för en vecka sedan` |
| 两天前 | `för två dagar sedan` |
| 一小时前 | `för en timme sedan` |

## 时间三角对比

| 表达 | 含义 | 例句 |
|------|------|------|
| `för ... sedan` | 多久以前（过去）| `Hon kom för tre år sedan.` |
| `i + period` | 持续多长时间 | `Hon har bott här i tre år.` |
| `om + period` | 多久以后（未来）| `Hon åker om tre månader.` |

## 语法提示

- 固定结构：`för` 在前，`sedan` 在末尾，中间插入时间量
- `sedan` 也可以单独作连词（"然后；自从"），注意区分
- 过去时时态：`för ... sedan` 通常与 preteritum（过去时）连用

## 例句

- För tre år sedan kom hon till Sverige för första gången. — 三年前，她第一次来到瑞典。
- Jag lärde mig svenska för fem år sedan. — 我五年前学了瑞典语。
- Det hände för precis en vecka sedan. — 那是恰好一周前发生的事。
