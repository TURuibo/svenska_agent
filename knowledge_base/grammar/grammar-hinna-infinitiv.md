# 📗 hinna + infinitiv — hinna + 不定式（来得及做某事）

级别: A2
一句话: `hinna` + 动词原形表示"时间上来得及/有时间做某事"。

## 规则说明 (Rules)

📐 结构公式:
```
hinner/hann/hunnit + [infinitiv utan att]

hinner + ses     → 来得及见面
hann + äta       → 来得及吃
har hunnit + gå  → 已经来得及走了
```

与中文对比: 中文用"来得及"或"有时间"，是分开的短语；瑞典语用一个动词 `hinna` 表达。
与英文对比: 类似英语 "manage to", "have time to" 或 "make it to"，但 `hinna` 更简洁。

## 详细讲解 (Detail)

**变形（第四类强变化动词）:**
| form | Swedish |
|------|---------|
| infinitiv | hinna |
| presens | hinner |
| preteritum | hann |
| supinum | hunnit |

**否定：**
- `hinner inte` = 来不及，没时间
- `hann inte` = 来不及了（过去式）

**常见用法：**
- `hinna med tåget` — 赶上火车
- `hinna äta` — 来得及吃
- `hinna ses` — 有时间见面（注意 ses = 互动动词）
- `Hinner du?` — 你来得及吗？

## 例句 (Examples)

- ✅ [[sent-det-är-kul-att-vi-äntligen-hann-ses]] 🇸🇪 Det är kul att vi äntligen hann ses! 🇨🇳 很高兴我们终于有时间见面了！
- ✅ 🇸🇪 Hinner du med bussen? 🇨🇳 你赶得上公车吗？
- ✅ 🇸🇪 Jag hann inte äta frukost imorse. 🇨🇳 我今早来不及吃早饭。
- ❌ *Jag hann att äta* ← `hinna` 后直接加动词原形，不用 `att`

## 常见错误 (Common Mistakes)

- ⚠️ 在 `hinna` 后加 `att`：正确是 `hinna äta`，不是 `hinna att äta`。
- ⚠️ 混淆 `hinna` 和 `kunna`：`hinner` = 时间上来得及；`kan` = 能力上能做到。
