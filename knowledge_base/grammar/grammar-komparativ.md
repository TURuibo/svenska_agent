# komparativ — 比较级 (comparative)

级别: A2
一句话: 瑞典语比较级通常在形容词后加 *-are*；不规则形容词另有形式。

## 规则说明 (Rules)

📐 结构公式:
```
形容词原级 + -are  →  比较级
ljus  → ljusare   (更亮)
sval  → svalare   (更凉)
lång  → längre    (更长, 不规则)
```

与中文对比: 中文用"更……"表达比较级；瑞典语直接在词尾加 *-are*。
与英文对比: 英文短词加 *-er*（brighter），长词加 *more*；瑞典语几乎总是加 *-are*，无论词长。

## 详细讲解 (Detail)

**规则变化（大多数形容词）:**
- 加 *-are*：ljus → ljusare，sval → svalare，tydlig → tydligare

**注意 *-el / -en / -er* 结尾的形容词去掉末音节 e：**
- enkel → enklare（更简单的）

**不规则比较级（需记忆）:**
| 原级 | 比较级 | 最高级 |
|------|--------|--------|
| bra / god | bättre | bäst |
| dålig / illa | sämre / värre | sämst / värst |
| liten | mindre | minst |
| stor | större | störst |
| gammal | äldre | äldst |
| lång | längre | längst |
| ung | yngre | yngst |

**比较级的格位（kongruens）:**
比较级形式不随性别/数变化，所有名词（en/ett/plural）都用同一比较级形式。

**"比……更"的表达：**
```
A + [比较级形容词] + än + B
Sommaren är varmare än hösten.  夏天比秋天热。
```

## 例句 (Examples)

- ✅ [[sent-nar-varen-kommer-borjar-dagarna]] 🇸🇪 Dagarna bli ljusare. 🇨🇳 白天变得更亮。
- ✅ [[sent-det-blir-svalare-och-regnet]] 🇸🇪 Det blir svalare och regnet återkommer. 🇨🇳 天气变得更凉爽，雨水重新降临。
- ✅ 🇸🇪 Hon är längre än sin bror. — 🇨🇳 她比她哥哥高。
- ❌ *Det är mer ljusare.* ← 错误：不能 *mer* + 比较级叠加使用。

## 常见错误 (Common Mistakes)

- ⚠️ 不要在比较级前加 *mer*（类比英语 *more brighter*），瑞典语直接用 *-are* 形式。
- ⚠️ 不规则比较级（如 *bättre, fler, längre*）需要单独记忆。
