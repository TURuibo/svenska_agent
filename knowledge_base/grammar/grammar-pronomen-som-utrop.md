# 📗 Pronomen + som … (utrop) — 感叹式片段

级别: SFI C / CEFR B1
一句话: “Jag som aldrig …” 是一个**没有主句的 som-从句**，表示“我这个从来没……的人（居然……）”，带惊讶、反差、自嘲。

## 规则说明 (Rules)

📐 结构公式:
```
人称代词 (Jag/Du/Han…) + som + [副词] + 动词 (…).
Jag som aldrig satt min fot på ett gym.
```

与中文对比: “我这个从没……的人，（竟然……）”。
与英文对比: Me, who never set foot in a gym (and now …)!

## 详细讲解 (Detail)

- som 引导**限定关系从句**，修饰前面的代词；主句被省略，意义由上下文补足（“……却买了健身卡”）。
- 从句内遵循 bisats 语序：主语 som 之后，副词 aldrig 在动词**前**（→ [[grammar-bisats-ordfoljd]]）。
- 常见开头：`Jag som …`, `Du som …`, `Vi som …`；也作为正式的关系结构：`Vi som bor här …`。
- 动词时态：本例 satt（preteritum）口语中代替 har aldrig satt / aldrig hade satt。

## 例句 (Examples)

- ✅ [[sent-jag-som-aldrig-satt-min-fot-på-ett-gym]] 🇸🇪 Jag som aldrig satt min fot på ett gym. 🇨🇳 我这个从没进过健身房的人。
- ✅ 🇸🇪 Du som alltid kommer sent! 🇨🇳 你这个总是迟到的人！
- ❌ Jag som satt aldrig … ← bisats 里副词应在动词前。

## 常见错误 (Common Mistakes)

- ⚠️ 把它当完整句子，误以为缺动词；它是有意省略主句。
- ⚠️ 在 som 从句中用主句语序（V2）。
