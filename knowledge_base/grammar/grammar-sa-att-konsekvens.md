# 📗 så ... att (konsekvens) — 如此……以至于…… (so ... that)

级别: SFI C/B1
一句话: så + adjektiv/adverb ... att + bisats，表达程度导致的结果（结果状语从句）。

## 规则说明 (Rules)

📐 结构公式:
```
subjekt + verb + så + adjektiv + att-bisats
Hans självbild var så starkt förknippad med ... att han förlorade sin identitet.
```

与中文对比: 完全对应"如此……以至于……"。
与英文对比: 完全对应 "so ... that ...".

## 详细讲解 (Detail)

- att-bisats 使用 bisats-ordföljd（若有 inte，放在动词前）。
- 常与 starkt, mycket, väldigt 等程度副词搭配。

## 例句 (Examples)

- ✅ [[sent-hans-självbild-var-så-starkt]] 🇸🇪 Hans självbild var så starkt förknippad med att vara idrottsman att han förlorade sin identitet. 🇨🇳 他的自我形象与运动员身份绑得太紧，以至于失去了自我认同。
- 🇸🇪 Det var så kallt att vi var tvungna att stanna inomhus. 🇨🇳 天气太冷了，我们不得不待在室内。
- ❌ Han var så trött han somnade direkt. ← 缺少 att，应为 "så trött att han somnade"

## 常见错误 (Common Mistakes)

- ⚠️ 漏掉连接词 att。
