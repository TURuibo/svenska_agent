# 📗 Informellt brev med tips och råd — 非正式建议信结构

级别: SFI B / A2
一句话: 问候 → 回应前信 → 建议 → 鼓励 → 结束语（Kram,）。

## 规则说明 (Rules)

📐 结构公式:
```
Till: / Ämne:
1. Hälsningsfras      Hej Elin!
2. Inledning          knyta an till tidigare brev (Vad bra att …! / Vad spännande att …!)
3. Råd                Du kan … / Du skulle kunna … / Har du provat att …?
4. Uppmuntran         Lycka till! Jag vet att du kommer att klara det!
5. Avslutningsfras    Kram, <namn>
```

与中文对比: 中文信也常"问候—回应—建议—祝福—落款"。
与英文对比: Hi X! … Good luck! … Hugs, Y。

## 详细讲解 (Detail)

| 部分 | 作用 | 例子 |
|------|------|------|
| [[hälsningsfras]] | 打招呼 | Hej Elin! |
| inledning | 与前信衔接 → [[knyta-an-till]] | Vad bra att du har bestämt dig … |
| råd | 用 [[grammar-ge-rad-fraser]] | Du kan också …, Då kan ni … |
| [[uppmuntran]] | 鼓励 | Lycka till! |
| [[avslutningsfras]] | 非正式结尾 | Kram, Maria |

- **Ämne**: 回信写 `Re: Hjälp!`（Re = 回复）。
- 与正式信对比：[[grammar-formellt-brev]] 用 "Med vänliga hälsningar"、不用口语词；非正式信则可用 [[grammar-informellt-talsprak]] 的标记。
- 相关信件: [[source-2026-06-26-brev-till-van-nya-livet]], [[source-2026-07-03-brev-till-van]]。

## 例句 (Examples)

- ✅ [[sent-vad-bra-att-du-har-bestämt]] 🇸🇪 Vad bra att du har bestämt dig för att sluta röka. 🇨🇳 你决定戒烟，真好。
- ✅ [[sent-lycka-till-jag-vet-att-du-kommer-att-klara]] 🇸🇪 Lycka till! Jag vet att du kommer att klara det! 🇨🇳 祝你好运！

## 常见错误 (Common Mistakes)

- ⚠️ 忘记回应对方上一封信（缺 inledning）。
- ⚠️ 只给命令（Gör så!）；多用 skulle kunna / Har du provat att …?。
