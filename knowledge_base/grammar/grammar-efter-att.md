# 📗 efter att + perfekt/pluskvamperfekt — efter att 从句的时态 (efter att clauses)

级别: SFI C/B1
一句话: `efter att` 引导的从句表示「在……之后」，从句动作先发生，所以用完成时：主句现在时 → 从句 perfekt；主句过去时 → 从句 pluskvamperfekt。

## 规则说明 (Rules)

📐 结构公式:
```
主句(preteritum) + efter att + subjekt + hade + supinum   (pluskvamperfekt)
主句(presens)    + efter att + subjekt + har  + supinum   (perfekt)
```

与中文对比: 中文「在她参与谋杀之后」不变时态；瑞典语要用完成时标明先后。
与英文对比: 类似 English "after she had taken part"；口语中 hade/har 常省略（见例句）。

## 例句 (Examples)

- ✅ [[sent-hon-blev-dömd-efter-att-hon-varit]] 🇸🇪 Hon blev dömd efter att hon varit med och mördat en ung kvinna. 🇨🇳 她因参与谋杀一名年轻女子而被判刑。（hade 被省略）

## 常见错误 (Common Mistakes)

- ⚠️ 不要写 *efter att hon var med*（时态未体现先后）。
- ⚠️ `efter att` 后是 bisats：否定词/副词在动词前（BIFF）。
