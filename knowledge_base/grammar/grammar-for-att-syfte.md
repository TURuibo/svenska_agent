# 📗 för att + infinitiv (syfte) — 表目的的 för att（为了……）(purpose clause with för att + infinitive)

级别: A2
一句话: "för att" + 动词原形表示目的（为了做某事），相当于英语 "in order to"。

## 规则说明 (Rules)

📐 结构公式:
```
主句 + för att + 动词原形
Vi träffas för att prata om ditt barn.
Jag åker dit för att hämta barnen.
```

与中文对比: 中文"为了"后可接名词或动词短语；瑞典语"för att"后只接动词原形。
与英文对比: 英语 "in order to" / "(just) to" = 瑞典语 "för att"。完全平行的结构。

## 详细讲解 (Detail)

- **关键规则**: "för att"-infinitiven 的主语与主句主语相同。
  - ✅ Vi vill träffa dig **för att** prata (Vi = de som pratar)
  - ⚠️ 如果主语不同，就需要用 "för att" + bisats（att-sats）而不是不定式。
- 与 [[grammar-for-att-infinitiv]] 重叠: 本笔记强调**目的**语义（syfte = purpose），原有笔记可能涵盖更广泛的 att-infinitiv 用法。

## 例句 (Examples)

- ✅ [[sent-vi-vill-traffa-dig-for]] 🇸🇪 Vi vill träffa dig för att prata om hur ditt barn har det i skolan. 🇨🇳 我们希望与您见面，讨论您的孩子在学校的情况。
- ✅ 🇸🇪 Han studerar svenska för att hitta ett bättre jobb. 🇨🇳 他学瑞典语是为了找到更好的工作。
- ✅ 🇸🇪 Jag gick till affären för att köpa mjölk. 🇨🇳 我去商店是为了买牛奶。
- ❌ "Vi vill träffa dig för att du pratar om barnet" ← 错误：主语不同时需要另一种结构

## 常见错误 (Common Mistakes)

- ⚠️ 混淆"för att"（目的）与"att"（其他不定式用法，如宾语从句）。
- ⚠️ 主句和"för att"从句的主语不同时，仍然使用不定式。
