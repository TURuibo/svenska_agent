# 📗 se fram emot att + infinitiv — 期待某事的表达结构 (to look forward to doing something)

级别: B1
一句话: "se fram emot att" 后接动词原形（裸不定式），表示"期待做某事"。

## 规则说明 (Rules)

📐 结构公式:
```
主语 + ser/såg fram emot att + 动词原形 (infinitiv)
Vi ser fram emot att träffas.
Jag ser fram emot att börja jobbet.
```

与中文对比: 中文"期待……"后可跟名词或动词，瑞典语必须用动词原形。
与英文对比: 英语"look forward to **doing**"后接动名词(-ing)；瑞典语用**动词原形**，不加-ing。这是最常见的错误来源。

## 详细讲解 (Detail)

- "se fram emot" 是一个**partikelverb**（小品动词）: se + fram + emot。
- 整个结构 = se fram emot + att + infinitiv。"att" 在这里引导不定式短语。
- 时态变化: ser (presens) → såg (preteritum) → sett fram emot (perfekt)
- 常见于formella brev, inbjudningar, e-post.

## 例句 (Examples)

- ✅ [[sent-vi-ser-fram-emot-att]] 🇸🇪 Vi ser fram emot att träffas! 🇨🇳 期待与您见面！
- ✅ 🇸🇪 Jag ser fram emot att börja den nya kursen. 🇨🇳 我期待开始新课程。
- ❌ "Vi ser fram emot att träffande" ← 不能用 -ing 形式（这是英语思维的错误）
- ❌ "Vi ser fram emot träffas" ← 必须有 "att" 引导不定式

## 常见错误 (Common Mistakes)

- ⚠️ 直接套用英语"look forward to doing"→ 用了-ing形式（瑞典语没有动名词）。
- ⚠️ 省略 "att" — 语法上不完整。
