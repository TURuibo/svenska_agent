# 📗 parvisa-konjunktioner — 成对连接词 (correlative conjunctions)

级别: SFI C / CEFR B1
一句话: 由两个部分组成、一起使用的连接词，如 dels … dels、antingen … eller、såväl … som。

## 规则说明 (Rules)

📐 结构公式:
```
dels A, dels B        一方面……另一方面……
antingen A eller B    要么……要么……
såväl A som B         A 也好 B 也好
både A och B          A 和 B 都
varken A eller B      既不……也不……
ju …, desto …         越……越……
```

与中文对比: 对应「一方面……另一方面」「要么……要么」「……也好……也好」。
与英文对比: partly … partly, either … or, as well as, both … and, neither … nor。

## 详细讲解 (Detail)

- 两个被连接的成分要同类、对称（名词配名词，动词短语配动词短语）。
- *Dels* / *Antingen* 置句首时，主句动词倒装（Dels sparar man pengar …）。
- 与 eller 搭配的 antingen 可放在动词之后（Man kan antingen cykla eller …）。

## 例句 (Examples)

- ✅ [[sent-dels-sparar-man-pengar-dels]] 🇸🇪 Dels sparar man pengar, dels blir man piggare och friskare. 🇨🇳 一方面省钱，另一方面更健康。
- ✅ [[sent-man-kan-antingen-cykla-med-dubbdäck]] 🇸🇪 Man kan antingen cykla med dubbdäck eller ta bussen. 🇨🇳 可以要么骑带钉轮胎，要么坐公交车。
- ✅ [[sent-de-gör-det-åt-alla-som-vill-cykla]] 🇸🇪 … barn såväl som äldre. 🇨🇳 孩子也好，老人也好。

## 常见错误 (Common Mistakes)

- ⚠️ 两部分不对称（✗ antingen cykla eller bussen）。
- ⚠️ 把 antingen 和 både 混用。
