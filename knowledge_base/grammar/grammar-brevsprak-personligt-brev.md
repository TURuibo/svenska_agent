# 📗 Brevspråk — personligt brev — 求职信书信语域规范 (Formal letter register for cover letters)

级别: A2
一句话: 求职信（personligt brev）有固定的结构和正式语域，掌握它能大大提升求职成功率。

## 规则说明 (Rules)

📐 结构公式:
```
1. 开头问候 (Hälsning)
   → Hej! / Hej [名字]! / Till [机构名]
   
2. 介绍自己 + 说明申请目的 (Vem du är + varför du söker)
   → Jag heter [名字] och söker tjänsten som [职位] på [机构].
   
3. 为什么你合适 (Varför du passar)
   → Jag har erfarenhet av... / Jag är [形容词] och...
   → Ni söker någon som är lugn och tålmodig, och det stämmer bra med mig.
   
4. 解释特殊情况 / 加分点 (Motivering)
   → Deltid passar mig utmärkt eftersom jag...
   → Erfarenhet av X är ett plus.
   
5. kontaktuppgifter + avslutning (Kontakt + avslutning)
   → Ni når mig på [telefon/email].
   → Jag hoppas att ni vill kalla mig till en intervju.
   
6. Avslutningshälsning (署名)
   → Med vänliga hälsningar, [Namn]
   → Mvh, [Namn]   (缩写形式)
   → Med vänlig hälsning, [Namn]  (单数形式，较常见)
```

与中文对比: 中文求职信通常更正式、长篇；瑞典语求职信鼓励简洁、直接和个人化。
与英文对比: 与英文 cover letter 结构相似；瑞典语中 "Hej" 开头比英文更普遍（即使是正式场合）。

## 详细讲解 (Detail)

### 开头 (Öppning)

| 场景 | 表达 | 说明 |
|------|------|------|
| 正式/不认识收件人 | `Hej!` / `Till [机构]` | 瑞典文化中 `Hej` 即使在正式信件中也完全可接受 |
| 知道收件人名字 | `Hej [名字]!` | 更个人化 |

### 申请目的句式

```
Jag söker tjänsten som [职位] på [机构].
→ "我申请[机构]的[职位]职位。"

Jag skriver för att ansöka om tjänsten som [职位].
→ "我写信是为了申请[职位]职位。"（更正式）
```

### 为何合适的常用句式

```
Jag har [X] års erfarenhet av att arbeta med...
→ "我有[X]年……工作经验。"

Jag är [形容词] och [形容词].
→ "我[特质]且[特质]。" （如：lugn och tålmodig）

Ni söker någon som är [特质], och jag tror att jag passar bra.
→ "您们寻找[特质]的人，我认为我很合适。"
```

### 结束语级别

| 正式度 | 表达 | 适用场景 |
|-------|------|---------|
| 最正式 | `Med vänliga hälsningar` | 求职信、官方信件 |
| 正式 | `Med vänlig hälsning` | 商务邮件 |
| 缩写 | `Mvh` | 邮件、较常见 |
| 半正式 | `Hälsningar` | 普通商务邮件 |

## 例句 (Examples)

- ✅ [[sent-jag-söker-tjänsten-som-barnskötare]] 🇸🇪 Jag söker tjänsten som barnskötare på Förskolan Solgården. 🇨🇳 我申请 Solgården 幼儿园的保育员职位。
- ✅ [[sent-jag-hoppas-att-ni-vill-kalla-mig]] 🇸🇪 Jag hoppas att ni vill kalla mig till en intervju. 🇨🇳 我希望您们能邀请我参加面试。
- ✅ [[sent-med-vänliga-hälsningar-sara-nguyen]] 🇸🇪 Med vänliga hälsningar, Sara Nguyen. 🇨🇳 此致，Sara Nguyen。

## 常见错误 (Common Mistakes)

- ⚠️ 不要写太长：瑞典求职信通常半页到一页，不超过一页。
- ⚠️ 不要用 `Bäste/Bästa` 开头再称名（太生硬）——直接用 `Hej [名字]` 更自然。
- ⚠️ 避免复制粘贴模板语言——招聘方更欣赏真实、具体的个人表达。
- ⚠️ `Med vänlig hälsning`（单数）和 `Med vänliga hälsningar`（复数）都正确，不要混用。
