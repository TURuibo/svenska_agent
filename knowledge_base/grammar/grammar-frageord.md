# 📗 Frågeord (interrogativa) — 疑问词 (Question words)

级别: A1-A2
一句话: 瑞典语直接疑问句 = 疑问词 + 动词 + 主语（V2 倒装），疑问词永远站在句首。

## 规则说明 (Rules)

📐 结构公式:
```
Frågeord + Verb + Subjekt + (övrigt) ?
  谁/什么   动词   主语
```

**七个核心疑问词：**

| 疑问词 | 中文 | 用法示例 |
|---|---|---|
| [[vem]] | 谁 | Vem var Elin Wägner? |
| [[vilken]] / vilket / vilka | 哪一个/哪些 | Vilken uppgift hade kvinnorna? |
| [[varför]] | 为什么 | Varför var det nästan bara pojkar...? |
| [[vad]] | 什么 | Vad ville Elin studera? |
| [[var]] | 哪里 | Var fick hon arbete? |
| [[hur]] | 怎样 | Hur kämpade Elin för kvinnors rättigheter? |
| [[när]] | 什么时候 | När fick kvinnor rösta till riksdagen? |

与中文对比: 中文疑问词**原位不动**（"她在哪里工作？" — "哪里" 留在动词后的宾语位置）。
与英文对比: 英语疑问词提前，但**不需要**像瑞典语这样把限定动词直接紧跟疑问词（英语常需要助动词 do/did：Where did she work?）。瑞典语更简单：疑问词直接 + 限定动词，无需助动词。

## 详细讲解 (Detail)

瑞典语直接疑问句遵循 **V2 语序**（动词永远排第二位）：
1. 疑问词占据句子第一位。
2. 限定动词（presens/preteritum 形式）紧跟其后，占第二位。
3. 主语排在动词之后（这就是"倒装" inversion，相对于陈述句"主语+动词"的顺序）。

```
陈述句:  Elin      studerade  ...        (主语-动词，正常语序)
疑问句:  Vad       ville      Elin  studera?  (疑问词-动词-主语，倒装)
```

若疑问词本身就是主语（如 "vem" 在 "Vem ringde?" 中作主语），则**不倒装**，因为疑问词已经占据主语位置：
```
Vem  ringde?
谁   打电话了？   (vem = 主语，无需额外倒装)
```

## 例句 (Examples)

- ✅ [[sent-vem-var-elin-wägner]] 🇸🇪 Vem var Elin Wägner? 🇨🇳 埃林·瓦格纳是谁？
- ✅ [[sent-vilken-uppgift-i-livet-hade]] 🇸🇪 Vilken uppgift i livet hade kvinnorna när Elin växte upp? 🇨🇳 埃林长大时女性在人生中承担着怎样的任务？
- ✅ [[sent-varför-var-det-nästan-bara]] 🇸🇪 Varför var det nästan bara pojkar som studerade vidare? 🇨🇳 为什么继续深造的几乎只有男孩？
- ✅ [[sent-när-fick-kvinnor-rösta-till]] 🇸🇪 När fick kvinnor rösta till riksdagen för första gången? 🇨🇳 女性第一次能在议会选举中投票是什么时候？
- ❌ Vad Elin ville studera? ← 常见错误（忘记倒装，误用中文/口语式语序，应为 "Vad ville Elin studera?"）

## 常见错误 (Common Mistakes)

- ⚠️ 忘记倒装：中文母语者容易按"疑问词+主语+动词"的顺序说，但瑞典语要求"疑问词+动词+主语"。
- ⚠️ 在间接问句（bisats）中误用倒装：例如 "Jag vet inte vad ville hon studera" 是错的，应为 "Jag vet inte vad hon ville studera"（bisats 不倒装，参见 [[grammar-bisats-ordfoljd]]）。
- ⚠️ 涉及介词的疑问句忘记把介词留在句末，如应说 "Vad kämpade hon **för**?" 而非按中文习惯把介词提前。参见 [[grammar-preposition-i-slutet]]。
