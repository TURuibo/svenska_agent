# det saknas — 无人称 s-被动（existential passive）

## 核心用法

`det saknas + 名词` = 缺少……；没有……（隐含：应该有但没有）

```
Det saknas + substantiv (obestämd form)
```

## 与 `det finns inte` 的区别

| 句型 | 含义 | 强调点 |
|------|------|--------|
| `Det finns inga cykelvägar.` | 没有自行车道（中性陈述）| 单纯不存在 |
| `Det saknas cykelvägar.` | 缺少自行车道（隐含问题）| 应该有却没有 |

## 语法结构

- `det` — 形式主语（无人称 subject）
- `saknas` — s-passiv 形式（`sakna` = 缺少；思念）
- 主语名词用**不定形式**（不定冠词）

```
Det saknas cykelvägar.   （缺少自行车道）
Det saknas en bra plan.  （缺少一个好计划）
Det saknas pengar.       （缺乏资金）
```

## 主动形式对比

- `Det saknas pengar.` （被动/无人称）= 资金缺乏
- `Kommunen saknar pengar.` （主动）= 市政府缺少资金

## 例句

- Det saknas cykelvägar på många gator i vår stad. — 我们城市的很多街道上缺少自行车道。
- Det saknas information om vilka regler som gäller. — 缺少关于哪些规则适用的信息。
- Det saknas fortfarande en lösning på problemet. — 这个问题至今仍缺乏解决方案。
