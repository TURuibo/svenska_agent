# 📗 Fraser för att ge råd — 给建议的句式 (Phrases for giving advice)

级别: SFI B / A2
一句话: 给朋友建议时，用 kan / skulle kunna / Har du provat att …? 等句式，从直接到委婉。

## 规则说明 (Rules)

📐 结构公式:
```
Du kan (också) + 不定式
Då kan ni + 不定式
Du skulle (också) kunna + 不定式
Ett annat tips är att + 不定式
Har du provat att + 不定式?
Se till att + 从句
```

与中文对比: 中文"你可以…""要不要试试…"；瑞典语用情态动词 + 无 att 不定式。
与英文对比: Du kan = You can；Du skulle kunna = You could；Har du provat att = Have you tried …ing。

## 详细讲解 (Detail)

📊 语气/礼貌度表（从直接到委婉）:

| 句式 | 语气 | 中文 |
|------|------|------|
| Se till att … / Kom ihåg att … | 最直接（命令式） | 务必… |
| Du kan … / Du kan också … | 直接、中性 | 你可以… |
| Då kan ni … | 直接，设想情景 | 这样你们可以… |
| Ett annat tips är att … | 中性，列举 | 另一个建议是… |
| Du skulle kunna … | 委婉（skulle = 条件式） | 你不妨… |
| Har du provat att …? | 最柔和（疑问形式） | 你试过…吗？ |

- **skulle + kunna** = 委婉条件式 → [[grammar-konditionalis]]。
- 情态动词后的不定式不带 att；Ett annat tips **är att** 与 provat **att** 带 att。
- 加 **också** 表示"另外一条"：Du kan också …

## 例句 (Examples)

- ✅ [[sent-då-kan-ni-plugga-i-nån-timme]] 🇸🇪 Då kan ni plugga i nån timme. 🇨🇳 这样你们可以学一个来小时。
- ✅ [[sent-du-skulle-också-kunna-göra-en-plan]] 🇸🇪 Du skulle också kunna göra en plan. 🇨🇳 你也可以做个计划。
- ✅ [[sent-men-se-till-så-att-det]] 🇸🇪 Se till så att det inte blir mer fika än plugg. 🇨🇳 注意别…。
- ❌ Du kan att plugga ← 情态动词后不加 att。

## 常见错误 (Common Mistakes)

- ⚠️ 不要写 *Du skulle kan*；正确 Du skulle kunna。
- ⚠️ 对长辈/陌生人少用 Du kan，改用 Du skulle kunna。
