# 📗 relativ bisats med där — 用 där 引导地点关系从句 (relative clause with där)

级别: B1
一句话: 当关系从句描述一个**地点**时，用 "där"（那里）而不是 "som" 引导。

## 规则说明 (Rules)

📐 结构公式:
```
[先行词，地点名词] + där + [主语] + [动词] ...
```
例：ett eget boende där jag trivs

与中文对比: 相当于中文"……的地方"结构（我住得舒心的地方），但语序不同：瑞典语先行词在前，där 从句在后。
与英文对比: 相当于英语 "where"：a place **where** I feel comfortable.

## 详细讲解 (Detail)

"där" 作关系副词，引导修饰地点名词的从句，从句内部遵循 bisats 语序（副词位于动词前，如否定词 inte）。
不要与用于人/物的 "som" 混淆：som 用于人或事物，där 专用于地点。

## 例句 (Examples)

- ✅ [[sent-jag-vill-ha-ett-eget-boende-dar-jag-trivs]] 🇸🇪 Jag vill ha ett eget boende där jag trivs. 🇨🇳 我想有一个自己住得舒心的住处。
- ❌ ett eget boende som jag trivs ← 常见错误（描述地点应用 där 而非 som）

## 常见错误 (Common Mistakes)

- ⚠️ 用 som 代替 där 来引导地点从句。
