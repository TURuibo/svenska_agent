# 📗 konditionalis — 条件式/礼貌式 (conditional)

级别: A2
一句话: *Skulle + infinitiv* 表示礼貌请求或假设条件。

## 规则说明 (Rules)

📐 结构公式:
```
skulle + infinitiv
(主语 + skulle + 动词原形)
```

与中文对比: 中文无此形式，用"想要/希望/如果"表达类似含义。
与英文对比: 相当于英语 "would + verb"。

## 详细讲解 (Detail)

konditionalis 在瑞典语中主要有两种用法：

**1. 礼貌请求（polite request）**
- *Jag skulle vilja ha...* = I would like... (我想要...)
- *Skulle du kunna...?* = Could you...? (你能...吗？)
- 比直接用 *vill* 或 *vill ha* 更礼貌。

**2. 假设/条件（hypothetical）**
- *Om jag hade tid, skulle jag...* = If I had time, I would...
- 用于 om-satser (如果从句) 中表达假设情况。

**重要变位形式：**
- skulle vilja = would like (礼貌愿望)
- skulle kunna = would be able to (礼貌能力请求)
- skulle behöva = would need (礼貌需求)

## 例句 (Examples)

- ✅ *Jag skulle vilja ha en latte.* = 我想要一杯拿铁。（礼貌点餐）
- ✅ *Skulle du kunna hjälpa mig?* = 你能帮我吗？（礼貌请求）
- ✅ *Om det regnade, skulle vi stanna inne.* = 如果下雨，我们就待在里面。（假设）
- ❌ *Jag vill vilja ha...* ← 冗余，不需要双重情态

## 常见错误 (Common Mistakes)

- ⚠️ 不要和 *ska* 混淆：*ska* 表示将来或意图，*skulle* 表示条件式或礼貌。
- ⚠️ *Skulle* 后接动词原形（infinitiv），不接 att。
