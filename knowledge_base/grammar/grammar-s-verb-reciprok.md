# 📗 s-verb-reciprok — s-动词的相互（互相）用法 (Reciprocal s-verbs)

级别: A2
一句话: 动词词尾加 -s 可以表示"互相"的动作（相互动词），如 "ses"（互相见面）、"höras"（互相听到/联系）。

## 规则说明 (Rules)

📐 结构公式:
```
主语(复数/vi) + 动词原形-s  →  表示互相动作
vi             +   ses        →  我们互相见面
de             +   hörs       →  他们互相联系/听到
```

与中文对比: 中文用"互相"或"彼此"来表达，如"我们互相见面"；瑞典语通过动词加 -s 实现。
与英文对比: 英语用 "each other" / "one another"，如 "we see each other"。

## 详细讲解 (Detail)

**常见相互动词（reciproka s-verb）：**

| 动词原形 | presens | preteritum | 意思 |
|----------|---------|------------|------|
| ses | ses | sågs | 互相见面 |
| höras | hörs | hördes | 互相联系；下次再说 |
| träffas | träffas | träffades | 互相会面 |
| hjälpas åt | hjälps åt | hjälptes åt | 互相帮助 |
| skiljas | skiljs | skildes | 分开；离婚 |

**注意区分三种 s-动词：**
1. **相互动词**（reciproka）: ses, höras — 主语必须是复数或代表两方的 "vi"
2. **被动语态**（passiv）: maten äts（食物被吃）→ [[grammar-passiv-med-s]]
3. **deponensverb**（外形像被动，含义主动）: hoppas, minnas, trivas → [[grammar-deponensverb]]

## 例句 (Examples)

- ✅ [[sent-det-var-längesen-vi-sågs]] 🇸🇪 Det var längesen vi sågs. 🇨🇳 我们好久没见了。（sågs = ses 的过去时）
- ✅ [[sent-vi-kan-ses-där-först-om-du-vill]] 🇸🇪 Vi kan ses där först om du vill. 🇨🇳 如果你愿意，我们可以先在那儿见面。
- ❌ "Jag ses med Johan." ← 错误；相互动词主语必须是复数或包含双方：应说 "Vi ses" 或 "Jag och Johan ses"

## 常见错误 (Common Mistakes)

- ⚠️ 把 "ses" 当成被动语态——"ses" 此处是相互义，不是"被看见"。
- ⚠️ "Vi hörs!" 是非常常见的道别语，意思是"保持联系！/下次再说！"，不是"我们被听见了"。
