# grammar-utformas-for-att — 目的被动结构

📐 中文：被动 + 目的不定式——utformas/är utformade för att · English: passive + purpose: designed to

## 规则说明 (Rule)

**utformas för att** / **är utformad/e för att** 是"被动 + 目的不定式"结构的典型例子：

| 构成 | 说明 |
|------|------|
| *utformas* | s-被动（现在时）= 被设计 |
| *är utformad* | bli-被动（完成分词）= 已被设计为 |
| *för att + infinitiv* | 目的不定式：为了…… |

### 两种形式

1. **s-被动 + för att**: `utformas för att [hålla/skydda/minska]`
2. **particip-被动 + för att**: `är utformade för att [hålla...]`

### 广泛应用

同样的结构适用于：
- `anpassas för att` — 被调整为……
- `regleras för att` — 被规范为……
- `skapas för att` — 被创造为……

## 例句 (Sentences)

- 🇸🇪 Algoritmerna är utformade för att hålla användarna engagerade. — 🇨🇳 算法被设计为使用户保持参与/尽可能长时间地吸引用户。
- 🇸🇪 Produkten utformas för att tilltala barn. — 🇨🇳 产品被设计为吸引儿童。
