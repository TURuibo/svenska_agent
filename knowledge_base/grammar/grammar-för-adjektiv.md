# 📗 för + adjektiv — 太……（过度） (too + adjective)

级别: SFI A / CEFR A2
一句话: `för` 放在形容词/副词前，表示"过度、太……"。

## 规则说明 (Rules)

📐 结构公式:
```
subjekt + vara + för + adjektiv (+ för att-sats / för + 人)
Skeppet var för tungt upptill.
```

与中文对比: 中文"太重"；瑞典语 `för tung`，形容词随 en/ett 变化（ett skepp → tungt）。
与英文对比: = too heavy。

## 例句 (Examples)

- ✅ [[sent-skeppet-var-för-tungt-upptill]] 🇸🇪 Skeppet var för tungt upptill. 🇨🇳 船的上部太重。
- ✅ Kaffet är för varmt. — 咖啡太烫了。
- ❌ Det är för mycket tungt. ← 不要加 mycket；`mycket för` 才是"非常太"

## 常见错误 (Common Mistakes)

- ⚠️ `för` 后形容词仍要性数一致（ett → -t）。
- ⚠️ 不要与 `för att`（为了）混淆。
