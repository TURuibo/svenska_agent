# 📗 vilja att + ska — 希望别人做某事 (want someone to do something)

级别: SFI C / CEFR B1
一句话: 想让**别人**（或另一个主语）做某事时，瑞典语不能说 *vill X göra*，而要用 att 从句：`vilja att + 新主语 + ska + 不定式`。

## 规则说明 (Rules)

📐 结构公式:
```
主语1 + vill + att + 主语2 + ska + 不定式
Kommunen vill att byggföretagen ska bygga bostäder.

主语1 + vill + 不定式              （主语相同时：我想做）
Jag vill bygga.
```

与中文对比: 中文"市政府希望建筑公司建住房"——动词"希望"后直接接新主语；瑞典语要加 **att** 并且从句里用 **ska**。
与英文对比: 英语 "The municipality wants the companies **to build**"（want + 宾语 + to）；瑞典语**没有**这种宾语+不定式结构，必须用 att + ska。

## 详细讲解 (Detail)

- 主语相同 → *vilja + 不定式*：*Jag vill säga att …*
- 主语不同 → *vilja att + S + ska + inf.*：*Jag vill att du ska komma.*
- 从句是 **bisats**：inte 等副词放在动词前（BIFF）：*Jag vill att du inte ska gå.*
- 同类：*önska att … ska*、*vilja att … får/kan*；口语也可 *Jag vill att du kommer.*（presens），但讲义范文用 ska。

| 中文 | ❌ 错 | ✅ 对 |
|---|---|---|
| 市政府希望建筑公司建房 | *Kommunen vill byggföretagen bygga.* | *Kommunen vill att byggföretagen ska bygga.* |
| 我想让你来 | *Jag vill dig komma.* | *Jag vill att du ska komma.* |

## 例句 (Examples)

- ✅ 🇸🇪 Igår läste jag i tidningen att kommunen vill att byggföretagen ska bygga bostäder vid Lötsjön. 🇨🇳 昨天我在报纸上读到，市政府希望建筑公司在 Lötsjön 旁建住房。（[[source-2026-11-17-formellt-brev-till-kommunen]]）
- ✅ 🇸🇪 Jag vill att du ska hjälpa mig. 🇨🇳 我想让你帮我。
- ✅ 🇸🇪 Läraren vill att eleverna ska öva varje dag. 🇨🇳 老师希望学生每天练习。
- ❌ *Kommunen vill byggföretagen bygga bostäder.* ← 不能 vilja + 新主语 + 不定式

## 常见错误 (Common Mistakes)

- ⚠️ 受英语 *want sb to do* 影响，漏掉 att 和 ska。
- ⚠️ 受中文影响，把"希望"后直接接新主语。
- ⚠️ 主语相同却也加 att：*Jag vill att jag ska …* ✗ → *Jag vill …* ✓
