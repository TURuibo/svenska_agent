# relativbisats — 关系从句 (relative clause)

级别: A2–B1
一句话: 用 `som`（或 `vilket/vilken/vars`）引导的从句，修饰名词，说明"哪一个"或"什么样的"。

## 规则说明 (Rules)

📐 结构公式:
```
主句名词 + som + (主语) + 谓语 + ...

En hjälte  [som dog i strid]  kom till Valhall.
  名词       关系从句              主句谓语
```

**关系代词选择：**

| 情况 | 用词 |
|------|------|
| 指人或物（最常见）| `som` |
| 指整个句子 | `vilket` |
| 表所属 | `vars`（…的，其） |
| 正式/书面，指物 | `vilken/vilket/vilka` |

**关系从句中的词序（BIFF规则）：**
- 否定词 `inte` 放在动词**前**：`En man som INTE talar svenska...`
- 频率副词 `alltid/ofta` 也在动词前

与中文对比: 中文关系从句前置（"死于战斗的英雄"），瑞典语后置（"en hjälte som dog i strid"）。
与英文对比: 英文有 who/which/that；瑞典语主要用 `som` 统一处理人和物。

## 详细讲解 (Detail)

**`som` 在关系从句中的位置：**

1. **som = 从句主语：** `En hjälte **som** dog i strid...`（som 是 dog 的主语）
2. **som = 从句宾语：** `Boken **som** jag läste var bra.`（som 是 läste 的宾语）— 此时可省略 `som`

**关系从句中的否定（BIFF）：**
```
En viking som INTE var bonde... = 一个不是农民的维京人
En saga som ALLTID berättas... = 一个总被讲述的故事
```

## 例句 (Examples)

- ✅ [[sent-en-hjalte-som-dog-i-strid-kom-till-valhall]] 🇸🇪 En hjälte som dog i strid kom till Valhall. 🇨🇳 死于战斗的英雄会去往瓦尔哈拉。
- ✅ 🇸🇪 Folk som bor i Sverige talar svenska. 🇨🇳 住在瑞典的人说瑞典语。
- ❌ `En hjälte vilket dog i strid...` ← 指人用 `som`，不用 `vilket`

## 常见错误 (Common Mistakes)

- ⚠️ 用 `vem` 代替 `som`：`En man som/inte vem...` 来修饰名词。
- ⚠️ 词序错误：从句中否定词 `inte` 要在动词**前**（BIFF 规则）。
