# 📗 rakt fram — 方向副词：直走；笔直向前 (directional adverb: straight ahead)

级别: A1
一句话: `rakt fram` 是方向副词短语，意为"笔直向前走"，是问路/指路场景的核心词。

## 规则说明 (Rules)

📐 结构公式:
```
rakt fram           → 直走（方向）
gå rakt fram        → 一直往前走
fortsätt rakt fram  → 继续直走

常见方向副词组:
rakt fram   → 直走
till vänster → 向左
till höger   → 向右
tillbaka     → 返回/回去
```

与中文对比: 中文"一直往前走" = `gå rakt fram`；"直走" = `rakt fram`
与英文对比: 英文 "straight ahead" = `rakt fram`；`rakt` = straight, `fram` = forward/ahead

## 详细讲解 (Detail)

- `rakt` = 笔直地（副词）；`fram` = 向前（方向副词）
- 组合 `rakt fram` = straight ahead，强调不拐弯
- 常用于指路（vägbeskrivning）：
  - `Gå rakt fram.` = 一直走（不拐）
  - `Fortsätt rakt fram till...` = 继续直走直到…
  - `Gå rakt fram längs [gatan].` = 沿着…一直走

短语变体:
| 短语 | 意思 |
|------|------|
| `rakt fram` | 直走，笔直向前 |
| `precis rakt fram` | 就在正前方 |
| `lite rakt fram` | 稍微往前走一点 |

## 例句 (Examples)

- ✅ [[sent-sedan-går-du-rakt-fram-längs-storgatan]] 🇸🇪 Sedan går du rakt fram längs Storgatan. 🇨🇳 然后沿着斯托大街一直往前走。
- ✅ 🇸🇪 Gå rakt fram i tio minuter. 🇨🇳 一直走十分钟。
- ✅ 🇸🇪 Fortsätt rakt fram tills du ser banken. 🇨🇳 一直走直到你看见银行。
- 🔗 → se även fraser: [[rakt-fram]]

## 常见错误 (Common Mistakes)

- ⚠️ 不要把 `rakt` 省略：`gå fram` 语义不够精确；`gå rakt fram` 更清晰
- ⚠️ `fram` ≠ `framme`：`gå rakt fram`（往前走的动作）vs `du är framme`（你到了，已到达目的地）
