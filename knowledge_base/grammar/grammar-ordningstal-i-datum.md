# ordningstal i datum (den första juli) — 日期中的序数词 (ordinal numbers in dates)

级别: A2
一句话: 瑞典语日期中使用序数词（den + ordningstal + månad），例如 *den första juli* = 七月一日。

## 规则说明 (Rules)

📐 结构公式:
```
den + ordningstal + månad
定冠词  序数词(utrum)  月份(no article)
```

例: *den första juli* = July 1st; *den tjugonde juni* = June 20th

与中文对比: 中文是"七月一日"（数词）；瑞典语用序数词
与英文对比: 类似 "the first of July" 结构，但瑞典语不加 "of"

## 详细讲解 (Detail)

**Key ordinals for dates:**
| Number | Ordinal |
|--------|---------|
| 1 | första |
| 2 | andra |
| 3 | tredje |
| 4 | fjärde |
| 5 | femte |
| 10 | tionde |
| 20 | tjugonde |
| 21 | tjugoförsta |
| 30 | trettionde |
| 31 | trettioförsta |

- Always use *den* (not *ett*) before the ordinal, regardless of gender.
- The month follows without any preposition or article.

## 例句 (Examples)

- ✅ [[sent-vad-sager-du-om-onsdag-den-forsta-juli]] 🇸🇪 Onsdag den första juli 🇨🇳 七月一日（周三）
- ✅ 🇸🇪 Den tjugonde juni öppnade cykelbanan. 🇨🇳 自行车道于六月二十日开通。
- ❌ *Juli en* ← wrong word order

## 常见错误 (Common Mistakes)

- ⚠️ Don't use cardinal numbers for dates: ~~den ett juli~~ → den *första* juli
- ⚠️ Month name is NOT capitalized in Swedish: *juli*, not *Juli*
