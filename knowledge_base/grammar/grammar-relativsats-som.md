# 📗 relativsats med som (bisats) — 关系从句用 som ('som' relative clause)

级别: A2
一句话: `som` 引导关系从句，回指前面的名词，可在从句中充当主语或宾语。

## 规则说明 (Rules)

📐 结构公式:
```
名词 + som + [从句谓语...]
```

例（本篇告示）：
```
en tid  som  krockar  med reparationen
  ↑            ↑
被修饰词   som 兼作从句主语（"一个与维修冲突的时间"）
```

与中文对比: 中文用前置定语「与维修冲突的」+ 时间；瑞典语用后置从句 `en tid som krockar med reparationen`。
与英文对比: 与英语 "a time that clashes with the repair" 结构一致，`som` = that/which/who，不区分人/物。

## 详细讲解 (Detail)

本例中 `som` 在从句 `som krockar med reparationen` 中充当**主语**（"它"（那个时间）与维修冲突），
指代前面的 `en tid`。这与 [[grammar-relativ-bisats-med-som]] 中"som 作主语"的用法一致，
是同一语法点在真实告示文本中的应用实例。

## 例句 (Examples)

- ✅ [[sent-har-du-bokat-en-tid-som]] 🇸🇪 Har du bokat en tid som krockar med reparationen? 🇨🇳 您预约的时间和维修冲突了吗？
- ❌ *Har du bokat en krockande-med-reparationen tid?* ← 中文式前置定语直译，错误

## 常见错误 (Common Mistakes)

- ⚠️ 中文学习者容易把修饰语堆到名词前，而不是用 `som` 从句后置。
- ⚠️ 别忘了 `som` 从句里动词位置紧跟在 `som` 之后（此处从句无其他状语，语序简单）。
