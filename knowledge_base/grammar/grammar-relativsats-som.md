# 📗 relativsats med som — som 引导的关系从句 (relative clause with som)

级别: A2
一句话: **som** = 英语 who / which / that 三合一，紧跟在被修饰的名词后面，从句里不再重复那个名词。

## 规则说明 (Rules)

📐 结构公式:
```
名词 + [ som + (主语) + 动词 + … ] + 主句其余部分

Barn  [som behöver omsorg de veckorna]  går på förskolan Ekbacken.
孩子   [那些需要托管的]                    去 Ekbacken 园
```

与中文对比: 中文定语放**前面**（"需要托管的孩子"），瑞典语关系从句放**名词后面**；翻译时要把 som-从句整体搬到名词前 + "的"。
与英文对比: 与 *children who need care* 一样的位置，但瑞典语只有一个 *som*，不分人/物、不分主格宾格；*som* 作宾语时可省略（同英语 that）。

## 详细讲解 (Detail)

1. **som 不变形**：人、物、单复数都用 som。*mannen som bor här* / *boken som ligger där* / *barnen som leker*。
2. **som 作主语时不可省**（*Barn som behöver omsorg*）；**作宾语时可省**（*boken (som) jag läser*）。
3. **从句语序 = bisats 语序**：否定词/副词放在动词前：*barn som **inte** behöver omsorg*（[[grammar-bisats-biff]]）。
4. **主语带长关系从句时主句不倒装**：整个 *Barn som … veckorna* 是主语，后面直接 *går*。
5. **介词**放在从句末尾：*förskolan som hon går på*（她上的那所幼儿园）。
6. **强调句** *Det är ni som ansvarar …*（负责的是你们）也是 som-从句的一种（utbrytning），见 [[grammar-den-som-relativ]]。
7. 注意 *som* 还有"作为 / 像"的意思（*som vårdnadshavare* = 作为监护人）——后面直接跟名词、没有动词时不是关系从句。

## 例句 (Examples)

- ✅ [[sent-barn-som-behöver-omsorg-de-veckorna]] 🇸🇪 Barn som behöver omsorg de veckorna går på förskolan Ekbacken. 🇨🇳 那几周需要托管的孩子去 Ekbacken 幼儿园。
- ✅ [[sent-kom-ihåg-att-det-är-ni]] 🇸🇪 Kom ihåg att det är ni som vårdnadshavare som ansvarar för att schemat stämmer. 🇨🇳 请记住，确保时间表准确无误是你们作为监护人的责任。
- ✅ 🇸🇪 Vi har en dotter som heter Ella. 🇨🇳 我们有个女儿叫 Ella。
- ✅ 🇸🇪 Kläderna som hänger på kroken är Ellas. 🇨🇳 挂在钩子上的衣服是 Ella 的。
- ✅ 🇸🇪 Det är en förskola (som) vi tycker mycket om. 🇨🇳 那是一所我们很喜欢的幼儿园。
- ❌ *Barn som de behöver omsorg …* ← som 已是主语，不能再加 de
- ❌ *Barn som behöver omsorg går de på …* ← 主句主语重复

## 常见错误 (Common Mistakes)

- ⚠️ 受中文影响把定语放前面、漏掉 som：✗ *behöver omsorg barn*。
- ⚠️ 在 som-从句里重复主语代词（✗ *som de behöver*）。
- ⚠️ 把 *vilken/vilket* 当日常关系代词——那是书面/正式用法，口语和通知都用 som。
- ⚠️ 从句里 *inte* 放错位置：✓ *som inte kan komma*，✗ *som kan inte komma*。
