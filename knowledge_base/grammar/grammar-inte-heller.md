# 📗 inte heller — 「也不」（否定句中的"也"） ("not ... either" / "nor")

级别: A2
一句话: 在否定句里表达"也不"，对应肯定句里的 "också"。

## 规则说明 (Rules)

📐 结构公式:
```
[negativ sats 1], och [subjekt] + inte heller + [verb...]
```
也可放句首触发 V2 倒装：`Inte heller fick de rösta.`

与中文对比: 中文"也不"vs 瑞典语——肯定句用 också 表达"也"，但否定句里不能直接说 "inte också"，必须换成 "inte heller"。
与英文对比: 类似英语 "not ... either" 或倒装的 "nor did..."。

## 详细讲解 (Detail)

`heller` 是 satsadverbial（句子副词），只用于否定语境，紧跟在 `inte` 之后，位置遵循 satsadverbial 规则（huvudsats 中位于动词之后、bisats 中位于主语之后动词之前）。

## 例句 (Examples)

- ✅ [[sent-kvinnor-fick-inte-välja-yrke]] 🇸🇪 Kvinnor fick inte välja yrke och de fick inte heller rösta. 🇨🇳 女性不能选择职业，也不能投票。
- ❌ ...de fick inte också rösta. ← 常见错误，"också" 不能直接用在否定句里表达"也不"

## 常见错误 (Common Mistakes)

- ⚠️ 中文母语者常把"也"直接翻成 också 即使句子是否定的，需要改用 `inte heller`。
