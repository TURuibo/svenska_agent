# 📗 Imperativ i anslag och instruktioner — 告示与指示语中的祈使句 (Imperative in notices)

级别: A2
一句话: 瑞典语告示（anslag）和使用说明中广泛使用祈使句（imperativ）发出指令，动词形式根据动词组别而异。

## 规则说明 (Rules)

📐 结构公式:
```
Grupp 1 (infinitiv -a):   infinitiv → imperativ = samma form
   boka     →  Boka!
   lämna    →  Lämna!
   avboka   →  Avboka!
   kontakta →  Kontakta!

Grupp 2 (-er presens):    imperativ = stammen (kortare form)
   tömma    →  Töm!    (ta bort -ma)
   läsa     →  Läs!    (ta bort -a, stammen utan -er)

Grupp 4 / oregelbundna:
   ta       →  Ta!
   kom      →  Kom! (komma → kom)
```

Negativ imperativ: Inte + imperativ: "Glöm inte!" / "Lämna inte kvar kläder!"

与中文对比: 中文告示常用"请…"（qǐng）表示礼貌，瑞典语直接用 imperativ 既礼貌又正式（特别在书面告示里）。
与英文对比: Same as English — "Book your time!" / "Empty the filter!" Direct imperatives are normal and polite in written notices.

## 详细讲解 (Detail)

In Swedish written notices (anslag), rules (regler), and instruction texts, the imperative is the standard form for giving directions to the reader. This is culturally neutral — not rude.

**Common contexts:**
- Tvättstugeregeln (laundry room rules): Boka! Avboka! Lämna ren! Töm filtret!
- Skyltning (signs): Stäng dörren! Rök inte! Ta med kvitto!
- Manualer: Tryck på knappen. Vrid ratten till höger.

**v.1 verbs — imperative = infinitive (same form):**
- boka → Boka din tid.
- lämna → Lämna rummet städat.
- avboka → Avboka i god tid.
- kontakta → Kontakta vaktmästaren.

**v.2 verbs — imperative = stem (drop -er from presens):**
- tömma → Töm filtret.  (presens: tömmer, stem: töm-)
- läsa → Läs anvisningarna.  (presens: läser, stem: läs-)
- stänga → Stäng dörren.  (presens: stänger, stem: stäng-)

## 常见错误 (Common Mistakes)

- ⚠️ Confusing v.1 and v.2 imperative: "Töma filtret!" ← wrong (tömma is v.2, imperative = Töm!)
- ⚠️ Adding "snälla" (please) in formal notices — not standard. Swedish notices just use bare imperatives.
