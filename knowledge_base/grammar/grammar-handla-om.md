# grammar-handla-om — 动词固定搭配

📐 中文：handla om——"讲述/涉及"的固定搭配 · English: fixed collocation: handla om (to be about)

## 规则说明 (Rule)

**handla om** 是 *handla*（行动/购物/交易）与介词 *om*（关于）构成的**固定搭配（partikelverb）**，意为"涉及/讲述/关于"。

⚠️ 注意区分：
- `handla om` = 关于/讲述（固定搭配，不可分）
- `handla` 单独 = 购物 / 行动

| 时态 | 形式 |
|------|------|
| presens | *handlar om* |
| preteritum | *handlade om* |
| supinum | *handlat om* |

## 常见句型

- `Filmen handlar om ...` — 电影讲述了……
- `Det handlar om ...` — 这涉及到……；这是关于……的事
- `Boken handlar om ...` — 这本书讲述了……

## 例句 (Sentences)

- 🇸🇪 Filmen handlar om Elle-Marja, en ung samisk flicka. — 🇨🇳 电影讲述了一个年轻萨米女孩埃勒-玛丽亚的故事。
- 🇸🇪 Det handlar inte om pengar, utan om principer. — 🇨🇳 这不是钱的问题，而是原则问题。
