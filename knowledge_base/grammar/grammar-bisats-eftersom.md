# 📗 Bisats med eftersom — eftersom引导的原因状语从句 (Causal subordinate clause with eftersom)

级别: SFI C / CEFR A2
一句话: `eftersom` 引导原因从句（相当于"因为"），当它在句首时，主句仍须 V2 倒装。

## 规则说明 (Rules)

📐 结构公式:
```
[Eftersom + bisats], [V2-动词] [主语] [其余成分...]
```

- `eftersom` = because（原因，比 `för att` 更正式/强调）
- 当 `eftersom` 从句置于位置1，后面的主句仍遵守 V2 规则 → **主谓倒装！**

与中文对比: 中文"因为…所以…"两个分句语序不变；瑞典语从句在前时主句要倒装。
与英文对比: 英语 *Because he left, she cried.* 也可倒装但语序不变为主流；瑞典语**必须**倒装。

## 详细讲解 (Detail)

### 三种常用"因为"连词对比

| 连词 | 语域 | 位置 | 例句 |
|------|------|------|------|
| `eftersom` | 中性/正式 | 可在句首或中间 | *Eftersom hon var trött, stannade hon hemma.* |
| `för (att)` | 口语 | 通常在主句后 | *Hon stannade hemma, för hon var trött.* |
| `då` | 文学/较正式 | 可在句首 | *Då hon var trött, stannade hon hemma.* |

### 语序变化示例

```
句首从句:
[Eftersom Astrid var ensam] | [kunde] [hon] [inte ta hand om barnet]
       bisats (位置1)          V2=modal  主语   其余成分（倒装！）

对比正常语序：
[Hon] [kunde] [inte ta hand om barnet] [eftersom hon var ensam]
 主语   V2        其余成分                     从句在后（无倒装）
```

## 例句 (Examples)

- ✅ [[sent-eftersom-astrid-var-ensam-kunde-hon]] 🇸🇪 **Eftersom** Astrid var ensam **kunde** hon inte ta hand om barnet själv. 🇨🇳 因为阿斯特丽德是独自一人，她无法自己照顾孩子。
- ✅ 🇸🇪 **Eftersom** böckerna var populära, **fick** Astrid beröm. 🇨🇳 因为书很受欢迎，阿斯特丽德获得了赞扬。
- ❌ *Eftersom Astrid var ensam **hon kunde** inte...* ← 忘记倒装（常见错误）

## 常见错误 (Common Mistakes)

- ⚠️ `eftersom` 从句在句首时，忘记主句的主谓倒装。
- ⚠️ 混淆 `eftersom`（原因）和 `även om`（尽管/即使）。
