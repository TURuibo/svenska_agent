# 📗 partikelverb med ur — 带 ur 的分离动词 (separable verb with particle ur)

级别: A2
一句话: ur（出/离）作为动词小品词，构成"spåra ur（出轨）、gå ur（退出）"等分离动词，可与动词分离书写。

## 规则说明 (Rules)

📐 结构公式:
```
动词 + ur = 分离动词（Partikelverb）
spåra + ur = spåra ur（出轨）
gå + ur = gå ur（退出/离开）
```

**粒子 ur 的基本含义：** 表示"从里面出来/脱离轨道/离开某状态"。

**分离规则：** 在简单句中，粒子 ur 通常与动词分离，放在句末或宾语之后：

| 例 | 分析 |
|----|------|
| Tåget spårade ur. | 主语 + 动词 + 粒子（句末） |
| Tåget har spårat ur. | 完成时：har + supinum + 粒子 |
| Han gick ur rummet. | 宾语（rummet）前移，粒子在句末 |

与中文对比: 类似"脱轨/退出"，中文结果补语相当于 ur 的作用。
与英文对比: 类似 "derail"（out of track），但英语常合成为一个词，瑞典语保持分离。

## 详细讲解 (Detail)

**常见 ur 复合动词：**

| 分离动词 | 意义 |
|----------|------|
| spåra ur | 出轨（列车） |
| gå ur | 退出（组织/房间） |
| falla ur | 掉出来 |
| komma ur | 从……里出来 |
| ta ur | 取出 |
| fly ur | 逃离 |

## 例句 (Examples)

- ✅ [[sent-det-var-inte-ett-tag-med]] 🇸🇪 Det var inte ett tåg med människor som spårade ur. 🇨🇳 出轨的不是载客列车。
- ✅ 🇸🇪 Tåget har spårat ur nära Borås. 🇨🇳 列车在博罗斯附近出轨了。
- ✅ 🇸🇪 Han gick ur laget efter förlusten. 🇨🇳 失利后他退出了队伍。
- ❌ "Tåget ursårade." ← ur 不能合并；应为 "Tåget spårade ur"

## 常见错误 (Common Mistakes)

- ⚠️ 忘记分离：不能写成 "urspårade"（一个词）；正确是 "spårade ur"
- ⚠️ 在完成时中：应为 "har spårat ur"，不是 "har urspårat"
