# 📗 preteritum-artighet — 过去时表委婉/礼貌提议 (Preteritum for politeness)

级别: A2
一句话: 用动词的过去时（preteritum）代替现在时，使表达更委婉、更礼貌，并非表示真正的过去时间。

## 规则说明 (Rules)

📐 结构公式:
```
主语 + 动词(preteritum) + [att] + 主语 + 情态动词(preteritum) + 动词
Jag  +  tänkte          + att   +  vi  +     kunde            + ta en fika
```

与中文对比: 中文用"我在想……"或加语气词"……嘛"来软化，不改变动词时态；瑞典语通过时态切换实现。
与英文对比: 英语同样用过去时委婉："I was wondering if..." / "I thought we could..."

## 详细讲解 (Detail)

最常见的委婉过去时动词：
- **tänkte**（tänka 的过去时） = "我在想……"；现在时 tänker 语气更直接
- **ville**（vilja 的过去时） = "我想要……"；现在时 vill 更直接
- **kunde**（kan 的过去时） = "或许可以……"；现在时 kan 更确定
- **skulle**（ska 的过去时） = "我想……"；经常与 vilja 合用

典型句型：
- "Jag tänkte att vi kunde..." = "我在想我们或许可以……"
- "Jag ville fråga om..." = "我想问一下……"
- "Jag undrade om du vill..." = "我想知道你是否愿意……"

## 例句 (Examples)

- ✅ [[sent-jag-tänkte-höra-om-du-är-ledig]] 🇸🇪 Jag tänkte höra om du är ledig på lördag. 🇨🇳 我想问问你周六有没有空。
- ✅ [[sent-vädret-ska-bli-fint-tänkte-vi-kunde]] 🇸🇪 Jag tänkte att vi kunde ta en fika ute. 🇨🇳 我想我们可以在户外喝个 fika。
- ❌ "Jag tänker att vi kan ta en fika." ← 现在时，语气更直接，不如过去时委婉

## 常见错误 (Common Mistakes)

- ⚠️ 学生常误以为这些句子是描述过去发生的事——实际上说话人用过去时是为了礼貌，说的是现在/将来的提议。
- ⚠️ 注意区分真正的过去时（"Jag tänkte på dig igår." = 我昨天想到你了）和礼貌用的过去时。
