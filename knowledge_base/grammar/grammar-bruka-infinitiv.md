# 📗 bruka + infinitiv — brukar + 不定式（表习惯性动作，不加 att） (bruka + infinitive habitual)

级别: A2
一句话: `brukar` 放在动词原形前，表示"通常/习惯做某事"，后面的动词不加 att。

## 规则说明 (Rules)

📐 结构公式:
```
主语 + brukar + 动词原形（不加 att）
Jag   brukar   äta lunch med kollegorna.
```

与中文对比: 中文用"通常""习惯"等词表达 → `Jag brukar...` = 我通常……/我习惯……
与英文对比: 英语用 "usually do" 或 "tend to" → `brukar + infinitiv` 是最直接的对应。

## 详细讲解 (Detail)

- `brukar` 是 `bruka` 的现在时形式，作情态助动词使用。
- 后接**动词原形（infinitiv），不带 att**：
  - ✅ `Jag brukar ta bussen.`（我通常坐公交）
  - ❌ `Jag brukar att ta bussen.`（错误——不加 att）
- 过去时 `brukade` 表示"过去常常"（used to）：`Jag brukade bo i Stockholm.`（我以前住在斯德哥尔摩）
- 否定: `brukar inte` → `Jag brukar inte äta frukost.`（我通常不吃早饭）

## 例句 (Examples)

- ✅ [[sent-pa-lunchen-brukar-jag-ata-tillsammans]] 🇸🇪 På lunchen brukar jag äta tillsammans med mina kollegor. 🇨🇳 午饭时我通常和同事们一起吃。
- ✅ [[sent-min-vardag-ar-ganska-enkel-men-jag]] 🇸🇪 ...trivs... (bruka-form in context) 🇨🇳 （示范习惯性动作语境）
- ❌ `Jag brukar att stiga upp tidigt.` ← 错误：brukar 后不加 att

## 常见错误 (Common Mistakes)

- ⚠️ 最常见错误：在 brukar 后面加 att → `brukar att + infinitiv`（英语 "used to + do" 的干扰）
- ⚠️ 勿混淆 `brukar`（通常）和 `ska`（将要）：意义和时态都不同。
