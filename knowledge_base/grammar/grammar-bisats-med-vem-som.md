# 📗 bisats med "vem som" — 带"vem som"的宾语从句 (subordinate clause with "vem som")

级别: A2
一句话: 在宾语从句中，**vem**（谁）后面必须加 **som** 作标记词，因为 som 代替了从句中的主语位置。

## 规则说明 (Rules)

📐 结构公式:
```
主句 + ... + vem som + 动词（BSV 词序）
                ↑
          som = 关系词，替代从句主语
```

具体例子分析：
```
Det spelar ingen roll | vem som | äger marken
      主句              连接词组   从句动词+宾语
                        ↑
               vem = 疑问词（谁）
               som = 替代主语标记
```

与中文对比:
- 中文"无论谁拥有土地" = 瑞典语 *vem som äger marken*
- 中文不需要额外标记词；瑞典语必须加 **som**

与英文对比:
- 英文 "whoever owns the land" / "who owns the land"
- 瑞典语中 **vem som** ≈ 英文 "whoever" / "who" in indirect questions

## 详细讲解 (Detail)

**为什么需要 som？**

在瑞典语宾语从句（bisats）中，如果疑问词（vem/vad）充当从句的**主语**，则必须在其后加 **som** 作标记。这个 **som** 占据了主语的位置，使句子结构清晰。

| 直接问句 | 宾语从句 |
|----------|----------|
| *Vem äger marken?*（谁拥有土地？）| *Jag vet inte vem som äger marken.*（我不知道谁拥有土地。）|
| *Vad hände?*（发生了什么？）| *Jag undrar vad som hände.*（我不知道发生了什么。）|

⚠️ 注意从句词序：bisats 内部用 **BSV 词序**（bisatsledare + subjekt + verb），不倒装。

## 例句 (Examples)

- ✅ [[sent-det-spelar-ingen-roll-vem-som]] 🇸🇪 Det spelar ingen roll vem som äger marken. 🇨🇳 无论谁拥有那片土地都没关系。
- ✅ 🇸🇪 Jag vet inte vem som ringde. 🇨🇳 我不知道是谁打来的电话。
- ✅ 🇸🇪 Fråga vem som vill ha kaffe. 🇨🇳 问一下谁想要咖啡。
- ❌ *Det spelar ingen roll vem äger marken.* ← 缺少 som，不正确

## 常见错误 (Common Mistakes)

- ⚠️ 遗漏 **som**：*vem äger* → 应为 *vem som äger*。
- ⚠️ 与 **vem** 用于直接问句混淆：直接问句无需 som（*Vem äger det?*）；宾语从句需要（*vem som äger det*）。
