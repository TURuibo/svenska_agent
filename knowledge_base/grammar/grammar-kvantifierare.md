# 📗 Kvantifierare — 量化词 (quantifiers)

级别: SFI B / CEFR A2
一句话: 表示「多少」的词；用作独立主语时代替名词，动词用复数（hälften 有时用单数）。

## 规则说明 (Rules)

📐 结构公式:
```
de flesta (+ V)          大多数人
många / få (+ V)         很多人 / 很少人
hälften av + 名词        一半
några / alla / ingen     一些 / 所有 / 没有
```

与中文对比: 中文「大多数/很多/一半」同样可单独作主语。
与英文对比: de flesta = most (people)；många = many；få = few；hälften = half。

## 详细讲解 (Detail)

| 词 | 含义 | 要点 |
|---|---|---|
| många | 很多 | 可数复数；单独用 = 很多人 |
| få | 很少 | 与动词 få 同形，注意语境 (få bakverk = 很少烘焙点心) |
| de flesta | 大多数 | 固定带 de，flesta 为 mycken 最高级 |
| hälften | 一半 | `hälften av barnen`；单独用 = 一半人 |
| några | 一些 | `några av dem` |
| alla | 所有 | 单独用 = 所有人 |

## 例句 (Examples)

- ✅ [[sent-de-flesta-trivs-bra-i-sitt-boende]] 🇸🇪 De flesta trivs bra i sitt boende. 🇨🇳 大多数人对住所满意。
- ✅ [[sent-hälften-äter-ensamma-fast-de-vill]] 🇸🇪 Hälften äter ensamma fast de vill äta tillsammans. 🇨🇳 一半人独自吃饭。
- ✅ [[sent-många-får-inte-bestämma-själva]] 🇸🇪 Många får inte bestämma själva. 🇨🇳 很多人不能自己决定。
- ✅ [[sent-det-är-få-bakverk-som-har-fått]] 🇸🇪 Det är få bakverk som har fått en egen dag. 🇨🇳 很少烘焙点心有自己的节日。
- ❌ De flesta trivs bra → *Flesta trivs bra* (缺 de)

## 常见错误 (Common Mistakes)

- ⚠️ 忘记 de：必须说 de flesta。
- ⚠️ få (少数) 与 få (得到/可以) 同形，看后面是名词还是动词。
- ⚠️ hälften 作主语时动词可用单数或复数，新闻中多用复数 (hälften äter)。
