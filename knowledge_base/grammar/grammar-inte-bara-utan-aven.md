# 📗 inte bara ... utan även/också — 不但……而且…… ("not only ... but also")

级别: B1
一句话: 表达递进关系"不但…而且/也…"；`även` 和 `också` 可互换，`även` 略偏书面。

## 规则说明 (Rules)

📐 结构公式:
```
inte bara [A] utan även/också [B]
```

## 详细讲解 (Detail)

`utan` 在这里不是普通的"没有"，而是承接前面否定的"不是A"，引出对比/补充的B，功能类似中文"而是/还有"。不要用 `men`（表转折对比）替代 `utan`。

与中文对比: "不但A而且B"
与英文对比: "not only A but also B"

## 例句 (Examples)

- ✅ [[sent-det-var-ingen-lätt-uppgift]] 🇸🇪 De mötte mycket motstånd, inte bara från män utan även från kvinnor. 🇨🇳 她们遇到很大阻力，不只来自男人，也来自女人。
- ❌ inte bara ... men även ← 常见错误，此处不用 "men"

## 常见错误 (Common Mistakes)

- ⚠️ "men" 通常表转折对比；"utan"才用于"不是A而是/还有B"的递进/对比结构。
