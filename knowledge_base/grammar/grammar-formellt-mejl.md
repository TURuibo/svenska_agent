# formellt mejl — 正式电子邮件结构 (formal email structure in Swedish)

级别: A2-B1
一句话: 瑞典正式邮件有固定的分区结构，从主题行到致意语都有惯用套语。

## 规则说明 (Rules)

正式瑞典语邮件的结构：

```
Ämne: [简短主题行]

Hej, / Hej [名字], / Till [机构]:

[段落1 — 自我介绍 + 写信目的]
[段落2 — 具体情况说明]
[段落3 — 请求/问题]

Jag är tacksam om ni kan svara mig snarast möjligt.

[联系方式]

Tack på förhand.

Med vänlig hälsning,
[姓名]
```

**关键惯用套语：**

| 功能 | 套语 |
|------|------|
| 开场 | *Hej,* / *Till hyresvärden,* |
| 说明写信目的 | *Jag skriver för att fråga om…* |
| 表达感激期待 | *Jag är tacksam om ni kan svara…* |
| 联系方式说明 | *Ni kan höra av er via e-post / ringa…* |
| 提前致谢 | *Tack på förhand.* |
| 结束敬语 | *Med vänlig hälsning,* |

与中文对比: 中文商务邮件通常更正式、有固定的称谓；瑞典语可以用 *Hej* 开头，即使对陌生机构，也不显失礼。
与英文对比: 类似 "Dear Sir/Madam" → "Hej," ; "Yours sincerely" → "Med vänlig hälsning,".

## 详细讲解 (Detail)

- **Ämne (subject):** 简短、信息明确，如 *Fråga om tillstånd för husdjur*.
- **Öppningshälsning:** *Hej,* is standard. If addressing an institution formally: *Till hyreskontoret:* is also acceptable.
- **Kropp (body):** Present your identity → state purpose → provide detail → make request.
- **Artighetsfraser (politeness phrases):** *Jag är tacksam om…*, *Tack på förhand*, *snarast möjligt* — all set expressions.
- **Avslutningshälsning:** *Med vänlig hälsning* (neutral-formal), *Med vänliga hälsningar* (slight variation), *Mvh* (informal abbreviation).

## 例句 (Examples)

- ✅ [[sent-darfor-vander-jag-mig-till]] 🇸🇪 Därför vänder jag mig till er med den här frågan. 🇨🇳 因此，我就此事向您咨询。
- ✅ [[sent-jag-ar-tacksam-om-ni-kan]] 🇸🇪 Jag är tacksam om ni kan svara mig snarast möjligt. 🇨🇳 如能尽快回复，我将不胜感激。
- ❌ *Kära hyresvärd,* ← 过于正式，瑞典语中不常用

## 常见错误 (Common Mistakes)

- ⚠️ Omitting *Ämne:* — always include a clear subject line.
- ⚠️ Using *Kära* (Dear) — too formal/archaic; use *Hej* instead.
- ⚠️ Writing *Tack för förhand* instead of *Tack på förhand* — the preposition is *på*.
