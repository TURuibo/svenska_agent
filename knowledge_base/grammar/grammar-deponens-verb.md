# 📗 deponens-verb — 异态动词 (deponent verbs)

级别: SFI C / B1
一句话: 一小组动词**所有形式都带 -s**（skämmas, finnas, hoppas, minnas, trivas, lyckas, andas, låtsas…），但意思是**主动**的，不是被动——它们没有不带 -s 的原形，也不能再被动化。

## 规则说明 (Rules)

📐 结构公式:
```
infinitiv   presens   preteritum   supinum     imperativ
skämma-s    skäm-s    skämde-s     skämt-s     skäms!
finna-s     finn-s    fann-s       funnit-s    —
hoppa-s     hoppa-s   hoppade-s    hoppat-s    hoppas!
trivas      trivs     trivdes      trivts      —
minnas      minns     mindes       mints       —
```
规律：先按动词组变位（skämma 是第 2 类：skäm-/skämde-/skämt-），**再在每个形式末尾加 -s**；presens 里 -er 脱落（skämmer+s → skäms，finner+s → finns）。

与中文对比: 中文没有形态标记，"难为情 / 记得 / 希望 / 存在" 都是普通动词——所以中文母语者最常错的是**忘记加 -s**（✗ *jag skämma*、✗ *det finn*）或把它当被动翻译（"被羞耻"）。
与英文对比: 类似拉丁语 deponent；英语没有对应形式。注意 *hoppas* ≠ hope 的被动，*finns* ≠ "is found"（虽然来源如此），直接译 hope / there is。

## 详细讲解 (Detail)

| 动词 | 意思 | 常见搭配 |
|------|------|----------|
| **skämmas** | 感到羞耻、难为情 | skämmas **för** något / skämmas **över** |
| **finnas** | 存在、有 | det finns … |
| **hoppas** | 希望 | jag hoppas **att** … / hoppas **på** |
| **minnas** | 记得 | jag minns inte |
| **trivas** | 感到自在、喜欢（环境） | trivas **på** jobbet / **med** kollegorna |
| **lyckas** | 成功做到 | lyckas **med** något |
| **andas** | 呼吸 | andas lugnt |
| **låtsas** | 假装 | låtsas **att** / låtsas **som om** |
| **umgås** | 交往、相处 | umgås **med** vänner |
| **kräkas** | 呕吐 | (A2 幼儿园高频) |

- 因为 -s 已被"占用"，这些动词**不能再做 s-passiv**；要表达被动得换说法。
- 别和三种其它 -s 用法混淆：① **s-passiv**（*dörren stängs* = 被关）② **相互 s-verb**（*vi ses, vi träffas* = 互相）③ 反身 *sig*（*anmäla sig* 不带 -s）。判断法：能否去掉 -s 变回主动？deponens **不能**（*skämma* 不存在）。

## 例句 (Examples)

- ✅ [[sent-det-är-inget-att-skämmas-för]] 🇸🇪 Det är inget att skämmas för – alla kan få lus. 🇨🇳 这没什么好难为情的——谁都可能长头虱。
- ✅ 🇸🇪 Jag hoppas att Leo trivs på förskolan. 🇨🇳 我希望 Leo 在幼儿园过得开心。
- ✅ 🇸🇪 Det finns extrakläder i lådan. 🇨🇳 抽屉里有备用衣服。
- ✅ 🇸🇪 Han skämdes när han glömde mössan. 🇨🇳 他忘了帽子时很难为情。
- ✅ 🇸🇪 Barnet kräktes i natt. 🇨🇳 孩子昨晚吐了。
- ❌ *Jag skämma mig.* ← 常见错误（没有 skämma 这个词；正确 *Jag skäms.*）

## 常见错误 (Common Mistakes)

- ⚠️ 漏掉 -s：✗ *det finn en park* → ✅ *det finns en park*。
- ⚠️ presens 多写 -er：✗ *jag hoppases / det finnes* → ✅ *hoppas / finns*。
- ⚠️ 当被动翻译："skämmas" 不是"被羞辱"，是自己"感到羞耻"。
- ⚠️ 搭配介词记错：skämmas **för**、trivas **med/på**、lyckas **med**、hoppas **på**。
