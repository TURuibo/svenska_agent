# stängt vs öppet — 告示中的中性形容词

## 核心规则

在**告示/公告**中，`stängt` 和 `öppet` 以**中性（neutrum）形式**出现，
无论所指名词的性别。这是固定的"告示体"用法。

```
[名词（无论性别）] är öppet / stängt.
```

## 形容词变形表

| 形式 | 用于 | 例子 |
|------|------|------|
| `öppen / stängd` | utrum 修饰语 | `en öppen dörr` / `en stängd butik` |
| `öppet / stängt` | neutrum 修饰语 **+ 告示体** | `ett öppet möte` / 告示上的 `Stängt` |
| `öppna / stängda` | plural / definit | `öppna butiker` / `stängda skolor` |

## 为什么告示用中性？

告示中 `stängt / öppet` 是**谓语形容词配合 `det är`（隐含）**：

```
(Det är) stängt.    = (It is) closed.
(Det är) öppet.     = (It is) open.
```

`det` 是中性的，所以谓语形容词取中性形式 → `stängt` / `öppet`。

## 常见告示组合

- `Öppet` — 营业中/开放
- `Stängt` — 关闭/不营业
- `Stängt idag` — 今日关闭
- `Stängt för sommaren` — 暑期关闭
- `Tillfälligt stängt` — 临时关闭

## 例句

- Gymmet är stängt på helger under sommaren. — 健身房夏季周末不开放。
- Obs! Receptionen är stängt 12–13. — 注意！接待处12点到13点关闭。（告示用法）
- Biblioteket är öppet även på söndagar. — 图书馆周日也开放。
