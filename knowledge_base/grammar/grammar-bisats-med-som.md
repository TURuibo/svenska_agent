# 📗 bisats med som — som引导的关系从句 (Relative clause introduced by som)

级别: A2-B1
一句话: `som` 引导关系从句，修饰前面的名词，相当于中文"……的"或英文 "that/which/who"。

## 规则说明 (Rules)

📐 结构公式:
```
[先行词(名词)] + som + [从句内容]
ubåtar          som   Sverige har beställt
潜艇            (是)  瑞典已经订购的
→ "瑞典已经订购的潜艇"
```

与中文对比: 中文关系从句前置（"……的 + 名词"）；瑞典语 `som` 从句后置（"名词 + som + ……"）。
与英文对比: 类似英语 that/which/who，但 `som` 不分人/物、不分主格宾格，统一用 `som`。

## 详细讲解 (Detail)

- `som` 在从句中可作主语或宾语：
  - 作主语：`mannen som bor här` (住在这里的那个男人) — som 后直接跟动词。
  - 作宾语：`ubåtar som Sverige har beställt` (瑞典已订购的潜艇) — som 后跟主语+动词，som 代替宾语位置。
- 当 `som` 作宾语且非正式语体时，常可省略：`ubåtar (som) Sverige har beställt`。
- bisats 内部遵循 bisats 语序（BIFF）：否定词/satsadverbial 放在主语和动词之间，如 `som han inte känner`。

## 例句 (Examples)

- ✅ [[sent-men-det-betyder-ocksa-att]] 🇸🇪 Det svenska försvaret kan få vänta på ubåtar som Sverige har beställt. 🇨🇳 瑞典国防军可能要为瑞典自己订购的潜艇多等一段时间。
- ✅ 🇸🇪 Boken som jag läste var spännande. 🇨🇳 我读的那本书很精彩。
- ❌ `ubåtar vilka Sverige har beställt` ← `vilka` 在口语关系从句中不自然，应使用 `som`

## 常见错误 (Common Mistakes)

- ⚠️ 在 som 从句内使用主句语序（动词提前）而非 bisats 语序。
- ⚠️ 误用 `vilken/vilka/vilket` 代替 `som`（这些更正式/书面，日常用 `som`）。
