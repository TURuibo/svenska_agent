# 📗 modal verb kan + bli — 情态动词 kan + bli 构成推测 (modal kan + bli for prediction/possibility)

级别: A2
一句话: kan bli = "可能变成/可能会是"，用于天气预报、赛事预测等不确定性较高的推测。

## 规则说明 (Rules)

📐 结构公式:
```
主语 + kan + bli + 形容词/名词
Det  + kan + bli + 35 grader varmt   （可能达到35度）
Det  + kan + bli + Frankrike eller Norge  （可能是法国或挪威）
```

**与 kommer att + infinitiv 的区别：**

| 结构 | 语气 | 用法 |
|------|------|------|
| kommer att + infinitiv | 较确定的将来 | 我确信会发生 |
| kan + bli | 推测/可能性 | 不确定，只是可能 |

与中文对比: "kan bli" ≈ 中文"可能会/也许会"。
与英文对比: "can become / might be / could be"。

## 详细讲解 (Detail)

kan bli 常见语境：
1. **天气预报：** Det kan bli 35 grader varmt i södra Sverige.（南瑞典可能高达35度）
2. **赛事预测：** Det kan bli Frankrike eller Norge.（可能是法国或挪威）
3. **一般推测：** Det kan bli problem.（可能会有问题）

**bli 在此是系动词（成为/变成）**，不是被动助动词：

| bli = 变成/成为（系动词） | bli = 被（被动助动词） |
|---------------------------|------------------------|
| Det kan bli varmt. | Han blev skadad. |
| kan bli Frankrike | —（被动不与 kan 这样搭配） |

## 例句 (Examples)

- ✅ 🇸🇪 Det kan bli 35 grader varmt i södra Sverige. 🇨🇳 南瑞典可能高达35摄氏度。
- ✅ 🇸🇪 Det kan bli Frankrike eller Norge i nästa match. 🇨🇳 下一场可能对阵法国或挪威。
- ✅ 🇸🇪 Det kan bli regn på eftermiddagen. 🇨🇳 下午可能会下雨。
- ❌ "Det kan komma att bli" ← 重复确定性表达，语气混乱；用其中一种即可

## 常见错误 (Common Mistakes)

- ⚠️ 混淆 kan bli（推测）与 kommer att bli（确定将来）
- ⚠️ 将 kan + bli 中的 bli 误解为被动；此处 bli 是系动词
