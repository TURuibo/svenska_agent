# 📗 brevmall – formellt och informellt brev — 信件模板：正式与非正式 (letter template: formal and informal)

级别: SFI C / CEFR A2–B1
一句话: SFI 写作讲义里老师手写批注的信件骨架：地点日期 → 问候 → 开头 → 正文 → 结尾 → 结束问候 → 署名；正式/非正式只是每一格的措辞不同。

## 规则说明 (Rules)

📐 结构公式（老师批注 = 6 + 1 格）:
```
Plats + Datum                          Rissne 2017-11-21      (右上角)
Hälsningsfras                          Hej Martin! / Hej skolans ledning,
(In)formell inledning                  为什么写 / 评论对方的处境
Huvuddel                               ┬ 给 tips och råd           (informellt mejl, s. 3)
                                       ├ 评论朋友的 förslag + 自己的 förslag + motivera (s. 4)
                                       ├ 给 förslag + motivera                 (formellt, s. 5)
                                       └ 写 åsikter                            (formellt, s. 6)
(In)formell avslutning                 Hoppas att … / Tack för att …
(In)formell hälsningsfras              Hälsningar / Kramar / Vänliga hälsningar / Med vänlig hälsning
Namn                                   Sofia / Annchi Fang
```

与中文对比: 中文信有"称呼—正文—祝语—署名—日期"，日期在**末尾**；瑞典语把 **地点+日期放在最前（右上角）**。
与英文对比: 英文 "Dear X, … Yours sincerely"；瑞典语正式信开头也常用 *Hej*（不用 Kära），正式度主要靠结束语和措辞体现。

## 详细讲解 (Detail)

### 📊 正式 vs 非正式对照（来自 4 封范文）

| 位置 | 非正式（s. 3 / s. 4） | 正式（s. 5 / s. 6） |
|---|---|---|
| Plats + Datum | Rissne 2017-11-21 · Sundbyberg 23 maj 2018 | Hallonbergen 19-06-28 · Hallonbergen 2017-05-24 |
| Hälsningsfras | *Hej Martin!* · *Hej!* | *Hej skolans ledning,* · *Hej Sundbybergs kommun!* |
| Inledning | *Jag känner igen din situation och jag förstår att det känns jobbigt.* · *Tänk att Anna fyller 30 år!* | *Vad positivt att ni frågar oss elever …!* · *Igår läste jag i tidningen att … Därför skriver jag till er.* |
| Tilltal 称呼对方 | du / ni（朋友们） | ni（单位）；自我介绍 *Jag heter … och …* |
| Huvuddel | 建议：*Du skulle kunna …* ；提议：*Jag tycker att vi ska …* | *Jag har flera förslag som jag skulle vilja framföra* ；*Jag tycker inte att ni ska …* |
| Avslutning | *Hoppas att det löser sig!* · *Hoppas allt är bra med er! Vi hörs och ses snart* | *Jag uppskattar att … och jag hoppas att ni …* · *Tack för att ni har läst mitt brev. Jag hoppas att ni tänker på det jag har sagt.* |
| Hälsningsfras (结束) | *Hälsningar* · *Kramar* | *Vänliga hälsningar* · *Med vänlig hälsning* |
| Namn | 只写名 *Sofia* / *Maria* | 全名 *Annchi Fang* / *Akberet Tesfamariam i Hallonbergen* |
| 语气 | 省略主语（*Hoppas att …*）、*kul*、*jätteglad* | 完整句、*skulle vilja*、*undrar jag om det skulle vara möjligt att …* |

### 💬 常用句式（按功能）

| 功能 | 句式 |
|---|---|
| 共情（非正式开头） | *Jag känner igen din situation* · *jag förstår att det känns jobbigt* · *Tänk att …!* |
| 给 tips och råd | *Du skulle kunna säga/fråga …* · *Du kan förklara …* · *Det är viktigt att …* · *Jag tänker att det är viktigt att …* |
| 反驳 / 评论别人的 förslag | *jag tycker inte att vi ska …* · *Det känns lite tråkigt att …* · *Jag förstår att … Men om ni …* |
| 自己的 förslag | *Jag tycker att vi ska …* · *Jag tycker att det vore roligare att …* · *Därför föreslår jag att …* |
| 征求意见（非正式） | *Vad tror ni om det?* · *Vad tycker ni?* · *Svara så snabbt ni kan!* |
| 礼貌请求（正式） | *Jag har flera förslag som jag skulle vilja framföra* · *undrar jag om det skulle vara möjligt att …?* |
| 写 åsikter | *Jag vill säga att jag tycker att …* · *Jag tycker inte att ni ska …* · *… betyder jättemycket för oss* |
| 列举 | *Men jag tror att …* → *En annan sak som …* → *Sist men inte minst …* |
| 结束 | *Hoppas att …* · *Vi hörs och ses snart* · *Tack för att ni har läst mitt brev* · *Jag hoppas att ni …* |

### 四种 huvuddel 对应的任务

| 讲义页 | 信类型 | Huvuddel 要做的事 |
|---|---|---|
| s. 3 | informellt mejl | 给朋友 **tips och råd**（先定规矩，再建议运动） |
| s. 4 | informellt brev | **评论**朋友的 förslag → 写**自己的 förslag** → **motivera** |
| s. 5 | formellt brev | 给 **förslag** 并**逐条 motivera**（3 条） |
| s. 6 | formellt brev | 写 **åsikter**（先理由，再让步，再替代方案） |

## 例句 (Examples)

- ✅ 🇸🇪 Hej Martin! … Hälsningar / Sofia 🇨🇳 非正式：*Hej + 名字!* … *Hälsningar* + 只写名。（[[source-2026-11-17-informellt-mejl-tips-och-rad]]）
- ✅ 🇸🇪 Hoppas allt är bra med er! Vi hörs och ses snart. Kramar, Maria 🇨🇳 非正式结尾 + *Kramar*。（[[source-2026-11-17-informellt-brev-med-forslag]]）
- ✅ 🇸🇪 Hej skolans ledning, … Vänliga hälsningar / Annchi Fang 🇨🇳 正式：*Hej + 机构,*（逗号）+ 全名。（[[source-2026-11-17-formellt-brev-med-forslag]]）
- ✅ 🇸🇪 Hej Sundbybergs kommun! … Med vänlig hälsning 🇨🇳 对市政府的意见信。（[[source-2026-11-17-formellt-brev-till-kommunen]]）
- ❌ *Kramar* 放在给 kommunen 的信末 ← 过于亲密
- ❌ *Hälsningar* 放在正式信 ← 太随意，用 *Vänliga hälsningar / Med vänlig hälsning*

## 常见错误 (Common Mistakes)

- ⚠️ 忘记 **Plats + Datum**（放最上面，不是最后）。
- ⚠️ 正式信里用口语省略（*Hoppas att …* 省 jag）、*kul/jättebra* 过多。
- ⚠️ 只列观点不 **motivera**——huvuddel 的核心是「观点 + 理由」。
- ⚠️ 日期格式：*2017-11-21*（ÅÅÅÅ-MM-DD）或简写 *19-06-28*；口头式 *23 maj 2018*。
- ⚠️ 结束语后的逗号：*Kramar* / *Hälsningar* 后直接换行写名字。
