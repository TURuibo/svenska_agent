# 📗 att-sats (objekt- och subjektsatser) — att从句（宾语从句与主语从句） (att-clause)

级别: SFI B-C / CEFR A2
一句话: `att` 引导从句作宾语或主语（对应英语 that-clause）；`för att` 引导目的从句（为了）。

## 规则说明 (Rules)

📐 结构公式:
```
类型1 — 宾语从句 (objektsats):
[主句] + att + [从句动词保持bisats语序]
例: De förstod   att   barn behöver leka.
     主句         att    宾语从句

类型2 — 目的从句 (för att + infinitiv):
[主句] + för att + [不定式]
例: barn behöver leka   för att   må bra.
    主句                för att   目的不定式（为了身心健康）
```

与中文对比: 中文用"说/认为/知道 + [内容]"不加"说"字前的标志词；瑞典语必须加 `att`。
与英文对比: 英语 *I think that he is right.* 中 "that" 可省略；瑞典语的 `att` 通常不可省略。

## 详细讲解 (Detail)

### 类型1：att-sats 作宾语（最常见）

常见触发动词：`tycka` (觉得), `tro` (相信), `veta` (知道), `förstå` (理解), `säga` (说), `berätta` (告诉)...

```
De förstod också   att   barn behöver leka.
他们也理解          that  孩子需要玩耍
```

### 类型2：för att + infinitiv（目的）

⚠️ 注意：`att` 和 `för att` 是不同结构！
- `att` = that（引导从句，有主语+动词）
- `för att` = in order to（引导目的不定式，无主语）

```
barn behöver leka   för att   må bra
孩子需要玩耍         为了       身心健康（不定式，无主语）
```

### att-sats 里的语序是 bisats 语序！

bisats 内 `inte` 等否定词/副词放在**有限动词前**：
```
Jag vet att hon inte är hemma.  (不是 *...att hon är inte hemma*)
```

## 例句 (Examples)

- ✅ [[sent-de-forstod-ocksa-att-barn-behover-leka]] 🇸🇪 De förstod också **att** barn behöver leka **för att** må bra. 🇨🇳 他们也理解孩子需要玩耍才能身心健康。
- ✅ [[sent-de-var-oroliga-att-barn-som-laste-om-pippi]] 🇸🇪 De var oroliga **att** barn som läste om Pippi skulle börja göra som henne. 🇨🇳 他们担心读了皮皮故事的孩子会开始模仿她。
- ✅ [[sent-ryssland-sager-att-det-ar-ett-svar]] 🇸🇪 Ryssland säger **att** det är ett svar på Ukrainas attacker. 🇨🇳 俄罗斯称这是对乌克兰袭击的回应。
- ✅ [[sent-det-gar-inte-att-bevisa-att]] 🇸🇪 Det går inte att bevisa **att** hon gjort något brott. 🇨🇳 无法证明她犯了罪。（注意：先有 `att + infinitiv`，再嵌套一个 `att`-从句）
- ❌ *De förstod att barn inte är trött.* ← 注意：不是 *att barn är inte trött*

## 常见错误 (Common Mistakes)

- ⚠️ 混淆 `att`（that-从句）和 `för att`（为了-目的从句）。
- ⚠️ att-sats 内忘记使用 bisats 语序（否定词位置错误）。
