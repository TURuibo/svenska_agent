# 📗 för (samordnande konjunktion) — för = 因为（并列连词，主句语序） (för as a coordinating conjunction)

级别: SFI B / CEFR A2-B1
一句话: `för`（因为）是**并列连词 (samordnande konjunktion)**，连接两个完整主句，后面的从句保持**正常主句语序**（V2），不像从属连词那样触发 bisats 语序。

## 规则说明 (Rules)

📐 结构公式:
```
[完整主句], för [完整主句（V2 语序）].
```

与中文对比: 中文"因为"可以放在句首或句中，较自由；瑞典语 `för` **只能**放在两个主句之间，绝不能放句首。
与英文对比: 类似英语的 "for"（书面/文学用法，如 "I stayed, for it was raining."），但瑞典语 `för` 在口语中很常用。

## 详细讲解 (Detail)

`för` 属于并列连词（samordnande konjunktioner，口诀 FANBOYS 的瑞典语版：och, men, för, så, eller, ...）。
它连接的两个部分都是**独立主句**，因此第二个主句仍然遵守 V2 规则——变位动词紧跟在主语后面（或如果主语后移，动词仍在第二位）。

**关键区别** vs 从属连词 `eftersom`/`därför att`（这些引导的是从句 bisats，用 BIFF 语序，`inte` 等副词放在动词前）：

| | för | eftersom / därför att |
|---|---|---|
| 连词类型 | 并列 (samordnande) | 从属 (underordnande) |
| 后接语序 | 正常主句语序 (V2) | bisats 语序 (BIFF) |
| 位置 | 只能在两个主句之间 | 可放句首或句中 |
| 例句 | *..., för jag känner att jag gör nytta.* | *Eftersom jag känner att jag gör nytta, ...* |

## 例句 (Examples)

- ✅ [[sent-jag-tycker-om-mitt-jobb-for]] 🇸🇪 Jag tycker om mitt jobb, för jag känner att jag gör nytta. 🇨🇳 我喜欢我的工作，因为我觉得自己在做有意义的事。（för 后 = 正常语序：jag känner）
- ✅ 🇸🇪 Hon stannade hemma, för hon var sjuk. 🇨🇳 她待在家里，因为她生病了。（för 后正常语序，不是 *för var hon sjuk*）
- ❌ *För jag känner att jag gör nytta, tycker jag om mitt jobb.* ← `för` 不能放句首（这是 eftersom 的用法，不是 för 的）

## 常见错误 (Common Mistakes)

- ⚠️ 把 `för` 错误地放在句首（受中文"因为"可前置影响）——`för` 严格只能放在两个完整主句之间。
- ⚠️ 把 `för` 后的从句误用 bisats 语序（如加 `inte` 到动词前）——`för` 后面语序和普通主句一样。
