# 📗 mängd-jämförelse — 量的比较（多/少）(comparing quantity)

级别: A2
一句话: 表达「多/少」时，瑞典语分**可数**和**不可数**两套词，各有自己的比较级和最高级——别和形容词比较级混。

## 规则说明 (Rules)

📐 三套体系:
```
可数名词 (räknebara):   många  →  fler   →  flest    （多 → 更多 → 最多）
                        få     →  färre  →  färst    （少 → 更少 → 最少）

不可数「量」(oräknebart): mycket →  mer    →  mest     （多 → 更多 → 最多）
                        lite   →  mindre →  minst    （少 → 更少 → 最少）

形容词 liten/låg 等:     liten/låg → mindre/lägre → minst/lägst （小/低 …）
```

与中文对比: 中文「多/少」不分可数不可数，一律「最多/最少」；瑞典语必须按名词是否可数选词。
与英文对比: 几乎一一对应——many/more/most、few/fewer/fewest、much/more/most、little/less/least。

## 详细讲解 (Detail)

**怎么选？看后面的名词能不能数：**
- 能数（böcker, produkter, enheter, personer）→ 用 **många/fler/flest**、**få/färre/färst**。
  - 卖得最多的产品：`produkten med **flest** sålda enheter`
  - 卖得最少的产品：`produkten med **färst** sålda enheter`
- 不能数 / 抽象量（försäljning 销量, tid, vatten, pengar 作为量）→ 用 **mycket/mer/mest**、**lite/mindre/minst**，或形容词 **hög/låg → högst/lägst**。
  - 最少的销售量：`den **lägsta** försäljningen` / `**minst** försäljning` / `den **lägsta** försäljningsvolymen`
  - 最多的销售量：`den **högsta** försäljningen` / `**mest** försäljning`

**⚠️ flest = 最多，不是「最少」！** 想表达「最少」用 färst（可数）或 minst/lägst（不可数/量）。

## 例句 (Examples)

- ✅ 🇸🇪 Vilken produkt har **lägst** försäljning? — 🇨🇳 哪个产品销量最少？
- ✅ 🇸🇪 Den här butiken sålde **minst** i hela landet. — 🇨🇳 这家店是全国卖得最少的。
- ✅ 🇸🇪 Han har **flest** poäng, hon har **färst**. — 🇨🇳 他分数最多，她最少。
- ✅ 🇸🇪 Vi har **mer** tid men **färre** uppgifter idag. — 🇨🇳 今天我们时间更多，但任务更少。
- ❌ *flest försäljning* ← 销量不可数，应说 **mest/högst försäljning**。

## 常见错误 (Common Mistakes)

- ⚠️ 把 `flest`（最多）当成「最少」——记反了。最少 = färst / minst。
- ⚠️ 给不可数名词用 fler/färre：应该用 mer/mindre。如 `mer vatten`✅ 而非 *fler vatten*❌。
- ⚠️ försäljning（销量/销售）算不可数概念，用 mest/minst/högst/lägst，不用 flest/färst。
