# 📗 preposition sist i relativsats — 介词留在关系从句末尾 (stranded preposition in relative clause)

级别: SFI C / CEFR B1
一句话: 用 som / vad 引导从句时，介词不放在关系词前面，而是**留在从句最后**：*grupper som man kan bli medlem **i***。

## 规则说明 (Rules)

📐 结构公式:
```
名词 + som + 主语 + 动词 + 介词
grupper som man kan bli medlem i
ämnen   att samtala om                (att + 不定式 + 介词)
vad de vill prata om                  (疑问词从句 + 介词)
```

与中文对比: 中文把介词内容放前面做定语："可以成为其成员的群组"；瑞典语按"群组，人们可以成为 [它的] 成员 **在**"的顺序，介词落到句尾。
与英文对比: 英语口语同样 *groups (that) you can become a member **of***；书面可 *of which*，瑞典语**一般不**用 *i vilka*（过于书面）。

## 详细讲解 (Detail)

| 类型 | 例 | 拆解 |
|---|---|---|
| som 从句 | *grupper som man kan bli medlem **i*** | bli medlem **i** grupper → 介词 i 跟着动词词组 |
| att + inf. | *ämnen att samtala **om*** | samtala **om** ämnen |
| 疑问从句 | *vad de vill prata **om*** | prata **om** vad |
| 疑问句 | *Vad pratar du **om**?* | 疑问句同理，介词在句末 |

- 介词与动词/形容词搭配固定（*bli medlem i, samtala om, prata om, tänka på*），所以要连着记。
- som 在从句里是介词的宾语，som 本身不能省略时放最前。

## 例句 (Examples)

- ✅ 🇸🇪 Det finns grupper som man kan bli medlem i där man kan prata om sina intressen. 🇨🇳 有一些群组你可以加入，在里面聊自己的兴趣。（[[source-2026-11-17-sociala-medier]]）
- ✅ 🇸🇪 Caféet skulle kunna erbjuda ämnen att samtala om. 🇨🇳 咖啡馆可以提供一些聊天的话题。（[[source-2026-11-17-formellt-brev-med-forslag]]）
- ✅ 🇸🇪 Eleverna kunde få välja själva vad de vill prata om. 🇨🇳 学生可以自己选择想聊什么。
- ✅ 🇸🇪 Det är en klubb som jag har hört mycket om. 🇨🇳 这是一个我听说过很多的俱乐部。
- ❌ *grupper i som man kan bli medlem* ← 介词不能提到 som 前面（"i vilka" 太书面，不建议）

## 常见错误 (Common Mistakes)

- ⚠️ 英语母语者想写 *i vilka*：虽然语法上可行，SFI 写作用句尾介词更自然。
- ⚠️ 漏掉介词：*grupper som man kan bli medlem* ✗。
- ⚠️ 搭配介词用错（*prata på* ✗ → *prata om* ✓）。
