# 📗 satsfläta — 嵌套从句 (det som han tyckte var roligast)

级别: SFI D / CEFR B1–B2
一句话: `som`（或疑问词）从一个**嵌在 tycka/tro/veta 后面的从句**里"跳"出来，于是两层从句编成一条辫子（fläta = 辫子）：`det som [han tyckte] var roligast` = "他觉得最好玩的那件事"。

## 规则说明 (Rules)

📐 结构公式:
```
det/den/något + som + [S + tycka/tro/veta/säga …] + V + 其余
det som        han tyckte                          var  roligast
                                                     ↑ som 是 "var roligast" 的主语
```

拆解步骤：
1. 去掉插在中间的 `han tyckte` → `det som var roligast`（最好玩的那件事）
2. 再把 `han tyckte` 放回去 → "**他觉得**最好玩的那件事"

与中文对比: 中文说"他觉得最好玩的事"，"他觉得"直接插在定语里，结构几乎一样——按中文语感读反而最顺。
与英文对比: 英语也有：*the thing **that** he thought **was** the most fun*。注意英语这里不能加 that 在 thought 后面，瑞典语同样**不能**说 ~~det som han tyckte att var roligast~~。

## 详细讲解 (Detail)

- **常见触发动词**：tycka, tro, veta, säga, hoppas, anse, mena —— 它们本来后面接 att-从句（han tyckte att X var roligast）。当 X 被 som / vad / vem 提到前面时，att 消失，形成 satsfläta。
- **som 是被嵌从句的主语时**，嵌入从句里不再有主语：det som han tyckte **var** roligast（var 前面没有 det）。
- **疑问句也一样**：Vem tror du **vinner**?（你认为谁会赢？）/ Vad tror du **händer** nu?（你觉得接下来会发生什么？）
- **阅读技巧**：看到 `som/vad/vem + 代词 + tycker/tror/vet + 动词` 连在一起，先把"代词 + tycker/tror"括起来，剩下的部分就是正常的句子。

## 例句 (Examples)

- ✅ [[source-2026-09-22-nils-van-der-poel]] 🇸🇪 …han slutade med det som han tyckte var roligast – att åka skateboard. 🇨🇳 ……他放弃了他觉得最好玩的事——玩滑板。
- ✅ 🇸🇪 Det är en film som jag tror att du kommer att gilla. 🇨🇳 这是一部我觉得你会喜欢的电影。（som 是 gilla 的宾语时，att 可以保留）
- ✅ 🇸🇪 Vem tror du vinner matchen? 🇨🇳 你觉得谁会赢这场比赛？
- ✅ 🇸🇪 Hon gjorde det som hon visste var rätt. 🇨🇳 她做了她知道是对的事。
- ❌ det som han tyckte **att** var roligast ← som 作嵌入从句主语时不能加 att

## 常见错误 (Common Mistakes)

- ⚠️ 把 `han tyckte var` 读成"他觉得是"然后找不到主语——主语就是前面的 som（指 det）。
- ⚠️ 在 som 作主语的嵌入从句里加 att 或加 det：~~det som han tyckte att det var roligast~~。
