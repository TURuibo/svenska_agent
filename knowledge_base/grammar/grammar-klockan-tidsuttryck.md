# 📗 Klockan — tidsuttryck — 时钟时间表达 (telling the time)

级别: SFI B / CEFR A1
一句话: 整点说 *klockan + 数字*；半点说 **halv + 下一个整点**；一刻说 **kvart över X**（X:15）/ **kvart i X**（X 差一刻）；分钟说 *fem över / tio i*。口语常省略 klockan。

## 规则说明 (Rules)

📐 结构公式:
```
整点      klockan nio            = 9:00        (Klockan är nio. / Vi äter klockan nio.)
半点      halv sju               = 6:30  ⚠️ 指"半小时到七点"，不是七点半
一刻      kvart över tolv        = 12:15
差一刻    kvart i tolv           = 11:45
分钟      fem över tre           = 3:05     tio i tre          = 2:50
半点前后  fem i halv sju         = 6:25     fem över halv sju  = 6:35
时段      från kvart i tolv till halv två   = 11:45–13:30

写法      kl. 8 / 08.00 / 17.30 (书面通知常用 24 小时制 + 点号)
```

与中文对比: 中文"六点半"是"六点 + 半"，瑞典语 **halv sju** 是"到七点还差半"——整整错一小时，是中文母语者最典型的错误。"差一刻十二点" = kvart i tolv 的逻辑和中文倒是相同。
与英文对比: half past six 是"过六点半小时"，瑞典语 halv sju 是"半个七点" —— 英语思维同样会错。quarter to / quarter past 对应 kvart i / kvart över。

## 详细讲解 (Detail)

| 瑞典语 | 时间 | 记忆法 |
|---|---|---|
| klockan sju | 7:00 | 整点直接说数字 |
| fem över sju | 7:05 | över = 过 |
| kvart över sju | 7:15 | kvart = 15 分钟 |
| tjugo över sju | 7:20 | |
| fem i halv åtta | 7:25 | 以"半点"为参照：差 5 分到 7:30 |
| **halv åtta** | **7:30** | ⚠️ 想成"7 点半 = halv 8" |
| fem över halv åtta | 7:35 | 过 7:30 五分钟 |
| tjugo i åtta | 7:40 | i = 差 |
| kvart i åtta | 7:45 | |
| fem i åtta | 7:55 | |

- 问时间：*Hur mycket är klockan?* / *Vad är klockan?* — 答：*Klockan är halv tre.* / *Den är halv tre.*
- 说几点做事：**klockan + 时刻**（无介词！不说 på klockan）：*Vi öppnar klockan halv sju.*
- 时间状语放句首要 **V2**：*Klockan nio **har** vi samling.*
- 上/下午区分：klockan sju **på morgonen** / **på kvällen**；书面用 07.00 / 19.00。
- 本篇 Solrosen 作息全用此系统：halv sju 开门 → halv åtta 早餐 → nio 晨会 → elva 午饭 → kvart i tolv–halv två 午睡 → halv tre 加餐 → tre 开始接 → halv sex 关门。

- ❌ *halv sju = 7:30* ← 错一小时，是 6:30
- ❌ *Vi äter på klockan elva.* ← klockan 前不加介词

## 常见错误 (Common Mistakes)

- ⚠️ halv X 理解成 X 点半（应是 X−1 点半）。
- ⚠️ kvart i / kvart över 搞反：i = 差（还没到），över = 过。
- ⚠️ klockan 前加 på / vid（*på klockan tre* ✗ → klockan tre；"大约三点"才用 vid tretiden）。
- ⚠️ 时间开头忘倒装：*Klockan nio vi har samling* ✗。
