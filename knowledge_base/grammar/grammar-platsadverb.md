# Platsadverb — 方位副词 (place adverbs)

级别: A2
一句话: 方位副词描述某物所在的位置，固定在句中，不随名词变格。

## 规则说明 (Rules)

📐 结构公式:
```
[动词 stå/ligga/sitta/finnas] + [platsadverb]
Mjölken står  längst bak.
       V       PLATS-ADV
```

与中文对比: 中文方位词常作定语（"最里面的货架"），瑞典语 platsadverb 通常在谓语之后作状语。
与英文对比: 与英文 "all the way back", "over there", "right in front" 等结构类似。

## 详细讲解 (Detail)

常用超市/室内方位副词：

| 副词 | 含义 |
|------|------|
| längst bak | 最里面（靠后） |
| längst fram | 最前面 |
| längst ner | 最下面（货架底层） |
| längst upp | 最上面（货架顶层） |
| där borta | 那边 → see [[där-borta]] |
| där framme | 前面那里（可见的较近处） |
| rakt fram | 一直往前 → see [[rakt-fram]] |

**区别于 riktningsadverb（方向副词）：**
- **platsadverb** 描述位置（回答 VAR — 在哪里）：*Mjölken finns **längst bak**.*
- **[[grammar-riktnings-adverb|riktningsadverb]]** 描述移动方向（回答 VÅR — 往哪里）：*Gå **rakt fram**.*（注意 rakt fram 两种用法均常见）

## 例句 (Examples)

- ✅ [[sent-den-star-langst-bak-till-hoger-bredvid-ostarna]] 🇸🇪 Den står längst bak till höger, bredvid ostarna. 🇨🇳 它在最里面靠右边，奶酪旁边。
- ✅ [[sent-ja-den-star-pa-samma-hylla-langst-ner]] 🇸🇪 Ja, den står på samma hylla, längst ner. 🇨🇳 有的，在同一个货架上，最下面。
- ✅ [[sent-ja-de-kostar-nu-nio-kronor-kilot-du-vager-dem-sjalv-vid-vagen-dar-borta]] 🇸🇪 Du väger dem själv vid vågen där borta. 🇨🇳 你自己在那边的秤上称重。
- ✅ [[sent-sjalvklart-du-kan-betala-vid-kassan-dar-framme]] 🇸🇪 Du kan betala vid kassan där framme. 🇨🇳 你可以在前面的收银台付款。
- ❌ *Mjölken är längst bakåt.* ← 应用 längst bak（位置），不用 bakåt（方向）

## 常见错误 (Common Mistakes)

- ⚠️ 混用 **längst bak**（位置）和 **bakåt**（向后方向）——位置用 bak/fram/ner/upp，移动方向用 bakåt/framåt/nedåt/uppåt
- ⚠️ **där borta** vs. **dit** — "那边"用 där borta（位置），"去那边"用 dit（方向）
