# Obs! / Observera! — 告示注意用语

## 核心用法

`Obs!` 是 `Observera!`（请注意！）的缩写，用于告示、通知、公告中，标记重要信息。

```
Obs! + [重要补充信息]
```

## 正式程度

| 表达 | 正式程度 | 场景 |
|------|----------|------|
| `Obs!` | 中性/书面 | 告示、通知、时间表 |
| `Observera!` | 较正式 | 官方文件、警告 |
| `OBS!` (大写) | 强调 | 重要警示 |
| `Notera att` | 正式 | 文件中 |
| `Kom ihåg att` | 口语 | 记得…… |

## 典型使用模式

在非线性文本中，`Obs!` 通常用于：
- **例外情况**：`Obs! Stängt midsommarafton.`（注意！仲夏节前夕关闭。）
- **重要提醒**：`Obs! Anmälan krävs.`（注意！需要提前报名。）
- **时间更改**：`Obs! Ändrade öppettider i juli.`（注意！7月份营业时间调整。）

## 例句

- Obs! Receptionen är stängd mellan 12 och 13. — 注意！接待处12点到13点关闭。
- OBS! Gymmet är stängt 24–26 december. — 注意！健身房12月24–26日关闭。
- Observera att priset kan ändras utan förvarning. — 请注意，价格可能在没有预先通知的情况下更改。
