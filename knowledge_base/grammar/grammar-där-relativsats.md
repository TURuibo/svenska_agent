# 📗 där-relativsats — där引导的关系从句（表地点）

级别: A2
一句话: 用 där（在那里/那里）引导表示地点的关系从句，相当于英语的 "where"。

## 规则说明 (Rules)

📐 结构公式:
```
[主句] + där + [从句（bisats语序）]
[plats] + där + [subjekt + verb + ...]
```

- där 既可作关系代词（引导从句），也作地点副词
- 从句内部保持 bisats 语序（satsadverbial 前移至动词前）

与中文对比: 汉语可用"在那里"或"那里"引导地点从句，功能相同
与英文对比: 与英语 "where" 完全对应

## 详细讲解 (Detail)

**两种 där 用法（需区分）：**

1. **关系代词 där** — 引导修饰前面地点名词的从句：
   - Staden, **där** kungafamiljen bor, är gammal.（那座城市，王室住在那里，很古老。）

2. **连词 där** — 引导表示条件地点的从句（antingen…eller / där）：
   - Mälaren möter Östersjön **där** Stockholm ligger.（梅拉伦湖在斯德哥尔摩所在处汇入波罗的海。）

在本文：
- "Mälaren möter Östersjön" — 主句
- "där" — 此处指"在那里"，表地点结果
- 整句：Staden ligger i östra Sverige, **där** sjön Mälaren möter Östersjön.

## 例句 (Examples)

- ✅ [[sent-staden-ligger-i-östra-sverige]] 🇸🇪 Staden ligger i östra Sverige, där sjön Mälaren möter Östersjön. 🇨🇳 城市位于瑞典东部，梅拉伦湖与波罗的海在此相汇。
- ✅ [[sent-där-ligger-stockholms-slott]] 🇸🇪 Där ligger Stockholms slott, där kungafamiljen bor. 🇨🇳 王宫坐落于此，王室住在那里。
- ✅ 🇸🇪 Det är ett café där man kan sitta utomhus. 🇨🇳 那是一家可以坐在户外的咖啡馆。
- ❌ Det är ett café som man kan sitta utomhus. ← 当指地点时，用 där 而非 som

## 常见错误 (Common Mistakes)

- ⚠️ 指地点时用 som 代替 där（英语"that/which"习惯）
- ⚠️ 混淆关系代词 där 与疑问词 var（var=哪里，疑问；där=那里，关系）
