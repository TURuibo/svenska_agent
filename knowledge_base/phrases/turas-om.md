# turas om

🗣️ 类型: partikelverb · 语域: neutralt · 常用度: 4/5
🇨🇳 轮流 · 🇬🇧 to take turns
📝 字面: tur（轮次）+ -as（互相）+ om

## 用法说明 (Usage)

- **deponens 动词**（永远带 -s）+ 小品词 *om*：*turas om / turas om / turades om / turats om*。
- 结构：*turas om (att + inf.)* 或 *turas om med något*：*Vi turas om att vabba* / *Vi turas om med hämtningen*.
- 主语通常是复数（vi / de / min fru och jag），因为「互相」轮换。
- 两位家长不能同一天 vab 同一个孩子，所以 *turas om* 是 vab 语境高频词。

## 短语中的语法 (Grammar inside)

- → [[grammar-deponens-verb]]（-s 结尾的主动动词）
- 小品词 *om* 重读：*Vi TURas OM*。

## 变体 & 相关 (Variations & Related)

- 🔄 *ta det i tur och ordning* — 按顺序轮流
- 🔄 *varannan dag / varannan vecka* — 每隔一天/一周（轮换的具体安排）
- 🔗 [[vabba]], [[vab]], [[tur]]

## 例句 / 对话 (Examples)

- [[sent-ja-vi-turades-om-min-fru]] 🇸🇪 Ja, vi turades om, min fru och jag. 🇨🇳 是啊，我和我太太轮流来。
- 🇸🇪 Vi turas om att lämna och hämta på förskolan. 🇨🇳 我们轮流送和接幼儿园。
- 🇸🇪 Kan ni turas om att vabba den här veckan? 🇨🇳 这周你们能轮流 vab 吗？
