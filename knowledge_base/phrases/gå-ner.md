# gå ner

🗣️ 类型: partikelverb · 语域: neutralt · 常用度: 4/5
🇨🇳 （太阳）落下；下降 · 🇬🇧 to set (sun); to go down
📝 字面: 走 + 下

## 用法说明 (Usage)

- 太阳落山：Solen går ner。与 gå upp（升起）相对。变位：går ner / gick ner / gått ner。也可指价格、温度下降。
