# tveka att

🗣️ 类型: 动词搭配 · 语域: neutralt · 常用度: 3/5
🇨🇳 不愿；犹豫去做 · 🇬🇧 to hesitate to
📝 字面: 犹豫去……

## 用法说明 (Usage)

- tveka att + 不定式；Tveka inte att … = 尽管……（客套）。
