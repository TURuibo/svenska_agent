# råda någon att

🗣️ 类型: fast-uttryck（动词 + 直接宾语 + att + 不定式）· 语域: 正式 / 书面 · 常用度: 3/5
🇨🇳 建议某人做某事 · 🇬🇧 to advise someone to
📝 字面: 劝告某人去……

## 用法说明 (Usage)

- 结构：`råda + 人 (直接宾语) + att + 动词不定式`：`Polisen råder förarna att använda hjälm.`
- 人是**直接宾语**，**不加** `till` / `för` / `om`。
- 否定：`råda någon att inte …` 或 `råda någon från att …`（劝某人别……）：`Vi råder dig att inte betala i förväg.`
- 语气比 `tycka att du ska …` 更正式，常见于警方、医生、官方公告：`Läkaren råder patienten att vila.`
- 口语里更常说 `Jag tycker att du ska …` 或 `Jag rekommenderar att du …`（[[rekommendera]]）。
- ⚠️ 不要和名词短语 `ge någon ett råd`（给某人一个建议）混；也不要和 [[det-råder-oklarhet]]（情况存在）混。

## 短语中的语法 (Grammar inside)

- → [[grammar-infinitivkonstruktion]]：`att` 引导不定式（`att använda`），不能省略 `att`。

## 变体 & 相关 (Variations & Related)

- 🔄 `Jag råder dig att …` — 我建议你……
- 🔄 `Vi råder alla att …` — 我们建议所有人……
- 🔄 `ett råd` / `ge råd` — 一条建议 / 给建议
- 🔗 [[råda]]、[[rekommendera]]、[[få-råd]]

## 例句 / 对话 (Examples)

- [[sent-polisen-råder-förarna-att-använda-hjälm]] 🇸🇪 Polisen råder förarna att använda hjälm. 🇨🇳 警方建议骑行者戴头盔。
- 🇸🇪 Läkaren råder mig att vila några dagar. 🇨🇳 医生建议我休息几天。
- 🇸🇪 Jag råder dig att läsa avtalet noga. 🇨🇳 我建议你仔细阅读合同。
- 🇸🇪 Vi råder alla att boka i tid. 🇨🇳 我们建议所有人提前预订。
