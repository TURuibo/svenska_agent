# vad kul att se er

🗣️ 类型: hälsningsfras · 语域: vardagligt · 常用度: 4/5
🇨🇳 见到你们真高兴 · 🇬🇧 how nice to see you
📝 字面: what fun to see you (pl.)

## 用法说明 (Usage)

- 意外碰到熟人（尤其一家人）时的热情问候，紧跟在 *hej* 后面。
- **er** = 你们（宾格）；对一个人说 *Vad kul att se dig*。
- 完整句 *Vad kul det är att se er* 的省略，口语里从不补 det är。

## 短语中的语法 (Grammar inside)

- → [[grammar-vad-utrop]] — vad + 形容词 感叹句
- → [[grammar-infinitiv]] — att se er 不定式补语

## 变体 & 相关 (Variations & Related)

- 🔄 *Vad roligt att se er!* / *Kul att se er!* / *Vad kul att ni kom!*
- 🔗 [[vad-kul]]（更短的通用感叹）
- 🔗 [[hej-då]]（告别）

## 例句 / 对话 (Examples)

- [[sent-vad-kul-att-se-er]] 🇸🇪 Oj, hej! Vad kul att se er! 🇨🇳 哎，嗨！见到你们真高兴！
- 🇸🇪 Vad kul att se dig igen, det var längesen! 🇨🇳 又见到你真高兴，好久不见！
