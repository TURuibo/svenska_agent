# Kan vi dela på notan?

🗣️ 类型: situationsfras · 语域: neutralt · 常用度: 4/5
🇨🇳 我们能分开付账吗？ · 🇬🇧 Can we split the bill?
📝 字面: 我们能分割账单吗？

## 用法说明 (Usage)

- 餐厅结账时请求 AA 制付账的标准问法
- *dela på* = 分摊（partikelverb：dela + prep. *på*）
- *nota* 特指餐厅账单（非通用"收据" kvitto）

## 短语中的语法 (Grammar inside)

- 情态动词 *kan* + 不定式 *dela* → [[grammar-modala-hjalpverb]]

## 变体 & 相关 (Variations & Related)

- 🔄 *Kan vi betala var för sig?* — 同义，各自付钱
- 🔄 *Kan vi få varsitt kvitto?* — 能给我们各自的收据吗？
