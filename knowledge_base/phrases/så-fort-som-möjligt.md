# så fort som möjligt

🗣️ 类型: fast-uttryck · 语域: neutralt · 常用度: 5/5
🇨🇳 尽快 · 🇬🇧 as soon as possible
📝 字面: 如此快如可能

## 用法说明 (Usage)

- 缩写 `ASAP` / 正式书面语可换成 `snarast`。
- 结构 `så + 形容词/副词 + som möjligt` 可替换：`så snabbt som möjligt`、`så mycket som möjligt`。
