# bra för miljön

**类型:** uttryck / adjektivfras (形容词短语/固定表达)
**中文:** 对环境有好处；有利于环境
**English:** good for the environment
**CEFR:** A2

## 用法 (Usage)

- **bra för miljön** = 对环境有益，常用于讨论可持续发展、环保措施等话题。
- 反义表达：*dåligt för miljön* = 对环境有害
- 类似结构：*bra för hälsan* (对健康有益), *bra för ekonomin* (对经济有好处)

## 例句 (Example Sentences)

1. *Det minskar trafiken och är bra för miljön.* — 这能减少交通量，对环境也有好处。
2. *Att cykla är bra för miljön.* — 骑自行车对环境有好处。
3. *Solenergi är bra för miljön.* — 太阳能对环境有好处。
4. *Vi måste tänka på vad som är bra för miljön.* — 我们必须想想什么对环境有好处。
