# säga upp sig

🗣️ 类型: partikelverb · 语域: neutralt · 常用度: 3/5
🇨🇳 辞职 · 🇬🇧 to resign
📝 字面: 字面：说起自己

## 用法说明 (Usage)

- säga upp sig = 自己辞职；säga upp någon = 解雇某人。名词 uppsägning。

## 例句 / 对话 (Examples)

- 🇸🇪 Hon sa upp sig i går. — 🇨🇳 她昨天辞职了。
- 🇸🇪 Om du säger upp dig börjar uppsägningstiden. — 🇨🇳 如果你辞职，通知期就开始了。
