# lika många som

🗣️ 类型: fast-uttryck · 语域: neutralt · 常用度: 4/5
🇨🇳 和……一样多 · 🇬🇧 as many as
📝 字面: 一样多 像

## 用法说明 (Usage)

- `lika + 形容词/副词 + som` 表示"和……一样"；可数复数用 `många`，不可数用 `mycket`：`lika mycket som`。
- 否定：`inte lika många som` = 不如……多。

## 例句 / 对话 (Examples)

- 🇸🇪 Många skänker gärna sina gamla kläder, men det är inte lika många som vill köpa dem. 🇨🇳 很多人乐意捐出旧衣服，但想买它们的人没那么多。
- 🇸🇪 Det kom inte lika många som vi trodde. 🇨🇳 来的人没有我们想的那么多。
