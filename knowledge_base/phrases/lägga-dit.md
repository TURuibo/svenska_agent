# lägga dit

类型: partikelverb · 语域: neutralt · 常用度: 3/5
中文：放进去；扔进去（到那里） · 英文：to put in there; to throw in there
字面：lägga (放) + dit (到那里)

## 用法说明 (Usage)

- *dit* 是方向性地点副词，表示"到那里"（指之前已提及的地方，如容器、箱子等）。
- 与 *lägga där*（放在那里，静止）区别：*dit* 强调动作方向，*där* 强调位置。
- 常见于公告语境：*du kan lägga dit ...* 意为"你可以把……放进去"。

## 变形 (Conjugation)

| 时态 | 形式 |
|------|------|
| 不定式 | lägga dit |
| 现在时 | lägger dit |
| 过去时 | lade dit |
| 完成时 | har lagt dit |
| 命令式 | lägg dit! |
