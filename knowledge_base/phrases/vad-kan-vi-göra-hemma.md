# Vad kan vi göra hemma?

🗣️ 类型: 家长常用问句 · 语域: neutralt · 常用度: 4/5
🇨🇳 我们在家能做什么？ · 🇬🇧 What can we do at home?
📝 字面: 什么能我们做在家

## 用法说明 (Usage)

- 家长和老师沟通的黄金问句——表示配合、把话题从"出了什么事"转到"怎么改进"。
- 结构：疑问词 *Vad* + 情态动词 *kan*（V2）+ 主语 *vi* + 不定式 *göra*。
- 老师通常用 *Hemma kan ni …* 回答（同样情态动词句型）。

## 短语中的语法 (Grammar inside)

- Vad 引导的疑问句 → [[grammar-frageord]]
- kan + 不定式 → [[grammar-modala-hjalpverb]]
