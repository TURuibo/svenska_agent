# bygga med klossar

🗣️ 类型: verbfras · 语域: neutralt · 常用度: 4/5
🇨🇳 搭积木 · 🇬🇧 to build with blocks
📝 字面: bygga（建）+ med（用）+ klossar（积木，复数不定形）

## 用法说明 (Usage)

- "用……搭/玩"用介词 **med**：bygga med klossar, leka med bilar。中文"搭积木"没有介词，别漏掉 med。
- klossar 复数不定形（泛指）；具体那盒积木：*bygga med klossarna*。
- 搭成的东西：*bygga ett torn / ett hus av klossar*（用积木搭塔）。

## 短语中的语法 (Grammar inside)

- → [[grammar-substantiv-plural]]（kloss → klossar，en-词 -ar 复数）

- 🔄 bygga torn / bygga ett högt torn
- 🔄 leka med klossar

## 例句 / 对话 (Examples)

- [[sent-vi-bygger-med-klossar-lägger-pussel]] 🇸🇪 Vi bygger med klossar, lägger pussel, ritar, målar och läser böcker. 🇨🇳 我们搭积木、拼拼图、画画、涂颜色、读书。
- 🇸🇪 Olle bygger ett högt torn med klossar. 🇨🇳 Olle 用积木搭了一座高塔。
