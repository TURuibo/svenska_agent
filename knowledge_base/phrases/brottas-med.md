# brottas med

🗣️ 类型: prepositionsuttryck · 语域: neutralt · 常用度: 3/5
🇨🇳 苦于应对……；与……抗争 · 🇬🇧 to struggle with, to grapple with
📝 字面: to wrestle with

## 用法说明 (Usage)

- 固定搭配：**brottas med** + 名词，表示"在应对某困难/问题时感到挣扎"
- 比 *ha problem med* 含有更强的挣扎感，常用于较严重或长期的问题
- 常见搭配：*brottas med skjutningar* · *brottas med ekonomin* · *brottas med ett svårt beslut*
- *brottas* 是去代词动词（deponensverb）：形态上为 -s，但含义是主动的

## 短语中的语法 (Grammar inside)

- *brottas* = deponensverb：brottas / brottades / brottats（perfekt: *har brottats*）
- *med* 引出"斗争的对象"

## 变体 & 相关 (Variations & Related)

- 🔄 *kämpa med* — 与……奋斗（物理或精神上的努力）
- 🔄 *ha problem med* — 在……方面遇到问题（更中性）
- 🔗 [[problem-med]]

## 例句 / 对话 (Examples)

- [[sent-polisen-har-brottats-med-skjutningar]] 🇸🇪 Polisen har brottats med skjutningar. 🇨🇳 警方一直在应对枪击案问题。
- 🇸🇪 Många kommuner brottas med ekonomiska svårigheter. — 🇨🇳 许多市政府在与经济困难抗争。
- 🇸🇪 Hon brottades länge med beslutet att flytta. — 🇨🇳 她在搬家这个决定上纠结了很久。
