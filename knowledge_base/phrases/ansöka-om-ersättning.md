# ansöka om ersättning

🗣️ 类型: prepositionsuttryck · 语域: formellt · 常用度: 3/5
🇨🇳 申请补偿金 · 🇬🇧 to apply for compensation
📝 字面: 申请关于补偿

## 用法说明 (Usage)

- *ansöka* 的介词固定是 **om**：*ansöka om ersättning / om bidrag / om uppehållstillstånd*。
- 向谁申请用 **hos**：*hos Försäkringskassan*。
- 名词是 *ansökan*（申请书）：*skicka in en ansökan*。
