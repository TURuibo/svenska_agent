# ge order

🗣️ 类型: fast-uttryck · 语域: neutralt · 常用度: 3/5
🇨🇳 下命令，发出指令 · 🇬🇧 to give orders, to issue orders
📝 字面: 给命令

## 用法说明 (Usage)

- 表示上级或负责人向下属发出指令
- *order* 是 en-ord，但在短语中常用不定形式（obestämd）
- 可用于军事、犯罪、组织管理等场合

## 短语中的语法 (Grammar inside)

- → [[grammar-partikelverb]]

## 变体 & 相关 (Variations & Related)

- 🔄 ge order om att + infinitiv（命令做某事）
- 🔄 ge order till ngn（向某人下令）
- 🔗 beordra（命令，动词，更正式）

## 例句 / 对话 (Examples)

- [[sent-han-jobbade-från-utlandet]] 🇸🇪 Han jobbade från utlandet och gav order genom chattar. 🇨🇳 他在国外通过聊天软件下达命令。
- 🇸🇪 Chefen gav order om att alla skulle arbeta övertid. — 🇨🇳 老板命令所有人加班。
