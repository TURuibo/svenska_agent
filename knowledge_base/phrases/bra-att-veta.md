# bra att veta

🗣️ 类型: uttryck · 语域: vardagligt · 常用度: 5/5
🇨🇳 好，知道了（这信息有用） · 🇬🇧 good to know
📝 字面: bra（好）+ att（不定式标记）+ veta（知道）

## 用法说明 (Usage)

- 对方告诉你一条实用信息后的**回应语**，表示「有用、记下了」。完整句是 *Det är bra att veta.*，口语省略成 *Bra att veta!*
- 常前置 *Okej / Aha / Tack*：*Okej, bra att veta.*
- 也用作标题：*Bra att veta*（幼儿园通知里的「须知」栏）。

## 短语中的语法 (Grammar inside)

- *bra att + infinitiv*：形容词 + att + 不定式（*bra att veta / svårt att säga / roligt att höra*）。

## 变体 & 相关 (Variations & Related)

- 🔄 *Det är bra att veta.* — 完整句
- 🔄 *Skönt att veta.* — 知道了就放心了

## 例句 / 对话 (Examples)

- [[sent-okej-bra-att-veta]] 🇸🇪 Okej, bra att veta. 🇨🇳 好的，知道了。
- 🇸🇪 — Förskolan stänger klockan fem på fredag. — Aha, bra att veta! 🇨🇳 ——周五幼儿园五点关门。——啊，知道了，谢谢！
- 🇸🇪 Bra att veta: man måste sjukanmäla före klockan åtta. 🇨🇳 须知：必须八点前请病假。
