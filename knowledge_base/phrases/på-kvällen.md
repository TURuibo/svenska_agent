# på kvällen

🗣️ 类型: 时间介词短语 · 语域: neutralt · 常用度: 5/5
🇨🇳 在晚上 · 🇬🇧 in the evening
📝 字面: på（在，时段介词）+ kvällen（晚上，定冠词形）

## 用法说明 (Usage)

- 与 `på morgonen` 构成一对，覆盖一天的两端。
- 完整时段系统：`på morgonen / på förmiddagen / på eftermiddagen / på kvällen / på natten`。
- `kväll` = 傍晚/晚间（日落后至就寝前）；`natt` = 深夜/夜间。
