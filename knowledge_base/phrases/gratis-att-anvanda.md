# gratis att använda

**类型:** uttryck / infinitivkonstruktion (固定表达/不定式结构)
**中文:** 免费使用
**English:** free to use; free of charge to use
**CEFR:** A2

## 用法 (Usage)

- **gratis att använda** = 可以免费使用，无需付费。
- 结构：*gratis* (免费，形容词/副词) + *att* + 动词原形
- 类似结构：*lätt att använda* (易于使用), *roligt att göra* (有趣的事情)

## 例句 (Example Sentences)

1. *Cykelbanan är gratis att använda.* — 这条自行车道免费使用。
2. *Appen är gratis att ladda ner.* — 这个应用程序可以免费下载。
3. *Biblioteket är gratis att besöka.* — 图书馆免费参观。
4. *Det är gratis att använda cykelparkering.* — 停放自行车是免费的。

## 语法模式 (Grammar Pattern)

```
[vara] + [gratis] + [att] + [infinitiv]
  是      免费        att   动词原形
```
