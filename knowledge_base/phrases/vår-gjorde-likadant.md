# vår gjorde likadant

🗣️ 类型: vardagsfras · 语域: vardagligt · 常用度: 3/5
🇨🇳 我家那个也一样（做过同样的事） · 🇬🇧 ours did the same
📝 字面: 我们的做了同样的

## 用法说明 (Usage)

- **vår** 单独用 = "我们家的（孩子）"，家长间省略 *barn/son/dotter*：*Vår gjorde likadant / Vår äldsta gjorde likadant*（我家老大也一样）。
- **likadant** 是 *likadan* 的 ett-形作副词用，意思"同样地"。
- preteritum *gjorde*（göra 的过去时，不规则）——讲自家过去的经历。
