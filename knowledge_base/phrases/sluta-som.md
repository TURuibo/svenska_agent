# sluta som

🗣️ 类型: prepositionsuttryck · 语域: neutralt · 常用度: 2/5
🇨🇳 辞去……的职位 · 🇬🇧 to stop working as
📝 字面: 作为……结束

## 用法说明 (Usage)

- `sluta som + 职业`：不再做某种工作。
- 对比 `sluta + 动名/att`（停止做某事）、`sluta på + 地点`（离开某单位）。

## 短语中的语法 (Grammar inside)

- som 引出职业身份，后无冠词：sluta som lärare。

## 例句 / 对话 (Examples)

- [[sent-efter-boken-kunde-hon-sluta-som]] 🇸🇪 Efter boken kunde hon sluta som lärare och bli författare. 🇨🇳 有了这本书，她可以辞去教职，成为作家。
- 🇸🇪 Min pappa slutade som chef förra året. 🇨🇳 我爸爸去年卸任了经理职务。
