# få tänder

🗣️ 类型: vardagsfras · 语域: vardagligt · 常用度: 4/5
🇨🇳 长牙 · 🇬🇧 to be teething
📝 字面: 得到牙齿

## 用法说明 (Usage)

- "长牙"用 **få tänder**（get teeth），不是 växa。*tand* 的复数不规则：tand → **tänder**（a→ä）。
- "是因为在长牙"说 **Det är tänderna**（用定式复数），是家长解释夜醒的万能句。
- 问对方：*Får Ella också tänder nu?*
