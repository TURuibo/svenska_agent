# börja gråta

🗣️ 类型: vardagsfras（verbfras） · 语域: neutralt · 常用度: 5/5
🇨🇳 哭起来 · 🇬🇧 start crying
📝 字面: 开始哭

## 用法说明 (Usage)

- *börja* + 不带 *att* 的动词原形 = 「开始做某事」：*börja gråta / skratta / äta*。
- 中文「哭起来 / 哭了」用 *börja gråta* 表达起始点；*gråta* 本身指持续哭。
- 送园分离时的典型句：*Nu börjar hon gråta.*（V2：*nu* 在句首，动词紧随）。
