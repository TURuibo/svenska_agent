# hur mycket blir det

🗣️ 类型: 询价句 / 情景短语 · 语域: vardagligt · 常用度: 5/5
🇨🇳 多少钱？ · 🇬🇧 how much will that be? / how much is it?
📝 字面: how much will it become

## 用法说明 (Usage)

- 收银台/服务台结账时最常用的问价句。
- `bli` 在这里表示"合计/总共是"，相当于英语的 "come to"。
- 回答模式：`Det blir [X kronor]`（一共 X 克朗）→ [[det-blir-x-kronor]]。
- 可用于任何消费场景：咖啡馆、餐厅、商店。

## 短语中的语法 (Grammar inside)

- → [[grammar-presens]]（`blir` 是 `bli` 的 presens）

## 变体 & 相关 (Variations & Related)

- 🔄 `Vad kostar det?` — 这个多少钱？（询问价格）
- 🔄 `Hur mycket kostar det?` — 多少钱？（同义）
- 🔗 [[det-blir-x-kronor]]（一共 X 克朗——对方的回答）
- 🔗 [[betala-med-swish]]（用 Swish 付款）

## 例句 / 对话 (Examples)

- [[sent-da-tar-jag-en-bit-morotskaka]] 🇸🇪 Då tar jag en bit morotskaka. Hur mycket blir det? 🇨🇳 那我要一块胡萝卜蛋糕。多少钱？
