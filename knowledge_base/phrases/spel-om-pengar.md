# spel om pengar

🗣️ 类型: fast-uttryck · 语域: neutralt · 常用度: 3/5
🇨🇳 赌博，赌钱 · 🇬🇧 gambling (for money)
📝 字面: game for money

## 用法说明 (Usage)

- `spel om pengar` är den neutrala svenska termen för gambling/hasardspel.
- Används i statistik, nyheter och formella sammanhang.
- `spelande om pengar` = verbalnomen (赌钱这件事).
