# beställa extra hämtning

🗣️ 类型: situationsfras · 语域: formellt · 常用度: 2/5
🇨🇳 预约额外收运 · 🇬🇧 order an extra collection
📝 字面: 订购额外的取走

## 用法说明 (Usage)

- 垃圾公司服务用语：当垃圾没被收走（如分错类）时，可付费预约额外上门收运。
- 原句：*Lägg över det som är felsorterat i de vanliga soporna eller beställ extra hämtning.*
- *hämtning* 在这里 = 垃圾收运（而不是接孩子）。→ [[hämtning]]

- 🇸🇪 Du kan beställa extra hämtning på hemsidan. 🇨🇳 你可以在网站上预约额外收运。
