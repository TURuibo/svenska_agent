# få reda på

🗣️ 类型: partikelverb · 语域: neutralt · 常用度: 4/5
🇨🇳 查明；打听到；得知 · 🇬🇧 to find out
📝 字面: 得到消息

## 用法说明 (Usage)

- `få reda på` + 宾语 / att-sats / 疑问从句。近义 `ta reda på`（主动去查）；`få reda på` 偏“得知”。

## 短语中的语法 (Grammar inside)

- → [[grammar-partikelverb]]

## 例句 / 对话 (Examples)

- 🇸🇪 Den som vill få reda på mer kan komma till ett möte. 🇨🇳 想了解更多的人可以来参加会议。
- 🇸🇪 Jag fick reda på att han flyttat. 🇨🇳 我得知他搬走了。
