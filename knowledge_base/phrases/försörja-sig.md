# försörja sig

🗣️ 类型: fast-uttryck（反身动词） · 语域: 中性 · 常用度: 4/5
🇨🇳 自食其力；养活自己 · 🇬🇧 to support oneself; to make a living
📝 字面: 供养 自己

## 用法说明 (Usage)

- 反身动词：`försörja sig` / `försörja mig / dig / sig / oss / er`，**反身代词随主语变化**：`Du kan inte försörja dig själv.`
- 常加 `själv`（自己）强调：`försörja sig själv`；也可写成 `försörja sig och sin familj`（养活自己和家人）。
- `försörja sig på + 来源` = 靠……谋生：`Hon försörjer sig på att undervisa.` / `på ett deltidsjobb`。
- 条件句里作"获得补助的前提"：`Om du inte kan försörja dig själv …`。
- 近义：[[livnära-sig-på]]（靠……为生）。

## 短语中的语法 (Grammar inside)

- 反身动词 + 反身代词（dig / sig / mig）→ [[grammar-reflexivt-verb]]

- 🔄 `försörja sin familj` · `försörja sig själv` · `försörja sig på …`
- 🔗 [[livnära-sig-på]] — 靠……为生
- 🔗 head word: [[försörja]] · [[försörjning]]

## 例句 / 对话 (Examples)

- [[sent-du-kan-få-ekonomiskt-bistånd-om-du-inte]] 🇸🇪 Du kan få ekonomiskt bistånd om du inte kan försörja dig själv eller din familj. 🇨🇳 如果你无法养活自己或家人，就可以获得经济补助。
- 🇸🇪 Hon försörjer sig som lärare. 🇨🇳 她靠当老师维生。
- 🇸🇪 Många unga kan inte försörja sig på sitt jobb. 🇨🇳 许多年轻人靠工作无法养活自己。
