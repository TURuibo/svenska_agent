# lägga till dricks

🗣️ 类型: situationsfras · 语域: neutralt · 常用度: 3/5
🇨🇳 加小费 · 🇬🇧 to add a tip
📝 字面: 加上小费

## 用法说明 (Usage)

- *lägga till* 是"添加/加上"的 partikelverb
- 在刷卡支付时终端会询问是否想要加小费
- 替代方式：*avrunda uppåt*（往上凑整）

## 短语中的语法 (Grammar inside)

- *lägga till* = partikelverb（lägger till / lade till / lagt till）→ [[grammar-partikelverb]]

## 变体 & 相关 (Variations & Related)

- 🔄 *avrunda uppåt* — 往上凑整代替明确给小费
- 🔄 *ge dricks* — 给小费（更口语）
