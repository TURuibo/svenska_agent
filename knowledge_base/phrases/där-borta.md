# där borta

🗣️ 类型: prepositionsuttryck · 语域: neutralt · 常用度: 4/5
🇨🇳 那边 · 🇬🇧 over there
📝 字面: där = 那里；borta = 在远处

## 用法说明 (Usage)

- 指示某处"在那边（较远处）"，常配合手势使用
- jfr **där framme** = 在前面那里（较近，可见范围内）
- jfr **här borta** = 在这边（较近的这一侧）
