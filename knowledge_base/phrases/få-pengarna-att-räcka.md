# få pengarna att räcka

🗣️ 类型: fast-uttryck · 语域: 中性 · 常用度: 4/5
🇨🇳 让钱够用；量入为出 · 🇬🇧 to make ends meet; to make the money last
📝 字面: 使 钱 去 够

## 用法说明 (Usage)

- 结构：**få + 宾语 + att + 不定式**（使/让……做到……）：`få pengarna att räcka`。
- 常带时间：`få pengarna att räcka hela månaden`（让钱撑到月底）。
- 同样的框架可换宾语：`få maten att räcka`、`få tiden att räcka`。
- 常见搭配：`ha svårt att få pengarna att räcka`（钱总是不够）。
- 对比 [[räcka-till]]：`pengarna räcker till` 是"钱够用"（状态）；`få pengarna att räcka` 是"让钱够用"（设法做到）。
