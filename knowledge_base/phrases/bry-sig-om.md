# bry sig om

🗣️ 类型: partikelverb · 语域: neutralt · 常用度: 5/5
🇨🇳 关心；在乎；介意 · 🇬🇧 to care about; to mind
📝 字面: to bother oneself about

## 用法说明 (Usage)

- Reflexivt partikelverb: "bry" + "sig" (reflexivt pronomen) + "om"
- Konjugation: bryr sig om / brydde sig om / brytt sig om
- Ofta i negationen: "ingen bryr sig" (nobody cares), "jag bryr mig inte om det"
