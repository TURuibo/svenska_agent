# ta slut — partikelverb

📖 中文：用尽，结束，耗尽 · English: to run out; to come to an end
类型: partikelverb

## 结构分析 (Structure)

`ta` (ta/handen) + `slut` (结局，终点) → 字面义"到达终点" → 引申"用完/结束"

## 语法变形 (Forms)

| form | form |
|------|------|
| infinitiv | ta slut |
| presens | tar slut |
| preteritum | tog slut |
| supinum | tagit slut |

`ta` 是不规则动词：ta – tar – tog – tagit

## 搭配 (Collocations)

- `håller på att ta slut` — 快用完了（进行时语气）
- `maten tog slut` — 食物用完了
- `pengarna håller på att ta slut` — 钱快花完了
- `sommaren tar snart slut` — 夏天快结束了

## 例句 (Sentences)

- 🇸🇪 [[sent-tiden-håller-på-att-ta-slut]] Tiden håller på att ta slut. — 🇨🇳 时间快不够了。
- 🇸🇪 Mjölken har tagit slut. — 🇨🇳 牛奶用完了。
- 🇸🇪 Sommaren tar snart slut. — 🇨🇳 夏天快结束了。

## 用法提示 (Usage Notes)

- `hålla på att ta slut` = 快要用完/结束（强调即将发生）
- 注意 `ta slut` 不及物（无宾语）；若说"我把某物用完"用 `använda upp` 或 `göra slut på`
