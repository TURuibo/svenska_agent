# rösta om

🗣️ 类型: prepositionsuttryck · 语域: neutralt · 常用度: 3/5
🇨🇳 就…投票 · 🇬🇧 vote on
📝 字面: vote + about/on

## 用法说明 (Usage)

- `rösta om` + 名词短语：表示"就某个议题/问题进行投票"。
- 例：*Ska de rösta om självständighet?* — 他们要就独立问题进行投票吗？
- 区分：*rösta på* = 投票给（某人/政党），*rösta om* = 就（某议题）进行表决。

## 短语中的语法 (Grammar inside)

- 动词 [[rösta]] + 介词 *om*
- → [[grammar-ska-infinitiv]] — *ska rösta om* 表将来
