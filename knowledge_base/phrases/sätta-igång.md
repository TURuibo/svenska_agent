# sätta igång

🗣️ 类型: partikelverb · 语域: neutralt · 常用度: 4/5
🇨🇳 开始；启动 · 🇬🇧 to get started; to set going
📝 字面: 放到运行中

## 用法说明 (Usage)

- 分离动词：`sätta igång arbetet` / `sätta arbetet igång`。反身用法：`sätta igång` = 开工。
