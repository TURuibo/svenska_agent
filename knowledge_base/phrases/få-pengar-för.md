# få pengar för

🗣️ 类型: kollokation · 语域: neutralt · 常用度: 3/5
🇨🇳 换到钱，得到…的钱 · 🇬🇧 to get money for

## 用法说明 (Usage)

- få pengar för + 物品 = 因某物（出售/兑换）得到钱。
- 核心词: [[få]], [[pengar]], [[sedel]]

## 例句 / 对话 (Examples)

- 🇸🇪 Du kan få pengar för din gamla cykel. 🇨🇳 你的旧自行车可以卖点钱。
- 🇸🇪 Snart går det inte att få pengar för sedlarna. 🇨🇳 很快就换不到这些纸币的钱了。
- 🇸🇪 Hur mycket fick du för bilen? 🇨🇳 你的车卖了多少钱？
