# trodde att … skulle

🗣️ 类型: fast-uttryck · 语域: neutralt · 常用度: 4/5
🇨🇳 以为……会…… · 🇬🇧 thought that … would … (reported future in past)
📝 字面: believed that … would

## 用法说明 (Usage)

- 表达"过去对未来的预期"（过去将来时）
- 结构：主语 + trodde att + 主语2 + skulle + infinitiv
- 对应中文"以为……会/要……"的用法

## 短语中的语法 (Grammar inside)

- → [[grammar-trodde-att-skulle]] — 过去将来时语法点
- → [[grammar-bisats]] — att-从句结构

## 变体 & 相关 (Variations & Related)

- 🔄 tänkte att ... skulle — 以为……会（同义）
- 🔄 trodde att ... var — 以为……是
- 🔄 visste att ... skulle — 知道……会

## 例句 / 对话 (Examples)

- 🇸🇪 Den första gången det blåste riktigt starkt trodde jag att mitt paraply skulle gå sönder. — 🇨🇳 第一次遇到真正强风时，我以为我的雨伞会坏掉。
- 🇸🇪 Jag trodde att det skulle bli soligt idag, men nu regnar det. — 🇨🇳 我以为今天会是晴天，但现在在下雨了。
