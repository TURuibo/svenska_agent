# från ett års ålder

🗣️ 类型: prepositionsuttryck · 语域: formellt · 常用度: 3/5
🇨🇳 从一岁起 · 🇬🇧 from the age of one
📝 字面: 从一年的年龄

## 用法说明 (Usage)

- 结构：*från/vid + X års ålder*。**års** 是属格（-s），修饰 *ålder*，中文母语者最容易漏掉这个 -s。
- 同型：*vid sex års ålder*（六岁时）、*i tre års ålder*（三岁时）、*från två års ålder*。
- 口语更常说 *när barnet är ett år* / *från ett år*；这是官方文本风格。
