# gå från (att) … till (att) …

🗣️ 类型: fast-uttryck · 语域: neutralt · 常用度: 3/5
🇨🇳 从……变成……（状态/情况的转变） · 🇬🇧 go from … to …
📝 字面: 走 从 … 到 …

## 用法说明 (Usage)

- 描述某人/某事从一种状态**转变**为另一种状态，常带"变化很大、很快"的意味：`gå från A till B`。
- 若 A、B 是**动作/状态**（动词），要写成 `gå från att + 不定式 till att + 不定式`——因为介词（`från`、`till`）后面不能直接跟动词，必须用 `att + 动词原形`（名词化）。
- 若 A、B 是**名词/数字/形容词**，就不需要 `att`：`gå från noll till hundra`、`gå från dåligt till bra`、`gå från 10 till 20 anställda`。
- 文章里："… **gick från att vara** i stort sett anonym **till att vinna** VM-guld"——`vara`（状态）→ `vinna`（结果）。
- 常和 `under en kort tid`（在很短的时间里）等时间状语连用，强调转变之快。
- 时态：`går` / `gick` / `har gått från … till …` 都可以，`gick från … till …` 在讲述人生转折时最常见。

## 短语中的语法 (Grammar inside)

- 介词后的动词要用 **att + 不定式** → [[grammar-infinitivkonstruktion]]

## 变体 & 相关 (Variations & Related)

- 🔄 `gå från … till …`（名词/数字版）· `bli ... från att vara ...`（口语不常用）· `övergå från … till …`（较书面：由…转为…）
- 🔗 [[allt-från-till]]（"从……到……"，列举范围，不是转变）
- 🔗 [[i-stort-sett]]（基本上；文章里 `i stort sett anonym`）

## 例句 / 对话 (Examples)

- 🇸🇪 Nils van der Poel är en svensk skridskoåkare som under en mycket kort tid gick från att vara i stort sett anonym till att vinna VM-guld. 🇨🇳 Nils van der Poel 是一名瑞典速滑运动员，他在很短时间里从几乎默默无闻到拿下世锦赛金牌。
- 🇸🇪 Hon gick från att vara blyg till att bli lärare. 🇨🇳 她从一个害羞的人变成了老师。
- 🇸🇪 Han gick från att inte kunna ett ord svenska till att prata flytande på två år. 🇨🇳 他从一个瑞典语一个词都不会，到两年内说得很流利。
- 🇸🇪 Företaget gick från tio till femhundra anställda. 🇨🇳 这家公司员工从十人增加到五百人。
