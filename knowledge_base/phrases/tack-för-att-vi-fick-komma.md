# Tack för att vi fick komma

🗣️ 类型: situationsfras · 语域: neutralt · 常用度: 5/5
🇨🇳 谢谢招待 / 谢谢让我们来 · 🇬🇧 thanks for having us
📝 字面: 谢谢-为了-我们-被允许-来

## 用法说明 (Usage)

- 客人离开主人家时说的固定句；主人回 [[tack-för-att-ni-kom]]。
- **fick** 是 [[få]] 的 preteritum，这里 = "得到许可"；一个人来就说 *Tack för att jag fick komma*。
- ⭐ 下次再见到主人（哪怕是周一在幼儿园门口），开口第一句要说 [[tack-för-senast]]，对方回 [[tack-själv]]。

## 短语中的语法 (Grammar inside)

- → [[grammar-tack-för-att-perfekt]] *tack för att + 从句* 结构
- → [[grammar-att-bisats]] att 引导的从句，主语 vi 在 att 之后
- → [[grammar-modal-fa-permission]] få 表许可（fick = preteritum）

## 变体 & 相关 (Variations & Related)

- 🔄 Tack för att jag fick komma · Tack för i dag（谢谢今天）· Tack för maten（谢谢款待饭）
- 🔄 之后：[[tack-för-senast]]（下次见面）
- 🔗 [[tack-för-att-ni-kom]] · [[det-var-jättetrevligt]] · [[tack-för-besöket]] · [[tack-för-att]]
