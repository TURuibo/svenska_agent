# på vilan

🗣️ 类型: uttryck · 语域: vardagligt · 常用度: 4/5
🇨🇳 在午休时 · 🇬🇧 at nap time (preschool)
📝 字面: 在休息上

## 用法说明 (Usage)

- 幼儿园术语 *vilan*（定形）= 午休/安静时间。*på vilan* = 午休期间；也常见 *vid vilan*、*efter vilan*。
- 用 **på** 表示"在某个活动/时段里"（类似 *på lektionen*、*på samlingen*）。
- 老师会说：*Hon sov bra på vilan.* / *Hon får sova längre på vilan.*
