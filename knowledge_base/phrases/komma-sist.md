# komma sist / komma först / komma tvåa

🗣️ 类型: fast-uttryck · 语域: neutralt · 常用度: 4/5
🇨🇳 得最后一名 / 得第一 / 得第二 · 🇬🇧 to come last / first / second
📝 字面: 来 最后 / 最先 / 第二

## 用法说明 (Usage)

- 比赛、考试、排名里表示"名次"，动词用 `komma`（`kom`、`kommit`）：
  - `komma sist` = 最后一名（`sist` = 最后，`sent` 的最高级副词）
  - `komma först` = 第一个到/第一名（`först` = 最先）
  - `komma tvåa` / `trea` / `fyra` … = 第二/三/四名（用基数词的名词形式，`tvåa`、`trea`；`etta` = 第一名）
- 也可以用 `komma på + 序数词 + plats`：`komma på andra plats`；或用 `sluta på`：`han slutade på en 14:e plats`（文章里 OS 2018）。
- 比较差距时可跟 `X sekunder efter segraren`（比冠军慢 X 秒）：文章 `kom han sist, 8 sekunder efter segraren`。
- 句子结构：`Trots att han hade tränat varje dag` 是前置的让步从句，作整个句子的**第一位（fundament）**，所以后面的主句要**倒装**：`kom han sist`（动词在主语前），不是 `han kom sist`。
- ⚠️ `komma sist` ≠ `komma sent`（= 迟到）。`sist` 讲"名次/次序上最后"，`sent` 讲"时间上晚"。

## 例句 / 对话 (Examples)

- 🇸🇪 Trots att han hade tränat varje dag kom han sist, 8 sekunder efter segraren. 🇨🇳 尽管他每天都训练，他还是得了最后一名，比冠军慢 8 秒。
- 🇸🇪 Hon kom först i mål. 🇨🇳 她第一个冲过终点。
- 🇸🇪 Vem kom tvåa i loppet? 🇨🇳 谁在比赛中得了第二？
- 🇸🇪 Vi kom sist i tävlingen men hade jättekul. 🇨🇳 我们在比赛中得了最后一名，但玩得很开心。
