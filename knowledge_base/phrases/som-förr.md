# som förr

🗣️ 类型: fast-uttryck · 语域: neutralt · 常用度: 3/5
🇨🇳 像从前一样 · 🇬🇧 as before

## 用法说明 (Usage)

- 常与否定连用：`inte som förr`（不再像以前）。 [[förr]]
- 比 `som vanligt`（照常）更强调“过去的样子”。

## 例句 / 对话 (Examples)

- [[sent-de-fortsatte-umgås-men-det-blev-inte-riktigt-som-förr]] 🇸🇪 … det blev inte riktigt som förr. 🇨🇳 ……但已不再像从前。
- 🇸🇪 Allt är inte som förr. 🇨🇳 一切都不像从前了。
