# för det första

🗣️ 类型: diskursmarkor · 语域: neutralt · 常用度: 4/5
🇨🇳 首先；第一点 · 🇬🇧 firstly; in the first place
📝 字面: for the first (time/item)

## 用法说明 (Usage)

- 用于列举观点或建议中的"第一条"。
- 常与 `för det andra`（第二点）和 `till sist`/`slutligen`（最后）配合使用，形成完整的论述结构。
- 可置于句首，后接逗号：`För det första, ...`；也可不用逗号直接接句子。
