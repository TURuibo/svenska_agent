# Det var jättetrevligt

🗣️ 类型: situationsfras · 语域: neutralt · 常用度: 5/5
🇨🇳 非常愉快 · 🇬🇧 it was really nice
📝 字面: 它-曾是-超级-愉快

## 用法说明 (Usage)

- 离开时评价这次聚会/见面，几乎总跟在 *Tack för att vi fick komma* 后面。
- **jätte-** 前缀 = 非常（口语最常用的加强前缀）：jättetrevligt、jättegott、jättekul。
- 用 **var**（过去时），因为聚会已结束；形容词用 -t 形（主语 det）。

## 短语中的语法 (Grammar inside)

- → [[grammar-preteritum]] 事件结束后用 var
- → [[grammar-adjektiv-som-predikat]] det + var + 形容词 -t 形
