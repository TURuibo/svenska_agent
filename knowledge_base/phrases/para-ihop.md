# para ihop

🗣️ 类型: partikelverb · 语域: neutralt · 常用度: 3/5
🇨🇳 配对，把……匹配在一起 · 🇬🇧 to match (up), to pair up
📝 字面: to pair together

## 用法说明 (Usage)

- "Para ihop X med Y" = match X with Y
- Vanlig i undervisningssammanhang: "para ihop rätt fråga med rätt svar" = match the right question with the right answer
- Partikel "ihop" kan separeras: "Para dem ihop" (separable particle verb)

## 例句 / 对话 (Examples)

- 🇸🇪 Läs intervjun och para ihop rätt fråga med rätt svar. 🇨🇳 读这篇采访，并把正确的问题与正确的答案配对。
- 🇸🇪 Para ihop orden med deras definitioner. 🇨🇳 把单词与它们的定义配对。
