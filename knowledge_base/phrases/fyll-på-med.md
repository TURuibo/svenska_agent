# fyll på med

类型: partikelverb · 语域: neutralt · 常用度: 3/5
中文：装满；补充；灌满 · 英文：to fill up with; to top up with
字面：fylla (填满) + på (上) + med (用/以)

## 用法说明 (Usage)

- 结构：*fyll på [容器] med [内容物]*，例：*fyll på flaskor med vatten*（把瓶子装满水）。
- 也用于非液体场景：*fyll på förrådet med mat*（补充食物储备）。
- 命令式常用：*fyll gärna på ...* 是礼貌建议的固定说法。

## 变形 (Conjugation)

| 时态 | 形式 |
|------|------|
| 不定式 | fylla på med |
| 现在时 | fyller på med |
| 过去时 | fyllde på med |
| 完成时 | har fyllt på med |
| 命令式 | fyll på med! |
