# det räcker med

🗣️ 类型: fast-uttryck · 语域: neutralt · 常用度: 4/5
🇨🇳 …就够了 · 🇬🇧 … is enough
📝 字面: 它够了用…

## 用法说明 (Usage)

- 形式主语 *det* + *räcker* + **med** + 名词：*Det räcker med en blankett*（一张表格就够了）。
- 中文「X 就够了」倒过来说：瑞典语先说 *det räcker*，再用 *med* 引出 X。
- 否定：*Det räcker inte med ett mejl*（一封邮件不够）。也可 *det räcker med att + infinitiv*。
