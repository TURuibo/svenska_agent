# vid halv nio

🗣️ 类型: 时间介词短语 · 语域: neutralt · 常用度: 3/5
🇨🇳 在八点半左右；将近八点半 · 🇬🇧 at around half past eight
📝 字面: vid（在/于）+ halv nio（九的一半 = 八点半）

## 用法说明 (Usage)

- ⚠️ 重要：瑞典语的 `halv nio` = 八点半（不是九点半！）。
  逻辑：halv（一半）+ nio（九）= 到九点的一半处 = 8:30。
- `vid` 比 `klockan` 更模糊，表示"大约/将近"。
- 完整的钟点系统：
  - `klockan åtta` = 8:00
  - `kvart i nio` = 8:45（差一刻九点）
  - `halv nio` = 8:30
  - `kvart över åtta` = 8:15
