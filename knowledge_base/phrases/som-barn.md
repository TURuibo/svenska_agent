# som barn

🗣️ 类型: prepositionsuttryck · 语域: neutralt · 常用度: 5/5
🇨🇳 小时候、当孩子的时候 · 🇬🇧 as a child
📝 字面: 作为 孩子

## 用法说明 (Usage)

- 这里的 `som` = **"作为……（身份/阶段）"**（英语 *as*），**不是关系代词** *that/who*。后面是**没有冠词的光杆名词**：`som barn`、`som lärare`、`som tonåring`、`som vuxen`。
- 意思："当（我/他）还是孩子的时候"——指一个人生阶段。
- 常见同类：

| 表达 | 意思 |
|------|------|
| `som barn` | 小时候 |
| `som liten` | 年幼时 |
| `som tonåring` | 十几岁时 |
| `som ung` | 年轻时 |
| `som vuxen` | 成年后 |
| `som student` | 当学生时 |
| `som lärare` | 作为老师 |

- 对比：`som barn` 是名词短语，不带动词；若想用完整从句，则是 `när jag var barn`（当我还是孩子的时候）。
- ⚠️ 不加冠词：不说 ~~som ett barn~~（会变成"像个孩子一样"的比喻）。
- 文章里：`Där växte Nils också upp och som barn höll han på med flera olika sporter`——`som barn` 放在第二个分句的**句首（第一位）**，所以主句倒装：`höll han`，不是 `han höll`。
- 与 `barn` 的形式：`ett barn – barnet – barn – barnen`（单复数同形）。

## 例句 / 对话 (Examples)

- 🇸🇪 Där växte Nils också upp och som barn höll han på med flera olika sporter. 🇨🇳 Nils 也在那里长大，小时候他玩过好几种运动。
- 🇸🇪 Som barn bodde jag i Kina. 🇨🇳 小时候我住在中国。
- 🇸🇪 Som liten var hon väldigt blyg. 🇨🇳 小时候她非常害羞。
- 🇸🇪 Som vuxen tycker jag annorlunda. 🇨🇳 成年后我的看法不同了。
