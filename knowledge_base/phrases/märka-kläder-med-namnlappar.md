# märka kläder med namnlappar

🗣️ 类型: vardagsfras · 语域: neutralt · 常用度: 4/5
🇨🇳 给衣服贴姓名标签 · 🇬🇧 label clothes with name tags
📝 字面: "用姓名标签标记衣服"

## 用法说明 (Usage)

- **märka + 东西 + med + 名字/标签**：märka kläder med namn、märka nappen med namnlapp、märka allt med barnets namn。
- 瑞典幼儿园的头号请求：20 个孩子的蓝色 overall 长得一样，没名字 = 找不回来。
- 命令式：*Märk alla kläder!*（märka 第 2 类 → märk）。变形：märker / märkte / märkt。
- ⚠️ **märka** 另一个常见义是"注意到"：*Jag märkte inte att det regnade.* —— 看上下文区分。
