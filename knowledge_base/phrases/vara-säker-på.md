# vara säker på

🗣️ 类型: uttryck · 语域: neutralt · 常用度: 4/5
🇨🇳 对……有把握；确信 · 🇬🇧 be sure about; be certain about
📝 字面: vara (be) + säker (sure) + på (on/about)

## 用法说明 (Usage)

- `vara säker på ngt` = 对某事有把握。
- `vara säker på att + bisats` = 确信……（后接从句）→ see [[vara-säker-på-att]]。
