# ansöka om

🗣️ 类型: prepositionsuttryck · 语域: 正式 · 常用度: 4/5
🇨🇳 申请（某物） · 🇬🇧 to apply for
📝 字面: 申请 关于

## 用法说明 (Usage)

- 结构：**ansöka om + 申请的东西 + hos + 机构**：`ansöka om bistånd hos socialtjänsten`。
- 介词 **om** 接"申请的东西"，**hos** 接"受理的机构"——别和英语 *apply for / apply to* 混。
- 变形：ansöker / ansökte / ansökt（名词 `en ansökan` = 申请，见 [[ansökan]]）。
- 口语里更常说 `söka` + 名词：`söka jobb`；`ansöka om` 偏正式，用于补助、许可、签证、居留。
- 介词 `om` 可以留在句末（关系从句）：`pengar som du kan ansöka om` → [[grammar-preposition-i-slutet]]。
