# jobba med att

🗣️ 类型: fast-uttryck · 语域: neutralt · 常用度: 3/5
🇨🇳 致力于做…；努力做… · 🇬🇧 to work on doing; to be engaged in
📝 字面: to work with doing

## 用法说明 (Usage)

- 结构：`jobba med att + infinitiv`。
- 表示"正在持续努力/投入地做某事"，带有过程感。
- `jobba` 是口语化的 `arbeta`。

## 短语中的语法 (Grammar inside)

- → [[grammar-infinitiv]]（att + 动词原形）

## 变体 & 相关 (Variations & Related)

- 🔄 `arbeta med att` — 更正式版本
- 🔄 `syssla med att` — 相似，但更中性
- 🔗 [[för-att-syfte]] (grammar)

## 例句 / 对话 (Examples)

- [[sent-raddningsarbetare-och-vanliga-manniskor-jobbar]] 🇸🇈 Räddningsarbetare och vanliga människor jobbar med att rädda folk. 🇨🇳 救援人员和普通民众正在努力营救群众。
- 🇸🇈 Vi jobbar med att förbättra systemet. — 🇨🇳 我们正在努力改善这个系统。
