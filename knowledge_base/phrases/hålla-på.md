# hålla på

🗣️ 类型: partikelverb · 语域: vardagligt · 常用度: 5/5
🇨🇳 正在做；正忙着 · 🇬🇧 be doing; be occupied with
📝 字面: hålla (hold) + på (on)

## 用法说明 (Usage)

- `hålla på med ngt` = 正在做某事（持续动作）。
- `hålla på att + verb` = 快要/正要（表示即将发生，常带情感色彩）：Jag höll på att ramla（我差点摔倒）。

- 🇸🇪 Vad håller du på med? 🇨🇳 你在干什么？

- 🇸🇪 Jag höll på att missa bussen! 🇨🇳 我差点没赶上公交车！
