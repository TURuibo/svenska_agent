# kan jag betala med kort?

🗣️ 类型: situationsfras · 语域: neutralt · 常用度: 5/5
🇨🇳 我可以用卡付款吗？ · 🇬🇧 can I pay by card?
📝 字面: kan = 可以；jag = 我；betala = 付款；med = 用；kort = 卡

## 用法说明 (Usage)

- 在瑞典，刷卡付款极为普遍，现金（kontant）使用越来越少
- 几乎任何收银场合都可以用这句话
- 常见回应：**Ja, självklart!** / **Vi tar kort och Swish.**

## 短语中的语法 (Grammar inside)

- → [[grammar-modala-hjalpverb]]：kan 是 modal verb，后接动词不定式 betala

## 变体 & 相关 (Variations & Related)

- 🔄 Tar ni kort? — 更简洁，问店家是否接受卡（→ see [[tar-ni-kort]]）
- 🔄 Kan jag betala med Swish? — 用 Swish 付款
