# utan att

🗣️ 类型: 连接短语 · 语域: neutralt
🇨🇳 不…就；没有…地 · 🇬🇧 without (doing)

## 用法说明 (Usage)

- utan att + 动词不带 att 的 bisats：Hon gick utan att säga hej.

## 例句 / 对话 (Examples)

- 🇸🇪 Han gick utan att säga hej. 🇨🇳 他没打招呼就走了。
