# känna sig som

🗣️ 类型: fast-uttryck · 语域: neutralt · 常用度: 3/5
🇨🇳 感觉自己像…… · 🇬🇧 to feel like (being)
📝 字面: 感觉自己如同

## 用法说明 (Usage)

- känna sig som + 名词：表示主观感受像某种人/状态。känna sig = 反身动词（känner mig, känner dig, känner sig）。
