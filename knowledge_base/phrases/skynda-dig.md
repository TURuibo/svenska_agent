# skynda dig

🗣️ 类型: fast-uttryck · 语域: vardagligt · 常用度: 5/5
🇨🇳 快点 · 🇬🇧 hurry up
📝 字面: hurry yourself（祈使句 + 反身代词）

## 用法说明 (Usage)

- 祈使句 + 反身代词：`skynda` (imperativ) + `dig` (reflexiv, 二人称)。
- 第三人称：*Han skyndar sig.* — 他在赶紧。
- 客气版：`Kan du skynda dig lite?` — 你能快一点吗？
- 更礼貌：`Kan ni skynda er?` — （对多人）你们能快点吗？

## 短语中的语法 (Grammar inside)

- → [[grammar-imperativ]] — 祈使句 skynda!
- → [[grammar-reflexivt-verb]] — skynda sig（反身动词）
