# Jag är så ledsen.

🗣️ 类型: 道歉语 · 语域: vardagligt · 常用度: 5/5
🇨🇳 我非常抱歉。 · 🇬🇧 I'm so sorry.
📝 字面: 我是那么难过

## 用法说明 (Usage)

- *ledsen* 有两义：伤心 / 抱歉。道歉语境 *Jag är så ledsen!* = 真诚的"对不起"，比 *förlåt* 更有感情、比 *jag ber om ursäkt* 更口语。
- 用于自己（或自己孩子）给别人造成了麻烦：咬人、打碎东西、忘约。
- 在瑞典说一次即可，对方通常回 *Det är lugnt / Ingen fara*。

## 短语中的语法 (Grammar inside)

- ledsen 作表语，随主语变形（ledset / ledsna） → [[grammar-adjektiv-som-predikat]]
