# Hur går det med …?

🗣️ 类型: vardagsfras · 语域: neutralt · 常用度: 5/5
🇨🇳 ……进展得怎样？ · 🇬🇧 How is … going?
📝 字面: How goes it with …

## 用法说明 (Usage)

- 后接名词（med + 事物）询问进展：Hur går det med svenskan / jobbet / skolan?
- 回答：Det går bra / Det går ganska bra / Det går sådär.
- 对人本身用 Hur mår du? / Hur är det med dig?
