# göra om ett misstag

🗣️ 类型: fras · 语域: neutralt · 常用度: 2/5
🇨🇳 重犯错误 · 🇬🇧 to repeat a mistake
📝 字面: 重新做一个错误

## 用法说明 (Usage)

- `göra om` = 重新做/再做一次；与 `misstag` 搭配表示"重蹈覆辙"。

## 短语中的语法 (Grammar inside)

- partikelverb `göra om` → [[grammar-partikelverb]]

- 🔗 —

## 例句 / 对话 (Examples)

- 🇸🇪 Nils var rädd för att göra om misstaget att satsa allt på idrotten. 🇨🇳 Nils 害怕重犯把一切都押在运动上的错误。
- 🇸🇪 Vi får inte göra om samma misstag igen. 🇨🇳 我们不能再重犯同样的错误。
