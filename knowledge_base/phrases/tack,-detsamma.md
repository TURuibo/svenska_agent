# Tack, detsamma!

🗣️ 类型: situationsfras（artighetsfras） · 语域: vardagligt · 常用度: 5/5
🇨🇳 谢谢，你也是！ · 🇬🇧 Thanks, same to you!
📝 字面: 谢谢，同样的

## 用法说明 (Usage)

- 对任何祝福（*Ha en bra dag! / Trevlig helg! / Smaklig måltid!*）的标准回应，= 「谢谢，你也一样」。
- *detsamma* = det + samma（同样的东西），一个词写。也可只说 *Detsamma!*
- 注意与 [[tack-själv]]（谢谢你才对——回应对方的 *tack*）区分：对方说「谢谢」用 *tack själv*，对方说「祝你……」用 *tack detsamma*。
