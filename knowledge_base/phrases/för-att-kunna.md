# för att kunna

🗣️ 类型: fast-uttryck · 语域: neutralt · 常用度: 5/5
🇨🇳 为了能够…… · 🇬🇧 in order to be able to; so as to be able to
📝 字面: in order to be able to

## 用法说明 (Usage)

- `för att` 引导目的状语（syftessats）
- `kunna` 是情态动词，后接动词原形，表达"能够做某事的能力"
- 完整结构：`… för att kunna + [动词原形]`（……以便能够……）

## 短语中的语法 (Grammar inside)

- → [[grammar-for-att-infinitiv]]

## 变体 & 相关 (Variations & Related)

- 🔄 `för att + infinitiv` — 为了做……（无 kunna）
- 🔄 `så att man kan` — 这样就能……（结果状语）
- 🔗 [[för-att-bygga]] — 为了建造
- 🔗 [[för-att-fira]] — 为了庆祝

## 例句 / 对话 (Examples)

- [[sent-jag-försöker-lära-mig-svenska-varje-dag]] 🇸🇪 Jag försöker lära mig svenska varje dag för att kunna kommunicera bättre. 🇨🇳 我每天努力学习瑞典语，以便能更好地沟通。
- 🇸🇪 Jag sparar pengar för att kunna resa till Japan. 🇨🇳 我攒钱为了能去日本旅行。
- 🇸🇪 Man måste öva varje dag för att kunna bli bra på svenska. 🇨🇳 要每天练习才能把瑞典语学好。
