# stå på listan

🗣️ 类型: verbfras · 语域: neutralt · 常用度: 4/5
🇨🇳 在名单上 · 🇬🇧 to be on the list
📝 字面: 站在名单上

## 用法说明 (Usage)

- 瑞典语说"（名字）在名单/纸上"用 stå，不是 vara：*Hon står inte på listan.*
- 听力/阅读里 stå 表示"写着"：*Vad står det på skylten?*（牌子上写着什么？）
- listan 用 bestämd form（说话双方都知道是哪张名单）。
