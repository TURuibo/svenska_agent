# ge inte upp

🗣️ 类型: fast-uttryck · 语域: neutralt · 常用度: 4/5
🇨🇳 不要放弃；坚持下去 · 🇬🇧 don't give up; keep going
📝 字面: don't give up

## 用法说明 (Usage)

- 祈使句（imperativ），用于鼓励他人坚持不懈。
- 否定祈使句结构：`ge` + `inte` + `upp`（inte 置于动词和小品词之间）。
- 常作鼓励性结语，尤其在语言学习、克服困难的语境中。

## 短语中的语法 (Grammar inside)

- → [[grammar-imperativ]]（祈使句）
- 否定祈使：`verb + inte`（`ge inte upp`，不要放弃）
