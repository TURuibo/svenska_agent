# det som saknas

🗣️ 类型: vardagsfras · 语域: neutralt · 常用度: 3/5
🇨🇳 缺少的东西 · 🇬🇧 what is missing
📝 字面: 那个被缺少的

## 用法说明 (Usage)

- **det som** + 动词 = "…的东西"（英语 *what*）：*det som saknas*（缺的）、*det som finns*（有的）。
- **saknas** 是 s 形式、意思"缺少/不在"，主语是缺的东西：*Vantarna saknas.*（手套不见了。）
- 中文"缺的（东西）"可直接对应，注意瑞典语必须有 *det som*，不能只说 ~~som saknas~~。
