# före klockan åtta

🗣️ 类型: tidsuttryck · 语域: neutralt · 常用度: 4/5
🇨🇳 八点前 · 🇬🇧 before eight o'clock
📝 字面: 在钟八点之前

## 用法说明 (Usage)

- `före + klockan + 数字` = 某时之前。*före* 是时间上的「之前」；空间上的「前面」用 *framför*。
- 近义 *senast klockan åtta*（最晚八点，deadline 语气更强）→ [[senast-klockan-åtta]]；*innan* 后面接**从句**（innan vi öppnar）。
- 幼儿园通常要求在开园前（8 点）报病假，这样不会给孩子备餐。
