# tack för hjälpen

🗣️ 类型: vardagsfras · 语域: neutralt · 常用度: 5/5
🇨🇳 谢谢帮忙；谢谢配合 · 🇬🇧 thanks for your help
📝 字面: 为帮助而谢

## 用法说明 (Usage)

- **tack för** + 名词**定式**：*tack för hjälpen / maten / idag / senast*。这是瑞典语"谢谢…"的固定模式。
- 公告结尾用它 = "谢谢配合"（事先感谢）；当面用 = "谢谢帮忙"（事后感谢）。
- 回答：*Ingen orsak!* / *Det var så lite!* / *Tack själv!*
- 对中文母语者：中文"谢谢你的帮助"有"你的"，瑞典语用定式 -en 代替，不说 ~~tack för din hjälp~~（可以说但不那么地道）。
