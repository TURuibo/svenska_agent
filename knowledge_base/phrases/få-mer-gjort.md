# få mer gjort

🗣️ 类型: fast-uttryck · 语域: vardagligt · 常用度: 3/5
🇨🇳 效率更高 · 🇬🇧 to get more done

## 用法说明 (Usage)

- 结构：`få + 数量词 + gjort`（gjort = göra 的 supinum 作过去分词）。
- 变体：`få mycket gjort`（做了很多事）、`få något gjort`。

## 例句 / 对话 (Examples)

- 🇸🇪 Där får jag mer gjort än om jag sitter hemma. — 🇨🇳 在那儿我比在家效率高。
- 🇸🇪 Jag får mycket gjort på morgonen. — 🇨🇳 我早上能做很多事。
