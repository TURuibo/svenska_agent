# passar det

🗣️ 类型: tidsfras · 语域: vardagligt · 常用度: 5/5
🇨🇳 （时间）合适吗 · 🇬🇧 does that work (for you)
📝 字面: fits it

## 用法说明 (Usage)

- 约时间时的核心问句：*Passar det klockan tio / på lördag / i morgon?*
- 回答：*Det passar bra / jättebra / perfekt.* 或 *Det passar tyvärr inte.*
- 这里的 **passa** = 适合、合适（不是"照看孩子"的 passa barn）。

- → [[grammar-ja-nej-fraga]] — 动词 passar 放句首

## 变体 & 相关 (Variations & Related)

- 🔄 *Passar det dig?* / *När passar det?* / *Det passar bra.*

## 例句 / 对话 (Examples)

- [[sent-passar-det-klockan-tio]] 🇸🇪 Passar det klockan tio? 🇨🇳 十点合适吗？
- [[sent-det-passar-jättebra-då-säger-vi]] 🇸🇪 Det passar jättebra, då säger vi så! 🇨🇳 很合适，那就这么定了！
