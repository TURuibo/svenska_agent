# skydda mot

🗣️ 类型: prepositionsuttryck（动词 + 介词）· 语域: 中性 · 常用度: 4/5
🇨🇳 保护免受……；防范…… · 🇬🇧 to protect against / from
📝 字面: 保护 + 对着（威胁）

## 用法说明 (Usage)

- 结构：`skydda + 被保护的对象 + mot + 威胁`：`skydda barn mot våld`。
- `mot` 后面是**威胁、危险、天气**：`mot kylan / solen / smitta / våld / bedrägerier`。
- 反身形式：`skydda sig mot + 威胁`（保护自己、防范）：`skydda sig mot kylan`。
- 介词也可以是 `från`（偏物理上"遮挡 / 免遭"）：`skydda huvudet från regn`；两者常互换。
- 与 [[hindra-från-att]] 区别：`skydda mot` = 保护对象不受伤害；`hindra från att` = 让某人不能做某事。

## 短语中的语法 (Grammar inside)

- 动词 [[skydda]] + 介词 `mot`；名词 [[skydd]]（保护）+ `mot`：`ett skydd mot kyla`（抗寒的保护）。

## 变体 & 相关 (Variations & Related)

- 🔄 `skydda sig mot …` — 保护自己免受
- 🔄 `skydd mot …` — 对……的保护
- 🔄 `vara skyddad mot …` — 受到……的保护
- 🔗 [[skydda]]、[[skydd]]、[[hindra-från-att]]

## 例句 / 对话 (Examples)

- 🇸🇪 Vaccinet skyddar mot flera sjukdomar. 🇨🇳 这种疫苗可以预防多种疾病。
- 🇸🇪 Glasögonen skyddar ögonen mot solen. 🇨🇳 这副眼镜保护眼睛免受阳光伤害。
- 🇸🇪 Lagen ska skydda barn mot våld. 🇨🇳 法律应当保护儿童免受暴力。
- 🇸🇪 Ta på dig en jacka för att skydda dig mot kylan. 🇨🇳 穿上外套，抵御寒冷。
