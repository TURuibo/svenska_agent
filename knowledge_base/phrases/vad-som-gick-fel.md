# vad som gick fel

🗣️ 类型: fast-uttryck (indirekt fråga) · 语域: neutralt · 常用度: 3/5
🇨🇳 出了什么问题 · 🇬🇧 what went wrong
📝 字面: 什么走错了

## 用法说明 (Usage)

- 间接疑问从句：`undersöka vad som gick fel`、`förstå vad som gick fel`。
- `vad` 在从句中作主语，所以要加 `som`。
- `gå fel` = 出错；`gå bra` = 顺利。

## 例句 / 对话 (Examples)

- 🇸🇪 De vill undersöka vad som gick fel. 🇨🇳 他们想调查出了什么问题。
- 🇸🇪 Jag förstår inte vad som gick fel. 🇨🇳 我不明白哪里出错了。
- 🇸🇪 Berätta vad som gick fel! 🇨🇳 告诉我出了什么问题！
