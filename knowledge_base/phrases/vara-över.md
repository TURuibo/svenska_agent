# vara över

🗣️ 类型: fast-uttryck（vara + 副词）· 语域: neutralt · 常用度: 4/5
🇨🇳 结束了 · 🇬🇧 to be over
📝 字面: 是 越过（过去了）

## 用法说明 (Usage)

- `vara över` = **（某事）已经结束了**，`över` 在这里是副词/表语，重音落在 **över**。
- 主语常为：事件、时期、关系、季节：
  - `Lektionen är över.` 课结束了。
  - `Sommaren är över.` 夏天过去了。
  - `Det är över mellan oss.` 我们之间结束了。
- 时态：现在 `är över`、过去 `var över`、完成 `har varit över`。
- 文章里：`Hans korta men mycket framgångsrika karriär som skridskoåkare var över.`（他短暂却极其成功的速滑生涯结束了。）——注意 `Hans` 作属格限定词，后面的形容词用定冠形式：`korta`、`framgångsrika`。
- ⚠️ `över` 的不同意思，勿混：

| 表达 | 意思 |
|------|------|
| `vara över` | 结束了 |
| `bli över` / `vara över` + 名词 | 剩下（`Det är pengar över.` 还剩钱） |
| `gå över` | 过去（疼痛/感冒消退）[[det-gick-över]] |
| `vara överens` | 意见一致 [[vara-överens]] |

- 近义说法见下方"变体"：`vara slut`、`ta slut`、`vara förbi`。
- 口语感叹：`Nu är det över!`（结束了！）、`Det är över nu.`（都过去了）。

## 短语中的语法 (Grammar inside)

- `vara` + 副词 `över` 作表语，无特殊语法点；属格 `Hans` 后的形容词取定冠形式（korta、framgångsrika）。

## 变体 & 相关 (Variations & Related)

- 🔄 `vara slut`（结束/用完了）· `ta slut`（结束、耗尽）· `vara förbi`（过去了）· `vara avslutad`（正式）
- 🔗 [[det-gick-över]]（过去了、消退了）
- 🔗 [[lägga-av]]（退出、不干了）
- 🔗 [[vara-överens]]（⚠️ 意见一致，形近）
- 🔗 [[vara]] · [[över]]

## 例句 / 对话 (Examples)

- 🇸🇪 Hans korta men mycket framgångsrika karriär som skridskoåkare var över. 🇨🇳 他作为速滑选手短暂却极其成功的生涯结束了。
- 🇸🇪 Festen var över klockan tolv. 🇨🇳 聚会十二点就结束了。
- 🇸🇪 Sommaren är över och skolan börjar igen. 🇨🇳 夏天过去了，学校又开学了。
- 🇸🇪 Det är över mellan oss. 🇨🇳 我们之间结束了。
