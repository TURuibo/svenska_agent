# börja bli kallt

🗣️ 类型: vardagsfras · 语域: vardagligt · 常用度: 4/5
🇨🇳 开始变冷 · 🇬🇧 start getting cold
📝 字面: "开始 + 变成 + 冷（中性）"

## 用法说明 (Usage)

- 天气句用**无人称 det** 做主语，形容词用 **-t 形**：*Det börjar bli kallt / mörkt / varmt.*（不是 ✗ kall）。
- **börja + 裸不定式**（不加 att）：börja bli、börja regna、börja snöa。
- **bli** 表"变得"：*det är kallt*（现在冷）vs *det blir kallt*（会变冷）vs *det börjar bli kallt*（正在开始变冷）。
- 秋季周信固定开场，后面必跟"记得带手套帽子"。

## 短语中的语法 (Grammar inside)

- → [[grammar-opersonligt-det]] — 天气/温度的 det
- → [[grammar-infinitiv]] — börja + infinitiv（无 att）

## 例句 / 对话 (Examples)

- [[sent-nu-börjar-det-bli-kallt-ute]] 🇸🇪 Nu börjar det bli kallt ute. 🇨🇳 现在外面开始变冷了。
- 🇸🇪 Det börjar bli mörkt tidigt på kvällen. 🇨🇳 晚上天开始黑得早了。
- 🇸🇪 Det börjar bli kallt – ta med en mössa! 🇨🇳 开始变冷了——带顶帽子！
