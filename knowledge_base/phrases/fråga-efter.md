# fråga efter

🗣️ 类型: prepositionsuttryck（动词 + 介词）· 语域: neutralt · 常用度: 4/5
🇨🇳 询问；要求（某物）；打听 · 🇬🇧 to ask for; to inquire about
📝 字面: 问 + 追着

## 用法说明 (Usage)

- `fråga efter + 东西/人`：向店家、银行等"要求提供、打听有没有"某物。近似 `efterfråga`（对……有需求）、`be om`（请求）。
- 在 WWF 文本里：`Fråga efter investeringar som inte bidrar …` = 向银行/顾问**要求**提供绿色投资，从而表明需求（[[efterfrågan]]）。
- ⚠️ 与固定搭配 `fråga efter vägen`（问路）同形，见 [[fråga-efter-vägen]]；`fråga om` = 就某事发问，`fråga efter` = 找/要某物。

## 短语中的语法 (Grammar inside)

- → [[grammar-imperativ]]：`Fråga efter …!`（祈使句）。

## 例句 / 对话 (Examples)

- 🇸🇪 Fråga efter investeringar som inte bidrar till den globala uppvärmningen. 🇨🇳 询问（要求）不会助长全球变暖的投资。
- 🇸🇪 Jag frågade efter en vegetarisk rätt. 🇨🇳 我问有没有素食菜。
- 🇸🇪 Kunderna frågar efter svenska produkter. 🇨🇳 顾客在找瑞典产品。
