# ha det som någon

🗣️ 类型: vardagsfras · 语域: neutralt · 常用度: 3/5
🇨🇳 过得像某人那样 · 🇬🇧 to have it like someone

## 用法说明 (Usage)

- `ha det` 表示“（生活状况）过得……”：`ha det bra / dåligt / som du`。
- 原文：`Jag önskar att jag hade det som du!` — 真希望我也能像你这样！
- 与 `Ha det bra!`（再见，保重）不同。

## 例句 / 对话 (Examples)

- 🇸🇪 Jag önskar att jag hade det som du. 🇨🇳 我真希望我过得像你一样。
- 🇸🇪 Hur har du det? 🇨🇳 你过得怎么样？
