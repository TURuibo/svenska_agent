# gå ombord

🗣️ 类型: partikelverb · 语域: neutralt · 常用度: 3/5
🇨🇳 登船；登上（交通工具） · 🇬🇧 to board (a ship/vessel/aircraft)
📝 字面: walk on board

## 用法说明 (Usage)

- "Gå ombord" används för att beskriva att kliva ombord på ett fartyg, flygplan eller annat fordon
- Prepositionen "på" specificerar vad man går ombord på: "gå ombord på fartyget"
- I militärt sammanhang: ett land "går ombord" på ett misstänkt fartyg = inspekterar det
