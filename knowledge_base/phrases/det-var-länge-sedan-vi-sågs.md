# det var länge sedan vi sågs

🗣️ 类型: situationsfras · 语域: vardagligt · 常用度: 5/5
🇨🇳 好久不见了 · 🇬🇧 it's been a long time since we met; long time no see
📝 字面: 自从我们上次见面已经很久了

## 用法说明 (Usage)

- 见到许久未见的朋友时的寒暄语，非常常用。
- 与 `det var länge sedan` 意思相近，但这句话更具体地说"见面"（`vi sågs`）。
- 可以单独说，或作为问候后的延伸：`Hej! Det var länge sedan vi sågs!`

## 短语中的语法 (Grammar inside)

- `sågs` = `ses` 的过去时（互动动词 s-form） → [[grammar-preteritum-s-form]]
- `det var länge sedan` = 时间状语结构（上次…已经很久了）

## 变体 & 相关 (Variations & Related)

- 🔄 `Det är länge sedan vi sågs` — 现在时形式，意思相同
- 🔄 `Det var länge sedan!` — 更简短版本
