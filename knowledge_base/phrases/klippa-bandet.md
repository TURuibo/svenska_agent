# klippa bandet

**类型:** uttryck (惯用表达)
**中文:** 剪彩
**English:** to cut the ribbon (at an opening ceremony)
**CEFR:** B1

## 用法 (Usage)

- 在正式开幕仪式上，由贵宾（政治家、王室等）剪断横跨入口的彩带，象征正式开通。
- 常与 **invigning**（开幕仪式）、**inviga**（正式开通）搭配使用。
- 可过去时变形：*klippte bandet* = 剪了彩带

## 例句 (Example Sentences)

1. *Anna Persson klippte bandet vid invigningen.* — 安娜·佩尔松在开幕仪式上剪了彩带。
2. *Kungen klippte bandet när museet öppnade.* — 国王在博物馆开幕时剪了彩带。
3. *Det är traditionellt att klippa bandet.* — 剪彩是一种传统。
4. *Vem ska klippa bandet vid invigningen?* — 谁来在开幕式上剪彩？
