# stå med på listan

🗣️ 类型: uttryck (situationsfras) · 语域: neutralt · 常用度: 3/5
🇨🇳 在名单上（已登记） · 🇬🇧 be on the list
📝 字面: 「站」在名单上——瑞典语用 [[stå]] 表示「写着/列着」

## 用法说明 (Usage)

- `stå på listan` = 名字在名单上；加 **med** 强调「也在其中、已被登记」。幼儿园接送场景固定说法。
- 「…的名单」用 över：`listan över hämtare`（接送人名单）。
- 否定：`Hon står inte med på listan` → 老师不能把孩子交给她。

## 短语中的语法 (Grammar inside)

- stå 表「写着」的用法：`Vad står det på skylten?`（牌子上写着什么？）
