# blunda för

🗣️ 类型: idiom · 语域: neutralt · 常用度: 3/5
🇨🇳 对……视而不见；无视 · 🇬🇧 to turn a blind eye to; to ignore
📝 字面: 为……闭上眼睛

## 用法说明 (Usage)

- 后接令人不舒服的事实/问题：`blunda för problemen / sanningen / klimatkrisen`。
- 常与否定 + 情态动词连用：`Vi kan inte blunda för …`（我们不能无视……），用于论证、呼吁。

- 🇸🇪 Man kan inte blunda för fakta. 🇨🇳 人不能对事实视而不见。
