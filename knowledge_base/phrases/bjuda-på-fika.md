# bjuda på fika

🗣️ 类型: vardagsfras · 语域: neutralt · 常用度: 5/5
🇨🇳 请大家吃 fika · 🇬🇧 offer fika / treat to coffee
📝 字面: "在 fika 上请客"

## 用法说明 (Usage)

- **bjuda på + 东西** = 请客（我付/我准备）：bjuda på fika、bjuda på lunch、bjuda på tårta。*Vi bjuder på fika!* 是活动通知里最暖的一句——意思是"来就有得吃"。
- **fika** = 咖啡/茶 + 甜点 + 聊天，瑞典文化关键词，可作名词也可作动词（*Ska vi fika?*）。
- 变形：bjuder / bjöd / bjudit（第 4 类强变化）。
- 带人：*bjuda någon på fika* = 请某人喝咖啡：*Jag bjuder dig på fika.*
