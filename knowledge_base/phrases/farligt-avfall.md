# farligt avfall

🗣️ 类型: fast-uttryck · 语域: neutralt · 常用度: 3/5
🇨🇳 危险废品 · 🇬🇧 hazardous waste
📝 字面: dangerous waste

## 用法说明 (Usage)

- 固定搭配：`farlig` (危险的) + `avfall` (废物)
- 指不能扔进普通垃圾桶、需要特殊处理的废弃物

## 短语中的语法 (Grammar inside)

- 形容词 `farlig` + 名词 `avfall`（ett-词，形容词不加 -t，因为是 obestämd form）
- ⚠️ 注意：`farlig` 修饰 `avfall (ett)` → 不定形应为 `farligt avfall`（加 -t）
