# trots att

🗣️ 类型: fast-uttryck · 语域: neutralt · 常用度: 5/5
🇨🇳 尽管；虽然 · 🇬🇧 despite the fact that, although
📝 字面: despite that

## 用法说明 (Usage)

- bisatsinledare（从句引导词），后接完整从句（有主语+动词）
- `trots att + [subjekt] + [inte] + [finit verb]` = BIFF 语序适用
- 区别：`trots att` (konjunktion + bisats) vs `trots` (preposition + nominal phrase)
  - *trots att han var trött* (尽管他疲惫) vs *trots tröttheten* (尽管疲惫)
