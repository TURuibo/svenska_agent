# drömma om

🗣️ 类型: partikelverb · 语域: neutralt · 常用度: 3/5
🇨🇳 梦想着 · 🇬🇧 to dream of

## 用法说明 (Usage)

- drömma om + 名词 / att + 不定式 = 梦想（得到）某事；介词 om 可留在关系从句句尾。
- 核心词: [[drömma]]

## 例句 / 对话 (Examples)

- 🇸🇪 Hon drömmer om att bli läkare. 🇨🇳 她梦想成为医生。
- 🇸🇪 Polis är jobbet som flest ungdomar drömmer om. 🇨🇳 警察是最多年轻人梦想的工作。
- 🇸🇪 Jag drömmer om en semester vid havet. 🇨🇳 我梦想着去海边度假。
