# vid hämtning

🗣️ 类型: prepositionsuttryck · 语域: neutralt · 常用度: 4/5
🇨🇳 接园时 · 🇬🇧 at pick-up
📝 字面: 在 接（园）

## 用法说明 (Usage)

- **vid + 动作名词（不定式、无冠词）** = "在…的时候"：*vid hämtning*（接园时）、*vid lämning*（送园时）、*vid behov*（需要时）、*vid frågor*（有问题时）。这是通知/公文常用的紧凑写法。
- 口语里说 *när ni hämtar*（你们来接的时候）更自然，意思一样。
- *hämtning* 来自动词 *hämta*（接、取）→ 名词化 -ning。

## 短语中的语法 (Grammar inside)

- 介词 *vid* + 动词派生名词 → 代替时间从句（när-sats）。
