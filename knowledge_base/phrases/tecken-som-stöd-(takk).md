# tecken som stöd (TAKK)

🗣️ 类型: 术语 · 语域: neutralt · 常用度: 2/5
🇨🇳 辅助手语（瑞典幼儿园用的手势支持） · 🇬🇧 signs as support
📝 字面: 作为支持的手势

## 用法说明 (Usage)

- TAKK = *Tecken som Alternativ och Kompletterande Kommunikation*：一边说话一边打关键词手势，帮助还不会说话的小孩理解和表达。几乎所有瑞典幼儿园都用。
- 不是手语（teckenspråk）——只配合口语打关键词，语法仍是瑞典语。
- 动词是 *teckna*：*hon tecknar "mer"* = 她比「更多」的手势。常与 *bildstöd*（图片辅助）一起提。
