# det krävs — opersonlig passiv (非人称被动)

📖 中文：需要；必须要有；要求 · English: it is required; it takes
📐 语法类型：非人称被动结构（opersonlig passiv / det-konstruktion）

## 用法 (Usage)

- `det krävs [substantiv]` — 需要……；必须有……
- `det krävs att [satsmening]` — 要求（某事）……
- `det kräver [substantiv]`（主动对应形式）— 这需要……

## 例句 (Sentences)

- 🇸🇪 Det krävs politiska åtgärder för att lösa detta. — 🇨🇳 解决这个问题需要政治措施。
- 🇸🇪 Det krävs mod att säga sanningen. — 🇨🇳 说出真相需要勇气。
- 🇸🇪 Det krävs att alla bidrar. — 🇨🇳 要求所有人都做出贡献。

## 用法提示 (Usage Notes)

- `det krävs` 是 `kräva`（要求）的非人称被动形式：字面上"它被要求/需要"。
- 比 `man behöver`（人们需要）更有力、更书面/正式。
- 常见于议论文、政策文件的结论段。
