# knyta an till

🗣️ 类型: partikelverb · 语域: neutralt · 常用度: 2/5
🇨🇳 与…衔接/呼应 · 🇬🇧 to connect to, refer back to

## 用法说明 (Usage)

- 写回信时，开头先 "knyta an till" 对方上一封信的内容。
- 教材："Inled med att knyta an till tidigare brev."（见 [[grammar-informellt-brev-struktur]]）。

## 例句 / 对话 (Examples)

- 🇸🇪 Jag börjar med att knyta an till ditt förra brev. — 🇨🇳 我先回应一下你上一封信。
- 🇸🇪 Vad bra att du har bestämt dig för att sluta röka. — 🇨🇳 你决定戒烟，真好。（knyta an 的例子）
