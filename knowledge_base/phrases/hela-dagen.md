# hela dagen

🗣️ 类型: fast-uttryck · 语域: neutralt · 常用度: 4/5
🇨🇳 一整天 · 🇬🇧 all day
📝 字面: 整个白天

## 用法说明 (Usage)

- 无介词，直接作时间状语："Jag arbetar hela dagen."
- 同类：hela natten, hela veckan, hela tiden。

## 例句 / 对话 (Examples)

- [[sent-först-tyckte-jag-att-det-lät]] 🇸🇪 … för jag satt vid datorn hela dagen. 🇨🇳 因为我整天坐在电脑前。
