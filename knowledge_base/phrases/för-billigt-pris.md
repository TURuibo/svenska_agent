# för ett bra/billigt pris — prepositionalfras

Zh: 以合适/便宜的价格 · English: for a good/cheap price
发音提示：för ett BRA/BIL-ligt PRIS

## 结构分析 (Structure)

```
för + ett + adjektiv + pris
```

- `för` — 以……（价格）
- `ett` — 不定冠词（`pris` 是 neutrum）
- `bra / billigt / bättre / rimligt` — 形容词修饰 pris

## 用法示例 (Examples)

- `för ett bra pris` — 以合适的价格
- `för ett billigt pris` — 以便宜的价格
- `för ett rimligt pris` — 以合理的价格
- `till ett bra pris`（也常见）— 以好的价格（`till` 和 `för` 在此语境可互换）

## 例句 (Sentences)

- Vi hittade massor av saker för ett bra pris på loppisen. — 我们在跳蚤市场以很好的价格找到了很多东西。
- Det gick att köpa gamla böcker för ett billigt pris. — 可以以便宜的价格买到旧书。
- Hon sålde sina gamla kläder för ett rimligt pris. — 她以合理的价格出售了自己的旧衣服。
