# något att dricka

🗣️ 类型: uttryck · 语域: neutralt · 常用度: 4/5
🇨🇳 喝点什么；饮品 · 🇬🇧 something to drink
📝 字面: something to drink

## 用法说明 (Usage)

- Common in restaurant/café contexts: *Vill ni ha något att dricka?* = Would you like something to drink?
- Pattern: *något att + infinitiv* = something to [verb].
- Also: *något att äta* = something to eat; *något att läsa* = something to read.
