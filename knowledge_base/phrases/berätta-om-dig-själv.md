# berätta om dig själv

🗣️ 类型: situationsfras · 语域: neutralt · 常用度: 4/5
🇨🇳 介绍你自己 · 🇬🇧 tell us about yourself
📝 字面: tell about yourself

## 用法说明 (Usage)

- 面试和自我介绍中的经典开场问题
- dig själv = dig（你，宾格）+ själv（自己）
- 也可说 berätta lite om dig själv（稍微介绍一下你自己）

## 短语中的语法 (Grammar inside)

- → [[grammar-reflexivt-pronomen]]（dig själv 是反身代词构式）
- → [[grammar-imperativ]]（berätta 是命令形）

## 变体 & 相关 (Variations & Related)

- 🔄 berätta lite om dig själv（稍微介绍一下你自己）
- 🔄 kan du berätta om dig själv?（你能介绍一下你自己吗？）
- 🔄 berätta om er/er själva（介绍你们自己，复数）

## 例句 / 对话 (Examples)

- [[sent-berätta-lite-om-dig-själv]] 🇸🇪 Berätta lite om dig själv. 🇨🇳 请介绍一下你自己。
- 🇸🇪 Intervjuaren sa: berätta om dig själv och din erfarenhet. 🇨🇳 面试官说：介绍一下你自己和你的经验。
