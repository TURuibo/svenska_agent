# så länge

🗣️ 类型: fast-uttryck（konjunktion） · 语域: neutralt · 常用度: 4/5
🇨🇳 只要 · 🇬🇧 as long as
📝 字面: 这么久

## 用法说明 (Usage)

- 作**从属连词**引导条件从句 = 「只要……（就）」：*Lite snuva gör inget så länge hon är pigg.* 从句里用 bisats 语序。
- ⚠️ 单独作副词时 *så länge* 意为「这么久 / 暂时」：*Vänta så länge!*（先等一会儿）。*än så länge* = 到目前为止。
- 与 *om* 的区别：*så länge* 强调「在……持续期间/条件保持时」。
