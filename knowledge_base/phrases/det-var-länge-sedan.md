# det var länge sedan

🗣️ 类型: fast-uttryck · 语域: vardagligt · 常用度: 5/5
🇨🇳 好久不见 · 🇬🇧 it's been a long time; long time no see
📝 字面: that was a long time ago

## 用法说明 (Usage)

- 用于久别重逢时的感叹句，相当于"好久不见"。
- 可独立使用，也常与 *Hur har du haft det?* 连用。

## 短语中的语法 (Grammar inside)

- → [[grammar-preteritum]] (var = 过去式)

## 变体 & 相关 (Variations & Related)

- 🔄 *Det var ett tag sedan!* (好久没见了！)
- 🔄 *Längesen!* (口语缩写形式)

## 例句 / 对话 (Examples)

- 🇸🇪 Johan! Det var länge sedan! Hur har du haft det? 🇨🇳 约翰！好久不见！你最近怎么样？
