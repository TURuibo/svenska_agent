# vakna från vilan

🗣️ 类型: verbfras · 语域: vardagligt · 常用度: 3/5
🇨🇳 午睡醒来 · 🇬🇧 wake up from nap
📝 字面: 从休息中醒来

## 用法说明 (Usage)

- 幼儿园的午睡叫 **vilan**（定形，是园里固定环节），不说 *lur*/*tupplur*。`vakna från vilan` = 午睡醒来。
- vakna（v.1：vaknar / vaknade / vaknat）是不及物「醒来」；「叫醒」是 *väcka*。
- 常接状态形容词：*vakna alldeles varm / gnällig / glad*。

## 例句 / 对话 (Examples)

- [[sent-hon-vaknade-från-vilan-alldeles-varm]] 🇸🇪 Hon vaknade från vilan alldeles varm och hängig. 🇨🇳 她午睡醒来浑身发热、蔫蔫的。
- 🇸🇪 Han vaknade från vilan på gott humör. 🇨🇳 他午睡醒来心情很好。
