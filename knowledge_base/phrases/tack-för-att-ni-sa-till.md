# tack för att ni sa till

🗣️ 类型: 礼貌表达 (situationsfras) · 语域: neutralt · 常用度: 3/5
🇨🇳 谢谢你们说一声 · 🇬🇧 thanks for letting me know
📝 字面: 谢谢 + 因为你们说了一声

## 用法说明 (Usage)

- 模板 **Tack för att + 从句** = 「谢谢你(们)做了…」：`Tack för att du ringde` / `Tack för att ni kom`。⚠️ 是 för **att**，不是 *tack att*。
- 对幼儿园老师用 **ni**（老师们，复数），对一个人用 du。
- [[säga-till]] 的 preteritum `sa till`。

## 短语中的语法 (Grammar inside)

- → [[grammar-att-bisats]]：för att 引导从句，主谓正常语序。
- → [[grammar-preteritum]]：sa（säga 的过去式）。

- 🇸🇪 Tack för att du sa till om blöjorna. 🇨🇳 谢谢你提醒尿布的事。
