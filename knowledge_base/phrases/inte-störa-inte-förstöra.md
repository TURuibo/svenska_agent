# inte störa, inte förstöra

🗣️ 类型: ordspråk/regel · 语域: neutralt · 常用度: 3/5
🇨🇳 不打扰，不破坏 · 🇬🇧 don't disturb, don't destroy
📝 字面: not disturb, not destroy

## 用法说明 (Usage)

- 这是**allemansrätten（公共通行权）的基本原则**，常被引用为两条核心规则。
- 语法上是两个并列的**否定不定式结构**（negerad infinitiv）：*inte + infinitiv*。
- 常见完整句：*Regeln är enkel: Inte störa, inte förstöra.* （规则很简单：不打扰，不破坏。）

## 短语中的语法 (Grammar inside)

- 否定副词 **inte** + 不定式（infinitiv）= 带否定的命令/规则表达

- 🇸🇪 Tänk på regeln: inte störa, inte förstöra — så kan alla njuta av naturen. 🇨🇳 记住规则：不打扰，不破坏——这样所有人都能享受大自然。
