# finns med på

🗣️ 类型: fast-uttryck · 语域: neutralt · 常用度: 3/5
🇨🇳 被列入……，出现在……名单上 · 🇬🇧 to be on (a list), to be included in
📝 字面: is included on

## 用法说明 (Usage)

- `finns med på` + lista/lista = 被列入某名单/榜单。
- 常用于说明某人或某地被收录在某个官方名单上。
- 常见搭配：`finns med på Unescos världsarvslista`。

## 变体 & 相关 (Variations & Related)

- 🔄 `tas upp på listan` — 被列入名单
- 🔄 `är med på` — 在……上面
- 🔗 [[det-finns]]

## 例句 / 对话 (Examples)

- 🇸🇪 Visby finns sedan 1995 med på Unescos världsarvslista. 🇨🇳 维斯比自1995年起被列入联合国教科文组织世界遗产名录。
- 🇸🇪 Hennes namn finns med på topplistan över bästa forskare. 🇨🇳 她的名字出现在最佳研究人员榜单上。
