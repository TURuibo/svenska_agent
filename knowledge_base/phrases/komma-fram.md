# komma fram

🗣️ 类型: partikelverb · 语域: neutralt · 常用度: 5/5
🇨🇳 到达；抵达 · 🇬🇧 to arrive / get there
📝 字面: komma（来）+ fram（向前）= 到达目的地

## 用法说明 (Usage)

- `komma fram till + 地点` = 到达某地。
- `kom fram` = preteritum（komma → kom，不规则）。
- 近义：`anlända`（正式），`nå fram`（强调终于到达）。

## 短语中的语法 (Grammar inside)

- → [[grammar-preteritum]]（komma → kom，不规则）

## 变体 & 相关 (Variations & Related)

- 🔄 `anlända` — 抵达（正式）
- 🔄 `nå fram` — 终于到达
- 🔗 [[ta-tunnelbanan]] — 乘地铁（到达前的步骤）

## 例句 / 对话 (Examples)

- [[sent-vid-halv-nio-kom-jag-fram-till-centralstationen]] 🇸🇪 Vid halv nio kom jag fram till Centralstationen. 🇨🇳 将近八点半，我到了中央车站。
