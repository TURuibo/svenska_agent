# klara trappan

🗣️ 类型: kollokation · 语域: neutralt · 常用度: 2/5
🇨🇳 能爬楼梯 · 🇬🇧 to manage the stairs
📝 字面: 应付楼梯

## 用法说明 (Usage)

- [[klara]] + 宾语 = 能应付/完成；常用否定形式 "klarar inte trappan" 表示体力上爬不了。

## 例句 / 对话 (Examples)

- [[sent-det-är-farligt-och-många-äldre-hyresgäster]] 🇸🇪 Många äldre hyresgäster klarar inte trappan. 🇨🇳 许多年长租户爬不了楼梯。
