# gå hungrig

🗣️ 类型: fast-uttryck · 语域: neutralt · 常用度: 3/5
🇨🇳 挨饿；饿着肚子 · 🇬🇧 go hungry, remain hungry
📝 字面: go hungry

## 用法说明 (Usage)

- 结构：`gå + adjektiv` = 保持某种状态（= remain/stay + adj）
  - *gå hungrig* = 一直饿着 (stay hungry)
  - *gå trött* = 一直很累
  - *gå ensam* = 一直孤单
- 课文：*han fick ofta gå hungrig* — 他经常不得不饿着肚子

## 短语中的语法 (Grammar inside)

- `gå + adj` 结构 = 状态持续动词短语（不同于 `bli + adj` = 变得...）

## 变体 & 相关 (Variations & Related)

- 🔄 `vara hungrig` — 处于饥饿状态（静态）
- 🔄 `bli hungrig` — 变得饿了（状态变化）
