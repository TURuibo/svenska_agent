# det kallas

🗣️ 类型: fast-uttryck · 语域: neutralt · 常用度: 4/5
🇨🇳 这叫做… · 🇬🇧 it is called
📝 字面: 它 被叫

## 用法说明 (Usage)

- **kallas** = kalla（叫、称）的 **s-被动**：*kallar → kallas*，"被称为"。*Det kallas sammanslagning.* = 这（种做法）叫合并托管。
- 解释术语时最常用的句型：*Det kallas (för) X.* / *X kallas (för) Y.* —— *för* 可有可无。
- 人名：*Hon heter Elisabeth men kallas Lisa.*（她叫 Elisabeth，但大家叫她 Lisa。）
- 中文"这叫做…"是主动式，瑞典语用被动 -s，看到 *kallas* 先想"被称作"。
- 变形：kallas / kallades / kallats。
