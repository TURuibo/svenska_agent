# fatta beslut

🗣️ 类型: fast-uttryck（动词 + 名词搭配）· 语域: 正式 / 新闻体 · 常用度: 4/5
🇨🇳 做出决定 · 🇬🇧 to make a decision
📝 字面: 抓住 / 拿起 + 决定

## 用法说明 (Usage)

- 结构：`fatta (ett) beslut (om + 事项)`：`Kommunen fattade beslutet om de nya reglerna.`
- 新闻 / 公文里常用**被动**：`Beslutet fattades i måndags.`（`fattas` = s-passiv，见 [[grammar-s-passiv]]）。
- `beslut` 是 **ett-词**：`ett beslut – beslutet – beslut – besluten`。
- 比 `ta ett beslut`（也可，较日常）更书面；动词 `besluta` 是同义的简单说法：`Kommunen beslutade att …`。
- 对象多是机构 / 有权的人：`styrelsen / kommunfullmäktige / regeringen fattar beslut`。

## 短语中的语法 (Grammar inside)

- → [[grammar-s-passiv]]：`Beslutet fattades` — 动词 + -s 表被动。
- 搭配 `fatta beslut om + 名词`，介词用 **om**（不是 *för / av*）。

## 变体 & 相关 (Variations & Related)

- 🔄 `ta ett beslut` — 做个决定（日常）
- 🔄 `besluta (att …)` — 决定（动词）
- 🔄 `fatta ett svårt / viktigt beslut` — 做出艰难 / 重要的决定
- 🔗 [[fatta]]、[[beslut]]、[[kommunfullmäktige]]、[[ta-sitt-livs-beslut]]、[[bestämma-sig]]

## 例句 / 对话 (Examples)

- [[sent-i-måndags-fattade-kommunfullmäktige-beslutet]] 🇸🇪 I måndags fattade kommunfullmäktige beslutet om de nya reglerna. 🇨🇳 周一，市议会就新规做出了决定。
- 🇸🇪 Vi måste fatta ett beslut före fredag. 🇨🇳 我们必须在周五之前做出决定。
- 🇸🇪 Beslutet fattades i går kväll. 🇨🇳 这个决定是昨晚做出的。
- 🇸🇪 Det är svårt att fatta ett beslut när man inte vet allt. 🇨🇳 在不了解全部情况时很难做出决定。
