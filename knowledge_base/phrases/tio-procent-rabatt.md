# tio procent rabatt

🗣️ 类型: prisuttryck · 语域: neutralt · 常用度: 3/5
🇨🇳 九折；十个百分点折扣 · 🇬🇧 ten percent discount

## 用法说明 (Usage)

- 瑞典购物中常用的折扣表达。
- 结构：数字 + *procent* + *rabatt*（例 *femton procent rabatt* = 85折）。
- 注意：中文"几折"与瑞典语方向相反（*tio procent rabatt* = 少10% = 九折）。
