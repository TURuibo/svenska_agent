# skåla med snaps

🗣️ 类型: vardagsfras · 语域: vardagligt · 常用度: 3/5
🇨🇳 用烈酒干杯 · 🇬🇧 to toast with snaps
📝 字面: toast with snaps (aquavit)

## 用法说明 (Usage)

- 仲夏节最典型的餐桌仪式：举起 snaps（烈酒）互相碰杯，通常配着唱 snapsvisor（干杯歌）
- skåla + med + 饮料 = 用…干杯
- 也可单独说 Skål! 作为祝酒词

## 短语中的语法 (Grammar inside)

- skåla（v.1）：skålar / skålade / skålat
- med = 用（工具/方式）

- 🔄 Ta en snaps — 喝一口烈酒
