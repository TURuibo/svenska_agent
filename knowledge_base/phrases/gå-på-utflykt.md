# gå på utflykt

🗣️ 类型: vardagsfras · 语域: neutralt · 常用度: 4/5
🇨🇳 去郊游 · 🇬🇧 go on an outing
📝 字面: "走在郊游上"

## 用法说明 (Usage)

- 固定介词 **på**：gå på utflykt、åka på utflykt（坐车去）、vara på utflykt（正在郊游中）。
- 目的地用 **till**：*gå på utflykt **till** lekparken / skogen / museet*。
- 幼儿园的 utflykt 通常是走路去附近公园/树林，所以用 **gå**；坐公交去远处才说 *åka på utflykt*。
- 通知里常配"请几点前到"：*Var här senast klockan 9* —— 迟到就跟不上队伍了。
