# Vi kommer!

🗣️ 类型: fast-uttryck (kort svar) · 语域: vardagligt · 常用度: 5/5
🇨🇳 我们来！ · 🇬🇧 We'll be there!
📝 字面: 「我们来」—— 现在时表示将来

## 用法说明 (Usage)

- 对邀请的**最短肯定回复**：*Lekträff på lördag? — Vi kommer!*
- 瑞典语用 **presens** 说已定的将来安排，不需要 *ska*：*Vi kommer (på lördag)*。
- 否定/婉拒：*Vi kan tyvärr inte komma.* / *Vi måste ställa in.*
- 单人：*Jag kommer!*；确认人数：*Vi kommer, vi blir tre.*
