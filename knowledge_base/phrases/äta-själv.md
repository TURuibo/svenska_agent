# äta själv

🗣️ 类型: 动词搭配 · 语域: vardagligt · 常用度: 4/5
🇨🇳 自己吃（不用喂） · 🇬🇧 to eat by oneself
📝 字面: 自己吃

## 用法说明 (Usage)

- *själv* 在这里 = 独立地、不用别人帮，是 1–2 岁的重要里程碑。
- *själv* 随主语变形：hon äter själv / barnet äter självt / de äter själva。
- 常和工具搭配：*äta själv med sked / med gaffel*。
