# tack för att du ringde

🗣️ 类型: artighetsfras · 语域: neutralt · 常用度: 5/5
🇨🇳 谢谢你打电话来 · 🇬🇧 thanks for calling
📝 字面: 谢谢因为你打了电话

## 用法说明 (Usage)

- 「谢谢你做了 X」= `tack för att + 从句`（*att* 不能省；从句用 preteritum 或 perfekt）。名词接 *tack för + 名词*：*tack för samtalet*。
- 常见回应：*Ingen fara* / *Det var så lite* / *Ingen orsak*。
- 中文「谢谢你打电话」直译容易漏掉 *för att*，是高频错误。
