# ligga vid kusten

🗣️ 类型: prepositionsuttryck · 语域: neutralt · 常用度: 3/5
🇨🇳 位于海岸边；临海 · 🇬🇧 to be situated on the coast, to lie by the coast
📝 字面: to lie by the coast

## 用法说明 (Usage)

- **ligga vid** + 水体名词，描述地理位置"靠近水"
- 关键介词：**vid**（靠近）而非 *i* 或 *på*
- 常见搭配：*ligga vid kusten* · *ligga vid havet* · *ligga vid en sjö* · *ligga vid en flod*
- 也可用 *bo vid kusten/havet/sjön*（居住在……边）

## 短语中的语法 (Grammar inside)

- → [[grammar-val-av-preposition-bo]] — *ligga/bo vid* 水体 = 水边介词 *vid* 的用法
- *ligga* 不规则：ligga / ligger / låg / legat

## 变体 & 相关 (Variations & Related)

- 🔄 *bo vid havet/sjön* — 住在海边/湖边（居住动词版本）
- 🔄 *ligga vid en flod* — 位于河边
- 🔄 *kuststad* — 海岸城市（名词复合词）

## 例句 / 对话 (Examples)

- 🇸🇪 Halland ligger vid kusten i västra Sverige. — 🇨🇳 哈兰省位于瑞典西部的海岸边。
- 🇸🇪 Stockholm ligger vid Östersjön. — 🇨🇳 斯德哥尔摩位于波罗的海边。
- 🇸🇪 Det är skönt att bo vid havet. — 🇨🇳 住在海边很惬意。
