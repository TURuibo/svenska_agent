# flytta till Sverige

🗣️ 类型: situationsfras · 语域: neutralt · 常用度: 4/5
🇨🇳 搬到瑞典 · 🇬🇧 to move to Sweden

## 用法说明 (Usage)

- flytta till + 地点 = 搬到某地；flytta från = 从某地搬走。

## 例句 / 对话 (Examples)

- 🇸🇪 Skatteverket ger dig ett personnummer när du flyttar till Sverige. 🇨🇳 你搬到瑞典时，税务局会给你个人号码。
