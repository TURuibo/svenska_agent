# börja med att + infinitiv

🗣️ 类型: fast-uttryck · 语域: neutralt · 常用度: 5/5
🇨🇳 先从……做起 · 🇬🇧 start by …ing

## 用法说明 (Usage)

- 结构：`börja med att + 动词不定式`。
- 经常用于指令（imperativ）：“Börja med att planera svaret.”，教材任务的典型开头。
- 区别：`börja + inf`（开始做）vs `börja med att + inf`（第一步先做）；`börja med + 名词`（以……开头）。
