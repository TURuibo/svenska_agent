# gå att se

🗣️ 类型: fras · 语域: neutralt · 常用度: 3/5
🇨🇳 可以看到（被动可能式） · 🇬🇧 can be watched/seen
📝 字面: go to see

## 用法说明 (Usage)

- `gå att + infinitiv` 是瑞典语表达"可以/能够被…"的常见被动可能式结构（modal passiv），主语是被动作用的对象。
- 结构：`X går att Y-a` = X可以被Y（X是承受者，不是执行者）。
- 例：`Filmen går att se på SVT Play.` = 这部电影可以在SVT Play上看到。

## 短语中的语法 (Grammar inside)

- → [[grammar-passiv-konstruktion]] — `gå att + infinitiv` 表达可能性被动，相当于 `kan + s-passiv`

## 变体 & 相关 (Variations & Related)

- 🔄 `kan ses` — 同义的 s-passiv 说法（更正式）
- 🔄 `går att göra` — 可以做到（泛用）

## 例句 / 对话 (Examples)

- 🇸🇪 Matchen går att se direkt på SVT Play. — 🇨🇳 比赛可以在SVT Play上直播观看。
- 🇸🇪 Den här artikeln går att läsa på flera språk. — 🇨🇳 这篇文章可以用多种语言阅读。
