# till fots

🗣️ 类型: prepositionsuttryck（固定副词短语）· 语域: 中性 · 常用度: 4/5
🇨🇳 步行；徒步 · 🇬🇧 on foot
📝 字面: 到脚（古式属格形式 `fots`）

## 用法说明 (Usage)

- `fots` 是 `fot`（脚）的古式属格，**只在固定短语里保留**：`till fots`、`på fri fot`（被释放）。不要拆开或改成 *till fot*。
- 常见搭配：`gå till fots`、`ta sig dit till fots`、`En kvart till fots.`（步行一刻钟）。
- 说"步行去"多用 `gå` 本身就含"步行"：`Jag går till jobbet.`；强调"不是开车 / 骑车"时才加 `till fots`。
- 名词形式 `fotgängare`（行人）、`gående`（步行的人）。

## 短语中的语法 (Grammar inside)

- 固定短语，无需变形；与其他交通方式对比：`med bil / med buss / med cykel`（用 `med`），步行用 `till fots`。

## 变体 & 相关 (Variations & Related)

- 🔄 `gå dit` — 走过去
- 🔄 `med cykel / med bil / med buss` — 骑车 / 开车 / 坐公交
- 🔗 [[fot]]、[[gå]]、`fotgängare`

## 例句 / 对话 (Examples)

- [[sent-kommunen-vill-att-det-ska-bli-tryggare]] 🇸🇪 Kommunen vill att det ska bli tryggare för alla som går till fots. 🇨🇳 市政府希望让所有步行的人更有安全感。
- 🇸🇪 Jag går till fots till jobbet. 🇨🇳 我步行去上班。
- 🇸🇪 Det tar tio minuter till fots. 🇨🇳 步行要十分钟。
- 🇸🇪 Kan man ta sig dit till fots? 🇨🇳 能走路到那儿吗？
