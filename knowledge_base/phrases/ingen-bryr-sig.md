# ingen bryr sig

🗣️ 类型: fast-uttryck · 语域: vardagligt · 常用度: 4/5
🇨🇳 没有人在意 · 🇬🇧 nobody cares / no one minds
📝 字面: no one cares themselves (reflexive)

## 用法说明 (Usage)

- 常用于表达某件事（如下雨）不会影响大家的心情或计划
- ingen（没有人）+ bryr sig（在乎/介意，反身动词）
- 语气轻松，有时带有幽默感

## 短语中的语法 (Grammar inside)

- → [[grammar-reflexivt-verb]]：bry sig（在意）是反身动词，必须带 sig
- ingen = 没有人（不定代词，用于否定）
- bry sig om = 在意某事/某人（更完整形式）

## 变体 & 相关 (Variations & Related)

- 🔄 Det bryr sig ingen om — 没人在意这件事（更正式语序）
- 🔄 Ingen bryr sig om det — 没有人在意那件事
- 🔗 [[inga-problem]]
