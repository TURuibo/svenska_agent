# till exempel (t.ex.)

🗣️ 类型: diskursmarkor · 语域: neutralt · 常用度: 5/5
🇨🇳 例如、比如 · 🇬🇧 for example
📝 字面: 到 例子

## 用法说明 (Usage)

- 缩写 **`t.ex.`**（读作 `till exempel`），书面中常用：`t.ex.`（注意两个点，中间无空格也可）。
- 可放的位置：
  1. **句首（第一位）** → 主句倒装：`Till exempel kan man …`（`kan` 在主语 `man` 前）
  2. **句中**：像 `inte`、`ofta` 一样的**语气副词（satsadverbial）**，在主句里放在**限定动词之后**：`Han kunde till exempel springa …`（`kunde` + `till exempel` + 不定式）。
  3. **列举时作插入语**：`Jag gillar sport, till exempel fotboll och tennis.`
- 在从句里则放在**主语之后、动词之前**：`… eftersom han till exempel har …`。
- 语义：给出**一个或几个例子**，不是穷尽列举。
- 对比：

| 表达 | 意思 |
|------|------|
| `till exempel` / `t.ex.` | 例如（举例） |
| `exempelvis` | 例如（更书面） |
| `bland annat` / `bl.a.` | 其中包括……等（列出部分，常放在动词后） |
| `det vill säga` / `d.v.s.` | 也就是说（解释、改述） |
| `som` | 像……这样的（名词前）：`frukt som äpplen` |

## 例句 / 对话 (Examples)

- 🇸🇪 Han kunde till exempel springa 3 timmar för att köpa godis eller cykla flera mil för en pizza. 🇨🇳 比如他会跑三个小时去买糖，或者骑几十公里去吃一个披萨。
- 🇸🇪 Jag gillar många sporter, till exempel fotboll och tennis. 🇨🇳 我喜欢很多运动，比如足球和网球。
- 🇸🇪 Till exempel kan du ta bussen. 🇨🇳 比如你可以坐公交。
- 🇸🇪 Man kan t.ex. öva genom att läsa nyheter. 🇨🇳 比如可以通过读新闻来练习。
