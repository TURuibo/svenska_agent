# allt från … till …

🗣️ 类型: fast-uttryck · 语域: neutralt · 常用度: 4/5
🇨🇳 从……到……（列举范围之广） · 🇬🇧 everything from … to …
📝 字面: 一切 从 … 到 …

## 用法说明 (Usage)

- 结构：`allt från + A + till + B`，A 和 B 是范围的**两端**，中间的一切都包括在内。用来强调"范围很广、种类很多"。
- `allt` 在这里 = "所有一切"，把 `från … till …` 的范围夸大了一点；不加 `allt` 的 `från A till B` 只是中性地指出起点和终点。
- 文章里 `till` 之后继续列举了更多项：`allt från höjdhopp till bandy, golf och fotboll`——`till` 后面可以接一串名词，不限于一个。
- 常见搭配：`allt från … till …` 前面常有逗号 + 概括名词（"flera olika sporter, allt från …"），像补充说明。
- 变体：`allt ifrån … till …`（更强调"起点"）；`allt mellan himmel och jord`（天南海北、无所不包）。
- 语域：口语书面都常用，介绍范围、产品、兴趣爱好时很自然。

## 短语中的语法 (Grammar inside)

- 介词 `från`（起点）+ `till`（终点）；`allt` 为名词性代词作"总括"。无特殊语法点。

## 变体 & 相关 (Variations & Related)

- 🔄 `allt ifrån … till …` · `från A till B` · `allt möjligt`（各种各样的东西）

## 例句 / 对话 (Examples)

- 🇸🇪 Som barn höll han på med flera olika sporter, allt från höjdhopp till bandy, golf och fotboll. 🇨🇳 小时候他玩过好几种运动，从跳高到班迪球、高尔夫和足球。
- 🇸🇪 Butiken säljer allt från mat till kläder. 🇨🇳 这家店从食品到衣服什么都卖。
- 🇸🇪 Hon läser allt från deckare till dikter. 🇨🇳 她什么都读，从侦探小说到诗歌。
- 🇸🇪 Vi pratade om allt från politik till mat. 🇨🇳 我们聊了从政治到美食的各种话题。
