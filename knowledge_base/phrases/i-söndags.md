# i söndags

🗣️ 类型: fast-uttryck · 语域: neutralt · 常用度: 4/5
🇨🇳 上周日 · 🇬🇧 last Sunday
📝 字面: 在周日（过去的）

## 用法说明 (Usage)

- i + 星期几 + -s = 刚过去的那个星期几（i måndags, i fredags）。与 på söndag（即将到来的周日）对比。
