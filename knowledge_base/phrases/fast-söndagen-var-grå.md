# fast (让步连词) — konjunktion

Zh: 虽然……；即使……（让步连词） · English: even though; although; though
发音提示：FAST（单音节）

## 结构分析 (Structure)

```
Huvudsats, fast + bisats.
  eller
Fast + bisats, + huvudsats.
```

- `fast` 在此用法中 = `även om` / `fastän`（虽然），表示让步
- 注意：`fast` 也有其他义项（见下方）

## `fast` 的多义 (Meanings)

| 义项 | 例句 | 说明 |
|------|------|------|
| 让步连词 | `Fast det var kallt, gick vi ut.` | 虽然；即使 |
| 副词（固定地）| `sitta fast` | 被卡住；固定 |
| 形容词（牢固的）| `ett fast grepp` | 牢固的抓握 |

## 例句 (Sentences)

- Fast söndagen var grå, var vi glada. — 虽然周日天气阴沉，我们依然很开心。
- Han lyckades, fast det var svårt. — 虽然很困难，他还是成功了。
- Fast hon var trött, stannade hon uppe för att studera. — 虽然她很累，她还是熬夜学习了。
