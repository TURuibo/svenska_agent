# kamma håret

🗣️ 类型: vardagsfras · 语域: neutralt · 常用度: 4/5
🇨🇳 梳头 · 🇬🇧 comb one's hair
📝 字面: "梳 + 头发（定式）"

## 用法说明 (Usage)

- 身体部位用**定式**代替物主代词：*kamma **håret***（不是 ✗ kamma mitt hår）、*tvätta händerna*、*borsta tänderna*。中文/英文都说"梳我的头"，瑞典语不说。
- 幼儿园秋季 **lus**（头虱）通知里，"kamma håret" 指用**luskam**（密齿虱梳）湿梳检查：*Kamma håret noga i helgen!*
- kamma 第 1 类：kammar / kammade / kammat；命令式 = kamma。
- 给别人梳：*kamma barnet* / *kamma håret på Leo*。
