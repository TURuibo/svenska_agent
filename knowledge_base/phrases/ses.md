# Ses!

🗣️ 类型: vardagsfras (avskedsfras) · 语域: vardagligt · 常用度: 5/5
🇨🇳 回见！ · 🇬🇧 See you!
📝 字面: *ses* = *se* + *-s*（相互形式「彼此看见」），省掉主语 *vi*

## 用法说明 (Usage)

- 最短的非正式道别，聊天和口语都常用；完整是 *Vi ses!*。
- 后面可加时间/地点：*Ses där!*（到时那儿见）、*Ses på söndag!*、*Ses i morgon!*、*Ses snart!*
- 同类 s-形式道别：*Hörs!*（回头联系）——两个连用 *Ses och hörs!*。
- 不能用于陌生人/正式场合，那时说 *Hej då* / *Vi ses* 也偏随意但可接受。

## 短语中的语法 (Grammar inside)

- → [[grammar-deponens-verb]] — *ses* 是 s-形式动词（相互义：彼此见）
