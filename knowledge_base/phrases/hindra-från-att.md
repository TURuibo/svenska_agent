# hindra från att

🗣️ 类型: prepositionsuttryck（动词 + 从 + att + 不定式）· 语域: 中性 · 常用度: 4/5
🇨🇳 阻止……做某事 · 🇬🇧 to prevent (someone) from (doing)
📝 字面: 阻止 + 从 + 去……

## 用法说明 (Usage)

- 结构：`hindra + 人 + från att + 动词不定式`：`Regnet hindrade oss från att gå ut.`
- ⚠️ 必须写全 `från att`，**不能省略**：*hindra honom gå* ✗ → `hindra honom från att gå` ✓。
- 主语可以是人，也可以是**事物 / 情况**：`Skadan hindrar henne från att springa.`
- 若宾语是**物 / 行为**而不是"某人做某事"，可直接带宾语，不用 `från att`：`hindra trafiken`、`hindra rullstolar`（见 [[hindra]]）。
- 更正式的说法是 `förhindra att + 从句`：`förhindra att olyckor sker`（事先防止）。

## 短语中的语法 (Grammar inside)

- → [[grammar-infinitivkonstruktion]]：介词 `från` 后接 `att + 不定式`（介词后的不定式必须有 `att`）。

## 变体 & 相关 (Variations & Related)

- 🔄 `hindra någon (från) att …` — 口语里有时省 `från`，但标准写法保留
- 🔄 `förhindra att …` — 防止（正式）
- 🔄 `hindras från att …` — 被阻止做……（s-passiv）

## 例句 / 对话 (Examples)

- 🇸🇪 Regnet hindrade oss från att gå ut. 🇨🇳 下雨使我们没能出门。
- 🇸🇪 Ingenting kan hindra honom från att försöka. 🇨🇳 什么也阻止不了他去尝试。
- 🇸🇪 Skadan hindrar henne från att springa. 🇨🇳 伤病使她无法跑步。
- 🇸🇪 Hindra barnen från att springa ut på gatan! 🇨🇳 别让孩子们跑到街上去！
