# vi puttas inte

🗣️ 类型: föräldrafras · 语域: vardagligt · 常用度: 4/5
🇨🇳 我们不推人 · 🇬🇧 we don't push (each other)
📝 字面: we push-each-other not

## 用法说明 (Usage)

- 瑞典家长/老师立规矩的固定格式：**vi + -s 动词 + inte**，语气是"我们大家都不这样做"，不是训斥。
- 同一模板：*Vi bits inte. Vi slåss inte. Vi kastar inte sand.*
- 说完通常接着安抚被推的孩子，并让推人的孩子道歉（*Säg förlåt*）。

## 短语中的语法 (Grammar inside)

- → [[grammar-s-verb-reciprok]] — puttas = 互相推（不是被动）
