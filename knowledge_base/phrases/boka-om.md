# boka om

🗣️ 类型: partikelverb · 语域: neutralt · 常用度: 3/5
🇨🇳 重新预约 · 🇬🇧 to rebook; to reschedule
📝 字面: book again

## 用法说明 (Usage)

- `boka` (预约) + 小品词 `om`（重新一次）→ "重新预约"。
- `om-` 前缀作小品词时常表示"重做一次"，常见同类词：`göra om`（重做）、`skriva om`（重写）。
- 变位：`bokar om / bokade om / bokat om`。

## 短语中的语法 (Grammar inside)

- → [[grammar-partikelverb]]（分离动词：主句中 `om` 移到句末，如 *hjälper vi dig att **boka om***）

## 变体 & 相关 (Variations & Related)

- 🔄 `avboka` — 取消预约（区别：不是重新预约，而是彻底取消）
- 🔗 [[boka-en-tid]]

## 例句 / 对话 (Examples)

- [[sent-ring-vaktmasteriet-sa-hjalper-vi]] 🇸🇪 Ring vaktmästeriet så hjälper vi dig att boka om. 🇨🇳 请致电管理处，我们会帮您重新预约。
- 🇸🇪 Kan jag boka om min tid till nästa vecka? — 🇨🇳 我能把预约改到下周吗？
- 🇸🇪 Hon bokade om mötet eftersom hon blev sjuk. — 🇨🇳 她因为生病重新预约了会议。
