# be om

🗣️ 类型: partikelverb · 语域: neutralt · 常用度: 5/5
🇨🇳 请求 · 🇬🇧 to ask for
📝 字面: 请求 关于

## 用法说明 (Usage)

- `be om något` = 请求某物（物用 om）：be om hjälp / ursäkt / mer tid。
- `be någon att + 不定式` = 请求某人做某事（如例句：bett Saudiarabien att ändra）。
- 变位: ber – bad – har bett。
