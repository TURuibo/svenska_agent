# förbinder med varandra

🗣️ 类型: fast-uttryck · 语域: neutralt · 常用度: 3/5
🇨🇳 将……与彼此相连 · 🇬🇧 connects with each other
📝 字面: connects with each other

## 用法说明 (Usage)

- 动词 `förbinda` 是不规则强变化动词：
  - Presens: **förbinder**
  - Preteritum: förbandt
  - Supinum: förbundit
- 结构：`[主语] förbinder [宾语] med varandra`
- `varandra` = each other（相互代词）

## 短语中的语法 (Grammar inside)

- → [[grammar-starka-verb]] — `förbinda` 属不规则动词
- → [[grammar-reflexivt-pronomen]] — `varandra` 作相互代词
