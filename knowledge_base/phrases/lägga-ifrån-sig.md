# lägga ifrån sig

🗣️ 类型: partikelverb · 语域: neutralt · 常用度: 3/5
🇨🇳 把（手里的东西）放下 · 🇬🇧 put down, set aside
📝 字面: lay from oneself

## 用法说明 (Usage)

- 反身粒子动词：`lägga ifrån sig ngt` — 把手上正拿着的东西放到一边。
- `sig` 随主语人称变化：`lägga ifrån mig/dig/sig...`
