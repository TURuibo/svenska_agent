# arbeta kvar

🗣️ 类型: partikelverb · 语域: neutralt · 常用度: 3/5
🇨🇳 继续留在（原单位）工作 · 🇬🇧 to still work (at the same place)

## 用法说明 (Usage)

- `-kvar` = 仍然留在原处/原状态：`bo kvar`、`stanna kvar`、`arbeta kvar`。 [[arbeta]]
- 原文：`Johan arbetade kvar på samma vårdcentral.`

## 例句 / 对话 (Examples)

- 🇸🇪 Hon arbetar kvar på samma skola. 🇨🇳 她还在同一所学校工作。
- 🇸🇪 Efter tio år arbetade han fortfarande kvar. 🇨🇳 十年后他依然在原单位工作。
