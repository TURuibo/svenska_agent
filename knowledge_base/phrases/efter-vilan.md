# efter vilan

🗣️ 类型: tidsuttryck · 语域: neutralt · 常用度: 4/5
🇨🇳 午睡后 · 🇬🇧 after the nap
📝 字面: efter（之后）+ vilan（那次休息，vila 的定形）

## 用法说明 (Usage)

- **vilan** = 园里的午睡/午休环节（sovvila 的口语简称）。老师说 "efter vilan" 指约 13:30–14:00 之后。
- 同 [[efter-lunchen]]：efter + **定形**。
- 相关介词：**på vilan**（午睡的时候）、**vid vilan**（在午睡环节）、vakna från vilan（午睡醒来）。

## 短语中的语法 (Grammar inside)

- → [[grammar-bestamd-form]]
- → [[grammar-v2-ordfoljd]]：*Efter vilan **skriver** vi i appen.*
