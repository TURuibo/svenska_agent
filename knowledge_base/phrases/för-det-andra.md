# för det andra

🗣️ 类型: diskursmarkor · 语域: neutralt · 常用度: 4/5
🇨🇳 其次；第二点 · 🇬🇧 secondly; in the second place
📝 字面: for the second (item)

## 用法说明 (Usage)

- 用于列举论点的第二条，与 `för det första`（首先）配合使用。
- 句首使用，引入下一个论点或建议。
- 完整论述结构：`för det första` → `för det andra` → `till sist`/`slutligen`。
