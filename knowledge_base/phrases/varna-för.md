# varna för

🗣️ 类型: partikelverb · 语域: neutralt · 常用度: 4/5
🇨🇳 警告，提醒提防某事 · 🇬🇧 to warn of/about
📝 字面: 警告关于

## 用法说明 (Usage)

- varna för + substantiv/att-sats
- 表示警告他人注意某种危险或风险
- 主语可以是人或机构（experterna, myndigheter）

## 短语中的语法 (Grammar inside)

- → [[grammar-partikelverb]]
- → [[grammar-for-att-infinitiv]] — *varna för att det kan bli…*

## 变体 & 相关 (Variations & Related)

- 🔄 varna för ngt（警告某事物）
- 🔄 varna för att + infinitiv（警告可能发生某事）
- 🔄 varning för（名词形式：关于…的警告）

## 例句 / 对话 (Examples)

- [[sent-experterna-varnar-för-att-det]] 🇸🇪 Experterna varnar för att det kan bli åska och mycket regn. 🇨🇳 专家警告可能出现雷暴和大雨。
- 🇸🇪 Myndigheten varnar för stark sol och hög värme. — 🇨🇳 当局警告强烈日晒和高温。
