# duka fram

🗣️ 类型: partikelverb · 语域: neutralt · 常用度: 3/5
🇨🇳 摆出（食物、餐具） · 🇬🇧 to set out (food, dishes)
📝 字面: set (table) forward

## 用法说明 (Usage)

- 把食物、杯盘摆到桌上准备招待：`duka fram fika`。
- 小品词 `fram` 重读；可分开：`Vi dukar fram fikan.`
