# fundera på (något / om …)

🗣️ 类型: prepositionsuttryck（动词 + på）· 语域: neutralt · 常用度: 5/5
🇨🇳 考虑、琢磨、思考 · 🇬🇧 to think about, consider
📝 字面: 琢磨 在 …

## 用法说明 (Usage)

- 动词 `fundera`（`funderar – funderade – funderat`）+ **på**，表示"在脑子里想、琢磨、掂量"：
  - `fundera på + 名词`：`fundera på saken`（琢磨这件事）
  - `fundera på om + 从句`：**是否**（间接疑问句）：`fundera på om det var värt det`（想想值不值得）
  - `fundera på hur/vad/varför …`：`fundera på hur man gör`（琢磨怎么做）
  - `fundera på att + 不定式`：**在考虑要不要做**：`Jag funderar på att byta jobb.`
- 文章里：`funderade på om det var värt det`——`om` 引导间接疑问句（"是否"），从句语序：`om + 主语 det + 动词 var + …`，不倒装。
- 对比近义词：

| 表达 | 意思 | 例子 |
|------|------|------|
| `fundera på` | 琢磨、考虑（可能还没决定） | `Jag funderar på det.` |
| `tänka på` | 想到、惦记、注意 | `Tänk på mig!`（想着我） |
| `tänka över` | 仔细考虑（决定前） | `Jag ska tänka över det.` |
| `överväga` | 慎重考虑（较书面） | `Vi överväger ett byte.` |

- 常用口语：`Jag ska fundera på det.`（我考虑考虑）；`Fundera på saken!`（好好想想）。

## 例句 / 对话 (Examples)

- 🇸🇪 Nils började tvivla på sin satsning och funderade på om det var värt det. 🇨🇳 Nils 开始怀疑自己的投入，思考这一切是否值得。
- 🇸🇪 Jag funderar på att byta jobb. 🇨🇳 我在考虑换工作。
- 🇸🇪 Hon funderade på om hon skulle tacka ja. 🇨🇳 她在琢磨要不要答应。
- 🇸🇪 Jag ska fundera på det och höra av mig i morgon. 🇨🇳 我考虑一下，明天再联系你。
