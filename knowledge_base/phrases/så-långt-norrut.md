# så långt norrut

🗣️ 类型: prepositionsuttryck · 语域: neutralt · 常用度: 2/5
🇨🇳 这么靠北 · 🇬🇧 so far north

## 用法说明 (Usage)

- `norrut` = 向北；`så långt` + 方向副词表示距离。类似 söderut, västerut, österut。
