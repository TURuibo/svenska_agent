# global uppvärmning

🗣️ 类型: fast-uttryck（固定名词词组）· 语域: neutralt · 常用度: 4/5
🇨🇳 全球变暖 · 🇬🇧 global warming
📝 字面: 全球的升温

## 用法说明 (Usage)

- `uppvärmning` 是 en-词，所以形容词用 en-形 `global`；带定冠词时：`den globala uppvärmningen`。
- 常搭配：`bidra till den globala uppvärmningen`（助长全球变暖）、`bromsa/stoppa den globala uppvärmningen`。
- 近义：`klimatförändringarna`（气候变化，范围更广）。

## 短语中的语法 (Grammar inside)

- → [[grammar-adjektiv-kongruens]]：global → globala（定指）。

## 例句 / 对话 (Examples)

- 🇸🇪 Fråga efter investeringar som inte bidrar till den globala uppvärmningen. 🇨🇳 询问不会助长全球变暖的投资。
- 🇸🇪 Den globala uppvärmningen smälter isen vid polerna. 🇨🇳 全球变暖正在融化两极的冰。
- 🇸🇪 Vi måste stoppa den globala uppvärmningen. 🇨🇳 我们必须遏制全球变暖。
