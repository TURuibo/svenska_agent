# söka plats

🗣️ 类型: vardagsfras · 语域: neutralt · 常用度: 4/5
🇨🇳 申请（幼儿园）名额 · 🇬🇧 to apply for a place
📝 字面: 寻找位子

## 用法说明 (Usage)

- *söka* 在这里 = 申请（不是「找」）：*söka plats / söka jobb / söka lägenhet*。*plats* 无冠词。
- 在哪个幼儿园：*söka plats på förskolan X*；通过什么渠道：*via kommunens e-tjänst*。
- 正式版是 *ansöka om plats*。
