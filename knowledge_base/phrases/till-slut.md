# till slut

🗣️ 类型: 时间副词短语 · 语域: neutralt · 常用度: 5/5
🇨🇳 最终；到最后；最后终于 · 🇬🇧 in the end / finally
📝 字面: till（到）+ slut（结尾）= 到了最后

## 用法说明 (Usage)

- `till slut` 用于叙事结尾，总结整件事的最终结果。
- 放句首时触发 V2 倒装：*Till slut **var** allt bra igen.*
- 与 `äntligen` 的区别：`till slut` 更强调经历了过程后到达终点；`äntligen` 更有情感色彩（如释重负）。
