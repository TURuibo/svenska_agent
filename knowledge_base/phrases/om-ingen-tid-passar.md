# om ingen tid passar

🗣️ 类型: uttryck · 语域: neutralt · 常用度: 3/5
🇨🇳 如果没有合适的时间 · 🇬🇧 if none of the times work
📝 字面: 如果没有时间合适

## 用法说明 (Usage)

- `om` 引导条件从句（如果……），`ingen tid` = "没有一个时间"（`ingen` 是否定不定代词，修饰单数名词）。
- 该从句常前置于主句，逗号后紧跟祈使句给出下一步行动，如：`Om ingen tid passar, kontakta mig.`
