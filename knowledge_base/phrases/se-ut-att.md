# se ut att

🗣️ 类型: konstruktion · 语域: neutralt · 常用度: 4/5
🇨🇳 看起来（要/像）…… · 🇬🇧 to appear to, to look like
📝 字面: 看出去要

## 用法说明 (Usage)

- se ut att + 动词不定式：Det ser ut att regna（看起来要下雨）。也可 se ut som + 名词。相关：[[se-ut]]。
