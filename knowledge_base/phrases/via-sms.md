# via sms

🗣️ 类型: prepositionsuttryck · 语域: neutralt · 常用度: 4/5
🇨🇳 通过短信 · 🇬🇧 by text message
📝 字面: 经由 sms

## 用法说明 (Usage)

- `via` + 渠道 = "通过 / 经由"：`via sms`, `via mejl`, `via appen`, `via telefon`。
- sms 是 ett-词，`via sms` 里用不定式、无冠词（泛指渠道）。
- 回复方式常和 OSA 连用：`OSA via sms till …`。

## 短语中的语法 (Grammar inside)

- 介词 `via` 后接名词原形，不加冠词表示"用……这种方式"。

## 变体 & 相关 (Variations & Related)

- 🔄 `per sms` — 同义，稍正式
- 🔄 `på sms` — 口语（`Jag skickar det på sms.`）
- 🔗 [[sms]] · [[osa]]

## 例句 / 对话 (Examples)

- [[sent-osa-senast-onsdag-7-oktober-via]] 🇸🇪 OSA senast onsdag 7 oktober via sms till Jonas. 🇨🇳 请最晚于 10 月 7 日星期三前发短信回复 Jonas。
- 🇸🇪 Förskolan skickar påminnelser via sms. 🇨🇳 幼儿园通过短信发提醒。
