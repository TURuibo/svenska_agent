# vara dömd till döden

🗣️ 类型: fast-uttryck · 语域: formellt · 常用度: 2/5
🇨🇳 被判死刑 · 🇬🇧 to be sentenced to death
📝 字面: 被判到死亡

## 用法说明 (Usage)

- `vara dömd` = 状态（已被判）；`bli dömd` = 动作（被判的过程），见 [[bli-dömd-till]]。
- dömd 是过去分词，作表语时随主语变化：dömd / dömt / dömda。
