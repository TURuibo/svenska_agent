# skriv ditt barns namn på listan

🗣️ 类型: uttryck · 语域: neutralt · 常用度: 2/5
🇨🇳 把孩子的名字写在名单上 · 🇬🇧 write your child's name on the list
📝 字面: 把你孩子的名字写在名单上

## 用法说明 (Usage)

- 祈使句结构（imperativ）：`skriv` 是 `skriva` 的祈使式，用于书面通知里的指令句。
- `ditt barns namn` = 属格结构，`barns` 是 `barn` 的所有格形式（-s 属格），字面"孩子的名字"。
- `på listan` = 定冠词形式，指代文中已提到/在场的那张具体名单。

## 短语中的语法 (Grammar inside)

- → [[grammar-imperativ]] — 祈使句
- → [[grammar-possessiva-pronomen]] — 物主代词 + 属格（ditt barns）
