# vi ses

🗣️ 类型: avsked · 语域: vardagligt · 常用度: 5/5
🇨🇳 到时候见；再见 · 🇬🇧 see you (then); we'll see each other
📝 字面: we see (each other)

## 用法说明 (Usage)

- Casual farewell used when you have arranged to meet again.
- Often followed by a time: *Vi ses klockan fem / på måndag / imorgon*.
- *Vi ses snart* = see you soon (see also [[vi-ses-snart]]).
- The -s form (*ses*) is reciprocal/reflexive: "we see each other".
