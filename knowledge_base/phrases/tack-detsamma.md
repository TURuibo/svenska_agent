# tack, detsamma

🗣️ 类型: 回应祝愿 / 礼貌表达 · 语域: vardagligt · 常用度: 4/5
🇨🇳 谢谢，你也一样 · 🇬🇧 thanks, you too; likewise
📝 字面: thanks, the same

## 用法说明 (Usage)

- 当对方对你说 `ha en bra dag`、`ha det bra`、`god helg` 等祝愿语时，用 `tack, detsamma` 回应。
- 简洁有礼，相当于英语 "thanks, same to you" 或 "likewise"。
- 也可说 `tack, dig också`（谢谢，你也是），但 `detsamma` 更地道。

- 🔄 `tack, dig också` — 谢谢，你也是（更直白）
