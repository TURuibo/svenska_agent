# kom ihåg att

🗣️ 类型: fast-uttryck · 语域: neutralt · 常用度: 5/5
🇨🇳 记住… · 🇬🇧 remember that
📝 字面: 来 在记忆里 …

## 用法说明 (Usage)

- **komma ihåg** = 记得（partikelverb，*ihåg* 重读）。祈使式 **Kom ihåg!** 是通知、周报结尾的经典提醒句。
- 三种接法：*kom ihåg att + 从句*（记住……这件事）/ *kom ihåg att + 不定式*（记得去做…）/ *kom ihåg + 名词*（别忘了…）。
- 反面说法：[[glöm-inte]]（别忘了）几乎等价，语气更口语。
- att 从句里遵守 bisats 语序（*inte* 放动词前）：*Kom ihåg att ni inte får parkera där.*
- 变形：kommer ihåg / kom ihåg / kommit ihåg。
