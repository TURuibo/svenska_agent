# mycket att se

🗣️ 类型: fast-uttryck · 语域: neutralt · 常用度: 4/5
🇨🇳 很多可看的 · 🇬🇧 a lot to see
📝 字面: much to see

## 用法说明 (Usage)

- 结构：`mycket + att + infinitiv`
- `att se` 是不定式结构，`se` = 看
- 类似搭配：`mycket att göra`（很多事做），`mycket att lära`（很多要学的）
- 常用于描述景点或活动丰富的地方

## 短语中的语法 (Grammar inside)

- → [[grammar-infinitivkonstruktion]] — `att + infinitiv` 结构

## 变体 & 相关 (Variations & Related)

- 🔄 `mycket att göra` — 很多事可做
- 🔄 `mycket att uppleva` — 很多可体验的
- 🔄 `mycket att lära sig` — 很多可学的
- 🔄 `det finns mycket att se` — 有很多可看的（完整句）

## 例句 / 对话 (Examples)

- 🇸🇪 I Stockholm finns det mycket att se och göra. 🇨🇳 在斯德哥尔摩有很多可看可做的事情。
- 🇸🇪 Det finns mycket att se i Gamla stan. 🇨🇳 在老城区有很多可以参观的地方。
