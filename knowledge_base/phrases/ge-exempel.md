# ge exempel

🗣️ 类型: fast-uttryck · 语域: neutralt · 常用度: 4/5
🇨🇳 举例 · 🇬🇧 to give examples
📝 字面: give examples

## 用法说明 (Usage)

- `ge ett exempel / ge några exempel` — 举一个/几个例子。
- 教材问句：`Ger skribenten något exempel i sina argument?`、`Kan du ge några exempel?`
- 回答时常用 `till exempel` 引出例子。

## 短语中的语法 (Grammar inside)

- exempel 是 ett-词，复数同形：ett exempel, flera exempel。

- 🔄 `ta ett exempel` — 举个例子
