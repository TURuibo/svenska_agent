# med stora ögon

🗣️ 类型: idiom · 语域: neutralt · 常用度: 2/5
🇨🇳 睁大眼睛（惊讶或入迷地） · 🇬🇧 with wide eyes
📝 字面: 带着大眼睛

## 用法说明 (Usage)

- 常与 lyssna / titta 连用：`lyssna med stora ögon`。 [[öga]]

## 例句 / 对话 (Examples)

- 🇸🇪 Barnen lyssnade med stora ögon. 🇨🇳 孩子们睁大眼睛听着。
- 🇸🇪 Hon tittade med stora ögon på tåget. 🇨🇳 她睁大眼睛看着那列火车。
