# hemma hos oss

🗣️ 类型: prepositionsuttryck · 语域: vardagligt · 常用度: 5/5
🇨🇳 在我们家 · 🇬🇧 at our place
📝 字面: hemma（在家）+ hos（在……处）+ oss（我们，宾格）

## 用法说明 (Usage)

- "在某人家"用 `hemma hos + 人（宾格）`：`hemma hos oss / mig / dig / Ella / mormor`。
- `hos` 本身就是"在……家/处"，`hemma` 加强"家里"这个意思，口语里几乎总连用。
- 方向"去某人家"也用 hos：`Vi går hem till Ella.` / `Kom hem till oss!`

## 短语中的语法 (Grammar inside)

- 介词 `hos` 后接**宾格**代词：oss / mig / dig / honom / henne / dem。
