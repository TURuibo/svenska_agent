# istället för att

**类型:** konjunktion / infinitivkonstruktion (连词/不定式结构)
**中文:** 而不是（做……）；代替做……
**English:** instead of (doing something)
**CEFR:** B1

## 语法结构 (Grammar)

```
[istället för att] + [infinitiv]
     连接词            动词原形
```

- **istället för att** 后面接**动词原形（infinitiv）**，表示"选择A而不是做B"。
- ⚠️ 注意：**att 不可省略**——这与英语 "instead of doing" 中的 -ing 形式对应，但瑞典语必须保留 att。
- 常见变体：*i stället för att*（两词版，同义，正式）

## 例句 (Example Sentences)

1. *Kommunen hoppas att fler ska cykla istället för att ta bilen.* — 市政府希望更多人骑车而不是开车。
2. *Han gick hem istället för att stanna kvar.* — 他回家了而不是留下来。
3. *Varför läser du istället för att sova?* — 你为什么读书而不是睡觉？
4. *Använd bussen istället för att köra bil.* — 乘公交车而不是开车。

## 对比 (Contrast)

| 表达 | 含义 |
|------|------|
| istället för att + infinitiv | 而不是做…… |
| istället för + substantiv | 而不是……（名词） |
| i stället | 取而代之（副词单独用） |
