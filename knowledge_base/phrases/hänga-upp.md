# hänga upp

🗣️ 类型: partikelverb（partikelverb） · 语域: neutralt · 常用度: 4/5
🇨🇳 挂起来 · 🇬🇧 hang up
📝 字面: 挂 上

## 用法说明 (Usage)

- partikelverb：重音在 *upp*；宾语放在小品词后：*hänga upp overallen*，代词也一样：*hänga upp den*。
- 门厅（hallen）里每个孩子有自己的 [[krok]]：*hänga upp jackan på kroken*。
- 引申义：*hänga upp (luren)* = 挂电话（现代常说 *lägga på*）。
