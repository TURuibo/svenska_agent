# lära sig svenska — verbfras (reflexiv)

Zh: 学习瑞典语 · English: to learn Swedish
发音提示：LÄ-ra sig SVEN-ska

## 结构分析 (Structure)

```
lära + sig + (ett språk / att + infinitiv)
```

- `lära sig` — 学习（reflexivt partikelverb）
- 区分：`lära` (aktiv) = 教；`lära sig` = 学（自己学）

## 变形 (Conjugation)

| form | Swedish |
|------|---------|
| infinitiv | lära sig svenska |
| presens | lär sig svenska |
| preteritum | lärde sig svenska |
| supinum | lärt sig svenska |

## 扩展 (Extension)

- `lära sig svenska` — 学瑞典语
- `lära sig ett nytt ord` — 学一个新词
- `lära sig att köra bil` — 学开车
- `lära sig av misstagen` — 从错误中学习

## 例句 (Sentences)

- Hon bestämde sig för att lära sig svenska när hon kom till Sverige. — 她来到瑞典后决定学习瑞典语。
- Det tar tid att lära sig svenska, men det går! — 学瑞典语需要时间，但可以做到！
- Jag lär mig svenska för att jag vill förstå mina grannar. — 我学瑞典语是因为我想听懂邻居说话。
