# det var länge sedan vi hördes

🗣️ 类型: situationsfras · 语域: vardagligt · 常用度: 4/5
🇨🇳 好久没联系了 · 🇬🇧 it's been a while since we talked / heard from each other
📝 字面: 自从我们上次互相联系已经很久了

## 用法说明 (Usage)

- 用于给久未联系（写信/打电话/发消息，而非当面见面）的朋友开场问候，常跟在 `Hur är läget?` 之后。
- 与 [[det-var-länge-sedan-vi-sågs]] 意思相近，但关键区别在动词：`hördes`（höras，互相"听到"彼此消息，泛指任何联系方式）vs `sågs`（ses，当面见面）。
- 常出现在书信、短信开头。

## 短语中的语法 (Grammar inside)

- `hördes` = `höras`（互相联系）的过去时 s-form → [[grammar-preteritum-s-form]]
- `det var länge sedan` = 时间状语结构（上次…已经很久了）

## 变体 & 相关 (Variations & Related)

- 🔄 `Det är länge sedan vi hördes` — 现在时形式，意思相同
- 🔗 [[det-var-länge-sedan]]
- 🔗 [[det-var-länge-sedan-vi-sågs]]
