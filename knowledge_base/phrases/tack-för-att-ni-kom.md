# Tack för att ni kom

🗣️ 类型: situationsfras · 语域: neutralt · 常用度: 5/5
🇨🇳 谢谢你们来（主人答语） · 🇬🇧 thanks for coming
📝 字面: 谢谢-为了-你们-来了

## 用法说明 (Usage)

- 主人送客时的固定答语，对应客人的 [[tack-för-att-vi-fick-komma]]。
- **kom** = komma 的 preteritum；对一个人说 *Tack för att du kom*。
- 也用于活动结束（家长会、聚会）主持人的收尾。

## 短语中的语法 (Grammar inside)

- → [[grammar-tack-för-att-perfekt]] tack för att + 从句
- → [[grammar-att-bisats]] 从句里主语 ni 紧跟 att

## 变体 & 相关 (Variations & Related)

- 🔄 Tack för att du kom · Tack för besöket（谢谢来访）· Välkomna tillbaka!（欢迎再来）
- 🔗 [[tack-för-att-vi-fick-komma]] · [[tack-för-besöket]] · [[hej-då]]

## 例句 / 对话 (Examples)

- [[sent-tack-för-att-ni-kom]] 🇸🇪 Tack för att ni kom! 🇨🇳 谢谢你们来！
- 🇸🇪 Tack för att du kom på Noahs kalas. 🇨🇳 谢谢你来 Noah 的生日会。
- 🇸🇪 Tack för att ni kom på föräldramötet. 🇨🇳 谢谢你们来参加家长会。
