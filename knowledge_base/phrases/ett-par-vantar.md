# ett par vantar

🗣️ 类型: vardagsfras · 语域: neutralt · 常用度: 4/5
🇨🇳 一双连指手套 · 🇬🇧 a pair of mittens
📝 字面: 一对手套

## 用法说明 (Usage)

- 成对的衣物用 **par** 计数：*ett par vantar / strumpor / stövlar / byxor / galonbyxor*。
- **par** 是 ett-词、复数不变：*ett par, två par*。数量后名词用**复数不定式**：*två par vantar*，不说 ~~två vantar~~（那是"两只手套"）。
- 可以省略名词只说 *ett par* / *två par*（上下文明确时）：*det är bra med två par*。
- 形容词修饰时按 ett 形：*ett större par*（一双大一号的）。
