# först … sedan … till sist

🗣️ 类型: diskursmarkör · 语域: neutralt · 常用度: 5/5
🇨🇳 先……然后……最后 · 🇬🇧 first … then … finally
📝 字面: först（首先）→ sedan（然后）→ till sist（最后）

## 用法说明 (Usage)

- 讲**流程/顺序**（作息、菜谱、路线、故事）时的三段式连接词，A1 写作和口语考试的"万能骨架"。
- 三个词都是**时间状语**，放句首时触发 V2：动词紧跟其后，主语退到第三位（*Först sjunger vi …*）。
- 中间可以加 **efter det / därefter**（之后），结尾也可用 **sist / slutligen**（更书面）。

## 短语中的语法 (Grammar inside)

- → [[grammar-v2-ordfoljd]]（句首状语 → 动词第二位）
- → [[grammar-tidsadverbial]]

## 变体 & 相关 (Variations & Related)

- 🔄 först … därefter … slutligen（更正式）
- 🔄 först … sen …（sen 是 sedan 的口语形式）
- 🔗 [[till-sist]] · [[efter-det]]

## 例句 / 对话 (Examples)

- [[sent-först-sjunger-vi-namnsången]] 🇸🇪 Först sjunger vi namnsången. 🇨🇳 先唱点名歌。
- [[sent-sedan-tittar-vi-på-bilder-och]] 🇸🇪 Sedan tittar vi på bilder och sjunger fler sånger. 🇨🇳 然后看图片，再唱几首别的歌。
- [[sent-till-sist-går-vi-ut-igen]] 🇸🇪 Till sist går vi ut igen. 🇨🇳 最后我们再出去一次。
- 🇸🇪 Först tvättar vi händerna, sedan äter vi, och till sist borstar vi tänderna. 🇨🇳 先洗手，然后吃饭，最后刷牙。
