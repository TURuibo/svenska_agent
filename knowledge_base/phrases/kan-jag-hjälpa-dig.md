# kan jag hjälpa dig

🗣️ 类型: servicefras · 语域: neutralt · 常用度: 5/5
🇨🇳 我能帮你吗？ · 🇬🇧 Can I help you?

## 用法说明 (Usage)

- 商店、服务台、超市等场合，店员主动问顾客是否需要帮助的标准用语。
- 变体：*Kan jag hjälpa er?*（尊称/复数）；*Hur kan jag hjälpa dig?*（更热情）

## 短语中的语法 (Grammar inside)

- → [[grammar-modala-hjalpverb]] — *kan* 是情态动词

## 变体 & 相关 (Variations & Related)

- 🔄 Hur kan jag hjälpa dig? — 我怎么能帮到你？
