# visa legitimation

🗣️ 类型: verbfras · 语域: neutralt · 常用度: 4/5
🇨🇳 出示身份证件 · 🇬🇧 to show ID
📝 字面: 展示证件

## 用法说明 (Usage)

- 固定搭配，legitimation 不加冠词。口语 *visa leg*。
- 园所/邮局/药店/银行都可能要求：*Kan du visa legitimation?* / *Får jag se din legitimation?*
- 新接送人第一次接孩子必须 visa legitimation，之后老师认得就不用了。
