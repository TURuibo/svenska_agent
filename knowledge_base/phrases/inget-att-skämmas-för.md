# inget att skämmas för

🗣️ 类型: fast-uttryck · 语域: vardagligt · 常用度: 3/5
🇨🇳 没什么好难为情的 · 🇬🇧 nothing to be ashamed of
📝 字面: "没有东西 + 去为之感到羞耻"

## 用法说明 (Usage)

- 结构：**Det är inget att + 不定式 + 介词**，介词留在句尾：*inget att skämmas **för*** / *inget att oroa sig **för*** / *inget att bråka **om***。
- **skämmas** 是 deponens 动词：永远带 -s（skäms / skämdes / skämts），意思却是主动的"感到羞耻"。搭配 *skämmas **för** något*。
- **inget** = ingenting 的口语短形（也 = ett-词的"没有"）。
- 安慰语气：头虱、尿床、孩子咬人……老师会说这句让家长放松。

## 短语中的语法 (Grammar inside)

- → [[grammar-deponensverb]] — skämmas（-s 形主动义）
- → [[grammar-preposition-i-slutet]] — 介词 för 留在句尾
