# springa fritt

🗣️ 类型: fast-uttryck · 语域: neutralt · 常用度: 3/5
🇨🇳 随便跑；自由活动 · 🇬🇧 run around freely
📝 字面: 跑-自由地

## 用法说明 (Usage)

- 说孩子（或狗）可以在家里/院子里自由活动，不用一直看着：*Ella kan springa fritt.*
- **fritt** 是形容词 fri 的 -t 形当副词用（"自由地"）。
- 常和 barnsäkra 一起出现：做了安全防护 → 孩子可以随便跑。

## 短语中的语法 (Grammar inside)

- → [[grammar-adjektiv-bojning]] 形容词 -t 形作方式副词
- → [[grammar-modala-hjalpverb]] kan + springa（可以跑）

## 变体 & 相关 (Variations & Related)

- 🔄 leka fritt（自由玩）· gå fritt（随意走动）· släppa barnen fria（放孩子自己玩）
- 🔗 [[fri]] · [[barnsäkra]]

## 例句 / 对话 (Examples)

- [[sent-vi-har-barnsäkrat-så-ella-kan]] 🇸🇪 Vi har barnsäkrat, så Ella kan springa fritt. 🇨🇳 我们做了儿童安全防护，Ella 可以随便跑。
- 🇸🇪 På gården får barnen springa fritt. 🇨🇳 在院子里孩子们可以随便跑。
- 🇸🇪 Hunden får inte springa fritt i parken. 🇨🇳 狗在公园里不能放开跑。
