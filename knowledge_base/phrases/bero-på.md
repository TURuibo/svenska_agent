# bero på

🗣️ 类型: partikelverb · 语域: neutralt · 常用度: 5/5
🇨🇳 取决于 · 🇬🇧 depend on
📝 字面: 依赖 于

## 用法说明 (Usage)

- **X beror på Y** = X 取决于 Y / X 是由 Y 引起的。*Avgiften beror på inkomsten.* / *Förseningen berodde på snön.*（延误是因为雪。）
- 万能回答 **Det beror på.**（看情况。）—— 相当于英语 *It depends.*
- 带从句：*Det beror på om …*（取决于是否…）/ *Det beror på hur mycket …*
- 变形：beror på / berodde på / berott på（v.4 不规则：bero – beror – berodde – berott）。
- 介词 **på** 固定，不能换成 av；否定时 *inte* 放在 *beror* 后：*beror inte på antalet timmar*。

## 短语中的语法 (Grammar inside)

- 介词固定搭配动词 → [[grammar-partikelverb]]（på 不重读，属"介词动词"而非严格 partikelverb）

- [[sent-avgiften-följer-maxtaxan-och-beror-på]] 🇸🇪 Avgiften följer maxtaxan och beror på hushållets inkomst, inte på antalet timmar. 🇨🇳 费用按照最高收费制度计算，取决于家庭的收入，而不是小时数。

- 🇸🇪 Hur mycket ni betalar beror på hur mycket ni tjänar. 🇨🇳 你们交多少钱取决于你们挣多少。
