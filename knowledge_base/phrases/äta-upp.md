# äta upp

🗣️ 类型: partikelverb · 语域: vardagligt · 常用度: 4/5
🇨🇳 吃光；吃完 · 🇬🇧 to eat up, devour completely
📝 字面: äta（吃）+ upp（完全地）

## 用法说明 (Usage)

- 结构：äter upp / åt upp / ätit upp + NP
- 粒子 "upp" 表示动作的完成性（completely），强调吃光、吃尽。
- 可用于人吃饭（把饭吃完），也可用于动物或害虫把食物吃光。

- 🇸🇪 Ät upp din mat innan du får glass! — 🇨🇳 把你的饭吃完才能吃冰淇淋！
- 🇸🇪 Barnen åt upp allt på tallrikarna. — 🇨🇳 孩子们把盘子里的东西都吃光了。
