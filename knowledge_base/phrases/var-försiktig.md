# var försiktig

🗣️ 类型: uppmaningsuttryck · 语域: neutralt · 常用度: 5/5
🇨🇳 小心！要谨慎！ · 🇬🇧 be careful!
📝 字面: be careful（字面意思即为中文义）

## 用法说明 (Usage)

- var 是 vara（是）的命令形式（imperativ）
- 用于警告、提醒或关心某人注意安全
- 常与地点/情境补充：var försiktig på vägarna（在路上小心）

## 短语中的语法 (Grammar inside)

- → [[grammar-imperativ]]（var = vara 的命令形）

## 变体 & 相关 (Variations & Related)

- 🔄 var försiktig med + 名词（小心某事物）
- 🔄 akta dig（当心！更口语）
- 🔗 [[försiktig]]

## 例句 / 对话 (Examples)

- [[sent-var-forsiktig-pa-vagarna]] 🇸🇪 Var försiktig på vägarna! 🇨🇳 在路上要小心！
- 🇸🇪 Var försiktig när du går utomhus på natten. 🇨🇳 晚上出门时要小心。
