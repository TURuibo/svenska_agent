# vid vilan

🗣️ 类型: 介词短语 · 语域: neutralt · 常用度: 4/5
🇨🇳 午休时 · 🇬🇧 at nap time
📝 字面: 在休息时

## 用法说明 (Usage)

- *vid + 定式名词* 表示「在…这个时间点/场合」：*vid vilan*, *vid lunchen*, *vid hämtningen*。
- 幼儿园里 *vilan* = 午睡/午休时间（定式，指每天固定的那段）。也常说 *på vilan*。
- *vid* 后接年龄：*vid ett och ett halvt år*（一岁半时）。
