# så snart som möjligt

🗣️ 类型: fast-uttryck · 语域: neutralt · 常用度: 5/5
🇨🇳 尽快 · 🇬🇧 as soon as possible
📝 字面: 像……一样快，尽可能

## 用法说明 (Usage)

- `så ... som möjligt` 是固定的比较级结构，可套用其他形容词/副词：`så billigt som möjligt`（尽可能便宜）、`så fort som möjligt`（尽可能快）。
- 口语和书面语都可用，比更正式的 [[snarast-möjligt]] 语域略随意一些。
- 常见于报修信、请求信中表达"希望尽快处理"。

## 短语中的语法 (Grammar inside)

- → 比较级固定结构 `så + adj/adv + som möjligt`

## 例句 / 对话 (Examples)

- [[sent-jag-ber-er-skicka-en-rörmokare]] 🇸🇪 Jag ber er skicka en rörmokare så snart som möjligt, helst inom två dagar. 🇨🇳 请尽快派水管工来处理，最好在两天以内。
