# tack för ett bra samtal

🗣️ 类型: 礼貌表达 · 语域: neutralt · 常用度: 3/5
🇨🇳 谢谢这次愉快的谈话 · 🇬🇧 thanks for a good talk
📝 字面: 谢谢一个好的谈话

## 用法说明 (Usage)

- 结束正式一点的谈话（utvecklingssamtal、面试、电话）时用；对方回 *tack själv / tack själva*。
- 模式 *tack för + 名词*：tack för idag · tack för hjälpen · tack för maten · tack för senast。
- *samtal* 是 ett-词 → *ett bra samtal*；*ett trevligt samtal* 也常见。
