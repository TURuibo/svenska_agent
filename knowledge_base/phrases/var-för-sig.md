# var för sig

🗣️ 类型: fast-uttryck · 语域: vardagligt · 常用度: 4/5
🇨🇳 各付各的；分开；各自 · 🇬🇧 separately; each on their own; individually
📝 字面: 每个人为自己

## 用法说明 (Usage)

- 付账时常见：`Betalar ni ihop eller var för sig?`（你们一起付还是各付各的？）
- 也用于其他语境，表示"分别"、"各自"：`Vi gör det var för sig`（我们各自做）。
- 对立词：`ihop`（一起），`tillsammans`（一起）。

## 短语中的语法 (Grammar inside)

- `var` = 每个（everyone/each）
- `för sig` = 为自己（for oneself）
- 固定表达，作为副词短语使用
