# vara någons pappa/mamma

🗣️ 类型: situationsfras · 语域: vardagligt · 常用度: 5/5
🇨🇳 是某人的爸爸/妈妈（家长间通过孩子自我介绍） · 🇬🇧 be someone's dad/mum
📝 字面: —

## 用法说明 (Usage)

- 瑞典家长圈的标准自我介绍：**Jag är Ellas pappa / Olles mamma**——先报孩子的名字，很多家长聊一年都不知道对方本名。
- 属格直接在人名后加 **-s**，不加撇号：Ella → Ellas，Olle → Olles；名字本身以 s 结尾（Jonas）则写 *Jonas mamma* 或 *Jonas' mamma*。
- 也可以只说同位语：*Jag heter Emma, Olles mamma.*（我叫 Emma，Olle 的妈妈。）
