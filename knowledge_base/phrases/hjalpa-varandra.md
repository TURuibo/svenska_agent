# hjälpa varandra

**类型:** uttryck / reciprokt verb (相互动词短语)
**中文:** 互相帮助；相互帮助
**English:** to help each other; to help one another
**CEFR:** A2

## 用法 (Usage)

- **hjälpa varandra** = 两人或多人互相帮助。
- **varandra** = 互相，always used with plural subjects.
- 过去时：*hjälpte varandra*

## 例句 (Example Sentences)

1. *Vi hjälpte varandra.* — 我们互相帮助。
2. *Vi måste hjälpa varandra.* — 我们必须互相帮助。
3. *De hjälper varandra med läxorna.* — 他们互相帮助做作业。
4. *På SFI hjälpte vi varandra att lära oss svenska.* — 在 SFI 上，我们互相帮助学瑞典语。

## 相关词 (Related Words)

- hjälpa (v.2b) — 帮助（动词）
- varandra — 互相（代词，仅复数）
