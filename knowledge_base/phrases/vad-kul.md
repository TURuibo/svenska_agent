# vad kul

🗣️ 类型: fast-uttryck · 语域: vardagligt · 常用度: 5/5
🇨🇳 真好！ · 🇬🇧 how nice!
📝 字面: 多么有趣

## 用法说明 (Usage)

- **Vad + 形容词!** = "多么…！"的感叹句：*Vad kul! Vad gott! Vad fint!*
- 后接 **att + 动词原形** 说明为什么高兴：*Vad kul att äntligen få prata lite!*
- *kul* 不变形（无 -t/-a 形式），口语极常用。
