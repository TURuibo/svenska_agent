# jag skriver för att fråga

🗣️ 类型: formell inledning · 语域: formellt · 常用度: 3/5
🇨🇳 我写信是想询问 · 🇬🇧 I am writing to ask
📝 字面: I write in order to ask

## 用法说明 (Usage)

- 邮件开头说明写信目的。*för att* + 不定式 = "为了…"；后可接 *om*（是否）或 *hur/vad*。
- 变体：*Jag skriver för att anmäla …*（我写信是想报告/申请…）。
