# anmälan görs på webbplatsen — funktionell fras

Zh: 报名通过网站进行 · English: registration is done on the website
发音提示：an-MÄ-lan GÖRS på WEBB-plat-sen

## 结构分析 (Structure)

```
anmälan + görs + på + webbplatsen
```

- `anmälan` — 报名；登记（en-ord）
- `görs` — s-passiv形式（göra → görs = is done）
- `på webbplatsen` — 在网站上

## 公告语言模板 (Notice Templates)

- `Anmälan görs på webbplatsen.` — 报名在网站上进行。
- `Anmälan krävs.` — 需要提前报名。
- `Ingen anmälan behövs / drop-in.` — 无需报名/随时可来。
- `Anmälan senast den <datum>.` — 报名截止日期为……。

## 例句 (Sentences)

- Anmälan görs på webbplatsen senast 15 juni. — 报名须在6月15日前通过网站完成。
- Anmälan görs direkt i receptionen eller online. — 报名可直接在前台或网上进行。
- Observera att anmälan görs på webbplatsen — inga telefonanmälningar. — 请注意，报名通过网站进行——不接受电话报名。
