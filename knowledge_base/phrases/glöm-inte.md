# glöm inte

🗣️ 类型: vardagsfras · 语域: neutralt · 常用度: 5/5
🇨🇳 别忘了 · 🇬🇧 don't forget
📝 字面: "忘记 + 不"（否定命令式）

## 用法说明 (Usage)

- 瑞典语**否定命令式 = 命令式 + inte**，直接放动词后：*Glöm inte!* / *Spring inte!* / *Rör inte!*（不像英语要加 don't）。
- glömma 是第 2 类动词，命令式去 -a：**glöm**。变形：glömmer / glömde / glömt。
- 接名词：*Glöm inte vantar och mössa!*；接动作：*Glöm inte **att** anmäla er!*（att + 不定式）。
- 比 *kom ihåg att…* 更简短、更常见于通知与提醒便条。

## 短语中的语法 (Grammar inside)

- → [[grammar-imperativ]] — 否定命令式：V-imperativ + inte

- 🔄 glöm inte bort（更口语，加 bort 强调）/ kom ihåg

## 例句 / 对话 (Examples)

- [[sent-glöm-inte-vantar-och-mössa]] 🇸🇪 Glöm inte vantar och mössa! 🇨🇳 别忘了手套和帽子！
- 🇸🇪 Glöm inte att anmäla er till föräldramötet. 🇨🇳 别忘了报名家长会。
- 🇸🇪 Glöm inte nappen hemma! 🇨🇳 别把奶嘴忘在家里！
