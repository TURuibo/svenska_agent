# sätta åldersgränser — politisk åtgärd

📖 中文：设定年龄限制 · English: to set age limits
📌 政策性表达，常见于立法与监管议题。

## 用法 (Usage)

- `sätta åldersgränser för` — 为……设定年龄限制
- `höja åldersgränsen` — 提高年龄门槛
- `sänka åldersgränsen` — 降低年龄门槛

## 例句 (Sentences)

- 🇸🇪 Lagstiftarna bör sätta åldersgränser för sociala medier. — 🇨🇳 立法者应该为社交媒体设定年龄限制。
- 🇸🇪 EU vill sätta en enhetlig åldersgräns. — 🇨🇳 欧盟希望设定统一的年龄限制。
