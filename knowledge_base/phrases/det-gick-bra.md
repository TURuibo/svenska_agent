# det gick bra

🗣️ 类型: tröstfras · 语域: vardagligt · 常用度: 5/5
🇨🇳 没事，没摔坏；一切顺利 · 🇬🇧 you're okay, it went fine
📝 字面: it went well

## 用法说明 (Usage)

- 孩子摔倒后大人说的"没事"；问句形式 *Gick det bra?* = 没事吧？
- 也是通用的"（考试/面试/会面）进行得顺利"：*Hur gick det? – Det gick bra.*
- 用过去式 gick，因为说的是刚发生的那件事。

## 短语中的语法 (Grammar inside)

- → [[grammar-preteritum]] — gick 是 gå 的过去式（不规则）
