# få någon att + infinitiv

🗣️ 类型: fast-uttryck（使役结构）· 语域: neutralt · 常用度: 5/5
🇨🇳 使/让某人（做某事） · 🇬🇧 to make / get someone to do
📝 字面: 得到 某人 去 + 动词

## 用法说明 (Usage)

- 结构：`få + 宾语（人，宾格） + att + 不定式`。表示**某事/某人促使某人做某事或产生某种反应**（使役）。
- 宾语用**宾格**：`få mig / dig / honom / henne / oss / dem att …`，`att` 不能省。
- 主语既可以是人，也可以是事物/情况：`Filmen fick mig att gråta`（这部电影让我哭了）。
- 文章里：`Det hade kunnat få honom att lägga av`——`hade kunnat + 不定式` = "本来可能会"（过去的假设），所以句意是"这本可能让他放弃"。
- ⚠️ 别和别的 `få` 用法混淆：
  - `få + 不定式`（无 att）= 被允许/得以做：`Jag får gå hem.`（我可以回家）
  - `få + 过去分词/宾语` = 得到：`få ett brev`
  - `få någon att …` = **促使/说服**某人做：`Hur får jag barnen att äta grönsaker?`
- 与 `låta någon + 不定式`（让某人做、不加 att，侧重"允许/让"）不同：`få … att` 侧重"促使、引起"。
- 与 `göra att`（使得）近义，但 `göra att` 的主语通常是事情本身、后面接完整从句：`Det gör att jag blir trött.`

- 🇸🇪 Det hade kunnat få honom att lägga av men istället tog han sitt livs viktigaste beslut. 🇨🇳 这本可能让他放弃，但他却做出了一生中最重要的决定。
- 🇸🇪 Filmen fick mig att gråta. 🇨🇳 这部电影让我哭了。
- 🇸🇪 Hur kan jag få barnen att äta grönsaker? 🇨🇳 我怎样才能让孩子们吃蔬菜？
