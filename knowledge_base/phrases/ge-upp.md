# ge upp

**类型:** partikelverb (小品动词)
**中文:** 放弃
**English:** to give up; to quit
**CEFR:** A2

## 变形 (Conjugation)

| 形式 | 瑞典语 |
|------|--------|
| 原形 | ge upp |
| 现在时 | ger upp |
| 过去时 | gav upp |
| 过去分词 | gett/givit upp |

## 用法 (Usage)

- **ge upp** = 停止尝试；放弃某事或某个目标。
- 常用于否定：*inte ge upp* = 不放弃（励志语境）
- 可带宾语：*ge upp hoppet* = 放弃希望；*ge upp rökning* = 戒烟

## 例句 (Example Sentences)

1. *Det är viktigt att inte ge upp.* — 不轻言放弃是很重要的。
2. *Ge inte upp!* — 不要放弃！
3. *Han gav aldrig upp.* — 他从未放弃。
4. *Det är svårt att ge upp gamla vanor.* — 放弃旧习惯很难。

## 相关词 (Related Words)

- ge in — 屈服，让步
- ge sig — 放弃（较口语）
