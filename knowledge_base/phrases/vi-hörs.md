# vi hörs

🗣️ 类型: avskedsfras · 语域: vardagligt · 常用度: 5/5
🇨🇳 回头联系 · 🇬🇧 talk soon
📝 字面: we hear (each other)

## 用法说明 (Usage)

- 与 [[vi-ses]] 并列的最常见告别语；hörs 偏"电话/消息联系"，ses 偏"见面"。
- 刚交换号码后说 *Vi hörs!* 特别自然。
- 可加时间：*Vi hörs i morgon / senare / i veckan.*

## 短语中的语法 (Grammar inside)

- → [[grammar-s-verb-reciprok]] — hörs = 互相听到 → 联系（不是被动）

## 变体 & 相关 (Variations & Related)

- 🔄 *Vi hörs!* / *Hörs!* / *Vi hörs snart.* / *Vi hörs av oss.*
- 🔗 [[vi-ses]]
- 🔗 [[hej-då]]

## 例句 / 对话 (Examples)

- [[sent-vi-hörs]] 🇸🇪 Hej då, Ella! Vi hörs! 🇨🇳 再见，Ella！回头联系！
- 🇸🇪 Jag ringer i kväll. Vi hörs! 🇨🇳 我晚上打给你，回头联系！
