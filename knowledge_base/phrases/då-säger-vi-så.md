# då säger vi så

🗣️ 类型: överenskommelse · 语域: vardagligt · 常用度: 4/5
🇨🇳 那就这么定了 · 🇬🇧 let's say that then, it's a deal
📝 字面: then say we so

## 用法说明 (Usage)

- 敲定约定的固定收尾句，说完就可以告别了。
- **då** 承接前面的确认（时间、地点），**så** = 这样。
- 常连着 *Vi ses! / Vi hörs!*。

## 短语中的语法 (Grammar inside)

- → [[grammar-v2-ordfoljd]] — då 句首 → säger 第二位 → vi 后置
