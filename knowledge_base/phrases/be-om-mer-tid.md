# be om mer tid

🗣️ 类型: verbfras · 语域: neutralt · 常用度: 3/5
🇨🇳 要求更多时间 · 🇬🇧 ask for more time

## 用法说明 (Usage)

- be om + 名词 = 请求/要求某物
- be om = 请求；注意 be 后必须带 om。

## 例句 / 对话 (Examples)

- 🇸🇪 Om hon inte är färdig kan hon be om mer tid. 🇨🇳 如果她没做完，可以要求更多时间。
- 🇸🇪 Jag ber om mer tid för uppgiften. 🇨🇳 我请求为这项任务多给些时间。
