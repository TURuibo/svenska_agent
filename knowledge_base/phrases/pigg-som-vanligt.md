# pigg som vanligt

🗣️ 类型: uttryck · 语域: vardagligt · 常用度: 3/5
🇨🇳 像平常一样精神 · 🇬🇧 perky as usual
📝 字面: 精神得像往常

## 用法说明 (Usage)

- **som vanligt** = "和往常一样"，可以接在任何形容词/句子后：*glad som vanligt*、*sen som vanligt*、*Vi äter klockan sex som vanligt.*
- *pigg* 描述人精神好、清醒（尤其早上）；反义 *trött*。
- 讲夜里折腾、宝宝早上却照常精神——是家长间的经典自嘲。
