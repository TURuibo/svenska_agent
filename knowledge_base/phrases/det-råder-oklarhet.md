# det råder oklarhet

🗣️ 类型: fast-uttryck（`Det råder + 抽象名词` 句型）· 语域: 正式 / 新闻体 · 常用度: 3/5
🇨🇳 情况不明确；存在不明确之处 · 🇬🇧 there is uncertainty / unclarity
📝 字面: 不明确占主导

## 用法说明 (Usage)

- 句型：`Det råder + 抽象名词 (+ om / kring / angående + 话题)`。`det` 是**虚主语**，真正的主语是后面的名词（`oklarhet`）。
- 常见名词：`oklarhet / förvirring / osäkerhet / brist på … / enighet / oenighet / stor oro / förbud mot …`。
- 只用于书面、新闻、公告；口语里会说 `Det är oklart …` 或 `Ingen vet …`。
- 与 [[råda-någon-att]]（建议某人）是 **[[råda]] 的另一个义项**，结构完全不同。
- 前置时间状语时，`det` 紧跟在动词之后：`I dag råder det oklarhet …`（V2 倒装）。

## 短语中的语法 (Grammar inside)

- → [[grammar-v2-ordfoljd]]：`I dag **råder** det oklarhet` — 状语放句首时，定式动词 `råder` 仍然排第二，主语 `det` 退到动词之后。

## 变体 & 相关 (Variations & Related)

- 🔄 `det råder förvirring / osäkerhet / brist på …`
- 🔄 `Här råder parkeringsförbud.` — 此处禁止停车
- 🔄 `det är oklart (om …)` — 不清楚（口语）
- 🔗 [[råda]]、[[oklarhet]]、[[råda-någon-att]]

## 例句 / 对话 (Examples)

- [[sent-i-dag-råder-det-oklarhet-om-var]] 🇸🇪 I dag råder det oklarhet om var man får parkera. 🇨🇳 目前，关于可以在哪里停车仍然不明确。
- 🇸🇪 Det råder stor förvirring efter beskedet. 🇨🇳 消息公布后一片混乱。
- 🇸🇪 Det råder brist på sjuksköterskor i många regioner. 🇨🇳 许多地区护士短缺。
- 🇸🇪 Här råder förbud mot cykling. 🇨🇳 此处禁止骑行。
