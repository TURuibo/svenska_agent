# Vad bra att …

🗣️ 类型: utrop · 语域: vardagligt · 常用度: 4/5
🇨🇳 …真好 · 🇬🇧 How good that …

## 用法说明 (Usage)

- `Vad + 形容词 + att + 从句` 表示对对方消息的积极反应；常用于信的开头"回应前信"。
- 类似：Vad spännande att …, Vad kul att …。

## 例句 / 对话 (Examples)

- 🇸🇪 Vad bra att du har bestämt dig för att sluta röka. — 🇨🇳 你决定戒烟，真好。
- 🇸🇪 Vad spännande att du går sista året på gymnasiet! — 🇨🇳 你读高三了，真令人兴奋！
