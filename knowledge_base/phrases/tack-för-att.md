# tack för att

🗣️ 类型: fast-uttryck · 语域: neutralt · 常用度: 4/5
🇨🇳 感谢…（+ att-sats） · 🇬🇧 thank you for (+ clause)
📝 字面: thank you for that

## 用法说明 (Usage)

- `tack för att + 动词（过去时）` — 感谢某人做了某事
- 后面接 att-sats（att-从句），动词通常用过去时（preteritum）
- 例：tack för att du hjälpte mig（感谢你帮助了我）
