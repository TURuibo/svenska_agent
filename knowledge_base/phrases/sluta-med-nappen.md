# sluta med nappen

🗣️ 类型: vardagsfras · 语域: vardagligt · 常用度: 4/5
🇨🇳 戒奶嘴 · 🇬🇧 give up the pacifier
📝 字面: 停止用奶嘴

## 用法说明 (Usage)

- **sluta med + 名词** = 戒掉/停止…：*sluta med nappen / sluta med blöjor*。介词 **med** 不能换。
- 名词用定式 *nappen*（那个奶嘴，家里那个）。
- 接动词时用 *sluta + 动词原形*：*sluta gråta*（不再哭）。
