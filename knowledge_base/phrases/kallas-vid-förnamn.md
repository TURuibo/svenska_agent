# kallas vid förnamn

🗣️ 类型: fast-uttryck · 语域: neutralt · 常用度: 3/5
🇨🇳 以名字相称 · 🇬🇧 to be called by one's first name
📝 字面: 被叫在名字旁

## 用法说明 (Usage)

- *kallas* 是 *kalla*（叫）的 **s-被动**：*Alla kallas vid förnamn* = 所有人都被用名字称呼。
- 介词是 **vid**：*kalla någon vid namn / vid förnamn*。
- 瑞典职场、学校、幼儿园都直呼其名，没有「X 老师」「X 校长」这种称呼；中文母语者容易想加头衔，反而显得生分。
