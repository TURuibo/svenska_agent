# vid tvåtiden

🗣️ 类型: tidsuttryck · 语域: vardagligt · 常用度: 4/5
🇨🇳 两点左右 · 🇬🇧 around two o'clock
📝 字面: 在两点的时间

## 用法说明 (Usage)

- 模板 **vid + 数字 + tiden**（定式）= 「X 点左右」：*vid tretiden, vid femtiden, vid lunchtiden*。
- 老师报时间几乎都用 *-tiden*（模糊时间），比精确 *klockan två* 更自然。
- 注意合写：*tvåtiden* 一个词。

## 短语中的语法 (Grammar inside)

- → [[grammar-bestämd-form]] — tiden 定式（复合词 två + tid + en）

## 变体 & 相关 (Variations & Related)

- 🔄 vid lunchtiden — 午饭前后
- 🔄 runt två / cirka klockan två — 两点左右（同义）
- 🔗 [[vid-hämtning]], [[kvart-i-två]]

## 例句 / 对话 (Examples)

- [[sent-hon-bajsade-vid-tvåtiden-annars-har]] 🇸🇪 Hon bajsade vid tvåtiden. 🇨🇳 她两点左右拉了臭臭。
- 🇸🇪 Vi går ut vid tiotiden. 🇨🇳 我们十点左右出去。
