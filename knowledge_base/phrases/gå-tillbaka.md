# gå tillbaka

🗣️ 类型: partikelverb · 语域: neutralt · 常用度: 5/5
🇨🇳 返回；回去 · 🇬🇧 to go back / return
📝 字面: gå（走）+ tillbaka（往回）

## 用法说明 (Usage)

- `gå tillbaka till + 地点` = 回到某地。
- preteritum：`gick tillbaka`（gå → gick，不规则）。
- 也说 `åka tillbaka`（乘交通工具返回）或 `komma tillbaka`（回来）。

## 短语中的语法 (Grammar inside)

- → [[grammar-preteritum]]（gå → gick，不规则）

## 变体 & 相关 (Variations & Related)

- 🔄 `åka tillbaka` — 乘车回去
- 🔄 `komma tillbaka` — 返回（更着重"回到"）
- 🔗 [[komma-fram]] — 到达（到达后可能需要 gå tillbaka）

## 例句 / 对话 (Examples)

- [[sent-jag-gick-tillbaka-till-tunnelbanestationen-fragade-personal]] 🇸🇪 Jag gick tillbaka till tunnelbanestationen och frågade personalen. 🇨🇳 我回到地铁站，问了工作人员。
