# bestämma sig för

🗣️ 类型: partikelverb (reflexivt) · 语域: neutralt · 常用度: 5/5
🇨🇳 下定决心做某事；决定（做） · 🇬🇧 to decide to (do something); to make up one's mind
📝 字面: decide oneself for

## 用法说明 (Usage)

- 结构：`bestämma sig för att + 原形动词`
  - `Jag bestämde mig för att ta det lugnt.` — 我决定放松一下。
  - `Hon bestämde sig för att börja träna.` — 她决定开始锻炼。
- `sig` 是反身代词，随主语变化：
  - `jag` → `mig`：`jag bestämde mig för att...`
  - `du` → `dig`：`du bestämde dig för att...`
  - `han/hon` → `sig`：`han bestämde sig för att...`
  - `vi` → `oss`：`vi bestämde oss för att...`
- 与 `bestämma` (决定/规定) 的区别：`bestämma sig för` 强调主观意志和决心，`bestämma` 可用于第三方或规则。
