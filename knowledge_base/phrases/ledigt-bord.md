# ledigt bord

🗣️ 类型: vardagsfras · 语域: vardagligt · 常用度: 4/5
🇨🇳 空桌子；空桌 · 🇬🇧 free/available table; empty table
📝 字面: 空闲的桌子

## 用法说明 (Usage)

- 在咖啡馆/餐厅寻找位置时使用。
- `Finns det ett ledigt bord?`（有空桌吗？）
- 注意：`bord` 是 ett-词，所以形容词用 `ledigt`（中性形），不是 `ledig`（en-形）。
- 对比：`ledig stol`（空椅子，en-词）vs `ledigt bord`（空桌子，ett-词）。

## 短语中的语法 (Grammar inside)

- `ledigt` = `ledig`（空闲的）的中性形，因为 `bord` 是 ett-词 → [[grammar-adjektiv-kongruens]]

## 变体 & 相关 (Variations & Related)

- 🔄 `finns det ett ledigt bord?` — 有空桌吗？ → [[finns-det-något-ledigt-bord]]
- 🔄 `ett ledigt bord vid fönstret` — 窗边有空桌
