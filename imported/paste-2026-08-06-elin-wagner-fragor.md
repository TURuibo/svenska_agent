## 瑞典语原文 (Källtext)

### 🎧 Lyssna

Lyssna på din lärare som berättar om Elin Wägner.

### 💬 Prata

Sammanfatta berättelsen om Elin Wägner med hjälp av tankekartan.

**Svara på frågorna.**

1. Vem var Elin Wägner?
2. Vilken uppgift i livet hade kvinnorna när Elin växte upp?
3. Varför var det nästan bara pojkar som studerade vidare?
4. Vad ville Elin studera?
5. Var fick hon arbete?
6. Hur kämpade Elin för kvinnors rättigheter?
7. Vad kämpade kvinnorättsrörelsen för?
8. Hur arbetade kvinnorättsrörelsen?
9. Vilken händelse gjorde att arbetet för kvinnlig rösträtt stannade av?
10. Vad hände ute i Europa efter första världskriget?
11. Hur påverkades Sverige av oroligheterna ute i Europa?
12. När fick kvinnor rösta till riksdagen för första gången?

## 🇨🇳 全文翻译 (Översättning)

### 🎧 听

听你的老师讲述关于 Elin Wägner 的事。

### 💬 说

借助思维导图，总结关于 Elin Wägner 的故事。

**回答下列问题。**

1. Elin Wägner 是谁？
2. 在 Elin 长大的年代，女性在人生中被赋予什么任务（角色）？
3. 为什么当时几乎只有男孩才继续升学深造？
4. Elin 想学什么？
5. 她在哪里找到了工作？
6. Elin 是如何为妇女权利而奋斗的？
7. 女权运动为了什么而奋斗？
8. 女权运动是怎样开展工作的？
9. 什么事件使得争取女性选举权的工作停滞了下来？
10. 第一次世界大战之后，欧洲（外面）发生了什么？
11. 瑞典是如何受到欧洲那些动荡影响的？
12. 女性第一次获准投票选举议会是在什么时候？

## 📌 教学备注 (Teaching Notes)

### 📐 这一页的语法核心：frågeord（疑问词）+ 倒装

12 道题正好把瑞典语 7 个常用疑问词全用了一遍。**瑞典语的疑问词必须提到句首，然后动词紧跟其后、主语退到动词之后（V2 倒装）**——这是和中文最大的差别：中文疑问词**原地不动**（"他是谁？"），瑞典语必须搬家。

```
📐 frågeord + 动词 + 主语 + 其余
   Vem      var     Elin Wägner?
   Vad      ville   Elin      studera?
   När      fick    kvinnor   rösta …?
```

| frågeord | 🇨🇳 | 🇬🇧 | 本页例句 | 备注 |
|----------|-----|-----|----------|------|
| **vem** | 谁 | who | Vem **var** Elin Wägner? | 只问人 |
| **vilken** | 哪一个 | which | **Vilken** uppgift hade kvinnorna? | 随名词变形：vilken (en-ord) / vilket (ett-ord) / vilka (复数) |
| **varför** | 为什么 | why | **Varför** var det nästan bara pojkar…? | |
| **vad** | 什么 | what | **Vad** ville Elin studera? | |
| **var** | 哪里 | where | **Var** fick hon arbete? | ⚠️ 与 `var` = "是"的过去式 (vara → var) 同形，靠位置区分 |
| **hur** | 怎样 | how | **Hur** kämpade Elin…? | |
| **när** | 什么时候 | when | **När** fick kvinnor rösta…? | |

> ⚠️ 第 1 题 `Vem **var** Elin Wägner?` 里的 `var` 是动词（是→过去式）；第 5 题 `**Var** fick hon arbete?` 里的 `var` 是疑问词"哪里"。**同形不同词**，看它站在句首还是动词位。

### 📌 介词被"留"在句末

```
Vad kämpade kvinnorättsrörelsen  för ?
                                  └─ 介词留在最后
```
完整搭配是 `kämpa **för** ngt`（为…而奋斗）。提问时把 `vad` 提到句首，介词 `för` **原地不动留在句尾**——和英语 "What did they fight **for**?" 一模一样，中文则说"为**什么**而奋斗"（介词在前）。同理第 7、8 题。

### 📌 -s 属格（无撇号！）

`kvinno**rs** rättigheter` = 妇女的权利。瑞典语属格直接加 **-s**，**不写撇号**（英语 women**'s** 有撇号，瑞典语没有）。

### 📌 s-被动 (s-passiv) 的过去式

第 11 题 `Hur **påverkades** Sverige av oroligheterna?`
- 主动: oroligheterna **påverkade** Sverige（动荡影响了瑞典）
- 被动: Sverige **påverkades av** oroligheterna（瑞典**被**动荡影响）

📐 preteritum s-passiv = **preteritum + s** → påverkade → påverkade**s**。施事者用 **av** 引出（≈ 英语 by）。

### 📌 复合词拆解 (sammansatta ord)

| 复合词 | 拆开 | 🇨🇳 |
|--------|------|-----|
| **röst**+**rätt** → rösträtt | 声音/票 + 权利 | 选举权 |
| **kvinno**+**rätts**+**rörelse** | 女性 + 权利 + 运动 | 女权运动 |
| **världs**+**krig** | 世界 + 战争 | 世界大战 |
| **tanke**+**karta** | 思想 + 地图 | 思维导图 |

> 瑞典语复合词**连写成一个词**，词义重心在**最后一节**：`kvinnorättsrörelsen` 归根到底是一个 *rörelse*（运动）。

### 📌 partikelverb（小品词动词）

- `växa **upp**` = 长大（≠ 单纯 växa "生长"）→ Elin **växte upp**
- `stanna **av**` = 停滞、中断（≠ 单纯 stanna "停下"）→ arbetet **stannade av**

### 📌 `som` 引导的关系从句

- din lärare **som** berättar om Elin Wägner（讲述 Elin Wägner 的那位老师）
- pojkar **som** studerade vidare（继续升学的那些男孩）

`som` 一词通吃中文的"…的"，人/物都能用，且**不能省略**（英语常可省，瑞典语不行）。

### 📝 参考答案要点（基于史实，供对照老师的讲述）

> 课本答案取决于老师朗读的那段故事；以下是 Elin Wägner 的真实史实，可用来对照。

| # | 要点 |
|---|------|
| 1 | Elin Wägner (1882–1949)，瑞典作家、记者、女权与和平运动者，1944 年成为继 Selma Lagerlöf 之后第二位瑞典学院院士。 |
| 2 | 当时女性"人生的任务"被认为是结婚、持家、照顾丈夫和孩子。 |
| 3 | 深造被看作男孩的事——女孩被期待走进婚姻家庭，教育被视为对她们"无用"。 |
| 4 | 她想继续读书深造（她自幼酷爱阅读写作）。 |
| 5 | 在报社当记者：1903–04 在 *Helsingborgsposten*，1904–05 在 *Vårt Land*，后来到斯德哥尔摩的女性周刊 *Idun*。 |
| 6 | 用笔战斗——写文章和小说（1908 *Norrtullsligan*、1910 *Pennskaftet*），并亲身参与选举权运动组织工作。 |
| 7 | 争取女性的投票权（rösträtt）、受教育权和工作权。 |
| 8 | 通过办刊物、写文章、演讲、征集签名、集会游行等和平方式。 |
| 9 | **第一次世界大战**（1914–1918）——战争让选举权运动的工作停滞下来。 |
| 10 | 战后欧洲出现革命与动荡（如俄国、德国的革命）。 |
| 11 | 瑞典也出现不安、饥饿抗议和对革命的担忧，促使议会在 1918–1919 年决定实行普遍和平等的选举权。 |
| 12 | **1921 年 9 月**的议会大选——女性第一次既能投票也能被选。 |
