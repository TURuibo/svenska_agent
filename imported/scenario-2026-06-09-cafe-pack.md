# Kafepaketet — 咖啡馆全场景会话包

**类型 (type):** dialog-pack (12 micro-dialogues)
**CEFR 估计:** A2–B1
**生成日期:** 2026-06-09

> 这个练习包涵盖一次咖啡馆探访的完整流程——从点单到结账、从找座到投诉——共 12 段微型对话，使用真实日常瑞典语（含缩读、语气词）。

---

### 1. Beställa kaffe — 点咖啡

**Setting:** 顾客（K）第一次走进柜台，向咖啡师（B）点单。

🇸🇪
```
B: Hej! Vad får det vara?
K: Hej! En latte, tack.
B: Stor eller liten?
K: Liten, tack. Här eller ta med?
B: Nej, du väljer ju — ska du sitta här eller ta med den?
K: Ah, förlåt! Här, tack.
B: Självklart! Det blir fyrtiofem kronor.
```

🇨🇳
```
B：你好！请问要点什么？
K：你好！一杯拿铁，谢谢。
B：大杯还是小杯？
K：小杯，谢谢。在这里喝还是带走？
B：哦，你来选——是坐这儿喝还是带走？
K：啊，不好意思！在这里喝，谢谢。
B：当然！一共四十五克朗。
```

📌 Teaching notes:
- **Vad får det vara?** 是咖啡馆/餐馆最常见的开场问句，字面意为"能是什么？"，相当于"请问要点什么？"
- **Här eller ta med?** 是完整短语 *här eller ta med* 的简化问法；完整说法是 *Ska du äta/dricka här eller ta med det?*
- **Det blir + belopp** 表示"一共是…钱"，比 *det kostar* 更常用于结账语境。

### 2. Mjölkalternativ — 选择植物奶

**Setting:** 顾客（K）在点咖啡时询问植物奶选项。

🇸🇪
```
K: Kan jag få havremjölk i stället?
B: Ja, absolut. Vi har havre, soja och laktosfri.
K: Havre, tack. Kostar det extra?
B: Det kostar fem kronor extra, ja.
K: Okej, det är lugnt.
```

🇨🇳
```
K：我可以换燕麦奶吗？
B：当然可以。我们有燕麦奶、豆奶和无乳糖奶。
K：燕麦奶，谢谢。要额外收费吗？
B：是的，要多五克朗。
K：好的，没问题。
```

📌 Teaching notes:
- **i stället** 意为"换成；作为替代"，口语中也写/说作 *istället*（一个词）。
- **Det är lugnt** 字面是"那是平静的"，口语中意为"没问题 / 无所谓"，是非常自然的应答。
- 植物奶三连：**havremjölk**（燕麦奶）、**sojamjölk**（豆奶）、**laktosfri mjölk**（无乳糖奶）——记住这三个，瑞典咖啡馆几乎必备。

### 3. Fikabeställning — 点菲卡套餐

**Setting:** 顾客（K）想要一个典型的 fika 套餐——咖啡加肉桂卷。

🇸🇪
```
K: Har ni nån fika-deal? Kaffe och bulle?
B: Ja! Kaffe med kanelbulle eller kardemummabulle — åttio kronor.
K: Oj, vilket ska jag ta... En kanelbulle, tack.
B: Den är precis nybakad, faktiskt!
K: Perfekt, då tar jag den.
```

🇨🇳
```
K：你们有菲卡套餐吗？咖啡加甜卷？
B：有！咖啡配肉桂卷或豆蔻卷——八十克朗。
K：哎，选哪个好呢……肉桂卷吧，谢谢。
B：刚好是刚出炉的！
K：太好了，那我就要这个。
```

📌 Teaching notes:
- **fika** 是瑞典文化核心词：喝咖啡 + 吃甜食的社交休息时间，既是名词也是动词（*att fika* = 去菲卡）。
- **kanelbulle**（肉桂卷）vs **kardemummabulle**（豆蔻卷）——后者是斯德哥尔摩精品咖啡馆的招牌，比肉桂卷更受年轻人欢迎。
- **nybakad** = 刚烤好的；**ny-** 前缀 + 过去分词构成"新鲜……的"复合形容词，非常实用。

### 4. Allergier / ingredienser — 询问过敏成分

**Setting:** 顾客（K）对坚果过敏，向店员（B）确认蛋糕是否安全。

🇸🇪
```
K: Ursäkta, innehåller den här kakan nötter?
B: Ja, tyvärr — den har mandel i sig.
K: Och den där då? Cheesecaken?
B: Den är nötfri, men den innehåller gluten.
K: Okej, är det nåt som är både glutenfritt och nötfritt?
B: Ja, den chokladkakan där är det. Den är faktiskt vegansk också.
```

🇨🇳
```
K：不好意思，这块蛋糕里有坚果吗？
B：有，很遗憾——里面有杏仁。
K：那那个呢？芝士蛋糕？
B：那个不含坚果，但含有麸质。
K：好的，有什么既不含麸质又不含坚果的吗？
B：有，那边那块巧克力蛋糕就是。其实它也是纯素的。
```

📌 Teaching notes:
- **innehåller** 是 *innehålla*（包含/含有）的现在时，询问食品成分时的核心动词。
- **nötfri** / **glutenfri** / **vegansk** — 这三个词在瑞典咖啡馆标签上极其常见，-fri 后缀表示"不含……的"。
- **ha nåt i sig** = 里面含有某东西，*nåt* 是口语中 *något*（某物）的缩读。

### 5. Betala — 结账付款

**Setting:** 顾客（K）结账，想用 Swish 付款并要求收据。

🇸🇪
```
K: Kan jag betala med Swish?
B: Ja, självklart. Scanna QR-koden där.
K: Klart! Kan jag få ett kvitto?
B: Du får ett digitalt kvitto via appen, eller vill du ha papper?
K: Papper, tack, det är enklare.
B: Varsågod! Ha en fin dag!
K: Tack detsamma!
```

🇨🇳
```
K：我可以用 Swish 付款吗？
B：当然可以。扫那边的二维码。
K：好了！能给我一张收据吗？
B：你会通过 app 收到电子收据，还是想要纸质的？
K：纸质的吧，更方便。
B：给你！祝你有美好的一天！
K：谢谢，你也是！
```

📌 Teaching notes:
- **Swish** 是瑞典最主流的手机支付应用，几乎人人使用，日常比现金更常见。
- **kvitto** = 收据（ett kvitto，复数 kvitton）；结账时问 *Kan jag få ett kvitto?* 是标准用法。
- **Tack detsamma!** = "谢谢，你也是！"，是回应 *ha en fin dag* 等祝福语的固定表达。

### 6. Påtår — 要免费续杯

**Setting:** 顾客（K）喝完第一杯咖啡，想要续杯（在很多瑞典咖啡馆是免费的）。

🇸🇪
```
K: Ursäkta, har ni påtår?
B: Ja, på filterkaffet — en påtår ingår i priset.
K: Toppen! Kan jag ta en till nu?
B: Absolut, häll bara på dig själv där borta vid kaffemaskinen.
K: Perfekt, tack så mycket!
```

🇨🇳
```
K：不好意思，你们提供免费续杯吗？
B：有，滴滤咖啡可以——续杯包含在价格里。
K：太棒了！我现在可以去拿吗？
B：当然，去那边咖啡机自己倒就行了。
K：完美，非常感谢！
```

📌 Teaching notes:
- **påtår** 是瑞典语特有词，指咖啡的免费续杯（字面：*på*（再）+ *tår*（一小口/一滴））——英语没有对应单词。
- **ingår i priset** = 包含在价格里，*ingå* 是"被包含/纳入"的动词。
- **häll på dig själv** = 自己去倒，非常口语化；*hälla* 是"倒（液体）"的动词。

### 7. Är platsen ledig? — 询问座位是否有人

**Setting:** 咖啡馆很满，顾客（K）看到一张桌子只有一人，想问另一把椅子是否有人。

🇸🇪
```
K: Hej, är den här platsen ledig?
G: Ja, varsågod — jag väntar inte på nån.
K: Tack! Jag sätter bara ner mig ett tag.
G: Självklart, ingen fara.
```

🇨🇳
```
K：你好，这个位置有人吗？
G：没有，请坐——我没有等人。
K：谢谢！我就坐一小会儿。
G：当然，没关系。
```

📌 Teaching notes:
- **Är den här platsen ledig?** 是找座位的标准问法；*ledig* = 空闲的、没有占用的（也用于"空缺的职位"：*en ledig tjänst*）。
- **ingen fara** = 没关系 / 不麻烦，是比 *det är okej* 更自然的口语回应。
- **ett tag** = 一小会儿，口语中极常见的时间表达。

### 8. Wifi-lösenord — 问 Wi-Fi 密码

**Setting:** 顾客（K）想连网，向咖啡师（B）询问 Wi-Fi 密码。

🇸🇪
```
K: Har ni wifi här?
B: Ja! Nätverket heter "FikaBageriet" och lösenordet är "kanelbulle23".
K: Kanelbulle, lätt att komma ihåg! Tack!
B: Haha, precis! Inga problem.
```

🇨🇳
```
K：这里有 Wi-Fi 吗？
B：有！网络名称是"FikaBageriet"，密码是"kanelbulle23"。
K：肉桂卷，好记！谢谢！
B：哈哈，就是这样！不客气。
```

📌 Teaching notes:
- **lösenord** = 密码（ett lösenord）；*lösen*（赎金/解锁词）+ *ord*（词）——记住它比 *password* 的音译更好用。
- **nätverket heter...** = 网络叫做……；*heta* 是表示"叫做/名为"的动词，用于名称介绍。
- **lätt att komma ihåg** = 容易记住；*komma ihåg* 是"记住/想起"的固定搭配（partikelverb）。

### 9. Ta med — 打包带走

**Setting:** 顾客（K）想要将拿铁带走，并要纸吸管和餐巾纸。

🇸🇪
```
K: En stor latte, tack — det är ta med.
B: Självklart. Vill du ha ett lock på?
K: Ja, tack. Och kan jag få en halm och lite servetter?
B: Visst! Vi har papperssugrör — håller du till höger?
K: Tack, jag hittar det.
```

🇨🇳
```
K：一杯大杯拿铁，谢谢——打包带走。
B：当然。要加杯盖吗？
K：要，谢谢。还能给我一根吸管和几张餐巾纸吗？
B：当然！我们有纸吸管——你往右边找一下？
K：谢谢，我自己找到。
```

📌 Teaching notes:
- **ta med** 作为打包用语等于英语 "to go / take away"；完整句是 *Kan jag få det ta med?* 或直接说 *det är ta med*。
- **lock** = 杯盖（ett lock）；**sugrör** = 吸管（ett sugrör）；**servett** = 餐巾纸（en servett）——咖啡馆三件套必备词汇。
- **papperssugrör** 是塑料吸管被禁后瑞典咖啡馆的标配；顾客有时主动说 *utan sugrör*（不要吸管）。

### 10. Fel beställning — 礼貌投诉

**Setting:** 顾客（K）拿到的咖啡是凉的，礼貌地告知咖啡师（B）。

🇸🇪
```
K: Förlåt att jag stör, men jag tror det är fel på min latte.
B: Å, vad är det för fel?
K: Den är helt kall — var det meningen?
B: Nej, det ska den absolut inte vara! Jag gör en ny till dig direkt.
K: Tack, det uppskattar jag verkligen.
B: Förlåt för det! Det tog nog för lång tid.
```

🇨🇳
```
K：很抱歉打扰您，但我觉得我的拿铁有问题。
B：哦，是什么问题？
K：它是完全凉的——是这样的吗？
B：不，绝对不应该是这样！我马上给你重新做一杯。
K：谢谢，我真的很感激。
B：真的非常抱歉！大概等太久了。
```

📌 Teaching notes:
- **Förlåt att jag stör** = 抱歉打扰您，是提出投诉或打断别人时最礼貌的开场白。
- **det var meningen** = 这是有意为之/这是打算这样做的；反问 *var det meningen?* = 这是故意的吗？是温和质疑的方式。
- **jag gör en ny till dig direkt** — 这里 *direkt* 意为"马上/立刻"（不是"直接地"），是服务业常用的紧迫感表达。

### 11. Möta en vän — 巧遇朋友、一起点单

**Setting:** 两位朋友 Maja（M）和 Leo（L）在咖啡馆门口相遇，决定一起坐下来，Leo 提出请客。

🇸🇪
```
M: Leo! Vad gör du här?
L: Maja! Jag skulle just ta en kaffe. Du då?
M: Samma! Ska vi sätta oss?
L: Absolut. Vad tar du?
M: En americano, tror jag.
L: Jag bjuder — du bjöd förra gången.
M: Verkligen? Det är snällt av dig, tack!
L: Ingen orsak. Sitt du, så hämtar jag.
```

🇨🇳
```
M：Leo！你怎么在这？
L：Maja！我正好要来喝杯咖啡。你呢？
M：一样！我们坐下来吧？
L：当然。你要喝什么？
M：一杯美式，我想。
L：我请客——上次是你请的。
M：真的吗？你真好，谢谢！
L：不客气。你先去坐，我去拿。
```

📌 Teaching notes:
- **Jag bjuder** = 我请客，是非常自然的口语表达；*bjuda* 在这里是"请客/招待"，不是"邀请"（虽然两者同词）。
- **Du bjöd förra gången** 用了 *preteritum*（过去时）：*bjuder → bjöd*；*förra gången* = 上次。
- **Sitt du, så hämtar jag** — *så*-结构表示"你……，然后我……"，是口语中表达分工的自然句型。

### 12. Öppettider / stängning — 问营业时间和最后点单

**Setting:** 顾客（K）快到打烊时间才进门，向店员（B）询问还能不能点单。

🇸🇪
```
K: Ursäkta, när stänger ni?
B: Vi stänger klockan fem — om tio minuter alltså.
K: Hinner jag beställa nåt?
B: Ja, men det är sista beställning nu.
K: Okej, då tar jag bara en espresso snabbt.
B: Självklart! Sätter du dig, så kommer jag med den.
K: Tack, det var precis vad jag behövde.
```

🇨🇳
```
K：不好意思，你们几点关门？
B：我们五点关——也就是再过十分钟。
K：我还来得及点东西吗？
B：可以，但现在是最后点单了。
K：好的，那我就快点来一杯浓缩咖啡。
B：当然！你去坐，我把咖啡端过来。
K：谢谢，这正是我需要的。
```

📌 Teaching notes:
- **när stänger ni?** = 你们几点关门？；*stänga* 是"关闭"的动词，*stänger* 是现在时；反义词是 *öppna*（开门）。
- **Hinner jag...?** = 我来得及……吗？；*hinna* 是"来得及/有足够时间做某事"，是时间紧迫语境下的关键动词。
- **det var precis vad jag behövde** — 字面"这正是我需要的"，过去时 *behövde* 用于感谢收到的东西（即使刚刚收到），是地道的礼貌用法。
