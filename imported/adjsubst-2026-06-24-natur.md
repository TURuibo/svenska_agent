### 语法要点

- **liten**（不规则）：ett-形 → litet，定式 → lilla，复数 → små
- **vild → vilt**：-d 结尾 → neutrum 变 -t（vild/röd/god 同类）
- **vacker → vackra**：-er 结尾 syncope，-e 脱落（vacker→vackr+a）
- **gammal → gamla**：-al 结尾 syncope（gammal→gamm+la）
- **blå / grå**：单音节以重读元音结尾，neutrum +tt（blått/grått），定式/复数不变（blå/grå）
- **vit → vitt**：长元音 + -t 结尾 → 定/复 vita（元音+t 规则）
- **tyst → tyst**：辅音+t 结尾（-st），neutrum 不再加 t
- **bred → brett**：-d 结尾长元音型，neutrum 变 -tt，定/复 breda
- **strand → stränder**：元音变音复数（a→ä）
- **himmel → himlen/himlar**：-el 结尾 syncope（himl+en/himl+ar）
- **moln / regn / träd / gräs**：ett-词零复数（形式与单数相同）
