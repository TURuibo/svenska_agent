# 🇸🇪 Ekonomiskt stöd på lättläst svenska — 经济补助（易读版）

**类型 (type):** myndighetsinformation (lättläst)
**来源 (source):** Socialstyrelsen — https://www.socialstyrelsen.se/stod-i-livet/lattlast-svenska/ekonomiskt-stod-pa-lattlast-svenska/

**主题:** T13 💰 钱·购物·经济
**目标词:** ekonomisk, stöd, bistånd, försörja, utgift, kostnad, rimlig, bedöma, planera, fackförening, försäkring, summa, el, rådgivare

## 瑞典语原文

Har du svårt att få pengarna att räcka? Då kan du få **stöd** från socialtjänsten. Vilket **stöd** du kan få beror på vad du behöver hjälp med.

### Har du skulder?

Om du har skulder eller svårt att **planera** din ekonomi kan du få **stöd** av en budget- och **skuldrådgivare**.

Det är någon som hjälper dig att

- få bättre koll på din ekonomi
- hantera dina skulder.

Kontakta din kommun för att få hjälp.

Du kan också hitta en budget- och **skuldrådgivare** via Konsumentverket.

### Vad är ekonomiskt bistånd?

**Ekonomiskt bistånd** är pengar som du kan ansöka om hos socialtjänsten.

Du kan få **ekonomiskt bistånd** om du inte kan **försörja** dig själv eller din familj.

Du kan också få **stöd** att klara din ekonomi i framtiden.

Reglerna om **ekonomiskt bistånd** finns i socialtjänstlagen.

### Två typer av ekonomiskt bistånd

**Ekonomiskt bistånd** kan vara två typer av **stöd**:

- försörjningsstöd
- **stöd** för andra levnadskostnader.

### Försörjningsstöd

Försörjningsstöd är pengar för dina vanliga **utgifter** varje månad.

Pengarna ska räcka till

- mat
- kläder och skor
- lek och fritid
- hälsa och hygien
- tidning och telefon
- förbrukningsvaror, till exempel diskmedel och glödlampor.

Regeringen bestämmer varje år hur mycket pengar du kan få. Den **summan** kallas riksnorm. Samma riksnorm gäller i hela Sverige.

Du kan också få **stöd** för vissa andra **kostnader**, till exempel

- boende
- **el**
- **hemförsäkring**
- resor till arbete
- **fackförening**
- a-kassa.

Socialtjänsten **bedömer** om **kostnaderna** är **rimliga**. Vad som är **rimligt** beror på olika saker. Till exempel var och hur du bor.

### Stöd för andra levnadskostnader

Du kan också få **ekonomiskt bistånd** för vissa **kostnader** som inte kommer varje månad.

Det kan till exempel vara **kostnader** för:

- tandvård
- glasögon
- sjukvård
- medicin.

Socialtjänsten **bedömer** om **stödet** behövs för att du ska kunna leva på en **rimlig** nivå.

## 🇨🇳 全文翻译

钱总是不够用？那你可以从社会服务处（socialtjänsten）得到帮助。你能得到哪种帮助，取决于你需要哪方面的帮助。

### 你有债务吗？

如果你有债务，或者难以规划自己的财务，可以向预算与债务顾问求助。

这是一个帮助你做到以下几点的人：

- 更好地掌握自己的财务状况
- 处理你的债务。

联系你所在的市政府（kommun）以获得帮助。

你也可以通过消费者事务局（Konsumentverket）找到预算与债务顾问。

### 什么是经济补助（ekonomiskt bistånd）？

经济补助是你可以向社会服务处申请的钱。

如果你无法养活自己或家人，就可以获得经济补助。

你还可以获得帮助，让你将来能把自己的经济安排好。

关于经济补助的规定写在《社会服务法》（socialtjänstlagen）里。

### 经济补助的两种类型

经济补助可以是两种补助：

- 生活费补助（försörjningsstöd）
- 其他生活开支补助。

### 生活费补助

生活费补助是用于你每个月日常开支的钱。

这笔钱应当够用于：

- 食物
- 衣服和鞋子
- 游戏与休闲
- 健康与卫生
- 报纸和电话
- 日用消耗品，例如洗洁精和灯泡。

政府每年决定你能拿到多少钱。这个金额叫作「全国标准」（riksnorm）。全瑞典都适用同一个全国标准。

你也可以就某些其他费用获得补助，例如：

- 住房
- 电费
- 家庭财产保险
- 上班的交通费
- 工会会费
- 失业保险基金（a-kassa）会费。

社会服务处会评估这些费用是否合理。什么算合理取决于不同情况，例如你住在哪里、怎么住。

### 其他生活开支补助

对于不是每个月都会发生的某些费用，你也可以获得经济补助。

例如可以是以下方面的费用：

- 看牙
- 眼镜
- 医疗
- 药品。

社会服务处会评估是否需要这笔补助，好让你能过上合理水平的生活。

## 📌 教学备注 (Teaching Notes)

- 📌 **ekonomiskt bistånd / försörjningsstöd / riksnorm** —— 三层概念：*ekonomiskt bistånd*（经济补助，总称，俗称 *socialbidrag*）⊃ *försörjningsstöd*（每月生活费部分）；*riksnorm* 是政府每年定的全国统一标准额。口语里常说「gå på socialbidrag」= 靠社会补助生活。
- 📌 **ansöka om något hos någon** —— 「向某机构申请某物」：*ansöka om ekonomiskt bistånd hos socialtjänsten*。介词 **om** 接申请的东西，**hos** 接机构，别和英语 *apply for / to* 混。
- 📐 **indirekt fråga + bero på**：*Vilket stöd du kan få beror på vad du behöver hjälp med.* —— 疑问词从句当主语和宾语，从句内是**主语在前**的语序（du kan få，不是 kan du få）；*hjälp med* 的介词留在句末。
- 📐 **sammansatta ord（复合词）**：skuld + rådgivare → *skuldrådgivare*，levnad + s + kostnad → *levnadskostnad*，försörjning + s + stöd → *försörjningsstöd*。中间的 **-s-** 是连接音（fogemorfem），重音在第一个成分。
- ⚠️ **rimlig ≠ billig**：*rimlig* 是「合理的、说得过去的」（reasonable），*leva på en rimlig nivå* = 过合理水平的生活；*rimligt* 是中性/副词形，*rimliga* 是复数。
- 🇸🇪 在瑞典，ekonomiskt bistånd 是**最后一道安全网**：先要用尽自己的收入、存款和其他补助（如 a-kassa、bostadsbidrag），socialtjänsten 才会按个人情况评估（*bedöma*）发放。
