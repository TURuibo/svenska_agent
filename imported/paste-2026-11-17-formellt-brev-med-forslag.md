## 瑞典语原文 (Källtext)

Formellt brev med förslag

Situation: Sfi-skolan frågar eleverna hur de tycker att skolan kan bli bättre.

Hallonbergen 19-06-28

Hej skolans ledning,

Vad positivt att ni frågar oss elever om hur skolan kan utvecklas! Jag har flera förslag som jag skulle vilja framföra.

Jag heter Annchi och studerar på D-kursen. Jag är mycket nöjd med mina studier eftersom skolan har engagerade lärare och jag har fått mycket hjälp med att lära mig svenska. Men jag tror att skolan skulle bli ännu bättre om Sfi-kurserna hade ett tydligare kursinnehåll. Jag har en vän som studerar Sfi på en annan skola och de har särskilda kursuppgifter som man måste göra och klara av. Det tror jag är bra för då kan man fokusera på de uppgifterna. Då vet man vad man ska göra för att bli klar med kursen.

En annan sak som jag tycker saknas på skolan är möjligheter att träna svenska på ett naturligt sätt utanför klassrummet. Därför föreslår jag att skolan ska ha ett språkcafé. Caféet skulle kunna erbjuda ämnen att samtala om och eleverna kunde få välja själva vad de vill prata om. Det tror jag skulle hjälpa många elever att utveckla sitt språk.

Sist men inte minst undrar jag om det skulle vara möjligt att ha Sfi-kurser även på helgen? Många elever jobbar under veckan och kan inte studera på veckodagarna. Jag vet att det finns flex-kurser och kvällskurser på skolan men jag tror att helgkurser ändå skulle passa en del elever bättre. Efter en lång arbetsdag orkar inte alla komma till skolan och när man går på flex-kurs går man inte i någon klass. Därför skulle det vara bra med en klassrumskurs på helgen.

Jag uppskattar att jag som elev får möjlighet att påverka skolan och jag hoppas att ni kan utveckla skolan på de sätt som jag föreslår.

Vänliga hälsningar

Annchi Fang

## 🇨🇳 全文翻译 (Översättning)

正式信件：提出建议

情境：SFI 学校询问学生，他们认为学校可以怎样变得更好。

Hallonbergen，19-06-28（2019 年 6 月 28 日）

学校领导们好：

你们来问我们学生学校可以怎样发展，这真是太好了！我有几条建议想提出来。

我叫 Annchi，在读 D 级课程。我对我的学习非常满意，因为学校有投入的老师，我在学瑞典语方面得到了很多帮助。不过我认为，如果 SFI 课程的课程内容更清晰一些，学校会变得更好。我有个朋友在另一所学校读 SFI，他们有特定的课程任务，必须完成并通过。我认为这很好，因为这样就能专注于这些任务。这样就知道要做什么才能完成课程。

我觉得学校还缺少另一样东西：在教室外以自然的方式练习瑞典语的机会。所以我建议学校开一个语言咖啡馆。咖啡馆可以提供一些聊天话题，学生也可以自己选择想聊什么。我认为这会帮助很多学生提高语言能力。

最后但同样重要的是，我想问问是否可以在周末也开 SFI 课程？很多学生平日要上班，没法在工作日学习。我知道学校有弹性课程和晚间课程，但我认为周末课程还是更适合一部分学生。上了一整天班之后，并不是每个人都有力气来学校；而上弹性课程的话，又不在任何一个班里。所以周末开一门在教室上课的课程会很好。

我很感激我作为学生有机会对学校产生影响，希望你们能按我建议的方式发展学校。

此致问候

Annchi Fang

## 📌 教学备注 (Teaching Notes)

**🖊️ 老师手写批注 = 正式「提议信」的结构（Formellt brev）**

| 部分 | 批注原文 | 本信中的内容 |
|---|---|---|
| Plats + Datum | Plats · Datum | Hallonbergen 19-06-28 |
| Hälsningsfras | Hälsningsfras | Hej skolans ledning, |
| Formell inledning | Formell inledning | Vad positivt att ni frågar … Jag har flera förslag … |
| Huvuddel | *Huvuddel där du ger förslag och motiverar dina förslag* | 三个建议：① 更清晰的课程内容 ② 语言咖啡馆 ③ 周末课程 —— 每个都有理由 |
| Formell avslutning | Formell avslutning | Jag uppskattar att … jag hoppas att ni … |
| Formell hälsningsfras | Formell hälsningsfras | Vänliga hälsningar |
| Namn | Namn | Annchi Fang（全名） |

| 点 | 原文 | 说明 |
|---|---|---|
| 💬 列举建议的连接词 | *Men jag tror att …* → *En annan sak som …* → *Sist men inte minst …* | 第一 → 另一个 → 最后但同样重要：议论文/提议信的骨架 |
| 💬 提议句式 | *Jag har flera förslag som jag skulle vilja framföra*, *Därför föreslår jag att …*, *undrar jag om det skulle vara möjligt att …* | skulle vilja / skulle vara möjligt = 礼貌正式 |
| 📐 Vad + adj + att! | *Vad positivt att ni frågar …!* | 感叹句："……真好！" |
| 📐 om + preteritum + skulle | *skolan skulle bli ännu bättre om kurserna hade …* | 假设条件：om 从句用过去时，主句用 skulle → [[grammar-konditionalis-med-om]] |
| 📐 Det tror jag är bra | *Det tror jag är bra*, *Det tror jag skulle hjälpa …* | 宾语从句的主语 det 提到句首（satsflätning），然后 tror jag 倒装 |
| 📐 det saknas / saknas | *En annan sak som jag tycker saknas* | saknas = 缺少（s-形式） |
| 📐 inte i fronten | *orkar inte alla komma* | 否定 + alla："不是每个人都……" |
| 📐 hjälpa ngn att | *hjälpa många elever att utveckla sitt språk* | hjälpa + 人 + att + 不定式 |
| 📌 klara av / bli klar med | *klara av kursuppgifter*, *bli klar med kursen* | 搞定、通过 / 完成 |
| 📌 日期写法 | *19-06-28* | ÅÅ-MM-DD（年-月-日），比 2019-06-28 更简 |
