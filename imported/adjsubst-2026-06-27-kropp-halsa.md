### 📌 本页变形要点（teaching notes）
- **past participle 形容词**：skadad/skadat/skadade；stressad/stressat/stressade；utmattad/utmattat/utmattade；infekterad/infekterat/infekterade；andfådd/andfått/andfådda；frusen/fruset/frusna（frysa 的过去分词，-en 形变 -et，复数 -na）。
- **形容词 syncope**：regelbunden → regelbundna（-en 结尾在 -a 形脱 e）。
- **-am/-am 双写 m**：smärtsam → smärtsamma；hälsosam → hälsosamma（-a 形双写 m；-t 形仍加单 -t → smärtsamt/hälsosamt）。
- **不变 -t 形**：akut（借词，词干已以 -t 结尾，中性形同原形 akut；复数/定式变 akuta）。
- **不规则复数**：öga → ögon / ögonen；tand → tänder / tänderna（变音）。
- **ett-ord 复数不变**：sår → sår / såren；bröst → bröst / brösten（定式加 -en）。
- **syncope 名词**：feber → febern / febrar / febrarna（词干 febr-）；läkare（5 类，复数同单数，定式 läkarna）。
- **不定单数 ett-ord 形容词 -t**：friskt, fräscht, fuktigt, blekt, yrt；注意 torrt（torr 短元音双 r，中性形加 -t）。
