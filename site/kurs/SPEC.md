# 📘 Kurs — 手机上认真学课文 (spec + plan)

> 2026-11-15 · 状态：P0 实施中。本文件是 Kurs 的唯一设计依据；改行为先改这里。
> 与 Flöde 的分工：Flöde = 碎片时间**刷**（见面 + 提取）；Kurs = 手机上**坐下来学**一段课文（理解 → 拆解 → 词 → 练）。

## 1. 现状分析：课文精读为什么在手机上学不动

素材本身很好：14 篇课文有「🔍 逐段精读」，共 116 段、609 句、1 755 条 ⚠️ 要点，格式完全统一。问题在**呈现方式是一篇长文档**：

| 问题 | 现状（以 *Ett perfekt liv* 为例，390×844） | 后果 |
|---|---|---|
| **同一句话出现 4–5 次** | 原文全文 → 全文翻译 → 每段原文 + 段译 → 每句原文 + 句译 → 导入块重点句 | 72 KB 一篇；真正的新信息（📐 结构、⚠️ 要点、生词说明）被重复内容稀释 |
| **同一个词出现 3 次** | 段内「📚 生词」表 → 文末导入块 words → 页面「学习项」面板 | 不知道该看哪份；三份都不含变形表和例句（要再点进笔记） |
| **表格不适合手机** | 26 张表，13 张宽过屏幕（生词表 5 列） | 横向滑动、字小 |
| **一页到底** | 段落全折叠时就有 17 屏，展开后数倍 | 找不到上次学到哪；被打断就丢位置 |
| **没有「学完」的概念** | 只有整篇「标为已读」 | 不知道哪段学过、哪句没懂、哪些词要记 |
| **看完不检验** | 精读内容只读不测 | 读懂 ≠ 记住；词的变形从没被主动提取过 |
| **顶部工具占 1/3 屏** | 题材 / 主题 / 补弱项 / 未读 / 生词 / 查词 / 想学 / 搜索 | 手机上正文可视区很小 |

**结论：内容不改、不删，改的是切法。** 把「文档」重排成「以句子为单位、分层展开、可断点续学」的课程。Läsning 里的长文档保留（电脑上通读用）。

## 2. 设计原则

| 原则 | 落实 |
|---|---|
| **单一出处，不重复** | 每句话、每个词在界面上只有一个「家」；其它地方是引用它，不是再抄一遍 |
| **不丢信息** | 精读里的每一行都必须进到某个字段；解析不了的原样放进 `extraMd` 显示。构建脚本 `--check` 逐行对账 |
| **分层展开** | 先原文 → 再结构 → 再要点 → 最后译文。译文默认收起（先自己想），一点即开 |
| **一屏一个单位** | 一句一页、一词一卡；没有横向滚动的表格 |
| **一段 = 一次学习** | 每段 3–6 句，约 3–5 分钟；四步走完算学完一段 |
| **随时中断、原地继续** | 位置精确到「课 / 段 / 步 / 句」自动保存；首页最上面永远是「继续上次」 |
| **学了就测** | 每段末尾 5–8 题，用的就是这一段的句子和词；成绩进 Öva 的间隔重复，之后 Flöde 会自动再考 |
| **词要学全** | 点任何一个词：文中形式 → 原形、它是哪个变形、完整变形表、IPA、🇸🇪 释义、例句、搭配、用法提示，都在同一张底部卡片里，不跳页 |

        ▼
课文页

 │    ② 拆   一句一页，左右滑；结构色块 + 要点卡 + 译文
 │    ③ 词   本段词组 + 生词，一行一个，点开看全

      📚 本课词表  全部生词合并去重，可只看 ⭐

### 点一个词 —— 底部卡片（不离开当前句）

```
┌──────────────────────────────┐
│ läste  →  läsa   verb · A1   🔊      │  文中形式 → 原形
│ 读 · to read                         │
│ 说明：läsa – läste – läst            │  ← 段内生词表的「说明」
│ ┌ 变形 ───────────────┐      │
│ │ infinitiv    läsa            │      │
│ │ presens      läser           │      │
│ │ preteritum   läste   ◀ 文中  │      │  ← 自动标出文中是哪个变形
│ │ supinum      läst            │      │
│ └──────────────────────┘      │
│ /ˈlɛːsa/ · 🇸🇪 titta på text och förstå │
│ ▸ 例句（3）  ▸ 搭配  ▸ 用法提示  ▸ 词族 │  ← 笔记的其余小节，点开看
│ ☆ 要记      ✓ 已会      完整笔记 →   │
└──────────────────────────────┘
```

### ④ 练 —— 题型（全部由本段数据在客户端生成）

| 题型 | 样子 | 数据来源 | 练什么 |
|---|---|---|---|
| 词义 | 句子里高亮一个词 → 选中文（4 选 1） | 段内生词表 | 语境中认词 |
| 变形 | `ångra` · preteritum → 从它自己的几个变形里选 | KB 变形表 | **词的各种 form** |
| 排语序 | 把打乱的成分块点成原句 | 📐 结构块（3–7 块的句子） | V2、从句语序 |
| 填空 | 句子挖掉一个词 → 选（选项是变形后的词） | 句子 + 生词表 | 回忆 + 变形 |

答错立即给出正确答案和该句的 ⚠️ 要点；词义 / 变形 / 填空的对错写进 `ova.state.v1`（规则同 Öva / Flöde）。可「跳过练习」，段仍算学完但标记为未测。

## 4. 「不丢信息」对账表

| 原文档里的东西 | 在 Kurs 里的家 | 去掉的重复 |
|---|---|---|
| 元信息行（体裁 / CEFR / 来源） | 课文页标题下、首页卡片 | — |
| `## 瑞典语原文` | 各段 ① 读；连起来 = 📜 全文 | 段内又抄一遍的原文 |
| `## 🇨🇳 全文翻译` | 各段的段译；📜 全文里逐段可开 | 全文翻译与段译是同一内容 |
| `## 📌 教学备注` 表 | ⋯ → 📌 语法要点（一行一卡） | — |
| 段标题 `### ¶N · …（N 句）` | 段落进度条、段首 | — |
| 每句 `**① …**` | ② 拆的一页 | 句子在段原文里的再次出现 |
| `- 📐 …` | 结构色块（解析失败则原样显示） | — |
| `- ⚠️ …`（含 `[[链接]]`） | 要点卡；链接 → 底部卡片 | — |
| `- 🇨🇳 …` | 句译（收起） | — |
| `#### 🧩 词组` 表 | ③ 词 的词组行 | — |
| `#### 📚 生词` 表（文中形式 / 原形 / 词性 / 中文 / 说明） | ③ 词 的生词行 + 底部卡片 | 导入块 words 与它合并去重 |
| 导入块 `# sentences`（重点句） | 对应句子页上的「重点句」标记；⭐ 我的标记里可筛 | 句子再次出现 |
| 导入块 `# grammar` | 📌 语法要点 末尾的「本课语法」列表 | — |
| 非标准小节（`### 图片说明`、`### Läxförhöret` 等） | 作为「附加段」，原样渲染 | — |
| 词笔记（变形表 / 例句 / 搭配 / 用法 / 词族） | 底部卡片 | 原来要跳到 Sök 才看得到 |

## 5. 状态

| key | 内容 |
|---|---|
| `kurs.state.v1` | `{ v:1, last: { slug, para, step, sent, at }, lessons: { <slug>: { paras: { <n>: { read:1, sents:[已看过的句序号], words:1, quiz:{ right, total, at } \| 'skipped' } }, starSents: { '<n>.<i>': 1 } } }, starWords: { <slug>: 1 }, knownWords: { <slug>: 1 }, prefs: { showZh:false, rate:0.85 } }` |
| `ova.state.v1` | 与 Öva / Flöde 共用：客观题对错按 Öva 规则写入（写前先重读，避免覆盖别的标签页） |
| 已读 | 整课学完后出现「✓ 标为已读」→ `ReadSync.setRead(<文章 slug>, true)`，与 Läsning 同一个标记，所以**算 §4.9 的活跃** |

段「学完」= 四步都到过（练可跳过）。位置随每次翻页即时保存；损坏 / 无 localStorage 时不崩，只是不记进度。

## 6. 数据契约（**冻结**——构建端和页面端都按它写）

`tools/build-kurs-data.js` 直接读 `imported/*.md`（凡含 `## 🔍 逐段精读` 的文件）+ `knowledge_base/` 笔记 + `listening/*.json`（找 `readingSlug`），不依赖其它 build。产出两类文件，均 **gitignore、由 Action 构建**：

- `site/kurs/kurs-index.js` → `window.KURS_INDEX`
- `site/kurs/data/<slug>.js` → `window.KURS_LESSONS = window.KURS_LESSONS || {}; window.KURS_LESSONS['<slug>'] = {...}`（按需用 `<script>` 加载，一课一个文件，≤ 800 KB raw，gzip 后最大约 250 KB）

文中凡标 `md` 的字段是**行内 Markdown**（`**粗**`、`*斜*`、`` `码` ``、`[[slug]]`、`[[slug|显示名]]`）；`secs[].md` 是**块级 Markdown**（可含表格、列表），页面用 `../kb-markdown.js` 渲染。所有 `[[slug]]` 目标若存在，一定在该课的 `kb` 里。

```js
window.KURS_INDEX = {
  v: 1, generatedAt: '…',
  lessons: [{                      // 新的在前
    slug: 'paste-2026-10-15-ett-perfekt-liv',   // = 文章 slug = ReadSync id
    title: 'Ett perfekt liv',      // 去掉 🇸🇪 和括号里的页码
    sub: 'SFI s. 129–131',         // 标题括号里的内容，或 ''
    book: '教材课文（Gilla svenska s. 129–131 · 第 6 章 …）',  // **体裁:** 行，或 ''
    cefr: 'B1', date: '2026-10-15',
    paras: 16, sents: 74, words: 66,
    paraTitles: ['一条消息', '童年和少年时代'],   // 供首页 / 进度条
    listen: 'sprakvagen-d-…' | ''  // 对应的 Lyssna 集 id（有 readingSlug 指向本文时）
  }]
};

lesson = {
  v: 1, slug, title, sub, cefr, date,
  meta: [{ k: '体裁', v: '…md' }, { k: '来源', v: '…md' }],
  notes: [{ point: '📐 ju … desto', sv: '…md', zh: '…md' }],   // 教学备注表的行
  notesMd: '',                     // 教学备注里表格以外的内容（块级 md），无则 ''
  paras: [{
    n: 1,                          // ¶ 编号；非标准小节从 100 起编
    kind: 'para',                  // 'para' | 'extra'（非 ¶ 小节）
    title: '一条消息',
    sv: 'Johan läste … sedan sist.',   // 段原文（保留换行，对话段一行一句）
    zh: 'Johan 第五次读这条消息。…',
    sents: [{
      i: 1,                        // 段内序号
      sv: 'Johan läste meddelandet för femte gången.',   // 去掉 **①** 包装
      chunks: [{ t: 'Johan', r: 'S' }, { t: 'läste', r: 'V' },
               { t: 'meddelandet', r: 'O' }, { t: 'för femte gången', r: 'A' }],
                                   // 由 📐 行解析：`文本`(角色)，顺序即原文顺序；
                                   // 角色照抄括号内容（S/V/O/A/表语/不定式/形式主语/V…/…）
                                   // 没标角色的成分给 r:''；行里有反引号外的说明文字、或拼不回原句 → null
                                   // （实测约 50% 的句子有 chunks；其余由页面把 struct 渲染成「色块 + 行间说明」）
      struct: '`Johan`(S) + `läste`(V) + …',   // 📐 行原文 md（去掉 "- 📐 "），总是保留
      points: ['「第 N 次」= **för + 序数词 + gången** … → [[grammar-…|📗叙事用过去时]]'],  // 每条 ⚠️，md
      zh: 'Johan 第五次读这条消息。',
      key: 0,                      // 1 = 这句在导入块 # sentences 里（重点句）
      extra: []                    // 该句下其它没归类的行（md），无则 []
    }],
    phrases: [{ sv: 'för femte gången', slug: '' /* 或已存在的词组 slug */, zh: '第五次', use: 'läste meddelandet för femte gången' }],
    vocab: [{ form: 'läste', lemma: 'läsa', slug: 'läsa' /* 笔记不存在则 '' */, pos: 'verb', zh: '读', note: 'läsa – läste – läst' /* md */ }],
    extraMd: ''                    // 该段里没被上面任何字段收走的内容（块级 md）。extra 小节的正文也放这里
  }],
  items: {                         // 导入块，供「本课词表 / 本课语法」
    words:   [{ sv, pos, zh, en, slug }],     // slug 解析不到则 ''
    phrases: [{ sv, pos, zh, en, slug }],
    grammar: [{ name, zh, en, slug }]
  },
  forms: { 'läste': 'läsa', 'meddelandet': 'meddelande' },   // 小写表层形式 → kb 里的词 slug；
                                   // 覆盖本课瑞典语正文里所有能在 KB 找到笔记的词（含变形）
  guideMd: '',                     // 精读开头的「💡 读法 / 💡 符号」说明（块级 md），可为空
  kb: {                            // 本课引用到的全部笔记
    'läsa': {
      t: 'word', title: 'läsa', pos: 'verb', genus: '', cefr: 'A1', zh: '读', en: 'to read',
      ipa: '/ˈlɛːsa/' /* 或 '' */, pron: '发音提示整行原文' /* 或 '' */, def: '🇸🇪 释义' /* 或 '' */,
      table: [['infinitiv', 'läsa'], ['presens', 'läser'], ['preteritum', 'läste'], ['supinum', 'läst']],  // 变形表行，无则 []
      secs: [{ h: '词组搭配', md: '…' }, { h: '例句', md: '…' }, { h: '用法提示', md: '…' }],
                                   // 笔记正文里除变形表外的各 `##` 小节（标题去掉括号英文）；
                                   // full 级才有，lite 级为 []
      lvl: 'full',                 // 'full' = 出现在生词表 / 导入块 / [[链接]]；'lite' = 只是正文里出现的词
      ex: [['Jag läser en bok.', '我在读一本书。']],   // 最多 2 个例句（lite 级也给）
      known: 0
    },
    'ha-svårt-att': { t: 'phrase', title: 'ha svårt att', zh: '难以……', en: '…', cat: 'verbfras', secs: [...] },
    'grammar-inversion-efter-fundament': { t: 'grammar', title: '…', zh: 'V2 倒装', tip: '一句话', secs: [...] },
    'sent-…': { t: 'sentence', title: '…', zh: '…', secs: [] }   // 其它类型：至少 t/title/zh
  }
};
```

`node tools/build-kurs-data.js --check`：对每课打印并校验——段数 = `### ¶` 数；句数 = `**①…**` 数；每句都有 `struct` 和 `zh`；⚠️ 条数对得上；`chunks` 解析率；生词行数对得上；**逐行对账**（精读小节里每个非空行都进了某个字段或 `extraMd`）；`[[slug]]` 悬空数；每课文件大小。任一硬指标不符则退出码非 0。

## 7. 技术设计

| 项 | 决定 |
|---|---|
| 文件 | `site/kurs/index.html` · `kurs.js` · `kurs.css` · `sw.js`；`tools/build-kurs-data.js` |
| 依赖 | `../styles.css`、`kurs.css`、`kurs-index.js`、`../kb-markdown.js`、`../speak.js`、`../read-sync.js`、`kurs.js`、`../nav.js`。**不加载** `kb-index.js` / `kb-bodies.js` / `reading-data.js`。课文数据按需插 `<script>` |
| 路由 | hash：`#` 首页 · `#l=<slug>` 课文（回到上次位置）· `#l=<slug>&p=<n>&s=<step>&i=<句>`；浏览器返回键可用 |
| 布局 | 首页显示站点导航；进入课文后隐藏站点导航，底部换成四步 tab。② 拆 用横向 scroll-snap 分页，每页内部可竖向滚动（要点多的句子不截断） |
| 结构色块 | S / V / O / A 四种固定颜色，其它角色用中性色；色块按原文顺序换行排列，角色小字标在块下；`chunks` 为 null 时把 `struct` 渲染成「富结构」：反引号里的片段照样成色块（后面跟 `(角色)` 就上色），片段之间的说明文字原样留在行间 |
| 底部卡片 | 一个通用 bottom sheet：词 / 词组 / 语法 / 句子笔记都用它；可下拉关闭；内部可滚动；卡片里的 `[[链接]]` 在同一卡片内前进，带返回 |
| 语音 | `SvSpeak.speak`；句子、例句、词都有 🔊；语速在设置里 |
| 离线 | `sw.js` 作用域仅 `kurs/`，stale-while-revalidate（同 Flöde 的做法）：打开过的课离线可学 |
| 导航 | `nav.js` 加 `{ id: 'kurs', icon: '📘', label: 'Kurs' }`，排在 Flöde 之后（8 个 tab，360 px 已验证放得下） |
