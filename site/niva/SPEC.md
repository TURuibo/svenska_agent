# 🪜 Nivå — 按级别集中学 (spec + plan)

> 2026-11-21 · 状态：**P0 已实现**（阶梯 + 级别页 7 个分区 + 语法「学过」✓ + 各页「← 返回 Nivå」，见 §12）；P1 / P2 待做。本文件是 Nivå 的唯一设计依据；改行为先改这里。
> 一句话：**选一个级别（A1 / A2 / B1 / B2+），一页看到这一级的全部材料——按顺序、带进度；这一级学完、自测通过，再进下一级。**
> 与其它页的分工：Dagbok = 按**日期**索引；Nivå = 按**级别**索引。材料仍住在原来的页面（Läsning / Tala / Lyssna / Kurs / Sök），
> Nivå 只回答三个问题：**这一级有什么 · 先学哪个 · 我学到哪了**。

## 2. 设计原则

| 原则 | 落实 |
|---|---|
| **一级 = 一个完整单元** | 这一级的语法、单词、词组、阅读、情景、听力、课文都在同一页，各成一个分区 |
| **只做索引，材料不搬家** | Nivå 列清单、算进度、给「下一步」；点开就跳到原页面（带 `frompage=niva`，那边有「← 返回 Nivå」） |
| **级别可信，规则只有一套** | 一个归级函数给所有类型用；区间 → 「🌉 过渡」；缺标签 → 推断并标「≈」；文本另算**实测难度**，用来排序 |
| **由易到难，不用做决定** | 每级每个分区都有固定顺序；页面上永远有一个「▶ 下一步」 |
| **快速过一遍，留下真实的掌握情况** | 单词 / 词组可以「过一遍」：翻卡自评 😎 会 / 🤔 不会。会 → `known: true`（经 `/ova` 写回 KB）；不会 → 进 Öva / Flöde 的复习 |
| **通关有标准，但不上锁** | 每级有完成度和 🏁 自测；通过后推荐进下一级，但任何一级随时都能看 |
| **设一次当前级别，各页都跟着** | 「📌 设为当前级别」后，Läsning / Tala / Lyssna / Öva / Kurs 默认按它筛选；随时点 ✕ 取消 |
| **轻** | 自带一个 ≤ 1 MB 的数据文件（gzip 后约 250 KB），不加载 6 MB 的 `kb-index.js`（同 Flöde / Kurs 的做法） |
| **缺材料就补** | 某级某类太少（如 A1 听力 0 集）→ 显示缺口卡片 + 可复制的生成命令 |

**非目标：** 不复制材料内容、不替代 Läsning / Tala / Lyssna / Kurs 的阅读界面；不做账号 / 后端；不改 §4.9 活跃度规则（Nivå 本身没有「标为已读」，在原页面读完再标）。

## 4. 归级规则（**冻结**：构建端只有一个函数 `tools/level-lib.js`，页面端 `site/niva-focus.js` 用同一套）

### 4.1 解析一个级别字符串

```
parseLevel(raw) → { lo, hi } | null
  1. 字符串里有「CEFR」→ 只看它后面的部分            "SFI B / CEFR A2"    → A2
  2. 取所有 A1–C2 记号：lo = 最低，hi = 最高          "A2–B1"              → A2..B1
  3. 没有 CEFR 记号、只有 SFI 字母：A→A1 · B→A2 · C→A2..B1 · D→B1   "SFI C" → A2..B1
  4. 都没有 → null

归属级别 lv = lo（C1、C2 并入 B2+）
hi > lo → br = 1：🌉 过渡材料，排在本级每个分区的末尾，标「→ B1」
```

> 为什么区间按**下限**归：标「A2–B1」的材料对刚学完 A2 的人正好是「跳一跳够得着」，放在 A2 末尾当过渡最合适；
> A2 末尾这一段 ≈ SFI C（官方近似 A2+ / B1−），与 sv-assess 的等级标尺一致。

### 4.2 各类型从哪取级别

| 类型 | 先看 | 再看 | 都没有时 |
|---|---|---|---|
| 单词 | `cefr` | — | （目前没有缺的） |
| 句子 | `cefr` | — | 句中词的最高级别（≈） |
| 语法 | `cefr` | `level` → 正文「级别:」行 | 未分级区 |
| 词组 | `cefr` | `head_words` 里各词级别的**最高值**（≈） | 链接到它的句子的级别中位数（≈）→ 未分级区 |
| 文章 / 情景 / 新闻 | 正文 `CEFR 估计` 行（**保留区间，不再截断**） | frontmatter `cefr` | 实测级别（≈，§4.3） |
| 词形练习 adjsubst | 导入块里各词级别的中位数（≈） | — | — |
| 没有正文可测、也没标级别的文本（如只有导入块的旧文件） | 导入块里各词级别的中位数（≈） | — | 不进 Nivå |
| 听力 | JSON `cefr` | 关联文章（`readingSlug`）的级别 | — |
| 课文（Kurs） | 文章的 CEFR 行 | — | — |

- 「≈」= 推断出来的级别，界面上显示为 `≈A2`，排序与正式标签相同。
- `horning-*` 文章就是 Lyssna 某一集的文字版，归入 🎧 听力分区（与那一集合并显示），不在 📖 阅读里重复。

### 4.3 文本的实测难度（只用来**排序**和提示，不改变归属级别）

```
lix  = 词数 / 句数 + 100 × 长词数(> 6 个字母) / 词数
       瑞典通用可读性指数：< 25 很易（童书）· 25–30 易 · 30–40 中等（报刊、小说）· 40–50 难（说明文）· > 50 很难（公文）
over = 超出本级的词次占比
       （认词：KB 单词笔记的变形表 + Kelly / SVALex 参考词表 profile/vocab-gaps.json；
        小写且两边都认不出的词也算超出；大写开头的专名不计）
len  = 词数

难度 d = 本级内的百分位：0.45 · rank(lix) + 0.45 · rank(over) + 0.10 · rank(len)  → 显示成 ●○○○○ 到 ●●●●●
⬆ 偏难 = 超出**标注上限**的词 > 10%（区间取上限：标「A1–A2」的文本用到 A2 词是应该的，不算偏难；
        每 10 个词就有 1 个超纲，不查词读不顺）。实测（2026-11-21）：259 篇里 12 篇。
```

- 计算放在 `build-reading-site.js` 里（它已经有词形 → 词元的映射），结果作为新字段写进 `reading-data.js`，Läsning / Tala 也能用来排序。
- 只做排序，不移动级别：标签是写文章时就定好的「目标级别」，实测只是告诉你在这一级里先读哪篇。

### 4.4 语法的顺序

- **P0（自动）：按被引用次数从多到少排**——一个语法点被越多句子 / 文章链接，说明越常见、越该先学。
  前 1/3 = 「核心」，中间 = 「常用」，其余 = 「细节」（多是 `betala-för-vs-betala` 这类用法小点）。
  实测 A1 排出来是：V2 语序 → 过去时 → 现在时 → 祈使句 → 定冠词形式 → 不定式 → ska + 不定式 → 空间介词 …；
  A2 是：从句 → 现在完成时 → 比较级 → 关系从句 → 反身动词 → 形容词一致 …
- **P2（可选）：手排课纲 `profile/niva-syllabus.md`**：每级列出语法 slug 的教学顺序，还可以**改级别**
  （例如 `grammar-preteritum` 现在标的是 A1，一般教材放在 A2）。有课纲时以课纲为准，课纲里没提到的按 P0 规则排在后面。

## 5. 进度与通关

### 5.1 每个分区怎样算「完成」

| 分区 | 算完成 | 数据从哪来 |
|---|---|---|
| 📗 语法 | 读过并勾「✓ 学过」 | `niva.state.v1.grammar` |
| 🔤 单词 / 🧩 词组 | 「会」= 过一遍时点了 😎，或 KB 里 `known: true`，或 Öva 箱 ≥ 4，或 Flöde 里点过「😎 会了」 | `niva.state.v1` + 数据里的 `k` + `ova.state.v1` + `flode.state.v1.mute` |
| 📖 阅读 / 🗣️ 情景 | 标为已读 | `ReadSync`（与 Läsning / Tala 同一个标记） |
| 🎧 听力 | 标为已读 | `ReadSync('lyssna:<id>')` |
| 📘 课文 | 所有段都学完 | `kurs.state.v1` |
| 💬 句子 | 不单独计（数量太多；自测和 Flöde 会覆盖） | — |

**级别完成度** = 本级**有材料的**分区完成度的平均值（A1 没有听力和课文，就不算这两项）。

### 5.2 通关条件（建议值，可调）

| 条件 | 阈值 |
|---|---|
| 单词「会」 | ≥ 80% |
| 语法 ✓ | 核心 100%，全部 ≥ 70% |
| 阅读 + 情景 已读 | ≥ 50%（本级不足 10 篇时：全部读完） |
| 🏁 自测 | ≥ 80%（16 / 20） |

全部满足 → 这一级打 ✅、阶梯点亮、提示「进入 B1？」（点了就把当前级别切过去）。
**不上锁**：没通关也能打开任何一级。

- 结果存进 `tests`；满足 §5.2 的其它条件 + 自测 ≥ 80% → `passed`。
- 答错的词 → Öva 箱 0、今天到期（之后在 Öva / Flöde 里复习）。
- **定级（🧭 从哪开始）**：从 A1 自测开始，≥ 90% 就自动接着测下一级，直到某一级 < 80%——那一级就是起点，前面的级别标「✅（测试通过）」。
  总共 4–12 分钟。

## 6. ▶ 下一步

在当前级别里按下面的顺序找第一个没完成的，一次只给一件事：

1. 单词「过一遍」中断的那一组 → 继续
2. 还没学的**核心**语法（一次一个）
3. 最容易的未读文本（阅读和情景轮流）
4. 还没听的听力 / 还没学完的课文

## 11. 页面与路由

- `site/niva/`：`index.html` · `niva.js` · `niva.css`（`?v=N`），`<body data-site="niva">`；加载 `../styles.css`、`../nav.js`、`../read-sync.js`、`niva-data.js`
  （P1 翻卡要朗读时再加 `../speak.js`）。
- Hash 路由：`#` 阶梯 · `#lv=A2` 级别页 · `#lv=A2&sec=read` 某分区 · `#lv=A2&sec=read&i=<id>` 定位到某一行（滚过去、闪一下，然后从网址里去掉 `i`）。
  P1：`#lv=A2&sec=words&g=topic-mat-dryck` 过一遍 · `#lv=A2&test=1` 自测 · `#place=1` 定级。
  分区 tab 用 `replaceState`（不产生历史记录）；阶梯 → 级别用 `pushState`，所以「←」和浏览器后退都回阶梯；直接打开某一级的链接时，先在底下垫一条阶梯记录（同 Kurs 的做法）。
- 返回入口：每一行打开 Läsning / Tala / Lyssna / Kurs 时带 `&from=<Nivå 的 hash，整段编码>&frompage=niva`。
  Läsning / Tala 的 `BACK_TARGETS` 加 `niva → ../niva/#`，Lyssna 的 `epBackLink` 同理，标签「← 返回 Nivå」；
  Kurs 从 Nivå 打开时左上角「←」直接回 Nivå（进过 Kurs 首页后恢复原样）。Nivå 解析 hash 前先整段 `decodeURIComponent`。
  去 Sök 看笔记不带参数：离开前先把这一行写进 Nivå 自己的网址（`&i=`），浏览器后退就落回原处。
- Öva：支持 `#deck=all&level=A2`（单词分区的「🔁 在 Öva 里复习 A2 单词」用它）。
- 导航：`nav.js` 的 `DEST` 在 Dagbok 后面加 `{ id: 'niva', icon: '🪜', label: 'Nivå' }`，共 9 个 tab。
  360 px 实测：每个 tab 38 px，最长标签「Läsning / Dagbok」34 px，一行放得下、不截断。
